# Initial Enumeration – Windows Privilege Escalation

## 1. Initial Enumeration কী?

Windows host-এ low-privileged shell পাওয়ার পর privilege escalation-এর জন্য system সম্পর্কে তথ্য সংগ্রহ করতে হয়।

Privilege escalation করে পাওয়া যেতে পারে:

- `NT AUTHORITY\SYSTEM` — LocalSystem; local administrator-এর চেয়েও বেশি privilege।
- Built-in `administrator` account।
- Local `Administrators` group-এর অন্য account।
- Local Administrators group-এর সদস্য standard domain user।
- Local Administrators group-এর সদস্য Domain Admin।

এতে sensitive file/share, অন্য credential এবং Active Directory-তে Domain Admin access পাওয়ার সুযোগ তৈরি হতে পারে।

Enumeration গুরুত্বপূর্ণ, কারণ OS version, patch, installed software, privilege, group membership ও running service সম্পর্কে জানতে হয়।

Manual enumeration জানা জরুরি, কারণ network restriction, internet না থাকা বা security protection-এর কারণে tool ব্যবহার করা নাও যেতে পারে।

[Windows Commands Reference](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/windows-commands?utm_source=chatgpt.com)

## 2. Key Data Points

| বিষয়             | কী জানতে হবে                                                                   |
| ---------------- | ------------------------------------------------------------------------------ |
| OS Name          | Windows workstation নাকি server, যেমন Windows 7/10, Server 2008/2012/2016/2019 |
| Version          | নির্দিষ্ট version-এর public exploit থাকতে পারে                                 |
| Running Services | বিশেষ করে `SYSTEM` বা administrator privilege-এ চলা service                    |

সতর্কতা: Windows exploit চালালে system unstable বা crash করতে পারে। Production system-এ চালানোর আগে exploit ও তার প্রভাব বুঝতে হবে।

## 3. System Information

System information থেকে OS version, hardware, installed program ও security update সম্পর্কে জানা যায়। এগুলো missing patch ও সম্ভাব্য CVE খুঁজতে সাহায্য করে।

### 3.2 Environment Variables – `set`

```
set
```

গুরুত্বপূর্ণ variable:

- `PATH` — Windows program খোঁজার directory list।
- `HOMEDRIVE` — User-এর home drive।
- `USERPROFILE` — User profile directory।
- `APPDATA` — Application data directory।

PATH কেন গুরুত্বপূর্ণ?

- Windows প্রথমে Current Working Directory (CWD), তারপর PATH-এর directory-গুলো বাম থেকে ডানে search করে।
- PATH-এ Python বা Java থাকলে Python ও `.JAR` file execute করা যায়।
- PATH-এর কোনো folder user-এর writable হলে DLL Injection-এর সুযোগ থাকতে পারে।
- Custom writable path যদি `C:\Windows\System32`-এর আগে থাকে, ঝুঁকি বেশি।

`HOMEDRIVE` বা file share-এ IT inventory spreadsheet, password ইত্যাদি পাওয়া যেতে পারে।

Roaming Profiles-এর কারণে user এক machine থেকে অন্য machine-এ একই profile ব্যবহার করতে পারে। Startup folder-এ malicious file থাকলে অন্য machine-এ login করার সময় সেটি execute হতে পারে।

## 4. User & Group Information

User ও group enumeration করে জানা যায়:

- কোন user system-এ logged in।
- Current user-এর privilege কী।
- কোন group-এ user আছে।
- Password policy কী।
- কোনো গুরুত্বপূর্ণ user-এর directory-তে password file আছে কি না।

### 4.1 Logged-in Users

```
query user
```

```
USERNAME              SESSIONNAME        ID  STATE   IDLE TIME  LOGON TIME
>administrator         rdp-tcp#2           1  Active          .  3/25/2021 9:27 AM
```

কোন user active বা idle তা জানা যায়। Active user-এর কাজ পর্যবেক্ষণ বা target করলে detection এড়াতে সতর্ক থাকতে হবে।

### 4.2 Current User

```
echo %USERNAME%
```

```
htb-student
```

প্রথমে current account context জানতে হবে। কখনো initial access-এই `SYSTEM` privilege থাকতে পারে।

Service account হলে `SeImpersonatePrivilege` থাকতে পারে, যা [Juicy Potato](https://github.com/ohpe/juicy-potato?utm_source=chatgpt.com) দিয়ে privilege escalation-এ কাজে লাগতে পারে।

| `net localgroup`                                              | All local groups                   |
| `net localgroup administrators`                               | Administrators group members       |
| `net accounts`                                                | Password policy                    |
