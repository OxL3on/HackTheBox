# Introduction to Windows Privilege Escalation

## 1. Privilege Escalation কী?

কোনো Windows system-এ initial access পাওয়ার পর নিজের permission বা privilege বাড়ানোকে Privilege Escalation বলে।

সাধারণ লক্ষ্য:

- `Local Administrators` group-এর member হওয়া।
- `NT AUTHORITY\SYSTEM` access পাওয়া।
- কখনো অন্য কোনো user-এর access পেলেও উদ্দেশ্য পূরণ হতে পারে।

এতে পাওয়া যায়:

- বেশি system access।
- Local sensitive information ও credentials।
- Network-এ lateral movement করার সুযোগ।

### কেন Privilege Escalation প্রয়োজন?

1. Client-এর Windows workstation ও server build (Gold Image) পরীক্ষা করতে।
2. Database-এর মতো local resource access করতে।
3. Domain-joined machine-এ `NT AUTHORITY\SYSTEM` access নিয়ে Active Directory environment-এ foothold পেতে।
4. Network-এ lateral movement বা privilege escalation-এর জন্য credentials পেতে।

## 2. Privilege Escalation Methods

Tools ব্যবহার করা যায়, তবে manually check করাও শিখতে হবে। কারণ target machine-এ internet না থাকা, firewall বা USB restriction-এর কারণে tools ব্যবহার করা সম্ভব নাও হতে পারে।

PowerShell ও Windows CMD দিয়ে manual enumeration জানা জরুরি।

| Methods                             |
| ----------------------------------- |
| Windows group privileges abuse      |
| Windows user privileges abuse       |
| User Account Control (UAC) bypass   |
| Weak service/file permissions abuse |
| Unpatched kernel exploits           |
| Credential theft                    |
| Traffic capture                     |
| আরও অনেক কিছু                       |

## 3. Real-world Scenarios

### Scenario 1 – Network Restrictions

- Target system-এ internet ও USB access বন্ধ ছিল।
- Printer VLAN-এ outbound port `80`, `443`, `445` allowed ছিল।
- Manual enumeration করে permission-related flaw পাওয়া যায়।
- LSASS process-এর memory dump নেওয়া হয়।
- Attack machine-এর SMB share mount করে LSASS DMP file বের করা হয়।
- Offline Mimikatz দিয়ে Domain Admin-এর NTLM hash পাওয়া যায়।
- Hash crack করে Domain Controller access করা হয়।

### Scenario 2 – Pillaging Open Shares

- Open file share-এ সবাই file list ও download করতে পারত।
- সেখানে VM backup পাওয়া যায়: `.VMDK`, `.VHDX`।
- Windows VM-এ `.VHDX` mount করে filesystem access করা হয়।
- `SYSTEM`, `SAM`, `SECURITY` registry hives সংগ্রহ করা হয়।
- Linux machine-এ `secretsdump.py` দিয়ে local administrator hash বের করা হয়।
- Gold Image ব্যবহারের কারণে একই hash দিয়ে প্রায় সব Windows system-এ Pass-the-Hash করে admin access পাওয়া যায়।

### Scenario 3 – Hunting Credentials and Abusing Account Privileges

- Standard domain user account দিয়ে শুরু।
- `Snaffler` দিয়ে file share-এ sensitive information খোঁজা হয়।
- `.sql` file থেকে low-privileged database credentials পাওয়া যায়।
- MSSQL client দিয়ে database-এ connect করা হয়।
- `xp_cmdshell` enable করে local command execution পাওয়া যায়।
- Service account-এর `SeImpersonatePrivilege` পাওয়া যায়।
- Custom compiled `Juicy Potato` ব্যবহার করে local admin user তৈরি করা হয়।
- Reverse shell/beacon কাজ করেনি, তবে remote access করে client's database-এর সম্পূর্ণ control পাওয়া যায়।

## 4. Why Does Privilege Escalation Happen?

একটি নির্দিষ্ট কারণ নেই। সাধারণ কারণ:

- Personnel-এর অভাব।
- Budget-এর অভাব।
- নিয়মিত patching না করা।
- Vulnerability management দুর্বল।
- Periodic internal assessment না করা।
- Continuous monitoring না করা।
- Workstation ও server upgrade না করা।
- File share audit না করা।
- Credentials থাকা script ও configuration file নিরাপদ না রাখা।

## 5. Moving On

Real-world penetration test-এ শুধু একটি host attack করলেই হয় না। Creative way-তে privilege escalate করে সেই access ব্যবহার করে assessment-এর মূল লক্ষ্য পর্যন্ত এগোতে হয়।

## 6. Practical Examples

এই module-এ বিভিন্ন command ও output দেওয়া হবে। সংশ্লিষ্ট target VM-এ এগুলো practice করা যাবে।

- Target VM-এর RDP credentials দেওয়া হবে।
- Pwnbox অথবা নিজের VM থেকে connect করা যাবে।
- নিজের VM ব্যবহার করলে machine spawn হওয়ার পর VPN key download করতে হবে।
- RDP-এর জন্য FreeRDP, Remmina অথবা অন্য RDP client ব্যবহার করা যাবে।

### Tools Location

অনেক section-এর প্রয়োজনীয় tools, precompiled binaries ও exploit PoC target host-এর নিচের directory-তে পাওয়া যাবে:

```
C:\Tools
```

নিজেও File Transfers module-এর technique ব্যবহার করে file upload এবং Visual Studio দিয়ে tools compile করার practice করতে হবে।

মূল শিক্ষা: শুধু tools-এর ওপর নির্ভর না করে manual enumeration ও creative privilege escalation শেখো।
