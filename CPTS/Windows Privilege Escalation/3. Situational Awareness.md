# Situational Awareness

## Situational Awareness কী?

কোনো system-এ access পাওয়ার পর privilege escalation করার আগে system ও network সম্পর্কে ধারণা নিতে হবে।

আমাদের জানতে হবে:

- কোন কোন host-এ access পাওয়া সম্ভব।
- কী কী security protection চালু আছে।
- কোন tools কাজ করবে বা block হবে।
- অন্য network-এ যাওয়ার সুযোগ আছে কি না।

## Network Information

Network enumeration করে গুরুত্বপূর্ণ তথ্য পাওয়া যায়।

Dual-homed host: যে host দুই বা তার বেশি network-এর সঙ্গে connected থাকে এবং একাধিক network interface থাকে।

এ ধরনের host compromise করলে অন্য network-এ Lateral Movement সম্ভব হতে পারে।

যা যা পরীক্ষা করতে হবে:

- Routing Table: Local ও connected network সম্পর্কে জানতে।
- ARP Cache: সম্প্রতি যোগাযোগ করা host ও তাদের MAC address জানতে।
- Domain Information: Active Directory থাকলে Domain Controller-এর IP জানতে।
- Network Interfaces: Host-এর IP, DNS ও network connection জানতে।

ARP cache থেকে বোঝা যেতে পারে Administrator কোন host-এ RDP বা WinRM দিয়ে connect করেছে। Credentials পেলে এগুলো lateral movement-এ কাজে লাগতে পারে।

## Enumerating Protections

Modern system-এ সাধারণত Antivirus ও EDR (Endpoint Detection and Response) থাকে। এগুলো threat monitor, detect ও block করে।

Privilege escalation-এর সময় public PoC বা tools detect/block হতে পারে। তাই আগে protection enumerate করতে হবে।

### Application Whitelisting

- নির্দিষ্ট user কোন application বা file চালাতে পারবে তা নিয়ন্ত্রণ করে।
- যেমন non-admin user যেন `cmd.exe` বা `powershell.exe` চালাতে না পারে।
- Microsoft-এর একটি জনপ্রিয় solution হলো [AppLocker](https://docs.microsoft.com/en-us/windows/security/threat-protection/windows-defender-application-control/applocker/applocker-overview?utm_source=chatgpt.com)।

AppLocker policy দেখতে:

[GetAppLockerPolicy](https://docs.microsoft.com/en-us/powershell/module/applocker/get-applockerpolicy?view=windowsserver2019-ps\&utm_source=chatgpt.com) cmdlet ব্যবহার করা হয়।

এটি Local, Effective (Enforced) ও Domain policy দেখাতে পারে।

কিছু EDR `net.exe`, `tasklist`-এর মতো common binary detect বা block করে। তাই:

- কোন binary চালানো যাবে তা জানতে হবে।
- Suspicious activity detect হচ্ছে কি না বুঝতে হবে।
- প্রয়োজন হলে lab-এ tool modify ও test করতে হবে।
- Client environment বুঝে কাজ করলে সময় বাঁচে এবং evasive engagement সফল হওয়ার সম্ভাবনা বাড়ে।

### 3. AppLocker Policy Test

```
Get-AppLockerPolicy -Local | Test-AppLockerPolicy -path C:\Windows\System32\cmd.exe -User Everyone
```

Output:

```
FilePath                    PolicyDecision MatchingRule
--------                    -------------- ------------
C:\Windows\System32\cmd.exe         Denied c:\windows\system32\cmd.exe
```

- `cmd.exe` চালানোর অনুমতি নেই।
- `PolicyDecision: Denied` মানে AppLocker এটি block করছে।




## LAB

Get eny exe that is blocked by applocker in a folder
```
# 1. Get the local AppLocker policy
$LocalPolicy = Get-AppLockerPolicy -Local

# 2. Scan a directory and find all blocked .exe files
Get-ChildItem -Path "C:\Windows\System32" -Filter *.exe -Recurse -ErrorAction SilentlyContinue | 
    ForEach-Object {
        $Test = $LocalPolicy | Test-AppLockerPolicy -Path $_.FullName -User Everyone
        if ($Test.PolicyDecision -eq "Denied") {
            [PSCustomObject]@{
                FileName       = $_.Name
                FullPath       = $_.FullName
                PolicyDecision = $Test.PolicyDecision
                MatchingRule   = $Test.MatchingRule
            }
        }
    } | Format-Table -AutoSize
```
