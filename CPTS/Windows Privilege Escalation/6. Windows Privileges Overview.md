# Windows Privileges Overview

## 1. Windows Privileges

[Privileges](https://docs.microsoft.com/en-us/windows/win32/secauthz/privileges?utm_source=chatgpt.com) হলো Windows account-এর এমন permission, যা দিয়ে service manage, driver load, system shutdown, application debug ইত্যাদি কাজ করা যায়।

- Privileges এবং Access Rights আলাদা। Access Rights কোনো object-এর access allow/deny করে।
- User ও group privileges database-এ থাকে এবং login-এর সময় Access Token-এ দেওয়া হয়।
- Active Directory domain account-এর বিভিন্ন computer-এ আলাদা privilege থাকতে পারে।
- Privileged action করার সময় Windows token check করে privilege আছে এবং enabled কি না।
- অধিকাংশ privilege defaultভাবে Disabled থাকে। কিছু Admin CMD/PowerShell থেকে enable করা যায়, কিছু manually enable করতে হয়।

Pentesting Goal: User-এর assigned privilege কাজে লাগিয়ে সরাসরি privilege escalation অথবা আরও access অর্জন করে Administrator, Domain Admin বা SYSTEM হওয়া।

## 2. Windows Authorization Process

Security Principal: Windows যাদের authenticate করতে পারে—User, Computer, Process ও Security Group।

- প্রত্যেক Security Principal-এর unique SID (Security Identifier) থাকে।
- তৈরি হওয়ার পর SID তার lifetime পর্যন্ত একই থাকে।
- Access করার সময় User-এর Access Token-এর SID, Group SID, Privileges ও অন্যান্য তথ্য Object-এর Security Descriptor-এর ACE-এর সঙ্গে compare হয়।
- Match হলে access allow, না হলে deny।

গুরুত্বপূর্ণ:

- Access Token: User SID, Group SID, Privileges ও extra information।
- Security Descriptor: Object-এর security information; Owner SID, Group SID, SACL ও DACL থাকে।
- ACE: Access Control Entry।
- DACL: কারা কী access পাবে।
- SACL: Access auditing-এর information।

## 3. Rights and Privileges in Windows

কিছু Windows group-এর powerful permission abuse করে Local Admin, SYSTEM বা Domain Admin হওয়া সম্ভব।

| Group                       | Description                                                                                                                                                                                                                                                                                                       |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Default Administrators      | Domain Admins ও Enterprise Admins হলো "super" groups।                                                                                                                                                                                                                                                             |
| Server Operators            | Service modify, SMB share access ও file backup করতে পারে।                                                                                                                                                                                                                                                         |
| Backup Operators            | DC-তে locally login, SAM/NTDS database-এর shadow copy, remote registry read এবং SMB দিয়ে DC filesystem access করতে পারে। এদের Domain Admin হিসেবে বিবেচনা করা উচিত। Non-DC-তেও local Backup Operators group-এ থাকতে পারে।                                                                                         |
| Print Operators             | DC-তে locally login করে Windows-কে malicious driver load করাতে পারে।                                                                                                                                                                                                                                              |
| Hyper-V Administrators      | Virtual DC থাকলে Hyper-V Administrators-সহ virtualization admin-দের Domain Admin হিসেবে বিবেচনা করা উচিত।                                                                                                                                                                                                         |
| Account Operators           | Domain-এর non-protected account ও group modify করতে পারে।                                                                                                                                                                                                                                                         |
| Remote Desktop Users        | Defaultভাবে বিশেষ permission নেই, তবে `Allow Login Through Remote Desktop Services` পেলে RDP দিয়ে lateral movement করতে পারে।                                                                                                                                                                                     |
| Remote Management Users     | PSRemoting দিয়ে DC-তে login করতে পারে। Non-DC-তেও local remote management group-এ থাকতে পারে।                                                                                                                                                                                                                     |
| Group Policy Creator Owners | নতুন GPO তৈরি করতে পারে, কিন্তু Domain বা OU-তে link করতে অতিরিক্ত permission প্রয়োজন।                                                                                                                                                                                                                            |
| Schema Admins               | AD schema modify করতে পারে এবং default object ACL-এ compromised account যোগ করে ভবিষ্যতে তৈরি হওয়া Group/GPO backdoor করতে পারে।                                                                                                                                                                                  |
| DNS Admins                  | DC-তে DLL load করতে পারে, কিন্তু DNS server restart করার permission নেই। Malicious DLL load করে reboot-এর অপেক্ষা করতে পারে (এতে service crash হতে পারে)। আরও reliable পদ্ধতি: [WPAD record তৈরি](https://web.archive.org/web/20231115070425/https://cube0x0.github.io/Pocing-Beyond-DA/?utm_source=chatgpt.com). |

### whoami /priv

বর্তমান user-এর privileges দেখতে:

```
whoami /priv
```

কিছু privilege শুধু elevated CMD/PowerShell-এ দেখা বা ব্যবহার করা যায়।

UAC (User Account Control): Windows Vista থেকে চালু security feature; প্রয়োজন না হলে application-কে full permission-এ চলতে বাধা দেয়।

### Backup Operators Rights

Group membership বা assigned privilege অনুযায়ী user-এর rights বাড়তে পারে।

Backup Operators-এর উদাহরণ:

```
PS C:\htb> whoami /priv

PRIVILEGES INFORMATION
----------------------

Privilege Name                Description                    State
============================= ============================== ========
SeShutdownPrivilege           Shut down the system           Disabled
SeChangeNotifyPrivilege       Bypass traverse checking       Enabled
SeIncreaseWorkingSetPrivilege Increase a process working set Disabled
```

- Backup Operators-এর `SeShutdownPrivilege` আছে।
- এর মাধ্যমে DC-তে locally login করলে Domain Controller shutdown করতে পারে, যা বড় service interruption ঘটাতে পারে।
- UAC বর্তমানে এদের কিছু অন্য right restrict করে।
- এটি RDP বা WinRM login-এর ক্ষেত্রে নয়; locally login-এর ক্ষেত্রে প্রযোজ্য।
