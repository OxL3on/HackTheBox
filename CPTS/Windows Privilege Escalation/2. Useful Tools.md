## 2. Tool Upload Location

Target system-এ অনেক directory-তে write permission নাও থাকতে পারে।

নিরাপদ upload location হিসেবে ব্যবহার করা যায়:

```
C:\Windows\Temp
```

কারণ `BUILTIN\Users` group-এর এই directory-তে write access থাকে।

## 3. Tools ব্যবহারের সীমাবদ্ধতা

- Tool সবসময় কাজ করবে না; তাই প্রতিটি tool কীভাবে কাজ করে বুঝতে হবে।
- Tool enumeration দ্রুত করে এবং output সহজে বুঝতে সাহায্য করে।
- `winPEAS`-এর মতো tool অনেক অপ্রয়োজনীয় information দেখাতে পারে (Information Overload)।
- False Positive তৈরি করতে পারে।
- False Negative-এর কারণে গুরুত্বপূর্ণ vulnerability বাদ পড়তে পারে।

তাই manual enumeration শিখতে হবে। Tool-এর output বুঝতে না পারলে বা tool কাজ না করলে নিজে troubleshoot করতে হবে।

শুধু `autopwn` script-এর ওপর নির্ভর না করে exploitation manually করাও শিখতে হবে। নিজের script/tool তৈরি করাও ভালো।

Air-gapped network বা internet/USB নিষিদ্ধ environment-এ manual কাজ করার দক্ষতা জরুরি।

## 4. Tools কারা ব্যবহার করতে পারে?

Penetration tester ছাড়াও System Administrator-রা ব্যবহার করতে পারে:

- সহজে fix করা যায় এমন vulnerability খুঁজতে।
- নিয়মিত machine security check করতে।
- Upgrade বা configuration change-এর impact দেখতে।
- Production-এ deploy করার আগে নতুন Gold Image security review করতে।

System administration, architecture এবং internal security/compliance-এর দায়িত্বে থাকা সবার জন্য এগুলো উপকারী।

## 5. Tool ব্যবহারের Risk

অতিরিক্ত enumeration করলে দুর্বল বা fragile system crash বা unstable হতে পারে।

এছাড়া পরিচিত tools সাধারণত Antivirus (AV) এবং EDR detect বা block করতে পারে। যেমন:

- Cylance
- Carbon Black
