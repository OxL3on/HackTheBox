# Windows Privilege Escalation

## 1. Privilege Escalation কী?

একটি host-এ `User A` হিসেবে access পাওয়ার পর system-এর weakness abuse করে `User B` হিসেবে access নেওয়াকে Privilege Escalation বলে।

সাধারণত লক্ষ্য Administrator access পাওয়া। তবে কখনো Administrator হওয়ার আগে অন্য unprivileged account-এ access নিতে হতে পারে।

Credentials পাওয়ার সহজ উপায় হতে পারে unsecured text file বা spreadsheet খুঁজে পাওয়া। এছাড়াও নিচের weakness abuse করা যায়:

- Windows services বা scheduled tasks-এর misconfiguration।
- নিজের account-এ অতিরিক্ত privileges।
- Vulnerable software।
- Missing Windows security patches।

## 2. Windows Users

Windows-এ প্রধানত দুই ধরনের user রয়েছে:

| User Type      | Description                                                                                                    |
| -------------- | -------------------------------------------------------------------------------------------------------------- |
| Administrators | সর্বোচ্চ privilege থাকে। যেকোনো system configuration পরিবর্তন ও সব file access করতে পারে।                      |
| Standard Users | সীমিত কাজ করতে পারে। সাধারণত permanent/গুরুত্বপূর্ণ system change করতে পারে না এবং নিজের file-এ সীমাবদ্ধ থাকে। |

- Administrator privilege থাকা user → `Administrators` group।
- Standard user → `Users` group।

### Special Built-in Accounts

| Account              | Description                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| SYSTEM / LocalSystem | Windows-এর internal task চালায়। Host-এর সব file ও resource-এ access থাকে; Administrator-এর চেয়েও বেশি privilege। |
| Local Service        | Minimum privilege দিয়ে Windows service চালায়। Network-এ anonymous connection ব্যবহার করে।                        |
| Network Service      | Minimum privilege দিয়ে Windows service চালায়। Network authentication-এর জন্য computer credentials ব্যবহার করে।   |

মনে রাখবে:

- এই account-গুলো Windows নিজে তৈরি ও manage করে।
- সাধারণ user account-এর মতো এগুলো ব্যবহার করা যায় না।
- নির্দিষ্ট service exploit করে এদের privilege পাওয়া সম্ভব।
