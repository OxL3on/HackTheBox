# Tools of the Trade

আগের task-এ যেসব enumeration manually করা হয়েছে, সেগুলো automated tools দিয়ে দ্রুত করা যায়। এগুলো privilege escalation-এর সম্ভাব্য পথ খুঁজে বের করে। তবে automated tools সব vulnerability খুঁজে পাবে এমন নিশ্চয়তা নেই।

## 1. WinPEAS

WinPEAS হলো Windows enumeration script, যা system-এর privilege escalation path খুঁজে বের করে।

- আগের task-এর মতো বিভিন্ন command চালিয়ে output দেখায়।
- Output অনেক বড় হতে পারে, তাই file-এ save করা ভালো।

```
winpeas.exe > outputfile.txt
```

Download: [WinPEAS GitHub](https://github.com/carlospolop/PEASS-ng/tree/master/winPEAS?utm_source=chatgpt.com)

## 2. PrivescCheck

PrivescCheck হলো PowerShell script, যা Windows system-এর common privilege escalation vulnerability খুঁজে বের করে।

WinPEAS-এর alternative; binary execute করার প্রয়োজন নেই।

Download: [PrivescCheck GitHub](https://github.com/itm4n/PrivescCheck?utm_source=chatgpt.com)

Execution Policy bypass করে চালানো:

```
Set-ExecutionPolicy Bypass -Scope process -Force
. .\PrivescCheck.ps1
Invoke-PrivescCheck
```

## 3. WES-NG (Windows Exploit Suggester - Next Generation)

WinPEAS-এর মতো কিছু tools target machine-এ upload করে চালাতে হয়। এতে Antivirus detect করে delete করতে পারে।

WES-NG attacker machine (Kali/AttackBox)-এ চলে, তাই target-এ tool upload করার প্রয়োজন নেই।

- Python-based script।
- Target-এর missing patches খুঁজে সম্ভাব্য exploitable vulnerability দেখায়।

Download: [WES-NG GitHub](https://github.com/bitsadmin/wesng?utm_source=chatgpt.com)

প্রথমে database update:

```
wes.py --update
```

Target machine-এ `systeminfo` চালিয়ে output `.txt` file-এ save করতে হবে। এরপর file attacker machine-এ transfer করতে হবে।

WES-NG চালানো:

```
wes.py systeminfo.txt
```

## 4. Metasploit

Target system-এ আগে থেকেই Meterpreter shell থাকলে Metasploit-এর `local_exploit_suggester` module ব্যবহার করা যায়।

```
multi/recon/local_exploit_suggester
```

এটি target system-এর সম্ভাব্য vulnerability খুঁজে privilege escalation-এর exploit suggest করে।

### Quick Comparison

| Tool         | কোথায় চলে           | কাজ                           |
| ------------ | ------------------- | ----------------------------- |
| WinPEAS      | Target machine      | System enumeration            |
| PrivescCheck | Target machine      | PowerShell-based enumeration  |
| WES-NG       | Attacker machine    | Missing patch ও exploit খোঁজা |
| Metasploit   | Meterpreter session | Local exploit suggest করা     |

মনে রাখবে: Automated enumeration সাহায্য করে, কিন্তু সব privilege escalation vector খুঁজে পায় না। তাই manual enumeration-ও গুরুত্বপূর্ণ।
