# Harvesting Passwords from Usual Spots

## 1. মূল ধারণা

Compromised Windows machine থেকে অন্য user-এর credentials সংগ্রহ করা সহজ privilege escalation পদ্ধতি।

Password পাওয়া যেতে পারে:

- Unsecured plaintext file থেকে।
- Browser বা email client-এর saved credentials থেকে।
- Software configuration ও history থেকে।

## 2. Unattended Windows Installations

অনেক computer-এ Windows install করতে Windows Deployment Services (WDS) দিয়ে একই OS image network-এর মাধ্যমে deploy করা হয়। এগুলোকে Unattended Installation বলে, কারণ user interaction লাগে না।

Initial setup-এর Administrator credentials নিচের file-গুলোতে থাকতে পারে:

```
C:\Unattend.xml
C:\Windows\Panther\Unattend.xml
C:\Windows\Panther\Unattend\Unattend.xml
C:\Windows\system32\sysprep.inf
C:\Windows\system32\sysprep\sysprep.xml
```

Example:

```
<Credentials>
    <Username>Administrator</Username>
    <Domain>thm.local</Domain>
    <Password>MyPassword123</Password>
</Credentials>
```

## 3. PowerShell History

PowerShell-এ চালানো command history file-এ save থাকে। Command-এর মধ্যে সরাসরি password থাকলে সেটি পাওয়া যেতে পারে।

CMD থেকে:

```
type %userprofile%\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadline\ConsoleHost_history.txt
```

Note: উপরের command শুধু `cmd.exe`-তে কাজ করবে। PowerShell-এ `%userprofile%` কাজ করে না। সেখানে ব্যবহার করতে হবে `$Env:userprofile`।

## 4. Saved Windows Credentials

Windows অন্য user-এর credentials save করার সুবিধা দেয়।

Saved credentials দেখতে:

```
cmdkey /list
```

এখানে actual password দেখা যায় না। তবে saved credentials ব্যবহার করে `runas` চালানো যায়।

```
runas /savecred /user:admin cmd.exe
```

## 5. IIS Configuration

IIS হলো Windows-এর default web server।

Website configuration `web.config` file-এ থাকে। এখানে database বা authentication mechanism-এর password থাকতে পারে।

সম্ভাব্য location:

```
C:\inetpub\wwwroot\web.config
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\Config\web.config
```

Database connection string খুঁজতে:

```
type C:\Windows\Microsoft.NET\Framework64\v4.0.30319\Config\web.config | findstr connectionString
```

## 6. Retrieve Credentials from Software: PuTTY

PuTTY হলো Windows-এর SSH client।

- Connection-এর IP, username ও অন্যান্য configuration session হিসেবে save করা যায়।
- SSH password সরাসরি save করে না।
- তবে proxy configuration-এর plaintext authentication credentials save করতে পারে।

Registry থেকে ProxyPassword খুঁজতে:

```
reg query HKEY_CURRENT_USER\Software\SimonTatham\PuTTY\Sessions\ /f "Proxy" /s
```

Note:

- `SimonTatham` হলো PuTTY-এর creator, password খোঁজার user-এর নাম নয়।
- Command-এর output-এ stored proxy username-ও দেখা যেতে পারে।

অন্যান্য software: Browser, email client, FTP client, SSH client ও VNC software-এও saved password recover করার পদ্ধতি থাকতে পারে।
