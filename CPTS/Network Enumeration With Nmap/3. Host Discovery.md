# Host Discovery

## 1. Host Discovery কী?

Internal penetration test শুরু করার সময় প্রথমে জানতে হবে network-এ কোন কোন system online বা active আছে।

Nmap-এর বিভিন্ন Host Discovery option ব্যবহার করে active host খুঁজে বের করা যায়।

- Host alive কিনা তা শনাক্ত করার অনেক option আছে।
- সবচেয়ে কার্যকর পদ্ধতিগুলোর একটি হলো ICMP Echo Request।

Note: প্রতিটি scan save করে রাখা উচিত। পরে comparison, documentation ও reporting-এর কাজে লাগে। বিভিন্ন tool ভিন্ন result দিতে পারে, তাই কোন tool কী result দিয়েছে তা আলাদা করে রাখা ভালো।

## 2. Scan Network Range

পুরো network range scan করে active host খুঁজতে:

```
sudo nmap 10.129.2.0/24 -sn -oA tnet | grep for | cut -d" " -f5
```

Output:

```
10.129.2.4
10.129.2.10
10.129.2.11
10.129.2.18
10.129.2.19
10.129.2.20
10.129.2.28
```

Scanning Options:

| Option          | Description                                      |
| --------------- | ------------------------------------------------ |
| `10.129.2.0/24` | Target network range                             |
| `-sn`           | Port scanning বন্ধ করে                           |
| `-oA tnet`      | `tnet` নাম দিয়ে সব format-এ scan result save করে |

এই পদ্ধতি তখনই কাজ করবে যখন host-এর firewall scan request allow করবে। Firewall block করলে active host খুঁজতে অন্য scanning technique ব্যবহার করতে হবে। এগুলো পরে `Firewall and IDS Evasion` section-এ আলোচনা করা হবে।

## 3. Scan IP List

Internal penetration test-এ অনেক সময় test করার জন্য IP address-এর list দেওয়া হয়।

Nmap-এ একে একে IP না লিখে list file থেকে target নেওয়া যায়।

hosts.lst তৈরি ও দেখা:

```
cat hosts.lst
```

Content:

```
10.129.2.4
10.129.2.10
10.129.2.11
10.129.2.18
10.129.2.19
10.129.2.20
10.129.2.28
```

List থেকে scan:

```
sudo nmap -sn -oA tnet -iL hosts.lst | grep for | cut -d" " -f5
```

Output:

```
10.129.2.18
10.129.2.19
10.129.2.20
```

Scanning Options:

| Option     | Description                                      |
| ---------- | ------------------------------------------------ |
| `-sn`      | Port scanning বন্ধ করে                           |
| `-oA tnet` | `tnet` নাম দিয়ে সব format-এ result save করে      |
| `-iL`      | দেওয়া `hosts.lst` file থেকে target নিয়ে scan করে |

এখানে ৭টি host-এর মধ্যে মাত্র ৩টি active পাওয়া গেছে।

তবে বাকি host-গুলো inactive মানেই তারা offline নয়। Firewall configuration-এর কারণে তারা default ICMP Echo Request ignore করতে পারে। Nmap response না পেলে host-গুলোকে inactive mark করে।

## 4. Scan Multiple IPs

Network-এর ছোট একটি অংশ scan করতে একাধিক IP address সরাসরি দেওয়া যায়।

```
sudo nmap -sn -oA tnet 10.129.2.18 10.129.2.19 10.129.2.20 | grep for | cut -d" " -f5
```

Output:

```
10.129.2.18
10.129.2.19
10.129.2.20
```

IP address-গুলো পাশাপাশি হলে range দিয়েও লেখা যায়।

```
sudo nmap -sn -oA tnet 10.129.2.18-20 | grep for | cut -d" " -f5
```

Output:

```
10.129.2.18
10.129.2.19
10.129.2.20
```

## 5. Scan Single IP

কোনো host-এর open port ও service scan করার আগে host alive কিনা check করতে হবে।

```
sudo nmap 10.129.2.18 -sn -oA host
```

Output:

```
Starting Nmap 7.80 ( https://nmap.org ) at 2020-06-14 23:59 CEST
Nmap scan report for 10.129.2.18
Host is up (0.087s latency).
MAC Address: DE:AD:00:00:BE:EF
Nmap done: 1 IP address (1 host up) scanned in 0.11 seconds
```

Scanning Options:

| Option        | Description                                 |
| ------------- | ------------------------------------------- |
| `10.129.2.18` | Target host                                 |
| `-sn`         | Port scanning বন্ধ করে                      |
| `-oA host`    | `host` নাম দিয়ে সব format-এ result save করে |

### ICMP Echo Request ও ARP Ping

`-sn` দিয়ে port scan বন্ধ করলে Nmap automatically `ICMP Echo Request` (`-PE`) ব্যবহার করে ping scan করতে পারে।

সাধারণত host alive থাকলে ICMP Echo Request পাঠানোর পর `ICMP Reply` আশা করা হয়।

তবে আগের scan-গুলোতে Nmap ICMP Echo Request পাঠানোর আগেই ARP Ping পাঠিয়েছিল। এর ফলে `ARP Reply` পেয়েই host alive শনাক্ত করেছে।

এটি `--packet-trace` দিয়ে দেখা যায়। ICMP Echo Request নিশ্চিতভাবে পাঠাতে `-PE` ব্যবহার করতে হবে।

```
sudo nmap 10.129.2.18 -sn -oA host -PE --packet-trace
```

Output:

```
Starting Nmap 7.80 ( https://nmap.org ) at 2020-06-15 00:08 CEST
SENT (0.0074s) ARP who-has 10.129.2.18 tell 10.10.14.2
RCVD (0.0309s) ARP reply 10.129.2.18 is-at DE:AD:00:00:BE:EF
Nmap scan report for 10.129.2.18
Host is up (0.023s latency).
MAC Address: DE:AD:00:00:BE:EF
Nmap done: 1 IP address (1 host up) scanned in 0.05 seconds
```

Scanning Options:

| Option           | Description                                             |
| ---------------- | ------------------------------------------------------- |
| `10.129.2.18`    | Target host                                             |
| `-sn`            | Port scanning বন্ধ করে                                  |
| `-oA host`       | `host` নাম দিয়ে সব format-এ result save করে             |
| `-PE`            | Target-এর বিরুদ্ধে ICMP Echo Request দিয়ে ping scan করে |
| `--packet-trace` | পাঠানো ও receive করা সব packet দেখায়                    |

### `--reason` দিয়ে Host Alive হওয়ার কারণ দেখা

Nmap কেন target-কে alive mark করেছে তা দেখতে `--reason` ব্যবহার করা যায়।

```
sudo nmap 10.129.2.18 -sn -oA host -PE --reason
```

Output:

```
Starting Nmap 7.80 ( https://nmap.org ) at 2020-06-15 00:10 CEST
SENT (0.0074s) ARP who-has 10.129.2.18 tell 10.10.14.2
RCVD (0.0309s) ARP reply 10.129.2.18 is-at DE:AD:00:00:BE:EF
Nmap scan report for 10.129.2.18
Host is up, received arp-response (0.028s latency).
MAC Address: DE:AD:00:00:BE:EF
Nmap done: 1 IP address (1 host up) scanned in 0.03 seconds
```

Scanning Options:

| Option        | Description                                 |
| ------------- | ------------------------------------------- |
| `10.129.2.18` | Target host                                 |
| `-sn`         | Port scanning বন্ধ করে                      |
| `-oA host`    | `host` নাম দিয়ে সব format-এ result save করে |
| `-PE`         | ICMP Echo Request দিয়ে ping scan করে        |
| `--reason`    | নির্দিষ্ট result পাওয়ার কারণ দেখায়          |

এখানে দেখা যাচ্ছে, Nmap শুধু ARP Request ও ARP Reply দিয়েই host alive শনাক্ত করেছে।

### ARP Ping বন্ধ করে ICMP Echo Request পাঠানো

শুধু ICMP Echo Request দিয়ে scan করতে ARP Ping বন্ধ করতে হবে।

এর জন্য `--disable-arp-ping` ব্যবহার করা হয়।

```
sudo nmap 10.129.2.18 -sn -oA host -PE --packet-trace --disable-arp-ping
```

Output:

```
Starting Nmap 7.80 ( https://nmap.org ) at 2020-06-15 00:12 CEST
SENT (0.0107s) ICMP [10.10.14.2 > 10.129.2.18 Echo request (type=8/code=0) id=13607 seq=0] IP [ttl=255 id=23541 iplen=28 ]
RCVD (0.0152s) ICMP [10.129.2.18 > 10.10.14.2 Echo reply (type=0/code=0) id=13607 seq=0] IP [ttl=128 id=40622 iplen=28 ]
Nmap scan report for 10.129.2.18
Host is up (0.086s latency).
MAC Address: DE:AD:00:00:BE:EF
Nmap done: 1 IP address (1 host up) scanned in 0.11 seconds
```

এখানে:

- `type=8/code=0` = ICMP Echo Request
- `type=0/code=0` = ICMP Echo Reply

এইভাবে নিশ্চিত হওয়া যায় যে Nmap ARP Ping নয়, সরাসরি ICMP Echo Request ব্যবহার করেছে।
