# Performance

## 1. Scan Performance

বড় network scan করতে বা network bandwidth কম থাকলে Nmap-এর scan performance গুরুত্বপূর্ণ।

Scan speed control করার জন্য কয়েকটি option রয়েছে:

| Option                       | কাজ                                                                 |
| ---------------------------- | ------------------------------------------------------------------- |
| `-T <0-5>`                   | Scan কত দ্রুত হবে নির্ধারণ করে।                                     |
| `--min-parallelism <number>` | একসাথে কতগুলো probe parallel-এ পাঠানো হবে তার minimum নির্ধারণ করে। |
| `--max-rtt-timeout <time>`   | RTT-এর maximum timeout নির্ধারণ করে।                                |
| `--min-rate <number>`        | প্রতি সেকেন্ডে minimum কত packet পাঠাবে নির্ধারণ করে।               |
| `--max-retries <number>`     | প্রতিটি scanned port-এর জন্য সর্বোচ্চ retry সংখ্যা নির্ধারণ করে।    |

## 2. Timeouts

Nmap packet পাঠানোর পর response পেতে যে সময় লাগে তাকে Round-Trip Time (RTT) বলে।

সাধারণত Nmap শুরুতে `100ms`-এর মতো high timeout ব্যবহার করে (`--min-RTT-timeout`)।

উদাহরণ: ২৫৬টি host এবং প্রতিটি host-এর top 100 ports scan করা।

### Default Scan

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.0/24 -F

<SNIP>
Nmap done: 256 IP addresses (10 hosts up) scanned in 39.44 seconds
```

### Optimized RTT

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.0/24 -F --initial-rtt-timeout 50ms --max-rtt-timeout 100ms

<SNIP>
Nmap done: 256 IP addresses (8 hosts up) scanned in 12.29 seconds
```

| Scanning Options             | Description                        |
| ---------------------------- | ---------------------------------- |
| `10.129.2.0/24`              | নির্দিষ্ট target network scan করে। |
| `-F`                         | Top 100 ports scan করে।            |
| `--initial-rtt-timeout 50ms` | Initial RTT timeout নির্ধারণ করে।  |
| `--max-rtt-timeout 100ms`    | Maximum RTT timeout নির্ধারণ করে।  |

Comparison:

- Default scan-এ ১০টি host পাওয়া গেছে, সময় লেগেছে `39.44 seconds`।
- Optimized scan-এ ৮টি host পাওয়া গেছে, সময় লেগেছে `12.29 seconds`।
- Scan প্রায় এক-চতুর্থাংশ সময়ে শেষ হয়েছে, কিন্তু ২টি host miss হয়েছে।

মনে রাখবে: Initial RTT timeout (`--initial-rtt-timeout`) খুব কম দিলে host miss হতে পারে।

## 3. Max Retries

Scan speed বাড়ানোর আরেকটি উপায় হলো packet retry সংখ্যা কমানো।

`--max-retries` দিয়ে retry সংখ্যা নির্ধারণ করা হয়।

- Default value: `10`
- Value `0` করলে কোনো response না পেলে Nmap আর packet পাঠাবে না এবং সেই port skip করবে।

### Default Scan

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.0/24 -F | grep "/tcp" | wc -l

23
```

### Reduced Retries

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.0/24 -F --max-retries 0 | grep "/tcp" | wc -l

21
```

| Scanning Options  | Description                            |
| ----------------- | -------------------------------------- |
| `10.129.2.0/24`   | নির্দিষ্ট target network scan করে।     |
| `-F`              | Top 100 ports scan করে।                |
| `--max-retries 0` | Scan-এর সময় retry সংখ্যা নির্ধারণ করে। |

Result:

- Default scan: `23`টি result।
- Reduced retries: `21`টি result।

মনে রাখবে: Retry কমালে scan দ্রুত হয়, কিন্তু গুরুত্বপূর্ণ information miss হতে পারে।

## 4. Rates

White-box penetration test-এ security system থেকে whitelist পাওয়া যেতে পারে, যাতে network-এর vulnerability পরীক্ষা করা যায়।

Network bandwidth জানা থাকলে packet sending rate নির্ধারণ করে scan দ্রুত করা যায়।

`--min-rate <number>` দিয়ে Nmap-কে প্রতি সেকেন্ডে minimum কতটি packet পাঠাতে হবে তা বলা হয়। Nmap সেই rate maintain করার চেষ্টা করে।

### Default Scan

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.0/24 -F -oN tnet.default

<SNIP>
Nmap done: 256 IP addresses (10 hosts up) scanned in 29.83 seconds
```

### Optimized Scan

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.0/24 -F -oN tnet.minrate300 --min-rate 300

<SNIP>
Nmap done: 256 IP addresses (10 hosts up) scanned in 8.67 seconds
```

| Scanning Options      | Description                                                   |
| --------------------- | ------------------------------------------------------------- |
| `10.129.2.0/24`       | নির্দিষ্ট target network scan করে।                            |
| `-F`                  | Top 100 ports scan করে।                                       |
| `-oN tnet.minrate300` | Normal format-এ result save করে, file name `tnet.minrate300`। |
| `--min-rate 300`      | প্রতি সেকেন্ডে minimum 300টি packet পাঠানোর চেষ্টা করে।       |

### Default Scan - Found Open Ports

```
00Luffy00@htb[/htb]$ cat tnet.default | grep "/tcp" | wc -l

23
```

### Optimized Scan - Found Open Ports

```
00Luffy00@htb[/htb]$ cat tnet.minrate300 | grep "/tcp" | wc -l

23
```

Result:

- Default scan: `29.83 seconds`, পাওয়া গেছে `23`টি result।
- Optimized scan: `8.67 seconds`, পাওয়া গেছে `23`টি result।

## 5. Timing

সবসময় manually scan settings optimize করা সম্ভব হয় না, বিশেষ করে black-box penetration test-এ।

এজন্য Nmap-এ ৬টি timing template রয়েছে: `-T <0-5>`।

এগুলো scan-এর aggressiveness নির্ধারণ করে।

| Option | Template     |
| ------ | ------------ |
| `-T 0` | `paranoid`   |
| `-T 1` | `sneaky`     |
| `-T 2` | `polite`     |
| `-T 3` | `normal`     |
| `-T 4` | `aggressive` |
| `-T 5` | `insane`     |

Default timing template হলো `-T 3` (`normal`)।

মনে রাখবে: বেশি aggressive scan করলে network traffic বাড়তে পারে এবং security system আমাদের block করতে পারে।

এই timing template-গুলোতে এমন কিছু option ও value রয়েছে, যেগুলো manually-ও set করা যায়। Developers তাদের testing অনুযায়ী এই value নির্ধারণ করেছেন, যাতে network environment অনুযায়ী সহজে scan adjust করা যায়।

সব template-এর exact options ও values: [Nmap Timing Templates](https://nmap.org/book/performance-timing-templates.html?utm_source=chatgpt.com)

### Default Scan

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.0/24 -F -oN tnet.default 

<SNIP>
Nmap done: 256 IP addresses (10 hosts up) scanned in 32.44 seconds
```

### Insane Scan

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.0/24 -F -oN tnet.T5 -T 5

<SNIP>
Nmap done: 256 IP addresses (10 hosts up) scanned in 18.07 seconds
```

| Scanning Options | Description                                           |
| ---------------- | ----------------------------------------------------- |
| `10.129.2.0/24`  | নির্দিষ্ট target network scan করে।                    |
| `-F`             | Top 100 ports scan করে।                               |
| `-oN tnet.T5`    | Normal format-এ result save করে, file name `tnet.T5`। |
| `-T 5`           | Insane timing template ব্যবহার করে।                   |

### Default Scan - Found Open Ports

```
00Luffy00@htb[/htb]$ cat tnet.default | grep "/tcp" | wc -l

23
```

### Insane Scan - Found Open Ports

```
00Luffy00@htb[/htb]$ cat tnet.T5 | grep "/tcp" | wc -l

23
```

Result:

- Default scan: `32.44 seconds`, পাওয়া গেছে `23`টি result।
- Insane scan: `18.07 seconds`, পাওয়া গেছে `23`টি result।
