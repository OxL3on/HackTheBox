# Introduction to Nmap

## 1. Nmap কী?

Network Mapper (Nmap) একটি open-source network analysis ও security auditing tool।

- এটি C, C++, Python এবং Lua দিয়ে তৈরি।
- Raw packets ব্যবহার করে network-এর active host খুঁজে বের করে।
- Host-এর services ও applications শনাক্ত করে।
- সম্ভব হলে service-এর name ও version বের করে।
- Host-এর operating system ও version শনাক্ত করতে পারে।
- Packet filter, Firewall এবং IDS (Intrusion Detection System) ঠিকভাবে configured আছে কিনা পরীক্ষা করতে পারে।

## 2. Use Cases

Network Administrator এবং IT Security Specialist-রা Nmap ব্যবহার করেন:

- Network security audit করতে।
- Penetration test simulate করতে।
- Firewall ও IDS settings/configuration পরীক্ষা করতে।
- Possible connection-এর ধরন শনাক্ত করতে।
- Network mapping করতে।
- Response analysis করতে।
- Open ports শনাক্ত করতে।
- Vulnerability assessment করতে।

## 3. Nmap Architecture

Nmap-এর scanning techniques মূলত পাঁচ ভাগে বিভক্ত:

1. Host Discovery: Network-এ কোন host active আছে খুঁজে বের করা।
2. Port Scanning: কোন port open বা closed তা শনাক্ত করা।
3. Service Enumeration and Detection: চলমান service ও তার details শনাক্ত করা।
4. OS Detection: Host-এর operating system শনাক্ত করা।
5. Nmap Scripting Engine (NSE): Target service-এর সঙ্গে script ব্যবহার করে interact করা।

## 4. Syntax

Nmap-এর basic syntax:

```
nmap <scan types> <options> <target>
```

- `scan types` = কোন ধরনের scan চালাবে।
- `options` = অতিরিক্ত settings।
- `target` = যে host বা network scan করবে।

## 5. Scan Techniques

Nmap বিভিন্ন ধরনের packet ও connection ব্যবহার করে আলাদা scan চালাতে পারে।

সব scan technique দেখতে:

```
nmap --help
```

Scan Techniques:

```
<SNIP>
SCAN TECHNIQUES:
  -sS/sT/sA/sW/sM: TCP SYN/Connect()/ACK/Window/Maimon scans
  -sU: UDP Scan
  -sN/sF/sX: TCP Null, FIN, and Xmas scans
  --scanflags <flags>: Customize TCP scan flags
  -sI <zombie host[:probeport]>: Idle scan
  -sY/sZ: SCTP INIT/COOKIE-ECHO scans
  -sO: IP protocol scan
  -b <FTP relay host>: FTP bounce scan
<SNIP>
```

### TCP SYN Scan (`-sS`)

- এটি সবচেয়ে popular scan method-গুলোর একটি।
- অন্যভাবে define না করলে এটি Nmap-এর default scan setting-গুলোর একটি।
- প্রতি সেকেন্ডে কয়েক হাজার port scan করতে পারে।
- SYN flag দিয়ে packet পাঠায়।
- TCP three-way handshake সম্পূর্ণ করে না।
- তাই scanned port-এর সঙ্গে full TCP connection তৈরি হয় না।

Response অনুযায়ী port status:

| Target-এর response | Port status | অর্থ                                     |
| ------------------ | ----------- | ---------------------------------------- |
| `SYN-ACK`          | `open`      | Port connection গ্রহণ করছে               |
| `RST`              | `closed`    | Port closed                              |
| কোনো response নেই  | `filtered`  | Firewall packet drop বা ignore করতে পারে |

### Example: TCP SYN Scan

```
sudo nmap -sS localhost
```

Output:

```
Starting Nmap 7.80 ( https://nmap.org ) at 2020-06-11 22:50 UTC
Nmap scan report for localhost (127.0.0.1)
Host is up (0.000010s latency).
Not shown: 996 closed ports
PORT     STATE SERVICE
22/tcp   open  ssh
80/tcp   open  http
5432/tcp open  postgresql
5901/tcp open  vnc-1

Nmap done: 1 IP address (1 host up) scanned in 0.18 seconds
```

Output বোঝা:

এখানে চারটি TCP port open পাওয়া গেছে।

| Column    | অর্থ                   |
| --------- | ---------------------- |
| `PORT`    | Port number ও protocol |
| `STATE`   | Port-এর status         |
| `SERVICE` | Port-এ চলমান service   |

উদাহরণ:

- `22/tcp` → SSH
- `80/tcp` → HTTP
- `5432/tcp` → PostgreSQL
- `5901/tcp` → VNC
