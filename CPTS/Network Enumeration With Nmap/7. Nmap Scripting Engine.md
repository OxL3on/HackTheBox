# Nmap Scripting Engine (NSE)

## 1. NSE কী?

Nmap Scripting Engine (`NSE`) দিয়ে Lua language ব্যবহার করে script তৈরি করা যায়, যা বিভিন্ন service-এর সাথে interact করতে পারে।

NSE script মোট ১৪টি category-তে ভাগ করা হয়েছে।

| Category    | Description                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------------ |
| `auth`      | Authentication credentials নির্ধারণ করে।                                                                           |
| `broadcast` | Broadcast-এর মাধ্যমে host discovery করে এবং পাওয়া host-গুলো automatically scan-এ যোগ করতে পারে।                    |
| `brute`     | Credentials brute-force করে service-এ login করার চেষ্টা করে।                                                       |
| `default`   | `-sC` ব্যবহার করলে default scripts execute হয়।                                                                     |
| `discovery` | Accessible services সম্পর্কে information সংগ্রহ করে।                                                               |
| `dos`       | Denial of Service vulnerability check করে। Service ক্ষতিগ্রস্ত হতে পারে বলে কম ব্যবহার করা হয়।                     |
| `exploit`   | Scanned port-এর known vulnerabilities exploit করার চেষ্টা করে।                                                     |
| `external`  | Further processing-এর জন্য external services ব্যবহার করে।                                                          |
| `fuzzer`    | বিভিন্ন fields-সহ packet পাঠিয়ে vulnerability ও unexpected packet handling খুঁজে বের করে। এতে অনেক সময় লাগতে পারে। |
| `intrusive` | Target system-এর ক্ষতি করতে পারে এমন intrusive scripts।                                                            |
| `malware`   | Target system-এ malware আছে কি না check করে।                                                                       |
| `safe`      | Defensive scripts, যা intrusive বা destructive access করে না।                                                      |
| `version`   | Service detection-এর extension হিসেবে কাজ করে।                                                                     |
| `vuln`      | নির্দিষ্ট vulnerabilities শনাক্ত করে।                                                                              |

## 2. NSE Scripts ব্যবহার

Nmap-এ প্রয়োজনীয় scripts নির্ধারণের কয়েকটি উপায় রয়েছে।

### Default Scripts

`-sC` দিয়ে default scripts execute করা হয়।

```
00Luffy00@htb[/htb]$ sudo nmap <target> -sC
```

### Specific Scripts Category

`--script` দিয়ে নির্দিষ্ট category-এর scripts চালানো যায়।

```
00Luffy00@htb[/htb]$ sudo nmap <target> --script <category>
```

### Defined Scripts

একাধিক নির্দিষ্ট script-এর নাম comma দিয়ে আলাদা করে দেওয়া যায়।

```
00Luffy00@htb[/htb]$ sudo nmap <target> --script <script-name>,<script-name>,...
```

### Example: নির্দিষ্ট NSE Scripts

Target-এর SMTP port-এ `banner` এবং `smtp-commands` scripts চালাই।

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.28 -p 25 --script banner,smtp-commands

Starting Nmap 7.80 ( https://nmap.org ) at 2020-06-16 23:21 CEST
Nmap scan report for 10.129.2.28
Host is up (0.050s latency).

PORT   STATE SERVICE
25/tcp open  smtp
|_banner: 220 inlane ESMTP Postfix (Ubuntu)
|_smtp-commands: inlane, PIPELINING, SIZE 10240000, VRFY, ETRN, STARTTLS, ENHANCEDSTATUSCODES, 8BITMIME, DSN, SMTPUTF8,
MAC Address: DE:AD:00:00:BE:EF (Intel Corporate)
```

| Scanning Options                | Description                        |
| ------------------------------- | ---------------------------------- |
| `10.129.2.28`                   | নির্দিষ্ট target scan করে।         |
| `-p 25`                         | শুধু নির্দিষ্ট port scan করে।      |
| `--script banner,smtp-commands` | নির্দিষ্ট NSE scripts ব্যবহার করে। |

Result থেকে যা জানা যায়:

- `banner` script দিয়ে Linux distribution Ubuntu শনাক্ত করা যায়।
- `smtp-commands` script SMTP server-এর available commands দেখায়।
- এই information target-এর existing users খুঁজে বের করতে সাহায্য করতে পারে।

## 3. Aggressive Scan

Nmap-এর `-A` option ব্যবহার করলে একসাথে কয়েকটি scan চালানো হয়:

- Service detection (`-sV`)
- OS detection (`-O`)
- Traceroute (`--traceroute`)
- Default NSE scripts (`-sC`)

- Username হিসেবে `admin` খুঁজে পেয়েছে।
