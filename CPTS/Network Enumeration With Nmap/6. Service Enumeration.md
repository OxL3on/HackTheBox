# Service Enumeration

## 1. Service Version Detection

কোনো service-এর নাম ও version সঠিকভাবে জানা গুরুত্বপূর্ণ। কারণ:

- Known vulnerabilities খুঁজতে পারি।
- নির্দিষ্ট version-এর source code বিশ্লেষণ করতে পারি।
- Target-এর service ও operating system অনুযায়ী সঠিক exploit খুঁজতে পারি।

প্রথমে quick port scan করে open port-এর ধারণা নেওয়া ভালো। এতে traffic কম হয় এবং security mechanism-এর মাধ্যমে detect বা block হওয়ার ঝুঁকি কমে।

এরপর background-এ full port scan (`-p-`) চালিয়ে নির্দিষ্ট port-গুলোর service ও version জানতে `-sV` ব্যবহার করতে পারি।

Full port scan চলাকালে Space Bar চাপলে scan-এর progress দেখা যায়।

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.28 -p- -sV

Starting Nmap 7.80 ( https://nmap.org ) at 2020-06-15 19:44 CEST
[Space Bar]
Stats: 0:00:03 elapsed; 0 hosts completed (1 up), 1 undergoing SYN Stealth Scan
SYN Stealth Scan Timing: About 3.64% done; ETC: 19:45 (0:00:53 remaining)
```

| Scanning Options | Description                                      |
| ---------------- | ------------------------------------------------ |
| `10.129.2.28`    | নির্দিষ্ট target scan করে।                       |
| `-p-`            | সব port scan করে।                                |
| `-sV`            | নির্দিষ্ট port-গুলোর service version detect করে। |

### Scan progress নির্দিষ্ট সময় পরপর দেখা

`--stats-every=5s` ব্যবহার করে নির্দিষ্ট সময় পরপর scan status দেখা যায়। এখানে `s` = seconds এবং `m` = minutes।

```
00Luffy00@htb[/htb]$ sudo nmap 10.129.2.28 -p- -sV --stats-every=5s

| `--stats-every=5s` | প্রতি ৫ সেকেন্ডে scan progress দেখায়।            |

Nmap প্রথমে port-এর banner দেখে service ও version শনাক্ত করে। Banner দিয়ে version শনাক্ত করতে না পারলে signature-based matching ব্যবহার করে। এতে scan-এর সময় অনেক বেড়ে যায়।

Nmap-এর automatic scan কখনো কিছু information miss করতে পারে, কারণ সব information handle করা Nmap-এর পক্ষে সম্ভব হয় না।

### Manual Banner Grabbing

Nmap result-এ port status, service name ও hostname দেখা যায়। কিন্তু SMTP server-এর banner-এ আরও information রয়েছে:

`220 inlane ESMTP Postfix (Ubuntu)`

এখানে target-এর Linux distribution Ubuntu সম্পর্কে জানা যায়, যা Nmap-এর সাধারণ result-এ দেখানো হয়নি।

কারণ successful TCP three-way handshake-এর পর server প্রায়ই নিজের পরিচয় জানাতে banner পাঠায়। TCP header-এ `PSH` flag ব্যবহার করে এই data পাঠানো হয়।

তবে:

- কিছু service সাথে সাথে banner পাঠায় না।
- Service-এর banner remove বা manipulate করা সম্ভব।

`nc` দিয়ে manually SMTP server-এ connect করে এবং `tcpdump` দিয়ে traffic capture করে Nmap-এর output-এ না দেখানো information পাওয়া যায়।

### Tcpdump

```
00Luffy00@htb[/htb]$ sudo tcpdump -i eth0 host 10.10.14.2 and 10.129.2.28

tcpdump: verbose output suppressed, use -v or -vv for full protocol decode
listening on eth0, link-type EN10MB (Ethernet), capture size 262144 bytes
```

### Nc

```
00Luffy00@htb[/htb]$  nc -nv 10.129.2.28 25

Connection to 10.129.2.28 port 25 [tcp/*] succeeded!
220 inlane ESMTP Postfix (Ubuntu)
```

18:28:07.319306 IP 10.129.2.28.smtp > 10.10.14.2.59618: Flags [P.], seq 1:36, ack 1, win 510, options [nop,nop,TS val 1800383985 ecr 331260304], length 35: SMTP: 220 inlane ESMTP Postfix (Ubuntu)
18:28:07.319426 IP 10.10.14.2.59618 > 10.129.2.28.smtp: Flags [.], ack 36, win 2058, options [nop,nop,TS val 331260368 ecr 1800383985], length 0
```

প্রথম ৩টি line TCP three-way handshake দেখায়।

| Step | TCP Flag    | Packet                                                                       |
| ---- | ----------- | ---------------------------------------------------------------------------- |
| 1.   | `[SYN]`     | `18:28:07.128564 IP 10.10.14.2.59618 > 10.129.2.28.smtp: Flags [S], <SNIP>`  |
| 2.   | `[SYN-ACK]` | `18:28:07.255151 IP 10.129.2.28.smtp > 10.10.14.2.59618: Flags [S.], <SNIP>` |
| 3.   | `[ACK]`     | `18:28:07.255281 IP 10.10.14.2.59618 > 10.129.2.28.smtp: Flags [.], <SNIP>`  |

এরপর target SMTP server `PSH` এবং `ACK` flag-সহ TCP packet পাঠায়।

- `PSH`: Target server আমাদের কাছে data পাঠাচ্ছে।
- `ACK`: প্রয়োজনীয় data গ্রহণের বিষয়টি acknowledge করে।

| Step | TCP Flag    | Packet                                                                       |
| ---- | ----------- | ---------------------------------------------------------------------------- |
| 4.   | `[PSH-ACK]` | `18:28:07.319306 IP 10.129.2.28.smtp > 10.10.14.2.59618: Flags [P.], <SNIP>` |

শেষ TCP packet-এ আমরা `ACK` পাঠিয়ে data পাওয়ার বিষয়টি confirm করি।

| Step | TCP Flag | Packet                                                                      |
| ---- | -------- | --------------------------------------------------------------------------- |
| 5.   | `[ACK]`  | `18:28:07.319426 IP 10.10.14.2.59618 > 10.129.2.28.smtp: Flags [.], <SNIP>` |
