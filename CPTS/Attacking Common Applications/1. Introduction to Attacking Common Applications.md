## 1. Web Applications

Web application browser দিয়ে ব্যবহার করা যায় এবং সাধারণত client-server architecture ব্যবহার করে।

- Frontend: Browser-এ দেখা interface; client-side চলে।
- Backend: Server-side code ও database।

বিস্তারিত: [Introduction to Web Applications](https://academy.hackthebox.com/course/preview/introduction-to-web-applications?utm_source=chatgpt.com)

CMS, custom applications, intranet portals, code repositories, monitoring tools, ticketing systems, wikis ও issue trackers—এসব application penetration test-এ পাওয়া যায়। Application এক environment-এ secure হলেও অন্যটিতে misconfigured বা unpatched হতে পারে।

বিভিন্ন application-এ সাধারণ vulnerability: [OWASP Top 10](https://owasp.org/www-project-top-ten/?utm_source=chatgpt.com), SQL injection, XSS, remote code execution (RCE), local file read ও unrestricted file upload। Built-in functionality অপব্যবহার করেও RCE হতে পারে।

External perimeter শক্ত হলেও web application internal বা external network-এ foothold, lateral movement বা sensitive data access-এর সুযোগ দিতে পারে।

### Application Security Survey

[The State of Application Security in 2021](https://blog.barracuda.com/2021/05/18/report-the-state-of-application-security-in-2021/?utm_source=chatgpt.com)

750টি বড় কোম্পানির decision-maker-এর survey:

- 72% — অন্তত একটি application vulnerability breach।
- 32% — দুটি breach।
- 14% — তিনটি breach।
- Bot attacks: 43%
- Software supply chain attacks: 39%
- Vulnerability detection: 38%
- Securing APIs: 37%

Module-টি open-source ও commercial applications-এর পরিচিত vulnerability এবং misconfiguration নিয়ে আলোচনা করে।

## 3. A Quick Story

একটি external penetration test-এ [Nexus Repository OSS](https://www.sonatype.com/products/repository-oss?utm_source=chatgpt.com)-এর default credentials `admin:admin123` পরিবর্তন করা হয়নি। Authenticated API ব্যবহার করে RCE পাওয়া যায়।

অন্য assessment-এ একই default credentials দিয়ে login করে [Tasks](https://help.sonatype.com/en/tasks.html?utm_source=chatgpt.com#UUID-53669de9-914f-58da-0ba3-9e129cd2e3de_id_Tasks-Admin-Executescript) functionality দিয়ে [Groovy](https://groovy-lang.org/?utm_source=chatgpt.com) [script](https://help.sonatype.com/en/writing-scripts.html?utm_source=chatgpt.com) চালিয়ে RCE পাওয়া যায়। প্রথম assessment-এ Tasks disabled ছিল।

এটি Jenkins-এর [Script Console](https://www.jenkins.io/doc/book/managing/script-console/?utm_source=chatgpt.com)-এর মতো। [ManageEngine OpManager](https://www.manageengine.com/products/applications_manager/me-opmanager-monitoring.html?utm_source=chatgpt.com)-এর মতো application-ও application যে user হিসেবে চলছে (সাধারণত `NT AUTHORITY\SYSTEM`), সেই user হিসেবে script চালাতে দিতে পারে। তাই application উপেক্ষা করা যাবে না।

## 5. Module Targets

Module-এ `http://app.inlanefreight.local`-এর মতো URL ব্যবহৃত হবে। বিভিন্ন web application একই host-এর আলাদা directory-তে Vhosts দিয়ে রাখা হয়। তাই FQDN ব্যবহার করা scan/example-এর জন্য Pwnbox বা local attack VM-এর `/etc/hosts`-এ entry যোগ করতে হবে। শুধু target IP ও port ব্যবহার করা Splunk-এর মতো section-এ hosts entry দরকার নেই।

### `/etc/hosts` Entry যোগ করা

```
00Luffy00@htb[/htb]$ IP=10.129.42.195
00Luffy00@htb[/htb]$ printf "%s\t%s\n\n" "$IP" "app.inlanefreight.local dev.inlanefreight.local blog.inlanefreight.local" | sudo tee -a /etc/hosts
```

### `/etc/hosts` যাচাই

```
00Luffy00@htb[/htb]$ cat /etc/hosts

# Your system has configured 'manage_etc_hosts' as True.
# As a result, if you wish for changes to this file to persist
# then you will need to either
# a.) make changes to the master file in /etc/cloud/templates/hosts.debian.tmpl
# b.) change or remove the value of 'manage_etc_hosts' in
#     /etc/cloud/cloud.cfg or cloud-config from user-data
#
127.0.1.1 htb-9zftpkslke.htb-cloud.com htb-9zftpkslke
127.0.0.1 localhost

# The following lines are desirable for IPv6 capable hosts
::1 ip6-localhost ip6-loopback
fe00::0 ip6-localnet
ff00::0 ip6-mcastprefix
ff02::1 ip6-allnodes
ff02::2 ip6-allrouters
ff02::3 ip6-allhosts

10.129.42.195   app.inlanefreight.local dev.inlanefreight.local blog.inlanefreight.local
```

নিজের script লিখে বা hosts file হাতে edit করেও entry যোগ করা যায়।

মনে রাখবে: Target-কে FQDN দিয়ে access করতে না পারলে `/etc/hosts` পরীক্ষা করে entry update করো। যেসব module exercise-এ Vhosts লাগে, target VM spawn করার পর section-এর নিচে প্রয়োজনীয় hosts entries দেওয়া থাকবে।
