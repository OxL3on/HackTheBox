## 2. Directory Traversal

Path Traversal দিয়ে application-এর নির্ধারিত directory-এর বাইরে থাকা file access করা যায়।

- কারণ: Input validation ঠিকমতো না করা।
- Attack হতে পারে URL parameter, form field, cookie ইত্যাদির মাধ্যমে।
- Sensitive file, configuration, user data পড়া সম্ভব।
- ColdFusion-এর `CFFile` ও `CFDIRECTORY` tag-এর file operation-এ vulnerability থাকতে পারে।

### Vulnerable Code

```
<cfdirectory directory="#ExpandPath('uploads/')#" name="fileList">
<cfloop query="fileList">
    <a href="uploads/#fileList.name#">#fileList.name#</a><br>
</cfloop>
```

এখানে `cfdirectory` uploads directory-এর file list করে এবং `cfloop` filename-গুলো clickable link হিসেবে দেখায়।

কিন্তু directory input validate না করলে attacker অন্য directory access করতে পারে।

Example:

```
http://example.com/index.cfm?directory=../../../etc/&file=passwd
```

`../` দিয়ে directory structure পেছনে গিয়ে `/etc/passwd` access করা যায়।

### CVE-2010-2861

- Adobe ColdFusion-এর Directory Traversal vulnerability।
- ColdFusion 9.0.1 ও তার আগের version আক্রান্ত।
- নির্দিষ্ট file-এর `locale` parameter manipulate করে arbitrary file পড়া যায়।

আক্রান্ত file:

```
CFIDE/administrator/settings/mappings.cfm
logging/settings.cfm
datasources/index.cfm
j2eepackaging/editarchive.cfm
CFIDE/administrator/enter.cfm
```

Normal URL:

```
http://www.example.com/CFIDE/administrator/settings/mappings.cfm?locale=en
```

Path Traversal URL:

```
http://www.example.com/CFIDE/administrator/settings/mappings.cfm?locale=../../../../../etc/passwd
```

`locale` parameter-এ `../` দিয়ে `/etc/passwd` পড়ার চেষ্টা করা হয়।

## 3. Unauthenticated RCE

Unauthenticated RCE হলো authentication ছাড়াই vulnerable system-এ arbitrary code execute করতে পারা।

- RCE-তে attacker-এর authentication প্রয়োজন হতে পারে।
- Unauthenticated RCE-তে কোনো valid credential ছাড়াই code execute করা যায়।
- এতে attacker system control করতে, sensitive data চুরি করতে বা damage করতে পারে।

### Vulnerable ColdFusion Code

```
<cfset cmd = "#cgi.query_string#">
<cfexecute name="cmd.exe" arguments="/c #cmd#" timeout="5">
```

- `cgi.query_string` থেকে command নেওয়া হচ্ছে।
- `cfexecute` দিয়ে Windows `cmd.exe` execute করা হচ্ছে।
- Input validation ও authentication না থাকায় attacker malicious command পাঠাতে পারে।

Example:

```
# Decoded: http://www.example.com/index.cfm?; echo "This server has been compromised!" > C:\compromise.txt

http://www.example.com/index.cfm?%3B%20echo%20%22This%20server%20has%20been%20compromised%21%22%20%3E%20C%3A%5Ccompromise.txt
```

- `%3B` হলো semicolon (`;`)।
- Semicolon দিয়ে একাধিক command execute করার সুযোগ তৈরি হতে পারে।
- `echo` message print করে এবং `>` দিয়ে `C:\compromise.txt` file-এ লিখে।

### CVE-2009-2265

- Adobe ColdFusion 8.0.1 ও আগের version আক্রান্ত।
- Unauthenticated user file upload করে RCE পেতে পারে।
- Vulnerability ছিল FCKeditor package-এ।

Vulnerable path:

```
http://www.example.com/CFIDE/scripts/ajax/FCKeditor/editor/filemanager/connectors/cfm/upload.cfm?Command=FileUpload&Type=File&CurrentFolder=
```
