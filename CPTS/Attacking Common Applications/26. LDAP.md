# LDAP

## 1. LDAP কী?

`LDAP (Lightweight Directory Access Protocol)` হলো directory information access ও manage করার protocol।

Directory: Hierarchical data store, যেখানে network-এর users, groups, computers, printers ও অন্যান্য device-এর তথ্য থাকে।

### LDAP-এর সুবিধা

| Functionality           | Description                                             |
| ----------------------- | ------------------------------------------------------- |
| Efficient               | দ্রুত query ও connection করা যায়।                       |
| Global naming model     | একাধিক directory-তে unique entry নিশ্চিত করে।           |
| Extensible and flexible | প্রয়োজন অনুযায়ী custom attributes ও schema যোগ করা যায়। |
| Compatibility           | TCP/IP ও SSL দিয়ে চলে; platform-independent।            |
| Authentication          | একবার sign-in করে একাধিক resource access করা যায়।       |

### LDAP-এর সমস্যা

| Functionality | Description                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Compliance    | Directory server-কে LDAP compliant হতে হয়, ফলে vendor choice সীমিত হতে পারে।                                              |
| Complexity    | Configure ও secureভাবে ব্যবহার করা কঠিন।                                                                                  |
| Encryption    | LDAP defaultভাবে traffic encrypt করে না। Encryption-এর জন্য LDAPS বা StartTLS প্রয়োজন।                                    |
| Injection     | LDAP injection-এর মাধ্যমে query পরিবর্তন করে unauthorized access পাওয়া সম্ভব। Input validation ও output encoding প্রয়োজন। |

### LDAP-এর ব্যবহার

| Use Case           | Description                                                                             |
| ------------------ | --------------------------------------------------------------------------------------- |
| Authentication     | একাধিক application ও system-এ একই login credentials ব্যবহার।                            |
| Authorisation      | Folder/file-এর permission ও access control manage করা; Kerberos integration লাগতে পারে। |
| Directory Services | Directory-তে data search, retrieve ও modify করা। এটি X.500 standard-এর উপর ভিত্তি করে।  |
| Synchronisation    | এক directory-এর পরিবর্তন অন্য directory-তে replicate করে data consistent রাখা।          |

জনপ্রিয় LDAP implementation:

- `OpenLDAP` — Open-source।
- `Microsoft Active Directory` — Windows-based implementation।

## 2. LDAP vs Active Directory

- LDAP: Directory service access ও modify করার protocol।
- AD: User ও computer data store এবং manage করার directory service। AD LDAP ব্যবহার করতে পারে, কিন্তু LDAP নিজে directory service নয়।
- AD-তে policy administration, single sign-on ও Microsoft products integration-এর মতো অতিরিক্ত সুবিধা আছে।

| LDAP                                                                           | Active Directory (AD)                                                     |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Client-server communication-এর protocol।                                       | LDAP ব্যবহার করে authentication ও authorisation দেয় এমন directory server। |
| Open ও cross-platform।                                                         | Proprietary, Windows-based; DNS ও Kerberos-এর মতো component প্রয়োজন।      |
| Flexible ও extensible schema; custom attributes ও object classes তৈরি করা যায়। | Predefined schema; X.500 extend করে। পরিবর্তন সতর্কভাবে করতে হয়।          |
| Simple bind, SASL ইত্যাদি authentication support করে।                          | Kerberos প্রধান; NTLM ও LDAP over SSL/TLS-ও support করে।                  |

## 3. LDAP কীভাবে কাজ করে?

LDAP client-server architecture ব্যবহার করে।

1. Client LDAP request পাঠায়।
2. Server directory search/process করে।
3. Server response ফেরত দেয়।
4. Client connection বন্ধ করে।

- LDAP, X.500-এর উপর ভিত্তি করে তৈরি, তবে আরও সহজ ও efficient।
- Message ASN.1 format-এ encode হয়ে TCP/IP দিয়ে যায়।
- Request types: `bind`, `unbind`, `search`, `compare`, `add`, `delete`, `modify` ইত্যাদি।

### LDAP Request-এর অংশ

1. Session connection: সাধারণত port `389` বা `636` দিয়ে connect করে।
2. Request type: যেমন `bind`, `search`।
3. Request parameters: DN, search scope/filter, attributes ও values।
4. Request ID: প্রতিটি request-এর unique ID, যাতে response match করা যায়।

### LDAP Response-এর অংশ

1. Response type: কোন operation-এর response।
2. Result code: সফল হয়েছে কি না এবং কেন।
3. Matched DN: প্রযোজ্য হলে কাছাকাছি matching entry-এর DN।
4. Referral: অন্য server-এর URL, যেখানে তথ্য থাকতে পারে।
5. Response data: Search/modify করা entry-এর attributes ও values।

### ldapsearch

Directory থেকে তথ্য খোঁজার command-line tool।

```
ldapsearch -H ldap://ldap.example.com:389 -D "cn=admin,dc=example,dc=com" -w secret123 -b "ou=people,dc=example,dc=com" "(mail=john.doe@example.com)"
```

- `-H` → `ldap.example.com`-এর port `389`-এ connect।
- `-D` → `cn=admin,dc=example,dc=com` হিসেবে bind/authenticate।
- `-w` → Password `secret123`।
- `-b` → Search শুরু হবে `ou=people,dc=example,dc=com` থেকে।
- Filter `(mail=john.doe@example.com)` → এই email থাকা entry খুঁজবে।

সম্ভাব্য response:

```
dn: uid=jdoe,ou=people,dc=example,dc=com
objectClass: inetOrgPerson
objectClass: organizationalPerson
objectClass: person
objectClass: top
cn: John Doe
sn: Doe
uid: jdoe
mail: john.doe@example.com

result: 0 Success
```

এখানে matching entry-এর DN, attributes ও values দেখানো হয়েছে।

## 4. LDAP Injection

`LDAP Injection` হলো LDAP ব্যবহার করা web application-এর query-তে malicious character বা code inject করে query-এর meaning পরিবর্তন করা।

এর মাধ্যমে:

- Authentication bypass করা যায়।
- Sensitive data access করা যায়।
- Security control bypass করা যায়।

### Special Characters

| Input    | কাজ                                                                                  |
| -------- | ------------------------------------------------------------------------------------ |
| `*`      | যেকোনো সংখ্যক character match করে।                                                   |
| `( )`    | Expression group করে।                                                                |
| `\\|`    | Logical OR।                                                                          |
| `&`      | Logical AND।                                                                         |
| `(cn=*)` | এমন condition তৈরি করতে পারে যা সবসময় true হয়। `(objectClass=*)`-ও ব্যবহার হতে পারে। |

LDAP Injection দেখতে SQL Injection-এর মতো, তবে এটি database নয়, LDAP directory target করে।

### Injection Example

Application-এর authentication query:

```
(&(objectClass=user)(sAMAccountName=$username)(userPassword=$password))
```

এখানে `$username` ও `$password` user-এর login credentials।

Username-এ `*` দিলে:

```
$username = "*";
$password = "dummy";
(&(objectClass=user)(sAMAccountName=$username)(userPassword=$password))
```

এতে `dummy` password থাকা যেকোনো user account match করতে পারে। যেকোনো username দিয়ে access পাওয়া সম্ভব হতে পারে।

Password-এ `*` দিলে:

```
$username = "dummy";
$password = "*";
(&(objectClass=user)(sAMAccountName=$username)(userPassword=$password))
```

এতে `dummy` user account-এর যেকোনো password দিয়ে access পাওয়া সম্ভব হতে পারে।

### LDAP Injection-এর প্রভাব

- Unauthorized access।
- Elevated privileges।
- Application/server-এর full control।
- Directory data modify বা delete করে data integrity ও availability নষ্ট করা।

প্রতিরোধ:

- User input validate ও sanitize করতে হবে।
- LDAP special character যেমন `*` সরাতে হবে।
- Parameterised query ব্যবহার করতে হবে, যাতে input শুধু data হিসেবে বিবেচিত হয়, executable code হিসেবে নয়।

## 5. LDAP Enumeration

প্রথমে target-এর open port ও service খুঁজতে Nmap scan করতে হবে।

### Injection Test

Server-এ OpenLDAP চলছে। তাই port `80`-এর web application authentication-এর জন্য LDAP ব্যবহার করছে বলে ধারণা করা যায়।

Username ও password field-এ wildcard `*` দিয়ে login চেষ্টা করলে authentication bypass করে access পাওয়া যায়।
