# Application Hardening

## 1. Application Inventory

প্রথমে organization-এর সব internal ও external-facing application-এর inventory তৈরি করতে হবে।

- Nmap ও EyeWitness-এর মতো pentesting tool দিয়ে inventory তৈরি করা যায়।
- Open-source ও paid tool ব্যবহার করা যায়।
- কী কী application আছে না জানলে সেগুলো protect করা সম্ভব নয়।

Inventory তৈরির মাধ্যমে পাওয়া যেতে পারে:

- Shadow IT: Unauthorized application installation।
- Deprecated application: আর প্রয়োজন নেই এমন application।
- Trial version থেকে automatically free version-এ পরিবর্তিত application। যেমন: Splunk, যেখানে authentication আর প্রয়োজন হয় না।

## 2. General Hardening Tips

| Category                               | কী করতে হবে                                                                                                                                                                                                      |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Secure authentication                  | Strong password enforce করতে হবে। Default admin password পরিবর্তন ও সম্ভব হলে default account disable করতে হবে। নতুন custom admin account তৈরি করতে হবে। সম্ভব হলে অন্তত admin-এর জন্য 2FA বাধ্যতামূলক করতে হবে। |
| Access controls                        | Proper access control দিতে হবে। Business reason না থাকলে external network থেকে login page access বন্ধ রাখতে হবে। Upload ও application deployment permission সীমিত করতে হবে।                                      |
| Disable unsafe features                | WordPress-এর PHP code editing-এর মতো feature disable করতে হবে, যাতে server compromise হলেও code execution আটকানো যায়।                                                                                            |
| Regular updates                        | Application নিয়মিত update এবং vendor-এর patch দ্রুত install করতে হবে।                                                                                                                                            |
| Backups                                | Website ও database-এর backup রাখতে হবে, যাতে compromise হলে দ্রুত restore করা যায়।                                                                                                                               |
| Security monitoring                    | Security tool/plugin দিয়ে application monitor করতে হবে। WAF অতিরিক্ত protection দিতে পারে, তবে এটি অন্য security measure-এর বিকল্প নয়।                                                                           |
| LDAP integration with Active Directory | AD Single Sign-On ব্যবহার করলে access সহজ হয়, auditing উন্নত হয় এবং credentials/service account manage করা সহজ হয়। Azure-এর সঙ্গে sync করলে auditing সুবিধা বাড়ে। Password policy-ও নিয়ন্ত্রণ করা যায়।           |

### গুরুত্বপূর্ণ Hardening Guidelines

- Admin ও user-এর জন্য সম্ভব হলে MFA enable করতে হবে।
- Default admin username পরিবর্তন করতে হবে।
- Admin account-এর সংখ্যা সীমিত রাখতে হবে।
- Admin access open internet থেকে বন্ধ রাখতে হবে।
- Principle of Least Privilege অনুসরণ করতে হবে।
- নিয়মিত update ও patch দিতে হবে।
- Secondary location-এ নিয়মিত backup রাখতে হবে।
- Brute-force ও malicious activity detect/block করার monitoring tool ব্যবহার করতে হবে।

### Internet Exposure

কোন application internet-এ expose করা প্রয়োজন, তা যাচাই করতে হবে।

উদাহরণ:

- GitLab repository কি সত্যিই public হওয়া দরকার?
- Ticketing system কি internal network-এর বাইরেও accessible হওয়া প্রয়োজন?

Application inventory নিয়মিত check ও update করতে হবে, যাতে অপ্রয়োজনীয় বা vulnerable application expose না থাকে।

এছাড়া:

- নিয়মিত security assessment করতে হবে।
- Vulnerability, misconfiguration ও sensitive data exposure খুঁজতে হবে।
- Pentest report-এর remediation recommendation বাস্তবায়ন করতে হবে।
- আগের পাওয়া vulnerability আবার পরীক্ষা করতে হবে।

কিছু সমস্যা technical নয়, বরং organizational process ও security awareness-এর সঙ্গে সম্পর্কিত।

## 4. Conclusion

- Web application একটি বিশাল attack surface, যা অনেক সময় overlooked থাকে।
- External penetration test-এ বেশিরভাগ target application হতে পারে।
- Application discovery ও scan data organize করতে জানতে হবে।
- Version fingerprinting ও known vulnerability খুঁজতে হবে।
- Built-in functionality abuse করার পদ্ধতি বুঝতে হবে।

অনেক organization patching ও vulnerability management ঠিকভাবে করলেও weak credentials উপেক্ষা করে।

উদাহরণ:

- Tomcat Manager-এর weak credentials।
- Printer-এর web management application-এ default credentials ব্যবহার।
- Printer থেকে LDAP credentials পাওয়া, যা internal network-এ foothold হিসেবে ব্যবহার করা যায়।
