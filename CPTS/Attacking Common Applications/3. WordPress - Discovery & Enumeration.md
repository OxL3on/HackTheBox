# WordPress - Discovery & Enumeration - [LINK](https://academy.hackthebox.com/app/module/113/section/1100)

## 1. WordPress পরিচিতি

[WordPress](https://wordpress.org/?utm_source=chatgpt.com) হলো 2003 সালে চালু হওয়া open-source CMS। Blog, forum ও website তৈরিতে ব্যবহৃত হয়। এটি PHP-তে লেখা এবং সাধারণত Apache ও MySQL ব্যবহার করে। Themes ও plugins customize করা যায়, তবে এগুলো vulnerability-এর কারণও হতে পারে।

তথ্যসূত্র: [WordPress Statistics](https://hostingtribunal.com/blog/wordpress-statistics/?utm_source=chatgpt.com)

- 50,000-এর বেশি plugins ও 4,100-এর বেশি GPL-licensed themes।
- শুরু থেকে 317টি পৃথক version প্রকাশিত হয়েছে।
- প্রতিদিন প্রায় 661টি নতুন WordPress website তৈরি হয়।
- Blog 120টির বেশি ভাষায় লেখা হয়।
- WordPress hack-এর প্রায় 8% weak password এবং 60% outdated version-এর কারণে।
- প্রায় 4,000 পরিচিত vulnerability-এর মধ্যে 54% plugins, 31.5% WordPress core এবং 14.5% themes-এর।
- ব্যবহারকারী বড় brand: The New York Times, eBay, Sony, Forbes, Disney, Facebook, Mercedes-Benz ইত্যাদি।

বিস্তারিত: [HTB Hacking WordPress](https://academy.hackthebox.com/course/preview/hacking-wordpress?utm_source=chatgpt.com)

## 2. Discovery / Footprinting

WordPress চেনার উপায়:

- `/robots.txt` পরীক্ষা।
- `/wp-admin` ও `/wp-content` directory খোঁজা।
- `/wp-admin` সাধারণত `/wp-login.php`-এ redirect করে।
- Plugins: `wp-content/plugins`
- Themes: `wp-content/themes`

### `robots.txt` উদাহরণ

```
User-agent: *
Disallow: /wp-admin/
Allow: /wp-admin/admin-ajax.php
Disallow: /wp-content/uploads/wpforms/

Sitemap: https://inlanefreight.local/wp-sitemap.xml
```

Login page: `http://blog.inlanefreight.local/wp-login.php`

[WordPress Login Screenshot](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/113/wp-login2.png?utm_source=chatgpt.com)

Plugins ও themes enumerate করতে হবে, কারণ এগুলো থেকে RCE হতে পারে।

### WordPress User Roles

1. Administrator: Users/posts add/delete এবং source code edit করতে পারে।
2. Editor: নিজের ও অন্যদের posts publish/manage করে।
3. Author: নিজের posts publish/manage করে।
4. Contributor: নিজের posts লিখতে/manage করতে পারে, কিন্তু publish করতে পারে না।
5. Subscriber: Posts browse ও নিজের profile edit করে।

Administrator access সাধারণত server-এ code execution পাওয়ার জন্য যথেষ্ট হতে পারে। Editor/Author-এরও কিছু vulnerable plugin-এ access থাকতে পারে।

## 5. WPScan

[WPScan](https://github.com/wpscanteam/wpscan?utm_source=chatgpt.com) হলো automated WordPress scanner। Themes/plugins outdated বা vulnerable কি না শনাক্ত করে। Parrot OS-এ সাধারণত আগে থেকেই থাকে; Ruby `gem` দিয়েও install করা যায়।

```
sudo gem install wpscan
```

[WPVulnDB](https://wpvulndb.com/?utm_source=chatgpt.com) থেকে API token নিয়ে WPScan-এ `--api-token` দিয়ে ব্যবহার করা যায়। Free plan-এ প্রতিদিন সর্বোচ্চ 25টি request।

## 6. Final Findings

- WordPress core: `5.8`; কিছু vulnerability আছে, তবে এই পর্যায়ে সেগুলো আকর্ষণীয় মনে হয়নি।
- Theme: `Transport Gravity`
- Plugins: Contact Form 7, mail-masta, wpDiscuz
- wpDiscuz `7.0.4`: unauthenticated RCE
- mail-masta `1.0.0`: LFI ও SQL injection
- Username enumeration সম্ভব; `admin` ও `john` valid users
- Site জুড়ে directory listing enabled; sensitive data leak হতে পারে।
- XML-RPC enabled; WPScan বা [Metasploit XML-RPC Login Scanner](https://www.rapid7.com/db/modules/auxiliary/scanner/http/wordpress_xmlrpc_login?utm_source=chatgpt.com) দিয়ে login page-এ password brute-force করা যেতে পারে।

মূল শিক্ষা: Manual ও automated enumeration একসঙ্গে ব্যবহার করো। Scanner সহায়ক, কিন্তু মানুষের যাচাই ও কৌতূহলের বিকল্প নয়।
