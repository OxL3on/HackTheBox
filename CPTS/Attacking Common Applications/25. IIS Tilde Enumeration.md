# IIS Tilde Enumeration

## মূল ধারণা

- IIS Tilde Enumeration দিয়ে IIS server-এর hidden file, directory এবং short filename খুঁজে বের করা যায়।
- Windows-এর 8.3 format-এ filename হয়: ৮টি অক্ষর + `.` + ৩ অক্ষরের extension।
- URL-এ `~` এবং sequence number ব্যবহার করে short filename শনাক্ত করা যায়।
- নির্দিষ্ট character দিয়ে HTTP request পাঠিয়ে valid short name খুঁজে বের করা হয়।

উদাহরণ:

```
http://example.com/~a
http://example.com/~b
http://example.com/~c
```

`200 OK` পেলে বুঝতে হবে ওই character দিয়ে শুরু হওয়া short name থাকতে পারে।

ধাপে ধাপে character যোগ করা হয়:

```
http://example.com/~se
http://example.com/~sec
http://example.com/~secret
```

এভাবে `secret~1` directory পাওয়া যেতে পারে।

এরপর directory-এর ফাইল access করা যায়:

```
http://example.com/secret~1/somefile.txt
http://example.com/secret~1/anotherfile.docx
```

ফাইলের short name দিয়েও access করা যায়:

```
http://example.com/secret~1/somefi~1.txt
```

একই directory-তে একই রকম নামের ফাইল থাকলে `~1`, `~2` দিয়ে আলাদা করা হয়।

- `somefile.txt` → `somefi~1.txt`
- `somefile1.txt` → `somefi~2.txt`

## Enumeration

### 1. Nmap – Open Ports

```
nmap -p- -sV -sC --open 10.129.224.91
```

Output-এর গুরুত্বপূর্ণ তথ্য:

| Port   | Service | Version                 |
| ------ | ------- | ----------------------- |
| 80/tcp | HTTP    | Microsoft IIS httpd 7.5 |

- Target-এর port `80`-এ IIS 7.5 চলছে।
- এই version-এ Tilde Enumeration পরীক্ষা করা যেতে পারে।

### 2. IIS ShortName Scanner

প্রতিটি character দিয়ে manually request পাঠানো সময়সাপেক্ষ। তাই `IIS-ShortName-Scanner` ব্যবহার করা যায়।

- GitHub: [IIS-ShortName-Scanner](https://github.com/irsdl/IIS-ShortName-Scanner?utm_source=chatgpt.com)
- প্রয়োজন: Oracle Java
- Installation: [How to Install Oracle Java](https://ubuntuhandbook.org/index.php/2022/03/install-jdk-18-ubuntu/?utm_source=chatgpt.com)

Command:

```
java -jar iis_shortname_scanner.jar 0 5 http://10.129.204.231/
```

Proxy চাইলে No-এর জন্য Enter চাপতে হবে।

Output:

```
IIS Short Name (8.3) Scanner version 2023.0
Target: http://10.129.204.231/
|_ Result: Vulnerable!
|_ Used HTTP method: OPTIONS
|_ Suffix (magic part): /~1/
|_ Extra information:
  |_ Number of sent requests: 553
  |_ Identified directories: 2
    |_ ASPNET~1
    |_ UPLOAD~1
  |_ Identified files: 3
    |_ CSASPX~1.CS
      |_ Actual extension = .CS
    |_ CSASPX~1.CS??
    |_ TRANSF~1.ASP
```

- মোট ২টি directory এবং ৩টি file পাওয়া গেছে।
- কিন্তু `http://10.129.204.231/TRANSF~1.ASP`-এ GET access সম্ভব নয়।
- তাই আসল filename brute-force করতে হবে।

### 3. Generate Wordlist

Pwnbox-এর wordlist পাওয়া যায় `/usr/share/wordlists/` directory-তে।

```
egrep -r ^transf /usr/share/wordlists/* | sed 's/^[^:]*://' > /tmp/list.txt
```

| Command             | কাজ                                                                             |
| ------------------- | ------------------------------------------------------------------------------- |
| `egrep -r ^transf`  | সব wordlist থেকে `transf` দিয়ে শুরু হওয়া line খোঁজে। `-r` recursive search করে। |
| `\\|`               | প্রথম command-এর output দ্বিতীয় command-এ পাঠায়।                                |
| `sed 's/^[^:]*://'` | প্রতিটি line থেকে filename ও colon সরিয়ে দেয়।                                   |
| `> /tmp/list.txt`   | ফলাফল `/tmp/list.txt` ফাইলে save করে।                                           |

### 4. Gobuster Enumeration

Custom wordlist দিয়ে hidden file ও directory খুঁজতে Gobuster ব্যবহার করা হয়। এটি Go দিয়ে তৈরি directory/file brute-forcing tool।

Command:

```
gobuster dir -u http://10.129.204.231/ -w /tmp/list.txt -x .aspx,.asp
```
