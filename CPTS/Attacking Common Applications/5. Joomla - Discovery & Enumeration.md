# Joomla - Discovery & Enumeration - [LINK](https://academy.hackthebox.com/app/module/113/section/1095)


## 1. Joomla পরিচিতি

[Joomla](https://www.joomla.org/?utm_source=chatgpt.com) হলো free, open-source CMS, released August 2005। এটি PHP-তে লেখা এবং backend-এ MySQL ব্যবহার করে। Forum, photo gallery, e-Commerce ও user community তৈরিতে ব্যবহৃত হয়।

- 7,000+ extensions এবং 1,000+ templates।
- প্রায় 2.5 million website Joomla ব্যবহার করে।
- [Joomla Statistics](https://websitebuilder.org/blog/joomla-statistics/?utm_source=chatgpt.com):
  - CMS market share-এর 3.5%।
  - 100% free; Swahili-তে “Jumla” অর্থ “all together”।
  - Online forum-এ প্রায় 700,000 community users।
  - Internet-এর 3% website এবং বিশ্বের top 1 million site-এর প্রায় 25,000টি Joomla ব্যবহার করে।
  - ব্যবহারকারী organization: eBay, Yamaha, Harvard University, UK government।
  - 770 developers অবদান রেখেছেন।

Joomla anonymous usage statistics সংগ্রহ করে—যেমন Joomla/PHP/database version ও server OS।

- [Usage Statistics](https://developer.joomla.org/about/stats.html?utm_source=chatgpt.com)
- [Public API](https://developer.joomla.org/about/stats/api.html?utm_source=chatgpt.com)

API query করে 2.7 million-এর বেশি Joomla installations দেখা যায়।

## 2. Discovery / Footprinting

External penetration test-এ কোনো e-commerce site custom মনে না হলে CMS fingerprint করে version, themes, plugins ও misconfiguration খুঁজতে হবে।

### Joomla শনাক্ত করা

Page source-এর generator metadata দেখতে:

```
curl -s http://dev.inlanefreight.local/ | grep Joomla
```

Output:

```
<meta name="generator" content="Joomla! - Open Source Content Management" />
```

### Version শনাক্ত করা

Joomla favicon একটি clue হতে পারে, তবে সবসময় নয়। `README.txt` থাকলে version সম্পর্কে ধারণা পাওয়া যায়।

```
curl -s http://dev.inlanefreight.local/README.txt | head -n 5
```

Output:

```
1- What is this?
    * This is a Joomla! installation/upgrade package to version 3.x
    * Joomla! Official site: https://www.joomla.org
    * Joomla! 3.9 version history - https://docs.joomla.org/Special:MyLanguage/Joomla_3.9_version_history

```

### 3.3 Admin login ও brute force

এই lab-এ Joomla version হলো `3.9.4`।

Admin login URL:

`http://dev.inlanefreight.local/administrator/index.php`

User enumeration করলে generic error দেখা যায়:

```
Warning
Username and password do not match or you do not have an account yet.
```

Joomla-তে default administrator username হলো `admin`; password installation-এর সময় সেট করা হয়। দুর্বল/common password হলে guesswork বা light brute force করে login পাওয়া সম্ভব।

[joomla-bruteforce script](https://github.com/ajnik/joomla-bruteforce?utm_source=chatgpt.com) ব্যবহার করা যায়।

```
sudo python3 joomla-brute.py -u http://dev.inlanefreight.local -w /usr/share/metasploit-framework/data/wordlists/http_default_pass.txt -usr admin
```

Output:

```
admin:admin
```

পাওয়া credentials: `admin:admin` — এটি দুর্বল password ব্যবহারের উদাহরণ।
