# PRTG Network Monitor

## 1. PRTG পরিচিতি

[PRTG Network Monitor](https://www.paessler.com/prtg?utm_source=chatgpt.com) হলো agentless network monitoring software। এটি দিয়ে monitor করা যায়:

- Bandwidth usage
- Uptime
- Router, switch, server ইত্যাদির statistics

গুরুত্বপূর্ণ তথ্য:

- প্রথম version: 2003
- Free version: 2015 সালে প্রকাশিত; সর্বোচ্চ 100 sensors এবং 20 hosts monitor করতে পারে।
- Auto-discovery দিয়ে network scan করে device list তৈরি করে।
- ICMP, SNMP, WMI, NetFlow ইত্যাদি protocol দিয়ে device থেকে তথ্য সংগ্রহ করে।
- REST API দিয়েও device communicate করতে পারে।
- AJAX-based website দিয়ে চলে; Windows, Linux ও macOS-এর desktop application-ও আছে।

কোম্পানি সম্পর্কিত তথ্য:

- 300,000 users worldwide।
- Paessler monitoring solution তৈরি করছে 1997 সাল থেকে।
- ব্যবহারকারী প্রতিষ্ঠানের উদাহরণ: Naples International Airport, Virginia Tech, 7-Eleven।
- [Customer list](https://www.paessler.com/company/casestudies?utm_source=chatgpt.com)

Vulnerability:

- মোট 26টি CVE রয়েছে।
- Public PoC সহজে পাওয়া যায় মাত্র 4টির:
  - 2টি XSS
  - 1টি Denial of Service
  - 1টি Authenticated Command Injection

Internal penetration test-এ PRTG প্রায়ই পাওয়া যায়, তবে externally exposed থাকা তুলনামূলক বিরল।

উদাহরণ: [HTB Netmon](https://0xdf.gitlab.io/2019/06/29/htb-netmon.html?utm_source=chatgpt.com)

### Command Injection

Notification-এর নাম দিয়ে নিচে scroll করে:

1. `EXECUTE PROGRAM` checkbox tick করতে হবে।
2. `Program File` থেকে `Demo exe notification - outfile.ps1` select করতে হবে।
3. `Parameter` field-এ command দিতে হবে।
4. `Save` click করতে হবে।

উদাহরণ: নিচের command দিয়ে নতুন local admin user তৈরি করা হয়।

### Local Admin Access Verify

এটি blind command execution, তাই command-এর output সরাসরি পাওয়া যাবে না।

Access verify করতে পারি:

- Listener-এ connection এসেছে কি না।
- Local admin credentials দিয়ে login করা যায় কি না।
- RDP বা WinRM দিয়ে access।
- `evil-winrm`, `wmiexec.py` অথবা `psexec.py` ব্যবহার।
