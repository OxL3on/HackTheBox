# Other Notable Applications

## 1. মূল ধারণা

এই module-এ ৯টি application নিয়ে আলোচনা করা হয়েছে। কিন্তু বাস্তবে আরও অনেক application পাওয়া যায়।

- বড় penetration test-এ ৫০০+ পৃষ্ঠার EyeWitness report পাওয়া যেতে পারে।
- Network enumerate করে application-গুলোর visual map তৈরি করতে হবে, যেন কোনো service বাদ না পড়ে।
- Application attack করার পদ্ধতি:
  - Fingerprinting ও discovery।
  - Built-in functionality abuse।
  - Known public exploits ব্যবহার।
- osTicket ও GitLab-এর মতো application থেকে অন্য জায়গায় কাজে লাগতে পারে এমন তথ্য, credentials ও access পাওয়া যেতে পারে।

মূল শিক্ষা:

কয়েকটি scan চালিয়ে সরাসরি exploit না পেলেই থেমে যাওয়া যাবে না। Scan result-এর noise filter করে ভালোভাবে examine করতে হবে।

উদাহরণ:

- Tomcat-এ weak/default credentials পাওয়া।
- Open Git repository থেকে SSH key বা password পাওয়া।
- Custom application-এর default credentials বা built-in functionality abuse করে RCE পাওয়া।

অজানা application পেলেও একই methodology ব্যবহার করতে হবে। শুধু এই module-এর application-গুলোর মধ্যে সীমাবদ্ধ থাকা যাবে না।

## 3. Final Lesson

এটি সম্পূর্ণ application list নয়। Corporate network-এ আরও অনেক application পাওয়া যেতে পারে।

অনেক সময় শুধু Default Password এবং Built-in Functionality-ই compromise করার জন্য যথেষ্ট।
