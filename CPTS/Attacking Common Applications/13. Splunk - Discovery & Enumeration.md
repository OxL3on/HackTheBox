## 1. Splunk কী?

Splunk হলো একটি Log Analytics Tool, যা data সংগ্রহ, analyze এবং visualize করতে ব্যবহৃত হয়।

- মূলত SIEM tool হিসেবে তৈরি হয়নি।
- Security monitoring এবং business analytics-এ ব্যবহার হয়।
- Splunk-এ sensitive data থাকতে পারে। তাই compromised হলে attacker অনেক information পেতে পারে।

Splunk-এর পরিচিত vulnerability খুব বেশি নেই। উল্লেখযোগ্য:

- `CVE-2018-11409` — Information disclosure vulnerability।
- `CVE-2011-4642` — অনেক পুরোনো version-এ authenticated Remote Code Execution (RCE) vulnerability।

### Pentesting-এ Splunk কেন গুরুত্বপূর্ণ?

- Internal network এবং বড় corporate environment-এ Splunk প্রায়ই পাওয়া যায়।
- External network-এ exposed থাকাও সম্ভব, তবে কম দেখা যায়।
- Splunk দ্রুত vulnerability patch করে।
- সবচেয়ে গুরুত্বপূর্ণ বিষয় হলো Weak বা Null Authentication।

Splunk-এর admin access পেলে custom application deploy করা যায়। এগুলোর মাধ্যমে:

- Splunk server compromise করা সম্ভব।
- Splunk-এর configuration অনুযায়ী network-এর অন্য host-ও compromise হতে পারে।

## 2. Discovery / Footprinting

Splunk সাধারণত:

- Linux-এ `root` হিসেবে চলে।
- Windows-এ `SYSTEM` হিসেবে চলে।
- Internal network-এ বেশি পাওয়া যায়।
- কখনো external network-এও exposed থাকতে পারে।

Scenario: Aquatone report-এ একটি পুরোনো Splunk instance পাওয়া গেল, যেটি পরে automatically Free version-এ convert হয়েছে। Free version-এ authentication প্রয়োজন হয় না।

আমাদের internal network-এ এখনো foothold নেই। তাই Splunk access ব্যবহার করে RCE পাওয়া যায় কি না পরীক্ষা করব।

### Splunk থেকে RCE

Splunk-এ code চালানোর একাধিক উপায় রয়েছে:

- Server-side Django applications
- REST endpoints
- Scripted inputs
- Alerting scripts

Scripted Input হলো Splunk server-এ RCE পাওয়ার একটি common method।

এগুলো ব্যবহার করা হয় custom method প্রয়োজন এমন data source-এর সাথে Splunk integrate করতে, যেমন:

- APIs
- File servers

Scripted inputs-এর কাজ:

1. Custom script execute করে।
2. Script-এর `STDOUT` output Splunk-এর input হিসেবে ব্যবহার করে।

### Supported Scripts

Splunk Windows এবং Linux উভয় system-এ install করা যায়।

তাই scripted input দিয়ে চালানো যায়:

- Bash scripts
- PowerShell scripts
- Batch scripts

প্রতিটি Splunk installation-এর সাথে Python installed থাকে। তাই যেকোনো Splunk system-এ Python script চালানো সম্ভব।

RCE পাওয়ার সহজ উপায়:

একটি scripted input তৈরি করে Splunk-কে Python reverse shell script চালানোর নির্দেশ দেওয়া।

এটি পরবর্তী section-এ আলোচনা করা হবে।

### Public Vulnerabilities

Splunk-এর built-in functionality ছাড়াও বিভিন্ন public vulnerability পাওয়া গেছে।

Example:

- [SSRF - Exploit DB 40895](https://www.exploit-db.com/exploits/40895?utm_source=chatgpt.com) — Splunk REST API-তে unauthorized access পেতে ব্যবহার করা যেত।
- [Splunk CVEs](https://www.cvedetails.com/vulnerability-list/vendor_id-10963/Splunk.html?utm_source=chatgpt.com) — লেখার সময় মোট `47`টি CVE ছিল।

Pentest-এর সময় Splunk vulnerability scan করলে অনেক non-exploitable vulnerability পাওয়া যেতে পারে।

মূল বিষয়: শুধু known vulnerability খোঁজার পরিবর্তে Splunk-এর built-in functionality কীভাবে abuse করা যায়, সেটি বোঝা গুরুত্বপূর্ণ।
