## 1. Jenkins কী?

Jenkins হলো Java দিয়ে তৈরি একটি open-source automation server। এটি developers-দের software project build ও test স্বয়ংক্রিয়ভাবে করতে সাহায্য করে।

- এটি একটি server-based system।
- Tomcat-এর মতো servlet container-এ চলে।
- এটি একটি Continuous Integration (CI) server।
- Jenkins-এ এমন vulnerability পাওয়া গেছে, যেগুলোর মাধ্যমে authentication ছাড়াই Remote Code Execution (RCE) সম্ভব।

### গুরুত্বপূর্ণ তথ্য

- Jenkins-এর আগের নাম ছিল Hudson।
- 2005 সালে Hudson release হয়।
- Oracle-এর সঙ্গে dispute-এর কারণে 2011 সালে নাম পরিবর্তন করে Jenkins রাখা হয়।
- [HG Data](https://discovery.hgdata.com/product/jenkins?utm_source=chatgpt.com) অনুযায়ী 86,000-এর বেশি company Jenkins ব্যবহার করে।
- Facebook, Netflix, Udemy, Robinhood ও LinkedIn Jenkins ব্যবহার করে।
- Project build ও test করার জন্য 300-এর বেশি plugin রয়েছে।

## 2. Discovery / Footprinting

ধরি, আমরা একটি internal penetration test করছি এবং web discovery scan শেষ করেছি। সেখানে একটি Jenkins instance পেয়েছি।

Jenkins অনেক সময় Windows server-এ install করা থাকে এবং SYSTEM account দিয়ে চলে।

যদি Jenkins access করে SYSTEM account হিসেবে RCE পেতে পারি, তাহলে Active Directory environment-এ foothold তৈরি করে domain enumeration শুরু করতে পারব।

### Default Ports

| Port   | কাজ                                                                                    |
| ------ | -------------------------------------------------------------------------------------- |
| `8080` | Jenkins সাধারণত Tomcat-এর এই default port-এ চলে।                                       |
| `5000` | Master ও slave server-এর মধ্যে communication এবং slave server attach করতে ব্যবহৃত হয়। |

### Jenkins Authentication Options

Jenkins বিভিন্ন authentication method ব্যবহার করতে পারে:

- Jenkins-এর local database
- LDAP
- Unix user database
- Servlet container-এর কাছে security delegate করা
- কোনো authentication ছাড়াই চালানো

Administrator চাইলে user-দের account তৈরি করার permission দিতে বা বন্ধ করতে পারে।

## 3. Enumeration

### Configure Global Security

URL:

[http://jenkins.inlanefreight.local:8000/configureSecurity/](http://jenkins.inlanefreight.local:8000/configureSecurity/?utm_source=chatgpt.com)

এই page থেকে Jenkins-এর authentication ও security configuration দেখা যায়।

উদাহরণে দেখা যাচ্ছে:

- Security Realm: Jenkins' own user database
- Authorization: Logged-in users can do anything

### Jenkins Login Page

Default installation সাধারণত Jenkins-এর নিজস্ব database-এ credentials store করে এবং user-দের নিজে থেকে account register করতে দেয় না।

Jenkins-এর login page দেখেও দ্রুত fingerprint করা যায়।

URL:

[http://jenkins.inlanefreight.local:8000/login?from=%2F](http://jenkins.inlanefreight.local:8000/login?from=%2F\&utm_source=chatgpt.com)

### Default / Weak Credentials

Jenkins instance-এ দুর্বল বা default credentials থাকতে পারে।

উদাহরণ:

```
admin:admin
```

কিছু instance-এ কোনো authentication-ই enable করা থাকে না।

Internal penetration testing-এ authentication ছাড়া Jenkins পাওয়া অস্বাভাবিক নয়। External penetration test-এও এমন Jenkins instance পাওয়া গেছে, যেগুলো attack করা সম্ভব হয়েছে।

| Old name            | Hudson                                                            |
| Released            | 2005                                                              |

| Default port        | `8080`                                                            |
| Slave communication | `5000`                                                            |
| Authentication      | Local DB, LDAP, Unix DB, Servlet container বা None                |
