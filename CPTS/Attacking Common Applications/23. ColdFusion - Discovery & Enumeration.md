# ColdFusion – Discovery & Enumeration

## 1. ColdFusion কী?

- ColdFusion হলো Java-ভিত্তিক programming language ও web application development platform।
- 1995 সালে Allaire Corporation এটি তৈরি করে। 2001 সালে Macromedia এটি কিনে নেয়। পরে Adobe, Macromedia-কে অধিগ্রহণ করে।
- Dynamic ও interactive web application তৈরি করতে ব্যবহৃত হয়।
- MySQL, Oracle ও Microsoft SQL Server-এর মতো database এবং বিভিন্ন API-এর সঙ্গে কাজ করতে পারে।

### CFML (ColdFusion Markup Language)

- CFML হলো ColdFusion-এর নিজস্ব programming language।
- এর syntax HTML-এর মতো এবং এটি tag-based।
- Database, web services, email management ইত্যাদি কাজে ব্যবহার হয়।

Database query চালাতে `cfquery`:

```
<cfquery name="myQuery" datasource="myDataSource">
  SELECT *
  FROM myTable
</cfquery>
```

Database থেকে পাওয়া record দেখাতে `cfloop`:

```
<cfloop query="myQuery">
  <p>#myQuery.firstName# #myQuery.lastName#</p>
</cfloop>
```

- JavaScript ও Java-ও ColdFusion environment-এ ব্যবহার করা যায়।
- Email, PDF manipulation, graphing ইত্যাদি built-in feature রয়েছে।
- Windows, Mac, Linux এবং AWS ও Azure-এর মতো cloud platform-এ ব্যবহার করা যায়।

## 2. ColdFusion-এর সুবিধা

| সুবিধা                       | কাজ                                                        |
| ---------------------------- | ---------------------------------------------------------- |
| Data-driven web applications | Dynamic ও responsive web application তৈরি                  |
| Database integration         | Oracle, SQL Server, MySQL থেকে data retrieve ও modify      |
| Web content management       | HTML generation, form, URL rewriting, file upload ও AJAX   |
| Performance                  | Low latency ও high throughput; একসঙ্গে অনেক request handle |
| Collaboration                | Code sharing, debugging ও version control                  |

## 3. Version ও Vulnerabilities

- ColdFusion কম জনপ্রিয় হলেও বিভিন্ন organization এখনো ব্যবহার করে।
- Source অনুযায়ী লেখার সময় সর্বশেষ stable version ছিল ColdFusion 2021 এবং ColdFusion 2023 Alpha-তে যাওয়ার কথা ছিল।
- পুরোনো version: ColdFusion 2018, 2016 ও 11।

ColdFusion-এর পরিচিত vulnerability:

| CVE                                                                                      | Vulnerability                                   |
| ---------------------------------------------------------------------------------------- | ----------------------------------------------- |
| [CVE-2013-0632](https://nvd.nist.gov/vuln/detail/CVE-2013-0632?utm_source=chatgpt.com)   | Remote Code Execution                           |
| [CVE-2013-0629](https://nvd.nist.gov/vuln/detail/CVE-2013-0629?utm_source=chatgpt.com)   | Directory Traversal ও sensitive file disclosure |
| [CVE-2010-2861](https://nvd.nist.gov/vuln/detail/CVE-2010-2861?utm_source=chatgpt.com)   | Directory Traversal ও arbitrary file reading    |
| [CVE-2018-15961](https://nvd.nist.gov/vuln/detail/CVE-2018-15961?utm_source=chatgpt.com) | Arbitrary file upload থেকে RCE                  |
| [CVE-2023-26360](https://nvd.nist.gov/vuln/detail/CVE-2023-26360?utm_source=chatgpt.com) | Pre-authentication RCE                          |

অন্যান্য সম্ভাব্য attack: SQLi, XSS, directory traversal, authentication bypass ও arbitrary file upload।

## 4. Default Ports

| Port | Protocol       | Description                     |
| ---- | -------------- | ------------------------------- |
| 80   | HTTP           | সাধারণ HTTP communication       |
| 443  | HTTPS          | Encrypted HTTP communication    |
| 1935 | RPC            | Client-server communication     |
| 25   | SMTP           | Email পাঠানো                    |
| 8500 | SSL            | ColdFusion server communication |
| 5500 | Server Monitor | Remote server administration    |

Note: Installation বা configuration-এর সময় default port পরিবর্তন করা যায়।

## 5. Enumeration

ColdFusion শনাক্ত করার কয়েকটি উপায়:

| Method          | কী খুঁজবে                                        |
| --------------- | ------------------------------------------------ |
| Port Scanning   | Port 80, 443 এবং ColdFusion-এর default port      |
| File Extensions | `.cfm` ও `.cfc`                                  |
| HTTP Headers    | `Server: ColdFusion`, `X-Powered-By: ColdFusion` |
| Error Messages  | ColdFusion-specific tags বা functions            |
| Default Files   | `admin.cfm`, `CFIDE/administrator/index.cfm`     |

### Nmap Scan

```
nmap -p- -sC -Pn 10.129.247.30 --open
```

Output:

```
Starting Nmap 7.92 ( https://nmap.org ) at 2023-03-13 11:45 GMT
Nmap scan report for 10.129.247.30
Host is up (0.028s latency).
Not shown: 65532 filtered tcp ports (no-response)
Some closed ports may be reported as filtered due to --defeat-rst-ratelimit
PORT      STATE SERVICE
135/tcp   open  msrpc
8500/tcp  open  fmtp
49154/tcp open  unknown

Nmap done: 1 IP address (1 host up) scanned in 350.38 seconds
```

- মোট ৩টি open port পাওয়া গেছে।
- `135` ও `49154` Windows RPC-related service হিসেবে দেখানো হয়েছে।
- `8500` ColdFusion-এর default SSL port।
- Browser-এ `IP:8500` খুললে `CFIDE` ও `cfdocs` directory পাওয়া যায়।

এরপর directory-তে আরও তথ্য পাওয়া যায়:

- `.cfm` extension-এর file
- Error messages
- Login pages

গুরুত্বপূর্ণ paths:

- `/CFIDE/` — এখানে `Application.cfm`, `adminapi/`, `install.cfm` ইত্যাদি পাওয়া যায়।
- `/CFIDE/administrator` — ColdFusion Administrator login page।

`/CFIDE/administrator` খুললে ColdFusion 8 Administrator login page পাওয়া যায়। তাই নিশ্চিত হওয়া যায় যে server-এ ColdFusion 8 চলছে।
