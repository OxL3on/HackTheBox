## 1. Drupal পরিচিতি

[Drupal](https://www.drupal.org/?utm_source=chatgpt.com) হলো open-source CMS, 2001 সালে চালু হয়। এটি PHP-তে লেখা এবং backend হিসেবে MySQL বা PostgreSQL ব্যবহার করে। DBMS না থাকলে SQLite ব্যবহার করা যায়। Themes ও modules দিয়ে website customize করা যায়।

- প্রায় 43,000 modules ও 2,900 themes।
- [Drupal Statistics](https://websitebuilder.org/blog/drupal-statistics/?utm_source=chatgpt.com):
  - Internet-এর প্রায় 1.5% website (1.1 million-এর বেশি), top 1 million-এর 5% এবং top 10,000-এর 7% Drupal ব্যবহার করে।
  - CMS market share প্রায় 2.4%।
  - 100টি language সমর্থন করে।
  - Community-তে 1.3 million-এর বেশি সদস্য।
  - Drupal 8 তৈরি করেছেন 3,290 contributors ও 1,288 companies, community-এর সহায়তায়।
  - Fortune 500-এর 33টি company Drupal ব্যবহার করে।
  - বিশ্বজুড়ে 56% government website Drupal ব্যবহার করে।
  - 23.8% university, college ও school Drupal ব্যবহার করে।
  - উদাহরণ: Tesla ও Warner Bros Records।

[Drupal usage statistics](https://www.drupal.org/project/usage/drupal?utm_source=chatgpt.com) অনুযায়ী, 5.x থেকে 9.3.x পর্যন্ত version মিলিয়ে 5 September 2021-এ প্রায় 950,000 Drupal instance ব্যবহৃত হচ্ছিল।

June 2013 থেকে September 2021 পর্যন্ত ব্যবহার প্রায় 900,000–1.1 million-এর মধ্যে ছিল। এই statistics সব Drupal instance অন্তর্ভুক্ত করে না; শুধু [Update Status module](https://www.drupal.org/project/update_status?utm_source=chatgpt.com) ব্যবহার করে এমন instance গণনা করে, যা নতুন Drupal version ও module update-এর জন্য প্রতিদিন drupal.org-এর সঙ্গে যোগাযোগ করে।

## 2. Discovery / Footprinting

WordPress বা Joomla নয় এমন CMS পেলে Drupal শনাক্ত করার জন্য নিচের clues পরীক্ষা করা যায়:

- Header/footer-এ `Powered by Drupal`
- Drupal logo
- `CHANGELOG.txt` বা `README.txt`
- Page source
- `robots.txt`-এ `/node` reference

### Drupal শনাক্ত করা

```
curl -s http://drupal.inlanefreight.local | grep Drupal
```

Output:

```
<meta name="Generator" content="Drupal 8 (https://www.drupal.org)" />
      <span>Powered by <a href="https://www.drupal.org">Drupal</a></span>
```

### Node

Drupal content-কে node হিসেবে index করে। একটি node-এ blog post, poll, article ইত্যাদি থাকতে পারে। সাধারণ URI format:

`/node/<nodeid>`

উদাহরণ: [http://drupal.inlanefreight.local/node/1](http://drupal.inlanefreight.local/node/1?utm_source=chatgpt.com)

[ITF Seafarers - Port of call online for maritime workers | Drupal.org](https://images.openai.com/static-rsc-4/HgtWbh2emVfrtTieOJYZOKW1IxS017OQQWVksF7LRkdvSqnPPdyCRcikKL9QU7-ACowrMqZMNaye49O6fawKfcHe86e0c6a9pGogX5-T0GmXy3K-z21jfu8ZB5yuAGipYNz2A7Y5AvG8DeM2FcauSuWTJm_JoTgr1XCpybFgjBs?purpose=inline)

[drupal.org](https://www.drupal.org/case-study/itf-seafarers-port-of-call-online-for-maritime-workers?utm_source=chatgpt.com)

এখানে blog post-এর URL `/node/1`। Custom theme থাকলেও এই pattern Drupal শনাক্ত করতে সাহায্য করে।

Note: সব Drupal installation একই রকম নয়। Login page দেখা নাও যেতে পারে বা internet থেকে login page access বন্ধ থাকতে পারে।

### Drupal-এর default user types

1. Administrator: পুরো Drupal website নিয়ন্ত্রণ করতে পারে।
2. Authenticated User: Login করে নিজের permission অনুযায়ী article add/edit করতে পারে।
3. Anonymous: সব visitor এই category-তে পড়ে; default ভাবে শুধু post পড়তে পারে।

## 3. Enumeration

Drupal শনাক্ত করার পর manual ও automated enumeration দিয়ে version, installed plugins এবং অন্যান্য তথ্য খুঁজতে হবে।

Version শনাক্ত করার পদ্ধতি Drupal version ও security hardening-এর ওপর নির্ভর করে। নতুন installation-এ `CHANGELOG.txt` ও `README.txt` access block থাকতে পারে।

### 3.1 CHANGELOG.txt দিয়ে version শনাক্ত

```
curl -s http://drupal-acc.inlanefreight.local/CHANGELOG.txt | grep -m2 ""
```

Output:

```
Drupal 7.57, 2018-02-21
```

এখানে Drupal version `7.57` পাওয়া গেছে।

Latest version-এর ক্ষেত্রে একই file access করলে `404` আসতে পারে:

```
curl -s http://drupal.inlanefreight.local/CHANGELOG.txt
```

Output:

```
<!DOCTYPE html><html><head><title>404 Not Found</title></head><body><h1>Not Found</h1><p>The requested URL "http://drupal.inlanefreight.local/CHANGELOG.txt" was not found on this server.</p></body></html>
```

### 3.2 droopescan দিয়ে scan

[droopescan](https://github.com/droope/droopescan?utm_source=chatgpt.com) Joomla-এর তুলনায় Drupal-এর জন্য বেশি functionality দেয়।

```
droopescan scan drupal -u http://drupal.inlanefreight.local
```

Output:

```
[+] Plugins found:
    php http://drupal.inlanefreight.local/modules/php/
        http://drupal.inlanefreight.local/modules/php/LICENSE.txt

[+] No themes found.

[+] Possible version(s):
    8.9.0
    8.9.1

[+] Possible interesting urls found:
    Default admin - http://drupal.inlanefreight.local/user/login

[+] Scan finished (0:03:19.199526 elapsed)
```

এখানে সম্ভাব্য version `8.9.0` ও `8.9.1`; অর্থাৎ target সম্ভবত Drupal `8.9.1` ব্যবহার করছে।

এই version June 2020-এ release হয়েছিল এবং লেখার সময় latest ছিল না। [Drupal vulnerabilities](https://www.cvedetails.com/vulnerability-list/vendor_id-1367/product_id-2387/Drupal-Drupal.html?utm_source=chatgpt.com) দ্রুত পরীক্ষা করে এই core version-এর জন্য স্পষ্ট vulnerability পাওয়া যায়নি।

পরবর্তী ধাপ: installed plugins পরীক্ষা করা অথবা built-in functionality কাজে লাগানোর সম্ভাবনা খোঁজা।
