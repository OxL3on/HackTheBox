# Search Engine Discovery - [LINK](https://academy.hackthebox.com/app/module/144/section/3080)


**Search Engine Discovery (OSINT)**
Search engine discovery uses advanced queries to extract publicly indexed data not readily visible on standard web pages. It is foundational for passive reconnaissance because it is publicly accessible, completely free, and leaves no direct footprints on the target's servers.

* **Security Assessments:** Uncover vulnerable servers, exposed login portals, open databases, and misconfigured security settings.
* **Competitive & Investigative Intelligence:** Map competitor infrastructures, uncover hidden internal documents, or track threat actor footprints.

**Search Operators Reference**
Operators act as filters to precision-target specific files, domains, or metadata.

| Operator | Function | Example |
| --- | --- | --- |
| `site:` | Restricts results to a specific domain or TLD. | `site:example.com` |
| `inurl:` | Finds pages with a specific term in the URL structure. | `inurl:login` |
| `filetype:` / `ext:` | Searches for specific file extensions (PDF, SQL, DOCX). | `filetype:pdf` |
| `intitle:` | Finds pages with specific terms in the HTML `<title>`. | `intitle:"confidential report"` |
| `intext:` / `inbody:` | Searches for exact terms within the body text of a page. | `intext:"password reset"` |
| `cache:` | Displays the last cached version of a webpage. | `cache:example.com` |
| `link:` | Finds pages that link to a specific URL. | `link:example.com` |
| `related:` | Discovers websites with similar content to the target. | `related:example.com` |
| `numrange:` / `..` | Searches for numbers within a specific range. | `site:example.com 1000..2000` |
| `AND` / `OR` | Logical operators to combine or broaden search requirements. | `inurl:admin OR inurl:login` |
| `-` (Minus) | Excludes specific terms from the search results. | `site:example.com -inurl:login` |
| `*` (Wildcard) | Acts as a placeholder for any character or word. | `user * manual` |
| `" "` (Quotes) | Forces an exact phrase match. | `"information security policy"` |
| `allinurl:` / `allintitle:` | Requires *all* specified words to be in the URL/Title. | `allinurl:admin panel` |

**Google Dorking (Google Hacking)**
Google Dorking strings multiple search operators together to discover security vulnerabilities and exposed data indexed by Google. The **Google Hacking Database (GHDB)** (maintained by Exploit-DB) catalogs thousands of these pre-built queries for penetration testers.

* **Finding Login Pages:** `site:example.com (inurl:login OR inurl:admin)`
* **Identifying Exposed Documents:** `site:example.com (filetype:pdf OR filetype:xlsx) "internal use only"`
* **Uncovering Configuration Files:** `site:example.com (ext:conf OR ext:cnf OR ext:env)`
* **Locating Database Backups:** `site:example.com inurl:backup filetype:sql`
