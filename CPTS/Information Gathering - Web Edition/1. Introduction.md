Web reconnaissance is the preparatory information-gathering phase of penetration testing used to systematically map a target's online footprint before exploitation.
<img width="2058" height="747" alt="image" src="https://github.com/user-attachments/assets/bcc5bdaf-abd0-4cdf-bb87-bb07295e9bb6" />


**Core Objectives**

* **Identify Assets:** Map public web pages, subdomains, technologies, and IP addresses.
* **Discover Hidden Data:** Uncover exposed backups, internal documentation, and configuration files.
* **Analyze Attack Surface:** Locate vulnerabilities, misconfigurations, and potential entry points.
* **Gather Intelligence:** Collect employee details, emails, and behavioral patterns for targeted social engineering.

**Methodology Comparison**

| Feature | Active Reconnaissance | Passive Reconnaissance |
| --- | --- | --- |
| **Mechanism** | Direct interaction with the target's infrastructure. | Gathering information from third-party, public resources. |
| **Detection Risk** | Medium to High (can trigger firewalls and IDS). | Very Low (blends in with standard internet traffic). |
| **Techniques** | Port/Vulnerability scanning, network mapping, banner grabbing, OS fingerprinting, web spidering. | Search engines, WHOIS lookups, DNS analysis, web archives, social media OSINT, code repo searches. |
| **Key Tools** | Nmap, Nessus, Traceroute, Netcat, Burp Suite, Nikto. | Google/Shodan, WHOIS, `dig`, Wayback Machine, GitHub, LinkedIn. |
