# Subdomain Bruteforcing - [LINK](https://academy.hackthebox.com/app/module/144/section/1253)



Subdomain Brute-Force Enumeration is an **active** discovery technique that systematically appends words from a pre-defined list to a target domain and queries the DNS server to see if they resolve to an IP address.

## 1. The Brute-Forcing Methodology

1. **Wordlist Selection:** The foundation of a good brute-force attack.
* *General-Purpose:* Broad lists of common names (`dev`, `admin`, `staging`). (e.g., SecLists).
* *Targeted:* Custom lists based on the target's industry or naming conventions.


2. **Iteration & Querying:** A tool systematically appends the wordlist items to the root domain (e.g., `word + .example.com`).
3. **DNS Lookup:** The tool asks the DNS resolver for the **A or AAAA records** of the newly formed subdomain.
4. **Filtering & Validation:** If an IP is returned, the subdomain exists and is logged for further vulnerability testing.

| Tool | Key Features / Best For |

| **puredns** | Highly powerful brute-forcer that excels at mass-resolving and filtering out wildcard false positives. |

## 3. Deep Dive: `dnsenum`

`dnsenum` goes beyond simple brute-forcing. It automatically attempts zone transfers, queries multiple record types (A, NS, MX, TXT), scrapes Google, and performs reverse WHOIS/DNS lookups.

**The Standard Command:**

```bash
dnsenum --enum inlanefreight.com -f /usr/share/seclists/Discovery/DNS/subdomains-top1million-20000.txt -r

```

**Command Breakdown:**

* `--enum`: A shortcut flag that applies standard tuning options for a comprehensive scan.
* `-f`: Specifies the path to your wordlist file (in this case, the top 20,000 subdomains list from SecLists).
* `-r`: Enables **recursive** brute-forcing. (If it discovers `dev.target.com`, it will then brute-force *against* `dev.target.com` to find things like `api.dev.target.com`).

*Pro-Tip: Always ensure your wordlist matches the scale of your engagement. Using a 10-million word list against a small target is usually a waste of time and highly noisy. Stick to top-10k or top-20k lists for initial passes.*
