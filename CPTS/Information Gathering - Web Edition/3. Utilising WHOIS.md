WHOIS data is a critical first step in reconnaissance, used to map infrastructure, build threat intelligence, and investigate malicious activity.

## WHOIS Application Scenarios

When analyzing domains during an investigation, WHOIS data provides immediate context to determine if a domain is legitimate or malicious.

| Use Case | Key WHOIS Indicators & Red Flags |
| --- | --- |
| **Phishing Investigations** | Domains with very recent creation dates, hidden registrants (privacy protection), and name servers tied to known "bulletproof" hosting. |
| **Malware/C2 Analysis** | Domains registered via anonymous free email providers, addresses in high-cybercrime regions, or registrars with notoriously lax abuse policies. |
| **Threat Intelligence** | Identifying patterns to build IOCs (Indicators of Compromise), such as domains registered in clusters just prior to attacks, shared name servers, or reused aliases. |

## Installing and Running WHOIS

If the tool is not native to your Linux environment, install it via the package manager:

```bash
sudo apt update && sudo apt install whois -y

```

Run a standard query against your target domain:

```bash
whois facebook.com

```

## Analyzing the Output

When reading a WHOIS record, prioritize these specific fields to profile the target:

* **Creation & Expiry Dates:** Establishes legitimacy. A domain registered in 1997 and expiring in 2033 is established and trustworthy. A domain registered three days ago is an immediate red flag.
* **Registrant Organization:** Identifies the true corporate owner (e.g., *Meta Platforms, Inc.*). If obscured, it will list a privacy protection service.
* **Domain Status:** Look for EPP status codes like `clientTransferProhibited`, `clientUpdateProhibited`, or `serverDeleteProhibited`. These indicate the domain is heavily locked down against unauthorized hijacking or DNS changes.
* **Name Servers:** Reveals DNS infrastructure. Large corporations often manage their own in-house name servers (e.g., `A.NS.FACEBOOK.COM`), whereas smaller targets or threat actors will point to third-party hosting providers.

**Crucial Limitation:** While WHOIS provides high-level organizational and administrative contacts, it rarely exposes specific lower-level employees or direct technical vulnerabilities. It is meant to be the foundation of your reconnaissance, which must be combined with active scanning and other OSINT techniques.
