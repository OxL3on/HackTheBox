# Automating Recon - [LINK](https://academy.hackthebox.com/app/module/144/section/3081)


Automating web reconnaissance allows you to scale data collection, maintain consistency, and execute multiple enumeration tasks simultaneously without human error. Frameworks bundle disparate tools into a single workflow, bridging the gap between passive OSINT gathering and active vulnerability scanning.

**Advantages of Automation**

* **Efficiency:** Rapidly processes repetitive, time-consuming tasks (like brute-forcing or crawling).
* **Scalability:** Effortlessly scans vast numbers of targets, domains, or IP ranges.
* **Consistency:** Removes human error by strictly following predefined algorithms.
* **Integration:** Outputs structured results (like JSON/CSV) directly into exploitation or vulnerability assessment pipelines.

## Deep Dive: FinalRecon

FinalRecon is a modular, Python-based script designed to provide a comprehensive overview of a target in a short amount of time.

**Core Modules & Capabilities:**

* **Headers & SSL:** Identifies backend servers, frameworks, security misconfigurations, and certificate validity.
* **Whois:** Extracts domain registration, expiry details, and contact information.
* **DNS & Subdomains:** Queries 40+ DNS records (including DMARC) and pulls subdomains from 15+ external APIs (e.g., crt.sh, VirusTotal, Shodan, BeVigil).
* **Crawling & Wayback:** Maps internal/external links, hidden JavaScript paths, and retrieves up to 5 years of historical URLs from the Wayback Machine.
* **Directory Enum:** Uses wordlists to uncover hidden directories, supporting custom file extensions and threading.

**Installation**

```bash
git clone https://github.com/thewhiteh4t/FinalRecon.git
cd FinalRecon
pip3 install -r requirements.txt
chmod +x ./finalrecon.py

```

**Essential Commands & Flags**
FinalRecon operates using strict flags to toggle specific modules on or off.

| Flag | Function | Extra / Tuning Flags |
| --- | --- | --- |
| `--headers` | Retrieve HTTP server headers. | `-nb` (Hide ASCII banner) |
| `--whois` | Fetch domain registration data. | `-T [sec]` (Request timeout, default 30s) |
| `--sslinfo` | Extract SSL/TLS cert data. | `-s` (Toggle SSL verification) |
| `--crawl` | Spider the target website. | `-r` (Allow HTTP redirects) |
| `--sub` | Enumerate subdomains via APIs. | `-k [key]` (Add API keys for Shodan, etc.) |
| `--dir` | Directory brute-force. | `-w [path]` (Custom wordlist), `-dt [num]` (Threads) |
| `--wayback` | Fetch historical URLs. | `-e [ext]` (File extensions like txt, php) |
| `--full` | Run every available module. | `-o [fmt]` (Export format, default txt) |

**Example: Running a Targeted Scan**
To fetch headers and Whois data for a target, skipping the ASCII banner, and outputting to the default export directory (`~/.local/share/finalrecon`):

```bash
./finalrecon.py --headers --whois --url http://inlanefreight.com -nb

```
