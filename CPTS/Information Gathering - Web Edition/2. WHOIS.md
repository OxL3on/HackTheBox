**WHOIS: The Internet Phonebook**

WHOIS is a query and response protocol used to query databases that store the registered users or assignees of internet resources, primarily domain names and IP address blocks.

**Anatomy of a WHOIS Record**

* **Registrar:** The company that sold the domain (e.g., GoDaddy, Amazon).
* **Contacts:** Details (often names, emails, and phone numbers) for the **Registrant** (Owner), **Administrative** (Manager), and **Technical** leads.
* **Dates:** Creation, Last Updated, and Expiration dates.
* **Name Servers:** Servers responsible for translating the domain name into an IP address.

**Strategic Value for Web Reconnaissance**

* **Social Engineering & Phishing:** Exposed contact information (emails, phone numbers, names) provides direct targets for social engineering campaigns.
* **Infrastructure Mapping:** Name servers and IP data reveal the target's underlying network setup, hosting providers, and potential entry points.
* **Historical Tracking:** Using tools like *WhoisFreaks* to view historical WHOIS data can expose past infrastructure setups, forgotten subdomains, or previous owners.

*Memory Hook: Created in the 1970s by Elizabeth Feinler for ARPANET, WHOIS is the first place you look to find out who owns a target and how their network is publicly routed.*
