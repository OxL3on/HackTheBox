**WHOIS: The Internet Phonebook**


WWHOIS is a query and response protocol used to access databases storing information about registered internet resources, such as domain names and IP address blocks. It acts as the internet's public phonebook, allowing you to identify who owns or manages specific online assets.

**Executing a WHOIS Query**

```bash
whois inlanefreight.com

```

**Anatomy of a WHOIS Record**

| Field | Description |
| --- | --- |
| **Domain Name** | The specific domain being queried (e.g., example.com). |
| **Registrar** | The company where the domain is registered (e.g., Amazon, GoDaddy). |
| **Registrant Contact** | The individual or organization that officially owns the domain. |
| **Administrative Contact** | The person responsible for the day-to-day management of the domain. |
| **Technical Contact** | The person handling technical issues and infrastructure. |
| **Dates** | Creation, Last Updated, and Expiration dates. |
| **Name Servers** | The servers responsible for translating the domain name into its IP address. |

**Importance in Web Reconnaissance (OSINT)**

* **Identifying Key Personnel:** Exposes names, emails, and phone numbers of administrators, providing direct targets for social engineering or phishing campaigns.
* **Mapping Infrastructure:** Name servers and IP details offer baseline clues about the target's network setup, hosting providers, and potential entry points.
* **Historical Analysis:** Tracking past records via third-party tools (like *WhoisFreaks*) reveals how the target's infrastructure, ownership, and technical contacts have evolved over time.

**Historical Origin**
WHOIS was created in the 1970s for the ARPANET (the precursor to the internet) by Elizabeth Feinler and her team at the Stanford Research Institute's Network Information Center (NIC) to track the growing number of network users and hostnames.
