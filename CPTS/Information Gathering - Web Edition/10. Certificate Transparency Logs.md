# Certificate Transparency Logs - [LINK](https://academy.hackthebox.com/app/module/144/section/1258)


Certificate Transparency (CT) logs are public, append-only ledgers that record every issued SSL/TLS certificate, acting as a global registry to verify website identities and secure the Web PKI.

## 1. The Purpose of CT Logs

* **Early Detection of Rogue Certificates:** Allows researchers and domain owners to spot unauthorized, mis-issued, or fraudulent certificates immediately, enabling swift revocation before they can be weaponized.
* **Certificate Authority (CA) Accountability:** Forces CAs to operate transparently. Any violations of issuance standards are permanently recorded for public audit, deterring bad practices.
* **Strengthening Web PKI:** Enhances the overall Public Key Infrastructure by enforcing public oversight and cryptographic verification.

## 2. Strategic Value for Web Reconnaissance

CT logs provide a distinct advantage over standard subdomain brute-forcing techniques:

* **Definitive Historical Record:** You do not need to guess or brute-force subdomain names. CT logs provide an exhaustive list of all certificates ever issued for a domain and its subdomains.
* **Uncovering Hidden Infrastructure:** Exposes subdomains that are not actively linked, not easily guessable, or tied to expired certificates running outdated, vulnerable software.

| **crt.sh** | Simple web interface and API, searches by domain/SAN entries. | Free, fast, no registration required. | Limited advanced filtering and analysis. |

## 4. Automating crt.sh Lookups via CLI

You can bypass the web interface and extract subdomains directly from the terminal using `curl` and `jq`.

To find all `dev` subdomains for a target (e.g., `facebook.com`):

```bash
curl -s "https://crt.sh/?q=facebook.com&output=json" | jq -r '.[] | select(.name_value | contains("dev")) | .name_value' | sort -u

```

**Command Breakdown:**

* `curl -s "..."`: Fetches the raw JSON output from the crt.sh database.
* `jq -r '.[] | select(.name_value | contains("dev")) | .name_value'`: Parses the JSON, filters for entries where the domain name contains "dev", and outputs the raw string.
* `sort -u`: Sorts the final list alphabetically and removes duplicate entries to provide a clean target list.
