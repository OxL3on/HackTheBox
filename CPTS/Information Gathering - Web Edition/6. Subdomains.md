# Subdomains - [LINK](https://academy.hackthebox.com/app/module/144/section/1252)


**Subdomains & Their Strategic Value**
Subdomains (e.g., `dev.example.com`, `mail.example.com`) are extensions of a primary domain used to separate different functionalities. In DNS, they are typically mapped using **A/AAAA records** (IP addresses) or **CNAME records** (aliases).

They are goldmines during web reconnaissance because they often host unlinked, vulnerable, or forgotten assets:

* **Development & Staging Environments:** Pre-production sites often have relaxed security measures, exposing new features, bugs, or hardcoded credentials.
* **Hidden Login Portals:** Administrative panels or employee gateways not meant for public discovery.
* **Legacy Applications:** Forgotten, outdated web applications running unpatched software.
* **Data Leaks:** Inadvertent exposure of internal documents, source code, or configuration files.

**Active Subdomain Enumeration**
Involves interacting *directly* with the target's DNS infrastructure. It is highly comprehensive but generates noise and is easily detectable by defenders.

* **DNS Zone Transfers:** Attempting to trick a misconfigured DNS server into handing over a complete copy of its zone file (very rare today due to modern security defaults).
* **Brute-Forcing:** Systematically firing a wordlist of common subdomain names against the target's DNS resolver to see which ones resolve to an IP.
* **Common Tools:** `dnsenum`, `ffuf`, `gobuster`.

**Passive Subdomain Enumeration**
Involves discovering subdomains *without* directly querying the target's servers, relying entirely on third-party data. It is completely stealthy but might miss internal or newly created subdomains.

* **Certificate Transparency (CT) Logs:** Public repositories of all issued SSL/TLS certificates. You can parse the **Subject Alternative Name (SAN)** field of a certificate to find all subdomains tied to it.
* **Search Engine Dorking:** Using advanced search operators (e.g., typing `site:example.com -www.example.com` in Google or DuckDuckGo) to force the search engine to reveal indexed subdomains.
* **Third-Party Databases:** Using OSINT aggregators that constantly collect and cache global DNS data.

For a complete reconnaissance strategy, always begin with passive enumeration to gather a stealthy baseline before moving to aggressive, active brute-forcing.
