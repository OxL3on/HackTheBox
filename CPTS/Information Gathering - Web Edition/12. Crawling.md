# Crawling - [LINK](https://academy.hackthebox.com/app/module/144/section/3076)


Web crawling (or spidering) is the automated process of systematically browsing a website to map its structure and collect data. A crawler starts at an initial **seed URL**, parses the page to extract links, adds those links to a queue, and iteratively repeats the process. *Key distinction: Crawling systematically follows visible links, whereas fuzzing blindly guesses hidden paths.*

**Crawling Strategies**

| Strategy | How it Works | Best Used For |
| --- | --- | --- |
| **Breadth-First** | Explores all links on the current level/page before moving deeper. | Gaining a broad, high-level overview of a website's overall structure and content. |
| **Depth-First** | Follows a single link path as far down as possible before backtracking. | Reaching deep into a site's architecture or hunting for highly specific nested content. |

**Key Data Extraction Targets**

Crawlers are configured to harvest specific artifacts that aid in reconnaissance:

* **Links (Internal & External):** Maps the site's architecture, reveals unlinked or hidden directories, and identifies relationships with third-party infrastructure.
* **Sensitive Files:** Actively searches for inadvertently exposed files, such as backups (`.bak`, `.old`), configurations (`web.config`, `settings.php`), and logs (`error_log`). These frequently leak database credentials, API keys, or source code.
* **Comments:** HTML and JavaScript comments often contain developer notes that leak internal workflows, employee names, or specific software versions.
* **Metadata:** Page titles, descriptions, authors, and publish dates provide context on the application's purpose and how frequently it is updated.

**The Power of Contextual Analysis**

Isolated data points are rarely enough to compromise a target; their true value lies in correlation. For example, an HTML comment mentioning a "legacy file server" might seem harmless on its own. However, if your crawler simultaneously maps a link to a `/files/` directory where directory browsing is enabled, correlating those two findings immediately exposes a path to sensitive internal documents. Holistic analysis transforms raw crawled data into actionable attack vectors.
