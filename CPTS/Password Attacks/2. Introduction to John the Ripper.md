## Introduction to John the Ripper

### Single Cracking Mode

- Rule-based cracking technique.

```
john --single password_hash
```

- Uses available information to generate passwords and test them against the hash.

### Wordlist Mode

Crack passwords using a dictionary attack.

```
john --wordlist=file <hashfile>
```

- Multiple wordlists can be specified with commas.

### Incremental Mode

- Brute-force style password cracking mode.
- Generates candidate passwords based on a statistical model (**Markov chains**).
- Designed to test all character combinations from a specific charset, prioritizing more likely passwords based on training data.

```
john --incremental <hash-file>
```

**Predefined config file**

```
john.conf
```

- Defines character sets and password lengths.
- Edit it to add new ones.

### Identifying Hash Formats

### hashID

Use the `-j` flag to get the **JtR** format.

Use the `--format=` argument to tell John which format the target hashes use.

```
john --format=md5
```
