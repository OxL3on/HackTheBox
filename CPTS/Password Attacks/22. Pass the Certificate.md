## 1. Pass-the-Certificate কী?

PKINIT-এর পূর্ণরূপ `Public Key Cryptography for Initial Authentication`। এটি Kerberos-এর extension, যা initial authentication-এ public-key cryptography ব্যবহার করে। Smart card-এর private key দিয়ে user logon-এ এটি ব্যবহৃত হয়।

Pass-the-Certificate: X.509 certificate ব্যবহার করে Kerberos-এর `TGT (Ticket Granting Ticket)` নেওয়ার কৌশল। এটি মূলত `AD CS` attack ও `Shadow Credential` attack-এ ব্যবহৃত হয়।

- [PKINIT — Microsoft Documentation](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-pkca/d0cf1763-3541-4008-a75f-a577fa5e8c5b?utm_source=chatgpt.com)
- [AD CS Attacks — HTB Academy](https://academy.hackthebox.com/module/details/236?utm_source=chatgpt.com)
- [Certified Pre-Owned — PDF](https://www.specterops.io/assets/resources/Certified_Pre-Owned.pdf?utm_source=chatgpt.com)

## 2. AD CS NTLM Relay Attack (ESC8)

ESC8 হলো AD CS-এর HTTP endpoint-এ NTLM relay attack। AD CS-এ একাধিক certificate enrollment পদ্ধতি আছে। Web Enrollment সাধারণত HTTP ব্যবহার করে এবং `/CertSrv` endpoint-এ পাওয়া যায়।

[AD CS NTLM Relay Attack from Linux · phish](https://images.openai.com/static-rsc-4/WbFKr4yuXg9Rf3YC3jNunaGEu_vNKg-FAmYIqSJtLVdO56Pw7oxbHaTYlzgMR__3CEeIN_QWv7nz8e9iiWxdJ6ifycBCtfW1J_4_WudODTJumotuJLqcZcHxQomflZKaIxn-gcQZ7xO0ZfhO114KIUjFnZeoR--_h3YpMdJgdbo?purpose=inline)

[dunderhay.github.io](https://dunderhay.github.io/posts/ad/attacking-adcs-esc8/?utm_source=chatgpt.com)

এখানে certificate request করা, pending request দেখা, certificate chain বা CRL download করা যায়।

### ধাপ ১: NTLM relay চালু করা

Impacket-এর [`ntlmrelayx.py`](https://github.com/fortra/impacket/blob/master/examples/ntlmrelayx.py?utm_source=chatgpt.com) inbound connection গ্রহণ করে AD CS Web Enrollment-এ relay করে।

```
impacket-ntlmrelayx -t http://10.129.234.110/certsrv/certfnsh.asp --adcs -smb2support --template KerberosAuthentication
```

`--template`-এর value environment অনুযায়ী ভিন্ন হতে পারে। এখানে `KerberosAuthentication` হলো Domain Controller authentication-এর certificate template। [`Certipy`](https://github.com/ly4k/Certipy?utm_source=chatgpt.com) দিয়ে template enumerate করা যায়।

### ধাপ ২: Printer Bug দিয়ে authentication trigger করা

## 4. Shadow Credentials (`msDS-KeyCredentialLink`)

Shadow Credentials attack-এ victim user-এর `msDS-KeyCredentialLink` attribute অপব্যবহার করা হয়। এই attribute-এ PKINIT authentication-এর জন্য public key রাখা হয়।

BloodHound-এর `AddKeyCredentialLink` edge বোঝায়, একজন user অন্য user-এর এই attribute-এ write permission রাখে। এই permission দিয়ে target account takeover করা সম্ভব হতে পারে।

## 5. No PKINIT?

কিছু environment-এ certificate পাওয়া গেলেও নির্দিষ্ট victim, যেমন Domain Controller machine account-এর জন্য pre-authentication ব্যর্থ হতে পারে। কারণ KDC উপযুক্ত `EKU` support নাও করতে পারে।

[`PassTheCert`](https://github.com/AlmondOffSec/PassTheCert/?utm_source=chatgpt.com) এ ধরনের ক্ষেত্রে certificate দিয়ে LDAPS authentication করতে পারে। এর ব্যবহার password পরিবর্তন বা DCSync rights দেওয়ার মতো কাজ পর্যন্ত বিস্তৃত।

\- [Authenticating with Certificates When PKINIT Is Not Supported](https://offsec.almond.consulting/authenticating-with-certificates-when-pkinit-is-not-supported.html?utm_source=chatgpt.com)

এই attack এই module-এর scope-এর বাইরে, তবে বিষয়টি পড়ে দেখা উপকারী।

## 6. Onwards

এখানে Windows ও Linux host থেকে বিভিন্ন lateral movement technique আলোচনা করা হয়েছে। পরবর্তী বিষয় Password Management। Assessment-এর সময় বিভিন্ন পরিস্থিতি মোকাবিলার জন্য lateral movement technique নিয়মিত অনুশীলন করা এবং একাধিক tool ব্যবহারে দক্ষ হওয়া গুরুত্বপূর্ণ।
