## 1. Password Manager কী?

একজন মানুষের গড়ে প্রায় 100টি password থাকতে পারে। তাই মানুষ password reuse করে বা সহজ password ব্যবহার করে।

- [NordPass Study](https://www.techradar.com/news/most-people-have-25-more-passwords-than-at-the-start-of-the-pandemic?utm_source=chatgpt.com)
- [Password Manager](https://en.wikipedia.org/wiki/Password_manager?utm_source=chatgpt.com): Encrypted database-এ password ও sensitive information নিরাপদে রাখে।
- সুবিধা: Password generation, 2FA support, secure form filling, browser integration, multi-device synchronization ও security alerts।

## 2. Password Manager কীভাবে কাজ করে?

বেশিরভাগ password manager একটি Master Password ব্যবহার করে password database encrypt করে।

- [Cryptographic Hash Functions](https://en.wikipedia.org/wiki/Cryptographic_hash_function?utm_source=chatgpt.com)
- [Key Derivation Functions](https://en.wikipedia.org/wiki/Key_derivation_function?utm_source=chatgpt.com)

এগুলো encrypted database-এ unauthorized access ঠেকাতে সাহায্য করে। পদ্ধতি provider এবং cloud/local storage অনুযায়ী আলাদা হতে পারে।

### Zero-Knowledge Encryption

[Zero-Knowledge Encryption](https://blog.cubbit.io/blog-posts/what-is-zero-knowledge-encryption?utm_source=chatgpt.com) এমন ব্যবস্থা, যেখানে service provider-ও encrypted data পড়তে পারে না।

Bitwarden-এর simplified process:

- `Master key`: Master password থেকে Key Derivation Function ব্যবহার করে তৈরি।
- `Master password hash`: Master password (এবং প্রায়ই master key) থেকে তৈরি; cloud service-এ authentication-এর জন্য ব্যবহৃত।
- `Decryption key`: Master key থেকে তৈরি symmetric key, যা vault items decrypt করে।

## 4. Local Password Managers

Password database নিজের device-এ সংরক্ষণ করে। Database ও storage location নিরাপদ রাখার দায়িত্ব ব্যবহারকারীর।

- [Dashlane](https://www.dashlane.com/?utm_source=chatgpt.com)
- [Password Manager Storage: Cloud vs. Local](https://blog.dashlane.com/password-storage-cloud-versus-local/?utm_source=chatgpt.com)

Local manager-ও cloud manager-এর মতো encryption ব্যবহার করে। প্রধান পার্থক্য হলো data transmission ও authentication।

- Local database নিরাপদ রাখে।
- Cryptographic hash functions ব্যবহার করে।
- Random salt-সহ Key Derivation Function ব্যবহার করে precomputed keys, dictionary ও guessing attacks কঠিন করে।
- কিছু manager memory protection ও keylogger resistance দেয়; Windows User Account Control (UAC)-এর মতো secure desktop environment ব্যবহার করতে পারে।

## 7. Going Passwordless

[Passwordless Authentication](https://en.wikipedia.org/wiki/Passwordless_authentication?utm_source=chatgpt.com) হলো password ছাড়া অন্য authentication factor দিয়ে পরিচয় যাচাই করা।

- Knowledge factor: ব্যবহারকারী যা জানে, যেমন password। এটি চুরি, share, reuse ও misuse হতে পারে।
- Possession factor: ব্যবহারকারীর কাছে যা আছে।
- Inherent factor: ব্যবহারকারী নিজে যা, অর্থাৎ তার স্বতন্ত্র বৈশিষ্ট্য।

[Passwordless](https://www.pingidentity.com/en/resources/blog/posts/2021/what-does-passwordless-really-mean.html?utm_source=chatgpt.com) পদ্ধতিতে password-এর পরিবর্তে possession বা inherent factor ব্যবহার করা হয়।
