## Introduction to Hashcat

**General syntax**

```
hashcat -a 0 -m 0 <hashes> [wordlist, rule, mask...]
```

Use:

```
hashid -m
```

to determine the value after `-m`.

## Attack Modes

### Dictionary Attack

```
-a 0
```

Rules files are located at:

```
/usr/share/hashcat/rules
```

Apply rules with:

```
-r <ruleset>
```

### Mask Attack

```
-a 3
```

A brute-force attack where the keyspace is explicitly defined by the user.

**Built-in charsets**

```
?l  : a-z
?u  : A-Z
?d  : 0-9
?h  : 0-9a-f
?H  : 0-9A-F
?s  : all symbols
?a  : ?l?u?d?s
?b  : 0x00-0xff
```

Example:

```
?u?l?l?l?l?l?d?s
```

Starts with one uppercase letter, followed by lowercase letters, then a digit, then a symbol.
