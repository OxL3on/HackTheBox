### CIA Triad & AAA Framework

* **CIA Triad:** Confidentiality, Integrity, Availability — information security-এর মূল তিনটি ভিত্তি।
* **Authentication (Who you are):** ব্যবহারকারীর পরিচয় যাচাই করার প্রক্রিয়া।
* **Authorization (What you can do):** সঠিক পরিচয় পাওয়ার পর সিস্টেমে নির্দিষ্ট কাজের অনুমতি বা পারমিশন দেওয়া।
* **Accounting/Auditing:** সিস্টেমে ব্যবহারকারীর কার্যক্রমের হিসাব রাখা ও ট্র্যাক করা।

## Authentication Factors

পরিচয় যাচাই করার জন্য প্রধানত ৪টি ফ্যাক্টর ব্যবহার করা হয়:

| Factor | Description | Examples |
| --- | --- | --- |
| **Something you know** | নিজের জানা কোনো গোপনীয় তথ্য | Password, Passphrase, PIN |
| **Something you have** | নিজের দখলে থাকা কোনো ভৌত বস্তু বা ডিভাইস | ID Card, Smart Card, Phone (2FA), CAC |
| **Something you are** | শরীরের ইউনিক বায়োমেট্রিক বৈশিষ্ট্য | Fingerprint, Face ID, Iris/Retina Scan |
| **Somewhere you are** | বর্তমান ভৌগোলিক অবস্থান বা নেটওয়ার্ক | Geolocation, IP Address |

## Password Security & Complexity Calculation

* **Definition:** অক্ষর, সংখ্যা এবং স্পেশাল ক্যারেক্টারের সমন্বয়ে তৈরি টেক্সট স্ট্রিং, যা পরিচয় প্রমাণের প্রধান উপায়।
* **Combination Formula Example:**
* uppercase letters (26) + numbers (10) = 36 characters.
* 8-digit password total combination: $36^8 = 208,827,064,576$ (সম্ভাব্য কম্বিনেশন)।


* **Alternative Passwords:** দীর্ঘ বাক্য, গানের লাইন, বা এলোমেলো শব্দের সমষ্টি (যেমন: `TreeDogEvilElephant`) পাসওয়ার্ড হিসেবে বেশি নিরাপদ।
* **Trade-off:** **Convenience vs Security** (নিরাপত্তা বাড়ালে ব্যবহারকারীর জন্য সিস্টেম জটিল হয়ে পড়ে, তাই ভারসাম্য বজায় রাখা জরুরি)।

## Key Password Statistics & Data Breach Trends

| Source / Survey | Metric | Key Insight |
| --- | --- | --- |
| **Google & Harris Poll (2019)** | Weak Passwords | ২৪% মানুষ দুর্বল পাসওয়ার্ড (যেমন: `123456`, `qwerty`) ব্যবহার করে। |
|  | Password Personalization | ২২% নিজের নাম এবং ৩৩% সন্তান/পোষা প্রাণীর নাম ব্যবহার করে। |
|  | Password Reuse | ৬৬% মানুষ একাধিক অ্যাকাউন্টে একই পাসওয়ার্ড ব্যবহার করে। |
|  | Password Managers | মাত্র ১৫% মানুষ পাসওয়ার্ড ম্যানেজার ব্যবহার করত। |
|  | Post-Breach Behavior | ৫৫% মানুষ ডাটা ব্রিচের পরেও leaked পাসওয়ার্ড বদলায় না। |
| **Panda Security (2025)** | Most Common Password | `123456` এখনও শীর্ষ পাসওয়ার্ড (ব্রিচে ৪.৫ মিলিয়নের বেশি বার পাওয়া গেছে)। |
|  | Multi-account Reuse | ২৩% মানুষ অন্তত ৩টি অ্যাকাউন্টে একই পাসওয়ার্ড পুনঃব্যবহার করে। |
|  | Password Managers | ৩৬% মানুষ পাসওয়ার্ড ম্যানেজার ব্যবহারে অভ্যস্ত হয়েছে (২০১৯ এর দ্বিগুণ)। |
