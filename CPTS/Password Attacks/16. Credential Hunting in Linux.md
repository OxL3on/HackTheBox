# Credential Hunting in Linux - [LINK](https://academy.hackthebox.com/app/module/147/section/1320)


সিস্টেমে প্রাথমিক অ্যাক্সেস পাওয়ার পর (যেমন রিভার্স শেল পাওয়ার পর), আমাদের সবচেয়ে গুরুত্বপূর্ণ কাজগুলোর একটি হলো ক্রেডেনশিয়াল বা পাসওয়ার্ড খুঁজে বের করা। এই কাজটিকে হ্যাকিংয়ের ভাষায় "Low-hanging fruits" (সহজে পাওয়া যায় এমন জিনিস) বলা হয়, কারণ এগুলো দিয়ে খুব সহজেই এবং দ্রুত সিস্টেমের প্রিভিলেজ এসকালেশন বা রুট অ্যাক্সেস পাওয়া সম্ভব।

লিনাক্স সিস্টেমে পাসওয়ার্ড বা ক্রেডেনশিয়াল সাধারণত চারটি প্রধান ক্যাটাগরিতে লুকিয়ে থাকে:

1. **Files (ফাইল):** কনফিগারেশন ফাইল, ডাটাবেস, নোট, স্ক্রিপ্ট, ক্রনজব এবং SSH কি।


2. **History (হিস্ট্রি):** লগ ফাইল এবং কমান্ড-লাইনের হিস্ট্রি।


3. **Memory (মেমোরি):** ক্যাশ এবং ইন-মেমোরি প্রসেস।


4. **Key-rings:** ব্রাউজারে সেভ করা পাসওয়ার্ড বা সিস্টেমের নিজস্ব পাসওয়ার্ড ম্যানেজার।



## Files (ফাইল)

লিনাক্সের একটি মূল নীতি হলো "Everything is a file" (সবকিছুই ফাইল)। তাই ফাইল সিস্টেমে ঠিকমতো খুঁজলে অনেক সংবেদনশীল তথ্য পাওয়া যায়।

### ১. Searching for configuration files (কনফিগারেশন ফাইল খোঁজা)

সার্ভিস বা সফটওয়্যারগুলোর কনফিগারেশন ফাইলে অনেক সময় সরাসরি পাসওয়ার্ড লেখা থাকে। সাধারণত এগুলোর এক্সটেনশন হয় `.conf`, `.config` বা `.cnf`।

পুরো সিস্টেমে এই ফাইলগুলো খুঁজে বের করার জন্য নিচের লুপ কমান্ডটি ব্যবহার করা যায়:

```bash
for l in $(echo ".conf .config .cnf");do echo -e "\nFile extension: " $l; find / -name *$l 2>/dev/null | grep -v "lib\|fonts\|share\|core" ;done

```

ফাইলগুলো পাওয়ার পর, তাদের ভেতর "user", "password", বা "pass" এর মতো শব্দ খোঁজার জন্য নিচের কমান্ডটি কাজে লাগে:

```bash
for i in $(find / -name *.cnf 2>/dev/null | grep -v "doc\|lib");do echo -e "\nFile: " $i; grep "user\|password\|pass" $i 2>/dev/null | grep -v "\#";done

```

এই কমান্ডটি আপনাকে দেখিয়ে দেবে কোন কনফিগ ফাইলের কোথায় সরাসরি পাসওয়ার্ড লেখা আছে।

### ২. Searching for databases (ডাটাবেস খোঁজা)

একইভাবে আমরা সিস্টেমের বিভিন্ন ডাটাবেস ফাইল খুঁজতে পারি, কারণ ডাটাবেসের ভেতরেও অনেক সময় গুরুত্বপূর্ণ তথ্য বা পাসওয়ার্ড থাকে। ডাটাবেসের এক্সটেনশন সাধারণত `.sql`, `.db`, `.*db` ইত্যাদি হয়।

```bash
for l in $(echo ".sql .db .*db .db*");do echo -e "\nDB File extension: " $l; find / -name *$l 2>/dev/null | grep -v "doc\|lib\|headers\|share\|man";done

```

### ৩. Searching for notes (নোট খোঁজা)

অ্যাডমিনরা অনেক সময় সার্ভারের ডেস্কটপে বা হোম ডিরেক্টরিতে `.txt` ফাইলে পাসওয়ার্ড বা অ্যাক্সেস পয়েন্টের লিস্ট সেভ করে রাখেন। আবার অনেক ফাইলের কোনো এক্সটেনশনও থাকে না।

```bash
find /home/* -type f -name "*.txt" -o ! -name "*.*"

```

### ৪. Searching for scripts (স্ক্রিপ্ট খোঁজা)

অনেক সময় স্বয়ংক্রিয় কাজ (automation) করার জন্য অ্যাডমিনরা ব্যাশ বা পাইথন স্ক্রিপ্টের ভেতরে সরাসরি পাসওয়ার্ড লিখে দেন (Hardcoded credentials)।

```bash
for l in $(echo ".py .pyc .pl .go .jar .c .sh");do echo -e "\nFile extension: " $l; find / -name *$l 2>/dev/null | grep -v "doc\|lib\|headers\|share";done

```

### ৫. Enumerating cronjobs (ক্রনজব চেক করা)

ক্রনজব হলো লিনাক্সের শিডিউল করা অটোমেটিক টাস্ক। অনেক অটোমেটিক স্ক্রিপ্টে রান করার জন্য পাসওয়ার্ড লাগে, যা ক্রন ফাইলে পাওয়া যেতে পারে।
সিস্টেম-ওয়াইড ক্রনজব দেখতে: `cat /etc/crontab`
বিভিন্ন সময়ের ক্রনজব দেখতে: `ls -la /etc/cron.*/`

## History and Log Files (হিস্ট্রি এবং লগ ফাইল)

### ১. Enumerating history files (কমান্ড হিস্ট্রি দেখা)

লিনাক্সে ডিফল্টভাবে ব্যাশ শেল ব্যবহৃত হয়, আর ইউজারের টাইপ করা সব কমান্ড `.bash_history` ফাইলে সেভ থাকে। ইউজার যদি ভুল করে কমান্ড লাইনে পাসওয়ার্ড টাইপ করে থাকে, তবে তা এখানে পাওয়া যাবে।

```bash
tail -n5 /home/*/.bash*

```

### ২. Enumerating log files (লগ ফাইল বিশ্লেষণ)

| **File**              | **Description**                                  |
| --------------------- | ------------------------------------------------ |
| `/var/log/messages`   | Generic system activity logs                     |
| `/var/log/syslog`     | Generic system activity logs                     |
| `/var/log/auth.log`   | (Debian) All authentication-related logs         |
| `/var/log/secure`     | (RedHat/CentOS) All authentication-related logs  |
| `/var/log/boot.log`   | Booting information                              |
| `/var/log/dmesg`      | Hardware and driver-related information and logs |
| `/var/log/kern.log`   | Kernel-related warnings, errors, and logs        |
| `/var/log/faillog`    | Failed login attempts                            |
| `/var/log/cron`       | Information related to cron jobs                 |
| `/var/log/mail.log`   | All mail server-related logs                     |
| `/var/log/httpd`      | All Apache-related logs                          |
| `/var/log/mysqld.log` | All MySQL server-related logs                    |


লিনাক্সে সবকিছু লগ হিসেবে সেভ থাকে। যেমন, `/var/log/auth.log` (ডেবিয়ান) বা `/var/log/secure` (রেডহ্যাট) এ লগইন ফেইল বা সেশনের তথ্য থাকে।
লগ ফাইলের ভেতর থেকে গুরুত্বপূর্ণ তথ্য বের করার কমান্ড:

```bash
for i in $(ls /var/log/* 2>/dev/null);do GREP=$(grep "accepted\|session opened\|session closed\|failure\|failed\|ssh\|password changed\|new user\|delete user\|sudo\|COMMAND\=\|logs" $i 2>/dev/null); if [[ $GREP ]];then echo -e "\n#### Log file: " $i; grep "accepted\|session opened\|session closed\|failure\|failed\|ssh\|password changed\|new user\|delete user\|sudo\|COMMAND\=\|logs" $i 2>/dev/null;fi;done

```

## Memory and Cache (মেমোরি এবং ক্যাশ থেকে পাসওয়ার্ড বের করা)

### ১. Mimipenguin

উইন্ডোজে যেমন মেমোরি থেকে পাসওয়ার্ড ডাম্প করার জন্য Mimikatz ব্যবহার করা হয়, লিনাক্সের জন্য তেমনি [mimipenguin](https://github.com/huntergregal/mimipenguin) নামের একটি টুল আছে। এটি লগইন করা ইউজারের পাসওয়ার্ড সরাসরি মেমোরি থেকে বের করে আনতে পারে (তবে এটি চালাতে রুট/অ্যাডমিন পারমিশন লাগে)।

```bash
sudo python3 mimipenguin.py

```

### ২. LaZagne (অটোমেটেড টুল)

LaZagne অত্যন্ত শক্তিশালী একটি টুল যা উইন্ডোজের পাশাপাশি লিনাক্সেও কাজ করে। এটি ওয়াইফাই, এসএসএইচ, ব্রাউজার, গিট, ফায়ারফক্স, ক্রোমিয়াম, শ্যাডো ফাইল, কীবোর্ড রিং— এক কথায় লিনাক্সের সব জায়গা থেকে অটোমেটিক পাসওয়ার্ড ডাম্প করে আনতে পারে।

```bash
sudo python2.7 laZagne.py all

```

## Browser credentials (ব্রাউজারের পাসওয়ার্ড)

কর্মীরা প্রায়শই তাদের ব্রাউজারে (যেমন ফায়ারফক্স বা ক্রোম) কোম্পানির পাসওয়ার্ড সেভ করে রাখেন। ফায়ারফক্স এই এনক্রিপ্ট করা পাসওয়ার্ডগুলো ইউজারের লুকানো ডিরেক্টরির `logins.json` ফাইলে সেভ করে রাখে।

এই এনক্রিপ্ট করা পাসওয়ার্ডগুলো ডিক্রিপ্ট করার জন্য **Firefox Decrypt** নামের একটি চমৎকার টুল রয়েছে।

```bash
python3.9 firefox_decrypt.py

```

এই টুলটি রান করলে ইউজারের ফায়ারফক্স প্রোফাইল সিলেক্ট করার অপশন আসবে এবং এরপর সে ওয়েবসাইটের URL, ইউজারনেম এবং ডিক্রিপ্ট করা আসল পাসওয়ার্ড স্ক্রিনে দেখিয়ে দেবে। বিকল্প হিসেবে LaZagne এর `browsers` মডিউল ব্যবহার করেও এই কাজ করা যায়।
