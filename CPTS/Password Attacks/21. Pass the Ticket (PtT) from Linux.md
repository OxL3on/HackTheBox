# Pass the Ticket (PtT) from Linux - [LINK](https://academy.hackthebox.com/app/module/147/section/1657)

## 1. Overview

Linux machine Active Directory (`AD`)-এর সঙ্গে integrate করা থাকলে সাধারণত authentication-এর জন্য `Kerberos` ব্যবহার করতে পারে।

কোনো Linux machine compromise হলে সেখানে থাকা Kerberos tickets ও `keytab` files পরীক্ষা করে অন্য user বা service account-এর access পাওয়া সম্ভব হতে পারে।

**Pass the Ticket (PtT):** বিদ্যমান Kerberos ticket ব্যবহার করে সংশ্লিষ্ট identity হিসেবে authenticate করার কৌশল।

## 2. Linux-এ Kerberos Storage

| Item | কাজ |
|---|---|
| `TGT` | Ticket Granting Ticket; অন্য Kerberos service ticket পাওয়ার জন্য ব্যবহৃত হয়। |
| `TGS` | নির্দিষ্ট service access করার ticket। |
| `ccache` | Kerberos credentials ও tickets cache করে রাখে। |
| `keytab` | Kerberos principal এবং encrypted key সংরক্ষণ করে; password না লিখেও authentication সম্ভব করে। |
| `KRB5CCNAME` | Kerberos credential cache-এর location নির্দেশ করে। |
| `/etc/krb5.keytab` | Linux host-এর default system keytab location। |
| `/tmp/krb5cc_*` | Linux-এ দেখা সাধারণ Kerberos credential cache files। |

References: [MIT Kerberos ccache](https://web.mit.edu/kerberos/krb5-1.12/doc/basic/ccache_def.html) · [Keytab Overview](https://servicenow.iu.edu/kb?sys_kb_id=2c10b87f476456583d373803846d4345&id=kb_article_view#intro)

## 3. Linux কি Active Directory-তে Joined?

### `realm`

```bash
realm list
```

Output-এ গুরুত্বপূর্ণ fields:

- `realm-name` — Kerberos realm, সাধারণত uppercase।
- `domain-name` — AD domain।
- `configured: kerberos-member` — Kerberos member হিসেবে configured।
- `server-software: active-directory` — AD integration নির্দেশ করে।
- `client-software: sssd` — SSSD ব্যবহার হচ্ছে।
- `permitted-logins`, `permitted-groups` — অনুমোদিত users ও groups।

### `sssd` ও `winbind` পরীক্ষা

```bash
ps -ef | grep -i "winbind\|sssd"
```

References: [blog post](https://web.archive.org/web/20210624040251/https://www.2daygeek.com/how-to-identify-that-the-linux-server-is-integrated-with-active-directory-ad/) · [SSSD](https://sssd.io/) · [Winbind](https://www.samba.org/samba/docs/current/man-html/winbindd.8.html)

## 4. Keytab ও ccache খোঁজা

### Keytab Files

```bash
find / -name '*keytab*' -ls 2>/dev/null
```

সাধারণ location:

```text
/etc/krb5.keytab
/opt/specialfiles/carlos.keytab
```

Keytab-এর নাম সবসময় `.keytab` দিয়ে শেষ হবে এমন নয়। তাই cronjob ও script-ও পরীক্ষা করতে হয়।

### Cronjob ও Script

```bash
crontab -l
cat /path/to/kerberos_script_test.sh
```

উদাহরণ script:

```bash
kinit svc_workstations@INLANEFREIGHT.HTB \
-k -t /path/to/svc_workstations.kt

smbclient //dc01.inlanefreight.htb/svc_workstations \
-c 'ls' -k -no-pass
```

- `kinit` — Kerberos authentication করে এবং ticket cache-এ TGT রাখতে পারে।
- `-k` — Keytab ব্যবহার করে authentication।
- `-t` — Keytab file path।
- `smbclient -k` — Kerberos authentication ব্যবহার করে SMB access।

Linux machine-এর `/etc/krb5.keytab`-এ machine account-এর credential থাকতে পারে। File-এর permissions গুরুত্বপূর্ণ; root access থাকলে sensitive Kerberos material-এ প্রবেশ সম্ভব হতে পারে।

### ccache Location

```bash
env | grep -i krb5
```

উদাহরণ:

```text
KRB5CCNAME=FILE:/tmp/krb5cc_647402606_qd2Pfh
```

Temporary cache files দেখতে:

```bash
ls -la /tmp
```

`ccache` file সাধারণত ticket ও session-এর সঙ্গে সম্পর্কিত। Access, validity এবং expiration নির্ভর করে permissions ও ticket lifetime-এর ওপর।

## 5. Keytab বিশ্লেষণ ও Authentication

### Keytab Information — `klist`

```bash
klist -k -t /opt/specialfiles/carlos.keytab
```

এতে দেখা যায়:
- Keytab-এর principal।
- Key Version Number (`KVNO`)।
- Entry-এর timestamp।

### Keytab দিয়ে Ticket নেওয়া

অনুমোদিত lab-এ:

```bash
kinit carlos@INLANEFREIGHT.HTB \
-k -t /opt/specialfiles/carlos.keytab
```

এরপর ticket যাচাই:

```bash
klist
```

`klist`-এ `Default principal`, `Ticket cache`, `Valid starting`, `Expires` এবং service principal দেখা যায়।

**গুরুত্বপূর্ণ:** Kerberos principal case-sensitive হতে পারে। `klist -k`-এ যে principal দেখায়, সেটিই ব্যবহার করতে হবে।

### SMB Share Access

```bash
smbclient //dc01/carlos -k -c ls
```

- `-k` — Kerberos authentication।
- `-c ls` — Share-এর directory listing দেখায়।

Ticket পরিবর্তনের আগে বর্তমান `KRB5CCNAME` cache-এর backup রাখা উপকারী হতে পারে, যাতে আগের session ticket হারিয়ে না যায়।

## 6. Keytab থেকে Hash Extract করা

[KeyTabExtract](https://github.com/sosdave/KeyTabExtract) keytab থেকে Kerberos metadata ও কিছু encryption type-এর key/hash-সংক্রান্ত তথ্য extract করতে পারে।

```bash
python3 /opt/keytabextract.py /opt/specialfiles/carlos.keytab
```

Output-এ থাকতে পারে:

- `REALM`
- `SERVICE PRINCIPAL`
- `NTLM HASH`
- `AES-256 HASH`
- `AES-128 HASH`

Keytab-এ বিভিন্ন encryption type-এর একাধিক credential entry থাকতে পারে।

এ ধরনের credential material সংবেদনশীল। Extracted hash-এর ব্যবহারকে access-control bypass বা account impersonation-এর অনুমতি হিসেবে ধরে নেওয়া যাবে না; testing অবশ্যই অনুমোদিত lab-এর মধ্যে সীমিত রাখতে হবে।

Tools: [Hashcat](https://hashcat.net/) · [John the Ripper](https://www.openwall.com/john/)

## 7. ccache ব্যবহার ও Ticket Validity

`ccache` file ব্যবহার করার জন্য file access এবং valid ticket প্রয়োজন।

### Cache Location পরিবর্তন

অনুমোদিত lab-এ cache file-এর copy নিয়ে তার path environment variable-এ দেওয়া যায়:

```bash
cp /path/to/krb5cc_file ./ticket.ccache
export KRB5CCNAME=/path/to/ticket.ccache
klist
```

`KRB5CCNAME`-এ cache path সঠিক হতে হবে। কিছু environment-এ `FILE:` prefix দেখা যায়; tool-এর compatibility অনুযায়ী format যাচাই করতে হয়।

### Ticket Expiration

`klist` output-এর fields:

- `Valid starting` — Ticket কখন থেকে valid।
- `Expires` — Ticket কখন expire হবে।
- `renew until` — Ticket renewal-এর সর্বশেষ সময়, যদি renewable হয়।

Expired ticket সাধারণত authentication-এর জন্য ব্যবহার করা যাবে না। Login/logout বা session পরিবর্তনের কারণে cache files-ও পরিবর্তিত হতে পারে।

## 8. Privilege Escalation এবং ccache আবিষ্কার

Module-এর lab scenario-তে একটি service account-এর sudo permission পরীক্ষা করা হয়:

```bash
sudo -l
```

Output-এ যদি user-এর জন্য `(ALL) ALL` থাকে, তাহলে sudo policy অনুযায়ী user যেকোনো command elevated privilege-এ চালাতে পারে।

Lab-এর উদাহরণ:

```bash
sudo su
whoami
```

Root permission পাওয়া গেলে `/tmp`-এর ticket caches পরীক্ষা করা যেতে পারে:

```bash
ls -la /tmp
```

`id` দিয়ে কোনো user-এর group membership পরীক্ষা করা যায়:

```bash
id julio@inlanefreight.htb
```

`Domain Admins`-এর মতো privileged group membership গুরুত্বপূর্ণ security finding। তবে শুধু group membership দেখেই ticket valid বা access সফল হবে ধরে নেওয়া যাবে না।

## 9. Non-Domain Linux Host থেকে Kerberos

Domain-joined নয় এমন attack host থেকেও Kerberos ব্যবহার করা সম্ভব, তবে সাধারণত প্রয়োজন হয়:

- KDC/Domain Controller-এ network connectivity।
- সঠিক DNS resolution বা hostname mapping।
- Valid Kerberos configuration ও ticket।
- প্রয়োজন হলে authorized network path বা tunnel।

Source lab-এ `MS01` হয়ে `LINUX01` ও Domain Controller-এ যোগাযোগের জন্য `Chisel` এবং `Proxychains` ব্যবহার করা হয়েছে।

### `/etc/hosts`

```text
172.16.1.10 inlanefreight.htb inlanefreight dc01.inlanefreight.htb dc01
172.16.1.5  ms01.inlanefreight.htb ms01
```

এটি DNS না থাকলে hostname-to-IP mapping দিতে পারে।

### Proxychains Configuration

```text
[ProxyList]
socks5 127.0.0.1 1080
```

### Chisel Resources

[Chisel GitHub](https://github.com/jpillora/chisel)

- Chisel client/server দিয়ে network tunnel তৈরি করা যায়।
- Proxychains-এর মাধ্যমে compatible application-এর traffic proxy করা যায়।
- Kerberos authentication-এর জন্য শুধু SOCKS proxy যথেষ্ট নাও হতে পারে; DNS, KDC reachability ও hostname configuration-ও ঠিক থাকতে হবে।

## 10. Impacket দিয়ে Kerberos

[Impacket](https://github.com/fortra/impacket)-এর বিভিন্ন tool Kerberos authentication সমর্থন করে।

উদাহরণ:

```bash
proxychains impacket-wmiexec dc01 -k
```

- `dc01` — Target hostname; Kerberos ব্যবহারের ক্ষেত্রে hostname গুরুত্বপূর্ণ।
- `-k` — Kerberos authentication ব্যবহার।
- `-no-pass` — Tool password prompt চাইলে এবং authentication setup সমর্থন করলে ব্যবহার করা যায়।

সফল authentication-এর জন্য সঠিক ticket, `KRB5CCNAME`, hostname resolution এবং domain controller-এর connectivity দরকার।

## 11. Evil-WinRM দিয়ে Kerberos

[Evil-WinRM](https://github.com/Hackplayers/evil-winrm) Windows Remote Management (WinRM) দিয়ে remote PowerShell session তৈরি করার tool।

Debian-based Linux-এ Kerberos client package:

```bash
sudo apt-get install krb5-user -y
```

`/etc/krb5.conf`-এর উদাহরণ:

```ini
[libdefaults]
    default_realm = INLANEFREIGHT.HTB

[realms]
    INLANEFREIGHT.HTB = {
        kdc = dc01.inlanefreight.htb
    }
```

Kerberos authentication-এর উদাহরণ:

```bash
proxychains evil-winrm -i dc01 -r inlanefreight.htb
```

প্রাসঙ্গিক বিষয়:
- `default_realm` — Default Kerberos realm।
- `kdc` — Key Distribution Center / Domain Controller।
- `-i` — Target hostname।
- `-r` — Kerberos realm।

Tool-এর version ও configuration অনুযায়ী realm ও Kerberos setup যাচাই করতে হবে।

## 12. ccache ও kirbi Conversion

Linux-এ `ccache` এবং Windows-এ `.kirbi` format ব্যবহৃত হতে পারে।

[Impacket ticketConverter](https://github.com/fortra/impacket/blob/master/examples/ticketConverter.py) দিয়ে supported cache format convert করা যায়।

```bash
impacket-ticketConverter ticket.ccache ticket.kirbi
```

Windows-এ [Rubeus](https://github.com/GhostPack/Rubeus)-এর `ptt` action ticket import করতে ব্যবহৃত হয়। Source-এর lab example:

```cmd
C:\tools\Rubeus.exe ptt /ticket:C:\tools\julio.kirbi
```

Ticket import হয়েছে কি না পরীক্ষা:

```cmd
klist
```

Ticket-এর principal, service, encryption type এবং expiry দেখতে পাওয়া যায়।

## 13. Linikatz

[Linikatz](https://github.com/CiscoCXSecurity/linikatz) হলো Linux environment-এ AD integration-সম্পর্কিত credential material ও Kerberos tickets শনাক্ত করার tool।

এটি বিভিন্ন implementation-এর data পরীক্ষা করতে পারে, যেমন:

- FreeIPA
- SSSD
- Samba
- Vintella / PBIS-ধরনের AD integration
- Kerberos credential caches ও keytab files

Module অনুযায়ী Linikatz সাধারণত root privileges প্রয়োজন করে এবং সংগৃহীত material `linikatz.*`-জাতীয় directory-তে রাখতে পারে।

## Key Takeaways

- Linux Active Directory integration-এ Kerberos ticket ও keytab গুরুত্বপূর্ণ authentication material।
- `ccache` সাধারণত active session-এর tickets রাখে; `KRB5CCNAME` এর location নির্দেশ করে।
- `keytab` script ও service-কে password ছাড়াই authenticate করতে দেয়।
- `klist`, `kinit`, `realm`, `find` ও `crontab` Kerberos configuration এবং ticket usage বোঝার কাজে লাগে।
- Impacket, Evil-WinRM, Rubeus ও ticketConverter Kerberos-compatible workflow-এ ব্যবহৃত হয়।
- Ticket-এর validity, principal, file permissions, privileges এবং network connectivity সবসময় যাচাই করতে হবে।
- Credential ও ticket extraction কেবল অনুমোদিত penetration test বা lab environment-এ করতে হবে।
