## Credential Hunting in Windows

After gaining access to a Windows machine, perform credential hunting.

### Search - Centric Approach

Think like the user. Use keywords to search.

### Search Tools

- Windows Search (if GUI access is available)

### LaZagne

Credential extraction tool.

Divided into modules.

- Browser stores credentials encrypted.
- To decrypt:
    - firefox_decrypt
    - decrypt_chrome_passwords

Run LaZagne:

```powershell
start LaZagne.exe all
```

Findstr:

```powershell
findstr /SIM /C:"password" *.txt *.ini *.cfg *.config *.xml *.git *.ps1 *.yml
```

### Other Places to Search

1. SYSVOL group policy passwords
2. SYSVOL scripts
3. IT share scripts
4. Web.config
5. unattend.xml
6. AD Description
7. KeePass DB
8. Network shares
