# Credential Hunting in Windows - [LINK](https://academy.hackthebox.com/app/module/147/section/1318)


অফেন্সিভ সিকিউরিটির ক্ষেত্রে, বিশেষ করে CPTS পাথওয়েতে, উইন্ডোজ মেশিনে প্রাথমিক অ্যাক্সেস (GUI বা CLI) পাওয়ার পর সবচেয়ে গুরুত্বপূর্ণ ধাপ হলো ক্রেডেনশিয়াল হান্টিং বা পাসওয়ার্ড খোঁজা। এটি মূলত ফাইল সিস্টেম এবং বিভিন্ন অ্যাপ্লিকেশনের ভেতরে লুকিয়ে থাকা পাসওয়ার্ড বা ক্রেডেনশিয়াল খুঁজে বের করার একটি প্রক্রিয়া।

ধরে নিন, আমরা RDP ব্যবহার করে একজন IT Admin-এর Windows 10 ওয়ার্কস্টেশনে অ্যাক্সেস পেয়েছি। এখন আমাদের কাজ হবে তার সেভ করা পাসওয়ার্ডগুলো খুঁজে বের করা।

## Search-centric Approach (সার্চ-ভিত্তিক পদ্ধতি)

বর্তমান সময়ের প্রায় সব অপারেটিং সিস্টেম এবং অ্যাপ্লিকেশনে চমৎকার সার্চ ফিচার থাকে। একজন ইউজার (বিশেষ করে IT Admin) তার দৈনন্দিন কাজের সুবিধার জন্য অনেক সময় পাসওয়ার্ডগুলো কোনো ফাইলে সেভ করে রাখেন। এলোমেলোভাবে না খুঁজে, টার্গেট ইউজার কী ধরনের কাজ করেন তার ওপর ভিত্তি করে সার্চ করলে পাসওয়ার্ড পাওয়ার সম্ভাবনা অনেক বেড়ে যায়।



## Key terms to search for (যেসব শব্দ দিয়ে সার্চ করবেন)

GUI বা CLI যে মাধ্যমেই থাকি না কেন, আমরা নির্দিষ্ট কিছু কি-ওয়ার্ড (Keyword) দিয়ে পাসওয়ার্ড খুঁজতে পারি। নিচের শব্দগুলো এক্ষেত্রে খুবই কার্যকরী:

* Passwords
* Passphrases
* Keys
* Username
* User account
* Creds
* Users
* Passkeys
* configuration
* dbcredential
* dbpassword
* pwd
* Login
* Credentials

### ১. Windows Search (উইন্ডোজের নিজস্ব সার্চ)

আমাদের যদি গ্রাফিকাল ইন্টারফেস (GUI) অ্যাক্সেস থাকে, তবে আমরা উইন্ডোজের ডিফল্ট সার্চ বার ব্যবহার করে উপরের কি-ওয়ার্ডগুলো দিয়ে সার্চ করতে পারি। উদাহরণস্বরূপ, স্টার্ট মেনুর সার্চ বারে "pass" লিখে সার্চ করলে অনেক সময় "passwords" নামের স্প্রেডশিট বা টেক্সট ফাইল সরাসরি চলে আসে।

### ২. LaZagne (থার্ড-পার্টি অটোমেটেড টুল)

[LaZagne](https://github.com/AlessandroZ/LaZagne) হলো এমন একটি টুল যা বিভিন্ন সফটওয়্যারে (যেমন: ব্রাউজার, চ্যাট অ্যাপ) অনিরাপদভাবে সেভ করে রাখা পাসওয়ার্ডগুলো খুব দ্রুত বের করে আনতে পারে। এটি বিভিন্ন মডিউলে বিভক্ত:

| মডিউল (Module) | কাজ (Description) |
| --- | --- |
| browsers | Chromium, Firefox, Microsoft Edge এবং Opera-এর মতো ব্রাউজার থেকে পাসওয়ার্ড বের করে। |
| chats | Skype-এর মতো চ্যাট অ্যাপ্লিকেশন থেকে পাসওয়ার্ড বের করে। |
| mails | Outlook এবং Thunderbird-এর মতো মেইলবক্স থেকে পাসওয়ার্ড খোঁজে। |
| memory | মেমোরি (LSASS) এবং KeePass থেকে পাসওয়ার্ড ডাম্প করে। |
| sysadmin | OpenVPN এবং WinSCP-এর মতো অ্যাডমিন টুলগুলোর কনফিগারেশন ফাইল থেকে পাসওয়ার্ড বের করে। |
| windows | উইন্ডোজের LSA সিক্রেট, ক্রেডেনশিয়াল ম্যানেজার ইত্যাদি থেকে উইন্ডোজ স্পেসিফিক পাসওয়ার্ড বের করে। |
| wifi | ওয়াইফাই (WiFi) এর পাসওয়ার্ড ডাম্প করে। |

নোট: ব্রাউজারগুলো সাধারণত পাসওয়ার্ড এনক্রিপ্ট করে রাখে। কিন্তু firefox_decrypt বা decrypt-chrome-passwords এর মতো অনেক টুল অনলাইনে পাওয়া যায় যা এগুলো ডিক্রিপ্ট করতে পারে। LaZagne উইন্ডোজের প্রায় ৩৫টি ভিন্ন ব্রাউজার সাপোর্ট করে।

**LaZagne এর ব্যবহার:**
অ্যাটাকিং মেশিন থেকে `LaZagne.exe` ফাইলটি টার্গেট মেশিনে (যেমন ডেস্কটপে) কপি করতে হবে। xfreerdp ব্যবহার করলে সরাসরি কপি-পেস্ট করা যায়। এরপর কমান্ড প্রম্পট বা পাওয়ারশেল ওপেন করে নিচের কমান্ডটি দিতে হবে:

```cmd
C:\Users\bob\Desktop> start LaZagne.exe all

```

এটি LaZagne-এর সবগুলো মডিউল রান করবে। ব্যাকগ্রাউন্ডে টুলটি কীভাবে কাজ করছে তা দেখতে চাইলে কমান্ডের শেষে `-vv` অপশনটি যুক্ত করা যায়।

**আউটপুট উদাহরণ:**

```cmd
########## User: bob ##########

------------------- Winscp passwords -----------------

[+] Password found !!!
URL: 10.129.202.51
Login: admin
Password: SteveisReallyCool123
Port: 22

```

আউটপুটে দেখা যাচ্ছে, WinSCP থেকে একদম ক্লিয়ারটেক্সটে (সরাসরি) পাসওয়ার্ড বের হয়ে এসেছে। অনেক অ্যাপ্লিকেশন এভাবেই অনিরাপদভাবে পাসওয়ার্ড সেভ করে রাখে।

### ৩. findstr (কমান্ড-লাইন টুল)

টার্মিনাল বা CLI থেকে কাজ করার সময় উইন্ডোজের ডিফল্ট কমান্ড `findstr` ব্যবহার করে আমরা বিভিন্ন ধরনের ফাইলের ভেতরে নির্দিষ্ট কি-ওয়ার্ড খুঁজতে পারি:

```cmd
C:\> findstr /SIM /C:"password" *.txt *.ini *.cfg *.config *.xml *.git *.ps1 *.yml

```

এখানে `/SIM` ফোল্ডার এবং সাব-ফোল্ডারগুলোতে কেস-ইনসেনসিটিভ (বড় হাতের/ছোট হাতের অক্ষর যাই হোক না কেন) সার্চ করার নির্দেশ দেয়। এটি একসাথে অনেকগুলো ফাইল এক্সটেনশনে (যেমন .txt, .config, .xml) "password" শব্দটি খুঁজবে।

## Additional considerations (অন্যান্য যেসব জায়গায় খোঁজা উচিত)

আমরা কোন টুল বা কি-ওয়ার্ড ব্যবহার করব, তা নির্ভর করে টার্গেট কম্পিউটারের কাজের ওপর। উইন্ডোজ সার্ভার এবং সাধারণ ডেস্কটপের ক্ষেত্রে খোঁজার জায়গা ভিন্ন হতে পারে। ম্যানুয়াল স্ক্রিপ্ট বা টুল রান করার পাশাপাশি নিচের জায়গাগুলোতেও পাসওয়ার্ড চেক করা উচিত:

* SYSVOL শেয়ারের Group Policy এবং স্ক্রিপ্টের ভেতরে।
* IT শেয়ার ফোল্ডারগুলোতে রাখা স্ক্রিপ্টের ভেতরে।
* ডেভেলপার মেশিন বা IT শেয়ারের `web.config` ফাইলে।
* `unattend.xml` ফাইলের ভেতরে।
* Active Directory (AD) এর ইউজার বা কম্পিউটার ডেসক্রিপশন (Description) ফিল্ডে।
* KeePass ডাটাবেসে (যদি মাস্টার পাসওয়ার্ড গেস বা ক্র্যাক করা যায়)।
* ইউজার সিস্টেম বা শেয়ারপয়েন্টে (Sharepoint) রাখা `pass.txt`, `passwords.docx`, `passwords.xlsx` নামের ফাইলগুলোতে।

সফল ক্রেডেনশিয়াল হান্টিং একটি নেটওয়ার্কে হ্যাকারের নিয়ন্ত্রণ আরও মজবুত করতে সাহায্য করে।
