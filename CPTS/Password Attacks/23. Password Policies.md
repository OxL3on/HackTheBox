## 1. Password Policy কী?

Password Policy হলো শক্তিশালী password তৈরি, ব্যবহার ও সংরক্ষণের নিয়ম। এটি password-এর পুরো lifecycle—creation, storage, management ও transmission—নিয়ন্ত্রণ করে।

- Definition: Password তৈরির নিয়ম নির্ধারণ করে।
- Enforcement: Technology ব্যবহার করে নিয়ম মানতে বাধ্য করে।

দুটিই কার্যকর Password Policy-এর জন্য জরুরি।

## 2. Password Policy Standards

প্রতিষ্ঠানগুলো security baseline ও compliance-এর জন্য বিভিন্ন standard অনুসরণ করে। তবে standard মানলেই সম্পূর্ণ security নিশ্চিত হয় না।

- [Password Policy](https://en.wikipedia.org/wiki/Password_policy?utm_source=chatgpt.com)
- [IT Security Standards](https://en.wikipedia.org/wiki/IT_security_standards?utm_source=chatgpt.com)
- [NIST SP800-63B](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-63b.pdf?utm_source=chatgpt.com)
- [CIS Password Policy Guide](https://www.cisecurity.org/insights/white-papers/cis-password-policy-guide?utm_source=chatgpt.com)
- [PCI DSS](https://www.pcisecuritystandards.org/document_library?category=pcidss\&document=pci_dss\&utm_source=chatgpt.com)

Password Expiration: আগে প্রতি 90 দিনে password পরিবর্তনের পরামর্শ দেওয়া হতো। বর্তমানে অনেক ক্ষেত্রে নিয়মিত expiration বন্ধ রাখার পরামর্শ দেওয়া হয়, কারণ এতে ব্যবহারকারীরা predictable ও weak password তৈরি করতে পারে। কিছু প্রতিষ্ঠান শুধু password compromise নিশ্চিত হলে পরিবর্তন করতে বলে।

## 3. Sample Password Policy

নমুনা নিয়ম:

- Minimum 8 characters।
- Uppercase ও lowercase letters থাকতে হবে।
- অন্তত একটি number থাকতে হবে।
- অন্তত একটি special character থাকতে হবে।
- Username-কে password হিসেবে ব্যবহার করা যাবে না।
- প্রতি 60 দিনে password পরিবর্তন করতে হবে।

Mark প্রথমে `password123` ব্যবহার করতে চেয়েছিল, কিন্তু policy-এর কারণে ব্যর্থ হয়। পরে সে `Inlanefreight01!` ব্যবহার করে account তৈরি করে।

এটি policy মানলেও weak, কারণ এতে company name রয়েছে। Expiration-এর পর `01` পরিবর্তন করে `02` করলেই প্রায় একই password ব্যবহার করা যায়। তাই password expiration-এর কার্যকারিতা নিয়ে বিতর্ক রয়েছে।

### Blacklisted Words

Password policy-তে এসব শব্দ নিষিদ্ধ রাখা যেতে পারে:

- Company's name
- Common words associated with the company
- Names of months
- Names of seasons
- Variations on `"welcome"` and `"password"`
- Common words: `"password"`, `"123456"`, `"abcde"`

## 4. Enforcing Password Policy

Policy কার্যকর করতে technology বা প্রয়োজনীয় tools ব্যবহার করতে হবে। Applications ও identity management systems-এ সাধারণত এ ধরনের feature থাকে।

Active Directory ব্যবহার করলে [Active Directory Password Policy GPO](https://activedirectorypro.com/how-to-configure-a-domain-password-policy/?utm_source=chatgpt.com) configure করে policy enforce করা যায়।

এরপর policy পুরো company-কে জানাতে হবে এবং সর্বত্র প্রয়োগ নিশ্চিত করতে processes ও procedures তৈরি করতে হবে।

## 5. Creating a Strong Password

Password তৈরি ও যাচাই করার tools:

- [PasswordMonster](https://www.passwordmonster.com/?utm_source=chatgpt.com) — Password strength পরীক্ষা করে।
- [1Password Password Generator](https://1password.com/password-generator/?utm_source=chatgpt.com) — Secure password তৈরি করে।

### Strong Password Example

[Password test image](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/308/img/strong_password_1.png?utm_source=chatgpt.com)

`CjDC2x[U`

- Lowercase, uppercase, numbers ও symbols রয়েছে।
- Tool অনুযায়ী এটি very strong।
- Estimated crack time: 1 thousand years।
- Crack বা password spraying attack-এ অনুমান করা কঠিন, কিন্তু মনে রাখা কঠিন হতে পারে।

### Password Phrase

সাধারণ শব্দ, phrase বা পছন্দের গানের lyrics দিয়েও শক্তিশালী password তৈরি করা যায়।

উদাহরণ:

- `This is my secure password`
- `The name of my dog is Popy`
- `()The name of my dog is Popy!`

[Password phrase test image](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/308/img/strong_password_phrase.png?utm_source=chatgpt.com)

`The name of my dog is Popy`

- Tool অনুযায়ী: very strong
- Estimated crack time: 381 trillion years

Special characters যোগ করলে phrase আরও complex হতে পারে। তবে attackers OSINT ব্যবহার করে ব্যক্তিগত তথ্য জানতে পারে। তাই নিজের পরিচিত তথ্য password-এ ব্যবহার করার সময় সতর্ক থাকতে হবে।

অনেকগুলো শক্তিশালী password মনে রাখা ও পরিচালনা করা কঠিন। পরবর্তী section-এ Password Manager ব্যবহার করে অনেক password তৈরি ও নিরাপদে সংরক্ষণ করার বিষয়টি আলোচনা করা হবে।
