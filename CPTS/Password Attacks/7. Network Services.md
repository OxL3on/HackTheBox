## Network Services

Think of Windows services such as:

- SMB
- WinRM
- RDP
- HTTPS (5986)
- WinRM (5985)

WinRM

ssh for windows, PC → winRM → Windows server, 5985 - HTTP, 5986 - HTTPS

### NetExec

Tool for testing credentials against network services.

Examples:

```
netexec <protocol> <IP> -u user -p pass
```

**Evil-WinRM**

Once know the creds:

```
evil-winrm -i ip -u user -p pass
```

**Brute-forcing SSH:**

```
hydra -L users.txt -P passwords.txt ssh://<IP>
```

**Brute-forcing RDP:**

```
hydra -L users.txt -P passwords.txt rdp://<IP>
```

### SMB

SMB (`smb://ip`), also alternative is Metasploit.

Enumerate SMB shares:

```
netexec smb ip -u user -p pass --shares
```

Access SMB:

```
smbclient -U user \\\\IP\\SHARENAME
```
