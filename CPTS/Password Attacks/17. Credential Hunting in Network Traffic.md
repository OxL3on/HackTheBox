## Credential Hunting in Network Traffic

Tools:

- TLS
- Wireshark

### Useful Wireshark Filters

- **Filter by IP:**

```
ip.addr == ip
```

- **Filter by port:**

```
tcp.port == 80
```

- **Show only HTTP:**

```
http
```

- **Show DNS:**

```
dns
```

- **Show TCP SYN packets:**

```
tcp.flags.syn == 1 && tcp.flags.ack == 0
```

- **Show ICMP:**

```
icmp
```

- **HTTP POST requests:**

```
http.request.method == "POST"
```

- **Follow one TCP conversation:**

```
tcp.stream eq 53
```

- **Ethernet address:**

```
eth.addr == MAC-address
```

- **Communication between two hosts:**

```
ip.src == ip && ip.dst == ip
```

- **Search inside packets:**

```
http contains "passw"
```

Another tool:

**Pcredz** (works on PCAP)

```
Pcredz -f demo.pcapng -t -v
```

(Searches for domain names, etc.)
