# Credential Hunting in Network Traffic - [LINK](https://academy.hackthebox.com/app/module/147/section/3715)


বর্তমান সময়ে সিকিউরিটির কথা মাথায় রেখে বেশিরভাগ অ্যাপ্লিকেশন ডেটা আদান-প্রদানের জন্য TLS বা এনক্রিপশন (যেমন HTTPS) ব্যবহার করে। তবে সব নেটওয়ার্ক পুরোপুরি সুরক্ষিত থাকে না। অনেক পুরনো সিস্টেম (Legacy systems), ভুল কনফিগার করা সার্ভিস অথবা সাধারণ টেস্টিং অ্যাপ্লিকেশনগুলো এখনও HTTP বা SNMP এর মতো আনএনক্রিপ্টেড (Unencrypted) বা প্লেইনটেক্সট প্রোটোকল ব্যবহার করে।

হ্যাকারদের জন্য এটি একটি সুবর্ণ সুযোগ! কারণ এই প্রোটোকলগুলোতে ডেটা লুকানো থাকে না, ফলে নেটওয়ার্ক ট্রাফিক অ্যানালাইজ করে সরাসরি পাসওয়ার্ড (Cleartext credentials) চুরি করা সম্ভব। এই সেকশনে আমরা শিখব কীভাবে Wireshark এবং Pcredz ব্যবহার করে নেটওয়ার্ক ট্রাফিক থেকে পাসওয়ার্ড খুঁজে বের করতে হয়।

## সাধারণ আনএনক্রিপ্টেড বনাম এনক্রিপ্টেড প্রোটোকল

নিচের টেবিলে কিছু পরিচিত প্রোটোকলের আনএনক্রিপ্টেড এবং এনক্রিপ্টেড (নিরাপদ) ভার্সনের তালিকা দেওয়া হলো:

| আনএনক্রিপ্টেড প্রোটোকল | এনক্রিপ্টেড প্রোটোকল (নিরাপদ) | কাজের ধরন (Description) |
| --- | --- | --- |
| **HTTP** | HTTPS | ইন্টারনেটে ওয়েব পেজ এবং রিসোর্স আদান-প্রদান করতে ব্যবহৃত হয়। |
| **FTP** | FTPS / SFTP | ক্লায়েন্ট এবং সার্ভারের মধ্যে ফাইল ট্রান্সফার করার কাজে ব্যবহৃত হয়। |
| **SNMP** | SNMPv3 (এনক্রিপশন সহ) | রাউটার এবং সুইচের মতো নেটওয়ার্ক ডিভাইসগুলো মনিটর ও ম্যানেজ করতে ব্যবহৃত হয়। |
| **POP3** | POP3S | মেইল সার্ভার থেকে লোকাল ক্লায়েন্টে ইমেইল নিয়ে আসার জন্য ব্যবহৃত হয়। |
| **IMAP** | IMAPS | মেইল সার্ভারে সরাসরি ইমেইল অ্যাক্সেস এবং ম্যানেজ করতে ব্যবহৃত হয়। |
| **SMTP** | SMTPS | ক্লায়েন্ট থেকে সার্ভারে বা সার্ভারগুলোর মাঝে ইমেইল পাঠাতে ব্যবহৃত হয়। |
| **LDAP** | LDAPS | ইউজার ক্রেডেনশিয়াল এবং রোলের মতো ডিরেক্টরি সার্ভিসগুলোতে কোয়েরি বা মডিফাই করার কাজে ব্যবহৃত হয়। |
| **RDP** | RDP (TLS সহ) | উইন্ডোজ সিস্টেমে রিমোট ডেস্কটপ অ্যাক্সেস দেওয়ার জন্য ব্যবহৃত হয়। |
| **DNS** | DNS over HTTPS (DoH) | ডোমেইন নেমকে আইপি (IP) অ্যাড্রেসে রূপান্তর করে। |
| **SMB** | SMB over TLS (SMB 3.0) | নেটওয়ার্কে ফাইল, প্রিন্টার এবং অন্যান্য রিসোর্স শেয়ার করতে ব্যবহৃত হয়। |
| **VNC** | VNC (TLS/SSL সহ) | অন্য একটি কম্পিউটারকে গ্রাফিকাল ইন্টারফেসের মাধ্যমে রিমোট কন্ট্রোল করতে দেয়। |

## Wireshark (ওয়ার্কশার্ক)

Wireshark হলো অত্যন্ত জনপ্রিয় একটি প্যাকেট অ্যানালাইজার টুল, যা পেনিট্রেশন টেস্টিংয়ের জন্য তৈরি প্রায় সব লিনাক্স অপারেটিং সিস্টেমে আগে থেকেই ইনস্টল করা থাকে। এর সবচেয়ে বড় শক্তি হলো এর "ফিল্টার ইঞ্জিন", যা দিয়ে লাইভ নেটওয়ার্ক বা ক্যাপচার করা ট্রাফিক থেকে খুব সহজেই প্রয়োজনীয় ডেটা খুঁজে বের করা যায়।

### গুরুত্বপূর্ণ Wireshark ফিল্টারসমূহ:

| Wireshark ফিল্টার | কাজ (Description) |
| --- | --- |
| `ip.addr == 56.48.210.13` | শুধুমাত্র নির্দিষ্ট একটি আইপি অ্যাড্রেসের প্যাকেটগুলো ফিল্টার করে দেখায়। |
| `tcp.port == 80` | নির্দিষ্ট পোর্ট অনুযায়ী প্যাকেট ফিল্টার করে (এক্ষেত্রে HTTP পোর্ট ৮০)। |
| `http` | শুধুমাত্র HTTP ট্রাফিকগুলো ফিল্টার করে। |
| `dns` | শুধুমাত্র DNS ট্রাফিক ফিল্টার করে, যা ডোমেইন নেম রেজোলিউশন মনিটর করতে সাহায্য করে। |
| `tcp.flags.syn == 1 && tcp.flags.ack == 0` | SYN প্যাকেট ফিল্টার করে। এটি নেটওয়ার্কে স্ক্যানিং বা কানেকশন তৈরির চেষ্টা ধরতে সাহায্য করে। |
| `icmp` | ICMP (Ping) প্যাকেট ফিল্টার করে, যা রিকন (Reconnaissance) বা নেটওয়ার্ক ইস্যু খুঁজতে কাজে লাগে। |
| `http.request.method == "POST"` | শুধুমাত্র HTTP POST রিকোয়েস্টগুলো ফিল্টার করে। আনএনক্রিপ্টেড HTTP তে POST রিকোয়েস্ট গেলে তার ভেতরে পাসওয়ার্ড বা সেনসিটিভ ডেটা থাকার সম্ভাবনা থাকে। |
| `tcp.stream eq 53` | নির্দিষ্ট একটি TCP স্ট্রিম ফিল্টার করে। এটি দুটি হোস্টের মধ্যকার পুরো কথোপকথন বা ডেটা আদান-প্রদান ট্র্যাক করতে সাহায্য করে। |
| `eth.addr == 00:11:22:33:44:55` | নির্দিষ্ট একটি MAC অ্যাড্রেস থেকে আসা বা সেখানে যাওয়া প্যাকেটগুলো ফিল্টার করে। |
| `ip.src == 192.168.24.3 && ip.dst == 56.48.210.3` | নির্দিষ্ট দুটি আইপির মধ্যকার ট্রাফিক ফিল্টার করে। এটি নির্দিষ্ট দুটি হোস্টের যোগাযোগ ট্র্যাক করতে কাজে লাগে। |

### Wireshark এ নির্দিষ্ট শব্দ বা পাসওয়ার্ড খোঁজা:

নেটওয়ার্ক ট্রাফিকের ভেতর নির্দিষ্ট কোনো বাইট বা শব্দ (যেমন "password") খোঁজার দুটি সহজ উপায় আছে:
১. **ডিসপ্লে ফিল্টার ব্যবহার করে:** সার্চ বারে `http contains "passw"` লিখে এন্টার দিলে যেসব প্যাকেটে "passw" শব্দটি আছে, শুধু সেগুলোই দেখাবে।
২. **ম্যানুয়ালি খোঁজা:** মেনু বার থেকে `Edit > Find Packet` এ ক্লিক করে নির্দিষ্ট কোয়েরি (যেমন "passw") লিখে সার্চ করা যায়।

## Pcredz (পিক্রেডস)

[Pcredz](https://github.com/lgandx/PCredz) হলো এমন একটি অসাধারণ টুল যা লাইভ নেটওয়ার্ক ট্রাফিক বা সেভ করা পিস্যাপ (pcap) ফাইল থেকে স্বয়ংক্রিয়ভাবে পাসওয়ার্ড ও অন্যান্য সেনসিটিভ ডেটা বের করে আনতে পারে।

**Pcredz যেসব তথ্য বের করতে পারে:**

* ক্রেডিট কার্ড নম্বর
* POP, SMTP, IMAP এবং FTP এর ক্রেডেনশিয়াল
* SNMP কমিউনিটি স্ট্রিং
* HTTP NTLM/Basic হেডার এবং HTTP ফর্মের ক্রেডেনশিয়াল
* DCE-RPC, SMBv1/2, LDAP, MSSQL এবং HTTP থেকে NTLMv1/v2 হ্যাশ
* Kerberos হ্যাশ (AS-REQ Pre-Auth etype 23)

### Pcredz এর ব্যবহার (Usage)

Pcredz ব্যবহার করার জন্য এর গিটহাব রিপোজিটরি ক্লোন করে ডিপেন্ডেন্সিগুলো ইনস্টল করে নিতে হয়, অথবা এর ডকার (Docker) কন্টেইনার ব্যবহার করা যায়।

একটি নির্দিষ্ট প্যাকেট ক্যাপচার (pcapng) ফাইল স্ক্যান করার জন্য নিচের কমান্ডটি ব্যবহার করা হয়:

```bash
00Luffy00@htb[/htb]$ ./Pcredz -f demo.pcapng -t -v

```

**আউটপুট বিশ্লেষণ:**
কমান্ডটি রান করার পর আউটপুটে দেখা যাবে টুলটি নিজে নিজেই নেটওয়ার্ক ট্রাফিক স্ক্যান করে বিভিন্ন পাসওয়ার্ড বের করে এনেছে।
যেমন, আউটপুটে এটি একটি SNMPv2 কমিউনিটি স্ট্রিং খুঁজে পেয়েছে:
`Found SNMPv2 Community string: s3cr...`

একইভাবে এটি FTP ট্রাফিক থেকে ইউজারনেম এবং পাসওয়ার্ড সরাসরি বের করে এনেছে:
`FTP User: le...`
`FTP Pass: qw...`

**সারমর্ম:** নেটওয়ার্ক ট্রাফিক অ্যানালাইসিস করে পাসওয়ার্ড বের করা পেনিট্রেশন টেস্টিংয়ের একটি অত্যন্ত কার্যকরী ধাপ। আনএনক্রিপ্টেড প্রোটোকলগুলো হ্যাকারদের জন্য ডেটা চুরির দরজা খোলা রাখে, যা Wireshark এবং Pcredz এর মতো টুল দিয়ে খুব সহজেই কাজে লাগানো যায়।
