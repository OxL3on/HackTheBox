## Linux Authentication Process

Common authentication process:

**PAM (Pluggable Authentication Modules)**

- PAM acts as the middleman between applications and the authentication system.

PAM modules are stored in:

```
/usr/lib/x86_64-linux-gnu/security/
```

### How PAM Updates Passwords

The module **pam_unix.so** uses Linux system libraries to update user information.

It works with two files:

- `passwd`
- `shadow`

### The /etc/passwd File Has 7 Fields

```
Username : Password : UID : GID : GECOS : Home Directory : Default Shell
```

Example:

```
htb-student:x:1000:1000::/home/htb-student:/bin/bash
```

If this file is writable:

```
root::0:0:root:/root:/bin/bash
```

(No password)

### /etc/shadow - 9 Fields

```
Username : Password : Last Change : Minimum Age : Maximum Age : Warning Period : Inactivity Period : Expiration Date : Reserved
```

- If the password field contains `!` the user can't log in using a Unix password.
- Password format:

```
$id$salt$hashed
```

Many Linux distributions now use **yescrypt**.

### /etc/security/opasswd

Linux prevents users from using old passwords by storing old hashes in this file.

### Crack Linux Credentials

