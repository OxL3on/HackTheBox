## Cracking Protected Archives

Decrypt `.gpg` file if it is encrypted with OpenSSL:

```
gpg2john file.gpg > hashopenssl enc-aes-256-cbc-d-in Gzip-KG7.zip/backup1.tar.gz
```

## Cracking BitLocker Drives

BitLocker is Microsoft's full-disk encryption.

- BitLocker also generates a **48-digit recovery key**.
- Use `bitlocker2john` → `backup1.hashes` (extracts the hash).
- Extract the hash:

```
bitlocker2john backup.hashes > backup1.hash
```

- BitLocker uses **Hashcat mode 22100**.

## Mount BitLocker on Linux

```
sudo mkdir -p /media/bitlocker
```

Install BitLocker utility:

```
sudo apt install dislocker
```

Attach volume:

```
sudo -u root dislocker -V /dev/<partition> -u1234... -- /media/bitlocker
```

Mount:

```
sudo mount -o loop /media/bitlocker/dislocker-file /media/bitlocker
```

Unmount:

```
sudo umount /media/bitlocker
```
