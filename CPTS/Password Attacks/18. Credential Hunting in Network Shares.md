## Credential Hunting in Network Shares

Search for:

- Keywords
- Interesting file types/names
- Use the target's language

### Hunting from Windows

- **Basic scan:**

```
Snaffler.exe -s
```

**Windows tool:**

#### **Snaffler**

Useful parameters:

```
-u   Get all AD users
-i   Specify which shares to include
-n
```

> Needs to run on a domain-joined computer.
> 

#### Another Tool - PowerHuntShares

It's a PowerShell script.

```
Invoke-HuntSMBShares -Threads 100 -OutputDirectory C:\Users\Public
```

### Hunting from Linux

#### MANSPIDER

Searches SMB shares remotely.

```
docker run --rm -v /manspider:/root/.manspider blacklanternsecurity/manspider <ip> -c "passw" -u "mendres" -p "password"
```

Using NetExec:

```
nxc smb ip -u username -p 'password' --spider IT --content --pattern "password"
```
