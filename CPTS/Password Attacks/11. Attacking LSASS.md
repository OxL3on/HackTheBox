## Attacking LSASS

LSASS stores credentials that are currently being used in memory.

First we'll create a copy of LSASS memory & analyze it offline.

![](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/308/img/lsassexe_diagram.png)

### Method 1 - Task Manager

Open **Task Manager** → Go to **Processes** → Find **lsass.exe** → Right click → **Select Create Dump File**

Transfer this file to the attack machine.

### Method 2 - Rundll32 + comsvcs.dll

### Step 1: Find LSASS PID

In CMD:

```
tasklist /svc
```

In PowerShell:

```
Get-Process lsass
```

### Step 2: Dump LSASS

```
rundll32 C:\Windows\System32\comsvcs.dll, MiniDump PID C:\lsass.dmp full
```

If antivirus blocks it, you'll need AV bypass techniques. Then transfer the file.

### Extract Credentials with pypykatz

```
pypykatz lsa minidump lsass.dmp
```

Output can contain a section called **MSV**, which is the Windows authentication package used to validate logins against the SAM database.

### WDIGEST Section

Old Windows authentication protocol.

If WDIGEST is enabled, LSASS stores plaintext passwords.

### Kerberos Section

LSASS stores:

- Password
- Encryption keys
- Tickets
- PIN

### DPAPI Section

Pypykatz can extract DPAPI master keys.

These keys can decrypt credentials protected by DPAPI.

### Crack NT Hash

Hashcat mode **1000** (`-m 1000`)
