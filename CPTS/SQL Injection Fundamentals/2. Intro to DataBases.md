## Intro to DataBases

A DBMS is software that helps create, define, host and manage databases.

### Architecture

![](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/33/db_2.png)

The diagram shows a three-tier architecture.

1. Tier I (Client Layer)
2. Tier II (Middleware / Application Server)
    - Receives requests from Tier I.
    - Interprets and converts them into a format the DBMS understands.
    - Uses DBMS-specific libraries and drivers to communicate with the database.
3. Tier III (DBMS / Database)
    - Receives requests from Tier I, performs CRUD operations
