## **Query Results**

**Sorting Results (`ORDER BY`)**

Use **`ORDER BY`** to sort query results.

<aside>

SELECT * FROM table_name
ORDER BY column_name;

</aside>

- ASC (Ascending) : sorts from small → large

<aside>

SELECT * FROM logins
ORDER BY password ASC;

</aside>

- DESC (Descending) : sorts from large → small

<aside>

SELECT * FROM logins
ORDER BY password DESC;

</aside>

- Sorting by Multiple Columns

<aside>

SELECT * FROM table_name
ORDER BY column1 DESC, column2 ASC;

</aside>

**LIMIT Results**

Use **`LIMIT`** to return only a specific number of rows.

<aside>

SELECT * FROM table_name
LIMIT number;

</aside>

- LIMIT with OFFSET

<aside>

SELECT * FROM table_name
LIMIT offset, count;

</aside>

**WHERE Clause**

The **`WHERE`** clause filters records based on a condition.

<aside>

SELECT * FROM table_name
WHERE condition;

</aside>

You can also use `WHERE` with the **UPDATE** statement to update only specific rows.

> Note:
> 
> - Strings and dates must be enclosed in single (`'`) or double (`"`) quotes.
> - Numbers do not need quotes.

**LIKE Clause**

The **`LIKE`** clause searches for data that matches a pattern.

- `%` Wildcard : `%` matches zero or more characters.

<aside>

SELECT * FROM logins
WHERE username LIKE 'admin%';

</aside>

- `_` Wildcard : `_` matches exactly one character.

<aside>

SELECT * FROM logins
WHERE username LIKE '___';

</aside>
