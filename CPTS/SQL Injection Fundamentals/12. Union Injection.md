## **Union Injection**

**Step 1: Test for SQL Injection**

We follow the SQLi Discovery process by adding a single quote (`'`). Getting an SQL error suggests that the page may be vulnerable to SQL Injection.

**Detecting the Number of Columns**

Before using a UNION injection, we must know how many columns the original query returns. There are two methods:

1. Using `ORDER BY` : `' ORDER BY 1-- -` The extra `-` is only to show there is a space after `--` . No error means column 1 exists. Then `' ORDER BY 2-- -` No error means column 2 exists. ….. `' ORDER BY 5-- -` Error. Means columns 1-4 exist.
2. Using `UNION` : Instead of testing with `ORDER BY`, we can keep changing the number of columns in a UNION query until it succeeds. Try 3 column : `cn' UNION SELECT 1,2,3-- -` (The column count is incorrect.). Try 4 Columns : `cn' UNION SELECT 1,2,3,4-- -` . The page displays:
    
    2
    3
    4
    
    Success! This confirms that the original query also has **4 columns**.

    #### Finding the Injection Location
    
    Knowing the number of columns is not enough. Even if a query returns several columns, the web application may only display some of them. If our injected data goes into a column that is not displayed, we won't see the output. So we must determine which columns are visible on the page.
    
    - Using numbers (`1,2,3,4`) helps identify which columns are visible.
    - In this example, columns 2, 3, and 4 are displayed, while column 1 is not.
    - `@@version` is commonly used to confirm that real database data can be retrieved through a visible column.
    - Once you know the column count and visible columns, you can begin extracting data from other tables and databases using UNION-based SQL Injection.
