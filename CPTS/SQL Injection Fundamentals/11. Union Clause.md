## **Union Clause**

The SQL UNION clause combines the results of multiple `SELECT` statements into one result. UNION-based SQLi allows attackers to retrieve data from other tables and databases.

**Combining Both Tables with UNION**

**Table 1 :** SELECT * FROM ports;

**Table 2 :** SELECT * FROM ships;

**Combine :** 

SELECT * FROM ports
UNION
SELECT * FROM ships;

**Even Number of Columns**

A `UNION` query only works if both SELECT statements return the same number of columns.

**Filling Extra Columns with Junk Data**

We fill unused columns with dummy values ("junk data"). 

SELECT username, 2
FROM passwords;

Use numbers or `NULL`. `NULL` works with almost every data type, making it very useful.

EX : (with 4 columns)

UNION
SELECT username, 2, 3, 4
FROM passwords-- -

`select * from employees union select *,2,3,4,5 from departments;`
