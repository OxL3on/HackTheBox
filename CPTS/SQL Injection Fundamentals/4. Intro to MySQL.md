## **Intro to MySQL**

### Structured Query Language (SQL)

Used to communicate with relational databases. All different RDBMS follow the ISO SQL standard

**MySQL Command Line**

<aside>
💡

mysql -u root -p

</aside>

- To connect to a remote database:

<aside>
💡

mysql -u root -h docker.hackthebox.eu -P 3306 -p

</aside>

- User Privileges

<aside>
💡

SHOW GRANTS;

</aside>

- Creating a Database

<aside>

CREATE DATABASE users;

</aside>

- Show Databases

<aside>

SHOW DATABASES;

</aside>

- Select a Database

<aside>

USE users;

</aside>

**Tables**

Databases store data in tables. It contains rows, columns, cell. Common datatypes : INT, VARCHAR, DATE, DATETIME, TIME, BINARY etc.

- Creating a Table

<aside>

CREATE TABLE logins (
id INT,
username VARCHAR(100),
password VARCHAR(100),
date_of_joining DATETIME
);

</aside>

- Show Tables

<aside>

SHOW TABLES;

</aside>

- Describe a Table

<aside>

DESCRIBE logins;

</aside>

**Table Properties (Constraints)**

1. AUTO_INCREMENT : Automatically increases the value by **1** whenever a new row is added.

<aside>

id INT NOT NULL AUTO_INCREMENT

</aside>

1. NOT NULL : The column cannot be empty. It is a required field.

<aside>

password VARCHAR(100) NOT NULL

</aside>

1. UNIQUE : Ensures every value is unique.

<aside>

username VARCHAR(100) UNIQUE NOT NULL

</aside>

1. DEFAULT : If no value is provided, MySQL automatically uses.

<aside>

date_of_joining DATETIME DEFAULT NOW()

</aside>

1. PRIMARY KEY : A Primary Key uniquely identifies each row in a table.

<aside>

PRIMARY KEY (id)

</aside>
