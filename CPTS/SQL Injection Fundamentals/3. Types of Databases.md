## **Types of Databases**

Databases are mainly divided into **two types**:

### 1. Relational Databases (SQL)

It uses a **schema** (a blueprint/template) that defines how data is organized. Instead of storing everything in one place, it uses different tables.

**Tables and Keys :** Each table contains related data and has one or more keys. A key uniquely identifies data and helps connect tables.

**Schema** : The relationship between tables in a relational database is called a Schema. The schema defines how tables are connected.

### 2. Non-Relational Databases

It stores data using different storage models like Key-Value, Document-Based, Wide-Column, Graph.

Example : NoSQL dB
