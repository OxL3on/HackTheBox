## **Subverting Query Logic**

Before trying to bypass login, we must check if the application is vulnerable to SQL Injection. A simple test is to insert special characters into the username field.

| Payload | URL Encoded |
| --- | --- |
| `'` | `%27` |
| `"` | `%22` |
| `#` | `%23` |
| `;` | `%3B` |
| `)` | `%29` |

![](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/33/or_inject_diagram.png)

The extra `'` creates an **odd number of quotes**. **`OR`** and **`AND`** injection.
