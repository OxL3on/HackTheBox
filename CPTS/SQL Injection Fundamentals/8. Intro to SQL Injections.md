## **Intro to SQL Injections**

**What is Sanitization? :** Sanitization means removing or escaping special characters from user input so they cannot be interpreted as code. Without sanitization, attackers can inject malicious SQL commands.

**What is an Injection? :** An Injection happens when an application treats user input as code instead of plain text, allowing the attacker to change how the program works.

**What is SQL Injection? :** SQL Injection happens when user input is directly inserted into an SQL query without proper sanitization or filtering.

### Types of SQL Injection

![](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/33/types_of_sqli.jpg)

### 1. In-Band SQL Injection

The query results are displayed directly on the web page.

**a) Union-Based SQL Injection :** Uses the `UNION` statement. Requires knowing which column's output is visible. Sends the injected data to that visible column.

**b) Error-Based SQL Injection :** Works when SQL or PHP error messages are shown. The attacker intentionally causes database errors. The error message leaks useful information.

### 2. Blind SQL Injection

The application does not display query results directly. Instead, attackers retrieve data one character at a time.

**a) Boolean-Based SQL Injection :** Uses SQL conditions. If the condition is:

- **True** → the page behaves normally.
- **False** → the page behaves differently.

Attackers use these differences to extract data.

**b) Time-Based SQL Injection :** Also uses SQL conditions. If the condition is true, functions like:

```
SLEEP()
```

delay the response. The response time tells the attacker whether the condition is true or false.

### 3. Out-of-Band SQL Injection

Used when there is **no direct output** from the database. Instead, the attacker sends the data to another location, such as:

- DNS requests
- Other remote servers

The attacker then retrieves the data from that external location.
