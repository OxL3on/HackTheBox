## **SQL Statements**

**INSERT Statement**

The INSERT statement is used to add new records to a table.

<aside>

INSERT INTO table_name VALUES (column1_value, column2_value, column3_value, ...);

</aside>

- Insert Multiple Records:

<aside>

INSERT INTO logins(username, password)
VALUES
('john', 'john123!'),
('tom', 'tom123!');

</aside>

**SELECT Statement**

The SELECT statement is used to retrieve data from a table.

- Select all columns:

<aside>

SELECT * FROM table_name;

</aside>

- Select Specific Columns:

<aside>

SELECT column1, column2
FROM table_name;

</aside>

**DROP Statement**

The DROP statement is used to delete tables or databases.

<aside>

DROP TABLE logins;

</aside>

**ALTER Statement**

The ALTER statement is used to modify an existing table.

- Add a Column:

<aside>

ALTER TABLE logins
ADD newColumn INT;

</aside>

- Rename a Column:

<aside>

ALTER TABLE logins
RENAME COLUMN newColumn TO newerColumn;

</aside>

- Change Data Type:

<aside>

ALTER TABLE logins
MODIFY newerColumn DATE;

</aside>

- Delete a Column:

<aside>

ALTER TABLE logins
DROP newerColumn;

</aside>

**UPDATE Statement**

The UPDATE statement is used to modify existing records in a table. UPDATE changes the data inside the table.

<aside>

UPDATE table_name
SET column1 = newvalue1,
column2 = newvalue2,
...
WHERE <condition>;

</aside>
