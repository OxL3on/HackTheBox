# Staff - [LINK](https://academy.hackthebox.com/app/module/112/section/1065)

## Introduction

Social media platform-গুলোতে কোম্পানির employees-দের (কর্মকর্তা/কর্মচারীদের) খুঁজে বের করা এবং তাদের আইডেন্টিফাই করার মাধ্যমে কোম্পানির teams, infrastructure এবং makeup সম্পর্কে অনেক গুরুত্বপূর্ণ তথ্য পাওয়া যেতে পারে। এর মাধ্যমে আমরা জানতে পারি তারা কোন technologies, programming languages এবং software applications ব্যবহার করছে।

Employees-দের skills-এর ওপর ভিত্তি করে তাদের কাজের মূল ফোকাস (focus) সম্পর্কেও আমরা ধারণা পেতে পারি। তারা অন্যদের সাথে যেসব posts এবং materials শেয়ার করে, তা থেকে বোঝা যায় বর্তমানে তারা কোন প্রজেক্টে যুক্ত আছে এবং কোন বিষয়গুলোকে তারা গুরুত্বপূর্ণ মনে করছে।

## Sources for Staff Enumeration

Employees-দের সাধারণত বিভিন্ন business networks, যেমন:

* **LinkedIn**
* **Xing**

ইত্যাদি প্ল্যাটফর্ম থেকে আইডেন্টিফাই করা যায়। এছাড়া, কোম্পানির Job postings (চাকরির বিজ্ঞাপন) থেকে তাদের infrastructure সম্পর্কে অনেক তথ্য পাওয়া যায় এবং আমাদের ঠিক কী খোঁজা উচিত, তার কিছু clues পাওয়া যায়।

## Job Post Analysis (চাকরির বিজ্ঞাপন বিশ্লেষণ)

নিচে LinkedIn-এ প্রকাশিত একটি job post-এর উদাহরণ দেওয়া হলো:

```txt
Required Skills/Knowledge/Experience:

* 3-10+ years of experience on professional software development projects.

« An active US Government TS/SCI Security Clearance (current SSBI) or eligibility to obtain TS/SCI within nine months.
« Bachelor's degree in computer science/computer engineering with an engineering/math focus or another equivalent field of discipline.
« Experience with one or more object-oriented languages (e.g., Java, C#, C++).
« Experience with one or more scripting languages (e.g., Python, Ruby, PHP, Perl).
« Experience using SQL databases (e.g., PostgreSQL, MySQL, SQL Server, Oracle).
« Experience using ORM frameworks (e.g., SQLAIchemy, Hibernate, Entity Framework).
« Experience using Web frameworks (e.g., Flask, Django, Spring, ASP.NET MVC).
« Proficient with unit testing and test frameworks (e.g., pytest, JUnit, NUnit, xUnit).
« Service-Oriented Architecture (SOA)/microservices & RESTful API design/implementation.
« Familiar and comfortable with Agile Development Processes.
« Familiar and comfortable with Continuous Integration environments.
« Experience with version control systems (e.g., Git, SVN, Mercurial, Perforce).

Desired Skills/Knowledge/ Experience:

« CompTIA Security+ certification (or equivalent).
« Experience with Atlassian suite (Confluence, Jira, Bitbucket).
« Algorithm Development (e.g., Image Processing algorithms).
« Software security.
« Containerization and container orchestration (Docker, Kubernetes, etc.)
« Redis.
« NumPy.

```

**What we learn from this job post:**

এই ধরনের একটি job post বিশ্লেষণ করে আমরা কোম্পানির ব্যবহৃত প্রযুক্তি সম্পর্কে ধারণা পেতে পারি:

* **Preferred Programming Languages:** Java, C#, C++, Python, Ruby, PHP, Perl
* **Databases:** PostgreSQL, MySQL, Oracle
* **Web Frameworks:** Flask, Django, ASP.NET, Spring
* **Tools & Architecture:** REST APIs, Github, SVN, Perforce, Atlassian Suite (Confluence, Jira, Bitbucket)

যেহেতু কোম্পানি Atlassian Suite নিয়ে কাজ করে, তাই আমরা এমন কিছু resources-এর সন্ধান পেতে পারি যেখানে সম্ভাব্যভাবে আমাদের অ্যাক্সেস পাওয়ার সুযোগ থাকতে পারে। Employees-দের career history থেকে তাদের skills এবং projects বিশ্লেষণ করে তাদের জ্ঞানের পরিধি সম্পর্কে একটি ভালো অনুমান করা সম্ভব।

## Analyzing Employee Profiles

### LinkedIn - Employee #1 About

Social media সাইটগুলোতে business contacts তৈরি করার জন্য মানুষ তাদের skills প্রদর্শন করে। এর ফলে তারা এযাবৎ যা শিখেছে এবং জানে, তা অবধারিতভাবেই পাবলিকের সাথে শেয়ার করে ফেলে।

কোম্পানিগুলো সাধারণত এমন employees-দের নিয়োগ দেয়, যাদের skills তারা তাদের ব্যবসায় কাজে লাগাতে পারে। উদাহরণস্বরূপ, আমরা জানি যে **Flask** এবং **Django** হলো Python programming language-এর web frameworks।

যদি আমরা "Django security misconfigurations" লিখে একটু search করি, তবে আমরা এমন একটি Github repository খুঁজে পেতে পারি যা "OWASP Top10 for Django" বর্ণনা করে। এটি ব্যবহার করে আমরা Django-এর inner structure এবং এটি কীভাবে কাজ করে তা বুঝতে পারি।

এছাড়া, best practices প্রায়শই আমাদের বলে দেয় কী খুঁজতে হবে। কারণ অনেকেই অন্ধভাবে best practices বিশ্বাস করে এবং instructions-এ দেখানো নামের মতোই তাদের file-গুলোর নাম রাখে।

### The Dangers of Public Projects

নিজের projects প্রদর্শন করা নতুন business contacts তৈরি করতে এবং চাকরি পাওয়ার ক্ষেত্রে দারুণ সহায়ক হতে পারে। কিন্তু অন্যদিকে, এটি এমন কিছু ভুলের কারণ হতে পারে যা ঠিক করা খুবই কঠিন।

উদাহরণস্বরূপ (Github-এর মতো প্ল্যাটফর্মে):

* কোনো একটি ফাইলের ভেতরে employee-এর personal email address পাওয়া যেতে পারে।
* আরও গভীরভাবে investigation করলে, web application-এর ভেতরে **hardcoded JWT token**-ও পাওয়া যেতে পারে।

### LinkedIn - Employee #2 Career

LinkedIn-এ employees খোঁজার জন্য একটি comprehensive search সুবিধা রয়েছে। এখানে নিচের criteria অনুযায়ী filter করা যায়:

* Connections
* Locations
* Companies
* School
* Industry
* Profile language
* Services
* Names
* Titles এবং আরও অনেক কিছু।

আমরা যত বেশি detailed information দিয়ে search করব, তত কম results পাব। তাই search করার উদ্দেশ্য সম্পর্কে আমাদের আগেই ভালোভাবে চিন্তা করে নেওয়া উচিত।

**Targeting for Infrastructure and Security Info:**

ধরা যাক, আমরা কোম্পানির ব্যবহৃত infrastructure এবং technology খুঁজে বের করতে চাই। সেক্ষেত্রে আমাদের এমন technical employees-দের খোঁজা উচিত, যারা **development** এবং **security** উভয় ক্ষেত্রেই কাজ করে।

কারণ, security area এবং সেই area-তে কাজ করা employees-দের profile বিশ্লেষণ করে আমরা নির্ধারণ করতে পারব কোম্পানি নিজেদের সুরক্ষিত রাখার জন্য কী ধরনের **security measures** গ্রহণ করেছে।
