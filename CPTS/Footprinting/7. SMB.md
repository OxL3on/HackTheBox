## 1. SMB কী?

SMB (Server Message Block) হলো একটি `client-server protocol`, যা network-এর মাধ্যমে file, directory, printer ও অন্যান্য resource share করতে ব্যবহৃত হয়।

- Client: Shared resource access করে।
- Server: Resource ও permission নিয়ন্ত্রণ করে।
- ACL (Access Control List): কোন user কী করতে পারবে তা নির্ধারণ করে।

| Permission    | কাজ                        |
| ------------- | -------------------------- |
| `Read`        | File পড়া                  |
| `Execute`     | অনুমোদিত executable চালানো |
| `Full access` | সম্পূর্ণ access            |
| `Write`       | File তৈরি বা পরিবর্তন      |

মনে রাখবে: Share permission ও filesystem permission আলাদা। দুটিই access সীমিত করতে পারে।

Reference: [Microsoft SMB Protocol](https://docs.microsoft.com/en-us/openspecs/windows_protocols/ms-smb/f210069c-7086-4dc2-885e-861d837df688?utm_source=chatgpt.com)

## 2. SMB Versions, Ports ও Samba

Samba: Linux/Unix-এ SMB protocol ব্যবহার করে Windows-এর সঙ্গে file sharing করার software implementation।

CIFS (Common Internet File System): SMB-এর পুরোনো dialect, মূলত SMB1-এর সঙ্গে সম্পর্কিত।

### গুরুত্বপূর্ণ Ports

| Port      | ব্যবহার                  |
| --------- | ------------------------ |
| `TCP 139` | SMB over NetBIOS         |
| `TCP 445` | Direct SMB over TCP      |
| `UDP 137` | NetBIOS Name Service     |
| `UDP 138` | NetBIOS Datagram Service |

### SMB Versions

| Version  | গুরুত্বপূর্ণ বৈশিষ্ট্য               |
| -------- | ------------------------------------ |
| SMB1     | পুরোনো protocol; security risk বেশি  |
| SMB2     | Performance উন্নত                    |
| SMB2.1   | উন্নত locking                        |
| SMB3     | Multichannel ও encryption            |
| SMB3.1.1 | উন্নত integrity ও encryption support |

### Samba Daemons

- `smbd` — SMB file ও printer sharing পরিচালনা করে।
- `nmbd` — NetBIOS name service ও browsing পরিচালনা করে।

### অন্যান্য Terms

- Workgroup: Network computer-এর একটি group।
- NetBIOS: Network communication-এর পুরোনো API।
- NBNS: NetBIOS name register ও resolve করে।
- WINS: NetBIOS name resolution-এর Windows service।

## 3. Samba Configuration

Configuration file:

```
/etc/samba/smb.conf
```

Comment ও semicolon-যুক্ত line বাদ দিয়ে দেখতে:

```
cat /etc/samba/smb.conf | grep -v "#\|\;"
```

### গুরুত্বপূর্ণ Parameters

| Parameter                      | কাজ                                                             |
| ------------------------------ | --------------------------------------------------------------- |
| `[sharename]`                  | Share-এর নাম                                                    |
| `workgroup`                    | Workgroup/domain নির্ধারণ                                       |
| `path`                         | Local directory-এর path                                         |
| `browseable = yes`             | Share list-এ দেখা যায়                                          |
| `guest ok = yes`               | Guest access অনুমোদন                                            |
| `read only = no`               | Write access অনুমোদিত হতে পারে                                  |
| `writable = yes`               | File লেখা ও পরিবর্তন করা যায়                                   |
| `create mask = 0777`           | নতুন file-এর permission mask                                    |
| `directory mask = 0777`        | নতুন directory-এর permission mask                               |
| `map to guest = bad user`      | Invalid username-কে guest হিসেবে map করতে পারে                  |
| `usershare allow guests = yes` | Guest-দের usershare access অনুমোদন করে                          |
| `logon script`                 | Login-এর সময় ব্যবহৃত script configuration                      |
| `magic script`                 | নির্দিষ্ট Samba functionality-তে script execution configuration |

### Risky Configuration Example

```
[notes]
    comment = CheckIT
    path = /mnt/notes/
    browseable = yes
    read only = no
    writable = yes
    guest ok = yes
    enable privileges = yes
    create mask = 0777
    directory mask = 0777
```

সম্ভাব্য ঝুঁকি:

- `guest ok = yes` → Password ছাড়া access সম্ভব হতে পারে।
- `writable = yes` → File পরিবর্তন করা সম্ভব হতে পারে।
- `0777` → Owner, group ও others-এর জন্য বিস্তৃত permission mask।
- `browseable = yes` → Share discover করা যায়।

কার্যকর access server-এর filesystem permission ও অন্যান্য security control-এর ওপরও নির্ভর করে।

Configuration পরিবর্তনের পর:

```
sudo systemctl restart smbd
```

Reference: [smb.conf Manual](https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html?utm_source=chatgpt.com)

## 4. Anonymous Access ও smbclient

Null Session: Empty username/password দিয়ে SMB session স্থাপনের চেষ্টা। Server অনুমতি দিলেই কেবল access পাওয়া যাবে।

### Share Enumeration

```
smbclient -N -L //10.129.14.128
```

| Option | কাজ                              |
| ------ | -------------------------------- |
| `-N`   | Password prompt ছাড়া চেষ্টা করে |
| `-L`   | Available share list দেখায়      |
| `//IP` | Target SMB server                |

Example output:

```
Sharename       Type      Comment
---------       ----      -------
print$          Disk      Printer Drivers
home            Disk      INFREIGHT Samba
dev             Disk      DEVenv
notes           Disk      CheckIT
IPC$            IPC       IPC Service
```

- `print$` — Printer drivers।
- `IPC$` — Inter-process communication।
- Share list-এ নাম দেখা মানেই file access পাওয়া নয়।

### Share-এ Connect করা

```
smbclient //10.129.14.128/notes
```

Connection-এর পরে:

```
help
ls
cd directory
pwd
get prep-prod.txt
mget *.txt
put file.txt
mput *.txt
mkdir test
rmdir test
del file.txt
rename old.txt new.txt
exit
```

| Command               | কাজ                                    |
| --------------------- | -------------------------------------- |
| `ls`, `dir`           | Remote file list                       |
| `cd`, `pwd`           | Directory পরিবর্তন ও current path দেখা |
| `get`                 | Remote থেকে local-এ download           |
| `mget`                | একাধিক file download                   |
| `put`, `mput`         | Local থেকে remote-এ upload             |
| `mkdir`, `rmdir`      | Directory তৈরি ও মুছে ফেলা             |
| `del`, `rm`           | File মুছে ফেলা                         |
| `rename`              | File rename                            |
| `chmod`               | সমর্থিত ক্ষেত্রে permission পরিবর্তন   |
| `getfacl`, `showacls` | ACL-সংক্রান্ত তথ্য                     |
| `help`                | Command list                           |
| `!ls`, `!cat`         | Local machine-এ command চালানো         |

Example:

```
smb: \> ls
smb: \> get prep-prod.txt
smb: \> !ls
smb: \> !cat prep-prod.txt
```

মনে রাখবে: `!cat` local machine-এ downloaded file পড়ে, remote server-এ নয়।

### Active SMB Connections

```
smbstatus
```

এটি server-এর active sessions, username, client IP, share ও protocol version দেখাতে পারে।

গুরুত্বপূর্ণ fields: `Username`, `Machine`, `Service`, `Protocol Version`, `Encryption`, `Signing`।

## 5. SMB Footprinting — Nmap

Footprinting: Target service-এর version, configuration, shares ও অন্যান্য তথ্য সংগ্রহ করা।

```
sudo nmap 10.129.14.128 -sV -sC -p139,445
```

| Option      | কাজ                               |
| ----------- | --------------------------------- |
| `sudo`      | Elevated privilege দিয়ে চালায়   |
| `-sV`       | Service version শনাক্ত করে        |
| `-sC`       | Default NSE scripts চালায়        |
| `-p139,445` | নির্দিষ্ট দুইটি TCP port scan করে |

Example output:

```
139/tcp open  netbios-ssn Samba smbd 4.6.2
445/tcp open  netbios-ssn Samba smbd 4.6.2

smb2-security-mode:
  Message signing enabled but not required
```

এখান থেকে বোঝা যায়:

- Port `139` ও `445` open।
- Samba version `4.6.2` হিসেবে শনাক্ত হয়েছে।
- SMB message signing enabled, কিন্তু বাধ্যতামূলক নয়।

SMB Signing: SMB message-এর integrity যাচাই করতে সাহায্য করে। Signing required না হলে কিছু পরিস্থিতিতে SMB relay attack-এর ঝুঁকি বাড়তে পারে; তবে এই output একাই vulnerability প্রমাণ করে না।

## 6. rpcclient — RPC Enumeration

RPC (Remote Procedure Call): Network-এর মাধ্যমে অন্য system-এ procedure/function call করার পদ্ধতি।

`rpcclient` ব্যবহার করে server, domain, share, user ও group information enumerate করা যায়।

Connection:

```
rpcclient -U "" 10.129.14.128
```

`-U ""` — Empty username দিয়ে connection করার চেষ্টা।

### গুরুত্বপূর্ণ Queries

| Query                   | কাজ                            |
| ----------------------- | ------------------------------ |
| `srvinfo`               | Server information             |
| `enumdomains`           | Domain enumerate               |
| `querydominfo`          | Domain ও server information    |
| `netshareenumall`       | সব share enumerate             |
| `netsharegetinfo notes` | নির্দিষ্ট share-এর information |
| `enumdomusers`          | Domain user list               |
| `queryuser 0x3e9`       | RID দিয়ে user information     |
| `querygroup 0x201`      | RID দিয়ে group information    |
| `querydispinfo`         | User display information       |

Reference: [rpcclient Manual](https://www.samba.org/samba/docs/current/man-html/rpcclient.1.html?utm_source=chatgpt.com)

### Example Queries

```
rpcclient $> srvinfo
rpcclient $> enumdomains
rpcclient $> querydominfo
rpcclient $> netshareenumall
rpcclient $> netsharegetinfo notes
rpcclient $> enumdomusers
rpcclient $> queryuser 0x3e9
rpcclient $> querygroup 0x201
```

### Share ACL Terms

- ACL: Access Control List।
- DACL: Discretionary Access Control List; কার access থাকবে তা নির্ধারণ করে।
- ACE: Access Control Entry; ACL-এর একটি entry।
- SID: Security Identifier; security principal শনাক্ত করে।
- `S-1-1-0` — `Everyone` group-এর SID।
- `WRITE_DAC_ACCESS` — DACL পরিবর্তনের permission।
- `WRITE_OWNER_ACCESS` — Object-এর owner পরিবর্তনের permission।
- `DELETE_ACCESS` — Object মুছে ফেলার permission।

### User ও RID

Example:

```
user:[mrb3n] rid:[0x3e8]
user:[cry0l1t3] rid:[0x3e9]
```

| Username   | RID     |
| ---------- | ------- |
| `mrb3n`    | `0x3e8` |
| `cry0l1t3` | `0x3e9` |

RID (Relative Identifier): একটি domain/authority-এর মধ্যে user বা অন্য security object শনাক্ত করতে ব্যবহৃত ID-এর অংশ।

User details:

```
queryuser 0x3e9
```

গুরুত্বপূর্ণ fields:

| Field                    | অর্থ                             |
| ------------------------ | -------------------------------- |
| `User Name`              | Username                         |
| `Home Drive`             | User home path                   |
| `Profile Path`           | User profile path                |
| `Password last set Time` | Password সর্বশেষ পরিবর্তনের সময় |
| `user_rid`               | User-এর RID                      |
| `group_rid`              | Primary group-এর RID             |
| `bad_password_count`     | Bad-password counter             |
| `logon_count`            | Logon counter                    |
| `acb_info`               | Account control information      |

Group details:

```
querygroup 0x201
```

Example:

```
Group Name: None
Description: Ordinary Users
Num Members: 2
```

## 7. RID Brute-Forcing

সব user সরাসরি enumerate করা না গেলে, অনুমতি থাকলে সম্ভাব্য RID range পরীক্ষা করে user information খোঁজা যায়।

```
for i in $(seq 500 1100); do
  rpcclient -N -U "" 10.129.14.128 \
  -c "queryuser 0x$(printf '%x\n' $i)" |
  grep "User Name\|user_rid\|group_rid" && echo ""
done
```

কীভাবে কাজ করে:

- `seq 500 1100` — Integer range তৈরি করে।
- `printf '%x\n'` — Decimal-কে hexadecimal-এ রূপান্তর করে।
- `queryuser` — প্রতিটি RID-এর user information চায়।
- `grep` — নির্দিষ্ট field filter করে।
- `&& echo ""` — সফল output-এর পরে blank line দেয়।

Example result:

| Username    | RID     | Group RID |
| ----------- | ------- | --------- |
| `sambauser` | `0x1f5` | `0x201`   |
| `mrb3n`     | `0x3e8` | `0x201`   |
| `cry0l1t3`  | `0x3e9` | `0x201`   |

সব RID valid নয়; server-এর restrictions-এর কারণে কিছু query ব্যর্থ হতে পারে।

### 8.2 SMBMap

SMB shares ও permissions enumerate করার tool।

```
smbmap -H 10.129.14.128
```

`-H` — Target host নির্ধারণ করে।

Possible results:

- `READ` — পড়তে পারে।
- `WRITE` — লিখতে পারে।
- `NO ACCESS` — বর্তমান connection context-এ access পাওয়া যায়নি।

Link: [SMBMap GitHub](https://github.com/ShawnDEvans/smbmap?utm_source=chatgpt.com)

### 8.3 CrackMapExec

SMB enumeration ও security testing-এর tool।

```
crackmapexec smb 10.129.14.128 --shares -u '' -p ''
```

| Option     | কাজ             |
| ---------- | --------------- |
| `smb`      | SMB protocol    |
| `--shares` | Share enumerate |
| `-u ''`    | Empty username  |
| `-p ''`    | Empty password  |

Example:

```
Share     Permissions

```

Link: [CrackMapExec GitHub](https://github.com/byt3bl33d3r/CrackMapExec?utm_source=chatgpt.com)

গুরুত্বপূর্ণ: SMBMap-এ `NO ACCESS` এবং CrackMapExec-এ `READ,WRITE` আসতে পারে। Authentication context ও enumeration method ভিন্ন হওয়ায় output আলাদা হতে পারে। তাই manual verification জরুরি।

| Field                        | অর্থ                                    |

Source-এর example:

```

DOMAIN_PASSWORD_COMPLEX: false
lockout_observation_window: 30 minutes

lockout_threshold: None
```

Security implication: ছোট minimum password length ও disabled complexity policy দুর্বল password policy-এর ইঙ্গিত হতে পারে। তবে enumeration output-এর সঙ্গে বাস্তব configuration যাচাই করা উচিত।

### Enum4linux-ng-এর আরও কিছু গুরুত্বপূর্ণ Terms

- `DEVSMB` — NetBIOS computer name।
- `DEVOPS` — Example domain/workgroup name।
- `FQDN` — Fully Qualified Domain Name।
- `SMB dialect` — SMB protocol-এর নির্দিষ্ট version।
- `ACB` — Account Control information।

## 10. গুরুত্বপূর্ণ Windows ও Domain Terms
