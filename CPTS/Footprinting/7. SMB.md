## **SMB**

SMB (Server Message Block) is a client-server protocol used to access and share. SMB is primarily used by Windows, but Linux and Unix systems can also use it through **Samba**.

### How SMB Works

SMB allows a client to communicate with another system on the network to access shared resources. Before communication begins:

1. Client and server establish a connection.
2. They exchange SMB messages.
3. Data transfer begins.

SMB uses TCP, so it relies on the TCP three-way handshake before communication starts.

**SMB Shares :** An SMB server can share: Entire folders , Parts of the filesystem. These shared folders are called shares.

**Access Control Lists (ACLs) :** Access permissions are controlled using ACLs (Access Control Lists)**.**

### Samba

Allows Linux ↔Windows communication and vice versa. Samba implements **CIFS (Common Internet File System).**  CIFS is a dialect of SMB, closely related to SMB Version 1. Thats why samba is often called SMB/CIFS.

**Ports Used**

**SMB1 / NetBIOS** Uses: TCP 137 , TCP 138 , TCP 139

**CIFS / Modern SMB** Uses: TCP 445

Samba uses background services (daemons) : smbd (Provides file sharing, printer sharing etc). nmbd (Provides NetBIOS services, Name resolution)

**Workgroups**

All SMB hosts belong to a: Workgroup . A workgroup is simply a name identifying a collection of computers and shared resources.

**NetBIOS**

IBM created NetBIOS (Network Basic Input/Output System). It allows computers to: Discover each other , Share information. When a computer joins the network, it must register its hostname. This can happen by:

- Registering its own hostname.
- Using a NetBIOS Name Server (NBNS).

NBNS later evolved into: **WINS (Windows Internet Name Service).**

**Default Samba Configuration**

**Configuration file: `/etc/samba/smb.conf`**

Important Samba Settings:

| Setting | Purpose |
| --- | --- |
| `[sharename]` | Share name |
| `workgroup` | Workgroup/domain |
| `path` | Shared directory |
| `server string` | Server description |
| `unix password sync=yes` | Sync UNIX and SMB passwords |
| `usershare allow guests=yes` | Allow guest access |
| `map to guest=bad user` | Invalid users become guests |
| `browseable=yes` | Show share during enumeration |
| `guest ok=yes` | Allow anonymous access |
| `read only=yes` | Read-only share |
| `create mask=0700` | Permissions for new files |

Dangerous Settings:

| Setting | Risk |
| --- | --- |
| `browseable=yes` | Anyone can list shares |
| `read only=no` | Files can be modified |
| `writable=yes` | Users can upload/change files |
| `guest ok=yes` | Anonymous access |
| `enable privileges=yes` | Honors special privileges |
| `create mask=0777` | New files become world-readable/writable |
| `directory mask=0777` | Directories become world-accessible |
| `logon script=script.sh` | Executes login script |
| `magic script=script.sh` | Executes script when closed |
| `magic output=script.out` | Output location |

**Restart Samba : `sudo systemctl restart smbd`**

**Enumerating Shares with smbclient : `smbclient -N -L //<IP>`**

**Connect to a Share : `smbclient //<IP>/notes`**

**Useful smbclient Commands :** help, ls, dir, cd, pwd, get, put, mkdir, rm, exit

Run Local Commands: `!ls` Commands beginning with **!** run locally, not on the SMB server.

**Administrative View :** Administrators can view active SMB connections using: `smbstatus`

### Footprinting SMB

- **Connect anonymously: `rpcclient -U "" <IP>`**

| Command | Purpose |
| --- | --- |
| srvinfo | Server information |
| enumdomains | List domains |
| querydominfo | Domain/server information |
| netshareenumall | List shares |
| netsharegetinfo | Share details |
| enumdomusers | List users |
| queryuser | User information |
| querygroup | Group Information |
