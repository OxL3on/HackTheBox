# Linux Remote Management Protocols - [LINK](https://academy.hackthebox.com/app/module/112/section/1240)

Linux remote management protocols provide administrative access but frequently present critical attack vectors due to misconfigurations, legacy implementations, or weak authentication.

## Secure Shell (SSH)

Operates on **TCP Port 22** and provides encrypted remote management. SSH-2 is the secure modern standard; SSH-1 is vulnerable to MITM attacks.

* **Authentication Methods:** Password, Public-key (most secure; uses unique public/private key pairs), Host-based, Keyboard, Challenge-response, GSSAPI.
* **Reconnaissance:** Use `ssh-audit` to fingerprint the server, identify the OpenSSH version, and find weak encryption algorithms (e.g., CVE-2020-14145). Use `ssh -v <user>@<IP>` to view allowed authentication methods.

**Dangerous Configurations (`/etc/ssh/sshd_config`)**

| Setting | Security Implication |
| --- | --- |
| `PasswordAuthentication yes` | Allows brute-force attacks on user passwords. |
| `PermitEmptyPasswords yes` | Allows logins for accounts with no password set. |
| `PermitRootLogin yes` | Allows direct, remote administrative access. |
| `Protocol 1` | Enforces outdated, vulnerable encryption. |
| `X11Forwarding yes` | Allows GUI forwarding (historically vulnerable to command injection). |
| `AllowTcpForwarding yes` | Enables port forwarding and tunneling through the host. |

## Rsync

A fast delta-transfer tool for backups and file copying, operating on **TCP Port 873**. It can transfer data unencrypted or tunnel through SSH (`-e ssh`).

* **Identify Open Shares:** Connect via netcat to view available modules.
`nc -nv <IP> 873` ➔ Type `#list` when connected.
* **Enumerate a Share:** List files within a specific share without downloading them.
`rsync -av --list-only rsync://<IP>/<share_name>`
* **Exploitation:** If a share (e.g., containing `.ssh` keys or `secrets.yaml`) is accessible without authentication, download all contents to your attack host using:
`rsync -av rsync://<IP>/<share_name>`

## R-Services

A legacy suite of remote access programs (Ports **512, 513, 514 TCP**) that transmit data and passwords in **clear text**.

**Authentication Bypass (Trust Files)**
R-services can bypass standard PAM authentication by relying on trusted IP/Hostname entries in `/etc/hosts.equiv` (global) or `.rhosts` (per-user).

* **Syntax:** `<username> <ip_address>`
* **Wildcard Misconfiguration:** A `+` symbol acts as a wildcard. An entry like `+ 10.0.17.10` allows any user from that IP to authenticate without credentials.

**Abused R-Commands**

| Command | Daemon | Port / Proto | Description |
| --- | --- | --- | --- |
| **rcp** | rshd | 514 / TCP | Remote copy (bidirectional). Overwrites files without warning. |
| **rsh** | rshd | 514 / TCP | Remote shell. Opens a shell without a login prompt based on trust files. |
| **rexec** | rexecd | 512 / TCP | Remote execution. Requires plaintext auth unless overridden by trust files. |
| **rlogin** | rlogind | 513 / TCP | Remote login. Similar to telnet but restricted to Unix hosts. |

**User Reconnaissance Commands**

* **`rwho`**: Broadcasts active interactive sessions on the local network (sends requests to UDP 513).
* **`rusers -al <IP>`**: Lists detailed logged-in user info (hostnames, TTYs, login times, idle times).
