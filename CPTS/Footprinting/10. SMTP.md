## 1. What is SMTP?

SMTP is the core protocol for sending and forwarding emails across IP networks. It operates over TCP and primarily pushes mail from the sender to the server, and between servers.

* **Standard Ports:**
* `25` (Default, unencrypted plaintext)
* `587` (Modern submission port, uses `STARTTLS` to encrypt the connection)
* `465` (Legacy SSL/TLS encrypted port)


* **ESMTP (Extended SMTP):** The modern standard that includes authentication (`SMTP-Auth`) and security extensions (`STARTTLS`).

## 2. Mail Delivery Architecture

When an email is sent, it passes through several agents:

1. **MUA (Mail User Agent):** The email client (e.g., Outlook, Thunderbird).
2. **MSA (Mail Submission Agent / Relay):** Checks validity and origin of the email.
3. **MTA (Mail Transfer Agent):** The core software (e.g., Postfix, Exchange) that routes the email via DNS to the destination.
4. **MDA (Mail Delivery Agent):** Delivers the email to the specific user's mailbox (accessible via POP3/IMAP).

## 3. Core SMTP Commands

You can interact with an SMTP server directly using `telnet` (e.g., `telnet <IP> 25`).

| Command | Description | Example Usage |
| --- | --- | --- |
| `HELO` / `EHLO` | Initiates the session and identifies the client. (`EHLO` is for ESMTP). | `EHLO mail1.inlanefreight.htb` |
| `MAIL FROM` | Specifies the sender's email address. | `MAIL FROM: <attacker@htb.com>` |
| `RCPT TO` | Specifies the recipient's email address. | `RCPT TO: <victim@htb.com>` |
| `DATA` | Initiates the email body. End the message with a single period (`.`) on a new line. | `DATA` -> Type message -> `.` |
| `VRFY` | Asks the server to verify if a specific user/mailbox exists (useful for enumeration). | `VRFY root` (May return false positives like `252` if configured securely). |
| `QUIT` | Terminates the SMTP session. | `QUIT` |

## 4. The Open Relay Vulnerability

An **Open Relay** is an SMTP server misconfigured to allow unauthenticated users to send emails to external domains. Spammers and attackers abuse this to send phishing campaigns or spam while hiding their true origin (Mail Spoofing).

* **Dangerous Configuration (Postfix `main.cf`):**
```ini
mynetworks = 0.0.0.0/0

```


*(This tells the server to trust and forward mail from ANY IP address on the internet).*

## 5. Footprinting & Enumeration (Nmap)

You can use Nmap to automate interaction and check for misconfigurations.

* **Enumerate Supported Commands:**
This script connects via `EHLO` and lists the server's capabilities (like `PIPELINING`, `VRFY`, `STARTTLS`).
```bash
sudo nmap <TARGET_IP> -sC -sV -p25

```


* **Test for Open Relay:**
This script runs 16 specific tests attempting to bounce mail through the target server to an external address (`relaytest@nmap.scanme.org`).
```bash
sudo nmap <TARGET_IP> -p25 --script smtp-open-relay -v

```


*(If the output shows "Server is an open relay (16/16 tests)", the server is highly vulnerable).*
