# SMTP - [LINK](https://academy.hackthebox.com/app/module/112/section/1072)


SMTP is a client-server protocol used for sending and forwarding emails across IP networks. By default, it transmits data in plaintext, making it vulnerable to interception unless paired with encryption (SSL/TLS) via Extended SMTP (ESMTP).



## 1. Key Ports & Architecture

* **Port 25:** Default SMTP (Plaintext).
* **Port 587:** Authenticated SMTP (Often upgraded to encrypted via `STARTTLS`).
* **Port 465:** Encrypted SMTP (SSL/TLS).
* **The Mail Flow:** Client (`MUA - Mail User Agent`) ➔ Submission Agent (`MSA` / Relay) ➔ Transfer Agent (`MTA` / Server) ➔ Delivery Agent (`MDA`) ➔ Mailbox (`POP3/IMAP`).

## 2. SMTP Commands Table

| Command | Description |
| --- | --- |
| **HELO / EHLO** | Initiates the session. EHLO is for Extended SMTP (ESMTP). |
| **MAIL FROM** | Specifies the sender's email address. |
| **RCPT TO** | Specifies the recipient's email address. |
| **DATA** | Initiates the transmission of the email body. End with `<CR><LF>.<CR><LF>` |
| **VRFY** | Verifies if a user/mailbox exists (Often disabled or returns fake `252` code). |
| **EXPN** | Asks the server for the membership of a mailing list. |
| **STARTTLS** | Upgrades a plaintext connection to SSL/TLS encryption. |
| **NOOP / QUIT** | Keeps the connection alive / Terminates the session. |

## 3. The "Open Relay" Vulnerability

If an administrator misconfigures the MTA (e.g., Postfix `main.cf`) to trust all IP addresses, attackers can use the server to send spoofed emails or mass spam without authentication.

* **Dangerous Config Line:** `mynetworks = 0.0.0.0/0`

## 4. Footprinting & Enumeration Commands

**A. Nmap Enumeration**
Identify available commands and test for the Open Relay vulnerability.

```bash
# List supported SMTP commands (e.g., VRFY, PIPELINING)
sudo nmap <TARGET_IP> -sC -sV -p25

# Run 16 tests to check if the server is a vulnerable Open Relay
sudo nmap <TARGET_IP> -p25 --script smtp-open-relay -v

```

**B. Manual Interaction via Telnet**
Connect manually to test commands, enumerate users (`VRFY`), or send a spoofed email.

```bash
telnet <TARGET_IP> 25

```

*Example of sending an email manually via Telnet:*

```text
EHLO inlanefreight.htb
MAIL FROM: <spoofed@inlanefreight.htb>
RCPT TO: <victim@inlanefreight.htb>
DATA
From: <spoofed@inlanefreight.htb>
To: <victim@inlanefreight.htb>
Subject: Urgent Database Update
Date: Tue, 28 Sept 2021 16:32:51 +0200

Please send the new credentials.
.
QUIT

```

*(Note: The email body is finalized by typing a single period `.` on a new line and pressing Enter).*
