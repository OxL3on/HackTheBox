# SNMP - [LINK](https://academy.hackthebox.com/app/module/112/section/1075)

Simple Network Management Protocol (SNMP) is used to remotely monitor, configure, and manage network devices (routers, switches, servers). It operates on **UDP port 161** for standard client queries and **UDP port 162** for "Traps" (unsolicited alerts triggered by specific server events and sent back to the client).

**Core Architecture**

* **MIB (Management Information Base):** A standardized text file (written in ASN.1) acting as a hierarchical dictionary. It maps out exactly where specific device information is stored but does not contain the data itself.
* **OID (Object Identifier):** A numeric sequence (e.g., `.1.3.6.1...`) representing a specific node within the MIB tree. The longer the chain, the more specific the data point.

**SNMP Versions**

| Version | Security Mechanism | Vulnerability Profile |
| --- | --- | --- |
| **SNMPv1** | None. | Transmits in plaintext. Anyone can intercept data. |
| **SNMPv2c** | Community Strings (acting as passwords). | Extremely common. Still transmits in plaintext, meaning "passwords" can be easily sniffed over the network. |
| **SNMPv3** | Username/Password Auth + Encryption. | Highly secure but complex to configure, leading many admins to improperly fall back to v2c. |

**Community Strings & Misconfigurations**
Community strings function as passwords granting Read-Only (`rocommunity`) or Read-Write (`rwcommunity`) access. A critical misconfiguration occurs when admins leave default strings (like `public` or `private`) or configure `rwcommunity <string>` or `rwuser noauth`—granting attackers full, unauthenticated access to view or modify the entire OID tree.

**Essential Enumeration Tools**

* **onesixtyone:** A fast brute-forcer used to discover hidden or custom community strings against a target IP using a wordlist.
```bash
onesixtyone -c /opt/useful/seclists/Discovery/SNMP/snmp.txt <TARGET_IP>

```


* **snmpwalk:** Once a community string is discovered, this tool walks the OID tree to extract exhaustive system info (OS versions, running processes, user accounts).
```bash
snmpwalk -v2c -c public <TARGET_IP>

```


* **braa:** A mass SNMP scanner used to aggressively brute-force and query individual OIDs at high speeds using a known community string.
```bash
braa public@<TARGET_IP>:.1.3.6.*

```
