# MSSQL - [LINK](https://academy.hackthebox.com/app/module/112/section/1246)

Microsoft SQL (MSSQL) is a relational database management system designed primarily for Windows environments and deeply integrated with the .NET framework. It traditionally listens on **TCP port 1433**.

## Core Concepts & Tools

* **Authentication:** MSSQL heavily utilizes Windows Authentication (via NTLM or Kerberos), meaning the underlying OS handles login requests. If Active Directory (AD) accounts are compromised, they can be leveraged to access MSSQL databases, and vice-versa.
* **Default Databases:**
* `master`: System-level config and login info.
* `model`: The template used for creating new databases.
* `msdb`: Used by SQL Server Agent for scheduling jobs and alerts.
* `tempdb`: Stores temporary data.


* **Key Pentesting Client:** While admins use SQL Server Management Studio (SSMS), penetration testers rely on **Impacket's `mssqlclient.py**` to establish remote command-line access.

## Dangerous Misconfigurations

* **Default `sa` Credentials:** The built-in System Administrator (`sa`) account is often left enabled with weak or default passwords.
* **Unencrypted Connections:** Admins may fail to enforce TLS encryption, allowing traffic to be sniffed.
* **Named Pipes Enablement:** Named pipes (`\\.\pipe\sql\query`) might be unnecessarily exposed over the network.
* **xp_cmdshell:** Though disabled by default in modern versions, admins often enable this stored procedure, granting the ability to execute underlying Windows operating system commands directly from the SQL shell.

## Footprinting & Enumeration

Target specific MSSQL metrics during your Nmap scans.

**Nmap Scripting Engine (NSE)**

```bash
sudo nmap --script ms-sql-info,ms-sql-empty-password,ms-sql-xp-cmdshell,ms-sql-ntlm-info --script-args mssql.instance-name=MSSQLSERVER -sV -p 1433 <TARGET_IP>

```

*Key outputs to log:* Windows Server name, Database Instance Name (e.g., MSSQLSERVER), Product Version, and whether Named Pipes are exposed.

**Metasploit Auxiliary Scanner**

```bash
msfconsole
use auxiliary/scanner/mssql/mssql_ping
set rhosts <TARGET_IP>
run

```

## Connecting & Interacting (Impacket)

If you secure valid credentials (either local or domain), use Impacket to connect to the SQL Database Engine.

```bash
# Connecting using Windows Authentication
python3 mssqlclient.py <DOMAIN>/<USER>@<TARGET_IP> -windows-auth

# Example with local Admin:
python3 mssqlclient.py Administrator@10.129.201.248 -windows-auth

```

**Basic T-SQL Interaction**
Once you reach the `SQL>` prompt, you can use standard Transact-SQL (T-SQL) commands:

* *List all databases:* `select name from sys.databases`
* *Change active database:* `use <DATABASE_NAME>`
* *List tables in current DB:* `select * from information_schema.tables`
