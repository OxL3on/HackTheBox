## 1. MSSQL কী?

Microsoft SQL Server (MSSQL) হলো Microsoft-এর তৈরি একটি closed-source Relational Database Management System (RDBMS)। এটি SQL ব্যবহার করে database তৈরি, পরিচালনা ও query করার কাজ করে।

- মূলত Windows-এর জন্য তৈরি, তবে Linux ও macOS-এও কিছু version চালানো যায়।
- Microsoft .NET framework-ভিত্তিক application-এ বহুল ব্যবহৃত।
- MSSQL-এর default TCP port হলো `1433`।

## 2. MSSQL Clients

Database-এর সঙ্গে connect ও manage করার জন্য বিভিন্ন client ব্যবহার করা যায়।

| Client                | কাজ                                          |
| --------------------- | -------------------------------------------- |
| SSMS                  | SQL Server পরিচালনা করার graphical interface |
| `mssql-cli`           | Command-line client                          |
| SQL Server PowerShell | PowerShell দিয়ে SQL Server পরিচালনা         |
| HeidiSQL              | Database management client                   |
| SQLPro                | Database client                              |
| `mssqlclient.py`      | Impacket-এর মাধ্যমে MSSQL-এ connect করা      |

Pentesting-এ Impacket-এর `mssqlclient.py` গুরুত্বপূর্ণ।

Client কোথায় আছে খুঁজতে:

```
locate mssqlclient
```

সম্ভাব্য output:

```
/usr/bin/impacket-mssqlclient
/usr/share/doc/python3-impacket/examples/mssqlclient.py
```

মনে রাখবে: SSMS শুধু database server-এ নয়, administrator বা developer-এর অন্য computer-এও ইনস্টল থাকতে পারে। সেখানে saved credentials থাকলে database access-এর ঝুঁকি তৈরি হতে পারে।

## 3. MSSQL System Databases

| Database   | কাজ                                            |
| ---------- | ---------------------------------------------- |
| `master`   | SQL Server instance-এর system information রাখে |
| `model`    | নতুন database তৈরির template                   |
| `msdb`     | SQL Server Agent-এর jobs ও alerts পরিচালনা করে |
| `tempdb`   | Temporary objects সংরক্ষণ করে                  |
| `resource` | System objects রাখে; read-only                 |

Reference: [Microsoft — System Databases](https://docs.microsoft.com/en-us/sql/relational-databases/databases/system-databases?view=sql-server-ver15\&utm_source=chatgpt.com)

## 4. Default Configuration

MSSQL network-accessible অবস্থায় ইনস্টল হলে service সাধারণত নিচের account-এ চলতে পারে:

```
NT SERVICE\MSSQLSERVER
```

এটি একটি সাধারণ configuration example; সব installation-এ একই হবে না।

### Windows Authentication

Windows Authentication ব্যবহার করলে Windows OS authentication request যাচাই করে। এটি local SAM database অথবা Active Directory domain controller-এর মাধ্যমে হতে পারে।

Security impact: কোনো Windows account compromise হলে তার permissions ও configuration অনুযায়ী SQL Server access, privilege escalation বা domain-এর অন্য system-এ lateral movement সম্ভব হতে পারে।

Source অনুযায়ী, default configuration-এ connection encryption বাধ্যতামূলক নাও থাকতে পারে।

## 5. Dangerous Settings

MSSQL-এর গুরুত্বপূর্ণ misconfiguration:

- Encryption ব্যবহার না করা: Client-server communication সুরক্ষিত নাও থাকতে পারে।
- Self-signed certificate: সঠিকভাবে যাচাই না করলে certificate spoofing-এর ঝুঁকি থাকে।
- Named Pipes enabled: Named Pipes-এর exposure ও configuration পরীক্ষা করা দরকার।
- Weak/default `sa` credentials: `sa` account সক্রিয় রেখে দুর্বল password ব্যবহার করলে database compromise হতে পারে।

## 6. Footprinting the Service

MSSQL-এর default TCP port `1433`। Nmap-এর MSSQL scripts দিয়ে server সম্পর্কে তথ্য সংগ্রহ করা যায়।

```
sudo nmap \
--script ms-sql-info,ms-sql-empty-password,ms-sql-xp-cmdshell,ms-sql-config,ms-sql-ntlm-info,ms-sql-tables,ms-sql-hasdbaccess,ms-sql-dac,ms-sql-dump-hashes \
--script-args mssql.instance-port=1433,mssql.username=sa,mssql.password=,mssql.instance-name=MSSQLSERVER \
-sV -p 1433 10.129.201.248
```

গুরুত্বপূর্ণ scripts:

| Script                  | উদ্দেশ্য                                                        |
| ----------------------- | --------------------------------------------------------------- |
| `ms-sql-info`           | Server ও instance-এর তথ্য                                       |
| `ms-sql-empty-password` | Empty password-এর সম্ভাবনা পরীক্ষা                              |
| `ms-sql-xp-cmdshell`    | `xp_cmdshell`-সম্পর্কিত পরীক্ষা                                 |
| `ms-sql-config`         | Configuration তথ্য                                              |
| `ms-sql-ntlm-info`      | NTLM-এর মাধ্যমে server/domain তথ্য                              |
| `ms-sql-tables`         | Database table-সংক্রান্ত তথ্য                                   |
| `ms-sql-hasdbaccess`    | Database access যাচাই                                           |
| `ms-sql-dac`            | Dedicated Administrator Connection-সংক্রান্ত পরীক্ষা            |
| `ms-sql-dump-hashes`    | অনুমতি ও পরিস্থিতি অনুযায়ী hash-সংক্রান্ত তথ্য সংগ্রহের চেষ্টা |

Scan থেকে পাওয়া যেতে পারে:

- Hostname
- MSSQL instance name
- Server version
- TCP port
- Named Pipes path
- Cluster configuration

Note: Scan-এ কোনো misconfiguration দেখা গেলেই সেটি নিশ্চিত ধরে নেওয়া যাবে না। Findings যাচাই করতে হবে।

## 7. Metasploit দিয়ে MSSQL Footprinting

Metasploit-এর `mssql_ping` auxiliary scanner-ও MSSQL service-এর তথ্য সংগ্রহ করতে পারে।

```
msf6 auxiliary(scanner/mssql/mssql_ping) > set rhosts 10.129.201.248
msf6 auxiliary(scanner/mssql/mssql_ping) > run
```

এটি দেখাতে পারে:

- `ServerName`
- `InstanceName`
- `IsClustered`
- `Version`
- `tcp`
- `np` — Named Pipes path

## 8. Impacket দিয়ে MSSQL-এ Connect করা

Credentials পাওয়া গেলে বা অনুমোদিতভাবে জানা থাকলে Impacket-এর client দিয়ে connect করা যায়।

```
python3 mssqlclient.py Administrator@10.129.201.248 -windows-auth
```

- `Administrator@10.129.201.248`: Username ও target
- `-windows-auth`: Windows Authentication ব্যবহার করে
- Password prompt এলে password দিতে হয়।

Connect করার পরে database list দেখতে:

```
SELECT name FROM sys.databases;
```

এটি SQL Server-এ থাকা database-গুলোর নাম দেখায়, তবে দৃশ্যমান ফলাফল user-এর permissions-এর ওপর নির্ভর করতে পারে।

## Quick Revision

| বিষয়                     | মনে রাখবে                                                             |
| ------------------------ | --------------------------------------------------------------------- |
| MSSQL default port       | TCP/1433                                                              |
| Graphical client         | SSMS                                                                  |
| Pentesting client        | Impacket `mssqlclient.py`                                             |
| Default system databases | `master`, `model`, `msdb`, `tempdb`, `resource`                       |
| Authentication           | Windows Authentication বা SQL Server Authentication                   |
| Dangerous settings       | Encryption অনুপস্থিত, self-signed certificates, weak `sa` credentials |
| Enumeration              | Nmap MSSQL scripts, Metasploit `mssql_ping`                           |
| Database list            | `SELECT name FROM sys.databases;`                                     |

Pentesting workflow: Port ও version শনাক্ত করো → Authentication ও encryption configuration পরীক্ষা করো → MSSQL instance ও named pipes enumerate করো → অনুমোদিত credentials দিয়ে connect করো → Database list ও access permissions যাচাই করো।
