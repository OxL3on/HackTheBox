## NFS

NFS (Network File System) is a network file system developed by Sun Microsystems.

**only one port is required: TCP/UDP 2049**

#### How NFS Works

NFS is built on: **ONC-RPC (SUN-RPC)** which used TCP 111, UDP 111. Data is exchanged using: **XDR (External Data Representation)** for platform-independent communication.

### Authentication

Authentication is handled by **RPC ,** Authorization comes from the filesystem permissions. Most NFS authentication relies on: UNIX GID , UNIX UID , Group memberships.

#### Default Configuration

Configuration file: `/etc/exports`

**Common Export Options**

| Option | Description |
| --- | --- |
| **rw** | Read and write access |
| **ro** | Read-only access |
| **sync** | Synchronous writes (slower) |
| **async** | Asynchronous writes (faster) |
| **secure** | Do not use ports above 1024 |
| **insecure** | Allow ports above 1024 |
| **no_subtree_check** | Disable subtree checking |
| **root_squash** | Maps root (UID/GID 0) to anonymous user, preventing root from accessing files on the mounted share |

#### Creating an NFS Share

```bash
echo '/mnt/nfs 10.129.14.0/24(sync,no_subtree_check)' >> /etc/exports

systemctl restart nfs-kernel-server

exportfs
```

**Dangerous NFS Settings**

| Option | Description |
| --- | --- |
| **rw** | Allows reading and writing |
| **insecure** | Allows ports above 1024 |
| **nohide** | Exports mounted filesystems beneath another exported directory |
| **no_root_squash** | Root-created files keep UID/GID 0 |

### Footprinting NFS

TCP 111 (RPC) , TCP 2049 (NFS)

**Basic Nmap Scan**

```bash
sudo nmap <IP> -p111,2049 -sV -sC
```

**NFS NSE Scripts**

```bash
sudo nmap --script nfs* <IP> -sV -p111,2049
```

**Show Available Shares**

```bash
showmount -e <IP>
```

**Mounting an NFS Share**

- Create a mount point: `mkdir target-NFS`
- Mount the share: `sudo mount -t nfs 10.129.14.128:/ ./target-NFS/ -o nolock`
- Navigate into it: `cd target-NFS`
- View its contents: `tree .`
- Viewing File Ownership: `ls -l mnt/nfs/`
- Viewing UID/GID: `ls -n mnt/nfs/`
- Unmounting the Share: `sudo umount ./target-NFS`
