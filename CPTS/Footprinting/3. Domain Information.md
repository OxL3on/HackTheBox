## **Domain Information**

Our goal is to gather information and understand:

- What the company does.
- How it operates.
- What technologies it uses.
- What infrastructure is needed to provide its services.

**Start With the Company's Website**

**Online Presence**

**SSL Certificates**

SSL certificates often reveal : Multiple subdomains , Additional domains

**Certificate Transparency (crt.sh)**

```
https://crt.sh/?q=inlanefreight.com
```

crt.sh stores Certificate Transparency logs. Certificate Transparency is defined in RFC 6962. **Its purpose is to**: Record every SSL certificate issued by Certificate Authorities , Detect false or malicious certificates , Make certificate issuance publicly auditable.

We can retrieve certificate data as JSON.

```bash
curl -s https://crt.sh/?q=inlanefreight.com&output=json | jq .
```

Get Only Unique Subdomains

```bash
curl -s https://crt.sh/?q=inlanefreight.com&output=json | jq . | grep name | cut -d":" -f2 | grep -v "CN=" | cut -d'"' -f2 | awk '{gsub(/\\n/,"\n");}1;' | sort -u
```

**Identify Company-Hosted Servers**

Next, determine which hosts belong to the company instead of third-party providers.

```bash
for i in $(cat subdomainlist); do
host $i | grep "has address" | grep inlanefreight.com | cut -d" " -f1,4
done
```

**Using Shodan**

After collecting IP addresses, we can investigate them with Shodan.

```bash
shodan host <IP>
```

**DNS Records**

```bash
dig any inlanefreight.com
```

#### **Understanding DNS Records**

**A Records :** Contain IP addresses for domains.

**MX Records :** Show the company's mail servers.

**NS Records :** Show the authoritative DNS servers. These often reveal the hosting provider.

**TXT Records :** TXT records often contain: Verification tokens , SPF , DKIM , DMARC , Other security information
