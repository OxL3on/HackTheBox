## 1. MySQL কী?

MySQL হলো Oracle-এর তৈরি ও পরিচালিত একটি open-source Relational Database Management System (RDBMS)। এটি SQL ব্যবহার করে structured data সংরক্ষণ, খোঁজা, পরিবর্তন ও মুছে ফেলার কাজ করে।

MySQL client-server architecture অনুসরণ করে।

- MySQL Server: Data সংরক্ষণ ও পরিচালনা করে।
- MySQL Client: SQL query পাঠিয়ে data access বা modify করে।
- Table: Row ও column-এর মাধ্যমে data সাজিয়ে রাখে।
- `.sql` file: Database-এর SQL statements ও data-এর backup/export থাকতে পারে।

উদাহরণ: WordPress posts, usernames ও passwords database-এ রাখে।

MySQL সাধারণত dynamic website-এ ব্যবহৃত হয়। Linux, Apache, MySQL ও PHP-এর সমন্বয়কে LAMP বলে; Nginx ব্যবহার করলে প্রচলিত stack-টি LEMP নামে পরিচিত।

## 2. MySQL কী ধরনের Data রাখে?

| Data Type        | উদাহরণ                                  |
| ---------------- | --------------------------------------- |
| Website content  | Headers, texts, forms                   |
| User information | Username, email, personal information   |
| Access control   | Permissions, administrators, moderators |
| Other data       | Meta tags, links, configuration values  |
| Sensitive data   | Passwords, payment information          |

Passwords সাধারণত plaintext-এ না রেখে application-এর মাধ্যমে secure password hashing করে সংরক্ষণ করা উচিত।

MySQL query ভুলভাবে তৈরি হলে SQL Injection-এর মতো vulnerability তৈরি হতে পারে। Error message থেকেও database structure বা configuration সম্পর্কে তথ্য প্রকাশিত হতে পারে।

## 3. Default Configuration

MySQL server install করার উদাহরণ:

```
sudo apt install mysql-server -y
```

Configuration file দেখতে:

```
cat /etc/mysql/mysql.conf.d/mysqld.cnf | grep -v "#" | sed -r '/^\s*$/d'
```

গুরুত্বপূর্ণ configuration:

| Setting            | কাজ                                              |
| ------------------ | ------------------------------------------------ |
| `user`             | MySQL service কোন OS user হিসেবে চলবে            |
| `port`             | Network port; সাধারণত `3306`                     |
| `socket`           | Local client-server communication-এর socket path |
| `pid-file`         | Process ID সংরক্ষণের file                        |
| `basedir`          | MySQL installation directory                     |
| `datadir`          | Database files-এর directory                      |
| `tmpdir`           | Temporary files-এর directory                     |
| `secure_file_priv` | File import/export-এর location সীমিত করে         |

## 4. Dangerous Settings ও Misconfiguration

| Setting            | Security গুরুত্ব                                                    |
| ------------------ | ------------------------------------------------------------------- |
| `user`             | Service-এর OS privileges নির্ধারণে ভূমিকা রাখে                      |
| `password`         | Configuration-এ credentials থাকলে সেগুলো প্রকাশিত হতে পারে          |
| `admin_address`    | Administrative TCP connection কোন IP-তে listen করবে তা নির্ধারণ করে |
| `debug`            | অতিরিক্ত diagnostic information প্রকাশ করতে পারে                    |
| `sql_warnings`     | SQL operation-এর warning information নিয়ন্ত্রণ করে                 |
| `secure_file_priv` | Database file import/export-এর সীমা নিয়ন্ত্রণ করে                  |

Configuration file-এর permission দুর্বল হলে username, password বা অন্যান্য sensitive তথ্য পড়া সম্ভব হতে পারে। Error message অতিরিক্ত বিস্তারিত হলে database structure ও সম্ভাব্য vulnerability সম্পর্কে তথ্য ফাঁস হতে পারে।

## 5. Footprinting MySQL

MySQL-এর default port হলো TCP/3306। Nmap দিয়ে service, version ও সম্ভাব্য configuration issue শনাক্ত করা যায়।

```
sudo nmap 10.129.14.128 -sV -sC -p3306 --script mysql*
```

গুরুত্বপূর্ণ options:

- `-sV`: Service version শনাক্ত করে।
- `-sC`: Default NSE scripts চালায়।
- `-p3306`: MySQL port scan করে।
- `--script mysql*`: MySQL-সম্পর্কিত Nmap scripts চালায়।

সম্ভাব্য output:

- MySQL version
- Authentication plugin
- Database service information
- সম্ভাব্য username ও authentication misconfiguration

গুরুত্বপূর্ণ: Nmap-এর ফলাফল সবসময় সঠিক নাও হতে পারে। False positive হতে পারে, তাই login করে বা অন্য উপায়ে findings যাচাই করতে হবে।

## 6. MySQL Server-এ Connect করা

```
mysql -u root -h 10.129.14.132
```

- `-u`: Username
- `-h`: Target IP/hostname
- `-p`: Password prompt

Password সরাসরি দিতে চাইলে source-এ দেখানো format:

```
mysql -u root -pP4SSw0rd -h 10.129.14.128
```

এখানে `-p` এবং password-এর মধ্যে space নেই। তবে বাস্তবে password prompt ব্যবহার করা নিরাপদ, কারণ command-line password history বা process information-এ প্রকাশিত হতে পারে।

### Empty Password Misconfiguration

কোনো account-এর password খালি থাকলে তা security risk হতে পারে। তবে Nmap এমন দেখালেই নিশ্চিত হওয়া যাবে না যে account-টির password সত্যিই empty।

উদাহরণস্বরূপ, login attempt-এ:

```
ERROR 1045 (28000): Access denied
```

দেখালে authentication ব্যর্থ হয়েছে।

সঠিক credentials দিয়ে login করতে পারলে SQL query চালানো যায়:

```
SHOW DATABASES;
SELECT VERSION();
USE mysql;
SHOW TABLES;
```

## 7. গুরুত্বপূর্ণ System Schemas

MySQL-এ system information ও metadata দেখার জন্য গুরুত্বপূর্ণ schema রয়েছে।

| Schema               | কাজ                                                               |
| -------------------- | ----------------------------------------------------------------- |
| `mysql`              | Server-এর users, privileges ও অন্যান্য system-related information |
| `information_schema` | Database, table, column ইত্যাদির metadata                         |
| `performance_schema` | Server performance ও execution monitoring                         |
| `sys`                | Performance data সহজে বিশ্লেষণ করার views                         |

### উদাহরণ: `sys` Schema

```
USE sys;
SHOW TABLES;
```

Host ও user-related summary দেখতে:

```
SELECT host, unique_users FROM host_summary;
```

`information_schema` মূলত metadata access-এর standard interface। `mysql` system schema-তে server-এর নিজস্ব system information থাকে। দুটির উদ্দেশ্য ও contents এক নয়।

## 8. গুরুত্বপূর্ণ MySQL Commands

| Command                                              | কাজ                                  |
| ---------------------------------------------------- | ------------------------------------ |
| `mysql -u <user> -p -h <IP>`                         | MySQL server-এ connect করা           |
| `SHOW DATABASES;`                                    | Database list দেখা                   |
| `USE <database>;`                                    | Database select করা                  |
| `SHOW TABLES;`                                       | Selected database-এর table list দেখা |
| `SHOW COLUMNS FROM <table>;`                         | Table-এর column দেখা                 |
| `SELECT * FROM <table>;`                             | Table-এর সব column ও row দেখা        |
| `SELECT * FROM <table> WHERE <column> = '<string>';` | নির্দিষ্ট value অনুযায়ী data খোঁজা  |
| `SELECT VERSION();`                                  | MySQL version দেখা                   |

### ছোট উদাহরণ

Database list:

```
SHOW DATABASES;
```

Database select:

```
USE wordpress;
```

Table list:

```
SHOW TABLES;
```

Column list:

```
SHOW COLUMNS FROM users;
```

নির্দিষ্ট username খোঁজা:

```
SELECT * FROM users WHERE username = 'admin';
```

## 9. গুরুত্বপূর্ণ বিষয় মনে রাখবে

- MySQL সাধারণত `TCP/3306` port-এ চলে।
- MySQL client-server architecture অনুসরণ করে।
- `.sql` file-এ database backup বা SQL statements থাকতে পারে।
- `mysql`, `information_schema`, `performance_schema` ও `sys` গুরুত্বপূর্ণ system schemas।
- Configuration file-এ credentials থাকলে file permissions পরীক্ষা করা জরুরি।
- `secure_file_priv` file import/export সীমিত করতে পারে।
- Nmap findings যাচাই না করে চূড়ান্ত সিদ্ধান্ত নেওয়া উচিত নয়।
- Database access-এর অনুমতি ও privilege অনুযায়ী data দেখা বা পরিবর্তন করা সম্ভব।
