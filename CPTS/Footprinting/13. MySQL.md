# MySQL - [LINK](https://academy.hackthebox.com/app/module/112/section/1238)


MySQL (and its fork, MariaDB) is an open-source relational database management system that operates on a client-server architecture, typically listening on TCP port 3306. In web penetration testing, compromising the database is often the primary objective for data exfiltration and credential harvesting.

## Footprinting & Enumeration

While MySQL should rarely be exposed to the public internet, misconfigurations occur. Use Nmap's scripting engine (NSE) to gather version data, supported capabilities, and test for default credentials.

* **Command:** `nmap <TARGET_IP> -sV -sC -p3306 --script mysql*`
* *Warning:* Always manually verify Nmap script results. Automated scripts frequently return false positives (e.g., reporting an empty `root` password when a password is actually enforced).

## Dangerous Server Configurations

If you achieve Local File Inclusion (LFI) or gain a low-privileged shell, immediately check the MySQL configuration file (typically found at `/etc/mysql/mysql.conf.d/mysqld.cnf`).

* **Plaintext Credentials:** Look for `user`, `password`, and `admin_address`. If file permissions are poorly configured, unprivileged users can read these plaintext credentials and assume database control.
* **Verbose Errors:** The `debug` and `sql_warnings` directives. If left enabled, the server leaks verbose structural data and syntax errors directly to the web application, providing a roadmap for SQL Injection (SQLi) attacks.
* **File Execution:** `secure_file_priv` controls the database's ability to import/export local files. If disabled or misconfigured, attackers can read sensitive system files (e.g., `/etc/passwd`) or write malicious web shells directly to the webroot.

## MySQL Interaction Cheat Sheet

Once you obtain valid credentials, use the MySQL client to connect. *Note: Do not place a space between the `-p` flag and the password.*

| Command | Description |
| --- | --- |
| `mysql -u <user> -p<pass> -h <IP>` | Connect to the remote MySQL daemon. |
| `show databases;` | List all databases on the server. |
| `use <database>;` | Select a specific database to interact with. |
| `show tables;` | List all tables within the active database. |
| `show columns from <table>;` | Display the schema/column headers for a specific table. |
| `select * from <table>;` | Dump all contents of a table. |
| `select * from <table> where <col> = "<string>";` | Query specific data matching a defined condition. |

## Target System Databases

When mapping an unfamiliar server, review these default databases to understand the backend architecture:

* **`information_schema`:** An ANSI/ISO standard database containing read-only metadata about all databases, privileges, tables, and columns on the server.
* **`sys` (System Schema):** Contains advanced operational metrics, process lists, and management metadata.
