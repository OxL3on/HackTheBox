# Windows Remote Management Protocols - [LINK](https://academy.hackthebox.com/app/module/112/section/1242)


Windows Server remote management heavily relies on three primary protocols. Understanding their ports, enumeration tactics, and exploitation tools is critical for lateral movement and remote code execution during an engagement.

## Remote Desktop Protocol (RDP)

RDP provides remote graphical interface management. While it supports TLS/SSL encryption, servers often rely on self-signed certificates or weak RDP Security, and require Network Level Authentication (NLA) by default.

* **Ports:** TCP / UDP 3389
* **Enumeration:**
```bash
nmap -sV -sC <TARGET_IP> -p3389 --script rdp*

```

In addition, we can use --packet-trace to track the individual packages and inspect their contents manually.
```
nmap -sV -sC 10.129.201.248 -p3389 --packet-trace --disable-arp-ping -n
```

A Perl script named [rdp-sec-check.pl](https://github.com/CiscoCXSecurity/rdp-sec-check) has also been developed by Cisco CX Security Labs that can unauthentically identify the security settings of RDP servers based on the handshakes.


* **Evasion Warning:** Running Nmap against RDP sends an identifiable cookie (`mstshash=nmap`). Endpoint Detection and Response (EDR) solutions actively signature this and may instantly block your IP.
* **Vulnerability Checking:** Use `rdp-sec-check.pl` to identify supported security layers (like CredSSP or weak encryption methods) without authenticating.
```bash
./rdp-sec-check.pl <TARGET_IP>

```

**RDP Security Check - Installation**
```
sudo cpan

git clone https://github.com/CiscoCXSecurity/rdp-sec-check.git && cd rdp-sec-check

./rdp-sec-check.pl 10.129.201.248
```


* **Connection (Linux Client):**
```bash
xfreerdp /u:<USERNAME> /p:"<PASSWORD>" /v:<TARGET_IP>

```





## Windows Remote Management (WinRM)

WinRM is a command-line remote management protocol utilizing SOAP. It operates via HTTP/HTTPS and is enabled by default on Windows Server 2012 and newer. It powers remote PowerShell sessions and Windows Remote Shell (WinRS).

* **Ports:** TCP 5985 (HTTP) / TCP 5986 (HTTPS)
* **Enumeration:**
```bash
nmap -sV -sC <TARGET_IP> -p5985,5986 --disable-arp-ping -n

```


* **Exploitation:** `evil-winrm` is the premier penetration testing tool for interacting with WinRM, providing a stable, interactive PowerShell environment.
```bash
evil-winrm -i <TARGET_IP> -u <USERNAME> -p "<PASSWORD>"

```



## Windows Management Instrumentation (WMI)

WMI is Microsoft's implementation of Web-Based Enterprise Management (WBEM). It grants read/write access to virtually all Windows OS settings and is heavily utilized for stealthy lateral movement.

* **Ports:** Initializes on **TCP 135**, then dynamically assigns a random high TCP port for the actual communication.
* **Exploitation:** Use Impacket's `wmiexec.py` to achieve an interactive or semi-interactive command prompt without dropping an executable to disk.
```bash
# Syntax for executing a single command
wmiexec.py <USERNAME>:"<PASSWORD>"@<TARGET_IP> "<COMMAND>"

# Example
wmiexec.py Administrator:"P455w0rD!"@10.129.201.248 "hostname"

```
