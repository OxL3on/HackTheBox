## **Password Security Fundamentals**

### **The Anatomy of a Strong Password**

- **Length** : Aim for a minimum of 12 characters.
- **Complexity :** While traditional advice emphasized using a mix of uppercase and lowercase letters, numbers, and symbols to create complex passwords, recent NIST guidelines have shifted focus towards password length and the use of passphrases.
- **Uniqueness** : Don't reuse passwords across different accounts. Each account should have its own unique and strong password.
- **Randomness** : Avoid using dictionary words, personal information, or common phrases.

**Common Password Weaknesses** : ****Short passwords, Common words and phrases, Personal Information, Reusing Passwords, Predictable Patterns

**Password Policies :** Minimum Length, Complexity, Password Expiration, Password History
