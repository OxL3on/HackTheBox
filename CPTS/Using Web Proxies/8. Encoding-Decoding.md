## **Encoding/Decoding**

We can input the above string in Burp Decoder and select `Decode as > Base64`, and we'll get the decoded value. In recent versions of Burp, we can also use the `Burp Inspector` tool to perform encoding and decoding (among other things), which can be found in various places like `Burp Proxy` or `Burp Repeater.`

In ZAP, we can use the `Encoder/Decoder/Hash` tool, which will automatically decode strings using various decoders in the `Decode` tab.
