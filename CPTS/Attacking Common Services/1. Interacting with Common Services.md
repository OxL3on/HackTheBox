## Introduction (ভূমিকা)

প্রযুক্তি, প্রোটোকল বা সার্ভিস ব্যবহারকারী এবং বোঝেন এমন ব্যক্তিরাই সাধারণত ভালনারেবিলিটি (vulnerabilities) আবিষ্কার করে থাকেন। সাইবার সিকিউরিটি ফিল্ডে কাজ করার সময় আমরা বিভিন্ন সার্ভিসের সম্মুখীন হব এবং প্রতিনিয়ত নতুন প্রযুক্তি সম্পর্কে জানতে ও শিখতে হবে।

যেকোনো সার্ভিসে সফলভাবে অ্যাটাক করার জন্য আমাদের জানতে হবে:

* সার্ভিসটির উদ্দেশ্য কী
* এর সাথে কীভাবে ইন্টারঅ্যাক্ট করতে হয়
* এর জন্য আমরা কী কী টুল ব্যবহার করতে পারি
* এর মাধ্যমে আমরা কী করতে পারি

এই সেকশনটি মূলত সাধারণ কিছু সার্ভিস (common services) এবং সেগুলোর সাথে কীভাবে ইন্টারঅ্যাক্ট করতে হয়, তা নিয়ে আলোচনা করবে।

## File Share Services (ফাইল শেয়ার সার্ভিস)

ফাইল শেয়ারিং সার্ভিস হলো এমন একটি সার্ভিস, যা কম্পিউটার ফাইলগুলোর ট্রান্সফার প্রদান, মধ্যস্থতা (mediate) এবং মনিটর করে। আগেকার দিনে ব্যবসা প্রতিষ্ঠানগুলো সাধারণত শুধুমাত্র অভ্যন্তরীণ (internal) ফাইল শেয়ারিং সার্ভিস ব্যবহার করত, যেমন— **SMB, NFS, FTP, TFTP, SFTP**। কিন্তু ক্লাউডের ব্যবহার বাড়ার সাথে সাথে অধিকাংশ কোম্পানি এখন থার্ড-পার্টি ক্লাউড সার্ভিসও ব্যবহার করে, যেমন— **Dropbox, Google Drive, OneDrive, SharePoint** বা অন্যান্য ক্লাউড স্টোরেজ (AWS S3, Azure Blob Storage, Google Cloud Storage)।

আমাদের ইন্টারনাল এবং এক্সটারনাল—উভয় ধরনের ফাইল-শেয়ারিং সার্ভিসের সম্মুখীন হতে হবে এবং এগুলো সম্পর্কে ভালোভাবে ধারণা থাকতে হবে। তবে এই সেকশনে মূলত ইন্টারনাল সার্ভিসের ওপর ফোকাস করা হয়েছে, যা সার্ভার বা ওয়ার্কস্টেশনে লোকালি সিঙ্ক (sync) করা ক্লাউড স্টোরেজের ক্ষেত্রেও প্রযোজ্য হতে পারে।

### Server Message Block (SMB)

**SMB** সাধারণত Windows নেটওয়ার্কে ব্যবহৃত হয় এবং আমরা প্রায়শই Windows নেটওয়ার্কে শেয়ার ফোল্ডার দেখতে পাব। আমরা GUI (Graphical User Interface), CLI (Command-Line Interface) অথবা টুলের সাহায্যে SMB-এর সাথে ইন্টারঅ্যাক্ট করতে পারি।

Windows এবং Linux ব্যবহার করে SMB-এর সাথে ইন্টারঅ্যাক্ট করার সাধারণ কিছু পদ্ধতি নিচে দেওয়া হলো:

#### Windows

Windows-এ শেয়ার্ড ফোল্ডারের সাথে ইন্টারঅ্যাক্ট করার বিভিন্ন উপায় রয়েছে।
GUI ব্যবহার করে:

1. `[WINKEY] + [R]` চেপে Run ডায়ালগ বক্স খুলুন।
2. ফাইল শেয়ারের লোকেশনটি টাইপ করুন, যেমন: `\\192.168.220.129\Finance\`

যদি শেয়ার্ড ফোল্ডারটি অ্যানোনিমাস অথেনটিকেশন (anonymous authentication) সাপোর্ট করে অথবা আমাদের কাছে এমন কোনো ইউজার থাকে যার ওই ফোল্ডারের ওপর প্রিভিলেজ (privilege) আছে, তবে আমরা কোনো অথেনটিকেশন রিকোয়েস্ট ছাড়াই ফোল্ডারের কন্টেন্ট দেখতে পাব। আর যদি অ্যাক্সেস না থাকে, তবে অথেনটিকেশন রিকোয়েস্ট আসবে।

Windows-এ দুটি কমান্ড-লাইন শেল রয়েছে: **Command shell (CMD)** এবং **PowerShell**। চলুন দেখা যাক কীভাবে এগুলো ব্যবহার করে ফাইল শেয়ারের সাথে ইন্টারঅ্যাক্ট করা যায়।

**Windows CMD - DIR:**
`dir` কমান্ড ব্যবহার করে ডিরেক্টরির ফাইল এবং সাবডিরেক্টরির লিস্ট দেখা যায়।

```cmd
C:\htb> dir \\192.168.220.129\Finance\

Volume in drive \\192.168.220.129\Finance has no label.
Volume Serial Number is ABCD-EFAA

Directory of \\192.168.220.129\Finance

02/23/2022  11:35 AM    <DIR>          Contracts
               0 File(s)          4,096 bytes
               1 Dir(s)  15,207,469,056 bytes free

```

**Windows CMD - Net Use:**
`net use` কমান্ডটি কোনো শেয়ার্ড রিসোর্সের সাথে কম্পিউটারকে কানেক্ট বা ডিসকানেক্ট করে। এটি ব্যবহার করে আমরা একটি ফাইল শেয়ারে কানেক্ট করতে পারি এবং এর কন্টেন্টকে `n` ড্রাইভের সাথে ম্যাপ করতে পারি।

```cmd
C:\htb> net use n: \\192.168.220.129\Finance

The command completed successfully.

```

অথেনটিকেট করার জন্য ইউজারনেম এবং পাসওয়ার্ডও দেওয়া যায়:

```cmd
C:\htb> net use n: \\192.168.220.129\Finance /user:plaintext Password123

The command completed successfully.

```

শেয়ার্ড ফোল্ডারটি `n` ড্রাইভ হিসেবে ম্যাপ হয়ে গেলে, আমরা আমাদের লোকাল কম্পিউটারের মতোই এতে Windows কমান্ড চালাতে পারি। উদাহরণস্বরূপ, শেয়ার্ড ফোল্ডার এবং সাবডিরেক্টরিতে মোট কতগুলো ফাইল আছে তা খুঁজে বের করা:

**Windows CMD - Count Files:**

```cmd
C:\htb> dir n: /a-d /s /b | find /c ":\"

29302

```

| অংশ | অর্থ |
| --- | --- |
| `dir` | অ্যাপ্লিকেশন বা কমান্ড। |
| `n:` | যে ডিরেক্টরি বা ড্রাইভে সার্চ করা হবে। |
| `/a-d` | `/a` হলো অ্যাট্রিবিউট এবং `-d` মানে হলো ডিরেক্টরিগুলো বাদ দেওয়া (not directories)। |
| `/s` | নির্দিষ্ট ডিরেক্টরি এবং এর সমস্ত সাবডিরেক্টরির ফাইল প্রদর্শন করে। |
| `/b` | বেয়ার ফরম্যাট ব্যবহার করে (কোনো হেডিং ইনফরমেশন বা সামারি ছাড়া)। |
| `| find /c ":\"` | ফাইলের সংখ্যা গণনা করে। |

২৯,৩০২টি ফোল্ডারের মধ্যে কিছু খোঁজা সময়সাপেক্ষ। স্ক্রিপ্টিং এবং কমান্ড লাইন ইউটিলিটি ব্যবহার করে আমরা নির্দিষ্ট নামের ফাইল খুঁজতে পারি, যেমন: `cred`, `password`, `users`, `secrets`, `key` বা সোর্স কোডের এক্সটেনশন (যেমন: `.cs`, `.c`, `.go`, `.java`, `.php`, `.asp`, `.aspx`, `.html`)।

```cmd
C:\htb>dir n:\*cred* /s /b

n:\Contracts\private\credentials.txt

C:\htb>dir n:\*secret* /s /b

n:\Contracts\private\secret.txt

```

টেক্সট ফাইলের ভেতরে নির্দিষ্ট শব্দ খুঁজতে আমরা `findstr` ব্যবহার করতে পারি।

**Windows CMD - Findstr:**

```cmd
c:\htb>findstr /s /i cred n:\*.*

n:\Contracts\private\secret.txt:file with all credentials
n:\Contracts\private\credentials.txt:admin:SecureCredentials!

```

**Windows PowerShell:**
PowerShell মূলত Command shell-এর সক্ষমতাকে আরও বাড়ানোর জন্য তৈরি করা হয়েছে এবং এটি `cmdlets` নামক কমান্ড রান করে।

PowerShell ব্যবহার করে শেয়ার্ড ডিরেক্টরি লিস্ট করা:

```powershell
PS C:\htb> Get-ChildItem \\192.168.220.129\Finance\

    Directory: \\192.168.220.129\Finance

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----         2/23/2022   3:27 PM                Contracts

```

`net use`-এর বদলে আমরা `New-PSDrive` ব্যবহার করতে পারি:

```powershell
PS C:\htb> New-PSDrive -Name "N" -Root "\\192.168.220.129\Finance" -PSProvider "FileSystem"

```

Powershell-এ ইউজারনেম এবং পাসওয়ার্ড দেওয়ার জন্য একটি `PSCredential` অবজেক্ট তৈরি করতে হয়:

```powershell
PS C:\htb> $username = 'plaintext'
PS C:\htb> $password = 'Password123'
PS C:\htb> $secpassword = ConvertTo-SecureString $password -AsPlainText -Force
PS C:\htb> $cred = New-Object System.Management.Automation.PSCredential $username, $secpassword
PS C:\htb> New-PSDrive -Name "N" -Root "\\192.168.220.129\Finance" -PSProvider "FileSystem" -Credential $cred

```

PowerShell-এ ফাইলের সংখ্যা বের করা:

```powershell
PS C:\htb> N:
PS N:\> (Get-ChildItem -File -Recurse | Measure-Object).Count

29302

```

নির্দিষ্ট নামের ফাইল খুঁজতে `-Include` প্রপার্টি ব্যবহার করা:

```powershell
PS C:\htb> Get-ChildItem -Recurse -Path N:\ -Include *cred* -File

```

ফাইলের ভেতরে নির্দিষ্ট শব্দ খুঁজতে `Select-String` ব্যবহার করা (এটি UNIX-এর `grep` বা Windows-এর `findstr.exe`-এর মতো কাজ করে):

```powershell
PS C:\htb> Get-ChildItem -Recurse -Path N:\ | Select-String "cred" -List

```

#### Linux

Linux (UNIX) মেশিন ব্যবহার করেও SMB শেয়ারগুলো ব্রাউজ এবং মাউন্ট করা যায়। টার্গেট সার্ভারটি Windows মেশিন হোক বা Samba সার্ভার, উভয় ক্ষেত্রেই এটি কাজ করে।

**Linux - Mount:**
SMB শেয়ার মাউন্ট করতে নিচের কমান্ডটি ব্যবহার করা হয়:

```bash
00Luffy00@htb[/htb]$ sudo mkdir /mnt/Finance
00Luffy00@htb[/htb]$ sudo mount -t cifs -o username=plaintext,password=Password123,domain=. //192.168.220.129/Finance /mnt/Finance

```

বিকল্প হিসেবে আমরা একটি ক্রেডেনশিয়াল ফাইল (credential file) ব্যবহার করতে পারি:

```bash
00Luffy00@htb[/htb]$ mount -t cifs //192.168.220.129/Finance /mnt/Finance -o credentials=/path/credentialfile

```

ক্রেডেনশিয়াল ফাইলের স্ট্রাকচার হবে এরকম:

```txt
username=plaintext
password=Password123
domain=.

```

> **Note:** SMB শেয়ার ফোল্ডারের সাথে কানেক্ট করতে `cifs-utils` ইন্সটল করা থাকতে হবে। এটি ইন্সটল করতে `sudo apt install cifs-utils` কমান্ডটি এক্সিকিউট করতে হবে।

শেয়ার মাউন্ট হয়ে গেলে আমরা `find` বা `grep` এর মতো সাধারণ Linux টুল ব্যবহার করে ইন্টারঅ্যাক্ট করতে পারি।

ফাইলনেমে `cred` স্ট্রিং খুঁজতে:

```bash
00Luffy00@htb[/htb]$ find /mnt/Finance/ -name *cred*

/mnt/Finance/Contracts/private/credentials.txt

```

ফাইলের ভেতরে `cred` স্ট্রিং খুঁজতে:

```bash
00Luffy00@htb[/htb]$ grep -rn /mnt/Finance/ -ie cred

/mnt/Finance/Contracts/private/credentials.txt:1:admin:SecureCredentials!
/mnt/Finance/Contracts/private/secret.txt:1:file with all credentials

```

**Other Services:**
FTP, TFTP, এবং NFS-এর মতো অন্যান্য ফাইল-শেয়ারিং সার্ভিসগুলোও আমরা বিভিন্ন টুল এবং কমান্ড ব্যবহার করে মাউন্ট করতে পারি। মাউন্ট করার পর আমরা Linux বা Windows-এর অ্যাভেইলেবল টুলগুলো ব্যবহার করে ফাইল এবং ডিরেক্টরির সাথে ইন্টারঅ্যাক্ট করতে পারি।

## Email (ইমেইল)

মেসেজ পাঠানো এবং রিসিভ করার জন্য আমাদের সাধারণত দুটি প্রোটোকলের প্রয়োজন হয়। ইন্টারনেট জুড়ে মেইল পাঠানোর জন্য ব্যবহৃত হয় **SMTP (Simple Mail Transfer Protocol)**। অন্যদিকে মেইল সার্ভিস থেকে ইমেইল রিসিভ করার জন্য **POP3** অথবা **IMAP** প্রোটোকল ব্যবহার করা হয়।

ইমেইল পাঠানো বা রিসিভ করার জন্য আমরা **Evolution**-এর মতো মেইল ক্লায়েন্ট ব্যবহার করতে পারি (এটি GNOME Desktop Environment-এর অফিশিয়াল মেইল ক্লায়েন্ট)।

**Linux - Install Evolution:**

```bash
00Luffy00@htb[/htb]$ sudo apt-get install evolution

```

> **Note:** Evolution চালু করার সময় যদি "bwrap: Can't create file at ..." টাইপের কোনো এরর দেখা দেয়, তবে `export WEBKIT_FORCE_SANDBOX=0 && evolution` কমান্ডটি ব্যবহার করে এটি চালু করুন।

সার্ভার যদি SMTPS বা IMAPS ব্যবহার করে, তবে সঠিক এনক্রিপশন মেথড (যেমন: ডেডিকেটেড পোর্টে TLS বা কানেক্ট করার পর STARTTLS) সিলেক্ট করতে হবে। অথেনটিকেশনের আন্ডারে থাকা "Check for Supported Types" অপশন ব্যবহার করে আমরা এটি নিশ্চিত করতে পারি।

## Databases (ডেটাবেস)

এন্টারপ্রাইজগুলোতে সাধারণত ডেটাবেস ব্যবহৃত হয় এবং বেশিরভাগ কোম্পানিই তাদের ইনফরমেশন স্টোর ও ম্যানেজ করার জন্য এটি ব্যবহার করে। আমরা মূলত **SQL relational databases** এবং সবচেয়ে প্রচলিত দুটি ডেটাবেস **MySQL** ও **MSSQL**-এর ওপর ফোকাস করব।

ডেটাবেসের সাথে ইন্টারঅ্যাক্ট করার প্রধান তিনটি উপায় রয়েছে:

1. Command Line Utilities (`mysql` বা `sqsh`)
2. Programming Languages
3. GUI Application (যেমন: HeidiSQL, MySQL Workbench, বা SQL Server Management Studio)

### Command Line Utilities

**MSSQL:**
Linux থেকে MSSQL-এর সাথে ইন্টারঅ্যাক্ট করতে আমরা `sqsh` ব্যবহার করতে পারি (Windows-এর ক্ষেত্রে `sqlcmd`)। `sqsh` কমান্ড শেলের মতো অনেক ফাংশনালিটি প্রদান করে।

Linux-এ `sqsh` ব্যবহার করে কানেক্ট করার কমান্ড:

```bash
00Luffy00@htb[/htb]$ sqsh -S 10.129.20.13 -U username -P Password123

```

Windows-এ `sqlcmd` ব্যবহার করে কানেক্ট করার কমান্ড:

```cmd
C:\htb> sqlcmd -S 10.129.20.13 -U username -P Password123

```

**MySQL:**
Linux বা Windows-এ MySQL-এর সাথে ইন্টারঅ্যাক্ট করার জন্য আমরা যথাক্রমে `mysql` বা `mysql.exe` ব্যবহার করতে পারি।

Linux - MySQL:

```bash
00Luffy00@htb[/htb]$ mysql -u username -pPassword123 -h 10.129.20.13

```

Windows - MySQL:

```cmd
C:\htb> mysql.exe -u username -pPassword123 -h 10.129.20.13

```

### GUI Application

ডেটাবেস ইঞ্জিনগুলোর সাধারণত নিজস্ব GUI অ্যাপ্লিকেশন থাকে (যেমন MySQL-এর জন্য MySQL Workbench এবং MSSQL-এর জন্য SSMS)। এর বিকল্প হিসেবে আমরা **dbeaver** ব্যবহার করতে পারি, যা Linux, macOS এবং Windows-এ কাজ করে এবং এটি একাধিক ডেটাবেস ইঞ্জিন (MSSQL, MySQL, PostgreSQL ইত্যাদি) সাপোর্ট করে।

Debian প্যাকেজ ব্যবহার করে `dbeaver` ইন্সটল করা:

```bash
00Luffy00@htb[/htb]$ sudo dpkg -i dbeaver-<version>.deb

```

অ্যাপ্লিকেশনটি রান করতে:

```bash
00Luffy00@htb[/htb]$ dbeaver &

```

ডেটাবেসে কানেক্ট করার জন্য আমাদের এক্সেট ক্রেডেনশিয়াল, টার্গেট আইপি, পোর্ট নাম্বার এবং ডেটাবেস ইঞ্জিন নির্দিষ্ট করে দিতে হবে। একবার ডেটাবেসে অ্যাক্সেস পেয়ে গেলে, আমরা Transact-SQL স্টেটমেন্ট ব্যবহার করে সংবেদনশীল তথ্য (যেমন ইউজারনেম ও পাসওয়ার্ড) এনুমারেট করতে পারি।

## General Troubleshooting (সাধারণ ট্রাবলশুটিং)

কোনো সার্ভিসে কানেক্ট করার সময় আমরা বিভিন্ন ধরনের সমস্যার সম্মুখীন হতে পারি। অ্যাক্সেস না পাওয়ার সম্ভাব্য কিছু কারণ:

* Authentication (অথেনটিকেশন ফেইল করা)
* Privileges (অ্যাক্সেস প্রিভিলেজ না থাকা)
* Network Connection (নেটওয়ার্ক কানেকশন লস)
* Firewall Rules (ফায়ারওয়াল ব্লক করা)
* Protocol Support (প্রোটোকল সাপোর্ট না থাকা)

সার্ভিস অনুযায়ী এরর মেসেজ ভিন্ন হতে পারে। এক্ষেত্রে আমরা এরর কোড (error codes) ব্যবহার করে অফিশিয়াল ডকুমেন্টেশন বা ফোরামে সমাধান খুঁজতে পারি।
