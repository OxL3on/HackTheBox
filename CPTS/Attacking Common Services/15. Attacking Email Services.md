## 1. Email Services Overview

`Mail Server` হলো এমন server, যা network-এর মাধ্যমে email গ্রহণ, পাঠানো ও সংরক্ষণ করে।

| Protocol | কাজ                                                | Default Port |
| -------- | -------------------------------------------------- | ------------ |
| `SMTP`   | Email পাঠানো ও server-to-server delivery           | `25`         |
| `POP3`   | Server থেকে email download করা                     | `110`        |
| `IMAP4`  | Server-এ email রেখে বিভিন্ন device থেকে access করা | `143`        |

Encrypted ports:

| Port  | Service                    |
| ----- | -------------------------- |
| `465` | SMTP over TLS              |
| `587` | SMTP Submission / STARTTLS |
| `993` | IMAP4 over TLS             |
| `995` | POP3 over TLS              |

- `POP3`: সাধারণত download করা message server থেকে সরিয়ে দেয়, তবে copy রেখে দেওয়ার option থাকতে পারে।
- `IMAP4`: সাধারণত message server-এ রেখে দেয়; একাধিক device থেকে access সহজ হয়।

## 2. Email Enumeration

প্রথমে DNS-এর `MX (Mail eXchanger)` record দেখে domain-এর mail server শনাক্ত করা যায়।

### MX Records

```
host -t MX hackthebox.eu
host -t MX microsoft.com
```

`dig` ব্যবহার করে:

```
dig mx inlanefreight.com | grep "MX" | grep -v ";"
```

Mail server-এর IP address বের করতে:

```
host -t A mail1.inlanefreight.htb
```

Online tool: [MXToolbox](https://mxtoolbox.com/)

MX record থেকে বোঝা যেতে পারে organization Google Workspace, Microsoft 365, Zoho অথবা নিজস্ব mail server ব্যবহার করছে কি না।

### Nmap Enumeration

```
sudo nmap -Pn -sV -sC -p25,143,110,465,587,993,995 10.129.14.128
```

- `-Pn` — Host discovery skip করে।
- `-sV` — Service version শনাক্ত করে।
- `-sC` — Default NSE scripts চালায়।
- `-p` — নির্দিষ্ট mail ports scan করে।

## 3. SMTP Username Enumeration

কিছু SMTP server-এর command ব্যবহার করে valid username শনাক্ত করা যায়।

### `VRFY`

নির্দিষ্ট user বা email account আছে কি না পরীক্ষা করে।

```
VRFY root
VRFY new-user
```

Server-এর response implementation অনুযায়ী পরিবর্তিত হতে পারে। `252` account যাচাইয়ের জন্য অনির্দিষ্ট response হতে পারে, আর `550` user unknown নির্দেশ করতে পারে।

### `EXPN`

Distribution list বা mailing alias-এর সদস্যদের তথ্য প্রকাশ করতে পারে।

```
EXPN john
EXPN support-team
```

### `RCPT TO`

Email-এর recipient শনাক্ত করে। Server-এর response থেকে recipient valid কি না বোঝার চেষ্টা করা যায়।

```
MAIL FROM:test@htb.com
RCPT TO:john
```

### Telnet দিয়ে SMTP Connect

```
telnet 10.10.110.20 25
```

### POP3 `USER` Command

কিছু POP3 server-এ `USER` command-এর response থেকে username valid কি না বোঝা যেতে পারে।

```
telnet 10.10.110.20 110
```

```
USER julio
USER john
```

`+OK` user গ্রহণ করার ইঙ্গিত দিতে পারে; `-ERR` rejection নির্দেশ করতে পারে। তবে server implementation অনুযায়ী ফল ভিন্ন হতে পারে।

### Automated SMTP Enumeration

Tool: [smtp-user-enum](https://github.com/pentestmonkey/smtp-user-enum)

```
smtp-user-enum -M RCPT -U userlist.txt \
-D inlanefreight.htb -t 10.129.203.7
```

- `-M` — Enumeration mode: `VRFY`, `EXPN` অথবা `RCPT`।
- `-U` — Username list।
- `-D` — Email domain।
- `-t` — Target mail server।

## 4. Cloud Email Enumeration

Cloud email provider-গুলোর নিজস্ব authentication ও implementation থাকে। তাই enumeration technique-ও আলাদা হতে পারে।

### O365spray

[O365spray GitHub](https://github.com/0xZDH/o365spray) Microsoft Office 365-এর username enumeration ও password spraying-এর tool।

প্রথমে domain Office 365 ব্যবহার করে কি না যাচাই:

```
python3 o365spray.py --validate --domain msplaintext.xyz
```

Username enumeration:

```
python3 o365spray.py --enum -U users.txt --domain msplaintext.xyz
```

- `--validate` — Domain-এর O365 usage যাচাই করে।
- `--enum` — সম্ভাব্য username পরীক্ষা করে।
- `-U` — Username wordlist।

## 5. Password Attacks

Email services-এ দুর্বল password বা password reuse থাকলে authentication ঝুঁকিতে পড়তে পারে।

### Hydra

[THC-Hydra](https://github.com/vanhauser-thc/thc-hydra) বিভিন্ন network service-এর authentication testing tool।

শুধু অনুমোদিত lab-এ POP3 password spraying-এর উদাহরণ:

```
hydra -L users.txt -p 'Company01!' -f 10.10.110.20 pop3
```

- `-L` — Username list।
- `-p` — একটি password।
- `-f` — Valid credential পাওয়া গেলে থামে।
- `pop3` — Target service।

**Password Spraying:** এক বা অল্প কয়েকটি password অনেক account-এ পরীক্ষা করা।

**Brute Force:** একটি বা একাধিক account-এর জন্য অনেক password পরীক্ষা করা।

Cloud service-এ সাধারণ Hydra-based attempts block হতে পারে। Module-এ উল্লেখিত অন্যান্য tools:

| Tool                                                 | Target                            |
| ---------------------------------------------------- | --------------------------------- |
| [O365spray](https://github.com/0xZDH/o365spray)      | Microsoft Office 365              |
| [MailSniper](https://github.com/dafthack/MailSniper) | Microsoft 365 security assessment |
| [CredKing](https://github.com/ustayready/CredKing)   | Gmail বা Okta-সংশ্লিষ্ট testing   |

### O365 Password Spraying

Source module-এর উদাহরণ:

```
python3 o365spray.py --spray -U usersfound.txt \
-p 'March2022!' --count 1 --lockout 1 --domain msplaintext.xyz
```

- `--spray` — Password spraying mode।
- `-U` — Username list।
- `-p` — পরীক্ষার password।
- `--count` — Password attempts-এর count।
- `--lockout` — Tool-এর lockout-related setting।
- `--domain` — Target domain।

বাস্তব service-এর rate limit ও lockout policy আগে বুঝতে হবে। এই ধরনের পরীক্ষা কেবল explicit authorization ও নির্ধারিত সীমার মধ্যে করা উচিত। Source-এর tool version অনুযায়ী option-এর আচরণ যাচাই করা প্রয়োজন।

## 6. Open SMTP Relay

`Open Relay` হলো misconfigured SMTP server, যা যথাযথ authentication বা restriction ছাড়াই email relay করতে দেয়।

### ঝুঁকি

- Spam পাঠাতে server অপব্যবহার হতে পারে।
- Forged sender address দিয়ে phishing সম্ভব হতে পারে।
- Email-এর প্রকৃত উৎস আড়াল করা সহজ হতে পারে।
- Organization-এর domain reputation ক্ষতিগ্রস্ত হতে পারে।

### Nmap দিয়ে পরীক্ষা

```
nmap -p25 -Pn --script smtp-open-relay 10.10.11.213
```

Output-এ `Server is an open relay` দেখা গেলে server relay abuse-এর ঝুঁকিতে থাকতে পারে। Result যাচাই ও reporting করতে হবে।

### Swaks

[Swaks](https://github.com/jetmore/swaks) একটি SMTP testing tool, যা SMTP conversation ও message delivery পরীক্ষা করতে ব্যবহার করা যায়।

```
swaks --from notifications@inlanefreight.com \
--to employees@inlanefreight.com \
--header 'Subject: Authorized SMTP Test' \
--body 'This is an authorized mail-flow test.' \
--server 10.10.11.213
```

এই command কেবল অনুমোদিত mail server-এ ব্যবহার করতে হবে। Open relay পরীক্ষা করার সময় অননুমোদিত recipient বা phishing content ব্যবহার করা উচিত নয়।

## 7. Quick Reference

| উদ্দেশ্য                     | Tool / Command                                         |
| ---------------------------- | ------------------------------------------------------ |
| MX record lookup             | `host -t MX DOMAIN`                                    |
| DNS MX enumeration           | `dig mx DOMAIN`                                        |
| Mail ports scan              | `nmap -Pn -sV -sC -p25,143,110,465,587,993,995 TARGET` |

| POP3 connect                 | `telnet TARGET 110`                                    |

| Office 365 domain validation | `o365spray.py --validate --domain DOMAIN`              |
| Email authentication testing | `hydra`                                                |
| Open relay check             | `nmap --script smtp-open-relay -p25 TARGET`            |
| SMTP testing                 | `swaks`                                                |

## Key Takeaways

- `MX` record mail server শনাক্ত করতে সাহায্য করে।
- SMTP-এর `VRFY`, `EXPN` ও `RCPT TO` কিছু ক্ষেত্রে username enumeration-এ কাজে লাগে।
- POP3-এর `USER` command থেকেও কখনো account validity সম্পর্কে ধারণা পাওয়া যায়।
- Cloud email provider-এর authentication ও security controls আলাদা হতে পারে।
- Open SMTP relay email spoofing, spam ও phishing-এর ঝুঁকি তৈরি করে।
- Pentest-এর সময় password attempts, account lockout এবং mail delivery-এর প্রভাব বিবেচনা করতে হবে।
