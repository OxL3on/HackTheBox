## **Protected File Transfers**

<img width="1024" height="559" alt="image" src="https://github.com/user-attachments/assets/f2750cea-ee43-4919-8ec0-15bb3918e926" />


Encrypting the data or files before a transfer is often necessary to prevent the data from being read if intercepted in transit.

### **File Encryption on Windows**

**Invoke-AESEncryption.ps1**

**Import Module Invoke-AESEncryption.ps1**

```powershell
**PS C:\htb> Import-Module .\Invoke-AESEncryption.ps1**
```

**File Encryption Example**

```powershell
**PS C:\htb> Invoke-AESEncryption -Mode Encrypt -Key "p4ssw0rd" -Path .\scan-results.txt**
```

### **File Encryption on Linux**

**Encrypting /etc/passwd with openssl**

```bash
00Luffy00@htb[/htb]$ openssl enc -aes256 -iter 100000 -pbkdf2 -in /etc/passwd -out passwd.enc

enter aes-256-cbc encryption password:
Verifying - enter aes-256-cbc encryption password:
```

**Decrypt passwd.enc with openssl**

```bash
00Luffy00@htb[/htb]$ openssl enc -d -aes256 -iter 100000 -pbkdf2 -in passwd.enc -out passwd

enter aes-256-cbc decryption password:
```
