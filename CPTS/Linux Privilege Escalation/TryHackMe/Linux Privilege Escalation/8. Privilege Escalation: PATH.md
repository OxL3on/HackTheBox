# Privilege Escalation: PATH

## PATH কী?

- `PATH` হলো Linux-এর একটি environment variable, যা executable খোঁজার directory নির্ধারণ করে।
- Shell-এর built-in command নয় এবং absolute path দেওয়া না থাকলে Linux, `PATH`-এ থাকা directory-গুলোতে executable খোঁজে।
- `PATH` = environment variable, আর `path` = কোনো ফাইলের location।

## 1. PATH Hijacking

কোনো user-এর write permission থাকা directory যদি `PATH`-এ থাকে, তাহলে application-কে hijack করে নিজের script চালানো সম্ভব।

কোনো vulnerability খোঁজার আগে ৪টি বিষয় যাচাই করতে হবে:

1. `$PATH`-এর মধ্যে কোন directory-গুলো আছে?
2. Current user কি ওই directory-গুলোর কোনো একটিতে write করতে পারে?
3. `$PATH` কি modify করা যায়?
4. এমন কোনো script/application আছে কি, যা এই vulnerability দ্বারা প্রভাবিত হবে?

## 2. Exploitation Process

- উদাহরণে একটি script system binary `thm` চালানোর চেষ্টা করে।
- Script-টি executable-এ compile করে SUID bit set করা হয়।
- এখন `path` script root privilege নিয়ে চলবে।
- Script যখন `thm` চালাবে, তখন Linux `$PATH`-এর directory-গুলোতে `thm` খুঁজবে।
- কোনো writable directory `PATH`-এ থাকলে সেখানে নিজের `thm` binary তৈরি করে চালানো সম্ভব।
- যেহেতু `path` script-এর SUID bit set, তাই binary-টি root privilege পেতে পারে।

## 3. Writable Directory খোঁজা

সব writable directory খুঁজতে:

```
find / -writable 2>/dev/null
```

Output পরিষ্কার করতে:

```
find / -writable 2>/dev/null | cut -d "/" -f 2,3 | grep -v proc | sort -u
```

- `grep -v proc` দিয়ে running process-সম্পর্কিত অনেক result বাদ দেওয়া হয়।
- পাওয়া writable directory-গুলো `$PATH`-এর সঙ্গে compare করতে হবে।
- `/usr`-এর subfolder-গুলোও পরীক্ষা করতে হবে।
- এই scenario-তে `/usr`-এর subfolder writable নয়।
- `/tmp` writable হলেও এটি শুরুতে `PATH`-এ নেই।

## 4. PATH Modify করা

`/tmp`-কে `PATH`-এর শুরুতে যোগ করতে:

```
export PATH=/tmp:$PATH
```

এখন `path` script `/tmp` directory-তেও `thm` executable খুঁজবে।

## 5. Fake Binary তৈরি

`/bin/bash` কপি করে `/tmp`-এ `thm` নামে রাখা যায়।

[medium.com](https://medium.com/purplebox/linux-privilege-escalation-with-path-variable-suid-bit-6b9c492411de?utm_source=chatgpt.com)

- Copy করা Bash-কে executable permission দিতে হবে।
- এই পর্যায়ে Bash নিজের user-এর privilege নিয়েই চলবে।
- কিন্তু `path` script root privilege নিয়ে চলার কারণে এর মাধ্যমে privilege escalation সম্ভব।

মূল বিষয়: SUID script কোনো command-কে absolute path দিয়ে execute না করে শুধু নাম দিয়ে চালালে, writable directory-তে একই নামে fake executable রেখে `PATH` hijacking করা সম্ভব।
