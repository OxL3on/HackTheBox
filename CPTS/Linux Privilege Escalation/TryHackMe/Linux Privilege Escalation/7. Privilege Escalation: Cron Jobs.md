# Privilege Escalation: Cron Jobs

## Cron Jobs কী?

- Cron নির্দিষ্ট সময়ে script বা binary চালায়।
- Cron job তার owner-এর privilege নিয়ে চলে, current user-এর privilege নিয়ে নয়।
- Root-এর cron job চালানো script পরিবর্তন করতে পারলে আমাদের script-ও root privilege নিয়ে চলবে।
- Cron configuration-কে crontab (cron table) বলা হয়।
- প্রতিটি user-এর নিজস্ব crontab থাকে। User login না করলেও cron job চলতে পারে।
- System-wide cron job দেখতে:

```
cat /etc/crontab
```

## 1. Writable Cron Script

- `/etc/crontab`-এ root-এর cron job খুঁজতে হবে।
- উদাহরণ: `backup.sh` প্রতি মিনিটে চলে এবং `prices.xls` ফাইলের backup তৈরি করে।
- Current user যদি `backup.sh` modify করতে পারে, তাহলে সেটিতে reverse shell script বসানো যায়।
- Cron job script-টি root হিসেবে চালালে reverse shell-ও root privilege পাবে।

মনে রাখবে:

1. Reverse shell command available tools-এর ওপর নির্ভর করে। যেমন, `nc`-তে `-e` option নাও থাকতে পারে।
2. Real penetration testing-এ system integrity ঠিক রাখতে reverse shell prefer করতে হবে।

\- Attacker machine-এ listener চালু রাখতে হবে, যাতে incoming connection receive করা যায়।

## 2. Path-based Cron Job Exploitation

কখনো script delete করা হলেও cron job থেকে যায়:

1. Admin নিয়মিত চালানোর জন্য script তৈরি করে।
2. সেটির জন্য cron job তৈরি করে।
3. পরে script আর প্রয়োজন না হওয়ায় delete করে।
4. কিন্তু cron job remove করতে ভুলে যায়।

এটি change management issue থেকে privilege escalation-এর সুযোগ তৈরি করে।

- উদাহরণ: `antivirus.sh` delete করা হয়েছে, কিন্তু cron job এখনো আছে।
- Cron job-এ script-এর full path দেওয়া না থাকলে `/etc/crontab`-এর `PATH` variable-এর directory-গুলোতে script খুঁজবে।
- তাই নিজের home directory-তে `antivirus.sh` নামে script তৈরি করলে cron job সেটি চালাতে পারে।
- Incoming reverse shell root privilege পেতে পারে।

## 3. Wildcard Exploitation

Cron job-এর সঙ্গে যুক্ত কোনো existing script পেলে সেটির কাজ ভালোভাবে বুঝতে হবে।

বিশেষ করে নিচের tools-এর wildcard feature exploit করা যেতে পারে:

- `tar`
- `7z`
- `rsync`

Important: Cron job check করা সবসময় জরুরি। Writable script, deleted script-এর leftover cron job এবং wildcard ব্যবহার—সবগুলোই privilege escalation-এর সুযোগ তৈরি করতে পারে।
