# Privilege Escalation: Capabilities


## Linux Capabilities

Capabilities হলো Linux-এ process বা binary-কে নির্দিষ্ট privilege দেওয়ার একটি পদ্ধতি।

এটি privilege-কে আরও ছোট ছোট অংশে ভাগ করে নিয়ন্ত্রণ করতে সাহায্য করে।

উদাহরণ: SOC Analyst-এর কোনো tool দিয়ে socket connection তৈরি করা প্রয়োজন, কিন্তু তাকে root access দিতে চাওয়া হচ্ছে না। Administrator ওই binary-কে প্রয়োজনীয় capability দিতে পারে। ফলে binary-টি root access ছাড়াই কাজটি করতে পারবে।

Capabilities-এর বিস্তারিত: `man capabilities`

### Capabilities Enumeration

Enabled capabilities দেখতে `getcap` ব্যবহার করা হয়।

```
getcap -r / 2>/dev/null
```

`2>/dev/null` ব্যবহার করলে permission-related error message দেখা যাবে না।

[infosecinstitute.com](https://www.infosecinstitute.com/resources/capture-the-flag/empire-breakout-vulnhub-ctf-walkthrough/?utm_source=chatgpt.com)

মনে রাখবে: এই privilege escalation vector SUID enumeration দিয়ে পাওয়া যাবে না। কারণ এখানে `vim` বা তার copy-তে SUID bit set নেই; বরং binary-তে capability দেওয়া আছে।

## Capabilities Abuse with GTFOBins

কোনো binary-তে dangerous capability পাওয়া গেলে [GTFOBins](https://gtfobins.github.io/?utm_source=chatgpt.com) থেকে সেটি abuse করার পদ্ধতি খুঁজতে হবে।

এই task-এ `vim`-এর capability ব্যবহার করে root shell পাওয়া যায়।

[medium.com](https://medium.com/%40NoOne./linux-privilege-escalation-tryhackme-part-2-9a4cddba01ab?utm_source=chatgpt.com)

Vim capability payload:

```
./vim -c ':py3 import os; os.setuid(0); os.execl("/bin/sh", "sh", "-c", "reset; exec sh")'
```

এটি `vim` ব্যবহার করে UID `0` সেট করে root shell চালু করে।

[learn.redhat.com](https://learn.redhat.com/t5/Platform-Linux/Current-User-Logged-In/td-p/50069?utm_source=chatgpt.com)

### Quick Revision

| বিষয়               | মনে রাখবে                                             |
| ------------------ | ----------------------------------------------------- |
| Capabilities       | Binary-কে নির্দিষ্ট privilege দেওয়া                   |
| Enumeration        | `getcap -r / 2>/dev/null`                             |
| SUID থেকে পার্থক্য | SUID bit ছাড়াও privilege পাওয়া সম্ভব                  |
| Exploitation       | Dangerous capability থাকা binary খুঁজে GTFOBins check |
| Example            | `vim` capability abuse করে root shell                 |

মূল পার্থক্য:

- SUID → File owner-এর privilege-এ execute।
- Capabilities → Binary-কে নির্দিষ্ট privileged operation করার অনুমতি দেয়।
