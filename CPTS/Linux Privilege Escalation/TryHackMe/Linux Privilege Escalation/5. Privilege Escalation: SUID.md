# Privilege Escalation: SUID


## SUID / SGID

Linux-এ সাধারণত file-এর `read`, `write`, `execute` permission user-এর privilege অনুযায়ী কাজ করে।

- SUID (Set-user Identification): File execute হলে file owner-এর privilege ব্যবহার করে।
- SGID (Set-group Identification): File execute হলে group owner-এর privilege ব্যবহার করে।

এগুলোর special permission bit হলো `s`।

SUID ও SGID file খোঁজা:

```
find / -type f -perm -04000 -ls 2>/dev/null
```

## Root-owned SUID Nano Abuse

`nano`-এর SUID bit set এবং owner `root` হলে root privilege ব্যবহার করে file read ও edit করা সম্ভব।

এখানে দুটি পদ্ধতি দেখানো হয়েছে:

### 1. Read `/etc/shadow` এবং Password Crack

`/etc/shadow`-এ password hashes থাকে।

SUID Nano দিয়ে file পড়া:

```
nano /etc/shadow
```

`/etc/shadow` ও `/etc/passwd` file ব্যবহার করে `unshadow` দিয়ে John the Ripper-এর উপযোগী file তৈরি করতে হবে।

```
unshadow passwd.txt shadow.txt > passwords.txt
```

এরপর সঠিক wordlist ব্যবহার করে John the Ripper দিয়ে password crack করা যায়।

John the Ripper শেখার জন্য: [TryHackMe - John the Ripper Basics](https://tryhackme.com/room/johntheripperbasics?utm_source=chatgpt.com)

### 2. `/etc/passwd`-এ Root User যোগ করা

Password crack না করেও `/etc/passwd`-এ নতুন root-privileged user যোগ করা যায়।

ধাপগুলো:

1. Kali Linux-এর `openssl` দিয়ে নতুন user-এর password hash তৈরি করতে হবে।
2. Username ও password hash `/etc/passwd` file-এ যোগ করতে হবে।
3. User entry-তে `root:/bin/bash` ব্যবহার করে root shell দেওয়া হয়।
4. নতুন user-এ switch করে root privilege পাওয়া যায়।
