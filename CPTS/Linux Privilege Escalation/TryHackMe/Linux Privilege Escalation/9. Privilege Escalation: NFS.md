# Privilege Escalation: NFS

## NFS কী?

- Privilege escalation শুধু local access-এর মধ্যে সীমাবদ্ধ নয়।
- Shared folder, SSH, Telnet এবং remote management interface ব্যবহার করেও root access পাওয়া সম্ভব।
- কখনো target system-এ root SSH private key খুঁজে root হিসেবে SSH connection করাও privilege escalation-এর উপায়।
- NFS misconfiguration CTF, exam এবং network backup system থাকা penetration testing environment-এ দেখা যেতে পারে।

## 1. NFS Configuration

NFS configuration থাকে:

```
/etc/exports
```

- NFS server install করার সময় এই file তৈরি হয়।
- সাধারণত users এই file read করতে পারে।

## 2. no_root_squash

Important

- Default অবস্থায় NFS root user-কে `nfsnobody` হিসেবে map করে এবং file-এর root privilege সরিয়ে দেয়।
- কিন্তু `no_root_squash` option থাকলে এই restriction থাকে না।
- Share writable হলে সেখানে SUID executable তৈরি করে target system-এ root privilege পাওয়া সম্ভব।

## 3. Exploitation Process

1. Attacker machine থেকে mountable NFS shares enumerate করতে হবে।
2. `no_root_squash` থাকা share mount করতে হবে।
3. Mounted share-এর মধ্যে executable তৈরি করতে হবে।
4. Executable-টি target system-এ `/bin/bash` চালাবে।
5. Code compile করে executable-এর SUID bit set করতে হবে।
6. যেহেতু share mount করা অবস্থায় কাজ করা হয়েছে, তাই `nfs.c` ও `nfs` file সরাসরি target system-এ পাওয়া যাবে; আলাদা করে transfer করতে হবে না।
7. Target system-এ `nfs` executable-এর SUID bit থাকবে এবং এটি root privilege নিয়ে চলবে।

মূল বিষয়: Writable NFS share-এ `no_root_squash` enabled থাকলে attacker root হিসেবে SUID executable তৈরি করতে পারে। Target system-এ সেটি চালিয়ে root privilege পাওয়া সম্ভব।
