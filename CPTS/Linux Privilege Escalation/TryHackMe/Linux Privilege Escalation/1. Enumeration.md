# Enumeration

Enumeration হলো কোনো system-এ access পাওয়ার পর system, user, process, network ও সম্ভাব্য privilege escalation vector সম্পর্কে তথ্য সংগ্রহ করা। এটি initial access এবং post-compromise—দুই পর্যায়েই গুরুত্বপূর্ণ।

## 1. System Information

| Command             | কাজ                                                                                     |
| ------------------- | --------------------------------------------------------------------------------------- |
| `hostname`          | Target machine-এর নাম দেখায়; নাম থেকে system-এর role বোঝা যেতে পারে। যেমন `SQL-PROD-01` |
| `uname -a`          | Kernel ও system information দেখায়; kernel vulnerability খুঁজতে কাজে লাগে।               |
| `cat /proc/version` | Kernel version ও GCC-এর মতো compiler installed আছে কি না জানায়।                         |
| `cat /etc/issue`    | OS information দেখায়; fileটি customize করা যায়।                                         |

## 2. Running Processes — `ps`

Running process ও system-এর activity দেখতে ব্যবহার হয়।

- `PID`: Process ID
- `TTY`: User-এর terminal type
- `Time`: Process-এর ব্যবহৃত CPU time (কতক্ষণ ধরে চলছে তা নয়)
- `CMD`: Running command/executable (command-line parameter দেখায় না)

Useful options:

```
ps -A       # সব running process
ps axjf     # Process tree
ps aux      # সব user-এর process, process চালানো user ও terminal ছাড়া চলা process
```

## 3. Environment Variables — `env`

```
env
```

Environment variables দেখায়। বিশেষ করে `PATH` check করতে হবে। এতে Python বা GCC-এর মতো compiler/language থাকলে code চালানো বা privilege escalation-এ কাজে লাগতে পারে।

## 4. Sudo Permissions — `sudo -l`

```
sudo -l
```

বর্তমান user কোন কোন command `sudo` দিয়ে root privilege-এ চালাতে পারে তা দেখায়।

## 5. Files & Directories — `ls`

```
ls -la
```

Privilege escalation খোঁজার সময় সবসময় `-la` ব্যবহার করা ভালো। কারণ hidden file সাধারণ `ls` বা `ls -l`-এ দেখা যায় না।

## 6. User & Group — `id`

```
id
```

বর্তমান user-এর privilege level ও group membership দেখায়। অন্য user-এর তথ্যও দেখা যায়:

```
id username
```

## 7. Users — `/etc/passwd`

```
cat /etc/passwd
```

System-এর user-দের তথ্য পাওয়া যায়। Output বড় হলে useful list তৈরি করা যায়; `/home` থাকা user-দের খুঁজতে:

```
cat /etc/passwd | grep home
```

সব user useful নয়—অনেকগুলো system বা service account।

## 8. Command History — `history`

```
history
```

আগের command দেখে system সম্পর্কে ধারণা পাওয়া যায়। কখনো কখনো password বা username-ও history-তে থাকতে পারে।

## 9. Network Enumeration

Network interfaces:

```
ifconfig
```

Network interface ও IP information দেখায়। Target অন্য network-এ pivoting point হতে পারে।

উদাহরণে target-এর interface ছিল `eth0`, `tun0`, `tun1`; attacker শুধু `eth0`-তে পৌঁছাতে পারত।

Routing information:

```
ip route
```

কোন network route আছে তা যাচাই করে।

Network connections — `netstat`:

| Command        | কাজ                                        |
| -------------- | ------------------------------------------ |
| `netstat -a`   | সব listening port ও established connection |
| `netstat -at`  | TCP connection                             |
| `netstat -au`  | UDP connection                             |
| `netstat -l`   | Listening port                             |
| `netstat -lt`  | TCP listening port                         |
| `netstat -s`   | Protocol অনুযায়ী network statistics        |
| `netstat -tp`  | Service name ও PID-সহ connection           |
| `netstat -ltp` | Listening port-এর service name ও PID       |
| `netstat -i`   | Network interface statistics               |

অন্য user-এর process হলে `PID/Program name` ফাঁকা থাকতে পারে; root privilege-এ চালালে তথ্য দেখা যেতে পারে।

Common command:

```
netstat -ano
```

- `-a`: সব socket
- `-n`: Name resolve করবে না
- `-o`: Timers দেখাবে

## 10. File Search — `find`

System-এ গুরুত্বপূর্ণ file, permission ও privilege escalation vector খুঁজতে ব্যবহার হয়।

File ও directory খোঁজা:

| Command                       | কাজ                                             |
| ----------------------------- | ----------------------------------------------- |
| `find . -name flag1.txt`      | Current directory-তে `flag1.txt` খোঁজা          |
| `find /home -name flag1.txt`  | `/home`-এ file খোঁজা                            |
| `find / -type d -name config` | `config` directory খোঁজা                        |
| `find / -type f -perm 0777`   | সবার read, write ও execute permission থাকা file |
| `find / -perm a=x`            | Executable file                                 |
| `find /home -user frank`      | `/home`-এ `frank`-এর file                       |
| `find / -mtime 10`            | গত ১০ দিনে modified file                        |
| `find / -atime 10`            | গত ১০ দিনে accessed file                        |
| `find / -cmin -60`            | গত ৬০ মিনিটে changed file                       |
| `find / -amin -60`            | গত ৬০ মিনিটে accessed file                      |
| `find / -size 50M`            | ৫০ MB file                                      |

`+` ও `-` ব্যবহার করে নির্দিষ্ট size-এর চেয়ে বড় বা ছোট file খোঁজা যায়।

Permission ও search error-এর output পরিষ্কার রাখতে:

```
find / -type f 2>/dev/null
```

Writable folders:

```
find / -writable -type d 2>/dev/null
find / -perm -222 -type d 2>/dev/null
find / -perm -o w -type d 2>/dev/null
```

তিনটি command-ই world-writable folder খোঁজে। `-perm` কীভাবে কাজ করবে তা নির্ধারণ করে।

World-executable folders:

```
find / -perm -o x -type d 2>/dev/null
```

Development tools ও languages:

```
find / -name perl*
find / -name python*
find / -name gcc*
```

SUID files:

```
find / -perm -u=s -type f 2>/dev/null
```

SUID file owner-এর privilege-এ execute হয়, চালানো user-এর privilege-এ নয়। তাই এটি privilege escalation-এর সম্ভাব্য পথ।
