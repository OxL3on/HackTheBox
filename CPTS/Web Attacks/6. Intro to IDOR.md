# Intro to IDOR - [LINK](https://academy.hackthebox.com/app/module/134/section/1179)


Insecure Direct Object References (IDOR) vulnerabilities occur when a web application exposes a direct reference to an internal object (like a file, database record, or user ID) that an end-user can manipulate to access or modify data belonging to others.

**The Root Cause: Lack of Access Control**
Exposing a direct reference (like a sequential database ID) is not inherently a vulnerability. An IDOR vulnerability explicitly exists because the back-end lacks a robust access control mechanism (such as Role-Based Access Control, or RBAC) to validate the request.

* Developers often mistakenly rely on the front-end application to hide data or functions, assuming standard users won't manually manipulate HTTP requests.
* If the back-end does not verify that the currently authenticated user actually has permission to access the requested specific object, an attacker can simply guess, calculate, or iterate through reference IDs to bypass all restrictions.

**Basic Exploitation Example**
If a user requests a personal file and the application generates a URL like `download.php?file_id=123`, an attacker can intercept or modify the request to target `download.php?file_id=124`. If the server fails to check ownership of object `124`, it will successfully serve the other user's file.

**Impact and Attack Vectors**

* **Information Disclosure:** Unauthorized access to private files, Personally Identifiable Information (PII), or sensitive financial data by enumerating IDs.
* **Data Modification & Deletion:** Altering or deleting resources owned by other users. If the ID references user profile settings, manipulating it can lead to complete account takeover.
* **Insecure Function Calls (Privilege Escalation):** Exploiting exposed admin-only URL parameters or APIs. If a standard user discovers and sends a request to an administrative endpoint, and the back-end fails to verify their administrative role, they can execute unauthorized operations like changing user passwords or granting admin privileges.
