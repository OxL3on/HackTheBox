# Bypassing Basic Authentication - [LINK](https://academy.hackthebox.com/app/module/134/section/1175)


Bypassing HTTP Basic Authentication via Verb Tampering relies on exploiting web servers that restrict access based only on specific HTTP methods (like `GET` and `POST`), leaving alternative methods unprotected.

1. **Identify the Restricted Endpoint:**
Locate the functionality triggering the 401 Unauthorized or HTTP Basic Auth prompt (e.g., clicking a "Reset" button leading to `/admin/reset.php`).


2. **Enumerate Allowed Methods:** Use an OPTIONS request to reveal accepted verbs.
```bash
curl -i -X OPTIONS http://SERVER_IP:PORT/

```

Look for the `Allow` header in the response to determine which methods the server accepts (e.g., `Allow: POST,OPTIONS,HEAD,GET`).


3. **Intercept the Request:**
Capture the original request (typically a `GET` request) triggering the authentication prompt in a proxy tool like Burp Suite.


4. **Tamper the HTTP Verb:**
Right-click the request in Burp and select **Change Request Method**, or manually edit the verb at the top of the HTTP request.

* **Test POST:** Check if the authentication filter also covers POST requests.
* **Test HEAD:** Because a `HEAD` request is identical to a `GET` request but returns no response body, it frequently bypasses poorly configured authentication filters while still forcing the back-end script to execute.


5. **Forward and Verify:**
Send the modified `HEAD` request. If successful, you will bypass the 401 prompt and receive an empty response, but the back-end action (e.g., resetting the files) will have successfully executed on the server.
