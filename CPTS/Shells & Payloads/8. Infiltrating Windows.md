## Fingerprinting Windows Hosts

* **ICMP TTL:** A Time-To-Live (TTL) of **128** strongly indicates a Windows operating system.
* **Nmap OS Detection:** Execute `sudo nmap -v -O <IP>` to identify the specific Windows build. Use `-A -Pn` if firewalls block standard checks.
* **Banner Grabbing:** Run `sudo nmap -v <IP> --script banner.nse` to extract service banners from open ports (e.g., identifying VMWare services or IIS versions).

## Payload Types & Delivery

* **DLLs:** Injectable libraries used for privilege escalation or User Account Control (UAC) bypasses.
* **Batch (.bat):** Native DOS text scripts ideal for automated command execution.
* **VBS:** Legacy scripting language frequently used in macro-based phishing payloads.
* **MSI:** Windows Installer databases executed via `msiexec` to drop elevated reverse shells.
* **PowerShell:** .NET-based dynamic shell and scripting language.
* **Tooling:** Generate payloads using **MSFVenom**, **Mythic C2**, or **Nishang**. Transfer files to the target utilizing **Impacket** (psexec, smbserver), native SMB shares (`C$`, `ADMIN$`), or MSF's built-in staging.

## Shell Selection: CMD vs. PowerShell

| Feature | CMD | PowerShell |
| --- | --- | --- |
| **Best Used For** | Older hosts (XP/7), basic native DOS tools, and bypassing execution policies. | Modern infrastructure, custom cmdlets, and interacting with cloud services. |
| **Stealth** | **High:** Does not retain command history by default. | **Low:** Extensive logging mechanisms and AMSI integration. |
| **Data Format** | Text-based input and output. | Object-based (.NET) input and output. |

> **Evasion Note:** The Windows Subsystem for Linux (WSL) and PowerShell Core are current blind spots for defenders, as network requests originating from a WSL instance frequently bypass both Windows Defender and the Windows Firewall.
