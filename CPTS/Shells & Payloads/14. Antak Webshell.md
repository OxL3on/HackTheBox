# Antak Webshell - [LINK](https://academy.hackthebox.com/app/module/115/section/1124)

IPPSEC's blog site [ippsec.rocks](ippsec.rocks)

The Antak Webshell is an ASP.NET-based payload from the Nishang project that provides a highly functional, PowerShell-themed web interface for exploiting Windows targets.

**Core Concepts**

* **ASPX (Active Server Page Extended):** Microsoft's ASP.NET file type. Uploading a malicious `.aspx` file to a Windows/IIS web server allows the backend to compile and execute your code, granting Remote Code Execution (RCE).
* **Antak Capabilities:** It functions like a browser-based PowerShell console. While it executes each command as a new process, it excels at executing scripts entirely in memory and encoding commands to bypass basic filtering.
* **Default Location:** Found natively in Kali/Parrot OS at `/usr/share/nishang/Antak-WebShell/antak.aspx`.

**Deployment & Execution Workflow**

1. **Clone the Payload:** Never edit the original file.
Copy the base payload to your working directory so you don't corrupt the master file:
`cp /usr/share/nishang/Antak-WebShell/antak.aspx /home/user/Upload.aspx`


2. **Configure Credentials:** Line 14.
Antak enforces authentication to prevent others from hijacking your session. Open the file and modify the default username and password variables on line 14.


3. **Sanitize for Evasion:**
Delete the ASCII art and developer comments from the source code. These elements are highly signatured and will instantly trigger Antivirus (AV) or Web Application Firewalls (WAF).


4. **Upload and Navigate:**
Upload the modified `.aspx` file via the target's vulnerable web form (e.g., an image upload portal). Navigate to the resulting file path in your browser (e.g., `target.local/files/Upload.aspx`) and log in.


5. **Execute Commands:**
Once authenticated, use the interface to issue native PowerShell commands, upload/download secondary tools, or execute a one-liner to establish a stable reverse shell back to your C2 framework. Type `help` in the UI for command syntax.
