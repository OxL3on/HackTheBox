# Infiltrating Unix/Linux - [LINK](https://academy.hackthebox.com/app/module/115/section/1114)


Unix/Linux systems host over 70% of the internet's web infrastructure. Gaining an initial shell on these environments usually involves exploiting a vulnerability in the hosted web application and establishing a reverse shell, followed by upgrading that shell for post-exploitation.

## 1. Initial Reconnaissance & Enumeration

Before attacking, map the underlying infrastructure and services to understand the attack surface.

* **Nmap Scan:** `nmap -sC -sV <TARGET_IP>`
* **Key Identification Points:**
* **OS/Distribution:** E.g., CentOS, Ubuntu.
* **Web Stack:** E.g., Apache 2.4.6, PHP 7.2.
* **Application/Version:** Navigate to the web app (Ports 80/443). Look closely at footers, login pages, or source code for exact version numbers (e.g., `rConfig 3.9.6`).



## 2. Discovering the Exploit

Once the application and version are identified, search for known vulnerabilities (CVEs) and Proof of Concepts (PoCs).

* **Search Engine:** `rConfig 3.9.6 exploit metasploit github`
* **Metasploit Search:** `search rconfig`

**Handling Missing Exploit Modules:**
If a known Metasploit module is missing from your local installation, you can download the raw `.rb` (Ruby) file from Rapid7's GitHub.

1. Find your Metasploit exploits directory: `locate exploits | grep metasploit` (Usually `/usr/share/metasploit-framework/modules/exploits/`).
2. Download the `.rb` file into the appropriate sub-directory (e.g., `/linux/http/`).
3. Reload Metasploit.

## 3. Exploitation & Establishing a Shell

Using the identified Metasploit module to exploit the target.

1. **Select the exploit:** `use exploit/linux/http/rconfig_vendors_auth_file_upload_rce`
2. **Configure:** Set `RHOSTS`, `LHOST`, `LPORT`, and any required application credentials.
3. **Execute:** Type `exploit`.

**Exploit Execution Flow:**
The module checks the version ➔ authenticates ➔ uploads a PHP payload ➔ triggers the payload to call back to the attacker ➔ deletes the PHP file ➔ drops the attacker into a `meterpreter >` prompt.

## 4. Upgrading to a TTY Shell (Python)

Typing `shell` in Meterpreter drops you into a native system shell. However, this is usually a "dumb" or **non-TTY shell**, meaning you have no prompt, no tab-completion, and cannot run interactive commands like `su` or `sudo`.

You must upgrade the shell to a fully interactive TTY shell.

1. **Check for Python:** `which python` or `which python3`
2. **Spawn the TTY Shell:**
```bash
# If Python 2 is installed:
python -c 'import pty; pty.spawn("/bin/bash")'

# If Python 3 is installed:
python3 -c 'import pty; pty.spawn("/bin/bash")'

```


*(Note: You can use `/bin/sh` or `/bin/bash` depending on what is available on the target system).*

Once executed, you will receive a proper interactive prompt (e.g., `bash-4.2$`) and full access to standard system commands.
