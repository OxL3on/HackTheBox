# Laudanum, One Webshell to Rule Them All - [LINK](https://academy.hackthebox.com/app/module/115/section/1122)


[Laudanum](https://github.com/jbarcia/Web-Shells/tree/master/laudanum) is a comprehensive repository of pre-built, injectable web shells (ASP, ASPX, JSP, PHP, etc.) designed to provide remote code execution and reverse shell capabilities directly through a web browser. Native to Kali and Parrot OS, it is a staple toolkit for exploiting unrestricted file upload vulnerabilities.

**Default Directory:** `/usr/share/laudanum/`

## Crucial Preparation Steps

Unlike basic one-liner web shells, Laudanum shells have built-in security mechanisms to prevent other actors from hijacking your shell. You **must** configure them before uploading.

* **Whitelist Your IP:** Open the shell file (e.g., `shell.aspx`) and locate the `allowedIps` variable (typically around line 59). You must add your attacker machine's IP address to this array, or the shell will reject your connection.
* **Sanitize for Evasion:** Laudanum shells contain heavy commenting and ASCII art. You must delete these before uploading, as they are highly signatured and will instantly trigger basic Antivirus (AV) or Web Application Firewalls (WAF).

## The Laudanum Attack Workflow

1. **Clone the Payload:** Never edit the base file directly.
```bash
cp /usr/share/laudanum/aspx/shell.aspx /home/tester/demo.aspx

```


2. **Configure:** Edit `demo.aspx`, update `allowedIps`, and strip out comments/ASCII art.
3. **Upload:** Leverage the target's vulnerable file upload feature. Pay close attention to the application's response—it often leaks the destination directory (e.g., `Saved to \\files\demo.aspx`).
4. **Navigate & Execute:** Access the uploaded shell via your browser.
* *Pathing Quirks:* If the backend uses Windows-style routing, you may need to format the URL carefully (e.g., `[http://target.local//files/demo.aspx](http://target.local//files/demo.aspx)`).


5. **Interact:** Use the Laudanum web UI to execute system commands (e.g., `systeminfo`, `whoami`) and map the underlying operating system.
