## Windows Logon Accounts

### ১. Interactive Logon

User credentials দিয়ে local বা domain system-এ login করলে Interactive Session তৈরি হয়।

উদাহরণ:

- সরাসরি computer-এ login।
- `runas` দিয়ে secondary logon session।
- Remote Desktop (RDP) দিয়ে login।

### ২. Non-interactive Accounts

Windows services, applications ও scheduled tasks স্বয়ংক্রিয়ভাবে চালাতে ব্যবহৃত হয়। সাধারণত সরাসরি login লাগে না এবং user password-এর পরিবর্তে built-in account identity ব্যবহার করে।

| Account         | পরিচয় ও Privileges                                                                                                                       |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Local System    | `NT AUTHORITY\SYSTEM` — Windows-এর অত্যন্ত privileged account; local Administrators-এর চেয়েও বেশি ক্ষমতাসম্পন্ন।                         |
| Local Service   | `NT AUTHORITY\LocalService` — কম privilege; local user-এর মতো সীমিত access।                                                              |
| Network Service | `NT AUTHORITY\NetworkService` — local machine-এ সীমিত privilege; নির্দিষ্ট network service-এর জন্য authenticated session তৈরি করতে পারে। |

মনে রাখো: Interactive = user নিজে login করে। Non-interactive = Windows account ব্যবহার করে service/task স্বয়ংক্রিয়ভাবে চলে।
