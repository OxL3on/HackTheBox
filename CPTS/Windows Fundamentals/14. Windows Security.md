## ১. Security Identifier (SID)

SID হলো প্রতিটি security principal (user/group)-এর unique identifier। Windows access token-এ SID ব্যবহার করে user-এর অনুমোদিত কাজ নির্ধারণ করে।

```
whoami /user
```

উদাহরণ:

```
User Name   SID
ws01\bob    S-1-5-21-674899381-4069889467-2080702030-1002
```

SID format:

```
(SID)-(revision)-(identifier-authority)-(subauthority1)-(subauthority2)-...
```

| অংশ                               | অর্থ                                 |
| --------------------------------- | ------------------------------------ |
| `S`                               | SID identifier                       |
| `1`                               | Revision level                       |
| `5`                               | Identifier authority                 |
| `21`                              | Subauthority                         |
| `674899381-4069889467-2080702030` | Computer/domain identifier অংশ       |
| `1002`                            | RID; account-কে আলাদা করে শনাক্ত করে |

## ২. SAM, ACL, ACE ও Access Token

- SAM (Security Accounts Manager): Windows local account database/management-এর অংশ।
- ACL: কোন user/group/process access পাবে, তার তালিকা।
- ACE: ACL-এর প্রতিটি permission entry।
- DACL: Access allow/deny নিয়ন্ত্রণ করে।
- SACL: Access attempt audit/logging-এর জন্য।
- Security Descriptor: Object-এর owner, group এবং ACL-সংক্রান্ত তথ্য রাখে।
- Access Token: SID ও অন্যান্য security information ধারণ করে; LSA authorization-এ এটি যাচাই করে।

এগুলো বোঝা Windows privilege escalation ও access control analysis-এর জন্য গুরুত্বপূর্ণ।

## ৩. User Account Control (UAC)

[UAC](https://docs.microsoft.com/en-us/windows/security/identity-protection/user-account-control/how-user-account-control-works?utm_source=chatgpt.com) অননুমোদিত administrative পরিবর্তন ঠেকাতে সাহায্য করে।

- Admin Approval Mode: Administrator-level কাজের আগে consent prompt দেখাতে পারে।
- Standard user-এর privilege না থাকলে operation deny হতে পারে অথবা administrator password চাইতে পারে।
- UAC prompt malware/script-এর execution আটকে রাখতে পারে, যতক্ষণ না অনুমতি দেওয়া হয়।

## ৪. Windows Registry

Registry হলো Windows ও application settings-এর hierarchical database। খুলতে `regedit` ব্যবহার করো।

- `HKLM`: Local system settings।
- `HKCU`: Current user settings।
- `HKLM`-এর প্রধান subkeys: `SAM`, `SECURITY`, `SYSTEM`, `SOFTWARE`, `HARDWARE`, `BCD`।
- Registry files: `C:\Windows\System32\Config\`
- User hive: `C:\Users\<USERNAME>\NTUSER.DAT`

```
gci -Hidden
```

### Registry Value Types

| Type                      | কাজ                                           |
| ------------------------- | --------------------------------------------- |
| `REG_BINARY`              | Binary data                                   |
| `REG_DWORD`               | 32-bit number                                 |
| `REG_DWORD_LITTLE_ENDIAN` | Little-endian 32-bit number                   |
| `REG_DWORD_BIG_ENDIAN`    | Big-endian 32-bit number                      |
| `REG_EXPAND_SZ`           | Environment variable-সহ string, যেমন `%PATH%` |
| `REG_LINK`                | Symbolic link target path                     |
| `REG_MULTI_SZ`            | একাধিক null-terminated string                 |
| `REG_NONE`                | Undefined data type                           |
| `REG_QWORD`               | 64-bit number                                 |
| `REG_QWORD_LITTLE_ENDIAN` | Little-endian 64-bit number                   |
| `REG_SZ`                  | Null-terminated string                        |

Reference: [Registry Value Types](https://docs.microsoft.com/en-us/windows/win32/sysinfo/registry-value-types?utm_source=chatgpt.com)

## ৫. Run ও RunOnce Keys

এই keys Windows startup বা user login-এর সময় application চালাতে ব্যবহৃত হয়। তাই persistence investigation-এ এগুলো পরীক্ষা করা গুরুত্বপূর্ণ।

চারটি গুরুত্বপূর্ণ path:

```
HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\Run
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\RunOnce
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\RunOnce
```

Values দেখতে:

```
reg query HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\Run
reg query HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
```

উদাহরণস্বরূপ, এখানে startup applications দেখা যেতে পারে:

```
SecurityHealth    REG_EXPAND_SZ    %windir%\system32\SecurityHealthSystray.exe
RTHDVCPL          REG_SZ           "C:\Program Files\Realtek\Audio\HDA\RtkNGUI64.exe" -s
Greenshot         REG_SZ           C:\Program Files\Greenshot\Greenshot.exe
```

## ৬. Application Whitelisting

Whitelisting: শুধু অনুমোদিত application চালানোর অনুমতি দেয়। অন্যদিকে Blacklisting নিষিদ্ধ application আটকায়, বাকিগুলো অনুমোদিত থাকে।

- Whitelisting-এর ভিত্তি: Zero Trust — নির্দিষ্টভাবে অনুমোদিত না হলে software-কে অনুমোদিত ধরা হয় না।
- বড় network-এ প্রথমে Audit Mode ব্যবহার করলে ভুল করে প্রয়োজনীয় application block হওয়ার ঝুঁকি কমে।
- [NIST Whitelisting Guide](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-167.pdf?utm_source=chatgpt.com)

### AppLocker

[AppLocker](https://docs.microsoft.com/en-us/windows/security/threat-protection/windows-defender-application-control/applocker/applocker-overview?utm_source=chatgpt.com) হলো Microsoft-এর application control/whitelisting solution।

এটি নিয়ন্ত্রণ করতে পারে:

- Executables ও DLLs
- Scripts
- Windows Installer files
- Packaged apps ও installers

Rules তৈরি করা যায় publisher/digital signature, product name, filename, version, path বা hash অনুযায়ী; user বা security group-এ প্রয়োগ করা যায়।

## ৭. Local Group Policy

Group Policy দিয়ে Windows settings ও security restrictions নিয়ন্ত্রণ করা যায়।

- Domain environment-এ Domain Controller থেকে GPO প্রয়োগ হতে পারে।
- Local Group Policy একক computer-এ ব্যবহার করা যায়।
- খুলতে: `gpedit.msc`
- দুটি প্রধান বিভাগ: `Computer Configuration` ও `User Configuration`।

ব্যবহার:

- Password requirements ও auditing
- Application execution restrictions
- Security settings
- Credential Guard configuration

Credential Guard LSA-কে isolate করে credential theft-এর ঝুঁকি কমাতে সাহায্য করে।

## ৮. Windows Defender Antivirus

Windows-এর built-in antivirus। গুরুত্বপূর্ণ features:

- Real-time protection: পরিচিত threat শনাক্ত ও প্রতিরোধ।
- Cloud-delivered protection: সন্দেহজনক sample বিশ্লেষণ।
- Tamper Protection: Registry, PowerShell বা Group Policy দিয়ে security settings পরিবর্তন ঠেকাতে সাহায্য করে।
- Controlled Folder Access: Ransomware-এর অননুমোদিত file changes প্রতিরোধে সাহায্য করে।
- Exclusions: নির্দিষ্ট file/folder scanning থেকে বাদ দেয়; সতর্কতার সঙ্গে ব্যবহার করা উচিত।

Protection status পরীক্ষা:

```
Get-MpComputerStatus | findstr "True"
```

উদাহরণ output:

```
AMServiceEnabled          : True
AntispywareEnabled        : True
AntivirusEnabled          : True
BehaviorMonitorEnabled    : True
IoavProtectionEnabled     : True
IsTamperProtected         : True
NISEnabled                : True
OnAccessProtectionEnabled : True
RealTimeProtectionEnabled : True
```

Windows Defender সাধারণ Metasploit payload বা অপরিবর্তিত Mimikatz-এর মতো tool শনাক্ত করতে পারে।

মূল কথা: Defender একাই সম্পূর্ণ সুরক্ষা নয়। Patch management, secure configuration, auditing ও একাধিক security layer একসঙ্গে প্রয়োজন।
