# Windows Management Instrumentation (WMI) - [LINK](https://academy.hackthebox.com/app/module/49/section/461)


## ১. WMI কী?

WMI হলো Windows-এর built-in management subsystem, যা local ও remote system monitor এবং manage করতে ব্যবহৃত হয়। Windows 2000 থেকে এটি অন্তর্ভুক্ত।

## ২. WMI Components

| Component          | কাজ                                                                       |
| ------------------ | ------------------------------------------------------------------------- |
| WMI Service        | Boot-এ চালু হয়ে providers, repository ও applications-এর মধ্যে যোগাযোগ করে |
| Managed Objects    | Manage করা physical/logical components                                    |
| WMI Providers      | নির্দিষ্ট object-এর data/events monitor করে                               |
| Classes            | Provider থেকে WMI service-এ data পাঠায়                                    |
| Methods            | Action চালায়, যেমন remote process start/stop                              |
| WMI Repository     | Static WMI data সংরক্ষণ করে                                               |
| CIM Object Manager | Provider থেকে data নিয়ে requesting application-এ পাঠায়                    |
| WMI API            | Applications-কে WMI access দেয়                                            |
| WMI Consumer       | CIM Object Manager-এর মাধ্যমে query পাঠায়                                 |

### WMI-এর ব্যবহার

- Local/remote system status দেখা
- Security settings ও user/group permissions পরিবর্তন
- System properties পরিবর্তন
- Code execution ও process scheduling
- Logging configuration

## ৩. WMIC

WMIC হলো WMI-এর command-line interface। CMD-তে `wmic` দিয়ে interactive shell অথবা সরাসরি command চালানো যায়।

```
wmic /?
```

Output-এ `WMIC is deprecated.` দেখা যেতে পারে।

গুরুত্বপূর্ণ global switches:

| Switch       | কাজ                    |
| ------------ | ---------------------- |
| `/NODE`      | Remote server নির্ধারণ |
| `/USER`      | Login user             |
| `/PASSWORD`  | Login password         |
| `/NAMESPACE` | WMI namespace          |
| `/IMPLEVEL`  | Impersonation level    |
| `/AUTHLEVEL` | Authentication level   |
| `/OUTPUT`    | Output redirect        |
| `/TRACE`     | Debugging information  |
| `/?`         | Help                   |

Hostname দেখা:

```
wmic computersystem get name
```

OS information:

```
wmic os list brief
```

উদাহরণ output:

```
BuildNumber  Organization  RegisteredUser  SerialNumber             SystemDirectory      Version
19041                      Owner           00123-00123-00123-AAOEM  C:\Windows\system32  10.0.19041
```

`LIST` data দেখায়; `BRIEF` শুধু প্রধান properties দেখায়।

Reference: [WMIC Documentation](https://docs.microsoft.com/en-us/windows/win32/wmisdk/wmic?utm_source=chatgpt.com)

## ৪. PowerShell দিয়ে WMI

### `Get-WmiObject`

WMI class-এর instances বা class information সংগ্রহ করে; local ও remote machine-এ ব্যবহার করা যায়।

```
Get-WmiObject -Class Win32_OperatingSystem |
    Select SystemDirectory,BuildNumber,SerialNumber,Version |
    Format-Table
```

উদাহরণ output:

```
SystemDirectory      BuildNumber SerialNumber            Version
---------------      ----------- ------------            -------
C:\Windows\system32  19041       00123-00123-00123-AAOEM 10.0.19041
```

Reference: [Get-WmiObject](https://docs.microsoft.com/en-us/powershell/module/microsoft.powershell.management/get-wmiobject?view=powershell-5.1\&utm_source=chatgpt.com)

### `Invoke-WmiMethod`

WMI object-এর method চালায়। উদাহরণ—ফাইল rename:

```
Invoke-WmiMethod -Path "CIM_DataFile.Name='C:\users\public\spns.csv'" `
    -Name Rename `
    -ArgumentList "C:\Users\Public\kerberoasted_users.csv"
```

Output-এ:

```
ReturnValue : 0
```

`ReturnValue = 0` মানে operation সফল হয়েছে।

Reference: [Invoke-WmiMethod](https://docs.microsoft.com/en-us/powershell/module/microsoft.powershell.management/invoke-wmimethod?view=powershell-5.1\&utm_source=chatgpt.com)
