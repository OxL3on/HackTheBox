# Windows Subsystem for Linux (WSL) - [LINK](https://academy.hackthebox.com/app/module/49/section/464)


## ১. WSL কী?

WSL Windows 10 ও Windows Server 2019-এ Linux binaries nativeভাবে চালাতে দেয়। Bash, Ruby এবং `sed`, `awk`, `grep`-এর মতো Linux tools Windows-এ ব্যবহার করা যায়।

- WSL 1: Linux command-line tools চালানোর সুবিধা।
- WSL 2: মে ২০১৯-এ প্রকাশিত; Hyper-V-এর কিছু feature ব্যবহার করে real Linux kernel যুক্ত করে।

## ২. Install করা

Administrator PowerShell-এ:

```
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

এরপর Microsoft Store থেকে Linux distro install করো অথবা distro download করে manually install করো।

## ৩. Bash Shell চালানো

Windows CMD বা PowerShell-এ:

```
bash
```

এতে Linux Bash shell খুলবে এবং Linux-এর standard directory structure ব্যবহার করা যাবে।

```
/
├── bin
├── boot
├── dev
├── etc
├── home
├── mnt
├── opt
├── root
├── tmp
├── usr
└── var
```

## ৪. Linux ও Windows Filesystem Access

WSL-এর `/mnt` directory দিয়ে Windows-এর C drive ও অন্যান্য mounted volume access করা যায়।

উদাহরণ:

```
ls /
uname -a
```

Sample output:

```
Linux WS01 4.4.0-18362-Microsoft #476-Microsoft
Fri Nov 01 16:53:00 PST 2019 x86_64 GNU/Linux
```

WSL-এ Linux-এর মতো command চালানো, package install এবং update করা যায়।

মনে রাখো: WSL Windows-এর ভেতরে Linux environment দেয়; WSL 2-তে real Linux kernel ব্যবহৃত হয়।
