# Microsoft Management Console (MMC) - [LINK](https://academy.hackthebox.com/app/module/49/section/463)

MMC হলো Windows-এর administrative tools এক জায়গায় যুক্ত করে hardware, software ও network components manage করার console। এটি local ও remote computer—দুটিই manage করতে পারে।

## ব্যবহার

1. Start Menu-তে `mmc` লিখে চালাও।
2. File → Add or Remove Snap-ins নির্বাচন করো।
3. প্রয়োজনীয় administrative tool বা Snap-in যোগ করো।
4. Local computer অথবা network-এর অন্য computer নির্বাচন করো।
5. Snap-ins যোগ হলে বাম পাশে দেখা যাবে।
6. Console-টি `.msc` ফাইল হিসেবে save করো, যাতে পরে একই configuration আবার খোলা যায়।

## গুরুত্বপূর্ণ বিষয়

- Snap-in: MMC-তে যুক্ত করা administrative tool, যেমন Services।
- Custom Console: প্রয়োজনীয় Snap-ins একত্র করে তৈরি করা console।
- `.msc` file: সংরক্ষিত MMC configuration; পরবর্তীতে পুনরায় খোলা যায়।
- Saved console সাধারণত Start Menu-এর Windows Administrative Tools directory-তে রাখা হয়।
