## 1. Introduction to Windows

একজন Penetration Tester-এর Windows এবং Linux—দুই ধরনের Operating System সম্পর্কে ভালো ধারণা থাকা প্রয়োজন। কারণ, On-premises এবং Cloud—উভয় পরিবেশেই এই দুটি OS-এর ব্যবহার ব্যাপক।

একজন Pentester-এর Windows ও Linux সম্পর্কে যা জানা দরকার:

- কীভাবে Operating System কাজ করে।
- কীভাবে সেগুলোকে Attack এবং Defend করতে হয়।
- কীভাবে একটি compromised system ব্যবহার করে পরবর্তী Penetration Testing কার্যক্রম চালানো যায়।
- বিভিন্ন OS version-এর দুর্বলতা, misconfiguration এবং নিরাপত্তার পার্থক্য বুঝতে হয়।

### 2.2 গুরুত্বপূর্ণ Windows Components

- MS-DOS: Windows-এর প্রাথমিক সংস্করণগুলোর ভিত্তি হিসেবে ব্যবহৃত Operating System।
- IIS (Internet Information Services): Microsoft-এর Web Server Software।
- Active Directory (AD): Windows Domain Environment-এ User, Computer এবং অন্যান্য Network Resource পরিচালনার জন্য ব্যবহৃত Directory Service।
- MMC (Microsoft Management Console): বিভিন্ন Windows Administration Tool পরিচালনার জন্য ব্যবহৃত Console।
- Hyper-V: Virtual Machine তৈরি ও পরিচালনার জন্য Microsoft-এর Virtualization Technology।
- Server Core: Windows Server-এর এমন একটি Installation Option, যেখানে সাধারণত পূর্ণ Desktop GUI থাকে না।
- Event Viewer: Windows-এর System, Application এবং Security Event Log দেখার Tool।
- Volume Shadow Copy Service (VSS): Windows-এ Volume-এর Snapshot বা Shadow Copy তৈরির সুবিধা দেয়।
- Failover Clustering: কোনো Server বা Node ব্যর্থ হলে অন্য Node-এর মাধ্যমে Service চালু রাখার ব্যবস্থা।
- Dynamic Disk Volumes: Windows-এর Disk Management-এর একটি প্রযুক্তি।

### 2.3 Legacy Windows এবং End of Life (EOL)

Windows-এর নতুন সংস্করণ প্রকাশিত হলে পুরোনো সংস্করণগুলো অনেক সময় Deprecated বা Unsupported হয়ে যায়। তখন সেগুলো নিয়মিত Microsoft Security Update পায় না। কিছু ক্ষেত্রে Long-Term Support Contract-এর মাধ্যমে অতিরিক্ত Support পাওয়া যেতে পারে।

HTB-এর মূল কনটেন্ট অনুযায়ী:

- Windows Server 2008 এবং Windows Server 2012-এর Security Update Support ১৪ জানুয়ারি, ২০২০-এ শেষ হয়েছিল।
- কনটেন্টে Windows Server 2012 R2 এবং তার পরবর্তী সংস্করণগুলোকে Supported বলা হয়েছে।
- EternalBlue নামের গুরুতর SMBv1 Vulnerability আবিষ্কারের পর Microsoft অতীতেও পুরোনো Windows সংস্করণগুলোর জন্য বিশেষ Out-of-band Patch প্রকাশ করেছে।

গুরুত্বপূর্ণ: উপরের Support Status হলো মূল HTB কনটেন্টের বক্তব্য; এটি বর্তমান Support Status যাচাই করে দেওয়া তালিকা নয়।

প্রতিষ্ঠানগুলো এখনো পুরোনো Windows ব্যবহার করতে পারে, কারণ:

- গুরুত্বপূর্ণ Application শুধু পুরোনো OS-এ চলে।
- নতুন System-এ Migration করা কঠিন।
- বাজেট বা Operational সমস্যা থাকে।

Pentester-এর জন্য পুরোনো Windows Version চেনা গুরুত্বপূর্ণ, কারণ বিভিন্ন সংস্করণে আলাদা Vulnerability এবং Misconfiguration থাকতে পারে।

## 3. Windows Versions

Windows-এর Version Number দেখে একটি System-এর Operating System সম্পর্কে প্রাথমিক ধারণা পাওয়া যায়।

### 3.1 Windows Version Table

| Operating System                     | Version Number |
| ------------------------------------ | -------------- |
| Windows NT 4                         | `4.0`          |
| Windows 2000                         | `5.0`          |
| Windows XP                           | `5.1`          |
| Windows Server 2003, 2003 R2         | `5.2`          |
| Windows Vista, Server 2008           | `6.0`          |
| Windows 7, Server 2008 R2            | `6.1`          |
| Windows 8, Server 2012               | `6.2`          |
| Windows 8.1, Server 2012 R2          | `6.3`          |
| Windows 10, Server 2016, Server 2019 | `10.0`         |

মনে রাখবে: একই Version Number একাধিক Windows Operating System-এর ক্ষেত্রে ব্যবহৃত হতে পারে। তাই শুধু Version Number দেখে OS-এর সঠিক নাম নির্ধারণ করা সব সময় সম্ভব নয়।

### 3.2 PowerShell দিয়ে Windows Version বের করা

Windows-এর Operating System Version এবং Build Number জানার জন্য `Get-WmiObject` Cmdlet ব্যবহার করা যায়।

```
Get-WmiObject -Class win32_OperatingSystem | select Version,BuildNumber
```

উদাহরণ Output:

```
Version    BuildNumber
-------    -----------
10.0.19041 19041
```

ব্যাখ্যা:

- `Get-WmiObject`: WMI (Windows Management Instrumentation)-এর মাধ্যমে System Information সংগ্রহ করে।
- `-Class win32_OperatingSystem`: Operating System সম্পর্কিত WMI Class নির্বাচন করে।
- `|`: আগের Command-এর Output পরের Command-এ পাঠায়।
- `select Version,BuildNumber`: শুধু Version এবং Build Number দেখায়।
- `10.0.19041`: System-এর OS Version।
- `19041`: System-এর Build Number।

এখানে Output থেকে বোঝা যাচ্ছে, System-টি Windows 10 এবং এর Build Number `19041`।

### 3.3 অন্যান্য গুরুত্বপূর্ণ WMI Class

| WMI Class               | কাজ                                  |
| ----------------------- | ------------------------------------ |
| `Win32_Process`         | System-এর Process List সংগ্রহ করে।   |
| `Win32_Service`         | System-এর Service List সংগ্রহ করে।   |
| `Win32_Bios`            | BIOS সম্পর্কিত তথ্য সংগ্রহ করে।      |
| `win32_OperatingSystem` | Operating System-এর তথ্য সংগ্রহ করে। |

BIOS (Basic Input/Output System): এটি Computer-এর Motherboard-এ থাকা Firmware, যা Power Management, Input/Output Interface এবং System Configuration-এর মতো মৌলিক কাজ নিয়ন্ত্রণ করে।

`Get-WmiObject`-এর অন্যান্য ব্যবহার:

- `ComputerName` Parameter ব্যবহার করে Remote Computer-এর তথ্য সংগ্রহ করা যায়।
- Local এবং Remote Computer-এর Service Start ও Stop করা যায়।
- বিভিন্ন WMI Class-এর তথ্য সংগ্রহ করা যায়।

অতিরিক্ত রেফারেন্স: [Get-WmiObject — Microsoft Learn](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/get-wmiobject?utm_source=chatgpt.com)

নোট: `Get-WmiObject` মূলত Windows PowerShell-এর পুরোনো Cmdlet। নতুন PowerShell সংস্করণে অনেক ক্ষেত্রে `Get-CimInstance` ব্যবহার করা হয়।

## 4. Accessing Windows

একটি Computer-এ কাজ করার জন্য সাধারণত দুই ধরনের Access পদ্ধতি রয়েছে:

1. Local Access
2. Remote Access

### 4.1 Local Access Concepts

Local Access হলো সরাসরি কোনো Computer ব্যবহার করা।

উদাহরণ:

- Desktop Computer
- Laptop
- Smartphone
- Tablet
- Raspberry Pi

Local Access-এর ক্ষেত্রে সাধারণত:

- Input: Keyboard, Mouse অথবা Trackpad।
- Output: Monitor বা Display Screen।

প্রতিষ্ঠানগুলো সাধারণত কর্মীদের Computer ব্যবহারের জন্য Security Policy এবং Security Control তৈরি করে। তবে Remote Work বাড়ার কারণে IT, Software Development এবং Information Security পেশাজীবীদের একাধিক Computer-এ Local ও Remote—দুইভাবেই কাজ করতে হয়।

### 4.2 Remote Access Concepts

Remote Access হলো Network-এর মাধ্যমে অন্য একটি Computer-এ Access করা।

উদাহরণ: তুমি নিজের Linux Laptop থেকে Network-এর মাধ্যমে একটি Windows Server-এ Login করলে, সেটি Remote Access।

Remote Access ব্যবহারের ক্ষেত্র:

- Remote System Administration
- Server Management
- Software Development
- Security Assessment
- Employee Workstation Management
- Security Incident-এর দ্রুত Response

MSP এবং MSSP প্রতিষ্ঠানগুলো Remote Access-এর মাধ্যমে তাদের Client-এর System পরিচালনা করে।

- MSP (Managed Service Provider): অন্য প্রতিষ্ঠানের IT Service পরিচালনা করে।
- MSSP (Managed Security Service Provider): অন্য প্রতিষ্ঠানের Security Service পরিচালনা করে।

Remote Access ব্যবহারের সুবিধা:

- কেন্দ্রীয়ভাবে System পরিচালনা করা যায়।
- একই ধরনের Technology ও Configuration বজায় রাখা যায়।
- অনেক কাজ Automation করা যায়।
- Remote Work সহজ হয়।
- System সমস্যা বা Security Threat দেখা দিলে দ্রুত ব্যবস্থা নেওয়া যায়।

### 4.3 সাধারণ Remote Access Technologies

| Technology | পূর্ণরূপ / কাজ                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| VPN        | Virtual Private Network — Network-এর মধ্যে নিরাপদ Connection তৈরি করতে সাহায্য করে।                                      |
| SSH        | Secure Shell — Remote System-এ Secure Command-Line Access দেয়।                                                           |
| FTP        | File Transfer Protocol — Network-এর মাধ্যমে File Transfer করে।                                                           |
| VNC        | Virtual Network Computing — Remote Desktop দেখার ও নিয়ন্ত্রণের সুবিধা দেয়।                                               |
| WinRM      | Windows Remote Management — Windows System Remote-ভাবে পরিচালনা করতে ব্যবহৃত হয়। PowerShell Remoting এর সঙ্গে সম্পর্কিত। |

এই HTB Module-এ মূলত RDP (Remote Desktop Protocol) ব্যবহার করা হবে।

## 5. Remote Desktop Protocol (RDP)

### 5.1 RDP কী?

RDP হলো Microsoft-এর Remote Desktop Protocol, যার মাধ্যমে Network ব্যবহার করে অন্য একটি Computer-এর Desktop-এ Remote Access নেওয়া যায়।

RDP Client/Server Architecture অনুসরণ করে।

- RDP Client: যে Computer থেকে Connection তৈরি করা হয়।
- RDP Server/Target: যে Computer-এ Remote Desktop Access চালু রয়েছে।
- IP Address: Network-এর মধ্যে Target Computer শনাক্ত করতে ব্যবহৃত হয়।
- Port: Target Computer-এর কোন Application বা Service-এর সঙ্গে যোগাযোগ করতে হবে, তা শনাক্ত করতে সাহায্য করে।

RDP-এর Default Port:

| বিষয়         | তথ্য                  |
| ------------ | --------------------- |
| Protocol     | RDP                   |
| Default Port | `3389`                |
| কাজ          | Remote Desktop Access |
| Architecture | Client/Server         |

### 5.2 IP Address এবং Port-এর সহজ ব্যাখ্যা

ধরো, একটি Corporate Network হলো একটি রাস্তা।

- Network: পুরো রাস্তা।
- IP Address: রাস্তার একটি নির্দিষ্ট বাড়ির ঠিকানা।
- Port: সেই বাড়ির নির্দিষ্ট দরজা বা প্রবেশপথ।
- Application/Service: বাড়ির ভেতরের নির্দিষ্ট কক্ষ বা সেবা।

যখন একটি Network Packet Target Computer-এ পৌঁছায়, তখন Packet-এর IP Address সেটিকে সঠিক Computer-এ পৌঁছাতে সাহায্য করে। Packet-এর Port Information নির্দিষ্ট Application বা Service-এর কাছে Request পৌঁছাতে সাহায্য করে।

RDP-এর ক্ষেত্রে:

- Target-এর IP Address দিয়ে Computer শনাক্ত করা হয়।
- Port `3389` দিয়ে সাধারণত RDP Service-এর সঙ্গে যোগাযোগ করা হয়।

এই Module-এ Networking-এর বিস্তারিত আলোচনা করা হবে না। এখানে IP Address, Port এবং Network Communication-এর এই মৌলিক ধারণাগুলো জানাই যথেষ্ট।

## 6. Windows থেকে RDP Connection

Windows Computer থেকে অন্য Windows Target-এ RDP Connection তৈরি করতে Built-in Tool `Remote Desktop Connection` ব্যবহার করা যায়।

এর Executable Name:

```
mstsc.exe
```

এটি ব্যবহারের আগে Target Windows System-এ Remote Access অনুমোদিত থাকতে হবে।

গুরুত্বপূর্ণ: Windows-এ Remote Access সাধারণত Default অবস্থায় Enabled থাকে না। HTB Academy Lab-এ অনেক Windows Target এমনভাবে Configure করা থাকে, যেন Academy Lab-এর VPN-এ Connect করার পর RDP ব্যবহার করা যায়।

### 6.1 Saved RDP Profiles

`Remote Desktop Connection`-এ Connection Profile Save করা যায়। এতে ভবিষ্যতে একই Remote Computer-এ Connect করা সহজ হয়।

Pentesting-এর সময় Saved Remote Desktop Files খুঁজে দেখা গুরুত্বপূর্ণ।

File Extension:

```
.rdp
```

কারণ, এসব File-এ Remote Connection-এর Configuration থাকতে পারে এবং কোনো কোনো ক্ষেত্রে Credential-সংক্রান্ত তথ্যও থাকতে পারে। তাই অনুমোদিত Security Assessment-এর সময় এগুলো পরীক্ষা করা উপকারী হতে পারে।

অন্যান্য RDP Client সম্পর্কে জানতে: [Remote Desktop clients — Microsoft Learn](https://learn.microsoft.com/en-us/windows-server/remote/remote-desktop-services/clients/remote-desktop-clients?utm_source=chatgpt.com)

## 7. Linux থেকে RDP Connection: xfreerdp

Linux-Based Attack Host থেকে Windows Target-এ Remote Desktop Connection তৈরির জন্য `xfreerdp` ব্যবহার করা যায়।

HTB Academy-তে এই Tool ব্যবহারের কারণ:

- সহজে ব্যবহার করা যায়।
- Command-Line Interface রয়েছে।
- প্রয়োজনীয় Feature-গুলো ব্যবহার করা যায়।
- কার্যকরভাবে Remote Desktop Connection তৈরি করা যায়।

### 7.1 Basic RDP Command

HTB Academy-এর দেওয়া Command:

```
xfreerdp /v:<targetIp> /u:htb-student /p:Password
```

Command-এর প্রতিটি অংশের ব্যাখ্যা:

| অংশ              | কাজ                                                   |
| ---------------- | ----------------------------------------------------- |
| `xfreerdp`       | Linux থেকে RDP Connection তৈরি করার Tool।             |
| `/v:<targetIp>`  | যে Windows Target-এ Connect করতে হবে, তার IP Address। |
| `/u:htb-student` | Login করার Username।                                  |
| `/p:Password`    | Login করার Password।                                  |

এখানে `<targetIp>`-এর জায়গায় HTB Target-এর প্রকৃত IP Address বসাতে হবে। একইভাবে Username এবং Password অবশ্যই Lab-এ দেওয়া Credential অনুযায়ী ব্যবহার করতে হবে।

উদাহরণ হিসেবে, Target IP যদি `10.129.10.20` হয়:

```
xfreerdp /v:10.129.10.20 /u:htb-student /p:Password
```

এটি কেবল উদাহরণ; IP Address এবং Credential তোমার নিজের Lab-এর তথ্য দিয়ে প্রতিস্থাপন করতে হবে।

### 7.2 RDP-এর মাধ্যমে File Transfer

`xfreerdp`-এ Drive Redirection-এর মতো Feature রয়েছে।

এর সাহায্যে Local Computer-এর Drive Remote Target-এর সঙ্গে Share করে File আদান-প্রদান করা যায়।

এটি কাজে লাগে যখন:

- Linux Attack Host থেকে Windows Target-এ File পাঠাতে হয়।
- Target থেকে নিজের System-এ File আনতে হয়।
- Remote Environment-এ Tool বা প্রয়োজনীয় File ব্যবহার করতে হয়।

HTB Academy-তে পরবর্তী Module-গুলোতে Drive Redirection এবং অন্যান্য `xfreerdp` Option আরও বিস্তারিতভাবে আলোচনা করা হবে।

আরও কিছু RDP Client:

- Remmina
- rdesktop

প্রয়োজন অনুযায়ী অন্যান্য RDP Client-ও পরীক্ষা করে দেখা যেতে পারে।

## 8. Connecting to the Windows Target — HTB Lab

HTB Academy-এর Windows Target-এ RDP দিয়ে Connect করার জন্য দেওয়া Command:

```
xfreerdp /v:<targetIp> /u:htb-student /p:Password
```

এখানে:

- `<targetIp>` — Lab-এর Windows Target IP।
- `htb-student` — প্রদত্ত Username।
- `Password` — প্রদত্ত Password।

Connection সফল হওয়ার জন্য:

1. Target IP Address সঠিক হতে হবে।
2. HTB Academy Lab-এর VPN Connection প্রয়োজন হলে সেটি চালু থাকতে হবে।
3. Target-এ RDP Access অনুমোদিত থাকতে হবে।
4. সঠিক Username এবং Password ব্যবহার করতে হবে।
5. Target-এর RDP Service-এ Network-এর মাধ্যমে পৌঁছানো সম্ভব হতে হবে।

এই শর্তগুলো পূরণ হলে `xfreerdp` ব্যবহার করে Remote Windows Desktop-এ প্রবেশ করা যাবে।
