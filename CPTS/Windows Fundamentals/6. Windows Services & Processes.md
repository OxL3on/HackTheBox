## ১. Windows Services

Services হলো দীর্ঘসময় চলা background process, যা boot-এর সময় স্বয়ংক্রিয়ভাবে চালু হতে পারে এবং user logout করলেও চলতে পারে। যেমন: networking, Windows Update, diagnostics ও credential management।

- SCM: Service Control Manager; `services.msc` দিয়ে GUI পরিচালনা।
- Command line: `sc.exe`, PowerShell-এর `Get-Service`।
- Status: `Running`, `Stopped`, `Paused`, `Starting`, `Stopping`।
- Startup: `Manual`, `Automatic`, `Automatic (Delayed Start)`।
- Service তৈরি, পরিবর্তন ও মুছতে সাধারণত Administrator লাগে।
- Service permission misconfiguration Windows privilege escalation-এর পথ হতে পারে।

### Running Services দেখানো

```
Get-Service | ? {$_.Status -eq "Running"} | select -First 2 | fl
```

Output-এর উদাহরণ:

```
Name        : AdobeARMservice
DisplayName : Adobe Acrobat Update Service
Status      : Running
CanStop     : True

Name        : Appinfo
DisplayName : Application Information
Status      : Running
CanStop     : True
```

### গুরুত্বপূর্ণ System Services

| Process                  | কাজ                                           |
| ------------------------ | --------------------------------------------- |
| `smss.exe`               | Session Manager                               |
| `csrss.exe`              | Windows subsystem-এর user-mode অংশ            |
| `wininit.exe`            | Startup initialization                        |
| `logonui.exe`            | User login interface                          |
| `lsass.exe`              | Logon authentication ও security policy        |
| `services.exe`           | Services চালু/বন্ধ পরিচালনা                   |
| `winlogon.exe`           | Secure logon, user profile, computer lock     |
| `System`                 | Windows kernel process                        |
| `svchost.exe` + RPCSS    | RPC-নির্ভর system services পরিচালনা           |

কিছু critical service সরাসরি restart করা যায় না; পরিবর্তনের জন্য system restart প্রয়োজন হতে পারে।

## ২. Processes

Process হলো চলমান application বা OS component।

- সাধারণ application process বন্ধ করলে সাধারণত বড় সমস্যা হয় না।
- Critical process বন্ধ করলে Windows-এর অংশ অকার্যকর হতে পারে।
- গুরুত্বপূর্ণ process: `System`, `System Idle Process`, `winlogon.exe`, `csrss.exe`, `smss.exe`, `svchost.exe`, `lsass.exe`।

## ৩. LSASS

`lsass.exe` (Local Security Authority Subsystem Service) Windows security policy প্রয়োগ করে।

- User logon যাচাই করে এবং permission অনুযায়ী access token তৈরি করে।
- Password পরিবর্তন পরিচালনা করে।
- Logon/logoff events Windows Security Log-এ সংরক্ষিত হয়।
- এর memory-তে plaintext ও hashed credentials থাকতে পারে, তাই এটি pentesting-এ high-value target।

## ৪. Sysinternals Tools

[Sysinternals Suite](https://docs.microsoft.com/en-us/sysinternals?utm_source=chatgpt.com) হলো Windows administration-এর portable tools-এর সংগ্রহ। Windows Explorer-এ নিচের path দিলে tools ব্যবহার করা যায়:

```
\\live.sysinternals.com\tools
```

উদাহরণ—`ProcDump` চালানো:

```
\\live.sysinternals.com\tools\procdump.exe -accepteula
```

`ProcDump` নির্দিষ্ট condition বা exception হলে process dump তৈরি করে।

অন্যান্য tools:

| Tool             | কাজ                                                               |
| ---------------- | ----------------------------------------------------------------- |
| Process Explorer | Running processes, handles, DLLs ও parent-child relationship দেখা |
| Process Monitor  | File system, Registry ও network activity monitor                  |
| TCPView          | Network connection/activity দেখা                                  |
| PsExec           | SMB-এর মাধ্যমে remote system পরিচালনা/সংযোগ                       |

এগুলো process investigation, troubleshooting, privilege escalation path শনাক্তকরণ এবং lateral movement বিশ্লেষণে কাজে লাগে।

## ৫. Task Manager

খোলার উপায়: `Ctrl + Shift + Esc`, `Ctrl + Alt + Del`, Start Menu-তে `Task Manager`, অথবা:

```
taskmgr
```

| Tab         | কাজ                                                                 |
| ----------- | ------------------------------------------------------------------- |
| Processes   | Application, background process ও CPU/RAM/Disk/Network usage        |
| Performance | CPU, memory, disk, network, GPU ও uptime; Resource Monitor খোলা যায় |
| App history | Application-এর resource usage history                               |
| Startup     | Boot-এ চালু হওয়া applications ও startup impact                      |
| Users       | Logged-in users ও তাদের processes                                   |
| Details     | Process name, PID, status, username ও resource usage                |
| Services    | Service name, PID, description ও status                             |

References: [Task Manager](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/49/taskmgr.png?utm_source=chatgpt.com) · [Resource Monitor](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/49/resource_monitor.png?utm_source=chatgpt.com)

## ৬. Process Explorer

[Process Explorer](https://docs.microsoft.com/en-us/sysinternals/downloads/process-explorer?utm_source=chatgpt.com) হলো উন্নত process investigation tool।

- Running processes ও তাদের loaded DLLs দেখায়।
- Process-এর handles, memory-mapped/swapped files পরীক্ষা করে।
- নির্দিষ্ট handle বা DLL কোন process ব্যবহার করছে তা search করে।
- Parent-child process relationship দেখে orphaned process ও application সমস্যা শনাক্ত করতে সাহায্য করে।
