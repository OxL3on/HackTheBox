# NTFS vs. Share Permissions - [LINK](https://academy.hackthebox.com/app/module/49/section/1017)


## 1. মূল ধারণা

Windows Malware Network Share দিয়ে ছড়াতে পারে, বিশেষত Permission দুর্বল হলে। `EternalBlue` হলো পুরোনো, Unpatched Windows-এর `SMBv1`-সম্পর্কিত Vulnerability, যা Ransomware Attack-এ ব্যবহৃত হয়েছে। কোনো OS-ই Malware থেকে সম্পূর্ণ নিরাপদ নয়।

SMB (Server Message Block): Network-এর মাধ্যমে File ও Printer Share করার Protocol। Client Request পাঠায়, Server Permission যাচাই করে Resource Access দেয়।

## 2. Share vs. NTFS Permissions

| Share Permission | কাজ                                                |
| ---------------- | -------------------------------------------------- |
| `Full Control`   | Read, Change এবং NTFS Permission পরিবর্তনের ক্ষমতা |
| `Change`         | File Read, Edit, Delete ও Add                      |
| `Read`           | File ও Subfolder দেখা                              |

| NTFS Basic Permission  | কাজ                                             |
| ---------------------- | ----------------------------------------------- |
| `Full Control`         | Add, Edit, Move, Delete এবং Permission পরিবর্তন |
| `Modify`               | File/Folder দেখা, পরিবর্তন, Add ও Delete        |
| `Read & Execute`       | File পড়া ও Program চালানো                       |
| `List folder contents` | File ও Subfolder-এর তালিকা দেখা                 |
| `Read`                 | File পড়া                                        |
| `Write`                | File পরিবর্তন ও নতুন File যোগ                   |
| `Special Permissions`  | Advanced Permission                             |

### NTFS Special Permissions

| Permission                       | কাজ                                                                |
| -------------------------------- | ------------------------------------------------------------------ |
| `Full control`                   | File/Folder পরিচালনা ও Permission পরিবর্তন                         |
| `Traverse folder / execute file` | Parent Content না দেখতে পারলেও Subfolder-এ যাওয়া; Program Execute  |
| `List folder/read data`          | Folder-এর তালিকা দেখা বা File পড়া                                  |
| `Read attributes`                | `System`, `Archive`, `Read-only`, `Hidden` Attribute দেখা          |
| `Read extended attributes`       | Application-নির্ভর Extended Attribute দেখা                         |
| `Create files/write data`        | File তৈরি ও Data পরিবর্তন                                          |
| `Create folders/append data`     | Subfolder তৈরি; File-এর শেষে Data যোগ, পুরোনো Content Overwrite নয় |
| `Write attributes`               | File/Folder Attribute পরিবর্তন                                     |
| `Write extended attributes`      | Extended Attribute পরিবর্তন                                        |
| `Delete subfolders and files`    | Child File/Folder Delete, Parent নয়                                |
| `Delete`                         | File/Folder Delete                                                 |
| `Read permissions`               | Permission দেখা                                                    |
| `Change permissions`             | Permission পরিবর্তন                                                |
| `Take ownership`                 | Ownership নেওয়া; Owner সাধারণত Permission পরিবর্তন করতে পারে       |

মনে রাখবে: NTFS Permission Local Login ও RDP Access-এর ক্ষেত্রেও প্রযোজ্য। SMB দিয়ে Network Access করলে Share ও NTFS—দুটির Permission-ই কার্যকর। সাধারণভাবে যেটি কম Access দেয়, সেটিই কার্যকর Access সীমিত করে। NTFS Folder ডিফল্টভাবে Parent-এর Permission Inherit করে; প্রয়োজন হলে Inheritance বন্ধ করা যায়।

## 3. Windows-এ Network Share তৈরি

HTB Lab-এ Windows 10 Desktop-এ `Company Data` নামে Folder তৈরি করে Properties → Advanced Sharing দিয়ে Share করতে হবে। Share Name ডিফল্টভাবে Folder Name হয়; একই সময়ে Connect করা User-এর সংখ্যাও সীমিত করা যায়।

- `ACL` (Access Control List): Permission-এর তালিকা।
- `ACE` (Access Control Entry): ACL-এর পৃথক Entry।
- `Security Principal`: User বা Group।

Share Permission GUI-এর Sharing Tab-এ এবং NTFS Permission Security Tab-এ থাকে। ধূসর Checkmark সাধারণত Parent Folder থেকে Inherited Permission বোঝায়।

Enterprise-এ Share সাধারণত `SAN`, `NAS` বা Windows Server-এর Storage-এ থাকে। Desktop-এ Share ছোট প্রতিষ্ঠানের Resource বা Pentest-এ পাওয়া সম্ভাব্য Data Collection Point হতে পারে।

## 4. Linux থেকে SMB Share Access

### Available Share List

```
smbclient -L SERVER_IP -U htb-student
```

Password দেওয়ার পর উদাহরণ Output:

```
Sharename       Type      Comment
---------       ----      -------
ADMIN$          Disk      Remote Admin
C$              Disk      Default share
Company Data    Disk
IPC$            IPC       Remote IPC
```

- `-L`: Share List করে।
- `-U`: Username নির্ধারণ করে।
- `ADMIN$`: Administrative Share।
- `C$`: C Drive-এর Administrative Share।
- `IPC$`: Remote Inter-Process Communication।
- `Company Data`: তৈরি করা Share।

### Share-এ Connect

```
smbclient '\\SERVER_IP\Company Data' -U htb-student
```

সফল হলে:

```
Password for [WORKGROUP\htb-student]:
Try "help" to get a list of possible commands.

smb: \>
```

`smb: \>` হলো Interactive SMB Prompt।

## 5. Windows Defender Firewall ও Authentication

Firewall সঠিক Credential ও Permission থাকা সত্ত্বেও SMB Connection Block করতে পারে।

Firewall Traffic নিয়ন্ত্রণ করে:

- Inbound: অন্য System থেকে Windows-এ আসা Traffic।
- Outbound: Windows থেকে অন্য System-এ যাওয়া Traffic।

তিনটি Firewall Profile:

- `Public`
- `Private`
- `Domain`

HTB-এর Lab-এ প্রয়োজনীয় Inbound Rule Enable করলে Share Connection সফল হয়। Firewall সম্পূর্ণ বন্ধ করার বদলে নির্দিষ্ট Rule Enable বা Exception তৈরি করা উত্তম। Domain-এ Group Policy দিয়ে Firewall Rules কেন্দ্রীয়ভাবে পরিচালনা করা যায়।

### Workgroup vs. Domain

| Workgroup                                | Windows Domain                                     |
| ---------------------------------------- | -------------------------------------------------- |
| Local `SAM` Database দিয়ে Authentication | `Active Directory` দিয়ে Centralized Authentication |
| প্রতিটি Computer-এর নিজস্ব Local Account | Domain-এর কেন্দ্রীয় Account Management             |

`SAM` হলো Local Windows Account-এর Database; `Active Directory` হলো Domain-এর Centralized Directory Service। তাই `htb-student` Account কোথায় রয়েছে, তা Authentication-এর সময় গুরুত্বপূর্ণ।

Lab-এ `Everyone` Group-এর `Read` Permission থাকায় `htb-student` Share পড়তে পারে। তবে `Read` Permission দিয়ে File Write/Delete করা যায় না।

## 6. Linux-এ SMB Share Mount

Share-কে Linux Directory-তে যুক্ত করলে সেটি Mount Point হিসেবে ব্যবহার করা যায়।

```
sudo mount -t cifs -o username=htb-student,password=Academy_WinFun! //ipaddoftarget/"Company Data" /home/user/Desktop/
```

| অংশ                              | কাজ                      |
| -------------------------------- | ------------------------ |
| `sudo`                           | Administrative Privilege |
| `mount -t cifs`                  | SMB/CIFS Share Mount     |
| `-o`                             | Mount Options            |
| `username=htb-student`           | Username                 |
| `password=Academy_WinFun!`       | Password                 |
| `//ipaddoftarget/"Company Data"` | Target Share Path        |
| `/home/user/Desktop/`            | Mount Point              |

`ipaddoftarget`-এর জায়গায় Target IP বসাতে হবে। Mount Point Directory আগে তৈরি থাকতে হবে।

Command ব্যর্থ হলে এবং `cifs-utils` ইনস্টল না থাকলে:

```
sudo apt-get install cifs-utils
```

সতর্কতা: Command-এ সরাসরি Password দিলে Shell History-তে থেকে যেতে পারে।

## 7. Windows-এ Share Enumeration

### `net share`

```
C:\Users\htb-student> net share
```

উদাহরণ Output:

```
Share name   Resource                        Remark
-------------------------------------------------------------------------------
C$           C:\                             Default share
IPC$                                         Remote IPC
ADMIN$       C:\WINDOWS                      Remote Admin
Company Data C:\Users\htb-student\Desktop\Company Data

The command completed successfully.
```

`C$` ও `ADMIN$` Windows-এর Default Administrative Share। এগুলো ম্যানুয়ালি তৈরি না করলেও থাকতে পারে। উপযুক্ত Access থাকলে Remote User পুরো `C:\` Drive-এ প্রবেশ করতে পারে।

### Computer Management

Windows-এর `Computer Management → Shared Folders`-এ:

- `Shares`: Share-এর তালিকা।
- `Sessions`: Connected User/Client।
- `Open Files`: বর্তমানে খোলা Shared File।

SMB Breach তদন্তে এগুলো কার্যকর।

### Event Viewer

`Event Viewer`-এ System, Application ও Security Log দেখা যায়। Folder তৈরি, Edit এবং Access-সংক্রান্ত Event তদন্তে এটি সাহায্য করে। `Audit Success` Entry দেখা যেতে পারে; তবে নির্দিষ্ট Event পাওয়া Auditing Configuration-এর ওপর নির্ভর করে।
