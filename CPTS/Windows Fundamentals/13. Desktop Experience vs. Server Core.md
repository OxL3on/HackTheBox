# Desktop Experience vs. Server Core - [LINK](https://academy.hackthebox.com/app/module/49/section/465)


## ১. Server Core কী?

Server Core হলো Windows Server-এর minimal installation option, যা Windows Server 2008 থেকে চালু হয়।

এর সুবিধা:

- কম RAM ও disk space ব্যবহার।
- কম management overhead।
- ছোট attack surface।
- GUI ছাড়াই CMD, PowerShell, MMC বা RSAT দিয়ে management।

## ২. Server Core Management

Server Core-এ বেশিরভাগ কাজ CMD, PowerShell ও remote management দিয়ে করা হয়।

`Sconfig` হলো text-based configuration interface, যা দিয়ে:

- Network configure
- Windows Update check/install
- Account management
- Remote management configure
- Windows activation

চালানো যায়।

Reference: [Windows Server Core](https://docs.microsoft.com/en-us/windows-server/administration/server-core/what-is-server-core?utm_source=chatgpt.com)

## ৩. GUI ও Supported Applications

Server Core-এ কিছু graphical tools-ও চলে, যেমন Registry Editor, Notepad, System Information, Windows Installer, Task Manager, PowerShell এবং কিছু Sysinternals tools।

তবে SCVMM 2019, Data Protection Manager 2019, SharePoint Server 2019 ও Project Server 2019 Server Core-এ চলে না।

## ৫. গুরুত্বপূর্ণ পার্থক্য

- Windows Server 2019 থেকে installation-এর সময় Server Core অথবা Desktop Experience নির্বাচন করতে হয়; পরে একটিকে অন্যটিতে convert করা যায় না।
- Server Core: Lightweight, কম resource ব্যবহার ও ছোট attack surface; তবে command-line দক্ষতা প্রয়োজন।
- Desktop Experience: GUI-ভিত্তিক management সহজ, কিন্তু বেশি resource প্রয়োজন হতে পারে।

কোনটি বেছে নেবে? Server-এর কাজ, business requirements এবং administrator-এর দক্ষতার ওপর নির্ভর করবে।
