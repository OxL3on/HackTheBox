## ১. GUI (Graphical User Interface)

GUI হলো point-and-click interface, যা command মুখস্থ না করেই Windows পরিচালনা করতে দেয়। Admin-রা Active Directory, IIS ও database পরিচালনায় GUI ব্যবহার করেন।

## ২. RDP (Remote Desktop Protocol)

[RDP](https://support.microsoft.com/en-us/help/186607/understanding-the-remote-desktop-protocol-rdp?utm_source=chatgpt.com) দিয়ে network-এর মাধ্যমে remote Windows system-এর GUI ব্যবহার করা যায়।

- Default port: `3389`
- প্রয়োজন: RDP client ও target-এ RDP server।
- ব্যবহার: Remote administration, বাসা বা ভ্রমণ থেকে office PC access; VPN ব্যবহার করা যেতে পারে।

## ৩. CMD (Command Prompt)

`cmd.exe` দিয়ে command, script ও batch file চালানো যায়।

খোলার উপায়: Start Menu → `cmd`, Run → `cmd`, অথবা `C:\Windows\system32\cmd.exe`।

```
help
help schtasks
ipconfig /?
```

- `help` — available commands
- `help <command>` — নির্দিষ্ট command-এর help
- `<command> /?` — command-এর usage ও parameters

`SCHTASKS`-এর প্রধান options:

| Option    | কাজ             |
| --------- | --------------- |
| `/Create` | Task তৈরি       |
| `/Delete` | Task মুছতে      |
| `/Query`  | Task দেখাতে     |
| `/Change` | Task পরিবর্তন   |
| `/Run`    | Task চালাতে     |
| `/End`    | চলমান task বন্ধ |

`ipconfig`-এর গুরুত্বপূর্ণ options: `/all`, `/release`, `/renew`, `/flushdns`, `/displaydns`, `/registerdns`।

[Windows Command Reference (PDF)](https://download.microsoft.com/download/5/8/9/58911986-D4AD-4695-BF63-F734CD4DF8F2/ws-commands.pdf?utm_source=chatgpt.com)

## ৪. PowerShell

PowerShell হলো Windows administration ও automation-এর command shell এবং scripting environment। এটি .NET Framework-এর ওপর তৈরি এবং CMD-এর অনেক কাজও করতে পারে।

### Cmdlets

Cmdlet হলো ছোট নির্দিষ্ট কাজের PowerShell command। Format: `Verb-Noun`।

```
Get-ChildItem
Get-ChildItem -Recurse
Get-ChildItem -Path C:\Users\Administrator\Documents
Get-ChildItem -Path C:\Users\Administrator\Downloads -Recurse
```

`Get-ChildItem` directory contents দেখায়; `-Recurse` subdirectories-সহ দেখায়।

### Aliases

```
Get-Alias
New-Alias -Name "Show-Files" Get-ChildItem
Get-Alias -Name "Show-Files"
```

| Alias       | Cmdlet           |
| ----------- | ---------------- |
| `cd`, `sl`  | `Set-Location`   |
| `ls`, `gci` | `Get-ChildItem`  |
| `cat`       | `Get-Content`    |
| `?`         | `Where-Object`   |
| `%`         | `ForEach-Object` |

### Help

```
Get-Help Get-AppPackage
Get-Help Get-AppPackage -Online
Update-Help
```

`Update-Help` local help files ডাউনলোড করে। Help files না থাকলে `Get-Help` শুধু partial/generated help দেখাতে পারে।

## ৫. PowerShell Scripts ও Modules

PowerShell ISE দিয়ে script লেখা, চালানো ও debug করা যায়।

Script চালানোর উদাহরণ:

```
.\PowerView.ps1; Get-LocalGroup | fl
```

Module import করলে তার functions বর্তমান session-এ ব্যবহার করা যায়:

```
Import-Module .\PowerView.ps1
Get-Module
Get-Module | Select Name,ExportedCommands | fl
```

`Get-Module` loaded modules এবং `ExportedCommands` তাদের exported commands দেখায়।

## ৬. Execution Policy

Execution Policy PowerShell scripts চালানোর ক্ষেত্রে নিয়ম নির্ধারণ করে। এটি পূর্ণ security boundary নয়।

| Policy         | কাজ                                                              |
| -------------- | ---------------------------------------------------------------- |
| `AllSigned`    | Local ও remote সব script signed হতে হবে                          |
| `Bypass`       | Block, warning বা prompt ছাড়াই চালায়                             |
| `Default`      | Desktop-এ `Restricted`, server-এ `RemoteSigned`                  |
| `RemoteSigned` | Internet থেকে download করা script signed হতে হবে                 |
| `Restricted`   | Script files চালানো বন্ধ; individual commands চলে                |
| `Undefined`    | ওই scope-এ policy নির্ধারিত নয়                                   |
| `Unrestricted` | Unsigned script চলে, তবে non-local-intranet script-এ warning আসে |

বর্তমান policy দেখো:

```
Get-ExecutionPolicy -List
```

উদাহরণ:

```
Scope          ExecutionPolicy
-----          ---------------
MachinePolicy  Undefined
UserPolicy     Undefined
Process        Undefined
CurrentUser    Undefined
LocalMachine   RemoteSigned
```

### Current Session-এ Bypass

```
Set-ExecutionPolicy Bypass -Scope Process
Get-ExecutionPolicy -List
```

পরিবর্তনটি শুধু বর্তমান PowerShell process/session-এর জন্য প্রযোজ্য। `Process` scope-এর policy পরিবর্তনে সাধারণত স্থায়ী configuration পরিবর্তন লাগে না।

নিরাপত্তা: Execution Policy-কে শক্তিশালী security control হিসেবে ধরা যাবে না; script অন্য উপায়েও চালানো সম্ভব। প্রয়োজন ছাড়া policy bypass কোরো না।
