## ১. Registry কী?

Windows Registry হলো hierarchical database, যেখানে Windows ও application-এর configuration সংরক্ষিত থাকে—যেমন user profile, software, hardware, services ও security policy।

ভুল পরিবর্তনে Windows বা application নষ্ট হতে পারে। তাই পরিবর্তনের আগে setting বুঝে নাও এবং lab-এ পরীক্ষা করো।

## ২. Registry Structure

| Component | কাজ                                      |
| --------- | ---------------------------------------- |
| Hive      | Registry-এর প্রধান বিভাগ                 |
| Key       | Folder-এর মতো container                  |
| Subkey    | Key-এর ভিতরের key                        |
| Value     | নির্দিষ্ট setting; Name, Type, Data থাকে |

উদাহরণ:

```
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion
```

- `HKEY_LOCAL_MACHINE` = Hive
- `SOFTWARE` = Key
- `Microsoft\Windows\CurrentVersion` = Subkeys

### প্রধান Hives

| Hive   | কাজ                                         |
| ------ | ------------------------------------------- |
| `HKCU (HKEY_CURRENT_USER)` | বর্তমান user-এর settings                    |
| `HKLM (HKEY_LOCAL_MACHINE)` | পুরো system-এর settings                     |
| `HKCR (HKEY_CLASSES_ROOT)` | File association ও application registration |
| `HKU (HKEY_USERS(`  | Loaded user profiles                        |
| `HKCC (HKEY_CURRENT_CONFIG)` | বর্তমান hardware configuration              |

`HKCU` সাধারণত বর্তমান user-কে প্রভাবিত করে; `HKLM` পুরো computer-কে এবং সাধারণত admin privilege প্রয়োজন।

### Registry Value Types

| Type           | কাজ           |
| -------------- | ------------- |
| `REG_SZ`       | Text string   |
| `REG_DWORD`    | 32-bit number |
| `REG_QWORD`    | 64-bit number |
| `REG_MULTI_SZ` | একাধিক string |
| `REG_BINARY`   | Binary data   |

## ৩. Registry Editor (`regedit.exe`)

খোলার উপায়: Start Menu-তে `regedit` অথবা `Win + R` → `regedit`।

- বাম পাশে Registry hierarchy, ডানে values।
- Address bar-এ Registry path দেওয়া যায়।
- Value double-click করে পরিবর্তন করা যায়।
- `Delete` দিয়ে key/value মুছতে পারো; Windows dependency যাচাই করে না।

## ৪. `reg.exe` Command Line

```
reg /?
```

প্রধান operations: `QUERY`, `ADD`, `DELETE`, `COPY`, `SAVE`, `LOAD`, `UNLOAD`, `RESTORE`, `COMPARE`, `EXPORT`, `IMPORT`, `FLAGS`।

Return code: `0` = সফল, `1` = ব্যর্থ।

```
reg query /?
```

গুরুত্বপূর্ণ parameters:

| Parameter | কাজ                              |
| --------- | -------------------------------- |
| `/v`      | নির্দিষ্ট value                  |
| `/ve`     | Default/empty-name value         |
| `/s`      | Subkeys-সহ recursive query       |
| `/f`      | Data বা pattern খোঁজা            |
| `/k`      | শুধু key name-এ search           |
| `/d`      | শুধু data-তে search              |
| `/c`      | Case-sensitive                   |
| `/e`      | Exact match                      |
| `/t`      | Value type নির্ধারণ              |
| `/z`      | Type-এর numeric equivalent দেখায় |
| `/reg:32` | 32-bit Registry view             |
| `/reg:64` | 64-bit Registry view             |
| `/se`     | `REG_MULTI_SZ` separator         |

`/f`-এ space-সহ string হলে double quotes ব্যবহার করো। Remote query-তে `HKLM` ও `HKU` ব্যবহার করা যায়।

### Query করা

```
reg query "HKCU\Software\HTB-Academy"
```

Output:

```
HKEY_CURRENT_USER\Software\HTB-Academy
    CourseName      REG_SZ       Windows Fundamentals
    LabComplete     REG_DWORD    0x1
```

নির্দিষ্ট value:

```
reg query "HKCU\Software\HTB-Academy" /v CourseName
```

আরও উদাহরণ:

```
reg query HKLM\Software\Microsoft\ResKit /v Version
reg query \\ABC\HKLM\Software\Microsoft\ResKit\Nt\Setup /s
reg query HKLM\Software\Microsoft\ResKit\Nt\Setup /se #
reg query HKLM /f SYSTEM /t REG_SZ /c /e
reg query HKCU /f 0F /d /t REG_BINARY
reg query HKLM\SOFTWARE /ve
```

### Value তৈরি বা পরিবর্তন

Parameters: `/v` = value name, `/t` = type, `/d` = data, `/f` = confirmation ছাড়াই execute।

```
reg add "HKCU\Software\HTB-Academy" /v CreatedBy /t REG_SZ /d "reg.exe" /f
reg add "HKCU\Software\HTB-Academy" /v LabComplete /t REG_DWORD /d 0 /f
```

যাচাই:

```
reg query "HKCU\Software\HTB-Academy"
```

Output:

```
HKEY_CURRENT_USER\Software\HTB-Academy
    CourseName    REG_SZ       Windows Fundamentals
    LabComplete   REG_DWORD    0x0
    CreatedBy     REG_SZ       reg.exe
```

### Registry Data Delete

শুধু একটি value মুছতে:

```
reg delete "HKCU\Software\HTB-Academy" /v CreatedBy /f
```

সম্পূর্ণ key ও তার values মুছতে:

```
reg delete "HKCU\Software\HTB-Academy" /f
```

সতর্কতা: `/f` confirmation ছাড়াই কাজ করে। Path ভালোভাবে যাচাই করো।

## ৫. Registry Permissions

- `HKCU`-এর কিছু setting সাধারণ user পরিবর্তন করতে পারে।
- `HKLM`-এর system-wide setting পরিবর্তনে সাধারণত Administrator privilege লাগে।
- Permission না থাকলে `Access is denied` বা `The requested operation requires elevation` error আসতে পারে।

## ৬. UAC ও Registry

UAC (User Account Control) অনুমতি ছাড়া administrative পরিবর্তন ঠেকাতে সাহায্য করে।

Policy path:

```
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
```

`EnableLUA` হলো `REG_DWORD` value:

- `1` = UAC enabled
- `0` = UAC disabled

বর্তমান value যাচাই:

```
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v EnableLUA
```

Output:

```
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
    EnableLUA    REG_DWORD    0x1
```

পরিবর্তনের জন্য Administrator privilege প্রয়োজন; সম্পূর্ণ কার্যকর হতে সাধারণত restart লাগে। UAC disable কেবল প্রয়োজন হলে isolated lab-এ করো।
