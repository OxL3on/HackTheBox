## 1. Windows-এর Directory Structure

Windows-এ সাধারণত Operating System `C:\` Drive-এ Install করা থাকে। এটিকে Root Directory বলা হয়। HTB-এর এই Section-এ একে Boot Partition হিসেবেও উল্লেখ করা হয়েছে।

অন্য Physical বা Virtual Drive-কে আলাদা Letter দেওয়া হয়। যেমন:

- `C:\` — সাধারণত Windows-এর প্রধান Drive।
- `E:\` — উদাহরণস্বরূপ Data Drive।

### 1.1 গুরুত্বপূর্ণ Windows Directories

| Directory                                   | কাজ                                                                                                                                                                       |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `C:\PerfLogs`                               | Windows Performance Log সংরক্ষণ করতে পারে। Default অবস্থায় সাধারণত খালি থাকে।                                                                                             |
| `C:\Program Files`                          | 32-bit Windows-এ 16-bit ও 32-bit Program Install হয়। 64-bit Windows-এ সাধারণত 64-bit Program Install হয়।                                                                  |
| `C:\Program Files (x86)`                    | 64-bit Windows-এ 32-bit ও 16-bit Program Install হওয়ার Directory।                                                                                                         |
| `C:\ProgramData`                            | Hidden Folder। Installed Program-এর প্রয়োজনীয় Data রাখে, যা বিভিন্ন User-এর Program ব্যবহার করতে পারে।                                                                    |
| `C:\Users`                                  | System-এ Login করা প্রত্যেক User-এর Profile থাকে। এর মধ্যে `Public` ও `Default` Folder-ও থাকে।                                                                            |
| `C:\Users\Default`                          | নতুন User তৈরি হলে তার Profile তৈরির Template হিসেবে ব্যবহৃত হয়।                                                                                                          |
| `C:\Users\Public`                           | বিভিন্ন User-এর মধ্যে File Share করার জন্য ব্যবহৃত হয়। Default অবস্থায় সব User এটি Access করতে পারে। Network Share-এর মাধ্যমে Access করতে বৈধ Network Account প্রয়োজন হয়। |
| `C:\Users\<username>\AppData`               | প্রত্যেক User-এর Application Data ও Settings রাখে। এটি Hidden Folder।                                                                                                     |
| `C:\Windows`                                | Windows Operating System চালানোর জন্য প্রয়োজনীয় অধিকাংশ File থাকে।                                                                                                        |
| `C:\Windows\System`, `System32`, `SysWOW64` | Windows-এর Core Feature ও Windows API-এর প্রয়োজনীয় DLL থাকে। Program কোনো DLL-এর Absolute Path না দিলে Windows এই ধরনের Directory-তে DLL খোঁজে।                           |
| `C:\Windows\WinSxS`                         | Windows Component Store। Windows Component, Update ও Service Pack-এর Copy রাখে।                                                                                           |

DLL (Dynamic-Link Library): এমন File, যাতে বিভিন্ন Program ব্যবহার করতে পারে এমন Code ও Function থাকে।

### 1.2 AppData Directory

প্রত্যেক User-এর Application Data ও Settings সাধারণত এখানে থাকে:

```
C:\Users\<username>\AppData
```

`AppData`-এর মধ্যে তিনটি গুরুত্বপূর্ণ Subfolder রয়েছে।

| Folder     | কাজ                                                                                                                                     |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `Roaming`  | User Profile-এর সঙ্গে অন্য Computer-এ নেওয়া বা Synchronize করা যায় এমন Data রাখার জন্য ব্যবহৃত হয়। উদাহরণ: Custom Dictionary।           |
| `Local`    | নির্দিষ্ট Computer-এর জন্য Application Data রাখে। সাধারণত Network-এর মাধ্যমে অন্য Computer-এ Synchronize করা হয় না।                     |
| `LocalLow` | `Local`-এর মতো Data রাখে, তবে এর Integrity Level কম। Protected বা Safe Mode-এ চলা Web Browser-এর মতো Application এটি ব্যবহার করতে পারে। |

উদাহরণ:

```
C:\Users\cliff.moore\AppData\Roaming
C:\Users\cliff.moore\AppData\Local
C:\Users\cliff.moore\AppData\LocalLow
```

Pentesting-এ কেন গুরুত্বপূর্ণ?

User Profile এবং Application Data পরীক্ষা করলে Application Configuration, User-সম্পর্কিত Data এবং বিভিন্ন গুরুত্বপূর্ণ File খুঁজে পাওয়া যেতে পারে।

### 1.3 System32 ও SysWOW64

`System32` এবং `SysWOW64` Windows-এর গুরুত্বপূর্ণ System Directory।

এগুলোতে Windows-এর Core Feature ও Windows API-এর জন্য প্রয়োজনীয় DLL থাকে। কোনো Program DLL Load করতে চাইলে এবং DLL-এর Absolute Path উল্লেখ না করলে Windows নির্দিষ্ট Search Path ব্যবহার করে।

তাই Pentesting-এর সময় এই Directory-গুলোর কাজ জানা গুরুত্বপূর্ণ, বিশেষত Windows-এর Program Execution ও DLL Loading বোঝার ক্ষেত্রে।

### 1.4 WinSxS

```
C:\Windows\WinSxS
```

এটি Windows Component Store। এখানে Windows Component, Update এবং Service Pack-এর Copy থাকে।

## 2. Command Line দিয়ে Directory দেখা

Windows Command Prompt (CMD) ব্যবহার করে File System পরীক্ষা করা যায়।

এই Section-এ দুটি গুরুত্বপূর্ণ Command রয়েছে:

- `dir` — Directory-এর File ও Folder-এর তালিকা দেখায়।
- `tree` — Folder Structure গাছের মতো করে দেখায়।

## 3. `dir` Command

`dir` Command দিয়ে কোনো Directory-এর File ও Folder-এর তালিকা দেখা যায়।

Official Documentation: [dir — Microsoft Learn](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/dir?utm_source=chatgpt.com)

### 3.1 Command

```
dir c:\ /a
```

ব্যাখ্যা:

| অংশ   | কাজ                                                                                                                                   |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `dir` | File ও Folder-এর তালিকা দেখায়।                                                                                                        |
| `c:\` | C Drive-এর Root Directory নির্বাচন করে।                                                                                               |
| `/a`  | Attribute অনুযায়ী File ও Directory দেখায়; কোনো Attribute নির্দিষ্ট না করায় Hidden ও System Attribute-যুক্ত Entry-ও তালিকায় আসতে পারে। |

### 3.3 Output-এর গুরুত্বপূর্ণ অংশ

| Entry                       | অর্থ                                                      |
| --------------------------- | --------------------------------------------------------- |
| `$Recycle.Bin`              | Deleted File-এর Recycle Bin-সংক্রান্ত Directory।          |
| `$WinREAgent`               | Windows Recovery Environment-সংক্রান্ত File রাখতে পারে।   |
| `Documents and Settings`    | এখানে `C:\Users`-এর দিকে নির্দেশ করা একটি Junction রয়েছে। |
| `hiberfil.sys`              | Windows Hibernation-এর জন্য ব্যবহৃত System File।          |
| `pagefile.sys`              | Virtual Memory-এর জন্য ব্যবহৃত Paging File।               |
| `swapfile.sys`              | Windows-এর Memory Management-সংক্রান্ত System File।       |
| `Program Files`             | Installed Program-এর Directory।                           |
| `Program Files (x86)`       | 64-bit Windows-এ সাধারণত 32-bit Program-এর Directory।     |
| `ProgramData`               | Program-এর জন্য ব্যবহৃত Data Directory।                   |
| `Recovery`                  | Recovery-সংক্রান্ত File ও Resource রাখতে পারে।            |
| `System Volume Information` | System-এর Volume-সংক্রান্ত তথ্য রাখে।                     |
| `Users`                     | User Profile-এর Directory।                                |
| `Windows`                   | Operating System-এর প্রধান Directory।                     |

Output-এর কিছু গুরুত্বপূর্ণ Indicator:

- `<DIR>` — Directory।
- `<JUNCTION>` — অন্য Directory বা Path-এর দিকে নির্দেশ করা File System Junction।
- `File(s)` — তালিকায় পাওয়া File-এর সংখ্যা।
- `Dir(s)` — তালিকায় পাওয়া Directory-এর সংখ্যা।
- `bytes free` — Drive-এ অবশিষ্ট Free Space।

এই Output-টি HTB-এর নির্দিষ্ট Windows System থেকে নেওয়া। অন্য Windows Computer-এ File, Size, Date এবং Directory-এর তালিকা আলাদা হতে পারে।

## 4. `tree` Command

`tree` Command দিয়ে কোনো Directory বা Drive-এর Folder Structure গাছের মতো করে দেখা যায়।

Official Documentation: [tree — Microsoft Learn](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/tree?utm_source=chatgpt.com)

### 4.1 নির্দিষ্ট Directory-এর Structure দেখা

HTB-এর Command:

```
tree "c:\Program Files (x86)\VMware"
```

এখানে:

- `tree` — Folder Structure প্রদর্শন করে।
- `"c:\Program Files (x86)\VMware"` — যে Directory-এর Structure দেখতে চাই, সেটির Path।
- Path-এর মধ্যে Space থাকায় Double Quote ব্যবহার করা হয়েছে।

## 5. সম্পূর্ণ Drive-এর File ও Directory Structure দেখা

C Drive-এর সব Directory এবং File-এর Structure দেখতে HTB-এর দেওয়া Command:

```
tree c:\ /f | more
```

এই Command-টি কয়েকটি অংশে কাজ করে:

\| অংশ | কাজ | |---|---| | `tree` | Folder Structure প্রদর্শন করে। | | `c:\` | C Drive-এর Root Directory নির্বাচন করে। | | `/f` | Folder-এর পাশাপাশি File-এর নামও প্রদর্শন করে। | | `|` | প্রথম Command-এর Output দ্বিতীয় Command-এ পাঠায়। | | `more` | Output-কে একাধিক Screen/Page-এ দেখায়, যাতে বড় Output ধীরে ধীরে পড়া যায়। |

এই Command যেকোনো উপযুক্ত Directory-এর জন্য পরিবর্তন করে ব্যবহার করা যায়।

উদাহরণস্বরূপ, অন্য Drive-এর Structure দেখতে চাইলে:

```
tree E:\ /f | more
```

Pentesting-এ ব্যবহার: কোনো Windows System-এ Access পাওয়ার পর Directory Structure পরীক্ষা করে Installed Software, User Directory এবং অন্যান্য গুরুত্বপূর্ণ File Location সম্পর্কে ধারণা নেওয়া যায়।

## 6. Quick Revision

| Command / Concept      | মনে রাখার বিষয়                                                            |
| ---------------------- | ------------------------------------------------------------------------- |
| `C:\`                  | Windows-এর সাধারণ Root Directory।                                         |
| `Program Files`        | সাধারণত 64-bit Program-এর Directory।                                      |
| `Program Files (x86)`  | 64-bit Windows-এ সাধারণত 32-bit Program-এর Directory।                     |
| `ProgramData`          | বিভিন্ন Program-এর ব্যবহৃত Data।                                          |
| `Users`                | User Profile-এর Directory।                                                |
| `AppData\Roaming`      | Profile-এর সঙ্গে Synchronize করা যেতে পারে এমন Application Data।          |
| `AppData\Local`        | Computer-নির্দিষ্ট Application Data।                                      |
| `AppData\LocalLow`     | তুলনামূলক কম Integrity Level-এ ব্যবহৃত Application Data।                  |
| `System32`, `SysWOW64` | Windows System File ও DLL-এর গুরুত্বপূর্ণ Directory।                      |
| `WinSxS`               | Windows Component Store।                                                  |
| `dir c:\ /a`           | C Drive-এর Root-এর File ও Directory তালিকা দেখায়, Hidden/System Entry-সহ। |
| `tree "C:\Path"`       | নির্দিষ্ট Directory-এর Folder Structure দেখায়।                            |
| `tree c:\ /f \\| more` | C Drive-এর Folder ও File Structure Page ধরে দেখায়।                        |

এই Section-এর মূল শিক্ষা: Windows File System-এর গুরুত্বপূর্ণ Directory চিনতে হবে এবং CMD-এর `dir` ও `tree` Command দিয়ে File System Enumeration করতে জানতে হবে।
