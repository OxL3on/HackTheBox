## **Writing and Importing Modules**

ExploitDB is a great choice when searching for a custom exploit. We can use tags 
to search through the different exploitation scenarios for each available script. One of these tags is Metasploit Framework (MSF), which, if selected, will display only scripts that are also available in Metasploit module format. These can be directly downloaded from ExploitDB and installed in our local Metasploit Framework directory, from where they can be searched and called from within the `msfconsole`.

```bash
00Luffy00@htb[/htb]$ searchsploit -t Nagios3 --exclude=".py"
```

We have to download the `.rb` file and place it in the correct directory. The default directory where all the modules, scripts, plugins, and `msfconsole` proprietary files are stored is `/usr/share/metasploit-framework`. The critical folders are also symlinked in our home and root folders in the hidden `~/.msf4/` location. We copy it into the appropriate directory after downloading the exploit. 

**MSF - Loading Additional Modules at Runtime**

```
00Luffy00@htb[/htb]$ cp ~/Downloads/9861.rb /usr/share/metasploit-framework/modules/exploits/unix/webapp/nagios3_command_injection.rb
00Luffy00@htb[/htb]$ msfconsole -m /usr/share/metasploit-framework/modules/
```

**MSF - Loading Additional Modules**

```
msf6> loadpath /usr/share/metasploit-framework/modules/
```

Alternatively, we can also launch `msfconsole` and run the **`reload_all`**
 command for the newly installed module to appear in the list. After the
 command is run and no errors are reported, try either the **`search [name]`** function inside `msfconsole` or directly with the **`use [module-path]`** to jump straight into the newly installed module.

#### **Porting Over Scripts into Metasploit Modules**

To adapt a custom Python, PHP, or any type of exploit script to a Ruby module for Metasploit, we will need to learn the Ruby programming language. Note that Ruby modules for Metasploit are always written using hard tabs.

If you would like to learn more about porting scripts into the Metasploit Framework, check out the Metasploit: A Penetration Tester's Guide book from No Starch Press. Rapid7 has also created blog posts on this topic, which can be found here.
