## **Targets**

<img width="1024" height="559" alt="image" src="https://github.com/user-attachments/assets/b7568af9-4724-4ca0-9788-3e03946a3459" />

`Targets`are unique operating system identifiers taken from the versions of 
those specific operating systems which adapt the selected exploit module
 to run on that particular version of the operating system.

**An exploit may work differently depending on the target OS/software version, so Metasploit needs to know which target it's attacking.**

```bash
msf6 > show targets
```

**What is Automatic?**

```
Target 0 = Automatic
```

This means: Metasploit will try to detect the victim's OS/software version and choose the correct target automatically.

If You already know the version: `set target 6`

**What is a Target Type? :** This is the most confusing part. Every Windows version stores programs differently in memory. For example:

```
Windows XP

JMP ESP
0x7C941EED
```

Windows 7:

```
JMP ESP
0x77A21FEE
```

Different address. Same vulnerability. Different exploit parameters. Therefore: Different Target.

To identify a target correctly, we will need to:

- Obtain a copy of the target binaries
- Use msfpescan to locate a suitable return address
