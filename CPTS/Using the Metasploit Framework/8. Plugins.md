## **Plugins**

Plugins are third-party software integrated into Metasploit to add extra functionality. Plugins make pentesting easier by bringing external tool functionality directly into: msfconsole.

### **Using Plugins**

```bash
ls /usr/share/metasploit-framework/plugins
```

(This the default directory for every new installation of msfconsole)

If the plugin is found here, we can fire it up inside `msfconsole` and will be met with the greeting output for that specific plugin, signaling that it was successfully loaded in and is now ready to use. 

**MSF - Load Nessus : `load nessus` .** Then ****`nessus_help`

### **Installing new Plugins**

To install new custom plugins not included in new updates of the distro, we can take the .rb file provided on the maker's page and place it in the folder at `/usr/share/metasploit-framework/plugins` with the proper permissions.

```bash
00Luffy00@htb[/htb]$ git clone https://github.com/darkoperator/Metasploit-Plugins

00Luffy00@htb[/htb]$ ls Metasploit-Plugins

00Luffy00@htb[/htb]$ sudo cp ./Metasploit-Plugins/pentest.rb /usr/share/metasploit-framework/plugins/pentest.rb

00Luffy00@htb[/htb]$ msfconsole -q

msf6 > load pentest

msf6 > help
```
