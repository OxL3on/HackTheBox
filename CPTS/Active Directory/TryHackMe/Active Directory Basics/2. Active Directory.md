# **Active Directory (AD)**

### **1. AD DS কী?**

**Active Directory Domain Services (AD DS):** Domain-এর সব object-এর information রাখে ও manage করে।

Common objects:

- Users
- Groups
- Machines
- Printers
- Shared folders

### **2. Users**

User হলো **Security Principal** — যে identity দিয়ে network-এ login করা যায় এবং resources access করা যায়।

দুই ধরনের User:

- **People:** Employees বা সাধারণ মানুষ।
- **Services:** IIS, MSSQL-এর মতো services চালানোর account। এদের শুধু প্রয়োজনীয় permissions দেওয়া হয়।

### **3. Machines**

- Domain-এ কোনো computer join করলে AD-তে তার Machine Account তৈরি হয়।
- Machine account-ও Security Principal।
- Computer-এর নিজের account থাকে, সাধারণত computer নিজেই এটি ব্যবহার করে।
- Password automatically rotate হয় এবং সাধারণত 120 random characters-এর হয়।
- Machine account চেনার নিয়ম: Computer name + `$`

Example: `DC01$`

### **4. Security Groups**

Group দিয়ে একসাথে অনেক User বা Machine-কে permission দেওয়া যায়।

- Group-এর member হতে পারে User ও Machine।
- Group-এর ভিতরে অন্য Group-ও রাখা যায়।
- User একাধিক Group-এর member হতে পারে।

**Important Groups:**

| Group              | কাজ                                                     |
| ------------------ | ------------------------------------------------------- |
| Domain Admins      | পুরো Domain ও DC manage করতে পারে                       |
| Server Operators   | Domain Controller manage করতে পারে                      |
| Backup Operators   | File permission ignore করে যেকোনো file access করতে পারে |
| Account Operators  | Domain account create/modify করতে পারে                  |
| Domain Users       | সব domain users                                         |
| Domain Computers   | সব domain computers                                     |
| Domain Controllers | সব DC                                                   |

Full list: [Microsoft – AD Security Groups](https://docs.microsoft.com/en-us/windows/security/identity-protection/access-control/active-directory-security-groups?utm_source=chatgpt.com)

### **5. Organizational Units (OUs)**

**OU:** AD-তে User ও Machine সাজিয়ে রাখার container। মূল কাজ হলো Group Policy দিয়ে একসাথে policies apply করা।

- IT, Sales, Marketing ইত্যাদি department অনুযায়ী OU তৈরি করা যায়।

- OU-এর ভিতরে User, Machine ও অন্য OU রাখা যায়।

**AD Users and Computers:** DC থেকে এই tool চালিয়ে User, Group, Machine manage করা যায়। যেমন create, delete, modify এবং password reset।

### **6. Default AD Containers**

| Container                | কাজ                    |
| ------------------------ | ---------------------- |
| Builtin                  | Default Windows groups |
| Computers                | নতুন domain computers  |
| Domain Controllers       | সব DC                  |
| Users                    | Default users ও groups |
| Managed Service Accounts | Service accounts       |

### **7. Security Groups vs OUs**

| OUs                       | Security Groups              |
| ------------------------- | ---------------------------- |
| Policies apply করে        | Permissions দেয়              |
| User একটিমাত্র OU-তে থাকে | User অনেক Group-এ থাকতে পারে |
| User/Machine organize করে | Resource access control করে  |

**Example:**

- OU: IT department-এর computers-এ একই security policy apply করা।
- Group: IT team-কে shared folder access দেওয়া।

### **Quick Revision**

- **AD DS:** Domain-এর objects manage করে।
- **Security Principal:** যাকে authenticate করে permissions দেওয়া যায়।
- **User:** People বা Service account।
- **Machine Account:** Computer-এর নিজস্ব account, যেমন `DC01$`।
- **Security Group:** একসাথে permissions দেওয়ার ব্যবস্থা।
- **OU:** User/Machine organize ও policies apply করার container।
- **OU = Policies, Group = Permissions।**

**Pentesting-এর জন্য মনে রাখবে:** Domain Admins, Backup Operators, Server Operators এবং Account Operators গুরুত্বপূর্ণ privilege groups। ভুলভাবে দেওয়া permissions privilege escalation-এর সুযোগ তৈরি করতে পারে।
