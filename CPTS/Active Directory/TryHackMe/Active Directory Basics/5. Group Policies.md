# **Group Policies (GPO)**

### **1. GPO কী?**

**Group Policy Object (GPO):** একসাথে অনেক User ও Computer-এর settings/security rules control করার ব্যবস্থা।

- GPO-তে User ও Computer দুটিরই settings থাকতে পারে।
- GPO তৈরি করে নির্দিষ্ট OU-তে link করতে হয়।
- Parent OU-এর GPO child OU-তেও apply হয় (inheritance)।

### **2. GPO Management**

Tool: **Group Policy Management**

- `Group Policy Objects` → Create GPO → Edit → OU-তে Link।
- **Scope:** কোন OU/Domain-এ GPO apply হবে।
- **Security Filtering:** কারা GPO পাবে।
- Default: `Authenticated Users` (সব authenticated users ও computers)।
- **Settings:** GPO-তে কী কী rules আছে।

### **3. Important GPOs**

| GPO                               | কাজ                             |
| --------------------------------- | ------------------------------- |
| Default Domain Policy             | পুরো Domain-এর default policies |
| RDP Policy                        | Domain-এর RDP-related policies  |
| Default Domain Controllers Policy | শুধু DC OU-এর policies          |

**Password Policy পরিবর্তনের path:**

```
Computer Configuration
→ Policies
→ Windows Settings
→ Security Settings
→ Account Policies
→ Password Policy
```

Example: Minimum password length = 10 characters।

কোনো policy বুঝতে: Double-click → `Explain` tab।

### **4. GPO Distribution – SYSVOL**

- GPO network-এ distribute হয় `SYSVOL` share দিয়ে।
- এটি Domain Controller-এ থাকে।
- Default path:

```
C:\Windows\SYSVOL\sysvol\
```

- GPO update হতে সর্বোচ্চ প্রায় 2 ঘণ্টা লাগতে পারে।
- সঙ্গে সঙ্গে update করতে:

```
gpupdate /force
```

### **5. Practical GPO Examples**

**A. Restrict Control Panel**

লক্ষ্য: IT ছাড়া অন্য department Control Panel access করতে পারবে না।

GPO Name: `Restrict Control Panel Access`

Policy path:

```
User Configuration
→ Policies
→ Administrative Templates
→ Control Panel
→ Prohibit Access to Control Panel and PC settings
```

- Policy Enable করো।
- Marketing, Management ও Sales OU-তে link করো।
- IT OU-তে link করবে না।

**B. Auto Lock Screen**

লক্ষ্য: 5 মিনিট inactivity হলে screen automatically lock হবে।

GPO Name: `Auto Lock Screen`

Policy: `Interactive logon: Machine inactivity limit`

- Value: 300 seconds (5 minutes)।
- `Computer Configuration`-এর অধীনে policy configure করো।
- Root Domain-এ link করো।
- Workstations, Servers ও DCs সবাই inherit করবে।

**Important:** User-only OU-তে Computer Configuration-এর policy কার্যকর হবে না।

### **6. Pentesting-এর জন্য গুরুত্বপূর্ণ**

- **GPO Misconfiguration:** ভুল policy দিয়ে security দুর্বল হতে পারে।
- **GPO Permissions:** কে GPO modify করতে পারে তা পরীক্ষা করা জরুরি।
- **SYSVOL:** Network users GPO files access করতে পারে; তাই এখানে sensitive information বা exposed credentials আছে কি না পরীক্ষা করতে হয়।
- **Inheritance:** Parent OU/Domain-এর policy child OU-তে apply হতে পারে।
- **Security Filtering:** কোন user/computer policy পাবে তা নিয়ন্ত্রণ করে।

### **Quick Revision**

| Term                   | মনে রাখবে                          |
| ---------------------- | ---------------------------------- |
| GPO                    | User/Computer settings control করে |
| Scope                  | কোথায় GPO apply হবে                |
| Security Filtering     | কার ওপর apply হবে                  |
| Inheritance            | Parent policy child-এ যায়          |
| SYSVOL                 | GPO distribution share             |
| `gpupdate /force`      | Immediately GPO update             |
| User Configuration     | User-এর settings                   |
| Computer Configuration | Computer-এর settings               |

**সবচেয়ে গুরুত্বপূর্ণ:** GPO = Settings/Policies, OU = কোথায় apply হবে, Security Filtering = কার ওপর apply হবে, SYSVOL = GPO distribution।
