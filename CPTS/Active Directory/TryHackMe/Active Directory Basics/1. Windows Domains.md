# **Windows Domains**

### **1. Windows Domain কী?**

- **Windows Domain:** একটি network যেখানে অনেকগুলো computer ও user এক জায়গা থেকে manage করা হয়।
- **Active Directory (AD):** সব user, computer ও security policy রাখার central database/service।
- **Domain Controller (DC):** যে server Active Directory চালায় এবং domain manage করে।

### **2. কেন Windows Domain ব্যবহার করা হয়?**

- **Centralised Identity Management:** এক জায়গা থেকে সব user account manage করা যায়।
- **Security Policy Management:** এক জায়গা থেকে সব computer ও user-এর security rules control করা যায়।

### **3. Real-world Example**

University-এর একটি username/password দিয়ে অনেকগুলো computer-এ login করা যায়।

কারণ:

1. User computer-এ credentials দেয়।
2. Computer authentication-এর জন্য DC/AD-এর কাছে পাঠায়।
3. AD credentials check করে।
4. সঠিক হলে access দেয়।

এছাড়া AD policy দিয়ে students-দের Control Panel access বন্ধ রাখা যায়।

### **Quick Revision**

| Term                 | সহজ অর্থ                                   |
| -------------------- | ------------------------------------------ |
| Windows Domain       | অনেক computer ও user-এর central management |
| AD                   | User, computer ও policy manage করার system |
| DC                   | AD চালানো server                           |
| Centralised Identity | এক জায়গা থেকে user manage                  |
| Security Policies    | Network-এর security rules                  |

**Remember:** Domain = Central Management, AD = Management System, DC = Server.
