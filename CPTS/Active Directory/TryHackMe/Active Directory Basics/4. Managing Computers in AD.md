# **Managing Computers in AD**


### **1. Default Computer Location**

- Domain-এ নতুন computer join করলে defaultভাবে `Computers` container-এ যায়।
- Domain Controllers আলাদা OU-তে থাকে।
- সব computer এক জায়গায় রাখলে আলাদা security policy apply করা কঠিন।

### **2. Types of Devices**

**1. Workstations**

- User-এর daily-use PC ও laptop।
- Browsing ও office work-এর জন্য ব্যবহৃত হয়।
- এখানে কখনো privileged user (Domain Admin) দিয়ে login করা উচিত নয়।

**2. Servers**

- অন্য users বা servers-কে services দেয়।
- Example: Web Server, Database Server।

**3. Domain Controllers (DC)**

- Active Directory ও Domain manage করে।
- সবচেয়ে sensitive devices।
- সব domain users-এর password hashes থাকে, তাই এগুলোকে শক্তভাবে secure করতে হয়।

| OU                 | কী থাকবে                     |
| ------------------ | ---------------------------- |
| Workstations       | Personal computers ও laptops |
| Servers            | সব servers                   |
| Domain Controllers | সব DCs                       |

**Steps:**

1. Domain (`thm.local`)-এ Right-click করে `Workstations` OU তৈরি করো।
2. একইভাবে `Servers` OU তৈরি করো।
3. `Computers` container থেকে PCs ও laptops → `Workstations`-এ move করো।
4. Servers → `Servers` OU-তে move করো।

### **4. Pentesting-এর জন্য গুরুত্বপূর্ণ**

- **Workstations:** সাধারণ users-এর entry point হতে পারে।
- **Servers:** গুরুত্বপূর্ণ services ও data থাকে।
- **Domain Controllers:** সবচেয়ে sensitive target; compromise হলে পুরো domain ঝুঁকিতে পড়ে।
- Privileged accounts দিয়ে সাধারণ workstation ব্যবহার করা উচিত নয় (credential theft-এর ঝুঁকি)।

### **Quick Revision**

| Device      | কাজ                        |
| ----------- | -------------------------- |
| Workstation | User-এর daily-use computer |
| Server      | Network services দেয়       |
| DC          | AD ও Domain manage করে     |

**Remember:** Computers আলাদা OU-তে রাখলে প্রতিটি category-তে আলাদা security policy apply করা যায়। DC সবচেয়ে sensitive device।
