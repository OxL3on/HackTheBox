### **1. Deleting OUs and Users**

- AD-তে unnecessary OU/User delete করা যায়।
- OU delete করতে গেলে error আসতে পারে, কারণ **Accidental Deletion Protection** enabled থাকে।

<img width="404" height="159" alt="image" src="https://github.com/user-attachments/assets/99227165-e1dc-463a-aa86-767221f2ecfd" />

**Delete করার নিয়ম:**

1. `View` → `Advanced Features` enable করো।
2. OU → `Properties` → `Object` tab।
3. `Protect object from accidental deletion` uncheck করো।
4. OU delete করো।

<img width="754" height="417" alt="image" src="https://github.com/user-attachments/assets/3c0d1d77-fd77-4a2e-b2f3-ae404f725f3d" />

Warning: OU delete করলে তার ভিতরের Users, Groups ও Child OUs-ও delete হবে।

### **2. Delegation**

**Delegation:** Domain Admin ছাড়াই নির্দিষ্ট User-কে কোনো OU-এর নির্দিষ্ট কাজ করার permission দেওয়া।

Example:

- Phillip = IT Support।
- Phillip-কে Sales OU-এর users-এর password reset করার permission দেওয়া হয়েছে।
- একইভাবে Marketing ও Management OU-তেও দেওয়া যায়।

<img width="420" height="472" alt="image" src="https://github.com/user-attachments/assets/584c1007-38c2-40d4-a810-f34a5d020852" />

**Steps:**

1. OU-তে Right-click → `Delegate Control`।
2. User select করো (যেমন `phillip`)।
3. `Check Names` → OK।
4. Password reset করার task select করো।
5. Finish।

### **3. Password Reset using PowerShell**

**Phillip-এর RDP username:**\
`THM\phillip`

**Password:** `Claire2008`

Sophie-এর password reset:

```
Set-ADAccountPassword sophie -Reset -NewPassword (Read-Host -AsSecureString -Prompt 'New Password') -Verbose
```

পরের login-এ password change বাধ্যতামূলক করতে:

```
Set-ADUser -ChangePasswordAtLogon $true -Identity sophie -Verbose
```

**Important:**

- `Set-ADAccountPassword` = User-এর password reset।
- `-Reset` = পুরোনো password ছাড়াই reset।
- `Read-Host -AsSecureString` = নিরাপদে নতুন password input।
- `Set-ADUser` = User-এর settings change।
- `-ChangePasswordAtLogon $true` = পরের login-এ password change করতে হবে।

### **4. Pentesting-এর জন্য গুরুত্বপূর্ণ**

- **Delegation Misconfiguration:** ভুল delegation দিলে low-privilege user অন্য user-এর account control করতে পারে।
- Password reset permission থাকলে target user's password পরিবর্তন করে তার account access করা সম্ভব।
- OU-level permissions এবং delegated rights pentesting-এর সময় পরীক্ষা করতে হবে।


### **Quick Revision**

| Concept                        | Remember                                      |
| ------------------------------ | --------------------------------------------- |
| Accidental Deletion Protection | OU delete করতে আগে disable করতে হয়            |
| Delegation                     | অন্য User-কে নির্দিষ্ট কাজের permission দেওয়া |
| `Set-ADAccountPassword`        | Password reset                                |
| `Set-ADUser`                   | User settings modify                          |
| `ChangePasswordAtLogon`        | Next login-এ password change বাধ্যতামূলক      |

**Most important for AD Pentesting: Delegation এবং delegated password reset permissions।**
