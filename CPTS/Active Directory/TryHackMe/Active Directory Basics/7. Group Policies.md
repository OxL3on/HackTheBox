# **Trees, Forests and Trusts**

### **1. Why Multiple Domains?**

একটি company বড় হলে এক Domain manage করা কঠিন হতে পারে।

তাই company-কে আলাদা Domain-এ ভাগ করা যায়, যাতে:

- আলাদা IT team আলাদা Domain manage করতে পারে।
- আলাদা security policies রাখা যায়।
- এক Domain অন্য Domain-এর management থেকে স্বাধীন থাকে।

### **2. Trees**

**Tree:** একই namespace-এর একাধিক connected Domain।

Example:

<img width="1218" height="963" alt="image" src="https://github.com/user-attachments/assets/a6efb984-972e-484c-8a61-0f3f2b232d34" />

[medium.com](https://medium.com/%40fath3ad.22/understanding-active-directory-basics-a8c3e721fbb6?utm_source=chatgpt.com)

```
        thm.local
        /       \
uk.thm.local   us.thm.local
```

- `thm.local` = Root Domain
- `uk.thm.local` ও `us.thm.local` = Child Domains।
- প্রতিটি Domain-এর নিজস্ব AD, Users, Computers ও DC থাকে।
- UK IT team শুধু UK Domain manage করতে পারে।
- প্রতিটি Domain-এর GPO আলাদাভাবে configure করা যায়।

**Enterprise Admins:** এই Group-এর members পুরো Forest-এর সব Domain manage করতে পারে।

**Domain Admins:** শুধু নিজের Domain manage করতে পারে।

### **3. Forests**

**Forest:** ভিন্ন namespace-এর একাধিক Domain Tree একসাথে যুক্ত হলে Forest তৈরি হয়।

<img width="2778" height="1119" alt="image" src="https://github.com/user-attachments/assets/fe9d23ca-8d39-445c-892c-f78b610da1f8" />

[medium.com](https://medium.com/%40aswinchandran274/active-directory-unveiled-beginners-guide-to-network-security-c3a1f8f75179?utm_source=chatgpt.com)

Example:

```
Forest
├── THM Tree
│   ├── thm.local
│   ├── uk.thm.local
│   └── us.thm.local
│
└── MHT Tree
    ├── mht.local
    └── asia.mht.local
```

- একই Forest-এ একাধিক Tree থাকতে পারে।
- প্রতিটি Tree-এর namespace আলাদা হতে পারে।
- Example: দুটি company merge হলে তাদের Domain Trees এক Forest-এ যুক্ত হতে পারে।

### **4. Trust Relationships**

**Trust:** দুটি Domain-এর মধ্যে বিশ্বাসের সম্পর্ক, যার মাধ্যমে এক Domain-এর User অন্য Domain-এর Resources access করার অনুমতি পেতে পারে।

**One-Way Trust**

যদি Domain AAA, Domain BBB-কে trust করে:

- BBB-এর User → AAA-এর Resource access করার অনুমতি পেতে পারে।
- AAA-এর User → BBB-এর Resource automatically access করতে পারে না।

<img width="963" height="386" alt="image" src="https://github.com/user-attachments/assets/712e20a3-68ef-4bd8-b377-89bbca328a29" />

[medium.com](https://medium.com/%40zm8870672/active-directory-basics-4482385122fd?utm_source=chatgpt.com)

**মনে রাখবে:** Trust direction এবং access direction উল্টো।

**Two-Way Trust**

- দুই Domain একে অপরকে trust করে।
- দুই Domain-এর User-ই অন্য Domain-এর Resources access করার অনুমতি পেতে পারে।

Tree বা Forest-এর মধ্যে Domain join করলে defaultভাবে Two-Way Trust তৈরি হয়।

[medium.com](https://medium.com/%40walidsalah231911/active-directory-trust-1c864233e306?utm_source=chatgpt.com)

**Important:** Trust থাকলেই সব Resources access করা যায় না। Resource access করার জন্য আলাদাভাবে permission দিতে হয়।

### **Quick Revision**

| Term              | সহজ অর্থ                           |
| ----------------- | ---------------------------------- |
| Domain            | User ও Computer-এর management unit |
| Tree              | একই namespace-এর একাধিক Domain     |
| Forest            | একাধিক Domain Tree                 |
| Root Domain       | Tree-এর মূল Domain                 |
| Child Domain      | Root Domain-এর অধীনে Domain        |
| Domain Admins     | নিজের Domain control করে           |
| Enterprise Admins | পুরো Forest control করে            |
| One-Way Trust     | একদিকে trust                       |
| Two-Way Trust     | দুইদিকে trust                      |

**সবচেয়ে গুরুত্বপূর্ণ মনে রাখবে:**

```
Domain → Tree → Forest
```

- Tree = Same namespace।
- Forest = Different namespaces হতে পারে।
- Trust = অন্য Domain-এর Resources access করার সুযোগ।
- Trust ≠ Automatic Access।
