# **Authentication Relays**

### **1. SMB (Server Message Block)**

**SMB:** Network protocol যার মাধ্যমে Client ও Server communicate করে।

ব্যবহার:

- File sharing
- Remote administration
- Network printer communication

**Important:** SMB-এর পুরোনো versions-এ security vulnerabilities ছিল।

### **2. SMB Authentication Attacks**

NetNTLM + SMB ব্যবহার করে প্রধানত দুই ধরনের attack করা যায়:

1. **Capture & Crack:** NTLMv2 challenge-response capture করে offline password crack করা।
2. **NTLM Relay:** Authentication request অন্য server-এ forward করে authenticated access পাওয়া।

### **3. LLMNR, NBT-NS & WPAD**

DNS কোনো hostname resolve করতে না পারলে Windows network-এ এসব protocol ব্যবহার হতে পারে।

| Protocol | কাজ                              |
| -------- | -------------------------------- |
| LLMNR    | Local network-এ hostname resolve |
| NBT-NS   | পুরোনো NetBIOS name resolution   |
| WPAD     | Proxy server খুঁজে বের করা       |

**Responder:** এই requests poison করে Client-কে নিজের machine-এর দিকে পাঠাতে পারে।

- Client ভুল IP-তে connect করে।
- Responder fake SMB, HTTP, SQL ইত্যাদি services চালায়।
- Client authentication করলে NetNTLM challenge-response capture করা যায়।

### **4. Capture NetNTLMv2 using Responder**

Tool: Responder

GitHub: [Responder](https://github.com/lgandx/Responder?utm_source=chatgpt.com)

VPN interface-এ Responder চালাও:

```
sudo responder -I breachad
```

- `-I` = Network interface select।
- `breachad` = VPN interface।

কিছুক্ষণ অপেক্ষা করলে এমন output পাওয়া যেতে পারে:

```
[+] Listening for events...

[SMBv2] NTLMv2-SSP Client   : <Client IP>
[SMBv2] NTLMv2-SSP Username : ZA\<Service Account Username>
[SMBv2] NTLMv2-SSP Hash     : <Username>::ZA:<NTLMv2-SSP Hash>
```

**Remember:** Responder local network-এর LLMNR, NBT-NS ও WPAD requests poison করে। VPN lab-এ শুধু VPN network-এর authentication challenges পাওয়া যাবে।

### **5. Crack Captured Hash**

Captured NTLMv2-SSP hash file-এ save করো।

Tool: [Hashcat](https://hashcat.net/hashcat/?utm_source=chatgpt.com)

```
hashcat -m 5600 <hash file> <password file> --force
```

| Parameter         | কাজ                  |
| ----------------- | -------------------- |
| `-m 5600`         | NTLMv2-SSP hash mode |
| `<hash file>`     | Captured hash        |
| `<password file>` | Password wordlist    |
| `--force`         | Force execution      |

THM wordlist location:

```
/root/Rooms/BreachingAD/task5/
```

Weak password হলে crack করে valid AD credentials পাওয়া সম্ভব।

### **6. NTLM Relay Attack**

**NTLM Relay:** Client-এর authentication challenge-response নিজের কাছে capture করে অন্য Server-এ forward করে authenticated access নেওয়া।

<img width="1430" height="288" alt="image" src="https://github.com/user-attachments/assets/6c089aa4-7b14-4ed7-af42-b4fbe92fe773" />

[beta.hackndo.com](https://beta.hackndo.com/ntlm-relay/?utm_source=chatgpt.com)

**Requirements:**

1. **SMB Signing:** Disabled অথবা enabled but not enforced হতে হবে। কারণ relay করার সময় request পরিবর্তন করতে হয়; signing enforce থাকলে forged signature reject হবে।
2. **Account Permissions:** যে account-এর authentication relay করা হচ্ছে, তার target server-এ প্রয়োজনীয় permissions থাকতে হবে।
3. **Target Knowledge:** কোন account কোন server-এ access পায় তা জানা থাকলে attack সফল হওয়ার সম্ভাবনা বাড়ে।

**Important:**

- Administrative account relay করতে পারলে target server-এ foothold পাওয়া সম্ভব।
- Blind relay কঠিন, কারণ account permissions আগে থেকে জানা থাকে না।
- আগে AD compromise করে enumeration করলে উপযুক্ত target নির্বাচন সহজ হয়।
- Relay দিয়ে lateral movement ও privilege escalation সম্ভব হতে পারে।
