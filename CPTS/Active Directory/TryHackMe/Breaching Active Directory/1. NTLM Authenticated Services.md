# **NTLM Authenticated Services**

### **1. NTLM vs NetNTLM**

- **NTLM:** Windows-এর authentication protocol suite।
- **NetNTLM:** NTLM ব্যবহার করে Challenge-Response authentication পদ্ধতি।
- Application নিজে password store করে না। Authentication request DC-তে forward করে।

**Common NetNTLM Services:**

- Exchange / OWA (Mail)
- RDP
- VPN
- Web Applications

### **2. Brute Force vs Password Spraying**

| Brute Force                    | Password Spraying              |
| ------------------------------ | ------------------------------ |
| একজন User-এর অনেক Password try | অনেক User-এর একটি Password try |
| Account Lockout হতে পারে       | Lockout-এর ঝুঁকি তুলনামূলক কম  |
| অনেক failed login              | অনেক failed login              |

**Password Spraying:** অনেকগুলো username-এর বিপরীতে একটি common password পরীক্ষা করা।

Example:

```
User1 → Changeme123
User2 → Changeme123
User3 → Changeme123
```

OSINT থেকে পাওয়া email/username ও initial password ব্যবহার করে initial AD access পাওয়া সম্ভব।

### **3. HTTP Authentication Response**

NetNTLM authentication-এ HTTP response code দেখে login success/failure বোঝা যায়।

| HTTP Code | অর্থ                                 |
| --------- | ------------------------------------ |
| `200`     | Authentication successful            |
| `401`     | Authentication failed / Unauthorized |

### **4. Python Password Spraying**

**Target URL:**

`http://ntlmauth.za.tryhackme.com`

Script-এর গুরুত্বপূর্ণ অংশ:

```
response = requests.get(    url,    auth=HttpNtlmAuth(self.fqdn + "\\" + user, password))
```

- `requests.get()` = Website-এ request পাঠায়।
- `HttpNtlmAuth()` = NTLM authentication ব্যবহার করে।
- `self.fqdn` = Domain name।
- `user` = Username।
- `password` = যে password পরীক্ষা করা হচ্ছে।

Success check:

```
if response.status_code == 200:    print("Valid credentials found!")
```

### **5. Attack Command (THM Lab)**


| Parameter | কাজ                |

### **6. Pentesting-এর জন্য গুরুত্বপূর্ণ**

- **OSINT:** Valid usernames ও email সংগ্রহ।
- **Password Spraying:** Common password দিয়ে multiple accounts পরীক্ষা।
- **NetNTLM:** Windows Authentication ব্যবহারকারী exposed services পরীক্ষা।
- **Account Lockout:** অনেক failed login হলে account lock হতে পারে।
- **Detection:** Password spraying অনেক failed authentication তৈরি করে, তাই logs-এ ধরা পড়তে পারে।

### **Quick Revision**

| Term              | মনে রাখবে                             |
| ----------------- | ------------------------------------- |
| NTLM              | Windows authentication protocol suite |
| NetNTLM           | Challenge-Response authentication     |
| Password Spraying | Many users + One password             |
| Brute Force       | One user + Many passwords             |
| HTTP 200          | Login success                         |
| HTTP 401          | Login failed                          |
| FQDN              | Full domain name                      |
| OSINT             | Public information সংগ্রহ             |

**Remember:** OSINT → Username List → Password Spraying → Valid Credentials → AD Enumeration।
