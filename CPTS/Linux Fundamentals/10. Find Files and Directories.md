# Find Files and Directories


Linux system-এ access পাওয়ার পর configuration file, user বা administrator-এর তৈরি script এবং অন্যান্য file ও directory খুঁজে বের করা জরুরি। প্রতিটি directory হাতে হাতে check না করে `which`, `find` ও `locate` ব্যবহার করা যায়।

## 1. `which`

`which` কোনো command বা program-এর executable path দেখায়। যেমন `curl`, `netcat`, `wget`, `python` ও `gcc` system-এ আছে কি না তা যাচাই করা যায়।

```
00Luffy00@htb[/htb]$ which python

/usr/bin/python
```

Program না থাকলে কোনো result দেখাবে না।

## 2. `find`

`find` দিয়ে file ও directory খোঁজা এবং বিভিন্ন condition দিয়ে result filter করা যায়—যেমন file size, modification date, owner ও object type।

Syntax:

```
find <location> <options>
```

### Command-এর Option

| Option                | কাজ                                                                                                                                                 |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`                   | Root directory থেকে search শুরু করে।                                                                                                                |
| `-type f`             | শুধু file খোঁজে; `f` মানে file।                                                                                                                     |
| `-name *.conf`        | `.conf` extension-যুক্ত file খোঁজে; `*` যেকোনো নাম বোঝায়।                                                                                           |
| `-user root`          | Owner `root` এমন file খোঁজে।                                                                                                                        |
| `-size +20k`          | 20 KiB-এর চেয়ে বড় file খোঁজে।                                                                                                                       |
| `-newermt 2020-03-03` | নির্দিষ্ট তারিখ `2020-03-03`-এর পরে পরিবর্তিত file খোঁজে।                                                                                           |
| `-exec ls -al {} \;`  | প্রতিটি result-এর জন্য `ls -al` চালায়। `{}` result-এর placeholder; `\;` command-এর শেষ semicolon-কে shell-এর special interpretation থেকে রক্ষা করে। |
| `2>/dev/null`         | `STDERR`-এর error message `/dev/null`-এ পাঠায়, তাই terminal-এ error দেখা যায় না। এটি `find`-এর option নয়, shell redirection।                        |

## 3. `locate`

`locate` local database ব্যবহার করে file ও directory খোঁজে। এটি সাধারণত `find`-এর তুলনায় দ্রুত, কারণ প্রতিবার পুরো filesystem search করে না।

Database update করতে:

```
00Luffy00@htb[/htb]$ sudo updatedb
```

সব `.conf` file খুঁজতে:

```
00Luffy00@htb[/htb]$ locate *.conf

/etc/GeoIP.conf
/etc/NetworkManager/NetworkManager.conf
/etc/UPower/UPower.conf
/etc/adduser.conf
<SNIP>
```

`locate` দ্রুত হলেও এর filter option কম। তাই কী খুঁজছি তার ওপর নির্ভর করে `locate` অথবা `find` বেছে নিতে হবে।
