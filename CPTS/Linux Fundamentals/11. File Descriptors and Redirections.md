# File Descriptors and Redirections


## 1. File Descriptor (FD)

File Descriptor (FD) হলো Linux/Unix-এ kernel-এর দেওয়া একটি number বা reference, যা কোনো open file, socket বা অন্য I/O resource-কে identify করে। এর সাহায্যে system বুঝতে পারে কোথা থেকে data পড়তে হবে বা কোথায় লিখতে হবে।

Windows-এ একই ধরনের জিনিসকে File Handle বলা হয়।

সহজ উদাহরণ: Coatroom-এ coat জমা দিলে একটি ticket পাওয়া যায়। Ticket দিয়ে যেমন নিজের coat খুঁজে পাওয়া যায়, তেমনি FD দিয়ে operating system নির্দিষ্ট resource-কে identify করে।

### Linux-এর প্রথম ৩টি File Descriptor

| FD  | নাম      | কাজ                  |
| --- | -------- | -------------------- |
| `0` | `STDIN`  | Input নেওয়া          |
| `1` | `STDOUT` | সাধারণ output দেখানো |
| `2` | `STDERR` | Error output দেখানো  |

## 2. STDIN এবং STDOUT

`cat` command চালালে input লিখে Enter চাপলে সেটি terminal-এ output হিসেবে দেখায়।

- `STDIN (FD 0)`: Input, যেমন `SOME INPUT`।
- `STDOUT (FD 1)`: Input দেওয়ার পর terminal-এ দেখা output।

অর্থাৎ, input যায় `STDIN` দিয়ে, আর সাধারণ output আসে `STDOUT` দিয়ে।

## 3. STDOUT এবং STDERR

`find` command দিয়ে `/etc/`-এর মধ্যে `shadow` file খুঁজলে সাধারণ output ও error—দুটিই দেখা যেতে পারে।

```
find /etc/ -name shadow
```

- `STDOUT`: পাওয়া result, যেমন `/etc/shadow`।
- `STDERR`: error message, যেমন `Permission denied`।

### Error `/dev/null`-এ পাঠানো

```
find /etc/ -name shadow 2>/dev/null
```

এখানে:

- `2`: `STDERR` বা FD 2।
- `>`: Output redirect করে।
- `/dev/null`: Null device; এখানে পাঠানো data discard হয়ে যায়।

ফলে `Permission denied` error আর দেখা যাবে না, শুধু সাধারণ output দেখা যাবে।

## 4. STDOUT একটি File-এ Redirect করা

```
find /etc/ -name shadow 2>/dev/null > results.txt
```

ফলাফল `results.txt` file-এ save হবে।

```
cat results.txt
```

Output:

```
/etc/shadow
```

এখানে `2>/dev/null` error বাদ দেয়, আর `>` সাধারণ output file-এ পাঠায়। তাই `results.txt`-এ শুধু `STDOUT` থাকবে, error থাকবে না।

## 5. STDOUT এবং STDERR আলাদা File-এ রাখা

```
find /etc/ -name shadow 2> stderr.txt 1> stdout.txt
```

- `2> stderr.txt`: Error output `stderr.txt`-এ রাখে।
- `1> stdout.txt`: সাধারণ output `stdout.txt`-এ রাখে।

ফলে:

- `stdout.txt`-এ `/etc/shadow`-এর মতো result থাকবে।
- `stderr.txt`-এ `Permission denied`-এর মতো error থাকবে।

এখানে `1>` লিখে `STDOUT` redirect করা হয়েছে; শুধু `>` লিখলেও default হিসেবে FD 1 redirect হয়।

## 6. STDIN Redirect করা

`<` দিয়ে কোনো file-এর content-কে command-এর input হিসেবে দেওয়া যায়।

```
cat < stdout.txt
```

এটি `stdout.txt`-এর content-কে `cat`-এর `STDIN` হিসেবে পাঠায়। ফলে file-এর content terminal-এ দেখা যায়।

মনে রাখবে:

- `>`: Output redirect।
- `<`: Input redirect।

এগুলোকে data কোন দিক থেকে কোথায় যাচ্ছে, সেই direction হিসেবে ভাবতে পারো।

## 7. STDOUT File-এ Append করা

`>` ব্যবহার করলে:

- File না থাকলে নতুন file তৈরি হয়।
- File আগে থেকে থাকলে তার পুরোনো content overwrite হয়; confirmation চাওয়া হয় না।

পুরোনো content না মুছে নতুন output যোগ করতে `>>` ব্যবহার করতে হয়।

```
find /etc/ -name passwd >> stdout.txt 2>/dev/null
```

এরপর:

```
cat stdout.txt
```

পাঠ্যাংশে দেখানো output:

```
/etc/pam.d/passwd
/etc/cron.daily/passwd
/etc/passwd
```

এখানে `>>` আগের `stdout.txt`-এর content রেখে নতুন result শেষে যোগ করে এবং `2>/dev/null` error বাদ দেয়।

## 8. `<<` দিয়ে Input Stream File-এ লেখা

`<<` ব্যবহার করে একাধিক লাইনের input command-এ দেওয়া যায়। এই পদ্ধতিতে `EOF` একটি delimiter হিসেবে ব্যবহৃত হয়, যা input-এর শেষ নির্দেশ করে।

```
cat << EOF > stream.txt
```

এরপর input হিসেবে লিখবে:

```
Hack The Box
EOF
```

তারপর:

```
cat stream.txt
```

Output:

```
Hack The Box
```

এখানে:

- `<< EOF`: `EOF` delimiter পর্যন্ত input নেয়।
- `cat`: Input পড়ে।
- `> stream.txt`: Output `stream.txt`-এ save করে।

## 9. Pipes (`|`)

Pipe (`|`) একটি command-এর `STDOUT` অন্য command-এর `STDIN` হিসেবে পাঠায়।

### `grep` দিয়ে output filter করা

`grep` নির্দিষ্ট pattern অনুযায়ী output filter করে।

```
find /etc/ -name *.conf 2>/dev/null | grep systemd
```

কাজের ধাপ:

1. `find /etc/ -name *.conf`: `/etc/`-এর মধ্যে `.conf` extension-এর file খোঁজে।
2. `2>/dev/null`: Error বাদ দেয়।
3. `| grep systemd`: result-এর মধ্যে `systemd` থাকা line দেখায়।

পাঠ্যাংশে দেখানো result:

```
system.conf
timesyncd.conf
journald.conf
user.conf
logind.conf
resolved.conf
```

### `wc -l` দিয়ে line গণনা

```
find /etc/ -name *.conf 2>/dev/null | grep systemd | wc -l
```

Output:

```
6
```

কাজের ধাপ:

1. `find` দিয়ে `.conf` file খোঁজা।
2. `grep systemd` দিয়ে matching line filter করা।
3. `wc -l` দিয়ে পাওয়া line-এর সংখ্যা গণনা করা।

একাধিক pipe একসঙ্গে ব্যবহার করে output filter ও process করা যায়।

## 10. Quick Revision

| Syntax        | কাজ                                          |
| ------------- | -------------------------------------------- |
| `0`           | `STDIN`                                      |
| `1`           | `STDOUT`                                     |
| `2`           | `STDERR`                                     |
| `>`           | Output file-এ লেখা; পুরোনো content overwrite |
| `>>`          | Output file-এর শেষে যোগ করা                  |
| `<`           | File থেকে input নেওয়া                        |
| `2>`          | Error output redirect                        |
| `2>/dev/null` | Error discard করা                            |
| `1> file`     | সাধারণ output file-এ লেখা                    |
| `<< EOF`      | Delimiter পর্যন্ত input নেওয়া                |
| `\\|`         | এক command-এর output অন্য command-এ পাঠানো   |
| `grep`        | Pattern অনুযায়ী line filter করা              |
| `wc -l`       | Line গণনা করা                                |

মূল ধারণা: File Descriptor input, output ও error stream identify করে। Redirection দিয়ে stream-কে file বা অন্য destination-এ পাঠানো যায়, আর pipe দিয়ে এক command-এর output অন্য command-এ process করা যায়।
