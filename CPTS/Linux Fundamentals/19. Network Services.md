# Network Services


## 1. Network Services কী?

Linux-এ Network Services network-এর মাধ্যমে অন্য computer-এর সঙ্গে যোগাযোগ, connection তৈরি, file transfer, network traffic analysis এবং remote system পরিচালনা করতে সাহায্য করে।

Penetration testing-এ এগুলো জানা গুরুত্বপূর্ণ, কারণ service-এর ভুল configuration থেকে vulnerability তৈরি হতে পারে।

উদাহরণ: কোনো user unencrypted FTP দিয়ে server-এ connect করলে network traffic capture করে তার username ও password plain text-এ পাওয়া যেতে পারে। FTP connection ও data encrypt করে না—এটি না জানলে credential ফাঁস হওয়ার ঝুঁকি থাকে।

## 2. SSH (Secure Shell)

SSH হলো network protocol, যা network-এর মাধ্যমে নিরাপদে data ও command আদান-প্রদান করতে দেয়।

এটি ব্যবহার করা হয়:

- Remote Linux system-এ নিরাপদে login করতে।
- Remote command execute করতে।
- Securely file transfer করতে।
- Encrypted tunneling ও port forwarding করতে।

OpenSSH হলো SSH protocol-এর একটি free ও open-source implementation। SSH দিয়ে remote system পরিচালনা করার জন্য SSH server চালু থাকতে হবে।

### OpenSSH Install করা

```
sudo apt install openssh-server -y
```

### Server Status দেখা

```
systemctl status ssh
```

উদাহরণ Output:

```
● ssh.service - OpenBSD Secure Shell server
     Loaded: loaded (/lib/system/system/ssh.service; enabled; vendor preset: enabled)
     Active: active (running) since Sun 2023-02-12 21:15:27 GMT; 1min 22s ago
       Docs: man:sshd(8)
             man:sshd_config(5)
   Main PID: 7740 (sshd)
      Tasks: 1 (limit: 9458)
     Memory: 2.5M
        CPU: 236ms
     CGroup: /system.slice/ssh.service
             └─7740 sshd: /usr/sbin/sshd -D [listener] 0 of 10-100 startups
```

`Active: active (running)` মানে SSH service চলছে।

### SSH দিয়ে Remote Login

```
ssh cry0l1t3@10.129.17.122
```

উদাহরণ Output:

```
The authenticity of host '10.129.17.122 (10.129.17.122)' can't be established.
ECDSA key fingerprint is SHA256:bKzhv+n2pYqr2r...Egf8LfqaHNxk.

Are you sure you want to continue connecting (yes/no/[fingerprint])? yes

Warning: Permanently added '10.129.17.122' (ECDSA) to the list of known hosts.

cry0l1t3@10.129.17.122's password: ***********
```

প্রথমবার connect করলে server-এর host key fingerprint যাচাই করতে বলা হয়। উদাহরণে `yes` দেওয়ার পর host key `known hosts`-এ যোগ হয়েছে।

### SSH Configuration

Configuration file:

```
/etc/ssh/sshd_config
```

এখানে পরিবর্তন করা যায়:

- সর্বোচ্চ concurrent connection সংখ্যা
- Password বা key দিয়ে login
- Host key checking
- অন্যান্য SSH settings

Configuration পরিবর্তনের সময় সতর্ক থাকতে হবে। SSH দিয়ে remote command চালানো এবং encrypted tunnel বা port forwarding ব্যবহার করে network ও system settings পরীক্ষা করা যায়।

## 3. NFS (Network File System)

NFS হলো network protocol, যার মাধ্যমে remote system-এর file-গুলো local system-এর file-এর মতো ব্যবহার ও manage করা যায়।

ব্যবহার:

- Centralized file storage ও management
- Linux ও Windows system-এর মধ্যে file sharing
- Server-এর মধ্যে file system replicate করা
- একাধিক user-কে একই data access করতে দেওয়া

NFS access control, real-time file transfer এবং একাধিক user-এর simultaneous access সমর্থন করে। Target system-এ FTP client না থাকলে বা FTP-এর বদলে NFS চালু থাকলে এটি file access-এর কাজে ব্যবহার করা যেতে পারে।

উদাহরণ হিসেবে উল্লেখ করা NFS server:

- NFS-UTILS — Ubuntu
- NFS-Ganesha — Solaris
- OpenNFS — Red Hat Linux

### NFS Install করা

```
sudo apt install nfs-kernel-server -y
```

### Server Status দেখা

```
systemctl status nfs-kernel-server
```

উদাহরণ Output:

```
● nfs-server.service - NFS server and services
     Loaded: loaded (/lib/system/system/nfs-server.service; enabled; vendor preset: enabled)
     Active: active (exited) since Sun 2023-02-12 21:35:17 GMT; 13s ago
    Process: 9234 ExecStartPre=/usr/sbin/exportfs -r (code=exited, status=0/SUCCESS)
    Process: 9235 ExecStart=/usr/sbin/rpc.nfsd $RPCNFSDARGS (code=exited, status=0/SUCCESS)
    Main PID: 9235 (code=exited, status=0/SUCCESS)
         CPU: 10ms
```

`active (exited)` মানে service unit-এর command শেষ হয়েছে; এটি `active (running)`-এর মতো নয়।

### NFS Configuration

Configuration file:

```
/etc/exports
```

এখানে নির্ধারণ করা হয় কোন directory share হবে এবং কোন user/system কী permission পাবে। Transfer speed ও encryption-সম্পর্কিত settings-ও configure করা যায়।

### গুরুত্বপূর্ণ NFS Permissions

| Permission       | কাজ                                                                                                             |
| ---------------- | --------------------------------------------------------------------------------------------------------------- |
| `rw`             | Shared directory-তে read ও write করতে দেয়।                                                                     |
| `ro`             | শুধু read করতে দেয়।                                                                                            |
| `no_root_squash` | Client-এর root user-কে সাধারণ user-এর permission-এ সীমাবদ্ধ করে না।                                             |
| `root_squash`    | Client-এর root user-এর permission সীমিত করে সাধারণ user-এর মতো করে।                                             |
| `sync`           | File system-এ পরিবর্তন সংরক্ষিত হওয়ার পর data transfer নিশ্চিত করে।                                            |
| `async`          | Asynchronously data transfer করে; দ্রুত হতে পারে, তবে পরিবর্তন পুরোপুরি সংরক্ষিত না হলে inconsistency হতে পারে। |

### NFS Share তৈরি করা

```
mkdir nfs_sharing
echo '/home/cry0l1t3/nfs_sharing hostname(rw,sync,no_root_squash)' >> /etc/exports
cat /etc/exports | grep -v "#"
```

Output:

```
/home/cry0l1t3/nfs_sharing hostname(rw,sync,no_root_squash)
```

এখানে share করা directory হলো `/home/cry0l1t3/nfs_sharing` এবং options হলো `rw`, `sync`, `no_root_squash`।

### NFS Share Mount করা

Target-এর NFS share local system-এ ব্যবহার করতে প্রথমে mount করতে হবে।

```
mkdir ~/target_nfs
mount 10.129.12.17:/home/john/dev_scripts ~/target_nfs
tree ~/target_nfs
```

Output:

```
target_nfs/
├── css.css
├── html.html
├── javascript.js
├── php.php
└── xml.xml

0 directories, 5 files
```

এখানে target `10.129.12.17`-এর `/home/john/dev_scripts` share-টি local system-এর `~/target_nfs` mount point-এ mount করা হয়েছে। এরপর remote files-গুলো local directory-এর মতো দেখা যায়।

NFS-এর নির্দিষ্ট কিছু configuration-এর কারণে remote system-এ privilege escalation-এর সুযোগও তৈরি হতে পারে।

## 4. Web Server

Web Server হলো এমন software, যা Internet-এর মাধ্যমে data, documents, applications ও বিভিন্ন functionality সরবরাহ করে।

এটি HTTP ব্যবহার করে browser-এর মতো client থেকে request গ্রহণ করে এবং response পাঠায়। Response-এর HTML browser-এ render হয়ে webpage তৈরি করে।

Linux-এ জনপ্রিয় web server:

- Apache
- Nginx
- Lighttpd
- Caddy

Apache Ubuntu, Solaris ও Red Hat Linux-সহ বিভিন্ন operating system-এর সঙ্গে compatibility-এর কারণে জনপ্রিয়।

### Penetration Testing-এ ব্যবহার

- HTTP/HTTPS দিয়ে target system-এ file transfer করা।
- Target page-এর replica host করে phishing test করা।
- Web server ও network-এর vulnerability পরীক্ষা করা।
- Server traffic logs বিশ্লেষণ করে attack সম্পর্কে তথ্য সংগ্রহ করা।

### Apache Install করা

```
sudo apt install apache2 -y
```

### Apache Configuration

Global configuration file:

```
/etc/apache2/apache2.conf
```

Directory access নিয়ন্ত্রণের উদাহরণ:

```
<Directory /var/www/html>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
</directory>
```

ব্যাখ্যা:

- `/var/www/html` — Default web directory।
- `Indexes` — Directory listing-এর option।
- `FollowSymLinks` — Symbolic link follow করার option।
- `AllowOverride All` — Directory-তে `.htaccess` দিয়ে configuration override করতে দেয়।
- `Require all granted` — সব user-কে ওই directory access করার অনুমতি দেয়।

File transfer করতে প্রয়োজনীয় file `/var/www/html`-এ রেখে target system থেকে `wget`, `curl` বা অন্য application দিয়ে download করা যায়।

### `.htaccess`

`.htaccess` file দিয়ে নির্দিষ্ট directory-র configuration পরিবর্তন করা যায়, global Apache configuration file edit না করেও।

Apache module-এর উদাহরণ:

- `mod_rewrite`
- `mod_security`
- `mod_ssl`

এগুলো web application-এর বিভিন্ন feature ও security উন্নত করতে সাহায্য করে।

### Python Web Server

Python Web Server হলো Apache-এর সহজ ও দ্রুত বিকল্প। একটি command দিয়ে একটি directory host করে file transfer করা যায়।

Python 3 install:

```
sudo apt install python3 -y
```

বর্তমান directory host করা:

```
python3 -m http.server
```

এটি default `TCP/8000` port-এ server চালু করে এবং বর্তমান directory access করতে দেয়।

অন্য directory host করা:

```
python3 -m http.server --directory /home/cry0l1t3/target_files
```

এতে `/home/cry0l1t3/target_files` directory browser থেকে access করা যাবে।

অন্য port ব্যবহার করা:

```
python3 -m http.server 443
```

এতে default `TCP/8000`-এর বদলে port `443`-এ server চালু হবে। Browser-এ server-এর address ও port দিয়ে access করা যাবে।

## 5. VPN (Virtual Private Network)

VPN একটি encrypted tunnel তৈরি করে client-কে অন্য network-এর সঙ্গে যুক্ত করে। এর মাধ্যমে user দূরে থেকেও সেই network-এর ভেতরে থাকা system ও resource access করতে পারে।

VPN-এর কাজ:

- Data encrypt করে confidential রাখা
- Unauthorized access থেকে traffic সুরক্ষিত রাখা
- দূর থেকে organization-এর internal network access করা
- Internet traffic anonymize করতে সাহায্য করা
- External intrusion প্রতিরোধে সহায়তা করা

Linux server-এ ব্যবহৃত VPN solution-এর উদাহরণ:

- OpenVPN
- L2TP/IPsec
- PPTP
- SSTP
- SoftEther

OpenVPN জনপ্রিয় open-source VPN solution। এটি Ubuntu, Solaris ও Red Hat Linux-সহ বিভিন্ন operating system-এ কাজ করে।

### Penetration Testing-এ OpenVPN

- Internal network-এ secure connection তৈরি করা।
- সরাসরি access সম্ভব না হলে দূর থেকে internal system পরীক্ষা করা।
- Encryption, tunneling, traffic shaping ও network routing ব্যবহার করা।
- Dynamic network environment-এ কাজ করা।

### OpenVPN Install করা

```
sudo apt install openvpn -y
```

Configuration file:

```
/etc/openvpn/server.conf
```

এই file-এ server settings এবং encryption, tunneling ও traffic shaping-এর মতো feature configure করা যায়।

### VPN-এ Connect করা

Server থেকে পাওয়া `internal.ovpn` file local system-এ রেখে:

```
sudo openvpn --config internal.ovpn
```

Connection সফল হলে internal network-এর host-গুলোর সঙ্গে যোগাযোগ করা যাবে।

## Quick Revision

| Service           | প্রধান কাজ                                       | গুরুত্বপূর্ণ file/command             |
| ----------------- | ------------------------------------------------ | ------------------------------------- |
| SSH               | Remote system-এ secure login ও command execution | `ssh user@IP`, `/etc/ssh/sshd_config` |
| NFS               | Network-এর মাধ্যমে file share করা                | `/etc/exports`, `mount`               |
| Apache            | Web content serve করা                            | `/etc/apache2/apache2.conf`           |
| Python Web Server | দ্রুত HTTP file sharing                          | `python3 -m http.server`              |
| VPN               | Encrypted tunnel দিয়ে internal network access   | `sudo openvpn --config internal.ovpn` |

Cybersecurity-তে মনে রাখবে: FTP-এর মতো unencrypted service credential প্রকাশ করতে পারে; NFS-এর ভুল permission privilege escalation-এর সুযোগ তৈরি করতে পারে; আর SSH, web server ও VPN-এর configuration নিরাপদ রাখা গুরুত্বপূর্ণ।
