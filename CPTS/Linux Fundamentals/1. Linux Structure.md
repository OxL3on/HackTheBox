# Linux Structure

## 1. Linux কী?

Linux হলো একটি Operating System (OS), যেমন Windows, macOS, iOS ও Android। OS কম্পিউটারের hardware resources পরিচালনা করে এবং software ও hardware-এর মধ্যে যোগাযোগ করায়।

Linux-এর বিভিন্ন version-কে Distribution (Distro) বলে। প্রতিটি distro আলাদা প্রয়োজন অনুযায়ী তৈরি।

## 2. History

- 1970: Ken Thompson ও Dennis Ritchie AT&T-তে Unix তৈরি করেন।
- 1977: Berkeley Software Distribution (BSD) প্রকাশিত হয়। AT&T-এর Unix code ব্যবহারের কারণে মামলা হওয়ায় BSD-এর development সীমিত হয়।
- 1983: Richard Stallman GNU Project শুরু করেন। লক্ষ্য ছিল free Unix-like OS তৈরি করা। এ কাজের অংশ হিসেবে GNU General Public License (GPL) তৈরি হয়।
- 1991: Finnish student Linus Torvalds Linux kernel তৈরি শুরু করেন।
- Linux kernel-এর source code C ভাষায় লেখা। বর্তমানে এতে 23 million-এর বেশি source code line রয়েছে (comments বাদে) এবং এটি GNU GPL v2-এর অধীনে licensed।
- Linux-এর 600-এর বেশি distribution রয়েছে। জনপ্রিয় distro: Ubuntu, Debian, Fedora, OpenSUSE, elementary, Manjaro, Gentoo Linux, RedHat ও Linux Mint।

Linux-এর বৈশিষ্ট্য:

- Free ও open-source; source code পরিবর্তন ও commercial/non-commercial কাজে বিতরণ করা যায়।
- তুলনামূলকভাবে secure, stable ও high-performance; malware-এর ঝুঁকি Windows-এর তুলনায় কম এবং নিয়মিত update হয়।
- Beginners-এর জন্য কঠিন হতে পারে এবং Windows-এর তুলনায় hardware driver কম।
- Server, mainframe, desktop, router, television, video game consoleসহ বিভিন্ন embedded system-এ চলে।
- Android Linux kernel-এর ওপর ভিত্তি করে তৈরি। তাই Linux সবচেয়ে বেশি installed operating system।

Linux OS-এর কাজ hardware ও software-এর যোগাযোগ পরিচালনা করা। Windows-এর মতো এরও বিভিন্ন version রয়েছে।

Pwnbox: HTB interactive instance-এ customized Parrot OS ব্যবহার করা হয়। এটি module-গুলোর প্রধান OS। Parrot OS হলো Debian-based Linux distribution, যা security, privacy ও development-এ গুরুত্ব দেয়।

Linux-কে একটি কোম্পানি ভাবলে, architecture হলো কর্মীদের সংগঠন ও যোগাযোগের কাঠামো; philosophy হলো তাদের কাজের মূলনীতি ও মূল্যবোধ।

## 3. Philosophy

Linux philosophy-এর মূল বিষয়: simplicity, modularity ও openness। ছোট, নির্দিষ্ট কাজের program তৈরি করে সেগুলো একসঙ্গে ব্যবহার করে জটিল কাজ করা যায়।

| Principle                                                     | সহজ ব্যাখ্যা                                                                                                                                           |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Everything is a file`                                        | Hardware device, process ও network connection-সহ system resource-গুলো file হিসেবে উপস্থাপিত হয়; একই standard tools ও commands দিয়ে read/write করা যায়। |
| `Small, single-purpose programs`                              | প্রতিটি tool নির্দিষ্ট কাজ করে; বিভিন্ন tool একসঙ্গে ব্যবহার করা যায়।                                                                                  |
| `Ability to chain programs together to perform complex tasks` | Tool একত্র করে data processing ও filtering-এর মতো জটিল কাজ করা যায়।                                                                                    |
| `Avoid captive user interfaces`                               | Linux মূলত shell/terminal দিয়ে কাজ করতে দেয়, ফলে OS-এর ওপর বেশি নিয়ন্ত্রণ থাকে।                                                                        |
| `Configuration data stored in a text file`                    | Configuration text file-এ রাখা হয়। উদাহরণ: `/etc/passwd` — system-এর registered user-দের তথ্য রাখে।                                                    |

## 4. Components

| Component         | কাজ                                                                                                                                      |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `Bootloader`      | OS চালু করার boot process পরিচালনা করে। Parrot Linux-এ GRUB Bootloader ব্যবহৃত হয়।                                                       |
| `OS Kernel`       | OS-এর মূল অংশ; hardware level-এ system-এর I/O device-এর resources পরিচালনা করে।                                                          |
| `Daemons`         | Background service। Scheduling, printing ও multimedia-এর মতো কাজ চালু রাখে। Boot বা login-এর পর load হয়।                                 |
| `OS Shell`        | OS ও user-এর মধ্যে interface; command interpreter হিসেবেও পরিচিত। প্রচলিত shell: Bash, Tcsh/Csh, Ksh, Zsh ও Fish।                        |
| `Graphics server` | `X` বা `X-server` graphical program স্থানীয়ভাবে বা দূর থেকে চালাতে দেয়।                                                                  |
| `Window Manager`  | GUI-সংক্রান্ত অংশ। উদাহরণ: GNOME, KDE, MATE, Unity ও Cinnamon। Desktop environment-এ file browser ও web browser-এর মতো application থাকে। |
| `Utilities`       | User বা অন্য program-এর নির্দিষ্ট কাজ সম্পন্ন করে এমন application/program।                                                               |

## 5. Linux Architecture

Linux architecture চারটি layer-এ ভাগ করা যায়।

| Layer            | কাজ                                                                                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Hardware`       | RAM, hard drive, CPU ও অন্যান্য peripheral device।                                                                                                                                    |
| `Kernel`         | CPU, allocated memory ও accessed data-এর মতো hardware resource নিয়ন্ত্রণ ও virtualize করে। প্রতিটি process-কে আলাদা virtual resource দেয় এবং process-গুলোর conflict প্রতিরোধ বা কমায়। |
| `Shell`          | Command-line interface (CLI), যেখানে user command দিয়ে kernel-এর function চালায়।                                                                                                      |
| `System Utility` | User-কে OS-এর সব functionality ব্যবহারের সুযোগ দেয়।                                                                                                                                   |

| Path     | কাজ                                                                                                                                                                    |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`      | Root filesystem। অন্য filesystem mount হওয়ার আগে OS boot করার প্রয়োজনীয় file থাকে। Boot-এর পরে অন্য filesystem-গুলো এর subdirectory-র standard mount point-এ যুক্ত হয়। |
| `/bin`   | Essential command binary।                                                                                                                                              |
| `/boot`  | Static bootloader, kernel executable ও Linux boot করার প্রয়োজনীয় file।                                                                                                 |
| `/dev`   | Hardware device access করার device file।                                                                                                                               |
| `/etc`   | Local system configuration file; installed application-এর configuration-ও এখানে থাকতে পারে।                                                                            |
| `/home`  | প্রতিটি user-এর নিজস্ব storage subdirectory।                                                                                                                           |
| `/lib`   | System boot-এর জন্য প্রয়োজনীয় shared library।                                                                                                                          |
| `/media` | USB drive-এর মতো removable media mount হয়।                                                                                                                             |
| `/mnt`   | Regular filesystem-এর temporary mount point।                                                                                                                           |
| `/opt`   | Third-party tool-এর মতো optional file রাখা যায়।                                                                                                                        |
| `/root`  | Root user-এর home directory।                                                                                                                                           |
| `/sbin`  | System administration-এর executable বা binary system file।                                                                                                             |
| `/tmp`   | Temporary file রাখার directory। সাধারণত system boot-এর সময় পরিষ্কার হয় এবং অন্য সময়ও warning ছাড়াই মুছে যেতে পারে।                                                     |
| `/usr`   | Executable, library, man file ইত্যাদি থাকে।                                                                                                                            |
| `/var`   | পরিবর্তনশীল data, যেমন log file, email inbox, web application-related file ও cron file থাকে।                                                                           |
