# Task Scheduling


## 1. Task Scheduling কী?

Task Scheduling হলো নির্দিষ্ট সময়ে বা নিয়মিত বিরতিতে স্বয়ংক্রিয়ভাবে task চালানোর ব্যবস্থা। এতে বারবার হাতে command চালাতে হয় না।

Linux-এর Ubuntu, Red Hat Linux ও Solaris-এর মতো system-এ এটি ব্যবহার করা হয়।

ব্যবহার:

- Software automatic update করা
- Script চালানো
- Database maintenance করা
- Backup নেওয়া
- নির্দিষ্ট event ঘটলে notification পাঠানো

উদাহরণ: প্রতিদিন সকালে নির্দিষ্ট সময়ে coffee maker নিজে থেকে coffee তৈরি করে। একইভাবে task scheduler নির্ধারিত সময়ে task চালায়।

### Cybersecurity-তে কেন গুরুত্বপূর্ণ?

Task scheduling একটি legitimate administrative tool, আবার malicious activity-র মাধ্যমও হতে পারে।

- Unauthorized cron job খুঁজে বের করা
- নির্দিষ্ট সময়ে harmful script চালানো শনাক্ত করা
- Scheduled task-এর মাধ্যমে persistent backdoor খুঁজে বের করা
- System audit করা
- Penetration testing-এ attack scenario simulate করা

## 2. Systemd

`systemd` দিয়ে নির্দিষ্ট সময়ে, নির্দিষ্ট interval-এ অথবা নির্দিষ্ট event/trigger অনুযায়ী process ও script চালানো যায়।

এটি ব্যবহার করতে তিনটি ধাপ:

1. Timer তৈরি: কখন `mytimer.service` চালু হবে তা নির্ধারণ করে।
2. Service তৈরি: কোন command বা script চলবে তা নির্ধারণ করে।
3. Timer Activate: Timer চালু ও enable করা।

### Step 1: Timer তৈরি

প্রথমে timer-এর জন্য directory তৈরি ও timer file edit করতে হবে।

```
sudo mkdir /etc/systemd/system/mytimer.timer.d
sudo vim /etc/systemd/system/mytimer.timer
```

`mytimer.timer` file:

```
[Unit]
Description=My Timer

[Timer]
OnBootSec=3min
OnUnitActiveSec=1hour

[Install]
WantedBy=timers.target
```

গুরুত্বপূর্ণ options:

| Option                   | কাজ                                                                        |
| ------------------------ | -------------------------------------------------------------------------- |
| `[Unit]`                 | Timer-এর description নির্ধারণ করে।                                         |
| `[Timer]`                | কখন timer চালু হবে এবং কখন task activate হবে তা নির্ধারণ করে।              |
| `OnBootSec=3min`         | System boot হওয়ার ৩ মিনিট পর timer-এর task চালানোর সময় নির্ধারণ করে।     |
| `OnUnitActiveSec=1hour`  | Unit সর্বশেষ সক্রিয় হওয়ার ১ ঘণ্টা পর আবার চালানোর interval নির্ধারণ করে। |
| `[Install]`              | Timer enable করার configuration নির্ধারণ করে।                              |
| `WantedBy=timers.target` | Timer-কে `timers.target`-এর সঙ্গে যুক্ত করে।                               |

যদি boot-এর পর একবার চালাতে চাও, `OnBootSec` ব্যবহার করা যায়। নিয়মিত interval-এ চালাতে `OnUnitActiveSec` ব্যবহার করা যায়।

### Step 2: Service তৈরি

```
sudo vim /etc/systemd/system/mytimer.service
```

Service file:

```
[Unit]
Description=My Service

[Service]
ExecStart=/full/path/to/my/script.sh

[Install]
WantedBy=multi-user.target
```

ব্যাখ্যা:

- `[Unit]` — Service-এর description।
- `ExecStart` — যে script চালাতে হবে তার সম্পূর্ণ path।
- `WantedBy=multi-user.target` — Normal multi-user mode-এ system startup-এর সময় কোন services চালু হবে তা নির্ধারণের সঙ্গে যুক্ত।

এখানে `/full/path/to/my/script.sh`-এর জায়গায় নিজের script-এর সম্পূর্ণ path দিতে হবে।

### Step 3: systemd Reload করা

নতুন configuration পড়ানোর জন্য:

```
sudo systemctl daemon-reload
```

### Step 4: Timer Start ও Enable করা

```
sudo systemctl start mytimer.timer
sudo systemctl enable mytimer.timer
```

- `start` — Timer এখন চালু করে।
- `enable` — ভবিষ্যতে system boot হলে স্বয়ংক্রিয়ভাবে চালু হওয়ার ব্যবস্থা করে।

এভাবে `mytimer.timer`-এ নির্ধারিত সময় বা interval অনুযায়ী `mytimer.service` চালানো হবে।

## 3. Cron

`cron` হলো Linux-এর আরেকটি task scheduling tool। এটি নির্দিষ্ট সময়ে বা নির্দিষ্ট interval-এ command ও script চালায়।

Systemd-এর মতোই Cron দিয়ে software update, script execution, database cleanup ও backup automate করা যায়।

Cron ব্যবহার করতে:

1. Task-গুলো `crontab` file-এ লিখতে হয়।
2. Cron daemon-কে জানাতে হয় কখন task চালাতে হবে।
3. নির্ধারিত সময় অনুযায়ী task স্বয়ংক্রিয়ভাবে চলে।

### Cron-এর Time Format

একটি cron entry-তে পাঁচটি time field থাকে।

| Field        | Range  | কাজ                    |
| ------------ | ------ | ---------------------- |
| Minutes      | `0–59` | কোন মিনিটে চলবে        |
| Hours        | `0–23` | কোন ঘণ্টায় চলবে       |
| Day of month | `1–31` | মাসের কোন দিনে চলবে    |
| Month        | `1–12` | বছরের কোন মাসে চলবে    |
| Day of week  | `0–7`  | সপ্তাহের কোন দিনে চলবে |

সাধারণ format:

```
minute hour day-of-month month day-of-week command
```

### Crontab Examples

```
# System Update
0 */6 * * * /path/to/update_software.sh

# Execute Scripts
0 0 1 * * /path/to/scripts/run_scripts.sh

# Cleanup DB
0 0 * * 0 /path/to/scripts/clean_database.sh

# Backups
0 0 * * 7 /path/to/scripts/backup.sh
```

### Example-গুলোর ব্যাখ্যা

1\. System Update

```
0 */6 * * * /path/to/update_software.sh
```

- প্রতি ৬ ঘণ্টা পরপর চলে।
- মিনিট `0`-তে চালু হয়।
- Script: `/path/to/update_software.sh`

2\. Execute Scripts

```
0 0 1 * * /path/to/scripts/run_scripts.sh
```

- প্রতি মাসের প্রথম দিনে রাত ১২টায় চলে।
- Script: `/path/to/scripts/run_scripts.sh`

3\. Cleanup DB

```
0 0 * * 0 /path/to/scripts/clean_database.sh
```

- প্রতি রবিবার রাত ১২টায় চলে।
- Script: `/path/to/scripts/clean_database.sh`

4\. Backups

```
0 0 * * 7 /path/to/scripts/backup.sh
```

- প্রতি রবিবার রাত ১২টায় চলে।
- Script: `/path/to/scripts/backup.sh`

Source-এর উদাহরণ অনুযায়ী, সপ্তাহের দিনের জন্য `0` ও `7`—দুটিই Sunday বোঝাতে ব্যবহার করা হয়েছে।

Cron task সফল বা ব্যর্থ হলে notification পাঠানোর ব্যবস্থা করা যায়। Task কখন execute হচ্ছে তা পর্যবেক্ষণের জন্য logs-ও তৈরি করা যায়।

## 4. Systemd vs. Cron

| বিষয়         | Systemd                                                       | Cron                                                 |
| ------------- | ------------------------------------------------------------- | ---------------------------------------------------- |
| Configuration | Timer ও service file তৈরি করতে হয়।                           | `crontab` file-এ task লিখতে হয়।                     |
| কাজ           | Timer কখন চলবে এবং service কোন script চালাবে তা নির্ধারণ করে। | Cron daemon নির্ধারিত সময়ে command/script চালায়।   |
| Schedule      | নির্দিষ্ট সময়, interval ও event/trigger ব্যবহার করা যায়।    | নির্দিষ্ট সময় ও interval অনুযায়ী task চালানো যায়। |

## Quick Revision

- Task Scheduling: নির্দিষ্ট সময়ে বা interval-এ স্বয়ংক্রিয়ভাবে task চালানো।
- Systemd Timer: কখন task চালাতে হবে তা নির্ধারণ করে।
- Systemd Service: কোন command বা script চালাতে হবে তা নির্ধারণ করে।
- `systemctl daemon-reload`: নতুন systemd configuration পড়ে।
- `systemctl start`: Service বা timer চালু করে।
- `systemctl enable`: Boot-এর সময় স্বয়ংক্রিয়ভাবে চালু হওয়ার ব্যবস্থা করে।
- Cron: `crontab`-এর পাঁচটি time field ব্যবহার করে task schedule করে।
- Cybersecurity relevance: Unauthorized scheduled task বা persistence-এর জন্য ব্যবহৃত malicious script শনাক্ত করতে সাহায্য করে।
