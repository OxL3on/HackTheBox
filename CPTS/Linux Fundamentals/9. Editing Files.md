# Editing Files


## 1. Nano Editor

Linux-এ file edit করার জন্য `Vi`, `Vim` ও `Nano`-এর মতো text editor রয়েছে। `Nano` তুলনামূলকভাবে সহজ, তাই এটি দিয়ে শুরু করা যায়।

নতুন file তৈরি ও edit করতে:

```
00Luffy00@htb[/htb]$ nano notes.txt
```

এতে `notes.txt` file খুলবে; file না থাকলে নতুন file তৈরি হবে।

Nano editor-এর interface:

```
GNU nano 2.9.3                                    notes.txt

Here we can type everything we want and make our notes.

^G Get Help    ^O Write Out   ^W Where Is    ^K Cut Text    ^J Justify     ^C Cur Pos     M-U Undo
^X Exit        ^R Read File   ^\ Replace     ^U Uncut Text  ^T To Spell    ^_ Go To Line  M-E Redo
```

`^` চিহ্নটি `CTRL` key বোঝায়।

| Shortcut   | কাজ                     |
| ---------- | ----------------------- |
| `CTRL + W` | Text search             |
| `CTRL + O` | File save               |
| `CTRL + X` | Editor থেকে বের হওয়া    |
| `CTRL + G` | Help                    |
| `CTRL + K` | Text cut                |
| `CTRL + U` | Cut করা text ফিরিয়ে আনা |
| `CTRL + \` | Replace                 |

### Text Search

`CTRL + W` চাপলে নিচে `Search:` আসবে। সেখানে খোঁজার শব্দ লিখে `ENTER` চাপলে cursor প্রথম matching word-এ যাবে।

উদাহরণ:

```
GNU nano 2.9.3                                    notes.txt

Here ▓we can type everything we want and make our notes.

Search:   notes
^G Get Help    M-C Case Sens  M-B Backwards  M-J FullJstify ^W Beg of Par  ^Y First Line  ^P PrevHstory
^C Cancel      M-R Regexp     ^R Replace     ^T Go To Line  ^O End of Par  ^V Last Line   ^N NextHstory
```

পরবর্তী match-এ যেতে আবার `CTRL + W`, তারপর `ENTER` চাপো।

```
GNU nano 2.9.3                                    notes.txt

Here we can type everything ▓we want and make our notes.

Search [we]:
^G Get Help    M-C Case Sens  M-B Backwards  M-J FullJstify ^W Beg of Par  ^Y First Line  ^P PrevHstory
^C Cancel      M-R Regexp     ^R Replace     ^T Go To Line  ^O End of Par  ^V Last Line   ^N NextHstory
```

### Save ও Exit

`CTRL + O` চাপো, file name নিশ্চিত করতে `ENTER` চাপো।

```
GNU nano 2.9.3                                    notes.txt

Here we can type everything we want and make our notes.

File Name to Write: notes.txt
```

Save করার পর `CTRL + X` দিয়ে বের হও।

File-এর content দেখতে:

```
00Luffy00@htb[/htb]$ cat notes.txt

Here we can type everything we want and make our notes.
```

## 2. `/etc/passwd` ও `/etc/shadow`

`/etc/passwd` file-এ system-এর user-দের গুরুত্বপূর্ণ তথ্য থাকে:

- Username
- User ID (`UID`)
- Group ID (`GID`)
- Home directory

আগে `/etc/passwd`-এ password hash-ও থাকত। বর্তমানে সাধারণত password hash `/etc/shadow`-এ রাখা হয়, যেখানে permissions আরও কঠোর।

Permissions ভুলভাবে সেট করা থাকলে sensitive information প্রকাশ পেতে পারে বা privilege escalation-এর সুযোগ তৈরি হতে পারে। তাই penetration tester-দের দুর্বল permission ও misconfigured file access খুঁজে দেখা জরুরি।

## 3. Vim Editor

`Vim` হলো open-source ASCII text editor এবং পুরোনো `Vi`-এর উন্নত সংস্করণ।

এটি মূলত text editing-এর জন্য তৈরি। `grep`, `awk`, `sed`-এর মতো external program-এর সঙ্গে কাজ করতে পারে। এতে Vim ছোট, দ্রুত, শক্তিশালী, flexible ও কম error-prone থাকে।

এটি Unix principle অনুসরণ করে: ছোট, নির্দিষ্ট কাজে তৈরি ও পরীক্ষিত program একত্রে ব্যবহার করে শক্তিশালী system তৈরি করা।

Vim চালু করতে:

```
00Luffy00@htb[/htb]$ vim
```

Source-এর Vim screen-এ version `8.0.1453` দেখানো হয়েছে। Vim help পেতে `:help` বা `F1`, version information পেতে `:help version8`, এবং বের হতে `:q` ব্যবহার করা যায়।

## 4. Vim-এর ছয়টি Mode

Vim একটি modal editor। অর্থাৎ, text লেখা ও command চালানোর জন্য আলাদা mode রয়েছে।

| Mode      | কাজ                                                                                                                                                                           |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Normal`  | Input-কে editor command হিসেবে নেয়; সাধারণত Vim চালু হলে এই mode-এ থাকে।                                                                                                      |
| `Insert`  | Enter করা character-গুলো text buffer-এ যোগ হয়, কিছু exception ছাড়া।                                                                                                           |
| `Visual`  | Text-এর অংশ select/highlight করে delete, copy বা replace করা যায়।                                                                                                             |
| `Command` | Editor-এর নিচে single-line command লেখা যায়; যেমন text sort, replace বা delete।                                                                                               |
| `Replace` | নতুন text বিদ্যমান character-কে overwrite করে; পুরোনো character শেষ হলে text যোগ হয়।                                                                                          |
| `Ex`      | [Ex editor](https://man7.org/linux/man-pages/man1/ex.1p.html?utm_source=chatgpt.com)-এর আচরণ অনুকরণ করে; Normal mode-এ ফিরে না গিয়েই একাধিক command ধারাবাহিকভাবে চালানো যায়। |

Vim-এ `:` লিখে Command mode-এ গিয়ে `q` লিখলে editor বন্ধ করা যায়।

```
:q
```

## 5. Vim Tutor

Vim প্রথমে কঠিন মনে হতে পারে, কিন্তু অভ্যাস হলে এটি দিয়ে দ্রুত ও কার্যকরভাবে text edit করা যায়।

Tutor চালানোর দুটি উপায়:

Vim-এর ভেতরে:

```
:Tutor
```

Shell থেকে:

```
00Luffy00@htb[/htb]$ vimtutor
```

Tutor-এর welcome screen:

```
===============================================================================
=    W e l c o m e   t o   t h e   V I M   T u t o r    -    Version 1.7      =
===============================================================================

     Vim is a very powerful editor that has many commands, too many to
     explain in a tutor such as this.  This tutor is designed to describe
     enough of the commands that you will be able to easily use Vim as
     an all-purpose editor.

     The approximate time required to complete the tutor is 25-30 minutes,
     depending upon how much time is spent with experimentation.

     ATTENTION:
     The commands in the lessons will modify the text.  Make a copy of this
     file to practice on (if you started "vimtutor" this is already a copy).

     It is important to remember that this tutor is set up to teach by
     use.  That means that you need to execute the commands to learn them
     properly.  If you only read the text, you will forget the commands!

     Now, make sure that your Caps-Lock key is NOT depressed and press
     the   j   key enough times to move the cursor so that lesson 1.1
     completely fills the screen.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
```

Tutor শেষ করতে আনুমানিক 25–30 মিনিট লাগতে পারে। এটি হাতে-কলমে command চালিয়ে শেখার জন্য তৈরি। শুধু পড়ার পরিবর্তে command-গুলো নিজে ব্যবহার করে শেখা গুরুত্বপূর্ণ।

Optional Exercise: `vimtutor` চালিয়ে editor-এর feature-গুলো ব্যবহার করে দেখো এবং practice করো।
