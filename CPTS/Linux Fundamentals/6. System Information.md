# System Information


## 1. Linux System Information Commands

Linux system-এর hardware, process, network, user ও directory সম্পর্কে তথ্য জানতে নিচের command-গুলো ব্যবহার করা হয়। এগুলো system administration এবং security assessment-এও কাজে লাগে।

| Command    | কাজ                                                                 |
| ---------- | ------------------------------------------------------------------- |
| `whoami`   | বর্তমান username দেখায়।                                             |
| `id`       | User ID, Group ID ও group membership দেখায়।                         |
| `hostname` | Hostname দেখায় বা সেট করে।                                          |
| `uname`    | Operating system ও hardware সম্পর্কে basic information দেখায়।       |
| `pwd`      | Current working directory দেখায়।                                    |
| `ifconfig` | Network interface-এর address ও configuration দেখায় বা পরিবর্তন করে। |
| `ip`       | Routing, network device, interface ও tunnel দেখায় বা পরিবর্তন করে।  |
| `netstat`  | Network status দেখায়।                                               |
| `ss`       | Socket পরীক্ষা করে।                                                 |
| `ps`       | Process status দেখায়।                                               |
| `who`      | কারা login করা আছে দেখায়।                                           |
| `env`      | Environment variable দেখায়, অথবা সেট করে command চালায়।             |
| `lsblk`    | Block device-এর তালিকা দেখায়।                                       |
| `lsusb`    | USB device-এর তালিকা দেখায়।                                         |
| `lsof`     | খোলা file-এর তালিকা দেখায়।                                          |
| `lspci`    | PCI device-এর তালিকা দেখায়।                                         |

Command-এর সাহায্য পেতে `-h`, `--help` বা `man` ব্যবহার করা যায়।

## 2. SSH দিয়ে Login

SSH (Secure Shell) হলো protocol, যার মাধ্যমে remote computer-এ connect করে command চালানো যায়।

- Linux server-এ remote administration ও maintenance-এর জন্য বহুল ব্যবহৃত।
- GUI প্রয়োজন হয় না।
- কম resource ব্যবহার করে দক্ষতার সঙ্গে কাজ করে।
- HTB lab-এ নিরাপদ পরিবেশে command practice করার জন্য SSH ব্যবহার করা হয়।

Connection command:

```
ssh htb-student@[IP address]
```

## 3. Hostname

`hostname` command দিয়ে যে computer-এ login করা আছে তার নাম দেখা যায়।

```
00Luffy00@htb[/htb]$ hostname

nixfund
```

## 4. Whoami

`whoami` বর্তমান user-এর username দেখায়।

Security assessment-এ reverse shell পাওয়ার পর প্রথমে কোন user হিসেবে command চলছে তা জানা গুরুত্বপূর্ণ। এরপর তার privilege ও access পরীক্ষা করা যায়।

```
cry0l1t3@htb[/htb]$ whoami

cry0l1t3
```

## 5. Id

`id` command, `whoami`-এর চেয়ে বেশি তথ্য দেয়। এটি user-এর UID, GID এবং group membership দেখায়।

```
cry0l1t3@htb[/htb]$ id

uid=1000(cry0l1t3) gid=1000(cry0l1t3) groups=1000(cry0l1t3),1337(hackthebox),4(adm),24(cdrom),27(sudo),30(dip),46(plugdev),116(lpadmin),126(sambashare)
```

গুরুত্বপূর্ণ group:

- `hackthebox` — non-standard group।
- `adm` — `/var/log`-এর log file পড়ার access থাকতে পারে; এতে sensitive information পাওয়া সম্ভব।
- `sudo` — user কিছু বা সব command `root` হিসেবে চালাতে পারে, যা privilege escalation-এর জন্য গুরুত্বপূর্ণ হতে পারে। Administrator-দেরও অপ্রয়োজনীয় permission ও group membership audit করা উচিত।

## 6. Uname

`uname` operating system ও hardware সম্পর্কে তথ্য দেয়। এর বিস্তারিত option দেখতে:

```
man uname
```

গুরুত্বপূর্ণ option:

| Option                      | কাজ                                           |
| --------------------------- | --------------------------------------------- |
| `-a`, `--all`               | সব তথ্য দেখায়; অজানা হলে `-p` ও `-i` বাদ দেয়। |
| `-s`, `--kernel-name`       | Kernel-এর নাম দেখায়।                          |
| `-n`, `--nodename`          | Network node hostname দেখায়।                  |
| `-r`, `--kernel-release`    | Kernel release দেখায়।                         |
| `-v`, `--kernel-version`    | Kernel version দেখায়।                         |
| `-m`, `--machine`           | Machine hardware name দেখায়।                  |
| `-p`, `--processor`         | Processor type দেখায় (non-portable)।          |
| `-i`, `--hardware-platform` | Hardware platform দেখায় (non-portable)।       |
| `-o`, `--operating-system`  | Operating system দেখায়।                       |

### `uname -a`

```
cry0l1t3@htb[/htb]$ uname -a

Linux box 4.15.0-99-generic #100-Ubuntu SMP Wed Apr 22 20:32:56 UTC 2020 x86_64 x86_64 x86_64 GNU/Linux
```

এখানে:

- Kernel name: `Linux`
- Hostname: `box`
- Kernel release: `4.15.0-99-generic`
- Kernel version: `#100-Ubuntu SMP Wed Apr 22 20:32:56 UTC 2020`
- এরপর machine hardware ও operating system-এর তথ্য রয়েছে।

প্রয়োজনীয় তথ্য আলাদাভাবে পেতে সংশ্লিষ্ট option ব্যবহার করা যায়।

### `uname -r` — Kernel Release

```
cry0l1t3@htb[/htb]$ uname -r

4.15.0-99-generic
```

Kernel release দিয়ে সম্ভাব্য kernel exploit খোঁজা যায়। উদাহরণস্বরূপ:

[Exploit-DB: 4.15.0-99-generic exploit](https://www.exploit-db.com/exploits/47163?utm_source=chatgpt.com)

Command-গুলোর manual পড়লে system information, vulnerability ও misconfiguration শনাক্ত করতে সুবিধা হয়। এগুলো পরবর্তী সময়ে Linux privilege escalation বুঝতেও কাজে লাগবে।
