# Working with Files and Directories


## 1. Linux-এ File Management

Windows-এ সাধারণত Explorer-এর মতো GUI দিয়ে file খোঁজা, খোলা ও edit করা হয়। Linux-এ terminal command দিয়েও সরাসরি file manage করা যায়।

Command line-এর সুবিধা:

- অল্প command দিয়ে দ্রুত file access ও edit করা যায়।
- `vim` বা `nano` ছাড়াও file edit করা সম্ভব।
- Regular Expression (`regex`) দিয়ে নির্দিষ্ট অংশ পরিবর্তন করা যায়।
- একসঙ্গে একাধিক command চালানো যায়।
- Output file-এ redirect এবং batch editing automate করা যায়।

## 2. Create, Move ও Copy

Target machine-এ কাজ করার আগে নির্দেশনা অনুযায়ী SSH দিয়ে connect করতে হবে।

### `touch` — Empty File তৈরি

Syntax:

```
touch <name>
```

Example:

```
00Luffy00@htb[/htb]$ touch info.txt
```

এতে `info.txt` নামে empty file তৈরি হবে।

### `mkdir` — Directory তৈরি

Syntax:

```
mkdir <name>
```

Example:

```
00Luffy00@htb[/htb]$ mkdir Storage
```

### `mkdir -p` — Nested Directory তৈরি

একাধিক parent directory একসঙ্গে তৈরি করতে `-p` ব্যবহার করা হয়।

```
00Luffy00@htb[/htb]$ mkdir -p Storage/local/user/documents
```

`tree` দিয়ে directory structure দেখা যায়:

```
00Luffy00@htb[/htb]$ tree .

.
├── info.txt
└── Storage
    └── local
        └── user
            └── documents

4 directories, 1 file
```

### নির্দিষ্ট Directory-তে File তৈরি

বর্তমান directory বোঝাতে `.` ব্যবহার করা যায়।

```
00Luffy00@htb[/htb]$ touch ./Storage/local/user/userinfo.txt
```

Structure:

```
00Luffy00@htb[/htb]$ tree .

.
├── info.txt
└── Storage
    └── local
        └── user
            ├── documents
            └── userinfo.txt

4 directories, 2 files
```

## 3. `mv` — Rename ও Move

`mv` দিয়ে file বা directory rename এবং move করা যায়।

Syntax:

```
mv <file/directory> <renamed file/directory>
```

### File Rename

`info.txt`-কে `information.txt` নামে rename করা:

```
00Luffy00@htb[/htb]$ mv info.txt information.txt
```

### একাধিক File Directory-তে Move

প্রথমে `readme.txt` তৈরি করি:

```
00Luffy00@htb[/htb]$ touch readme.txt
```

এরপর দুটি file `Storage/`-এ move করি:

```
00Luffy00@htb[/htb]$ mv information.txt readme.txt Storage/
```

Structure:

```
00Luffy00@htb[/htb]$ tree .

.
└── Storage
    ├── information.txt
    ├── local
    │   └── user
    │       ├── documents
    │       └── userinfo.txt
    └── readme.txt

4 directories, 3 files
```

## 4. `cp` — File Copy

`cp` দিয়ে file copy করা যায়।

```
00Luffy00@htb[/htb]$ cp Storage/readme.txt Storage/local/
```

এতে `readme.txt`-এর একটি copy `Storage/local/`-এ তৈরি হবে।

Structure যাচাই:

```
00Luffy00@htb[/htb]$ tree .

.
└── Storage
    ├── information.txt
    ├── local
    │   ├── readme.txt
    │   └── user
    │       ├── documents
    │       └── userinfo.txt
    └── readme.txt

4 directories, 4 files
```

## 5. File Editing ও Redirection

Linux-এ file management-এর আরও উপায় রয়েছে:

- Redirection: Command-এর input/output অন্য command বা file-এ পাঠানো যায়। এতে file তৈরি ও পরিবর্তন দ্রুত হয়।
- Text editor: `vim` ও `nano` দিয়ে interactive editing করা যায়।
