# Regular Expressions


## 1. Regular Expressions কী?

Regular Expression (RegEx) হলো text-এর মধ্যে নির্দিষ্ট pattern খোঁজার পদ্ধতি। এর সাহায্যে text search, replace এবং manipulate করা যায়।

RegEx ব্যবহার হয়:

- Text বা file থেকে নির্দিষ্ট data খুঁজতে।
- Input validate করতে।
- Text-এর pattern অনুযায়ী data filter করতে।
- `grep`, `sed` এবং বিভিন্ন programming language-এ।

RegEx-এ কিছু special symbol থাকে, যাদের metacharacters বলে। এগুলো দিয়ে search pattern নির্ধারণ করা হয়—যেমন কোন character, digit বা text pattern খুঁজতে হবে।

## 2. Grouping Operators

RegEx-এ তিন ধরনের bracket-সহ কয়েকটি গুরুত্বপূর্ণ operator আছে।

| Operator | কাজ                                                                                                                                    |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `(a)`    | Round bracket দিয়ে pattern-এর অংশ group করা হয়।                                                                                        |
| `[a-z]`  | Square bracket দিয়ে character class নির্ধারণ করা হয়। এখানে `a` থেকে `z` পর্যন্ত character বোঝায়।                                       |
| `{1,10}` | Curly bracket দিয়ে quantifier নির্ধারণ করা হয়—আগের pattern ১ থেকে ১০ বার match করবে।                                                   |
| `\\|`    | OR operator—দেওয়া expression-গুলোর যেকোনো একটি match করলে result দেখায়।                                                                |
| `.*`     | `.` যেকোনো character এবং `*` শূন্য বা তার বেশি repetition বোঝায়। একসঙ্গে ব্যবহার করে দুই pattern-এর মাঝখানে যেকোনো content থাকতে পারে। |

মনে রাখবে: এখানে `.*`-কে AND-এর মতো ব্যবহার করা হয়েছে। এটি নিজে AND operator নয়; বরং দুইটি pattern-কে নির্দিষ্ট order-এ match করতে সাহায্য করে।

## 3. OR Operator

একটি line-এ `my` অথবা `false` থাকলে সেটি খুঁজতে:

```
grep -E "(my|false)" /etc/passwd
```

Output:

```
lxd:x:105:65534::/var/lib/lxd/:/bin/false
pollinate:x:109:1::/var/cache/pollinate:/bin/false
mysql:x:116:120:MySQL Server,,:/nonexistent:/bin/false
```

ব্যাখ্যা:

- `grep`: Pattern search করে।
- `-E`: Extended Regular Expressions ব্যবহার করে।
- `(my|false)`: `my` অথবা `false` match করে।
- `/etc/passwd`: যে file-এ search করবে।

এখানে তিনটি line-ই result-এ এসেছে, কারণ প্রতিটিতে `false` আছে।

## 4. AND-এর মতো Pattern Matching

একই line-এ `my` এবং তার পরে `false` খুঁজতে:

```
grep -E "(my.*false)" /etc/passwd
```

Output:

```
mysql:x:116:120:MySQL Server,,:/nonexistent:/bin/false
```

ব্যাখ্যা:

- `my`: প্রথম pattern।
- `.*`: মাঝখানে শূন্য বা তার বেশি character থাকতে পারে।
- `false`: পরের pattern।

অর্থাৎ, একই line-এ `my`-এর পরে `false` থাকতে হবে।

একই কাজ দুইবার `grep` ব্যবহার করেও করা যায়:

```
grep -E "my" /etc/passwd | grep -E "false"
```

এখানে:

1. প্রথম `grep` দিয়ে `my` থাকা line বের হয়।
2. `|` দিয়ে result দ্বিতীয় `grep`-এ যায়।
3. দ্বিতীয় `grep` শুধু `false` থাকা line রাখে।

### Practice করার জন্য প্রয়োজনীয় ধারণা

- `^` — line-এর শুরু।
- `$` — line-এর শেষ।
- `[^...]` — bracket-এর ভেতরের character-গুলো ছাড়া অন্য character।
- `grep -v` — pattern match করা line বাদ দেয়।
- `grep -E` — extended regex ব্যবহার করে।
