# Getting Help


## 1. Linux-এ Help নেওয়া কেন জরুরি?

Linux-এ অনেক command ও tool আছে, যেগুলোর সব option মুখস্থ রাখা সম্ভব নয়। নতুন tool ব্যবহার করার আগে তার কাজ ও option সম্পর্কে জানা জরুরি।

Help নেওয়ার প্রধান উপায়:

- `man` — বিস্তারিত manual।
- `--help` বা `-h` — command-এর option ও ব্যবহার দ্রুত দেখা।
- `apropos` — keyword দিয়ে সম্পর্কিত manual খোঁজা।
- [ExplainShell](https://explainshell.com/?utm_source=chatgpt.com) — বড় command-এর প্রতিটি অংশ বুঝতে সাহায্য করে।

## 2. `ls` Command

`ls` বর্তমান বা নির্দিষ্ট directory-র file ও directory-এর তালিকা দেখায়।

```
00Luffy00@htb[/htb]$ ls

cacert.der  Documents  Music     Public     Videos
Desktop     Downloads  Pictures  Templates
```

## 3. `man` — Manual Page

Command-এর বিস্তারিত documentation দেখতে `man` ব্যবহার হয়।

Syntax:

```
man <tool>
```

Example:

```
man ls
```

Output-এর গুরুত্বপূর্ণ অংশ:

```
LS(1)                            User Commands                           LS(1)

NAME
       ls - list directory contents

SYNOPSIS
       ls [OPTION]... [FILE]...

DESCRIPTION
       List  information  about  the FILEs (the current directory by default).
       Sort entries alphabetically if none of -cftuvSUX nor --sort  is speci‐
       fied.

       Mandatory  arguments  to  long  options are mandatory for short options
       too.

       -a, --all
              do not ignore entries starting with .

       -A, --almost-all
              do not list implied . and ..

       --author
```

Manual page থেকে command-এর কাজ ও option-এর বিস্তারিত জানা যায়। `q` চাপলে manual থেকে বের হওয়া যায়; `h` চাপলে help দেখা যায়।

## 4. `--help` — দ্রুত Option দেখা

পুরো manual না পড়ে দ্রুত option দেখতে:

Syntax:

```
<tool> --help
```

Example:

```
ls --help
```

Output:

```
Usage: ls [OPTION]... [FILE]...
List information about the FILEs (the current directory by default).
Sort entries alphabetically if none of -cftuvSUX nor --sort is specified.

Mandatory arguments to long options are mandatory for short options too.
  -a, --all                  do not ignore entries starting with .
  -A, --almost-all           do not list implied . and ..
      --author               with -l, print the author of each file
  -b, --escape               print C-style escapes for nongraphic characters
      --block-size=SIZE      with -l, scale sizes by SIZE when printing them;
                             e.g., '--block-size=M'; see SIZE format below

  -B, --ignore-backups       do not list implied entries ending with ~
  -c                         with -lt: sort by, and show, ctime (time of last
                             modification of file status information);
                             with -l: show ctime and sort by name;
                             otherwise: sort by ctime, newest first

  -C                         list entries by columns
<SNIP>
```

## 5. `-h` — Short Help

কিছু command, যেমন `curl`, help দেখাতে `--help`-এর বদলে `-h` ব্যবহার করতে পারে।

Syntax:

```
<tool> -h
```

Example:

```
curl -h
```

Output:

```
Usage: curl [options...] <url>
     --abstract-unix-socket <path> Connect via abstract Unix domain socket
     --anyauth       Pick any authentication method
 -a, --append        Append to target file when uploading
     --basic         Use HTTP Basic Authentication
     --cacert <file> CA certificate to verify peer against
     --capath <dir>  CA directory containing CA certificates
 -E, --cert <certificate[:password]> Client certificate file and password
<SNIP>
```

এই উদাহরণে `--help` ও `-h`-এর output-এ পার্থক্য নেই।

## 6. `apropos` — Keyword দিয়ে Help খোঁজা

প্রতিটি manual page-এ command-এর সংক্ষিপ্ত description থাকে। `apropos` keyword দিয়ে সেই description-গুলো search করে।

Syntax:

```
apropos <keyword>
```

Example:

```
apropos sudo
```

Output:

```
sudo (8)             - execute a command as another user
sudo.conf (5)        - configuration for sudo front end
sudo_plugin (8)      - Sudo Plugin API
sudo_root (8)        - How to run administrative commands
sudoedit (8)         - execute a command as another user
sudoers (5)          - default sudo security policy plugin
sudoreplay (8)       - replay sudo session logs
visudo (8)           - edit the sudoers file
```

এটি `sudo`-সম্পর্কিত manual ও tool খুঁজে দেয়।

## 7. ExplainShell

কোনো বড় command বুঝতে সমস্যা হলে ব্যবহার করো:

[https://explainshell.com/](https://explainshell.com/?utm_source=chatgpt.com)

এটি command-এর বিভিন্ন অংশ বুঝতে সাহায্য করে।

মনে রাখবে: নতুন command-এর option বুঝতে `man` বা `--help` ব্যবহার করো। নির্দিষ্ট keyword দিয়ে manual খুঁজতে `apropos` ব্যবহার করো। Tool নিয়ে পরীক্ষা-নিরীক্ষা করাও শেখার গুরুত্বপূর্ণ অংশ।
