# Package Management

## 1. Package Management কী?

Linux-এ software install, update, upgrade ও remove করার জন্য Package Manager ব্যবহার করা হয়।

Package হলো একটি archive file, যার মধ্যে software-এর binary, configuration file, dependency information এবং update-এর তথ্য থাকে।

Package Management-এর প্রধান কাজ:

- Package download করা
- Dependency resolve করা
- Standard binary package format ব্যবহার করা
- Software-এর installation ও configuration-এর নির্দিষ্ট location রাখা
- System-related configuration ও functionality পরিচালনা করা
- Quality control করা

Linux-এ `.deb`, `.rpm` ইত্যাদি বিভিন্ন package format রয়েছে। Software-টি সংশ্লিষ্ট package হিসেবে available থাকতে হয়।

Package Manager package-এর প্রয়োজনীয় পরিবর্তনগুলো system-এ প্রয়োগ করে software install করে। কোনো dependency missing থাকলে এটি warning দিতে পারে অথবা repository থেকে dependency download করে install করতে পারে। Software remove করার সময় package-এর তথ্য ও configuration অনুযায়ী সংশ্লিষ্ট file মুছে দেয়।

## 2. Common Package Managers

| Command    | কাজ                                                                                                                                                                                                                                                               |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dpkg`     | Debian package install, build, remove ও manage করে।                                                                                                                                                                                                               |
| `apt`      | Package management-এর high-level command-line interface।                                                                                                                                                                                                          |
| `aptitude` | `apt`-এর বিকল্প high-level package manager interface।                                                                                                                                                                                                             |
| `snap`     | Snap package install, configure, refresh ও remove করে। Cloud, server, desktop এবং IoT-এর জন্য apps ও utilities distribute করতে ব্যবহৃত হয়।                                                                                                                       |
| `gem`      | Ruby-এর standard package manager RubyGems-এর frontend।                                                                                                                                                                                                            |
| `pip`      | Python package installer। Debian archive-এ নেই এমন Python package install করতে recommended। Git, Mercurial ও Bazaar repository-এর সঙ্গে কাজ করতে পারে, বিস্তারিত output দেয় এবং installation শুরুর আগে সব requirements download করে partial installation এড়ায়। |
| `git`      | দ্রুত ও scalable distributed version control system; এতে high-level operations এবং internal functionality-তে access রয়েছে।                                                                                                                                       |

Practice করার জন্য নিজের VM-এ package install করে পরীক্ষা করা ভালো। উদাহরণে `apt` দিয়ে `git` install করা হবে।

## 3. Advanced Package Manager (APT)

Debian-based Linux distribution-এ APT (Advanced Package Tool) ব্যবহার করা হয়।

- Package হলো archive file, যার মধ্যে একাধিক `.deb` file থাকতে পারে।
- `dpkg` দিয়ে `.deb` file থেকে program install করা যায়।
- আলাদা `.deb` file install করলে dependency সমস্যা হতে পারে।
- APT প্রয়োজনীয় dependencies install করার প্রক্রিয়াকে সহজ করে।

### APT Repository

Linux distribution-গুলো software repository ব্যবহার করে। নতুন software install বা update করার সময় system repository থেকে package খোঁজে।

Repository হতে পারে:

- `stable`
- `testing`
- `unstable`

সাধারণত distribution-এর stable বা main repository ব্যবহার করা হয়।

Repository configuration দেখতে:

```
cat /etc/apt/sources.list
```

Parrot OS-এর repository list:

```
cat /etc/apt/sources.list.d/parrot.list
```

Output:

```
# parrot repository
# this file was automatically generated by parrot-mirror-selector
deb http://htb.deb.parrot.sh/parrot/ rolling main contrib non-free
#deb-src https://deb.parrot.sh/parrot/ rolling main contrib non-free
deb http://htb.deb.parrot.sh/parrot/ rolling-security main contrib non-free
#deb-src https://deb.parrot.sh/parrot/ rolling-security main contrib non-free
```

### APT Cache-এ Package Search

APT Cache installed system-এর package সম্পর্কে offline-এ তথ্য দিতে পারে।

Impacket সম্পর্কিত package খুঁজতে:

## Quick Revision

| Command                                | কাজ                              |
| -------------------------------------- | -------------------------------- |
| `apt-cache search impacket`            | Impacket-সম্পর্কিত package খোঁজা |
| `apt-cache show impacket-scripts`      | Package-এর বিস্তারিত তথ্য দেখা   |
| `apt list --installed`                 | Installed package-এর তালিকা দেখা |
| `sudo apt install impacket-scripts -y` | APT দিয়ে package install        |
| `git clone URL`                        | Git repository download          |
| `wget URL`                             | URL থেকে file download           |
| `sudo dpkg -i package.deb`             | Local `.deb` package install     |
| `strace -h`                            | `strace`-এর help দেখা            |

মূল পার্থক্য: `apt` repository ও dependencies নিয়ে কাজ সহজ করে; `dpkg` সরাসরি `.deb` package manage করে; `git` repository থেকে source code ও tools download করতে সাহায্য করে।
