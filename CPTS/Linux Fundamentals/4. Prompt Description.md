# Prompt Description


## 1. Bash Prompt কী?

Bash prompt হলো terminal-এর সেই text, যা দেখে বোঝা যায় system command নেওয়ার জন্য প্রস্তুত।

সাধারণত এতে থাকে:

- `username` — কে login করেছে।
- `hostname` — computer-এর নাম।
- `current working directory` — বর্তমানে কোন directory-তে আছি।

Prompt-এর পরে cursor থাকে, যেখানে command লিখি।

```
<username>@<hostname><current working directory>$
```

## 2. `$`, `#` ও `~` এর অর্থ

Home directory বোঝাতে `~` ব্যবহার হয়। Login করার পর এটি default directory।

```
<username>@<hostname>[~]$
```

- `$` — সাধারণ user-এর prompt।
- `#` — `root` user-এর prompt।

উদাহরণ:

```
root@htb[/htb]#
```

কোনো target system-এ shell upload ও run করলে username, hostname বা directory দেখা নাও যেতে পারে। `PS1` variable সঠিকভাবে set না থাকলে এমন হতে পারে।

Unprivileged user:

```
$
```

Privileged root user:

```
#
```

## 3. PS1 Variable

`PS1` variable terminal prompt-এর format নিয়ন্ত্রণ করে। এটি customize করে username, hostname, current directory, color ও special character দেখানো যায়।

Penetration testing-এর সময় prompt-এ IP address, date, time এবং শেষ command সফল হয়েছে নাকি ব্যর্থ হয়েছে—এসবও দেখানো যায়। এতে নিজের কাজ track করা সহজ হয়।

- `script` tool দিয়ে command record করা যায়।
- User-এর home directory-তে থাকা `.bash_history` file দেখে ব্যবহৃত command review করা যায়।
- Command-গুলো date ও time অনুযায়ী সাজিয়ে documentation ও analysis করা যায়।
- Current directory-এর শুধু নামের পরিবর্তে সম্পূর্ণ path এবং প্রয়োজন হলে target-এর IP address দেখানো যায়।

Bash prompt সাধারণত `.bashrc` configuration file-এ special character ব্যবহার করে customize করা যায়।

## 4. PS1 Special Characters

| Special character | কাজ                                    |
| ----------------- | -------------------------------------- |
| `\d`              | Date (Mon Feb 6)                       |
| `\D{%Y-%m-%d}`    | Date (YYYY-MM-DD)                      |
| `\H`              | Full hostname                          |
| `\j`              | Shell-এর managed job-এর সংখ্যা         |
| `\n`              | Newline                                |
| `\r`              | Carriage return                        |
| `\s`              | Shell-এর নাম                           |
| `\t`              | 24-hour time (HH:MM:SS)                |
| `\T`              | 12-hour time (HH:MM:SS)                |
| `\@`              | Current time                           |
| `\u`              | Current username                       |
| `\w`              | Current working directory-এর full path |

Prompt customize করলে terminal আরও ব্যক্তিগত ও কার্যকর করা যায়। System-এর অবস্থা বোঝা, troubleshooting ও problem-solving-এও সাহায্য করে।

Terminal-এর color scheme, font ও অন্যান্য settings-ও পরিবর্তন করা যায়।

Windows GUI-তে যেমন logged-in user, computer name ও বর্তমান directory সম্পর্কে জানা যায়, Bash prompt-ও একই ধরনের তথ্য দেখায়। নিজের প্রয়োজন অনুযায়ী এটি পরিবর্তন করা যায়।
