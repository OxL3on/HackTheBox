# Working with Web Services


## 1. Web Services কী?

Web development-এ browser ও web server-এর মধ্যে communication খুব গুরুত্বপূর্ণ। Linux-এ web server চালানোর জন্য জনপ্রিয় software হলো:

- Nginx
- IIS
- Apache

Apache একটি বহুল ব্যবহৃত web server। এটি browser ও website-এর মধ্যে communication পরিচালনা করে।

Apache-এর শক্তি হলো এর modularity—অর্থাৎ বিভিন্ন module যোগ করে নতুন functionality ব্যবহার করা যায়।

### Apache-এর গুরুত্বপূর্ণ Modules

| Module        | কাজ                                                               |
| ------------- | ----------------------------------------------------------------- |
| `mod_ssl`     | Browser ও web server-এর মধ্যে communication encrypt করে।          |
| `mod_proxy`   | Request সঠিক destination-এ পাঠায়; proxy server তৈরিতে কাজে লাগে। |
| `mod_headers` | HTTP headers পরিবর্তন করতে দেয়।                                  |
| `mod_rewrite` | URL পরিবর্তন ও rewrite করতে দেয়।                                 |

Apache শুধু static content নয়, server-side scripting language ব্যবহার করে dynamic webpage-ও তৈরি করতে পারে।

উদাহরণ: PHP, Perl, Ruby, Python, JavaScript, Lua ও .NET।

### Start

Apache চালু করার জন্য `apache2ctl`, `systemctl` বা `service` ব্যবহার করা যায়। `apache2` binary সরাসরি চালানো সাধারণত recommended নয়, কারণ default configuration-এ environment variables ব্যবহৃত হয়।

```
sudo systemctl start apache2
```

Apache চালু হলে browser-এ যাও:

`http://localhost`

Apache-এর default HTTP port হলো 80। URL-এ অন্য port উল্লেখ না করলে HTTP browser সাধারণত এই port ব্যবহার করে।

Default page-এ “It works!” দেখা গেলে বোঝা যায় web server কাজ করছে।

### Port পরিবর্তন করা

Pwnbox-এ Apache start করতে সমস্যা হলে port 80 অন্য service ব্যবহার করছে কি না পরীক্ষা করতে হবে।

Port configuration file:

```
/etc/apache2/ports.conf
```

উদাহরণ:

```
# If you just change the port or add more ports here, you will likely also
# have to change the VirtualHost statement in
# /etc/apache2/sites-enabled/000-default.conf

Listen 8080

<IfModule ssl_module>
Listen 443
</IfModule>

<IfModule mod_gnutls.c>
Listen 443
</IfModule>
```

এখানে HTTP-এর জন্য port `8080` নির্ধারণ করা হয়েছে। Port পরিবর্তনের পাশাপাশি প্রয়োজন হলে VirtualHost configuration-ও পরিবর্তন করতে হবে।

Apache restart করার পর access করো:

`http://localhost:8080`

### `curl` দিয়ে পরীক্ষা

```
curl -I http://localhost:8080
```

`HTTP/1.1 200 OK` বোঝায় server request সফলভাবে handle করেছে।

## 3. cURL

cURL হলো command-line tool, যা HTTP, HTTPS, FTP, SFTP, FTPS ও SCP-এর মতো protocol দিয়ে data transfer করতে পারে। এটি command line থেকেই website access, request ও response পরীক্ষা করতে সাহায্য করে।

বেশিরভাগ Linux system-এ cURL আগে থেকেই install করা থাকে।

### Website Content দেখা

```
curl http://localhost
```

Output-এর অংশ:

```

<html xmlns="http://www.w3.org/1999/xhtml">

    Modified from the Debian original for Ubuntu
    Last updated: 2016-11-16
    See: https://launchpad.net/bugs/1288690

  <head>
    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
    <title>Apache2 Ubuntu Default Page: It works</title>
    <style type="text/css" media="screen">
```

`curl` website-এর HTML source STDOUT-এ দেখায়।

Browser HTML, CSS ও JavaScript render করে visual webpage দেখায়। কিন্তু `curl` দিয়ে সাধারণত response content ও source সরাসরি দেখা যায়।

এটি webpage-এর source inspect এবং server response বিশ্লেষণে কাজে লাগে।

## 4. Wget

`wget` হলো `curl`-এর বিকল্প একটি tool। এটি terminal থেকে HTTP বা FTP server থেকে file download করতে পারে।

### Website Download করা

```
wget http://localhost
```

Output:

```
--2020-05-15 17:43:52--  http://localhost/
Resolving localhost (localhost)... 127.0.0.1
Connecting to localhost (localhost)|127.0.0.1|:80... connected.
HTTP request sent, awaiting response... 200 OK
Length: 10918 (11K) [text/html]
Saving to: 'index.html'

index.html                 100%[=======================================>]  10,66K  --.-KB/s    in 0s

2020-05-15 17:43:52 (33,0 MB/s) - ‘index.html’ saved [10918/10918]
```

এখানে website-এর content `index.html` নামে local file-এ save হয়েছে।

পার্থক্য:

- `curl http://localhost` — response content terminal-এ দেখায়।
- `wget http://localhost` — content download করে local file-এ save করে।

## 5. Python 3 Web Server

File transfer-এর জন্য Python 3 দিয়েও সহজে web server চালানো যায়।

এই উদাহরণে WordPress installation directory-তে `readme.html` file রয়েছে।

### Server চালু করা

```
python3 -m http.server
```

Output:

```
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```

Default port হলো TCP/8000। Command যে directory থেকে চালানো হয়, সেই directory-র content server থেকে access করা যায়।

### Server Request-এর Logs

Server চালু রেখে request করলে logs দেখা যায়:

```
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
127.0.0.1 - - [15/May/2020 17:56:29] "GET /readme.html HTTP/1.1" 200 -
127.0.0.1 - - [15/May/2020 17:56:29] "GET /wp-admin/css/install.css?ver=20100228 HTTP/1.1" 200 -
127.0.0.1 - - [15/May/2020 17:56:29] "GET /wp-admin/images/wordpress-logo.png HTTP/1.1" 200 -
127.0.0.1 - - [15/May/2020 17:56:29] "GET /wp-admin/images/wordpress-logo.svg?ver=20131107 HTTP/1.1" 200 -
```

এখানে কোন resource-এর জন্য request এসেছে, কোন path access করা হয়েছে এবং response status কী ছিল তা দেখা যায়।

উদাহরণস্বরূপ, `200` হলো successful HTTP response status।

## 6. Penetration Testing-এ শেখার পদ্ধতি

Web server নিয়ে কাজ করার সময় সব সমস্যার সমাধান আগে থেকেই জানা থাকবে না। তাই:

- নতুন পরিস্থিতিতে নিজে research করতে হবে।
- বিভিন্ন approach পরীক্ষা করতে হবে।
- নিজের মতো solution খুঁজতে শিখতে হবে।
- বাস্তব সমস্যায় সবসময় একটিমাত্র solution নাও থাকতে পারে।

এই learning process-এর উদ্দেশ্য হলো research, problem-solving ও adaptability বাড়ানো।

## Quick Revision

| Tool / Feature                 | কাজ                                   |
| ------------------------------ | ------------------------------------- |
| Apache                         | Web server চালানো                     |
| `mod_ssl`                      | Communication encryption              |
| `mod_proxy`                    | Request অন্য destination-এ পাঠানো     |
| `mod_headers`                  | HTTP header পরিবর্তন                  |
| `mod_rewrite`                  | URL rewrite                           |
| `sudo systemctl start apache2` | Apache চালু করা                       |
| `/etc/apache2/ports.conf`      | Apache listening port configure করা   |
| `curl -I URL`                  | HTTP response headers দেখা            |
| `curl URL`                     | Response content terminal-এ দেখা      |
| `wget URL`                     | Content local file-এ download করা     |
| `python3 -m http.server`       | TCP/8000-এ Python web server চালু করা |

মনে রাখবে: `curl` মূলত request ও response পরীক্ষা করতে কাজে লাগে, `wget` file download করতে সুবিধাজনক, আর Python 3 Web Server দ্রুত কোনো directory HTTP-এর মাধ্যমে share করতে সাহায্য করে।
