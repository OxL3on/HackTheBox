# Filter Contents


## 1. File Content দেখার Tools

Linux terminal থেকে text file না খুলেই content পড়া, search করা, sort করা ও filter করার জন্য কয়েকটি গুরুত্বপূর্ণ tool আছে।

- `more` ও `less`: File এক screen করে দেখায়; এগুলোকে pager বলে।
- `head`: File-এর প্রথম দিকের line দেখায়।
- `tail`: File-এর শেষ দিকের line দেখায়।
- `sort`: Content sort করে।
- `grep`: নির্দিষ্ট pattern খোঁজে।
- `cut`: নির্দিষ্ট field বের করে।
- `tr`: Character পরিবর্তন করে।
- `column`: Output table আকারে সাজায়।
- `awk`: নির্দিষ্ট field নিয়ে কাজ করে।
- `sed`: Text replace করে।
- `wc`: Line বা character গণনা করে।

## 2. `more`

`more` file-এর content এক screen করে দেখায়। বড় file পড়তে সুবিধা হয়।

```
cat /etc/passwd | more
```

`/etc/passwd` file-এ system-এর user information থাকে, যেমন username, UID, GID, home directory এবং default shell।

উদাহরণ:

```
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
sync:x:4:65534:sync:/bin:/bin/sync
<SNIP>
--More--
```

- `[Q]` চাপলে pager বন্ধ হবে।
- `more` বন্ধ করার পর দেখা output terminal-এ থেকে যায়।

## 3. `less`

`less`-ও file এক screen করে দেখায়, তবে `more`-এর তুলনায় বেশি feature আছে।

```
less /etc/passwd
```

এর output দেখতে প্রায় `more`-এর মতো।

- `[Q]` চাপলে বন্ধ হবে।
- `less` বন্ধ করার পর দেখা output terminal-এ থেকে যায় না।

মনে রাখবে: `more` এবং `less`—দুটিই বড় file পড়তে ও সামনে-পেছনে navigate করতে কাজে লাগে; file পরিবর্তন করে না।

## 4. `head`

File-এর প্রথম দিকের line দেখতে `head` ব্যবহার করা হয়। Default হিসেবে প্রথম ১০টি line দেখায়।

```
head /etc/passwd
```

Output:

```
sync:x:4:65534:sync:/bin:/bin/sync
games:x:5:60:games:/usr/games:/usr/sbin/nologin

mail:x:8:8:mail:/var/mail:/usr/sbin/nologin
news:x:9:9:news:/var/spool/news:/usr/sbin/nologin
```

## 5. `tail`

## 6. `sort`

## 7. `grep`

নির্দিষ্ট pattern-যুক্ত line খুঁজতে `grep` ব্যবহার করা হয়।

### নির্দিষ্ট shell-যুক্ত user খোঁজা

```
cat /etc/passwd | grep "/bin/bash"
```

Output:

```
root:x:0:0:root:/root:/bin/bash
mrb3n:x:1000:1000:mrb3n:/home/mrb3n:/bin/bash
cry0l1t3:x:1001:1001::/home/cry0l1t3:/bin/bash
htb-student:x:1002:1002::/home/htb-student:/bin/bash
```

এখানে `/bin/bash` থাকা line-গুলো দেখানো হয়েছে।

### `-v` দিয়ে line বাদ দেওয়া

`grep -v` নির্দিষ্ট pattern-যুক্ত line বাদ দেয়।

```
cat /etc/passwd | grep -v "false\|nologin"
```

Output:

```
root:x:0:0:root:/root:/bin/bash
sync:x:4:65534:sync:/bin:/bin/sync
postgres:x:111:117:PostgreSQL administrator,,,:/var/lib/postgresql:/bin/bash
user6:x:1000:1000:,,,:/home/user6:/bin/bash
```

এখানে `false` অথবা `nologin` থাকা line বাদ দেওয়া হয়েছে।

`false\|nologin`-এ `\|` হলো এই pattern-এ `false` অথবা `nologin` match করার উপায়।

## 8. `cut`

একটি line থেকে নির্দিষ্ট field বের করতে `cut` ব্যবহার করা হয়।

- `-d`: Field আলাদা করার delimiter নির্ধারণ করে।
- `-f`: কোন field দেখাবে তা নির্ধারণ করে।

উদাহরণ:

```
cat /etc/passwd | grep -v "false\|nologin" | cut -d":" -f1
```

Output:

```
root
sync
postgres
mrb3n
cry0l1t3
htb-student
```

এখানে:

- `-d":"`: Colon (`:`) দিয়ে field আলাদা করা হচ্ছে।
- `-f1`: প্রথম field, অর্থাৎ username দেখানো হচ্ছে।

## 9. `tr`

একটি character-কে অন্য character দিয়ে replace করতে `tr` ব্যবহার করা হয়।

```
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " "
```

Output:

```
root x 0 0 root /root /bin/bash
sync x 4 65534 sync /bin /bin/sync
postgres x 111 117 PostgreSQL administrator,,, /var/lib/postgresql /bin/bash
mrb3n x 1000 1000 mrb3n /home/mrb3n /bin/bash
cry0l1t3 x 1001 1001  /home/cry0l1t3 /bin/bash
htb-student x 1002 1002  /home/htb-student /bin/bash
```

এখানে colon (`:`) পরিবর্তন করে space দেওয়া হয়েছে।

## 10. `column`

Output-কে table-এর মতো সুন্দরভাবে সাজাতে `column -t` ব্যবহার করা হয়।

```
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | column -t
```

Output:

```
root         x  0     0      root               /root                /bin/bash
sync         x  4     65534  sync               /bin                 /bin/sync
postgres     x  111   117    PostgreSQL         administrator,,,    /var/lib/postgresql     /bin/bash
mrb3n        x  1000  1000   mrb3n              /home/mrb3n          /bin/bash
cry0l1t3     x  1001  1001   /home/cry0l1t3     /bin/bash
htb-student  x  1002  1002   /home/htb-student  /bin/bash
```

এখানে `-t` output-কে tabular format-এ সাজায়।

## 11. `awk`

`awk` দিয়ে line-এর নির্দিষ্ট field বের করা যায়।

- `$1`: প্রথম field।
- `$NF`: শেষ field; `NF` হলো field-এর সংখ্যা।

আগের output-এ `postgres` user-এর description-এর মধ্যে space থাকায় অতিরিক্ত column দেখা যায়। শুধু username ও শেষ field, অর্থাৎ shell দেখাতে:

```
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}'
```

Output:

```
root /bin/bash
sync /bin/sync
postgres /bin/bash
mrb3n /bin/bash
cry0l1t3 /bin/bash
htb-student /bin/bash
```

এতে প্রতিটি line-এর প্রথম ও শেষ field দেখানো হয়।

## 12. `sed`

`sed` হলো stream editor। এটি input বা file-এর text-এ pattern খুঁজে replace করতে পারে। সাধারণত regex ব্যবহার করা হয়।

উদাহরণ: `bin`-কে `HTB` দিয়ে replace করা।

```
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | sed 's/bin/HTB/g'
```

Output:

```
root /HTB/bash
sync /HTB/sync
postgres /HTB/bash
mrb3n /HTB/bash
cry0l1t3 /HTB/bash
htb-student /HTB/bash
```

Syntax:

```
sed 's/old/new/g'
```

- `s`: Substitute বা replace command।
- `bin`: যে text খুঁজবে।
- `HTB`: যে text দিয়ে replace করবে।
- `g`: প্রতিটি line-এ সব matching occurrence replace করবে।

## 13. `wc`

Line বা character-এর সংখ্যা গণনা করতে `wc` ব্যবহার করা হয়। `-l` দিলে শুধু line গণনা করে।

```
cat /etc/passwd | grep -v "false\|nologin" | tr ":" " " | awk '{print $1, $NF}' | wc -l
```

Output:

```
6
```

অর্থাৎ filtered output-এ ৬টি line আছে।
