# Navigation


## 1. Navigation কী?

Linux-এ navigation মানে directory ও file-এর মধ্যে চলাচল করা এবং সেগুলো নিয়ে কাজ করা। File ও folder তৈরি, move, edit, delete, search এবং redirection শেখার আগে navigation জানা জরুরি।

Practice করার সময় local VM ব্যবহার করা এবং system ক্ষতিগ্রস্ত হলে restore করার জন্য আগে VM snapshot তৈরি করা ভালো।

## 2. `pwd` — বর্তমান Directory দেখা

`pwd` (Print Working Directory) বর্তমান directory-এর path দেখায়।

```
cry0l1t3@htb[~]$ pwd

/home/cry0l1t3
```

## 3. `ls` — File ও Directory দেখা

`ls` বর্তমান directory-এর file ও folder দেখায়।

```
cry0l1t3@htb[~]$ ls

Desktop  Documents  Downloads  Music  Pictures  Public  Templates  Videos
```

### `ls -l` — বিস্তারিত তথ্য

```
cry0l1t3@htb[~]$ ls -l

total 32
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:37 Desktop
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Documents
drwxr-xr-x 3 cry0l1t3 htbacademy 4096 Nov 15 03:26 Downloads
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Music
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Pictures
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Public
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Templates
drwxr-xr-x 2 cry0l1t3 htbacademy 4096 Nov 13 17:34 Videos
```

`total 32` মানে directory listing-এর file ও directory-গুলো মোট 32টি 1024-byte block ব্যবহার করছে।

\\(32 \times 1024 = 32,768\\) bytes বা 32 KB।

| Output         | অর্থ                                                                |
| -------------- | ------------------------------------------------------------------- |
| `drwxr-xr-x`   | File type ও permissions                                             |
| `2`            | Hard link-এর সংখ্যা                                                 |
| `cry0l1t3`     | Owner                                                               |
| `htbacademy`   | Group owner                                                         |
| `4096`         | File size বা directory information সংরক্ষণে ব্যবহৃত block-এর সংখ্যা |
| `Nov 13 17:37` | Date ও time                                                         |
| `Desktop`      | Directory name                                                      |

## 4. `cd` — Directory পরিবর্তন

`cd` (Change Directory) দিয়ে অন্য directory-তে যাওয়া যায়।

```
cry0l1t3@htb[~]$ cd /dev/shm

cry0l1t3@htb[/dev/shm]$
```

সম্পূর্ণ path দিয়ে সরাসরি destination-এ যাওয়া যায়।

### `cd -` — আগের Directory-তে ফেরা

```
cry0l1t3@htb[/dev/shm]$ cd -

cry0l1t3@htb[~]$
```

### `cd ..` — Parent Directory-তে যাওয়া

- `.` = বর্তমান directory।
- `..` = parent directory।

```
cry0l1t3@htb[/dev/shm]$ cd ..

cry0l1t3@htb[/dev]$
```

## 5. Tab Auto-completion

Shell-এর autocomplete দিয়ে path বা directory-এর নাম দ্রুত লেখা যায়।

`cd /dev/s` লিখে `[TAB]` দুইবার চাপলে `/dev/`-এর `s` দিয়ে শুরু হওয়া entry দেখা যাবে।

```
cry0l1t3@htb[~]$ cd /dev/s [TAB 2x]

shm/ snd/
```

এরপর `h` যোগ করলে `sh` দিয়ে শুরু হওয়া directory হিসেবে `shm` complete করা যায়।

```
cry0l1t3@htb[/dev/shm]$ ls -la /dev/shm

total 0
drwxrwxrwt  2 root root   40 Mai 15 18:31 .
drwxr-xr-x 17 root root 4000 Mai 14 20:45 ..
```

এখানে `.` বর্তমান directory এবং `..` parent directory `/dev` বোঝায়।

## 6. Terminal পরিষ্কার করা

`clear` command terminal-এর screen পরিষ্কার করে।

```
cry0l1t3@htb[/dev]$ cd shm && clear
```

এখানে `cd shm && clear` মানে `cd shm` সফল হলে `clear` চালানো হবে।

Shortcut: `Ctrl + L`

## 7. Command History

আগে ব্যবহার করা command আবার খুঁজতে:

- `↑` — আগের command দেখা।
- `↓` — history-তে পরের command দেখা।
- `Ctrl + R` — command history search করা। এরপর command-এর কিছু text লিখে খুঁজতে পারো।
