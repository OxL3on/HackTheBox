# Introduction to Shell


## 1. Linux Shell কী?

Linux shell শেখা গুরুত্বপূর্ণ, কারণ অনেক server Linux-ভিত্তিক। Linux server-কে Windows server-এর তুলনায় কম error-prone মনে করা হয়। Web server-ও প্রায়ই Linux-ভিত্তিক হয়।

Shell বুঝতে ও ব্যবহার করতে পারলে Linux system কার্যকরভাবে control করা যায়।


- Terminal / Shell / Command line: Text-based interface, যার মাধ্যমে user command দিয়ে system control করে।
- Terminal user ও kernel-এর মধ্যে text-based input/output (I/O) interface দেয়।
- Console: সাধারণত text mode-এর screen বোঝায়, কোনো window নয়।
- Shell-কে text-based GUI-এর মতো ভাবা যায়, যেখানে command দিয়ে directory পরিবর্তন, file নিয়ে কাজ ও system information দেখা যায়। তবে shell-এর capability আরও বেশি।

## 2. Terminal Emulators

Terminal emulation হলো এমন software, যা terminal-এর কাজ অনুকরণ করে। এর সাহায্যে graphical user interface (GUI)-এর মধ্যে text-based program ব্যবহার করা যায়।

CLI (Command-Line Interface) একই terminal-এর ভেতরে অতিরিক্ত terminal হিসেবেও চলতে পারে।

সহজভাবে:

- Shell: মূল server room-এর মতো, যেখানে command process হয়।
- Terminal: Reception desk-এর মতো, যেখান দিয়ে shell-এ command বা request পাঠানো হয়।
- Terminal emulator: GUI-এর মধ্যে virtual reception desk, যা দিয়ে text-based command চালানো যায়।
- একাধিক CLI: একই interface-এর মধ্যে একাধিক virtual desk-এর মতো, যেগুলো দিয়ে আলাদাভাবে command পাঠানো যায়।

Terminal emulator ও multiplexer terminal-এর কাজ আরও সহজ করে। এগুলোর সাহায্যে:

- Terminal একাধিক pane-এ ভাগ করা যায়।
- একাধিক directory-তে কাজ করা যায়।
- আলাদা workspace তৈরি করা যায়।

উদাহরণ: Tmux


## 3. Shell

Linux-এ সবচেয়ে বেশি ব্যবহৃত shell হলো Bash (Bourne-Again Shell), যা GNU Project-এর অংশ।

Shell দিয়ে GUI-তে করা কাজগুলোও করা যায়। পাশাপাশি এটি program ও process-এর সঙ্গে আরও বেশি উপায়ে কাজ করতে এবং দ্রুত information পেতে সাহায্য করে।

ছোট-বড় script দিয়ে অনেক কাজ automate করা যায়, ফলে manual কাজ সহজ হয়।

Bash ছাড়াও অন্যান্য shell রয়েছে:

- [Ksh](https://en.wikipedia.org/wiki/KornShell?utm_source=chatgpt.com)
- [Zsh](https://en.wikipedia.org/wiki/Z_shell?utm_source=chatgpt.com)
- [Fish](https://en.wikipedia.org/wiki/Friendly_interactive_shell?utm_source=chatgpt.com)
