# User Management


## 1. User Management কী?

Linux-এ User Management হলো user account তৈরি, group-এ যুক্ত করা, account পরিবর্তন বা delete করা এবং অন্য user-এর permission ব্যবহার করে command চালানোর প্রক্রিয়া।

System administrator-কে সাধারণত যেসব কাজ করতে হয়:

- নতুন user account তৈরি করা।
- User-কে প্রয়োজনীয় group-এ যুক্ত করা।
- নির্দিষ্ট file ও directory-তে access দেওয়া।
- প্রয়োজন হলে অন্য user বা `root` হিসেবে command চালানো।

উদাহরণ: Alex নামে নতুন employee যোগ দিলে তার account তৈরি করে project files ও development tools ব্যবহারের জন্য উপযুক্ত group-এ যুক্ত করতে হবে।

## 2. User হিসেবে Command চালানো

উদাহরণ:

```
cat /etc/shadow
```

Output:

```
cat: /etc/shadow: Permission denied
```

`/etc/shadow` হলো Linux-এর গুরুত্বপূর্ণ system file। এতে user account-এর password-সংক্রান্ত তথ্য থাকে। Security-এর জন্য সাধারণ user সাধারণত এই file পড়তে পারে না; এর access সীমাবদ্ধ থাকে।

## 3. `sudo` দিয়ে Root হিসেবে Command চালানো

`sudo`-এর অর্থ superuser do। এটি অনুমোদিত user-কে অন্য user-এর privilege-এ command চালাতে দেয়; সাধারণত `root` হিসেবে।

```
sudo cat /etc/shadow
```

Output-এর উদাহরণ:

```
root:<SNIP>:18395:0:99999:7:::
daemon:*:17737:0:99999:7:::
bin:*:17737:0:99999:7:::
<SNIP>
```

এখানে `sudo` ব্যবহার করার কারণে command-টি `root` privilege-এ চালানো সম্ভব হয়েছে।

মনে রাখবে: `sudo` ব্যবহার করতে হলে user-এর উপযুক্ত permission থাকতে হবে। এটি সাধারণ user-কে স্বয়ংক্রিয়ভাবে সব privilege দেয় না।

## 4. গুরুত্বপূর্ণ User Management Commands

| Command    | কাজ                                                                              |
| ---------- | -------------------------------------------------------------------------------- |
| `sudo`     | অন্য user-এর privilege-এ command চালানো                                          |
| `su`       | Authentication-এর মাধ্যমে অন্য user ID-তে switch করা; default user হলো superuser |
| `useradd`  | নতুন user তৈরি করা বা নতুন user-এর default information পরিবর্তন করা              |
| `userdel`  | User account এবং সংশ্লিষ্ট file মুছে ফেলা                                        |
| `usermod`  | User account পরিবর্তন করা                                                        |
| `addgroup` | System-এ group যোগ করা                                                           |
| `delgroup` | System থেকে group সরানো                                                          |
| `passwd`   | User-এর password পরিবর্তন করা                                                    |

### `sudo` বনাম `su`

- `sudo`: নির্দিষ্ট command অন্য user-এর privilege-এ চালায়।
- `su`: অন্য user হিসেবে switch করে এবং একটি shell চালায়।

`su` উপযুক্ত user-এর credentials PAM-এর মাধ্যমে যাচাই করে।

## 5. Practice ও Security-এর গুরুত্ব

User account, permissions এবং authentication কীভাবে কাজ করে তা বুঝলে Linux system-এর security assessment করা সহজ হয়। এর মাধ্যমে misconfiguration ও সম্ভাব্য vulnerability শনাক্ত করা যায়।

Practice করার জন্য:

1. Controlled environment-এ নতুন user account তৈরি করো।
2. User-দের জন্য file ও directory তৈরি করো।
3. প্রয়োজনীয় group ও permissions নির্ধারণ করো।
4. File থেকে নির্দিষ্ট তথ্য পড়ো এবং filter করো।
5. Output redirect করে নতুন user-এর file বা directory-তে রাখো।
6. Command-গুলোর বিভিন্ন option পরীক্ষা করো।

Command-এর option দেখতে:

```
useradd --help
usermod --help
userdel --help
passwd --help
```

অথবা:

```
man useradd
man usermod
man userdel
man passwd
```

HTB target-এ practice করার সময় কিছু ভুল হলে target reset করে আবার শুরু করা যায়।

## Quick Revision

- User: Linux system-এর account।
- Group: একাধিক user-এর access একসঙ্গে পরিচালনা করতে সাহায্য করে।
- `sudo`: অন্য user-এর privilege-এ command চালায়।
- `su`: অন্য user হিসেবে switch করে shell চালায়।
- `useradd`: User তৈরি করে।
- `usermod`: User account পরিবর্তন করে।
- `userdel`: User account মুছে ফেলে।
- `addgroup` / `delgroup`: Group যোগ বা সরায়।
- `passwd`: Password পরিবর্তন করে।

মূল ধারণা: Linux-এ user, group, permissions ও authentication একসঙ্গে কাজ করে system-এর resource-এ কার access থাকবে তা নিয়ন্ত্রণ করে।
