# Service and Process Management


## 1. Service ও Daemon কী?

Service/Daemon হলো Linux-এর এমন program, যা background-এ চলে এবং সরাসরি user interaction ছাড়াই system-এর কাজ পরিচালনা করে।

Service প্রধানত দুই ধরনের:

### System Services

- System startup-এর সময় চালু হয়।
- Hardware-related কাজ ও OS-এর প্রয়োজনীয় components initialize করে।
- এগুলো ছাড়া system সঠিকভাবে কাজ নাও করতে পারে।

### User-Installed Services

- User নিজে install করে।
- Server applications ও অন্যান্য background processes এর উদাহরণ।
- অতিরিক্ত features ও functionality দেয়।

অনেক daemon-এর নামের শেষে `d` থাকে।

উদাহরণ:

- `sshd` — SSH daemon
- `systemd` — system ও service management

Service বা process নিয়ে সাধারণত পাঁচটি কাজ করতে হয়:

1. Start/Restart করা
2. Stop করা
3. Status ও logs দেখা
4. Boot-এর সময় Enable/Disable করা
5. Service/Process খুঁজে বের করা

### PID ও PPID

- PID (Process ID): প্রতিটি process-এর নিজস্ব ID।
- PPID (Parent Process ID): যে process অন্য process চালু করেছে, তার ID।
- `/proc/` directory: Linux process-গুলোর তথ্য থাকে।
- `systemd`: অধিকাংশ আধুনিক Linux distribution-এ boot-এর সময় শুরু হওয়া প্রথম process এবং এর PID হলো `1`।

## 2. Systemctl

`systemctl` দিয়ে systemd service পরিচালনা করা হয়।

### Service Start করা

OpenSSH service চালু করতে:

```
systemctl start ssh
```

```
systemctl status ssh
```

গুরুত্বপূর্ণ তথ্য:

- `Main PID: 846` — প্রধান process-এর PID।
- `port 22` — SSH server-এর listening port।

### Boot-এর সময় Service চালু রাখা

```
systemctl enable ssh
```

Output:

```
Synchronizing state of ssh.service with SysV service script with /lib/systemd/systemd-sysv-install.
Executing: /lib/systemd/systemd-sysv-install enable ssh
```

এতে system reboot হলে OpenSSH স্বয়ংক্রিয়ভাবে চালু হবে।

চালু থাকা SSH process পরীক্ষা করতে:

```
ps -aux | grep ssh
```

Output:

```
root       846  0.0  0.1  72300  5660 ?        Ss   Mai14   0:00 /usr/sbin/sshd -D
```

## 3. Kill a Process

একটি process চার ধরনের অবস্থায় থাকতে পারে:

- Running: চলছে।
- Waiting: কোনো event বা system resource-এর জন্য অপেক্ষা করছে।
- Stopped: থামানো হয়েছে।
- Zombie: বন্ধ হলেও process table-এ entry রয়ে গেছে।

Process পরিচালনার command:

- `kill`
- `pkill`
- `pgrep`
- `killall`

Process-এর সঙ্গে কাজ করতে signal পাঠানো হয়।

### গুরুত্বপূর্ণ Signals

| Signal           | কাজ                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------- |
| `1` — `SIGHUP`   | Controlling terminal বন্ধ হলে process-এ পাঠানো হয়।                                     |
| `2` — `SIGINT`   | Controlling terminal-এ `Ctrl + C` চাপলে process interrupt করার জন্য পাঠানো হয়।         |
| `3` — `SIGQUIT`  | Source অনুযায়ী `Ctrl + D` চাপলে quit করার জন্য পাঠানো হয়।                             |
| `9` — `SIGKILL`  | Process সঙ্গে সঙ্গে বন্ধ করে; cleanup করার সুযোগ দেয় না।                               |
| `15` — `SIGTERM` | Program terminate করার signal।                                                          |
| `19` — `SIGSTOP` | Program থামায়; process এটি handle করতে পারে না।                                        |
| `20` — `SIGTSTP` | `Ctrl + Z` চাপলে process suspend করার অনুরোধ করে; পরে user আবার এটি পরিচালনা করতে পারে। |

### Process Forcefully বন্ধ করা

কোনো program freeze করলে:

```
kill 9 <PID>
```

এখানে `<PID>`-এর জায়গায় process-এর ID দিতে হবে।

## 4. Background a Process

কখনো কোনো scan বা process চালানোর পর একই terminal-এ অন্য কাজ করতে হয়। তখন process-কে background-এ রাখা যায়।

### `Ctrl + Z` দিয়ে Suspend করা

`Ctrl + Z` চাপলে `SIGTSTP` signal পাঠিয়ে process suspend করা হয়। এটি তখন আর execute হয় না।

উদাহরণ:

```
ping -c 10 www.hackthebox.eu
```

Output:

```
PING www.hackthebox.eu (104.20.55.68) 56(84) bytes of data.
[Ctrl + Z]
[1]+  Stopped                 ping -c 10 www.hackthebox.eu
```

এরপর আরেকটি command চালানো:

```
vim tmpfile
```

আবার `Ctrl + Z` চাপলে:

```
[2]+  Stopped                 vim tmpfile
```

### Background Jobs দেখা

```
jobs
```

Output:

```
[1]+  Stopped                 ping -c 10 www.hackthebox.eu
[2]+  Stopped                 vim tmpfile
```

### `bg` দিয়ে Background-এ চালানো

`Ctrl + Z` শুধু process suspend করে। এটিকে background-এ আবার চালাতে `bg` ব্যবহার করা হয়।

```
bg
```

Output:

```
[1]+ ping -c 10 www.hackthebox.eu &
```

এরপর process চলতে থাকবে, আর একই terminal-এ অন্য কাজ করা যাবে।

Source-এর output:

```
--- www.hackthebox.eu ping statistics ---
10 packets transmitted, 0 received, 100% packet loss, time 113482ms

[ENTER]
[1]+  Exit 1                  ping -c 10 www.hackthebox.eu
```

### Command-এর শেষে `&` ব্যবহার

Command-এর শেষে `&` দিলে সেটি সরাসরি background-এ শুরু হয়।

```
ping -c 10 www.hackthebox.eu &
```

Output:

```
[1] 10825
PING www.hackthebox.eu (172.67.1.1) 56(84) bytes of data.
```

Process শেষ হলে output দেখা যায়:

```
--- www.hackthebox.eu ping statistics ---
10 packets transmitted, 0 received, 100% packet loss, time 9210ms

[ENTER]
[1]+  Exit 1                  ping -c 10 www.hackthebox.eu
```

## 5. Foreground a Process

Background process-এর তালিকা দেখতে:

```
jobs
```

Output:

```
[1]+  Running                 ping -c 10 www.hackthebox.eu &
```

Background process চলার সময় একই shell-এ অন্য কাজ করা যায়। Process শেষ হলে terminal-এ তার completion status দেখা যায়।

### `fg` দিয়ে Foreground-এ আনা

Background process-কে আবার foreground-এ এনে interact করতে:

```
fg 1
```

Output:

```
ping -c 10 www.hackthebox.eu

--- www.hackthebox.eu ping statistics ---
10 packets transmitted, 0 received, 100% packet loss, time 9206ms
```

এখানে `1` হলো job ID।

## 6. Execute Multiple Commands

একাধিক command একের পর এক চালানোর তিনটি উপায়:

1. Semicolon (`;`)
2. Double ampersand (`&&`)
3. Pipe (`|`)

এগুলোর পার্থক্য হলো আগের command সফল বা ব্যর্থ হলে পরের command কীভাবে চলবে।

### Semicolon (`;`)

`;` আগের command-এর result বা error উপেক্ষা করে পরের command চালায়।

```
echo '1'; echo '2'; echo '3'
```

Output:

```
1
2
3
```

মাঝখানে ভুল command থাকলেও পরের command চলবে:

```
echo '1'; ls MISSING_FILE; echo '3'
```

Output:

```
1
ls: cannot access 'MISSING_FILE': No such file or directory
3
```

এখানে `ls MISSING_FILE` ব্যর্থ হলেও `echo '3'` চালানো হয়েছে।

### Double Ampersand (`&&`)

`&&` ব্যবহার করলে আগের command সফল হলেই পরের command চলে। কোনো command ব্যর্থ হলে পরের command-গুলো চালানো হয় না।

```
echo '1' && ls MISSING_FILE && echo '3'
```

Output:

```
1
ls: cannot access 'MISSING_FILE': No such file or directory
```

এখানে `ls MISSING_FILE` ব্যর্থ হওয়ায় `echo '3'` চালানো হয়নি।

### Pipe (`|`)

Pipe একটি command-এর output পরের command-এর input হিসেবে পাঠায়। এটি শুধু আগের command-এর success বা failure-এর ওপর নয়, আগের command-এর output-এর ওপরও নির্ভর করে।

## Quick Revision

| Command / Symbol                       | কাজ                                                          |
| -------------------------------------- | ------------------------------------------------------------ |
| `systemctl start ssh`                  | SSH service চালু করা                                         |
| `systemctl status ssh`                 | Service-এর status দেখা                                       |
| `systemctl enable ssh`                 | Boot-এর সময় service চালু রাখা                               |
| `systemctl list-units --type=service`  | Service-এর তালিকা দেখা                                       |
| `journalctl -u ssh.service --no-pager` | SSH service-এর logs দেখা                                     |
| `ps -aux \\| grep ssh`                 | SSH-সম্পর্কিত process খোঁজা                                  |
| `kill -l`                              | Signal-এর তালিকা দেখা                                        |
| `kill 9 <PID>`                         | Process forcefully বন্ধ করা                                  |
| `Ctrl + Z`                             | Process suspend করা                                          |
| `jobs`                                 | Background jobs দেখা                                         |
| `bg`                                   | Suspended job background-এ চালানো                            |
| `command &`                            | Command সরাসরি background-এ চালানো                           |
| `fg 1`                                 | Job ID `1`-কে foreground-এ আনা                               |
| `;`                                    | আগের command সফল বা ব্যর্থ—দুই অবস্থাতেই পরের command চালানো |
| `&&`                                   | আগের command সফল হলে পরেরটি চালানো                           |
| `\\|`                                  | আগের command-এর output পরের command-এ পাঠানো                 |
