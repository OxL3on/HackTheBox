# **Moving Through the Network**

## **1. What is Lateral Movement?**

**Lateral Movement** হলো এমন কিছু technique, যার মাধ্যমে attacker একটি machine-এ access পাওয়ার পর network-এর অন্য machine-গুলোতে move করে।

এর উদ্দেশ্য:

- Attacker-এর লক্ষ্য অর্জন করা।
- Network restrictions bypass করা।
- Network-এ additional entry point তৈরি করা।
- Confusion তৈরি করে detection এড়ানো।

### **Lateral Movement Cycle**

এটি একবারের কাজ নয়; একটি continuous cycle:

1. পাওয়া credentials ব্যবহার করে অন্য machine-এ access নেওয়া।
2. নতুন machine-এ privilege escalation করা।
3. সম্ভব হলে নতুন credentials সংগ্রহ করা।
4. নতুন credentials দিয়ে আবার অন্য machine-এ move করা।

এই cycle কয়েকবার repeat হতে পারে। প্রথম machine-এ network access সীমিত থাকলে বেশি privilege থাকা অন্য machine-এ যেতে হয়।

## **2. A Quick Example**

ধরো, একটি red team engagement-এ লক্ষ্য হলো company's internal code repository-তে access পাওয়া।

1. Phishing campaign-এর মাধ্যমে Marketing department-এর workstation compromise করা হলো।
2. Marketing workstation firewall policy-এর কারণে code repository, database, administrative protocols ইত্যাদিতে access করতে পারে না।
3. Workstation-এ privilege escalation করে local users-এর password hashes সংগ্রহ করা হলো।
4. একজন local administrator-এর hash পাওয়া গেল।
5. Recon করে `DEV-001-PC` নামে developer-এর workstation পাওয়া গেল।
6. Administrator-এর password hash ব্যবহার করে `DEV-001-PC`-তে access নেওয়া হলো।
7. Developer workstation থেকে target code repository-তে access পাওয়া গেল।

**মনে রাখবে:** Lateral movement শুধু firewall bypass করার জন্য নয়, detection এড়াতেও কাজে লাগে। সরাসরি Marketing PC থেকে repository-তে না গিয়ে developer PC ব্যবহার করলে login audit logs-এ activity কম suspicious মনে হতে পারে।

## **3. The Attacker's Perspective**

Attacker বিভিন্ন administrative protocol ব্যবহার করে lateral movement করতে পারে।

Common protocols:

- **WinRM**
- **RDP**
- **VNC**
- **SSH**

এগুলো ব্যবহার করে network-এর অন্য machine-এ connect করা যায় এবং সাধারণ user-এর মতো আচরণ করা সম্ভব।

তবে account ও connection-এর মধ্যে consistency রাখতে হবে।

উদাহরণ:

- IT user-এর web server-এ RDP connection স্বাভাবিক হতে পারে।
- কিন্তু `Marketing-PC` থেকে local admin account দিয়ে `DEV-001-PC`-তে connection suspicious হতে পারে।

Attacker detection কঠিন করার জন্য আরও বিভিন্ন lateral movement technique ব্যবহার করে। কোনো technique-ই সম্পূর্ণ undetectable নয়।

## **4. Administrators and UAC**

Lateral movement-এর অনেক technique-এ administrator credentials ব্যবহার করা হয়। Windows-এ administrator দুই ধরনের হতে পারে:

1. Local account, যা local **Administrators** group-এর সদস্য।
2. Domain account, যা local **Administrators** group-এর সদস্য।

### **UAC (User Account Control)**

UAC local administrator-এর remote administrative access সীমিত করতে পারে।

**Local Administrator:**

- Default Administrator account ছাড়া অন্য local administrator remote connection করে সাধারণত administrative task চালাতে পারে না।
- RDP-এর interactive session দিয়ে administrative কাজ করা সম্ভব।
- RPC, SMB বা WinRM দিয়ে administrative task request করলে Windows তা deny করতে পারে।
- কারণ account-টি filtered **medium integrity token** নিয়ে login করে, যা privileged action আটকায়।

**Domain Administrator:**

- Local Administrators group-এর সদস্য domain account একই restriction-এর আওতায় পড়ে না।
- Full administrative privileges নিয়ে login করে।

### **Important**

- চাইলে এই security feature disable করা যায়।
- কিছু system-এ local ও domain administrator-এর মধ্যে পার্থক্য নাও থাকতে পারে।
- কোনো lateral movement technique কাজ না করলে UAC restriction-এর কারণে হতে পারে, বিশেষ করে non-default local administrator ব্যবহার করলে।

**Reference:** [User Account Control and remote restrictions](https://docs.microsoft.com/en-us/troubleshoot/windows-server/windows-security/user-account-control-and-remote-restriction?utm_source=chatgpt.com)

**মূল বিষয়:** Lateral Movement হলো এক machine থেকে অন্য machine-এ credentials ব্যবহার করে move করা, নতুন privilege ও credentials সংগ্রহ করা এবং লক্ষ্য অর্জন না হওয়া পর্যন্ত এই cycle repeat করা।
