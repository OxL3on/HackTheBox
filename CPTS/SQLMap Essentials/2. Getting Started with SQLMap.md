## **Getting Started with SQLMap**

**Basic Listing:**

```bash
sqlmap -h
```

**Advanced Listing:**

```bash
sqlmap -hh
```

```bash
sqlmap -u "http://www.example.com/vuln.php?id=1" --batch
```

Here -u is used to provide the target URL and —batch is used for skipping any required user-input, by automatically choosing using the default option.
