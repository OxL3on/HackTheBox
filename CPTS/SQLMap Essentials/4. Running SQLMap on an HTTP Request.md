## **Running SQLMap on an HTTP Request**


## 1. Introduction

SQLMap-এর HTTP request ঠিকভাবে configure করার জন্য অনেক options ও switches রয়েছে।

ভুল configuration-এর কারণে SQLi detect বা exploit নাও হতে পারে। যেমন:

- সঠিক cookie value না দেওয়া।
- অনেক বড় command line দিয়ে setup জটিল করা।
- POST data ভুলভাবে declare করা।

## 2. Curl Commands

SQLMap request setup করার সহজ উপায় হলো Browser Developer Tools-এর Network (Monitor) panel থেকে Copy as cURL ব্যবহার করা।

Supported browsers:

- Chrome
- Edge
- Firefox

[Network panel showing a GET request to www.example.com with a 404 status, and a context menu with options like 'Copy as cURL'.](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/58/M5UVR6n.png?utm_source=chatgpt.com)

পদ্ধতি:

1. Network panel থেকে request-এর `Copy as cURL` select করো।
2. Clipboard content command line-এ paste করো (`Ctrl-V`)।
3. Original `curl` command-এর জায়গায় `sqlmap` লিখো।

Example:

```
sqlmap 'http://www.example.com/?id=1' -H 'User-Agent: Mozilla/5.0 (X11; Ubuntu; Linux x86_64; rv:80.0) Gecko/20100101 Firefox/80.0' -H 'Accept: image/webp,*/*' -H 'Accept-Language: en-US,en;q=0.5' --compressed -H 'Connection: keep-alive' -H 'DNT: 1'
```

SQLMap-কে test করার জন্য অবশ্যই থাকতে হবে:

- SQLi test করার মতো parameter value, অথবা
- Automatic parameter finding-এর options: `--crawl`, `--forms` বা `-g`।

## 3. GET/POST Requests

### GET Request

`-u` / `--url` দিয়ে GET parameter দেওয়া হয়।

### POST Request

`--data` দিয়ে POST data পাঠানো হয়।

```
sqlmap 'http://www.example.com/' --data 'uid=1&name=test'
```

এখানে `uid` ও `name` parameter দুটোই SQLi-এর জন্য test হবে।

শুধু `uid` test করতে:

```
sqlmap 'http://www.example.com/' --data 'uid=1&name=test' -p uid
```

অথবা data-এর মধ্যে `*` marker ব্যবহার করতে:

```
sqlmap 'http://www.example.com/' --data 'uid=1*&name=test'
```

## 4. Full HTTP Requests

অনেক header value বা বড় POST body-সহ complex HTTP request দিতে `-r` ব্যবহার করা হয়।

- সম্পূর্ণ HTTP request একটি text file-এ রাখতে হয়।
- সাধারণত `Burp` proxy থেকে request capture করা যায়।

[HTTP GET request to www.example.com with headers including User-Agent and Accept-Language.](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/58/x7ND6VQ.png?utm_source=chatgpt.com)

Burp থেকে HTTP request:

```
GET /?id=1 HTTP/1.1
Host: www.example.com
User-Agent: Mozilla/5.0 (X11; Ubuntu; Linux x86_64; rv:80.0) Gecko/20100101 Firefox/80.0
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8
Accept-Language: en-US,en;q=0.5
Accept-Encoding: gzip, deflate
Connection: close
Upgrade-Insecure-Requests: 1
DNT: 1
If-Modified-Since: Thu, 17 Oct 2019 07:18:26 GMT
If-None-Match: "3147526947"
Cache-Control: max-age=0
```

Request file তৈরির উপায়:

1. Burp থেকে HTTP request copy করে file-এ লিখতে পারো।
2. Burp-এ request-এর ওপর right-click করে `Copy to file` select করতে পারো।
3. Browser Developer Tools থেকে `Copy` > `Copy Request Headers` ব্যবহার করেও file তৈরি করা যায়।

SQLMap চালানো:

```
sqlmap -r req.txt
```

Example output:

```
[*] starting @ 14:32:59 /2020-09-11/

[14:32:59] [INFO] parsing HTTP request from 'req.txt'
[14:32:59] [INFO] testing connection to the target URL
[14:32:59] [INFO] testing if the target URL content is stable
[14:33:00] [INFO] target URL content is stable
```

Tip: `--data`-এর মতো request file-এর মধ্যেও `*` দিয়ে injection parameter mark করা যায়।

Example:

```
/?id=*
```

## 5. Custom SQLMap Requests

SQLMap-এর request manually configure করার জন্য বিভিন্ন switches ও options রয়েছে।

### Cookie নির্ধারণ

Cookie value `PHPSESSID=ab4530f4a7d10448457fa8b0eadac29c` দিতে `--cookie` ব্যবহার করা হয়।

```
sqlmap ... --cookie='PHPSESSID=ab4530f4a7d10448457fa8b0eadac29c'
```

একই কাজ `-H/--header` দিয়েও করা যায়:

```
sqlmap ... -H='Cookie:PHPSESSID=ab4530f4a7d10448457fa8b0eadac29c'
```

একইভাবে নিচের options দিয়ে HTTP header value নির্ধারণ করা যায়:

- `--host`
- `--referer`
- `-A/--user-agent`

### Random User-Agent

`--random-agent` ব্যবহার করলে SQLMap-এর database থেকে random regular browser User-Agent select হয়।

এটি গুরুত্বপূর্ণ, কারণ অনেক protection solution SQLMap-এর default User-Agent চিনে HTTP traffic block করে।

Default User-Agent example:

```
User-agent: sqlmap/1.4.9.12#dev (http://sqlmap.org)
```

অন্যদিকে `--mobile` ব্যবহার করে smartphone imitate করা যায়।

### Header-এ SQLi Test

SQLMap default-এ শুধু HTTP parameter test করে।

Header-এ SQLi test করতে header value-এর পরে `*` marker দিতে হয়।

Example:

```
--cookie="id=1*"
```

একই নিয়ম request-এর অন্য অংশেও প্রযোজ্য।

### HTTP Method পরিবর্তন

GET ও POST ছাড়া অন্য method (যেমন `PUT`) ব্যবহার করতে `--method` ব্যবহার করা হয়।

```
sqlmap -u www.target.com --data='id=1' --method PUT
```

## 6. Custom HTTP Requests

SQLMap নিচের format-এর HTTP request support করে:

| Format         | Example                         |
| -------------- | ------------------------------- |
| Form-data POST | `id=1`                          |
| JSON           | `{"id":1}`                      |
| XML            | `<element><id>1</id></element>` |

- এই format-গুলোর support relaxed manner-এ implement করা হয়েছে।
- Parameter value কোথায় store করা হবে, তার ওপর strict constraint নেই।
- POST body ছোট ও simple হলে `--data` ব্যবহার করা যায়।
- Complex বা বড় POST body হলে `-r` ব্যবহার করা যায়।

### JSON Request Example

`req.txt`:

```
HTTP / HTTP/1.0
Host: www.example.com

{
  "data": [{
    "type": "articles",
    "id": "1",
    "attributes": {
      "title": "Example JSON",
      "body": "Just an example",
      "created": "2020-05-22T14:56:29.000Z",
      "updated": "2020-05-22T14:56:28.000Z"
    },
    "relationships": {
      "author": {
        "data": {"id": "42", "type": "user"}
      }
    }
  }]
}
```

SQLMap চালানো:

```
sqlmap -r req.txt
```

Example output:

```
[*] starting @ 00:03:44 /2020-09-15/

[00:03:44] [INFO] parsing HTTP request from 'req.txt'
JSON data found in HTTP body. Do you want to process it? [Y/n/q]
[00:03:45] [INFO] testing connection to the target URL
[00:03:45] [INFO] testing if the target URL content is stable
[00:03:46] [INFO] testing if HTTP parameter 'JSON type' is dynamic
[00:03:46] [WARNING] HTTP parameter 'JSON type' does not appear to be dynamic
[00:03:46] [WARNING] heuristic (basic) test shows that HTTP parameter 'JSON type' might not be injectable
```
