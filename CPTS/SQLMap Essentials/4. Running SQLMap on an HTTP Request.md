## **Running SQLMap on an HTTP Request**

**Curl Commands**

Network tab → Copy as cURL. Then change curl to sqlmap.

```bash
sqlmap 'http://www.example.com/?id=1' -H 'User-Agent: Mozilla/5.0 (X11; Ubuntu; Linux x86_64; rv:80.0) Gecko/20100101 Firefox/80.0' -H 'Accept: image/webp,*/*' -H 'Accept-Language: en-US,en;q=0.5' --compressed -H 'Connection: keep-alive' -H 'DNT: 1'
```

**GET/POST Requests**

`-u / --url` is for GET.

`--data` is for POST. 

```bash
sqlmap 'http://www.example.com/' --data 'uid=1&name=test'
```

If we know that only the uid parameter is vulnerable we can narrow down the tests to only this parameter using `-p uid` otherwise use `*` :

```bash
sqlmap 'http://www.example.com/' --data 'uid=1*&name=test'
```

**Full HTTP Requests**

Capture request in Burp. Burp → Copy to file.

```bash
sqlmap -r req.txt
```

**Custom SQLMap Requests**

- If there is a requirement to specify the (session) cookie value:

```bash
sqlmap ... --cookie='PHPSESSID=ab4530f4a7d10448457fa8b0eadac29c'
```

Same this can be does with the option `-H/--header` : 

```bash
sqlmap ... -H='Cookie:PHPSESSID=ab4530f4a7d10448457fa8b0eadac29c'
```

We can apply the same to options like `--host`, `--referer`, and `-A/--user-agent`

There is a switch `--random-agent` designed to randomly select a `User-agent`

The `--mobile` switch can be used to imitate the smartphone by using that same header value.

Also, if we wanted to specify an alternative HTTP method, other than `GET` and `POST` (e.g., `PUT`), we can utilize the option `--method`, as follows:

```bash
sqlmap -u www.target.com --data='id=1' --method PUT
```
