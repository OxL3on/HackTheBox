**Why GET Requests Matter**

A GET request sends its parameters as part of the URL. Because of this, the attacker can place the XSS payload directly inside the URL. You can obtain this URL by:

- Copying it from the browser's address bar after submitting the payload, or
- In the Network tab, right-clicking the GET request and selecting:
    - Copy → Copy URL
