## **DOM XSS**

Unlike Reflected XSS, where the input is sent to the back-end server through an HTTP request, DOM XSS is processed entirely in the browser using JavaScript. DOM XSS occurs when JavaScript changes the webpage through the Document Object Model (DOM).

**Checking the Network Tab**

Open Firefox Developer Tools:

- Press CTRL + SHIFT + I.
- Open the Network tab.
- Add the task again.

You will notice no HTTP requests are made. This tells us that:

- The input is not sent to the server.
- Everything is handled inside the browser.

**URL Uses `#` (Fragment)**

The URL now looks like:

```
http://SERVER_IP:PORT/#task=test
```

Notice the `#` (hashtag). Anything after `#` is a client-side parameter. This means:

- The browser processes the input.
- JavaScript reads the value.
- The data never reaches the back-end server.

This is a strong indication of DOM-based XSS.
